## 一滴血离开左心室后，要走哪两圈才回到原地？ {#step0 h2=s0t}

::: strings
nav0: 0 一滴血的路线
:::

第 0 步 · 一滴血的路线 {#s0k .step-kicker i18n=text}

这一步要回答：血液在体内走的是一条怎样的路线？人的血液循环是**两个环**：**体循环**——左心室把血泵出，经动脉到全身毛细血管送出氧气，再经静脉回到右心房；**肺循环**——右心室把血泵向肺，在肺毛细血管里吸进氧气，再经肺静脉回到左心房。图上颜色表示血液含氧量：红 = 含氧多，蓝紫 = 含氧少，这只是画法，真实血管里的血都是红色。按「播放」，看小圆点走完一圈，颜色在哪里变。 {#s0e .explain}

::: html step0-1
s0stage: 循环路线示意（不按真实比例）：顶部的环经过肺，底部的环经过全身；小圆点是一滴血，颜色是它此刻的含氧量
s0canvas: 血液循环示意图：一滴血从左心室出发，先经全身再回右心房，再经肺回左心房，颜色在毛细血管处改变
s0hr: 心率
s0play: 播放
s0next: 跳到下一段
s0reset: 回到起点
:::

结论：血液先后经体循环和肺循环，回到左心室才算一圈；颜色在两处毛细血管变——全身变蓝（氧被组织取走）、肺里变红（吸进氧气）。条件：示意图；真实一圈约需 1 分钟，本页加快约 10 倍，且「肺动脉含氧少、肺静脉含氧多」是按血流方向命名的。 {#s0result .readout i18n=text}

s0red: 含氧多，画成红色
s0blue: 含氧少，画成蓝紫色
s0mid: 正在交换氧气，颜色渐变

## 心脏为什么要分成四个腔，还要有瓣膜？ {#step1 h2=s1t}

::: strings
nav1: 1 心脏四个腔
:::

第 1 步 · 心脏四个腔 {#s1k .step-kicker i18n=text}

这一步要回答：心脏一个心动周期里，四个腔和瓣膜依次做什么？上面两个是**心房**（收血），下面两个是**心室**（泵血）；心房与心室之间、心室与动脉之间的**瓣膜**像单向门，只让血往前走。拖「周期进度」或按播放：先心房收缩把血挤进心室，再心室收缩把血射入动脉，然后全部放松、血回流进来。心率越快，一分钟泵出的血越多：心输出量 = 每搏输出量 × 心率。 {#s1e .explain}

::: html step1-1
s1stage: 心脏示意：左半为右心（接体循环回血），右半为左心（接肺回血）；腔变小表示收缩，绿色瓣膜表示打开，红色表示关闭；播放时动画放慢约 4 倍
s1canvas: 心脏四腔示意图：随周期进度，心房和心室先后收缩，瓣膜单向开合
s1hr: 心率
s1ph: 周期进度
s1play: 播放
:::

结论：瓣膜让血液只能单向流动，心房和心室接力收缩；心输出量 = 每搏输出量 × 心率。条件：每搏输出量取 70 mL；三段时长按约 1/8、3/8、4/8 周期示意，实际随心率会变。 {#s1result .readout i18n=text}

::: strings
s1pause: 暂停
s1ro: 周期 {ph}%：{state}；心率 {hr} 次/分，每个周期约 {T} s；心输出量 = {sv} mL × {hr} = {co} L/min。
s1st0: 心房收缩，血被挤进心室（房室瓣开、动脉瓣关）
s1st1: 心室收缩，血射入动脉（房室瓣关、动脉瓣开）
s1st2: 全部放松，血流回心房和心室（房室瓣开、动脉瓣关）
:::

## 为什么血在毛细血管里流得最慢？ {#step2 h2=s2t}

::: strings
nav2: 2 三种血管
:::

第 2 步 · 三种血管 {#s2k .step-kicker i18n=text}

这一步要回答：同样一股血流，经过不同的血管，流速怎么变？血流量 Q（每分钟流过的血量）在整条回路里各处都相同，血管的**总横截面积** A 越大，流速 v = Q ÷ A 越小。从主动脉到毛细血管，分支越来越多，总面积增大约 1000 倍以上，所以毛细血管里血流最慢，有时间交换物质。选一段血管，拖心输出量，看流速怎么变。 {#s2e .explain}

::: html step2-1
s2stage: 上：各段血管的总横截面积（对数刻度）；下：对应的血流速度（对数刻度）；橙色高亮是选中的那段
s2canvas: 各段血管的总横截面积与血流速度：面积越大流速越小，毛细血管最慢
s2seg: 选一段血管
s2q: 心输出量 Q
:::

结论：流速与总横截面积成反比（连续性方程），毛细血管总面积最大、流速最慢。条件：面积数值是常见教材的近似值；血液当作不可压缩液体，忽略脉动。 {#s2result .readout i18n=text}

::: strings
s2ro: {name}：总横截面积约 {a} cm²，Q = {q} L/min = {qs} cm³/s，流速 v = Q ÷ A ≈ {v} cm/s。
:::

## 血压是怎么由心脏和血管共同决定的？ {#step3 h2=s3t}

::: strings
nav3: 3 血压从哪来
:::

第 3 步 · 血压从哪来 {#s3k .step-kicker i18n=text}

这一步要回答：血压的高低由哪几样东西决定？**血压**是血液对血管壁的压强（单位 mmHg）。心脏每分钟泵出的血量（心输出量 CO）越大、全身小血管对血流的阻力 R 越大，平均血压越高：平均动脉压 ≈ CO × R。每次心跳时压力上升到**收缩压**、回落到**舒张压**。调心率、每搏输出量、血管阻力，看波形和数字。 {#s3e .explain}

::: html step3-1
s3stage: 血压波形（教学示意）：横轴时间（2 s），纵轴压力（mmHg）；上沿是收缩压，下沿是舒张压，虚线是平均动脉压
s3canvas: 动脉血压波形：随心率、每搏输出量和血管阻力改变而变化
s3hr: 心率
s3sv: 每搏输出量
s3r: 外周阻力 R
:::

结论：CO 或 R 增大，血压升高；每搏输出量大则脉压（收缩压 − 舒张压）大。条件：教学模型，血管弹性常数取 1.5 mL/mmHg、R 的单位为 mmHg·min/L；仅用于理解原理，不能用来判断健康状况。 {#s3result .readout i18n=text}

::: strings
s3ro: 心输出量 CO = {sv} mL × {hr} = {co} L/min；平均动脉压 MAP = CO × R = {co} × {r} = {map} mmHg；收缩压 / 舒张压 ≈ {sys} / {dia} mmHg。
:::

## 跑步时，心脏多泵出来的血都去了哪里？ {#step4 h2=s4t}

::: strings
nav4: 4 运动时去哪了
:::

第 4 步 · 运动时去哪了 {#s4k .step-kicker i18n=text}

这一步要回答：运动时增加的心输出量怎样分配到各器官？静息时 5 L/min 的血流大致分给脑、心脏、肌肉、消化道、肾和皮肤；运动时心率加快、每搏输出量增大，总量最高可到约 20 L/min，而且大部分改道流向骨骼肌，消化道和肾的血流反而减少。拖运动强度，看各器官血流（L/min）的变化。 {#s4e .explain}

::: html step4-1
s4stage: 各器官的血流量（L/min）：柱子是当前值，竖线是静息时的值；右下读数给出心率与每搏输出量
s4canvas: 运动强度改变时，各器官血流量的分配：骨骼肌大幅增加，消化道和肾减少
:::

结论：运动时总血流量增加，并重新分配到最需要氧气的肌肉。条件：数据为常见生理教材的近似值，强度线性插值；个体差异很大，本页不能用于评估运动能力。 {#s4result .readout i18n=text}

::: strings
s4e2: 运动强度
s4ro: 强度 {e}%：心率 {hr} 次/分，心输出量 {co} L/min（每搏 {sv} mL）；骨骼肌分到 {mu} L/min（占 {pct}%），静息时是 {mu0} L/min。
:::
