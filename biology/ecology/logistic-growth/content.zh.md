## 每一代都翻倍：先猜，再数 {#step0 h2=s0t}

::: strings
nav0: 0 翻倍狂奔
:::

第 0 步 · 翻倍的狂奔 {#s0k .step-kicker i18n=text}

这一步只问一件事：**每代翻一倍的增长，快到什么程度？**从 1 个细菌开始，一代翻一倍。先在心里押个注：第 10 代会有多少个？——然后一下一下点「下一代」，让数自己长出来。 {#s0e .explain}

::: html step0-1
s0next: 下一代 →
s0reset: 重来
:::

结论：**指数增长的标志是「每过一代，乘上同一个倍数」**。开头不起眼，是因为基数小；基数一大，同样的倍数就是天文数字。 {#s0conc .readout}

::: strings
s0ro: 第 <b>{g}</b> 代：<b>{n}</b> 个（= 2<sup>{g}</sup>，实算）。
s0ro10: 第 10 代揭晓：<b>{n}</b> 个。如果你押的是 20 或 100，那就差得远了。这不是细菌特别能生，是「每代乘 2」这种方式本身就这么猛。
s0gen: 代
s0count: 数量
:::

## 不止翻倍：r 定陡缓 {#step1 h2=s1t}

::: strings
nav1: 1 增长率 r
:::

第 1 步 · 增长率 r {#s1k .step-kicker i18n=text}

真实种群不一定每代翻倍，增长可能慢得多。把「倍数」推广成连续的**增长率 r**：N(t) = N₀·e<sup>rt</sup>。拖动 r，看曲线陡缓和**翻倍时间**（数量翻一倍要多久，= ln2 / r）怎么变。 {#s1e .explain}

::: html step1-1
s1rLab: 增长率 r（每单位时间）
:::

结论：r 不必对应整数倍——哪怕 r 只有 0.2，只要一直「按比例」涨，形状还是指数，区别只在快慢。 {#s1conc .readout}

::: html step1-2
s1lk: 底图回顾：指数与对数那一页把 e<sup>x</sup> 与 ln 讲透了 →
:::

::: strings
s1ro: r = {r}：翻倍时间 = ln2 / r ≈ <b>{td}</b> 个时间单位；t = {T} 时 N = 10·e<sup>{r}×{T}</sup> ≈ <b>{n}</b>。
:::

## 容纳量 K 登场：曲线被压弯 {#step2 h2=s2t}

::: strings
nav2: 2 世界装不下
:::

第 2 步 · 世界装不下 {#s2k .step-kicker i18n=text}

培养皿就这么大，食物就这么多。引入**容纳量 K**（环境最多养得起多少）：每一代的实际增长率变成 r·(1 − N/K)——N 越接近 K，这一项越接近 0，涨得越慢。同一组参数画两条线：青线不管 K（指数），橙线受 K 约束（逻辑斯蒂）。看它们从哪一代开始分家。 {#s2e .explain}

::: html step2-1
s2rLab: 增长率 r
s2kLab: 容纳量 K
:::

结论：**S 形不是画出来的，是「越挤越难生」逐代算出来的**：前期像指数，中期最陡，后期被 (1 − N/K) 摁回平坦。 {#s2conc .readout}

::: strings
s2ro: 第 {g} 代：指数线 N ≈ <b>{ne}</b>；逻辑斯蒂 N = <b>{nl}</b>，此刻实际增长率 = r·(1 − N/K) = <b>{eff}</b>（起步时约等于 r = {r}）。
s2exp: 指数（无 K）
s2log: 逻辑斯蒂（有 K）
:::

## 从上边来，也回到 K {#step3 h2=s3t}

::: strings
nav3: 3 K 是渐近线
:::

第 3 步 · K 是渐近线 {#s3k .step-kicker i18n=text}

如果一开始就超载（N₀ &gt; K）会怎样？拖动起始数量 N₀ 到 K 上方，逐代生成：数量会自己回落到 K 附近。两个方向都奔着 K 去——**K 是吸引子，不是碰不得的墙**。注意这是逐代跳的离散模型：N₀ 离 K 太远时，一步的回落会「刹过头」落到 K 下方，再从下边爬回 K；超载得更离谱时这一步甚至会算出负数，所以本步给 N₀ 设了上限。 {#s3e .explain}

::: html step3-1
s3n0Lab: 起始数量 N₀
s3kLab: 容纳量 K
s3next: 下一代 →
s3reset: 重来
:::

结论：N &lt; K 时实际增长率为正、往上爬；N &gt; K 时变负、往下落。K 两边的力都指向 K 本身。 {#s3conc .readout}

::: strings
s3ro: 第 <b>{g}</b> 代：N = <b>{n}</b>，距 K <b>{d}</b>（实际增长率 {eff}，可正可负）。
s3cap: N₀ 上限 = 2.5K = {m}：当 N₀ &gt; K(1 + 1/r) ≈ {thr} 时，这个离散模型的第一步就会把种群算成负数（模型失效），所以滑杆被钳在 {m} 以内。
:::

## 模型也有适用范围 {#step4 h2=s4t}

::: strings
nav4: 4 r 调过头
:::

第 4 步 · r 调过头（越界实验） {#s4k .step-kicker i18n=text}

前面的离散迭代里 r 都不超过 1（第 2 步滑杆上限 1.0，第 3 步固定 0.6）。离散迭代 N ← N + rN(1 − N/K) 的真实分界是：**r ≤ 1 单调趋近 K；1 &lt; r &lt; 2 先冲过 K、再衰减振荡回到 K；r &gt; 2 不再趋稳**——先是 2 周期、4 周期……来回振荡，r 过了约 2.57 进入**混沌**（永不重复，初值差一点结果就天差地别）；r 过了 3 甚至算出负数——「崩盘」。这一格就是**越界实验**，滑杆从 1 到 3.1。要注意：对世代重叠、连续繁殖的种群，这种逐代剧烈跳动多半是离散化带来的假象；但世代不重叠的种群（如许多温带昆虫）确实可能出现这类过冲振荡乃至混沌（May 1976），真实种群的振荡也可能另有成因（如 Nicholson 绿头苍蝇实验中的发育时滞）。**看到模型失效的样子，也是理解模型的一部分。** {#s4e .explain}

::: html step4-1
s4rLab: 增长率 r（r > 2 为越界区）
:::

结论：任何模型都有适用范围。r 的稳定区来自稳定性条件（本离散形式只在 r ≤ 2 时回到 K，r = 2 是临界点）；出界后的振荡、混沌、负数，先要问是模型的离散化在作怪，还是种群真有这种动态。 {#s4conc .readout}

::: strings
s4mono: 状态：<b>单调趋近</b>——从下方一路爬向 K，从不越过（r ≤ 1 的情形）。
s4damp: 状态：<b>阻尼振荡后趋稳</b>——冲过 K 又回落，晃动越来越小，最终停在 K（仍在 r ≤ 2 的稳定区内；r = 2 恰在临界，回落极慢）。
s4osc: 状态：<b>{p} 周期振荡</b>——长期在 {p} 个数值之间循环，不再趋稳到 K（最近 6 代极差 {spread}）。
s4oscLong: 状态：<b>振荡</b>——不再趋稳到 K，周期超过 64 代（最近 6 代极差 {spread}）。
s4chaos: 状态：<b>混沌</b>——不再趋稳也不循环，永不重复；李雅普诺夫指数 λ ≈ {lam} &gt; 0，初值的微小差别会被逐代放大（最近 6 代极差 {spread}）。
s4crash: 状态：<b>崩盘</b>——第 {g} 代算出 N ≤ 0，模型已失效（真实种群不会变负数，这是离散迭代的数学假象）。
:::

## 把这一页收成三句话 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

一、没有约束时，按比例增长就是指数增长，翻倍时间由 r 定。二、有了容纳量 K，实际增长率 r·(1 − N/K) 随 N 逼近 K 而减小，逐代算出 S 形（逻辑斯蒂）曲线；K 是两个方向都趋近的吸引子。三、离散迭代在 r &gt; 2 时不再趋稳（振荡、混沌，r &gt; 3 还会算出负数）——模型边界要明说。 {#s5e .explain}

::: html step5-1
s5lkExp: 上游：指数与对数（底图）→
s5lkEq: 旁支：化学平衡——同样是「自我刹车」的系统 →
:::

符号提醒：第 1 步的 r 是连续增长率（e<sup>rt</sup>，翻倍时间 ln2/r 只对它成立）；第 2–4 步的 r 是每代的离散增长率（每代乘 1 + r），两者同名但不是同一个数。模型边界：本页用离散迭代 N ← N + rN(1 − N/K) 与连续指数式作教学示意；细菌情境为示意，真实种群还受年龄结构、迁入迁出、时滞与随机波动影响，参数须由数据拟合，勿把模拟值当实测值。 {#s5bound .hint}
