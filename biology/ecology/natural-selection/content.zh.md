## 鸟只吃它看得见的：颜色决定存活率 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 谁被吃掉
:::

::: html step0-1
:::

这一步要回答：为什么环境会改变哪些个体活下来？同一种蛾有两种可遗传的颜色：浅色和深色。鸟靠视觉捕食，和树皮反差越大的蛾越容易被发现。设树皮深浅为 b（0 是浅色，1 是全黑）。浅色蛾的存活概率 w浅 = 1 − k·b，深色蛾 w深 = 1 − k·(1 − b)，k = 0.5 是鸟的捕食强度（被完全看见时被吃掉的概率）。点“让鸟捕食一轮”：每只蛾按各自的存活概率随机存活。 {#s0e .explain}

::: html step0-2
s0o: 先把树皮调浅（b = 0.2）捕食几轮（每轮前点重置）：浅色蛾存活更多；再把树皮调深（b = 0.9）：结果颠倒；对照读数里的实测存活率与公式值（随机，会有偏差）。
lBark: 树皮的深浅（0 浅 ~ 1 深）
bHunt: 让鸟捕食一轮
bRestore: 重置：恢复 60 只蛾
:::

## 世代更替：存活的繁殖，颜色比例逐代改变 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 几代之后
:::

::: html step1-1
:::

这一步要回答：捕食的差别怎样累积成种群的变化？每一代：先被捕食（按上面的存活概率），存活的蛾繁殖，子代保持父母的颜色（颜色可遗传），种群补回 200 只。深色比例 p 的变化：p′ = p·w深 / (p·w深 + (1 − p)·w浅)。点播放，每次一代，折线累积深色比例的变化；虚线是不考虑随机性的理论值（200 只的种群，随机性仍会让实线上下抖动）。 {#s1e .explain}

## 选择有多强？每代的优势比决定快慢 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 选择有多强
:::

::: html step2-1
:::

这一步要回答：颜色比例变化的快慢由什么决定？每代深色相对浅色的优势比 r = w深 / w浅。深色比例 p 的“对数几率” logit(p) = ln(p/(1 − p)) 每代恰好增加 ln r，所以从 p₀ 到 p 需要的代数 = [logit(p) − logit(p₀)] / ln r。优势比越大，变化越快。图中橙线是当前设置的深色比例曲线（从 1% 开始），读数给出升到 50% 和 90% 所需的代数。 {#s2e .explain}

::: html step2-2
s2o: 把树皮从 0.5 调到 1：优势比从 1 增大，所需代数急剧缩短；把捕食强度 k 加大，同样效果；b = 0.5 时 r = 1，永远不变。
lK: 捕食强度 k（被看见的蛾被吃掉的最大概率）
:::

::: strings
r2: w浅 = {wl}，w深 = {wd}，优势比 r = {r}：从 1% 升到 50% 需 {t50} 代，升到 90% 需 {t90} 代。
never: 永远不会（r ≤ 1）
:::

## 环境在变：种群的颜色跟着变，但有滞后 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 环境在变
:::

::: html step3-1

这一步要回答：环境变化时选择怎样跟上？以工业革命为例：树皮因烟尘熏黑，之后空气变清洁又变浅。树皮深浅随世代变化（灰线：先在 0.4，第 10–40 代升到 0.9，第 60–90 代降到 0.15），深色蛾比例（橙线）每代按上一步的公式更新（另加每代 0.1% 的个体因突变变成另一种颜色，两个方向都有，使稀有颜色不会彻底消失），起始 2%（b = 0.5 时两种颜色同样有利，b 越过 0.5 选择方向才反转）。拖动世代滑块，圆点沿两条曲线移动。你会看到种群的变化总是落后于环境的变化，因为每一代只能改变一部分。 {#s3e .explain}

## 偶然 vs 选择：小种群里，没有选择也会“漂变” {#step4 h2=s4t pre=1}

::: strings
nav4: 4 偶然 vs 选择
:::

::: html step4-1
:::

这一步要回答：颜色比例的变化一定是选择造成的吗？不一定。每代从上一代随机抽 N 个后代，即使两种颜色同样适应（没有选择，起始各 50%），比例也会随机涨落，这叫**遗传漂变**；种群越小，涨落越大，甚至一种颜色会完全消失（**固定**）。单代抽样的方差是 p(1 − p)/N。图中是 5 个互相独立的种群 100 代的轨迹。读数用 40 个重复统计第 100 代时比例的标准差，并与理论值对比。 {#s4e .explain}

::: html step4-2
s4o: 把 N 从 10 增大到 1000：轨迹从剧烈乱窜到几乎一条水平线；统计里“已固定”的个数减少；点“再随机跑 5 个群体”换一批轨迹，比较。
lLogN: 种群大小 N = 10^x
bNewPops: 再随机跑 5 个群体
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 个体有可遗传的差异（浅色与深色）；② 环境（鸟、树皮）使不同个体的存活率不同；③ 存活的繁殖，种群的比例逐代改变，logit(p) 每代增加 ln(w深/w浅)；④ 选择越强变化越快，环境改变时种群的变化会滞后；⑤ 小种群里即使没有选择，偶然也会让比例漂变。 {#s5e .explain}

::: html step5-2
qq: 树皮被烟尘熏黑后，深色蛾为什么变多？
qo0: 浅色蛾为了躲避鸟，把自己变成了深色
qo1: 深色蛾被吃掉的概率更低，存活并繁殖得更多，把深色遗传给后代
qo2: 鸟偏爱吃浅色的蛾，把深色蛾赶了回来
s5m: 本页是教学模型：只有两种颜色，颜色由单基因（单倍体，不分显隐）决定且忠实遗传，没有迁入迁出和雌雄配对（第 3 步只加入固定的 0.1% 双向突变）；存活概率 w 取简单线性式，固定世代、种群大小恒定；第 3 步的树皮曲线是示意，不是实测数据；真实的胡椒蛾研究（Kettlewell 等）的结论还受到鸟的取食行为、蛾的栖息位置等因素的争议和修正；漂变用标准的“随机抽样”模型（Wright–Fisher）。
lk0: DNA 复制与翻译页：突变是新颜色变异的来源
lk1: 遗传与概率页：基因和等位基因怎样传给后代
lk2: 种群生态学页：种群数量怎样受资源和捕食限制
:::

lblBark: 灰线：树皮深浅 b

qwhy: 变化发生在种群层面：个体的颜色不变，不同颜色的个体存活、繁殖的机会不同，深色比例逐代上升（第 1 步）。
