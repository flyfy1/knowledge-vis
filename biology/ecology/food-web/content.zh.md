## 这张图里，谁吃谁、能量往哪个方向走？ {#step0 h2=s0t}

::: strings
nav0: 0 谁吃谁
:::

第 0 步 · 谁吃谁 {#s0k .step-kicker i18n=text}

这一步要回答：怎样读一张食物网？箭头从**被吃的**指向**吃它的**，也就是能量传递的方向。**生产者**（草）自己用阳光制造养料；**消费者**靠吃别的生物获得能量。**营养级**是它在食物链里的位置：生产者为第 1 级，吃第 1 级的是第 2 级，以此类推；吃多种食物的，取它所吃食物营养级的平均值再加 1。选一个物种（也可点图上的点），看它吃谁、被谁吃。 {#s0e .explain}

::: html step0-1
s0stage: 食物网：箭头从食物指向吃它的动物；横向位置只为排版，纵向高度是营养级；青色线 = 它吃的，橙色线 = 吃它的
s0canvas: 八种生物组成的食物网：草在底层，蛙、蛇、狐、鹰在上层，箭头表示能量流向
s0sp: 选一个物种
:::

结论：箭头方向 = 能量流向；营养级越高，离阳光越远。条件：这是一个简化的 8 种生物的虚构草地食物网，真实的网要复杂得多。 {#s0result .readout i18n=text}

::: strings
s0ro: {name}（营养级 {tl}）：吃 {eats}；被 {eaten} 吃。
s0none: 无
s0prod: 自己制造养料
s0top: 没有天敌（顶级捕食者）
:::

## 为什么吃肉的动物总是比吃草的少得多？ {#step1 h2=s1t}

::: strings
nav1: 1 能量金字塔
:::

第 1 步 · 能量金字塔 {#s1k .step-kicker i18n=text}

这一步要回答：每往上一个营养级，能量会剩下多少？生物吃进的能量大部分用来呼吸、运动、散热，只有一小部分长成自己的身体，成为下一级能吃到的能量。常用的经验数是**能量传递效率**约 10%（本页可调 5–20%）。从 10000 kJ 的生产者出发，一层层乘以效率；能量不足 5 kJ 的层，养不活一个种群。拖效率，看金字塔能垒几层。 {#s1e .explain}

::: html step1-1
s1stage: 能量金字塔（宽度按对数）：从下往上是生产者到顶级消费者；写出每层的能量（kJ）；灰色表示养不活
s1canvas: 能量金字塔：每上一层能量乘以传递效率，能量不足 5 kJ 的层变灰
s1eff: 能量传递效率
:::

结论：效率越低，金字塔越矮，顶级捕食者越少。条件：10000 kJ 起点、5 kJ 门槛、效率固定为各层相同，都是教学数字；真实生态系统的效率因生物而异。 {#s1result .readout i18n=text}

::: strings
s1ro: 效率 {eff}%：各层能量 {list}；能养活的营养级数 = {n}。
:::

## 把一个物种拿走，别的物种数量会怎样变？ {#step2 h2=s2t}

::: strings
nav2: 2 少了一个物种
:::

第 2 步 · 少了一个物种 {#s2k .step-kicker i18n=text}

这一步要回答：拿走食物网里的一个物种，其他物种的数量会怎么变，会不会连带消失？每个物种的数量随它吃到的食物增加、被吃而减少。本页用一个简化的数学模型（每对「吃—被吃」的关系都按相遇次数计）模拟：先让八种生物处在平衡，再移走一个物种，看各条曲线（占原数量的百分比）。选一个物种，按「移走并运行」。 {#s2e .explain}

::: html step2-1
s2stage: 横轴：模拟时间，纵轴：各物种数量占平衡值的百分比（最高显示 250%）；每种生物一条线，低于 2% 视为消失
s2canvas: 移走一个物种后各物种数量随时间的变化曲线：有的上升，有的下降，有的消失
s2rm: 要移走的物种
s2run: 移走并运行
s2reset: 恢复原来的网
:::

结论：移走一个物种会沿着「吃—被吃」的链条间接影响很多别的物种，有些上升、有些下降。条件：本页是一个线性相互作用的玩具模型，参数是为稳定而调的；真实生态系统的反应取决于具体物种。 {#s2result .readout i18n=text}

::: strings
s2ro0: 八种生物处在平衡：每种都是 100%。选一个物种移走再运行。
s2ro1: 移走「{name}」后第 {t} 个时间单位：{list}
s2dead: （消失）
:::

## 水里微量的毒，为什么会在最高层的动物体内浓得吓人？ {#step3 h2=s3t}

::: strings
nav3: 3 毒物富集
:::

第 3 步 · 毒物富集 {#s3k .step-kicker i18n=text}

这一步要回答：难分解、难排出的毒物进入食物链后，每一级体内的浓度会怎样？这类物质（如某些农药、汞）会在体内积存，每吃一次就积累一次：低一级的生物体内的毒物，几乎全被吃它的生物留住，所以每上一级浓度大约乘以一个倍数。用 **浓度**（单位质量体内含有的毒物量）比较。拖「每级放大倍数」和「生产者体内浓度」，看哪一级越过危险线。 {#s3e .explain}

::: html step3-1
s3stage: 沿着草 → 蚱蜢 → 蛙 → 蛇 → 鹰这条食物链，各级体内的毒物浓度（对数刻度）；红色虚线是教学用的危险线 100
s3canvas: 毒物沿食物链逐级放大：每一级浓度是前一级的若干倍，到顶级捕食者可超过危险线
s3f: 每级放大倍数
s3c0: 生产者体内浓度
:::

结论：能积存的毒物沿食物链逐级放大，顶级捕食者受害最重，即使环境里浓度很低。条件：只对难降解、难排出的物质成立；很多毒物会被排出或分解，不会放大；倍数和危险线都是教学数字。 {#s3result .readout i18n=text}

::: strings
s3ro: 各级浓度：{list}；超过危险线 100 的级别：{over}。
s3over: 第 {n} 级（{name}）
:::

## 为什么食物来源越多的生态系统越经得起打击？ {#step4 h2=s4t}

::: strings
nav4: 4 网比链稳
:::

第 4 步 · 网比链稳 {#s4k .step-kicker i18n=text}

这一步要回答：同样移走一个物种，单线的食物链和交织的食物网，哪个连带消失得更多？规则很简单：一个消费者只要还有**一种**食物活着就能活下去，所有食物都没了就会跟着消失。选「完整的网」或「单线食物链」，选一个物种，按「移走」，数连带消失的物种数。 {#s4e .explain}

::: html step4-1
s4stage: 食物网：彩色 = 存活，红色叉 = 被你移走，灰色 = 因为食物断了而消失
s4canvas: 移走一个物种后的食物网，灰色的是连带消失的物种
s4mode: 食物网的样子
s4rm: 要移走的物种
s4remove: 移走
s4reset: 全部恢复
:::

结论：一种食物消失时，吃它的捕食者如果还有别的食物就能撑住；网越交织，连带消失越少。条件：这里只看「有没有食物」这一条结构规则，不含数量变化、竞争和疾病。 {#s4result .readout i18n=text}

::: strings
s4ro: {mode}，移走「{name}」：连带消失 {n} 种（{list}）。同一个物种在另一种结构里连带消失 {other} 种。
s4ro0: {mode}：八种生物都在。选一个物种按「移走」。
:::
