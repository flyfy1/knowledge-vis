## 酶只认形状合适的底物 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 锁钥配合
:::

::: html step0-1
:::

这一步要回答：酶怎样“挑选”它要催化的反应？酶是一种蛋白质，表面有一个形状固定的**活性中心**（口袋）。只有形状吻合的分子（**底物**）才能嵌进去，在口袋里被转化成**产物**并释放，酶本身不变，可以立即再用。这叫锁钥模型（本页做了简化）。图中三个灰色的是酶，凹口是活性中心；漂浮的小图形是底物。点播放：底物随机运动，碰到空闲的酶并且形状合适就被转化。在接触的每个时间步里，形状吻合的底物结合的相对几率为 100%，形状接近的为 15%，形状不合的为 0（接触期间可以多次尝试，所以实测速率之比不一定正好等于几率之比）。 {#s0e .explain}

::: html step0-2
s0o: 依次选三种底物，各点播放运行一段时间再对比读数里的“产物数”和“速率”：形状吻合的产物最多，形状不合的为零；每次切换底物会清空计数以便公平比较。
sMatch: 底物：形状吻合（三角形）
sNear: 底物：形状接近（梯形）
sMiss: 底物：形状不合（圆形）
bPlay: 播放 / 暂停
bReset: 重置：清空产物计数
:::

kMatch: 形状吻合
kNear: 形状接近

## 饱和：酶都忙不过来时，加底物也不再变快 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 饱和
:::

::: html step1-1
:::

这一步要回答：底物越多反应越快吗？底物浓度 [S] 低时，酶大多空着，底物一多就更多结合，速率随 [S] 增加；但每个酶一次只能处理一个底物，当所有酶都被占满（**饱和**）后速率到顶，叫**最大速率** Vmax（与酶的量成正比）。米氏方程：v = Vmax·[S]/(Kₘ + [S])。Kₘ 是速率达到 Vmax 一半时的底物浓度，Kₘ 越小说明酶越容易结合底物。下方的 10 个酶图标按被占据比例 [S]/(Kₘ + [S]) 着色。 {#s1e .explain}

::: html step1-2
s1o: 把 [S] 从 0 拉到 10：看曲线先陡后平，酶图标逐渐被填满；把 [S] 设为 Kₘ，速率恰好是 Vmax 的一半；把酶的量加倍，曲线整体升高一倍，但达到一半的位置（Kₘ）不变。
lS: 底物浓度 [S]（mM）
lKm: 米氏常数 Kₘ（mM）
lE: 酶的量 [E]（相对）
:::

::: strings
r1: [S] = {s} mM，Kₘ = {km} mM，Vmax = {vmax}：v = {v}（是 Vmax 的 {pct}%）；约 {occ}/10 的酶被底物占据。
:::

## 温度：先加快，再因变性而崩溃 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 温度
:::

::: html step2-1
:::

这一步要回答：为什么酶在体温附近最活跃，太热就失效？温度升高，分子碰撞更剧烈，反应本身加快（温度每升高 10 °C 约快 2 倍，见活化能页）；但酶是蛋白质，温度过高会**变性**（立体结构被破坏，活性中心变形，不可逆）。两条曲线乘在一起：灰色虚线是“只考虑加快”，青色是仍保持折叠状态的酶比例（我们取一半变性发生在 50 °C），橙色是它们的乘积——活性曲线，峰值处是**最适温度**。 {#s2e .explain}

::: html step2-2
s2o: 把温度从 0 拉到 80 °C：活性先上升、过了最适温度后突然下降；对照读数里的最适温度；注意在 37 °C 与 45 °C 之间，活性随温度怎样变化。
lT: 温度 T（°C）
:::

::: strings
r2: T = {t} °C：加快因子 {rate}（相对 37 °C），保持折叠的比例 {fold}%，活性 {act}（相对最大值 {pct}%）；最适温度约 {topt} °C。
:::

## pH：每种酶有自己的最适 pH {#step3 h2=s3t pre=1}

::: strings
nav3: 3 pH
:::

::: html step3-1
:::

这一步要回答：为什么胃里的酶到了小肠就不工作了？酶的活性依赖几个关键基团带电的状态，pH 改变会改变它们的电荷，进而改变活性中心的形状。本页用简单的两个电离步骤：活性 = 1/(1 + 10^(pK₁ − pH) + 10^(pH − pK₂))，在 pK₁ 与 pK₂ 的中间最高。三种酶的最适 pH 不同：胃蛋白酶约 2，唾液淀粉酶约 7，胰蛋白酶约 8。 {#s3e .explain}

::: html step3-2
s3o: 选胃蛋白酶，把 pH 从 2 拉到 8；再换胰蛋白酶，从 2 拉到 8：看两条曲线的峰在哪里，并想想它们各自工作的器官的酸碱度。
lPh: 溶液 pH
ePepsin: 胃蛋白酶（胃里）
eAmylase: 唾液淀粉酶（口腔）
eTrypsin: 胰蛋白酶（小肠）
:::

::: strings
r3: {enz}：pH = {ph}，相对活性 {act}%；最适 pH 约 {opt}。
nPepsin: 胃蛋白酶
nAmylase: 唾液淀粉酶
nTrypsin: 胰蛋白酶
:::

## 抑制剂：竞争性与非竞争性 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 抑制剂
:::

::: html step4-1
:::

这一步要回答：抑制剂怎样让酶变慢，加底物能“救回来”吗？**竞争性抑制剂**长得像底物，占据活性中心与底物竞争：表观 Kₘ 变大（Kₘ,app = Kₘ(1 + [I]/Kᵢ)），Vmax 不变，所以底物足够多时可以把它挤走。**非竞争性抑制剂**结合在别的位置，使一部分酶失活：Vmax 变小（Vmax,app = Vmax/(1 + [I]/Kᵢ)），Kₘ 不变，加底物也救不回来。本页取 Vmax = 1，Kₘ = 1 mM，Kᵢ = 2 mM。灰色是无抑制剂，彩色是有抑制剂的曲线，圆点是当前 [S]。 {#s4e .explain}

::: html step4-2
s4o: 选竞争性抑制剂，把 [I] 调到 10，再把 [S] 拉到 20：曲线能否接近无抑制剂的曲线？换成非竞争性：同样操作，曲线能否追上？
lI: 抑制剂浓度 [I]（mM）
iComp: 竞争性抑制剂
iNon: 非竞争性抑制剂
:::

::: strings
r4: {kind}，[I] = {i} mM：Vmax,app = {vm}，Kₘ,app = {kma}；[S] = {s} mM 时 v = {v}（无抑制剂时 {v0}）。
kComp: 竞争性抑制
kNonc: 非竞争性抑制
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 酶的活性中心只接受形状吻合的底物，酶反应后不变；② v = Vmax[S]/(Kₘ + [S])：底物多了酶会饱和，速率有上限；③ 温度：加快与变性相乘，出现最适温度；④ 每种酶有最适 pH；⑤ 竞争性抑制可被高浓度底物克服，非竞争性不能。 {#s5e .explain}

::: html step5-2
qq: 当底物浓度远大于 Kₘ（酶已接近饱和）时，再把底物浓度加倍，反应速率会？
qo0: 加倍
qo1: 几乎不变
qo2: 减半
s5m: 本页只是教学模型：锁钥配合忽略了诱导契合和构象变化；米氏方程假设单底物、稳态；温度曲线用“加快 × 未变性比例”的简单乘积，变性中点 50 °C 为示意值；pH 曲线用两步电离的简化公式；抑制剂取简单的可逆结合，Kᵢ 为示例值；第 0 步的模拟用随机碰撞与结合几率，数字有涨落；真实的酶有变构调节、辅酶和多底物反应。
lk0: 活化能页：催化剂降低能垒，酶是生物版的催化剂
lk1: 反应速率页：从粒子碰撞角度看催化剂和浓度
lk2: 酸碱平衡页：pH 改变基团的电离状态
:::

::: strings

:::
