## 二倍体细胞的染色体是成对的 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 成对的染色体
:::

::: html step0-1
:::

这一步要回答：为什么说“减数”分裂？大多数体细胞是**二倍体**（记为 2n）：染色体成对，每一对中一条来自母方（红），一条来自父方（蓝），这两条叫**同源染色体**。本页用 n 表示同源染色体的对数，所以细胞里有 2n 条染色体。要产生精子或卵（**配子**），细胞必须把染色体数目减半，让每个配子只带每对里的一条，这样受精后两个配子合起来才恢复 2n。点“复制染色体”看 S 期：每条染色体复制成两条相同的**姐妹染色单体**（X 形），条数还是 2n，但 DNA 加倍。 {#s0e .explain}

::: html step0-2
s0o: 调节对数 n：数一数红蓝染色体各有几条；点复制：每条变成 X 形（两条姐妹染色单体），染色体条数不变；读数给出细胞内染色体条数和染色单体条数，以及配子应得到的条数。
lPairs: 同源染色体对数 n
bRep: 复制染色体（S 期）

:::

## 两次分裂：先分同源染色体，再分姐妹染色单体 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 两次分裂
:::

::: html step1-1
:::

这一步要回答：染色体数怎样减半，又怎样产生新的组合？减数分裂有两次连续的分裂。**减数分裂 I**：同源染色体先配对（前期 I），可能在非姐妹染色单体之间**交换**片段（互换），然后在中期 I 排在赤道板上，后期 I 同源染色体被拉向两极——这一步把染色体数减半。**减数分裂 II**：类似有丝分裂，姐妹染色单体分开，得到 4 个单倍体细胞。图中取 n = 2 对，红蓝是母方、父方来源，一条染色单体上、下两段颜色不同就表示发生过交换。拖动滑块逐阶段观察。 {#s1e .explain}

::: html step1-2
s1o: 把阶段从 0 拖到 7：注意哪一步染色体数从 4 条（2n）降到 2 条（n），哪一步姐妹染色单体才分开；点“重新随机取向”看最终 4 个配子里红蓝怎样重新搭配；打开“发生交换”看单条染色单体上出现两种颜色。

## 随机取向：n 对染色体能搭配出 2ⁿ 种配子 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 随机组合
:::

::: html step2-1
:::

这一步要回答：为什么同一对父母的孩子互不相同？在中期 I，每对同源染色体朝哪个极是**独立随机**的，所以 n 对染色体的搭配共有 2ⁿ 种（不考虑交换）。人类 n = 23，2²³ = 8,388,608 种，已经很多。点“做 10 次减数分裂”：每次随机取向并产生 4 个配子；下面的柱状图累积每种搭配出现的次数。次数越多，各柱越接近相等。条形下方的编码里 R 表示某对染色体取母方（红），B 表示父方（蓝）。 {#s2e .explain}

::: html step2-2
s2o: 把 n 设为 3（8 种搭配），连续点几次：先看柱子参差不齐，再看累积到几百个配子后是否趋于均匀；读数里“最高/期望”应逐渐接近 1。

:::

## 交换：连锁的基因也能重新搭配 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 交换
:::

::: html step3-1
:::

这一步要回答：位于同一条染色体上的两个基因一定一起走吗？不一定。设母方染色体带 A B，父方带 a b（A、B 在同一条染色体上，称为**连锁**）。如果不发生交换，配子只有 AB 和 ab（亲本型）；交换发生后，非姐妹染色单体换了一段，出现 Ab 和 aB（**重组型**）。重组型配子占全部配子的比例叫**重组率** RF；两个基因离得越远，RF 越大，最大约 0.5（相当于不连锁）。点“做 25 次减数分裂”累积 100 个配子，看重组型比例是否接近你设的 RF。 {#s3e .explain}

::: html step3-2
s3o: 把 RF 设为 0：只出现亲本型；设为 0.2：约 20% 是重组型（Ab、aB 各约 10%）；设为 0.5：四种配子各约 25%；多累积几次，看实测 RF 怎样接近设定值。
lRf: 重组率 RF（两个基因之间）
bMake100: 做 25 次减数分裂（得到 100 个配子）
bReset3: 重置：清空统计
:::

## 和有丝分裂比：细胞数、染色体数、遗传一致性 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 与有丝分裂比
:::

::: html step4-1
:::

这一步要回答：减数分裂和有丝分裂到底有什么不同？对 n = 3 对染色体的细胞各做一次：**有丝分裂**复制后姐妹染色单体直接分开，得到 2 个与母细胞完全一样的二倍体子细胞（2n = 6）；**减数分裂**经过两次分裂得到 4 个配子，每个只有 n = 3 条染色体，而且互相不一定相同（取向随机，每对还有一半的概率发生交换）。读数会统计子细胞的个数、每个细胞的染色体数、其中互不相同的细胞种类数。 {#s4e .explain}

::: html step4-2
s4o: 先点“有丝分裂”再点“再随机做一次”：始终 2 个相同的细胞，每个 6 条；再点“减数分裂”并多做几次：4 个细胞、每个 3 条；有的时候只有 2 种、有的时候 4 种不同——为什么？
bMito: 有丝分裂
bMeio: 减数分裂
bAgain: 再随机做一次
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 体细胞是二倍体（2n），配子是单倍体（n）；② 减数分裂 I 分开同源染色体（数目减半），II 分开姐妹染色单体；③ 中期 I 的随机取向使 n 对染色体产生 2ⁿ 种搭配；④ 交换让连锁的基因重新搭配，重组率 RF 反映基因间距离；⑤ 有丝分裂得到 2 个相同的二倍体细胞，减数分裂得到 4 个不一定相同的单倍体配子。 {#s5e .explain}
