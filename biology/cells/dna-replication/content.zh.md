## 碱基配对：A 配 T，G 配 C {#step0 h2=s0t pre=1}

::: strings
nav0: 0 碱基配对
:::

::: html step0-1
:::

这一步要回答：DNA 的两条链为什么能“对得上”？DNA 由四种碱基组成：A（腺嘌呤）、T（胸腺嘧啶）、G（鸟嘌呤）、C（胞嘧啶）。两条链之间，A 总与 T 配对（形成 2 个氢键），G 总与 C 配对（形成 3 个氢键）。给定一条模板链，请依次为每个位置选出互补的碱基；选错会提示并计数。配完后，页面按配对类型统计氢键总数，并用华莱士法则估算双链“拆开”所需温度 Tm ≈ 2×(A+T) + 4×(G+C) °C：G–C 越多越牢。 {#s0e .explain}

::: html step0-2
s0o: 逐个选择互补碱基，注意选错时提示的内容；配完后读 GC 含量、氢键数和 Tm；点“换一条新的模板链”再配一次，比较不同链的 Tm。
bA: A 腺嘌呤
bT: T 胸腺嘧啶
bG: G 鸟嘌呤
bC: C 胞嘧啶
bNewStrand: 换一条新的模板链
bReset0: 重置：清除已配对的碱基
:::

::: strings
r0: 已配对 {k}/{n} 个；选错 {err} 次；{status}
st0: 下一个要配的是模板上的 {b}。
stOk: 全部配对完成：氢键共 {hb} 个，GC 含量 {gc}%，Tm ≈ {tm} °C。
wrong: 选错了：{t} 只能与 {c} 配对。
:::

## 半保留复制：每个子代 DNA 一条旧链、一条新链 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 半保留复制
:::

::: html step1-1
:::

这一步要回答：DNA 复制后，新旧链是怎样分配的？复制时双链解开，**每条旧链当模板**，按碱基配对合成一条新链，所以每个子代 DNA 由一条旧链和一条新链组成，叫**半保留复制**。1958 年梅塞尔森–斯塔尔用重氮（¹⁵N，旧链）标记，再放入轻氮（¹⁴N，新链）培养，用密度离心验证了这一点。图中紫色是最初的两条旧链，青色是新合成的链；右侧是离心管：重–重、重–轻、轻–轻三种 DNA 沉在不同密度位置。滑块是复制轮数。 {#s1e .explain}

::: html step1-2
s1o: 把轮数从 0 拉到 4：看分子总数 2^轮数，含旧链的分子始终只有 2 个；右侧离心管里，中间的“重–轻”带在第 1 轮占 100%，之后越来越淡，“轻–轻”带越来越浓。
lRounds: 已复制的轮数
:::

::: strings
r1: 复制 {r} 轮：共 {tot} 个双链分子；其中重–重 {hh} 个、重–轻 {hl} 个、轻–轻 {ll} 个；离心带占比：重–轻 {fhl}%，轻–轻 {fll}%。
:::

## 转录：把基因抄成 mRNA {#step2 h2=s2t pre=1}

::: strings
nav2: 2 转录
:::

::: html step2-1
:::

这一步要回答：基因里的信息怎样被抄出来？在细胞核里，RNA 聚合酶沿着 DNA 的**模板链**移动，按配对规则合成一条 **mRNA**：A 配 U（RNA 里用尿嘧啶 U 代替 T），T 配 A，G 配 C，C 配 G。mRNA 的序列与另一条（编码链）相同，只是 T 换成 U。滑块是已抄出的碱基数；mRNA 每 3 个碱基为一个**密码子**（下一步用到）。 {#s2e .explain}

::: html step2-2
s2o: 把滑块从 0 拉到 18：看 mRNA 一格一格长出来，每个字母与模板链上方的字母对应配对；换基因 2、3 对比序列；核对读数里“编码链”与 mRNA 的关系。
lPos: 位置
gene1: 基因 1
gene2: 基因 2
gene3: 基因 3
:::

::: strings
r2: 已转录 {p}/{n} 个碱基；模板链：{tpl}；mRNA：{mr}；编码链（T→U）：{cod}。
:::

## 翻译：核糖体按密码子造蛋白质 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 翻译
:::

::: html step3-1
:::

这一步要回答：mRNA 上的序列怎样变成蛋白质？核糖体沿 mRNA 每次读 3 个碱基（一个**密码子**），按**遗传密码表**（共 64 个密码子）查出对应的氨基酸，加到肽链上；AUG 是起始密码子（编码甲硫氨酸 Met），UAA、UAG、UGA 是终止密码子，不对应氨基酸，读到它蛋白质就合成结束。滑块是核糖体已读过的密码子个数；下方圆圈是正在增长的肽链。 {#s3e .explain}

::: html step3-2
s3o: 把滑块逐格右移：看肽链每次多一个氨基酸；到终止密码子时肽链停止；换基因 2、3，对比它们合成的肽链。
lCodon: 核糖体走到第几个密码子
:::

::: strings
r3: 基因 {g}：已读 {k}/{m} 个密码子；刚读的密码子 {cod} → {aa}；肽链：{pep}。
stopW: 终止
nextNone: 尚未开始
:::

## 突变：改一个字母，蛋白质会怎样？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 突变
:::

::: html step4-1
:::

这一步要回答：DNA 上的小变化会让蛋白质变成什么样？在 mRNA 上选一个位置：**替换**一个碱基；或**删除**、**插入**一个碱基。结果有几类：**同义突变**（密码子变了但氨基酸没变）、**错义突变**（换了一个氨基酸）、**无义突变**（变成终止密码子，肽链提前结束）、**移码突变**（插入或删除 1–2 个碱基，后面所有密码子的分组都错位）。页面把改后的 mRNA 重新翻译，与原蛋白质比对后自动判类。基因按第 3 步的选择（可在此切换）。 {#s4e .explain}

::: html step4-2
s4o: 以基因 1 为例试一试：把第 6 位改成任意碱基（GCU→GCx 都是丙氨酸 Ala，同义）；把第 4 位改成 C（GCU→CCU，Ala 变 Pro，错义）；把第 9 位改成 A（UAC→UAA，出现终止密码子，无义）；删除一个碱基（移码）。点重置恢复。
subA: 把此位置改成 A
subU: 把此位置改成 U
subG: 把此位置改成 G
subC: 把此位置改成 C
bDel: 删除此位置的碱基
bIns: 在此位置前插入一个 A
bReset4: 重置：恢复原来的基因
:::

::: strings
r4: 原蛋白质：{p0}；突变后：{p1}；类型：{kind}。{note}
kNone: 尚无突变
kSil: 同义突变（蛋白质不变）
kMis: 错义突变（氨基酸被替换）
kNon: 无义突变（提前终止）
kFrame: 移码突变（读码框错位）
kIn: 整码插入/缺失（读码框不变，多或少氨基酸）
mutNote: 共 {n} 处改动，改后 mRNA：{mr}。
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① A–T（2 个氢键）、G–C（3 个氢键）互补配对；② 半保留复制：每个子代 DNA 一条旧链、一条新链；③ 转录：RNA 聚合酶按模板链合成 mRNA（T 换成 U）；④ 翻译：核糖体每 3 个碱基读一个密码子，查表得到氨基酸，遇终止密码子停止；⑤ 突变的后果取决于是否改变氨基酸、是否提前终止或移码。 {#s5e .explain}

::: html step5-2
qq: 为什么说 DNA 的复制是“半保留”的？
qo0: 每个子代 DNA 的两条链都是新合成的
qo1: 每个子代 DNA 含一条旧链和一条新链
qo2: 旧的 DNA 完整保留，新 DNA 另外合成
s5m: 本页做了很多简化：链的方向（5′→3′ 与反向平行）被忽略；复制只画了结果，没有解旋酶、引物、冈崎片段、校对；转录没有启动子、内含子和加工；翻译没有 tRNA 和核糖体的具体结构；密码表是标准遗传密码；突变只演示替换与单碱基插入删除；基因都是很短的示例序列，不是真实基因；华莱士法则只对很短的链粗略成立。
lk0: 细胞结构页：细胞核是遗传信息的保管处
lk1: 遗传与概率页：基因怎样一代代传下去，从配子到表型
:::
