# BRIEF：原子结构（atomic-structure）· 初中化学（化学线第二页）

## 定位
- slug `atomic-structure`，category `chemistry`（已在 `pages.config.js` 的 `KNOWLEDGE_CATEGORIES` 注册，粒子页上线时新增），stage `junior`。
- 受众：初中生 + 家长。前置：粒子页（particles-states）看过最好，但页面内自足交代——第一步用一句话把「粒子」接回来即可独立阅读。
- 核心直觉一句话：**原子不是实心球：中间一个极小的核（质子 + 中子）几乎占了全部质量，电子在外面按层排布——每层能坐几个有定数，排布决定了这个原子「活泼不活泼」**。
- 已知：物质由粒子组成、粒子一直在动（粒子页）；生活中见过元素名字（氢、氧、碳、钠……）。唯一新问题：把**一个**原子再放大，它内部到底长什么样，又是什么决定了它是哪种元素、活泼不活泼？

## 与粒子页的分工（评审防混淆句，构建与文案都须遵守）
- 粒子页讲的是**一群**粒子：物质由粒子组成，粒子动得多凶决定物态与温度（固/液/气是同一群粒子的三种队形）。
- 本页讲的是**一个**原子内部的结构：核里有什么、电子怎么分层、质子数为什么决定身份。两页的「动」不是一回事——粒子页的动是整个粒子在物质里跑，本页电子的「分层排布」讲的是住址，不是跑道；文案不得把两页的运动图景混写。
- 衔接：第 0 步开场一句回收粒子页（「上一页把物质放大成一群粒子；这一页再放大一颗」），终章深链回粒子页（见互链节）。

## 模型假设与失配（本页专节，构建与文案都必须遵守）
本页是结构示意模型，不是真实原子的照片。以下假设与失配必须在构建报告中复述，并在页面终章「这页的模型边界」一处如实交代（SPEC 清晰度第 8 条：模型失配必须明说）：
- **尺度严重失真，且必须明示**：真实原子里，核的直径只有原子直径的约十万分之一——按真比例画，核在整页画布上比一个像素还小、根本看不见。本页把核**放大了很多倍**才画得出来；文案在第 0 步与终章各出现一次「核与电子都被放大了、不是真比例」的双语明示（放大倍数若写具体数字，必须与画布几何实测一致，否则只写「放大了很多倍」定性口径）。同理电子的圆点大小也是示意。
- **电子层不是轨道（本页第一红线）**：本页用同心圈表示电子层，圈只是电子的「住址分区」，**不是电子的跑道**。电子不得画成沿圆周匀速绕核公转的「行星模型」——若页面有任何动画，电子只许在自己层内缓慢无规则地换位置（示意「在这一层里活动」），不许沿圈转。第 2 步与终章必须各有一句双语模型说明：「这是示意画法：电子实际不是沿着圈跑的，圈只表示它们大致住在哪一层。」（英文口径：The rings are a diagram convention — they mark roughly which layer an electron belongs to, not a track it runs on.）
- **排布规则是初中简化模型**：每层容量按 2 / 8 / 8 简化口径逐层填（第 4 层在本页范围内只出现在 K、Ca 的 [2,8,8,1]、[2,8,8,2]，顺势带过）。文案须在第 2 步明示「这是简化排布规则，真实排布更细，高中会展开」，不得把简化规则说成完整真理。
- **元素范围写死 Z = 1…20**（H 到 Ca，初中常用范围）。超出范围不假装能算：质子控件量程就钳在 1…20，读数区明示「本页只排到钙」。元素名/符号是**查表数据源**（见纯函数节），不是判定逻辑。
- **中子口径写死**：中子数取该元素最常见同位素的定值（查表数据源），页面只在第 1 步用一句话带过——「中子只改变质量数 A（= 质子数 + 中子数），不改变它是谁」；不展开同位素专题、不做中子控件。
- **稳定性是定性口径**：第 3 步的「稳定 / 易失电子 / 易得电子」是按最外层是否填满做的定性判定（判定规则见纯函数节写死），不是反应速率或真实化学活性的定量结论；文案用「容易 / 不容易」措辞，不用「一定会反应」式断言（SPEC 清晰度第 7 条）。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件；步骤 id 0 起）
0. **把一个原子放大：中间一个核，外面一大片空**：已知粒子页的「粒子」是构成物质的小单元；唯一问题：挑出其中一个原子再放大，它内部是实心的吗？输入：一个默认原子（建议碳，Z=6——生活里熟、排布 [2,4] 又不至于太空）；求量：核占的地方有多大、质量在谁身上。控件：放大/缩小（或拖动「放大镜」滑杆）从「一群粒子」过渡到单个原子视图；核可点高亮、电子层可点高亮，两处读数对照（核的直径占比示意值 vs 质量占比≈全部）。**尺度失真明示必须在本步出现**（见失配节）。预期观察：原子内部绝大部分是空的，核小得离谱却几乎扛了全部质量。结论：原子 = 极小的核 + 外面分层的电子，中间大片是空的。适用：本页示意模型口径（非真比例）。
1. **质子数决定它是谁**：已知第 0 步核里有质子和中子两种东西（本步首现处就近解释：质子带正电、中子不带电，合称核电荷数 = 质子数）；唯一问题：碳和氧差在哪，是什么让它「是」碳？输入：质子数 Z（控件 1…20）；求量：元素名与符号。控件：「+1 质子 / −1 质子」按钮（或滑杆，步进 1，钳 1…20）——每改一次，元素名、符号、核内质子点数**当场同步变**；中子点数按查表定值跟随，质量数 A 读数 = Z + N 实算更新，旁边一句中子口径（见失配节）。电子数本步默认跟随 Z（中性原子，为第 2 步留口：读数标明「电子数先跟质子数一样多」）。预期观察：Z 改 1，身份就换一家；加中子只变重、不换身份。结论：**元素身份只由质子数（核电荷数）决定**。适用：Z 1…20。
2. **电子分层排布：每层有定数**：已知电子在核外、带负电；唯一问题：电子在外面是怎么住的，是挤成一团还是有规矩？输入：电子数 e（本步默认 e = Z，可用第 1 步选定的元素接着看）；求量：每一层各住几个。控件：切几个预置原子（H / C / Na / Cl 建议做快捷钮）+ 电子数 ±1 试探钮——排布由纯函数当场重算并重画：电子**逐个落座**式地填（动画呈现「填」的顺序感：先填满内层再往外，但电子落座后静止或仅层内微动，**不许沿圈绕行**，见第一红线）。读数行给排布式（如 2、8、1）与总电子数。**简化模型明示必须在本步出现**（见失配节）+ 轨道非跑道说明在本步出现。预期观察：第一层最多 2 个、第二层最多 8 个，填满才轮到下一层；排布式随电子数增减实时对。结论：电子按层排布，每层容量有定数（本页简化口径 2/8/8），排布由电子数唯一算出。适用：e 在 0…20、本页简化规则。
3. **最外层决定活泼不活泼**：已知第 2 步的排布式；唯一问题：排布里哪一位说了算，为什么氖「高冷」、钠「一点就着」？输入：排布式（沿用第 2 步状态或预置对照组）；求量：最外层电子数、离填满还差几个。控件：对照组快捷钮（He / Ne / Ar 稳定组 vs Na / Mg / Cl 活泼组）逐个切，读数行只报三件事：最外层几个、满没满、判定（稳定 / 容易失去电子 / 容易得到电子，判定纯函数见下）；画布上最外层整层高亮。预期观察：最外层满的（2 或 8）都稳定；不满的要么差几个（想得到）、要么多几个（想失去）。结论：化学脾气主要看最外层——满了稳定，不满就想通过得失电子凑满。适用：本页定性口径
