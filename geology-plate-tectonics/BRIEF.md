# Plate Tectonics · build brief

## Learning outcome
Learners can distinguish divergent, convergent, and transform boundaries, then connect relative motion to ridge/trench/earthquake evidence.

## Interaction contract
- Step 0 time slider changes the geological snapshot and sea-floor expansion readout.
- Step 1 boundary buttons change arrow direction, cross-section shape, and explanation.
- Step 2 speed and mantle-heat sliders update three derived quantities and a profile trace.
- Step 3 shuffled evidence cards can be selected and checked as a causal loop.
- Chinese/English toggle uses the shared `knowledge-lang` key.

## Scope and model limits
Canvas drawings are schematic. Values in step 2 are relative teaching quantities, not geophysical forecasts. The evidence cards intentionally cover one canonical example per boundary type.
