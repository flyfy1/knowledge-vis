# BRIEF：小孔成像（pinhole-camera）· 小学科学 / 初中物理预备

## 定位
- slug `pinhole-camera`，category `physics`（站内已注册，velocity-vt 起用），stage `primary`。受众：小学高年级 + 家长，兼作初中物理光学的预备页。OUTLINE-v2 定位（W4）：光学线源头——光沿直线传播；蜡烛隔着小孔在墙上投出上下颠倒的像，接反射与折射、凸透镜。
- 核心直觉一句话：**光沿直线走——蜡烛每一点的光只能沿直线穿过小孔，顶部的光斜向下、底部的光斜向上，在孔口交叉，落到屏上就成了上下左右都交换的倒像；像相对物体有多大，由「蜡烛到孔」与「孔到屏」两个距离的比决定**。
- 已知：影子（生活经验：有光就有影）、长短距离的比较。唯一新问题：光走的路是什么形状？这条「直」能把像变成什么样？
- 文案口径（SPEC stage 条）：亲切但不幼稚化；数与几何不许为简化而失真——像高、落点、光斑宽全部实算（见「判定口径」）。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **光走直线，影子作证**：已知影子的存在；唯一问题：光到底走直线还是会拐弯，怎么知道？控件：侧视图——小灯泡（点光源示意）、一块挡板（圆片）、一块屏；代表光线从灯泡沿直线画出、被挡板截断，影子的两条边缘线由「灯泡点与挡板边缘连线延长到屏」几何实算；挡板可横向拖动（另有滑杆等价入口），影子实时跟随；「让光飞一遍」播放键：光点沿直线段前进（须显示进度与已走轨迹，不得只换帧）。预期观察：影子边缘利落、位置随挡板移动完全可预测——光要是会拐弯，影子边缘不会这样整齐。诚实注记（正文一句，必须有）：「这里用小灯泡，它近似『一个点发的光』，所以影子边缘利落；太阳那样的大光源，影子边缘会带一圈渐变，不在本页范围。」结论：**光在同一种介质（这里是空气）里沿直线传播**。适用条件：同一种均匀介质；碰到镜面会弹回、穿进水里会拐弯，是后面页面的事（终章回收，本步不展开）。
2. **小孔倒像登场**：已知光走直线；唯一问题：让光只能从一个小孔穿过、落到后面的屏上，会出现什么？控件：暗箱侧视图——左蜡烛（顶端点 A、底端点 B 有标记）、中挡板带小孔、右屏；「点亮光线」键逐条画两条关键光线（焰顶 A 的光穿孔心落屏下方、焰底 B 的光穿孔心落屏上方），两条线在孔口交叉、端点全部连线实算；角落附同步小俯视图（只画俯视的两条边光线），让「左右也交换」看得见——侧视图本身看不见左右交换，不许只靠文字宣称。蜡烛、屏本步固定（距离留到第 3 步动）。预期观察：屏上的像上下颠倒（焰尖朝下）、左右也反；交叉点就在小孔处。结论：**倒像**的成因就是直线交叉——不是孔把像「翻」了，是顶部的光只能走到下面去。
3. **像的大小谁说了算**：已知倒像由直线交叉形成、白话说过的「蜡烛到孔的距离 / 孔到屏的距离」在本步正式命名为**物距 u / 像距 v**，蜡烛高叫**物高 H**、像高叫 **h**（首现即给白话：就是字面意思的两个距离、两个高度）。唯一问题：像比蜡烛大还是小，由什么决定？输入与求量：物高 H（拖蜡烛或滑杆，30–90）、物距 u（拖挡板或滑杆）、像距 v（拖屏或滑杆），求像高 h。控件操作与预期观察：三量可调、两条关键光线与像实时重画；读数行给对账式——「像高 h = {h}；物高 ×（像距 ÷ 物距）= {H} × {v÷u，两位小数} = {同值}」，两边同值当场对账；预设卡点三键直达：u=v（等大）、u=2v（像半高）、v=2u（像双倍）。预期观察：蜡烛离孔越远像越小、屏离孔越远像越大，孔本身的大小不掺和（下一歩专问孔）。结论：**像高 ÷ 物高 = 像距 ÷ 物距**，像的大小只由两个距离的比决定。适用条件：孔足够小（下一歩说清「足够小」是什么意思）；初中埋线一句（结论处括注）：「这个『比相等』，初中叫相似三角形对应边成比例——同一件事的正式名字。」
4. **孔变大会怎样**：已知小孔时「一个物点 → 屏上一个像点」；唯一问题：孔开大，像为什么变糊？控件：孔径滑杆从小孔连续拖到大孔；焰顶、焰底两点各画 3 条代表光线（分别穿孔的上缘、中心、下缘），屏上落点各摊成一小段**光斑**（端点逐条连线实算、斑宽由孔径与两距离实算，见判定口径）；孔越大斑越宽、相邻点的斑叠得越多。示意口径（正文一句，必须有）：「图上每个物点只画 3 条代表光线；真实的光有无数条，摊成的是一整片光斑——只画 3 条，是为了看清『摊开』这件事。」附带读数：进光量随孔变大而变多，像变亮（一句：亮和糊是一对交换——孔大换来亮、赔上糊）。结论：本几何光学近似中，缩小孔径减小几何光斑并变暗；极小真实孔还受波动衍射限制，不能外推无限缩孔总更清晰；针孔相机、看日食的小孔投影盒用的都是小孔。适用条件：本步定性看「摊开与叠印」，落点与斑宽仍是几何实算、不是手绘示意。
5. **自测**：①物高 60、物距 30、像距 15，像高是多少？（正确答案 30，由 h=H·v/u 实算；干扰项口径写死：60 = 误以为永远等大；120 = 把比用反 H·u/v。）②蜡烛不动、屏也不换，想让屏上的像相对蜡烛更大，该怎么做？（把屏拉远 ✓；把孔开大 ✗——只会变糊，回收第 4 步；把蜡烛吹亮 ✗——亮度不改大小。）③屏上的像和蜡烛比，方向如何？（上下左右都反 ✓；只有上下反 ✗；完全一样 ✗——回收第 2 步俯视图。）④孔开得很大，像会怎样？（变糊 ✓；变大 ✗；消失 ✗——回收第 4 步。）四题全答对才出终章提示（沿用全站自测锁定口径）；每题反馈须点名错在哪条直觉，不许只说「再想想」。
6. **终章**：三卡收束（光走直线，影子作证 / 直线在孔口交叉，像就倒了 / 像高比 = 像距 ÷ 物距；几何孔径/光斑交换与极小孔衍射边界）。互链区（规则 12，带步锚、写明去那页学什么）：①`../reflection-refraction/#step0`——⚠️ 实核结论先行：反射页**没有**专讲直线传播的步，#step0 是镜面反射步、它以「光走直线」为已知前提；链文必须按落点实情措辞，如「光一直走直线，直到碰到镜面——镜面会把它按『入射角 = 反射角』弹回去，去看看弹的规矩」，**不许**写成「去学光为什么走直线」。②`../lens/#step1`——「把小孔换成凸透镜，像还是靠光线来定位：透镜页用三条有规矩的光线找像点，其中穿过光心的那条走的正是直线，和本页穿孔的这条是同一个道理。」登记注记：CONCEPT-MAP 现只有 lens#step2 一行，注册时请 Alberto 补 lens#step1 概念行（三条光线定位像点）后再挂此链；若注册时未补行，本链暂缓、不得裸链无锚的 lens 首页。埋线一句：照相机和眼睛，都是这套「成像」的后代（点到为止，不展开）。

## 判定口径（写死，构建与自查都按此执行）
- 像高 h 由状态实算：h = H × v / u。画布上像的两个端点独立实算：物端点与孔心连成直线、与屏平面（x = 孔 + v）求交点；两路结果必须一致（映射到像素后差 < 1.5px），自查断言覆盖至少三组（u=v、u=2v、v=2u）。
- 光斑宽由相似关系实算：斑宽 = 孔径 d × (u + v) / u；第 4 步 3 条代表光线的屏上落点逐条按「物点 → 孔缘点（上缘/中心/下缘）→ 屏」两段直线实算，不得手绘角度或弧线冒充光路。全页所有「光」都是两点式直线段。
- 自测答案与干扰项按公式生成/回算核对（题①的 30/60/120 须与公式口径逐一对上），不许写与公式不符的死数。
- 读数口径全页统一：距离与物高为整数（单位 cm，图按比例缩小、正文首现处注一句「图是按比例缩小的示意，数字按真实比例算」）、像高一位小数、比值（v÷u 与 h÷H）两位小数。
