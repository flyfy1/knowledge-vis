# BRIEF：声音是波（sound-waves）· Sound Is a Wave
- category `physics`，stage `junior`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：sound-vibration（同批小学）已讲振幅→响度、频率→音高、需要介质、回声测距；本页聚焦波的空间/时间图像、v=fλ、叠加（拍）、谐波音色、声速与温度、频率带，仅响度音高回链，重合约 30%。doppler-effect、standing-wave、resonance 不含这些。
- 核心直觉：疏密传播（质点不随波走）；周期 T=1/f 与波长 λ=v/f，v=fλ；拍频 |f₁−f₂|；谐波决定音色而周期不变；v≈331.3+0.606T 与雷声距离；20 Hz–20 kHz 听域。
- 备注：遵守“声音只用于有教学意义的比较”：本页不播放声音（无 AudioContext），因此没有需要实听验证的内容。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **一疏一密**
   - 已知：频率、响度（上页）。
   - 唯一问题：声音在空气里传的是什么？
   - 输入与求量：输入 f（100–1000 Hz）、振幅；求 T、λ=v/f、4 m 内波长数。
   - 控件操作与预期观察：拖 f：疏密变密 λ 变短；拖振幅：对比变大间距不变；暂停；动画慢放 250 倍；减弱动态/隐藏时停止。
   - 适用条件：位移夸大，一维线性。
1. **v = fλ**
   - 已知：周期与波长。
   - 唯一问题：周期与波长是什么关系？
   - 输入与求量：输入介质（空气/水/钢）与 f；求 T、λ、f×λ。
   - 控件操作与预期观察：同 f 换介质：上图不变、下图拉长。
   - 适用条件：介质声速取常数。
2. **拍**
   - 已知：叠加原理。
   - 唯一问题：两个相近音为何忽强忽弱？
   - 输入与求量：输入 f₁、f₂（400–480 Hz）；求拍频与平均频率；包络。
   - 控件操作与预期观察：f₂→f₁ 拍变慢，相等时消失；>约 15 Hz 变颤音（人耳特性）。
   - 适用条件：理想正弦叠加。
3. **音色**
   - 已知：正弦与周期。
   - 唯一问题：同一个音为什么听起来不同？
   - 输入与求量：输入模式（纯正弦/奇次/全部）与衰减指数 b（0–3）；求波形与频谱。
   - 控件操作与预期观察：周期恒为 1/220 s，形状随谐波变化。
   - 适用条件：谐波强度 ∝ n^{-b}，12 次。
4. **打雷的距离**
   - 已知：声速。
   - 唯一问题：怎样由间隔算距离？
   - 输入与求量：输入气温（−10…40 ℃）、间隔（0–15 s）；求声速、d=vΔt、光时间。
   - 控件操作与预期观察：约每公里 3 s；温度高声速略大。
   - 适用条件：均匀空气，忽略风与湿度。
5. **听得见的范围**
   - 已知：频率与波长。
   - 唯一问题：声音都听得见吗？
   - 输入与求量：输入对数滑杆频率；分类题（次声/可听/超声）；求波长。
   - 控件操作与预期观察：检查给反馈；下一题清除选择；重来清零；终章含回顾与 3 条互链。
   - 适用条件：典型值，个体差异大。

## 模拟设定与模型失配
一维线性无损耗，速度常数（空气 343 m/s，温度公式近似）；位移夸大、动画慢放 250 倍；拍与音色由理想正弦和计算（探针验证和差化积恒等式、周期为 1/f、谐波幅度 n^{-b}）；不播放声音，因此没有“未实听”的内容。
