# BRIEF：导数（derivative）· 高中数学

## 定位
- slug `derivative`，category math，stage senior。受众：高中生 + 家长。回收两条线：初中 velocity-vt 的「瞬时速度」与 parabola 的曲线——平均速度人人会算，「这一刻」的速度怎么算？
- 核心直觉一句话：**导数就是把「一段的平均变化率」压成「一点的瞬时变化率」：割线两点越靠越拢，割线斜率就收敛到切线斜率——那个斜率，就是函数在这一点的导数**。
- 已知：一次函数的斜率、平均速度、函数图像。唯一新问题：曲线在某一点的「斜率」怎么定义、怎么算？

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **平均速度不够用**：已知平均速度=路程÷时间；唯一问题：变速运动里「第 2 秒这一刻」有多快，平均速度答不了。控件：复用投篮/小车位移曲线 s=t²（0–3 s），时钟动画 + 时刻探针；取 [1,3]、[1,2]、[1,1.5] 三个区间算平均速度各得 4、3、2.5（读数逐项对账 Δs/Δt），区间越窄、数越往一个值靠。预期观察：平均速度随区间选取而变，它答的是「这段」不是「此刻」。结论：要问此刻，就得让区间往一点缩。
2. **割线逼近切线**（核心步）：唯一问题：两点重合成一点，割线会变成什么？控件：y=x² 上固定点 P(1,1)，动点 Q 可拖（或 Δx 滑杆：1、0.5、0.1、0.01 三档按钮 + 连续滑杆），割线 PQ 实时画、斜率读数实时算（=(Q.y−1)/Δx=2+Δx）；Δx→0 时割线肉眼转成切线，切线在 Δx 足够小后点亮并保持；负方向 Δx<0 同样可拖（从左侧逼近、斜率从 <2 靠拢，双侧一致须明说）。预期观察：Δx 从正负两侧缩小，斜率都收敛到 2。结论：这个收敛到的数就叫**导数** f′(1)=2；割线极限位置叫**切线**。适用条件：曲线在该点足够光滑（埋线：尖点处两侧靠不到一起——终章一句带过不展开）。
3. **每个点都有自己的导数**：唯一问题：换一个点，导数还是 2 吗？控件：P 点沿 y=x² 可拖（x 从 −2 到 2），每点自动画切线、读该点导数（实算 (x+Δ)²−x²)/Δ 取数值极限并与 2x 对账，读数给「测得 ≈2x」口径）；拖动时下方同步描出一条新曲线——把每个点的导数收集起来，点列逐渐描成直线 y=2x。预期观察：导数随点变、且变化有规律（负半轴为负、正半轴为正、0 处为 0）。结论：导数本身也是一个函数，叫**导函数**；x² 的导函数是 2x。适用条件：先以 x² 为例，公式表在收口给（x³→3x² 只作「试一试」验证、不证明）。
4. **导数在说什么**：唯一问题：导数的正负大小，翻回实景是什么意思？控件：同一曲线切换三种读法：①增减——导数>0 段曲线上升段着色、<0 下降、=0 在顶点；②陡缓——|导数| 越大曲线越陡（与 2、3 步拖动联动回顾）；③瞬时速度——切回 s=t² 情境，导数就是第 t 秒的瞬时速度，探针读数与 velocity-vt 页口径一致（深链回收）。预期观察：同是导数，几何（切线斜率）、代数（变化率）、物理（瞬时速度）三张脸是同一个数。结论：导数 = 此刻的变化率，三种读法同源。
5. **自测 + 终章**：①给 y=x² 在 x=3 的割线逼近三档读数（Δx=1/0.1/0.01 → 7/6.1/6.01），问导数是几（判定 6）；②y=x³ 在 x=1 的导数试一试：按页面提供的逼近工具实测选 3（选项 1/2/3/4）；③判断题「导数就是切线本身」（错：导数是切线的斜率、一个数）。终章三卡（平均→瞬时靠缩区间 / 导数是切线斜率 / 导函数收集每点斜率）+ 深链：velocity-vt#step1（瞬时速度在那页先见过）、parabola#step2（顶点处导数为 0——在那页是对称轴顶点、在这页是导数零点）；integral 未上线不链，只一句埋线「把变化率反过来累加回去，就是下一页的定积分」纯文本。
