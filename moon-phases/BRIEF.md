# BRIEF：月相（moon-phases）· 小学科学
- category `earth`（地球与太空，已注册），stage `primary`（已注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，记录不确定性）。去重：day-night-rotation 讲昼夜，不含月相；无重复。
- 核心：月亮永远亮半边，月相 = 地球上看到的亮面比例 (1−cosθ)/2，周期 29.53 天；轨道倾斜使日月食不每月发生；潮汐锁定使同一面朝向地球。

## 步骤（五必填项）
0. 总有半边亮。已知：太阳光直线传播；问题：月亮哪半边亮？输入月亮位置角 θ；观察：俯视图中亮半边始终朝右（太阳）；适用：平行光、圆轨道。
1. 从地球看。问题：为何有圆缺？输入 θ；观察：左俯视位置、右北半球月面，读数 = (1−cosθ)/2；θ 0–180° 右侧亮（渐盈），180–360° 左侧亮。
2. 一个月。问题：八相顺序与周期？输入：天数滑杆、播放/暂停/重置；观察：八个小月亮依次点亮并记录“已出现 k/8”；重置清除记录并停止播放，页面隐藏时停止；减弱动态时直接跳到月末。
3. 为何不天天食。问题：为何不是每次新月满月都有食？输入轨道夹角 i、离交点角 ν；观察：月亮偏离日地连线高度 h = 38.44 万千米·sin i·sin ν，与阈值 RE+RM=8108 千米比较（粗略判据，如实说明）；侧视图距离按比例、天体放大 3 倍。
4. 同一面朝向我们。问题：自转与公转关系？输入：真实/不自转、θ；观察：标记指向地球 vs 偏离；读数为标记方向与地球方向夹角（0° vs θ）。
5. 终章。问题：由月相反推位置？输入猜测 θ、检查/换一个；容差 15°；判定考虑亮侧。深链：day-night-rotation#step0、pinhole-camera#step0（均已核对存在；仅 2 条，因站内尚无其它直接相关页）。

## 新术语首现表
月相、被照亮的比例（步 1）；朔望月（步 2）；轨道夹角、交点（步 3：月球轨道面与地球轨道面的交线上的点，在步 3 正文中说明夹角）；潮汐锁定（步 4 以“每公转一圈自转一圈”描述）。

## 模拟设定 / 模型失配
轨道为圆、光平行、大小距离不按比例（步 3 距离按比例）；北半球视角；日月食判据为粗略几何阈值（真实还含本影半径与距离变化）；交点概念只给判据不推导。
