# BRIEF：杠杆与滑轮（lever-pulley）· 初中物理

## 定位
- slug `lever-pulley`，category physics，stage junior（物理）。受众：初中生 + 家长。接在力学启蒙位置——前面页讲过力与运动（velocity-vt），本页第一次问「力能不能被放大、代价是什么」。
- 核心直觉一句话：**转动的账看力矩：力 × 力臂，两边相等就平衡——支点一挪，同样的重物要用的力立刻变；但省力必费距离，功的账本两边永远相等；滑轮组不用算，数一数吊着重物的绳子段数，就知道省几倍力**。
- 已知：力有大小和方向、重力与质量的关系（重力 = 质量 × g）、距离与位移。唯一新问题：为什么小力能撬动大物、省下来的力到底从哪「借」来的、又要拿什么还？

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **跷跷板：力矩登场**（step0）：已知重力随质量变大、离支点越远「压得越沉」的生活经验；唯一问题：大人比小孩重得多，为什么大人往支点挪一挪，两人就能平？控件：一根跷跷板，支点固定在正中；大人（60 kg）与小孩（30 kg）各可在本侧沿板拖动（位置以 0.2 m 为格、距支点 0.4–2.0 m，另有滑杆等价入口）；板子随净力矩实时倾斜（倾斜方向与幅度由两边力矩差决定），水平时锁定「平衡」态并给视觉标记。读数行同屏对账：左侧力矩 = 60×10×大人距离、右侧力矩 = 30×10×小孩距离（单位 N·m，三量——力、力臂、力矩——在图上就地标注：力的箭头、力臂的双向标尺、力矩的数值牌）。预期观察：大人坐到 1.0 m、小孩坐到 2.0 m 时板平——重的人离支点近，照样能平；把任一人拖远一格，板立刻向他那侧沉。结论：**决定转动的是力矩 = 力 × 力臂，不是力本身；两边力矩相等就平衡**。适用条件：力竖直向下（重力）、板水平时的力臂就是到支点的水平距离；板自重忽略（支点在正中、自重力矩两边抵消，正文一句点到）。
2. **撬棍：支点滑杆对账**（step1）：已知第 1 步的力矩平衡；唯一问题：撬大石头时，支点垫在哪最省力、省多少能算出来吗？控件：一块大石（重力 G = 800 N）压在撬棍右端，支点（垫石）位置用滑杆在棍上连续滑动（支点到石头的阻力臂 L阻 0.1–0.5 m，动力臂 L动 = 棍长 1.5 m − L阻，图上两段长度实时标注），手在左端向下用力；读数行给对账表：所需力 F（由平衡条件实算）、左力矩 F×L动、右力矩 G×L阻，两值恒相等并排显示。另设「用力试试」按钮：按当前 F 施力，石头被撬起的动画与力矩归零同步。预期观察：支点越靠近石头，L阻 越小、L动 越大，F 从近 800 N 一路降到 200 N 以下；支点滑到最左也没有「不用力」——F 永远 > 0。结论：**杠杆平衡条件 F×L动 = G×L阻；省力倍数 = L动/L阻，支点越贴近重物越省力**。适用条件：静止或匀速撬起的平衡口径；棍自重忽略。
3. **省力必费距离：功的账本**（step2）：已知前两步「省力倍数」；唯一问题：力省掉的那部分，是不是凭空消失了？控件：沿用第 2 步撬棍场景（力臂比固定 3:1 一档、另可切 2:1 / 4:1），「撬起」播放键让撬棍转过一个固定小角度：手端沿弧线下压的距离 s 与石头被抬起的高度 h 在图上以弧线标尺实时量出（s 与 h 均由同一转角 × 各自力臂实算），画面两侧各一条「功账本」进度条：手做的功 W入 = F×s、石头得到的功 W出 = G×h，两条恒长得一样高（现象须肉眼可见地同步涨满，不是只给两个数字）。预期观察：力臂比 3:1 时 F 只有 G 的三分之一，但手要压下 3 倍距离；两条账本条严丝合缝相等；切到 4:1，F 更小、s 更长，账本仍相等。结论：**省力必费距离——W入 = W出，功的账本从不亏空；省力倍数是几，手移动的距离就是几倍**。适用条件：理想口径（不计摩擦与棍自重）；转角相同时弧长比严格等于力臂比，故账本相等是几何必然、不是近似（正文点明这一句）。
4. **定滑轮：只改方向**（step3）：已知功账本；唯一问题：井口、旗杆顶上那个轮子，到底省不省力？控件：一个定滑轮（固定在支架上），绳一端吊重物（G = 200 N），一端由手向下拉（拉力方向可切：竖直下拉 / 斜向拉，两个预设钮）；拉绳滑杆控制拉出的绳长 s，重物上升 h 实时跟随；读数行三列对账：拉力 F、拉绳长 s、重物升 h，并与「不用滑轮直接提」基线并排（F 恒 = 200 N、s 恒 = h）。预期观察：怎么拉 F 都是 200 N 一分不少，但人可以站在地上往下拉、不用爬上去抱重物；斜着拉 F 也不变（绳中张力处处相等，图上以同一颜色/粗细画整条绳示意）。结论：**定滑轮不省力、不省距离，只改变力的方向**。适用条件：理想滑轮（不计摩擦、绳重）；拉力沿绳任意方向，大小不变。
5. **动滑轮与滑轮组：数段数定倍数**（step4）：已知定滑轮不省力、功账本；唯一问题：轮子跟着重物一起动，会怎样？控件分两段：①单个动滑轮场景——滑轮钩着重物（G = 400 N）随绳升降，绳一端固定在天花板、一端手拉，图上把「吊着动滑轮与重物的绳段」用高亮色逐段点数（2 段，点数动画逐段亮起）；②滑轮组场景——段数选择钮 2 / 3 / 4 段（绕绳图随段数真实重绘，段数 = 图上实际画出的承重绳段根数），手拉端出绳方向随绕法如实呈现（奇数段向下、偶数段向上，或以本页统一绕法图为准并在正文说明）。统一控制：拉绳滑杆给 s，读数行对账：F = G/n、h = s/n、W入 = F×s 与 W出 = G×h 账本再对一次。预期观察：段数每 +1，F 立刻按 G/n 变小、同样拉绳长度下 h 按比例变矮；手拉 2 m、4 段时重物只升 0.5 m。结论：**省力倍数 = 承重绳段数 n：F = G/n，代价是拉绳 n 倍距离；数段数不用背公式**。适用条件：理想口径（不计摩擦、动滑轮自重与绳重）；n 只数吊着动滑轮与重物的段数，手拉的自由端若也承重则计入——计数口径以图上高亮段为准，正文给一句数法口诀。
6. **自测 + 终章**（step5）：自测三题（判定值写死、答对锁定、答错给指向对应步的提示）：①跷跷板：80 kg 的爸爸坐支点左侧 1.0 m，40 kg 的你坐右侧多远能平衡？（2.0 m）②滑轮组：3 段绳吊 600 N 重物，拉力多大？（200 N）③判断：手拉出 3 m 绳、4 段滑轮组，重物升多高？（0.75 m）终章三卡（力矩平衡 F₁L₁ = F₂L₂ / 省力必费距离、功账本相等 / 滑轮组数段数定倍数）。深链处置：写前已核对 CONCEPT-MAP.md——站内暂无「功与能」的专讲页（velocity-vt#step2 的「面积 = 路程」是另一种账、非本页功账本的落点），**不硬链**；终章只回扣本页三卡，另以一句无链文字预告「功和能以后会有专页」。本页可被链入的概念行（注册时由 Alberto 补入 CONCEPT-MAP）：lever-pulley#step0「力矩 = 力 × 力臂，平衡即两边力矩相等」、lever-pulley#step4「滑轮组：数承重绳段数定省力倍数」。

## 新术语首现表（首现处就近一句话解释，规则 11：每步首现都要就近带口径）
- 支点（第 1 步：杠杆转动的那个固定点）、力臂（第 1 步：支点到力的作用线的距离，本页力竖直向下，就是到支点的水平距离，图上以双向标尺画出）、力矩（第 1 步：力 × 力臂，量「让东西转动有多带劲」，单位 N·m）、杠杆（第 2 步：一根能绕支点转的硬杆，本页撬棍就是）、动力 / 阻力（第 2 步：你使的力叫动力、要克服的重物重力叫阻力，各自的力臂叫动力臂 / 阻力臂）、功（第 3 步：力 × 沿力方向移动的距离，单位 J，读数行两边对账）、定滑轮（第 4 步：轴固定不动的滑轮）、动滑轮（第 5 步：轴随重物一起移动的滑轮）、滑轮组（第 5 步：定、动滑轮搭配成的组合）、承重绳段（第 5 步：直接吊着动滑轮与重物的那几段绳，数它定倍数）。

## 数值口径（写死，实现与评审一律照此对账）
- **单位与 g**：质量 kg、力 N、长度 m、力矩 N·m、功 J。**全页 g 取 10 N/kg**，任何读数/题面不得出现 9.8 混用。选 N 而不用「重量单位（kg 当力）」的理由：kgf 不是课标单位、且功的账本要用焦耳对账，只有 N 体系下 F×s 才严丝合缝；g=10 又保住初中生的心算友好（60 kg → 600 N 整数）。跷跷板人物质量只用 10 的倍数（30/40/60/80 kg），滑轮重物重力只用整百 N，保证所有标准断言值为整数。
- **力矩实算**：M = F × L 全部由纯函数实算，画布倾斜、读数、平衡判定同源。平衡判定：|M左 − M右| ≤ 1e-9 判平衡（本页参数均为整数或一位小数、运算精确，容差只防浮点尾巴，不得放宽成「差不多平」）。跷跷板倾斜角是**示意量**：θ = clamp(ΔM × 0.06°, ±18°)，正文/图注标明「倾斜角度是示意、力矩数值是实算」；撬棍、滑轮的位移与升距是**实算量**（同一转角下弧长 = 力臂 × 转角），不得与示意量混口径。
- **功账本**：W入 = F × s手、W出 = G × h 恒由各自实测量算出后并排显示，两者之差断言为 0（构造上 F = G/n、s = n·h 同源，差只允许浮点尾差 ≤1e-9）；账本进度条以 W 的相对涨幅绘制，两条必须同帧同步。
- **滑轮几何关系写死**：理想滑轮口径——不计摩擦、绳重、动滑轮自重（第 4 步正文一句话声明，第 5 步首现再带一句，规则 11）。定滑轮 F = G、s = h；n 段滑轮组 F = G/n、s = n·h（n ∈ {2,3,4}）。**图上承重绳段根数必须与公式 n 一致**：画布逐段绘制、高亮计数 = n，脚本断言（切到每种段数后数高亮段元素数 == n）；出绳方向随绕法如实画，不得画 3 段的图配 4 段的数。
- **标准断言值**（自查脚本必须逐条跑）：跷跷板 大人 60 kg@1.0 m vs 小孩 30 kg@2.0 m → 两边力矩 600 = 600 N·m、平衡；大人拖到 1.2 m → 左 720 > 右 600、板左沉。撬棍 G=800 N、L阻=0.3 m、L动=1.2 m → F=200 N、两边力矩 240 = 240 N·m。功账本 3:1 档转角下 s=0.6 m、h=0.2 m → W入 = W出。定滑轮 G=200 N → F=200 N、s=h。滑轮组 G=400 N、n=2 → F=200 N；G=600 N、n=3 → F=200 N；n=4、s=2 m → h=0.5 m、F=G/4。自测三题答案 2.0 m / 200 N / 0.75 m。
- **显示口径**：力矩与功优先整数显示，非整数时一位小数加 ≈；力臂以 m 显示两位小数或一格 0.2 m 的格数读数，全页统一一种，不得同一读数行两种口径并存。
