## 先选社会，再揭开幕布看自己是谁 {#step0 h2=s0t}

第 0 步 · 一个思想实验 {#s0k .step-kicker i18n=text}

这一步要回答：不知道自己会是谁时，选择会变成什么样的问题？哲学家罗尔斯（John Rawls，《正义论》，1971）设想一层**无知之幕**：选择社会规则的人不知道自己的阶层、财富、社会地位。下面三种社会各有 5 个人数相同的**位置**，柱子高度是该位置的**福祉分**（本页虚构的抽象单位，不是钱）。选一种社会，再按「揭开幕布」，随机落到一个位置。 {#s0e .explain}

::: html step0-1
choose: 我选
socA: A · 人人一样
socB: B · 高增长、差距大
socC: C · 托底的增长
lift: 揭开幕布
resetDraws: 清空记录
:::

每抽一次，对应位置下方就多一个点（历史保留；换一种社会再换回来，原来的记录还在，「清空记录」只清当前社会）。多抽几次，你会同时感到两件事：「平均下来不错」和「万一落在最底下」。下面两步分别把这两种想法写成规则。 {#s0hint .hint i18n=text}

## 平均原则：既然谁都可能是，就算平均 {#step1 h2=s1t}

第 1 步 · 第一种规则 {#s1k .step-kicker i18n=text}

这一步要回答：如果你落在每个位置的机会一样大，该怎么比较？经济学家海萨尼（John Harsanyi，1975 年批评罗尔斯的论文）主张：完全不知道时，就假设落在每个位置的**概率相等**，于是该选**平均福祉**最高的社会（<a class="xlink" href="../../../probability/basics/expected-value/#step0">→ 期望值第 0 步：随机游戏「平均」能拿多少</a>）。按这个规则，B（平均 45）胜出。下图是从所选社会里反复抽取时，**累计平均**（抽到的分数之和 ÷ 次数）怎样走向这个平均值。 {#s1e .explain}

::: html step1-1
draw100: 再抽 100 次
:::

观察顺序：选 B，连按几次「再抽 100 次」，看折线怎样越来越贴近虚线（平均值）。再换成 A、C 比较。平均原则只看这条虚线，不看折线一路上抽到过多低的分数。 {#s1hint .hint i18n=text}

## 最大最小原则：先保证最差的位置 {#step2 h2=s2t}

第 2 步 · 第二种规则 {#s2k .step-kicker i18n=text}

这一步要回答：如果这个选择只做一次、改不了，还该只看平均吗？罗尔斯认为，幕后的选择决定你一生的前景、无法重来，所以应采用**最大最小原则**（maximin）：比较各个社会**最差位置**的福祉，选最差位置最好的那个。他给出三条适用条件：没有或只有很不可靠的依据去估计自己落在哪个位置的概率；最大最小原则选出的结果本身是可以接受、能够与之共处的，比它多出来的收益不那么要紧；而别的选项有无法接受、无法与之共处的坏结果。罗尔斯后来说，第一条作用较小，关键在后两条。按这个规则，A（最差 30）胜出，B 的最差只有 10。 {#s2e .explain}

:::

## 风险态度 η：从「只看平均」到「只看最差」 {#step3 h2=s3t}

第 3 步 · 把两者接起来 {#s3k .step-kicker i18n=text}

这一步要回答：两条规则之间有没有中间地带？这里用一个**教学用的旋钮**（不是罗尔斯或海萨尼本人的提法）：**风险厌恶程度 η**（eta）。对每个社会算一个**确定性等价**——你愿意用来换掉「随机落到一个位置」的那个确定分数。η = 0 时它就是平均值；η 越大，低分位置的分量越重；η 很大时它接近最差位置。这和「保费高于期望损失仍有人买保险」是同一种心理（<a class="xlink" href="../../../probability/basics/expected-value/#step4">→ 期望值第 4 步</a>）。 {#s3e .explain}

::: html step3-1
ceAxis: 确定性等价
eta: 风险厌恶 η
:::

观察顺序：把 η 从 0 慢慢拖到 8，看右图竖线扫过三条曲线：先是 B 最高，约 η = 0.8 后 C 最高，约 η = 3.5 后 A 最高。C 这种「托底的增长」只在中间地带胜出。 {#s3hint .hint i18n=text}

## 再分配越多，底层越好，但蛋糕可能变小 {#step4 h2=s4t}

第 4 步 · 拉平有代价时 {#s4k .step-kicker i18n=text}

这一步要回答：如果可以从 B 出发做再分配，各条规则会选多大力度？设**再分配比例 t**：每个位置交出 t 份福祉，汇总后平均分回。再假设拉平会让总量缩小到原来的 (1 − k·t²)，**效率损失 k** 是本页随手设定的教学参数，不来自任何数据。下图三条线随 t 变化：平均、最差位置、以及当前 η（风险厌恶：越大越看重低分位置）下的确定性等价（愿意用来换掉「随机落到一个位置」的确定分数）；圆点是各自的最好 t。平均原则选平均最高的 t，最大最小原则选最差位置最好的 t。 {#s4e .explain}

::: html step4-1
bars: 当前 t 下的 5 个位置
tLabel: 再分配比例 t
kLabel: 效率损失 k（教学假设）
eta4: 风险厌恶 η
:::

观察顺序：先把 k 设为 0（拉平没有代价）——最大最小原则会一直拉到 t = 1，平均原则无所谓。再把 k 调大，看最大最小原则的最好 t 怎样停在中间：再往下拉，底层也会因蛋糕变小而受损。 {#s4hint .hint i18n=text}

## 同一层幕，两种谨慎 {#step5 h2=s5t}

收束 {#s5k .step-kicker i18n=text}

::: html step5-1
s5fin: 无知之幕把「对我好不好」变成「对任何一个位置好不好」。**平均原则**把每个位置看得一样可能，求平均；**最大最小原则**认为这次选择不可重来，先保护最差的位置。它们的分歧可以读成对风险的不同态度，但罗尔斯本人强调的是选择情境的特殊性，不只是性格上怕不怕风险。
