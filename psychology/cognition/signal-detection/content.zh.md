## 两位检测者都对了 80%，谁更会分辨？ {#step0 h2=s0t}

第 0 步 · 一个问题 {#s0k .step-kicker i18n=text}

这一步要回答：只看「正确率」能不能比较两位检测者？下面是一个**假设的教学例子**（取自 Birmingham 大学 Georgeson 的讲义）：各看 100 张有肿瘤、100 张无肿瘤的片子。每次只有两种回答「有」或「没有」，于是只有四种结果：有肿瘤说「有」叫**命中**，有肿瘤说「没有」叫**漏报**，没肿瘤说「有」叫**虚报**（误报），没肿瘤说「没有」叫**正确拒绝**。两边的总正确率都是 80%。 {#s0e .explain}

::: html step0-1

predB: 机器更会分辨

:::

注意机器几乎不漏报，但虚报多；医生两种错误一样多。正确率把这两种错误加在了一起。 {#s0hint .hint i18n=text}

## 每次判断背后，都有一个看不见的「证据强度」 {#step1 h2=s1t}

第 1 步 · 模型 {#s1k .step-kicker i18n=text}

这一步要回答：同一张片子，为什么有时判对、有时判错？信号检测论假设：每看一次，脑中（或机器里）产生一个**证据强度 x**，它每次都有随机起伏。没有信号时，x 来自**噪声分布**（灰色，平均 0）；有信号时，x 来自**信号分布**（青色，平均更高）。两者是同样宽的正态分布（<a class="xlink" href="../../../probability/basics/binomial-normal/#step3">→ 二项与正态第 3 步：正态曲线长什么样</a>）。观察者只定一条线叫**判据**：x 超过它就说「有」。 {#s1e .explain}

::: html step1-1
runTrials: 再做 20 次试验
resetTrials: 清空
:::

本步固定两分布相距 1.5 个标准差、判据在正中间。**命中率 H** = 有信号时说「有」的比例；**虚报率 F** = 无信号时说「有」的比例。多做几轮，看实测比例怎样靠近模型给的面积（图中涂色部分）。 {#s1hint .hint}

::: strings
s1readout: 已做 {n} 次（一半有信号）· 命中 {hit} · 漏报 {miss} · 虚报 {fa} · 正确拒绝 {cr}　｜　命中率 H 实测 {H} · 模型 {Hm}　虚报率 F 实测 {F} · 模型 {Fm}
s1empty: 按按钮做试验：每个点是一次试验的证据强度 x，上排为有信号，下排为无信号；点在判据线右边就是回答「有」。
:::

## 判据 c：只改「多愿意说有」，不改分辨能力 {#step2 h2=s2t}

第 2 步 · 第一个量 {#s2k .step-kicker i18n=text}

这一步要回答：把判据线左右移，会发生什么？**判据 c** 衡量判据线离两个分布正中间有多远，单位是标准差：c &lt; 0 叫**宽松**（更爱说「有」），c &gt; 0 叫**严格**，c = 0 叫**无偏**。往左移，**命中率 H**（有信号时说「有」的比例）和**虚报率 F**（无信号时说「有」的比例）*一起*上升：少漏报，就得多虚报。两条分布的距离没变。 {#s2e .explain}

::: html step2-1
cLabel: 判据 c（负=宽松，正=严格）
:::

观察顺序：从 c = 1 拖到 c = −1，看两块涂色面积一起变大；松手后旧判据线变淡留在图上。反算的 c 用的是 z(·)：把一个比例换成「标准正态里左边占这么多面积的位置」，单位是标准差。 {#s2hint .hint i18n=text}

::: strings
s2readout: c = {c} · H = {H} · F = {F} · 每 100 次有信号漏报 {miss} 次、每 100 次无信号虚报 {fa} 次 · 用 H、F 反算 c = −[z(H)+z(F)]/2 = {cBack}
:::

## 敏感度 d'：两个分布离得多远 {#step3 h2=s3t}

第 3 步 · 第二个量 {#s3k .step-kicker i18n=text}

这一步要回答：什么才是真正的「分辨能力」？**敏感度 d'**（读作 d-prime）= 信号分布和噪声分布平均值的距离，以它们共同的标准差为单位。d' = 0 时两条曲线重合，怎么判都是瞎猜；d' 越大，重叠越少。实验里看不到分布，只看得到 H（命中率：有信号时说「有」的比例）和 F（虚报率：无信号时说「有」的比例），所以要反算：**d' = z(H) − z(F)**，其中 z(p) 是把比例 p 换成标准正态中对应位置（单位：标准差）的换算。 {#s3e .explain}

::: html step3-1
dLabel: 敏感度 d'
:::

观察顺序：保持 c（判据：判据线离两分布正中间几个标准差）不动，只拖 d'——H 升、F 降，正确率上升。再保持 d' 不动、拖 c（第 2 步）——反算出的 d' 不变。这个「不变」只在本页的等方差正态模型里成立。 {#s3hint .hint i18n=text}

::: strings
s3readout: d' = {d} · c = {c} · H = {H} · F = {F} · 反算 z(H) − z(F) = {dBack} · 正确率 {pc}%
:::

## ROC 曲线：同一个 d'，所有判据画成一条弧 {#step4 h2=s4t}

第 4 步 · 一张图看全 {#s4k .step-kicker i18n=text}

这一步要回答：怎样一眼看出两位检测者谁更会分辨？把判据从严到松扫一遍，每个判据给出一对 (虚报率 F, 命中率 H)，连起来就是 **ROC 曲线**（受试者工作特征曲线）。同一条曲线上的点 d'（敏感度：两分布平均值相距几个标准差）相同，只是判据 c 不同；曲线越鼓向左上角，d' 越大。对角线是 d' = 0（瞎猜）。图上标出了第 0 步的医生和机器。 {#s4e .explain}

::: html step4-1
:::

观察顺序：只拖 c，当前点沿着一条曲线滑；只拖 d'，点跳到另一条曲线。这些弧形是在「两分布等宽的正态」假设下画的；真实数据的 ROC 若不对称，说明这个假设不成立，d' 也就随判据变。 {#s4hint .hint i18n=text}

## 最好的判据，取决于错误有多贵、信号有多常见 {#step5 h2=s5t}

第 5 步 · 用起来 {#s5k .step-kicker i18n=text}

这一步要回答：判据该放在哪？答案不是「正中间」。设**基础率**（每次试验里真有信号的比例）为 p，一次**漏报**的代价是 m，一次**虚报**的代价是 f。每次试验的**期望代价** = p·(1−H)·m + (1−p)·F·f，其中 H 是命中率（有信号时说「有」的比例）、F 是虚报率（无信号时说「有」的比例）。下图画出它随判据 c（判据线离两分布正中间的距离，负 = 宽松）的变化，绿点是最低处。漏报越贵、信号越常见，最佳判据越宽松（更左）。这和贝叶斯里「先验 × 似然比」是同一笔账（<a class="xlink" href="../../../probability/inference/bayes-updating/#step2">→ 贝叶斯更新第 2 步：后验 = 先验 × 似然比</a>）。 {#s5e .explain}

::: html step5-1
baseRate: 基础率 p（真有信号的比例）
costRatio: 漏报代价 ÷ 虚报代价
yourC: 你的判据 c
:::

期望代价按本页模型（d' = 1.5）计算，单位是「虚报一次 = 1」。试试：把漏报代价调到 10（比如漏诊很严重），看最佳判据往哪移；再把基础率调到 0.05。 {#s5hint .hint i18n=text}

## 先拆开，再比较 {#step6 h2=s6t}

收束 {#s6k .step-kicker i18n=text}

::: html step6-1
s6fin: 任何「有 / 没有」的判断都同时含有两样东西：**d'**（分得多清）和 **c**（多愿意说有）。只看正确率或只看命中率，会把两者混在一起。先用 H、F 把它们拆开，再按错误的代价选判据。
formula: H = P(说有 | 有信号)　F = P(说有 | 无信号)　d' = z(H) − z(F)　c = −[z(H) + z(F)]/2
boundary: 模型边界：本页假设两种试验的证据强度都是同样宽的正态分布（等方差模型）；试验数据由固定种子的随机数生成，是模拟不是实测。H 或 F 等于 0 或 1 时 z 为无穷大，实际分析需要修正。医生与机器是讲义里的假设例子，不代表真实诊断水平。
quizPrompt: 一位雷达员换了更严格的判据，少喊「有」了。按本页模型，他的 d' 会怎样？
quizA: 上升：他犯的虚报少了。
quizB: 不变：判据只移动 H 和 F，不改两个分布的距离。
quizC: 下降：他的命中也少了。
check: 检查判断
lk1: ↗ 记忆与注意第 1 步：干扰越多，命中率越低
lk2: ↗ 假设检验第 2 步：「冤枉公平硬币」就是虚报
lk3: ↗ 假设检验第 3 步：硬币真有偏时能否揪出来，就是命中率
lk4: ↗ 贝叶斯更新第 2 步：先验 × 似然比
:::

::: strings
correct: 正确：H 和 F 一起降，z(H) − z(F) 不变（在等方差模型里）。
wrong: 再看第 3 步：只拖 c 时，反算出的 d' 变了吗？
:::
