## 原电池：把氧化和还原分在两个烧杯里 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 原电池
:::

::: html step0-1
:::

这一步要回答：电子为什么会沿导线从一个电极流向另一个？氧化还原反应里，一种金属失去电子（**氧化**），另一种离子得到电子（**还原**）。把它们分在两个烧杯，用导线接起来，电子就只能走导线。失电子的一极叫**阳极**（氧化发生处，原电池里为负极），得电子的一极叫**阴极**（还原发生处，正极）。哪一个金属更容易失电子，看**标准电极电势** E°（金属离子得电子的倾向，V）：E° 低的当阳极，E° 高的当阴极；电池电动势 E°电池 = E°阴极 − E°阳极。盐桥让离子流动、保持两个烧杯电中性。点播放，黄色小点是电子。 {#s0e .explain}

::: html step0-2

pZnAg: 锌–银
pCuAg: 铜–银
pMgCu: 镁–铜

:::

## 放电：电压怎样随反应进行而变化？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 放电
:::

::: html step1-1
:::

这一步要回答：电池用着用着，电压怎么变？以锌–铜电池为例（锌片浸在 [Zn²⁺] = 0.01 mol/L 的溶液，铜片浸在 [Cu²⁺] = 起始浓度的溶液，各 1 L）。每转移 2 mol 电子，溶解 1 mol Zn，沉积 1 mol Cu。电池电动势随浓度变化服从 E = E° − (0.0592/2)·log₁₀([Zn²⁺]/[Cu²⁺])（25 °C，能斯特方程，下一步细讲）。点播放，曲线累积 E 随反应进度（已反应的 Cu²⁺ 摩尔数）的变化。你会看到：大部分时间电压只缓慢下降，等 Cu²⁺ 快用完时下降才明显加速（本页是理想模型，电压只降到约 0.9 V；真实电池要到电极材料耗尽才会骤降为零）。 {#s1e .explain}

::: html step1-2
s1o: 播放到结束，找电压下降明显加速的位置；把起始 [Cu²⁺] 调小，加速下降的位置提前；把放电快慢调大，只影响曲线画得多快，不改变曲线形状。
lC0: 起始 [Cu²⁺]（mol/L）
lRate: 放电快慢
bReset: 重置：清除曲线，电极回到初始
:::

:::

## 能斯特方程：浓度也会推动电压 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 能斯特方程
:::

::: html step2-1
:::

这一步要回答：不是标准状态时，电动势是多少？用**反应商** Q = [Zn²⁺]/[Cu²⁺]（生成物浓度比反应物浓度）：E = E° − (0.0592/n)·log₁₀Q（25 °C，n = 2 是转移的电子数）。Q 越大（生成物多、反应物少），电压越低；Q = K（平衡）时 E = 0，电池“没电”。右图横轴是 log₁₀Q，纵轴是 E，是一条斜率为 −0.0296 V 的直线；圆点是当前浓度。E° = 1.10 V，平衡常数 K = 10^(nE°/0.0592)。 {#s2e .explain}

::: html step2-2
s2o: 把两个浓度滑块都设成 0（即 1 mol/L）：E = E°；把 [Cu²⁺] 调小 10 倍：E 变化多少？再把 [Zn²⁺] 调大 10 倍，对比；读数里 log₁₀K 是 Q 要涨到多大电压才归零。
lLogCu: log₁₀[Cu²⁺]
lLogZn: log₁₀[Zn²⁺]
:::

::: strings
r2: Q = [Zn²⁺]/[Cu²⁺] = {q}，log₁₀Q = {lq}；E = 1.10 − 0.0296×({lq}) = {e} V；平衡时 log₁₀K = {lk}（Q 达到 K 时 E = 0）。
:::

## 电解池：外加电压反推，反应倒着走 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 电解池
:::

::: html step3-1
:::

这一步要回答：外加电压会怎样影响反应方向？还是锌–铜电池（两边都是 1 mol/L），E = 1.10 V。串联一个反向电压 V 的电源：回路的净电动势 = E − V，电流 I = (E − V)/R（R 取 1 Ω）。V &lt; E 时仍是原电池放电（Zn 溶解、Cu 沉积）；V = E 时电流为零；V &gt; E 时电流反向，变成**电解池**：Cu 溶解、Zn 沉积，外电源在“把电池充电”。电流方向反转时，哪个电极是阳极（氧化发生处）也会跟着变。 {#s3e .explain}

::: html step3-2
s3o: 把 V 从 0 拉到 2：看电子流向在 V = 1.10 V 处变成零并反转；注意阳极标签怎样从锌变成铜；读数里电流正负代表方向。
lVapp: 外加反向电压 V（V）
:::

::: strings
r3: 外加 V = {v} V，E = {e} V：净推动 = {net} V，电流 I = {i} A（{dir}）；阳极（氧化）是 {an}。
dirGal: 原电池放电：电子 Zn → Cu

## 法拉第电解定律：通多少电，析出多少金属 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 法拉第定律
:::

::: html step4-1
:::

这一步要回答：电解 Cu²⁺ 溶液时，阴极析出多少铜？通过的电量 Q = I·t（库仑）；每析出 1 mol Cu 需要 2 mol 电子，1 mol 电子带电 F = 96485 C。所以析出质量 m = M·I·t/(n·F)，M = 63.55 g/mol（Cu 的摩尔质量），n = 2。点播放，铜层随时间累积，右图是质量–时间的直线，斜率 = M·I/(nF)。 {#s4e .explain}

::: html step4-2
s4o: 把电流 I 加倍：同一时刻质量加倍；把时间加倍：质量也加倍；验证读数里“I = 1 A、t = 60 分钟”的参考值约为 1.19 g。
lAmp: 电流 I（A）
lMin: 通电时间 t（分钟）
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 原电池：E° 低的金属当阳极（氧化），电子从阳极经导线流向阴极；E°电池 = E°阴 − E°阳；② 放电时电压缓慢下降，反应物用尽时骤降；③ 能斯特方程 E = E° − (0.0592/n)·log₁₀Q；④ 外加电压超过 E 就变成电解池，反应倒着走；⑤ 法拉第定律 m = M·I·t/(nF)。 {#s5e .explain}

::: html step5-2
qq: 在原电池里，电子在导线中的流向是？
qo0: 从阴极流向阳极
qo1: 从阳极流向阴极
qo2: 沿着盐桥从一个烧杯流向另一个
s5m: 本页用理想的标准电极电势（25 °C）与能斯特方程：忽略内阻与过电势、浓度换算成活度、温度变化、极化与气体副反应；第 1 步体积固定 1 L、两个烧杯电荷平衡由盐桥保证；第 3 步电阻 R = 1 Ω 是教学取值；第 4 步假设电流效率 100%，只析出 Cu；电子点的速度和数量是示意，不代表真实电子漂移速度。
lk0: 电场页：电势与电势差，E° 就是这类“单位电荷的能量差”
lk1: 化学平衡页：Q 与 K，能斯特方程里同一个反应商
lk2: 活化能页：电池反应自发（E > 0）不代表反应一定快，速率由另一座山决定
:::

qwhy: 阳极发生氧化、释放电子，电子经导线流向发生还原的阴极；盐桥里流的是离子，不是电子（第 0 步）。
:::
