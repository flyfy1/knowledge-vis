## 一团火至少需要哪几样东西同时存在？ {#step0 h2=s0t}

::: strings
nav0: 0 三条腿
:::

第 0 步 · 三条腿 {#s0k .step-kicker i18n=text}

这一步要回答：为什么有的东西放着不烧、有的东西一点就烧？**燃烧**是可燃物与氧气发生的剧烈、发光放热的反应。要持续烧起来，需要三样同时具备：**可燃物**（能烧的东西）、**氧气**（通常来自空气）、**温度达到着火点**（着火点是物质开始燃烧所需的最低温度）。把三个开关一个个关上，看火在什么时候熄。 {#s0e .explain}

::: html step0-1
s0stage: 三角形的三条边就是三个条件：亮着表示具备；三条边都亮时中间才有火焰
s0canvas: 燃烧三角形：三条边分别是可燃物、氧气、温度，三边齐全中间才出现火焰
s0fuel: 有可燃物
s0air: 有氧气（空气）
s0heat: 温度够高（达到着火点）
:::

结论：三个条件同时具备才燃烧，去掉任意一个，火就灭。条件：这是简化的「三角」模型；更完整的说法还要加上持续的链式反应。 {#s0result .readout i18n=text}

::: strings
s0ro: {legs}。{verdict}
s0legs: 具备：{have}；缺少：{miss}
s0none: 无
s0burn: 三个条件齐全：燃烧。
s0out: 至少缺一个条件：不会（继续）燃烧。
:::

## 蜡烛罩上玻璃罩为什么会灭？罩子大小有关系吗？ {#step1 h2=s1t}

::: strings
nav1: 1 罩住蜡烛
:::

第 1 步 · 罩住蜡烛 {#s1k .step-kicker i18n=text}

这一步要回答：蜡烛在密闭的玻璃罩里为什么会灭，罩子越大会怎样？空气里氧气约占 21%（体积分数）。蜡烛烧着不断消耗氧气，氧气的比例降到约 16% 以下，火焰就维持不住。拖罩子的体积，按「盖上罩子」，看氧气比例随时间下降、火焰变小直到熄灭。 {#s1e .explain}

::: html step1-1
s1stage: 上：蜡烛与玻璃罩；下：氧气比例随时间的曲线（实线已发生，虚线是预测），横线是约 16% 的熄火线
s1canvas: 蜡烛罩上玻璃罩后氧气比例下降，降到熄火线以下火焰熄灭
s1v: 玻璃罩体积
s1cover: 盖上罩子
s1lift: 揭开罩子，重新点燃
:::

结论：罩子越大，氧气越多，烧得越久。条件：本页取氧气消耗速率 1 mL/s、熄火线 16% 的教学数值，忽略二氧化碳与温度变化的影响；真实蜡烛的熄灭点因设置而异。 {#s1result .readout i18n=text}

::: strings
s1ro: 罩子 {v} mL：第 {t} s，氧气比例 {frac}%；{state}
s1on: 火焰还在，但越来越小。
s1out: 氧气比例低于约 16%，火焰熄灭了（熄灭时刻约 {te} s）。
s1idle: 还没盖上罩子；盖上后约 {te} s 熄灭。
:::

## 温度要多高才会着火，所有东西都一样吗？ {#step2 h2=s2t}

::: strings
nav2: 2 着火点
:::

第 2 步 · 着火点 {#s2k .step-kicker i18n=text}

这一步要回答：同样加热，为什么有的东西先烧起来？每种物质有自己的**着火点**（引燃所需的最低温度）。选一种物质，拖加热温度；温度到达着火点、同时有氧气，才起火。下面的条形图给出几种常见物质的着火点（近似值），橙色竖线是当前温度，线左边的物质这个温度下已经能着火。 {#s2e .explain}

::: html step2-1
s2stage: 条形图：每种物质的着火点（近似值，℃）；橙色竖线是当前加热温度；左上是正在被加热的那一种
s2canvas: 几种物质的着火点条形图与当前加热温度线，温度线越过的物质能着火
s2mat: 被加热的物质
s2T: 加热温度
s2air: 有氧气（空气）
:::

结论：着火点因物质而异，温度、氧气缺一不可。条件：着火点是常见资料的近似值（受压力、颗粒大小、加热方式影响），不能当作安全阈值。 {#s2result .readout i18n=text}

::: strings
s2ro: {mat}：着火点约 {ign} ℃，现在 {T} ℃；{state}
s2go: 温度已达着火点且有氧气：着火了。
s2noT: 还没到着火点：不会着火。
s2noAir: 温度够了，但没有氧气：烧不起来。
s2others: 此刻温度下还能着火的物质：{list}。
:::

## 各种灭火办法，各自抽掉了哪一条腿？ {#step3 h2=s3t}

::: strings
nav3: 3 怎么灭火
:::

第 3 步 · 怎么灭火 {#s3k .step-kicker i18n=text}

这一步要回答：选一种灭火办法，它在这个火场里抽掉了哪条腿，真的管用吗？水主要靠吸热让温度降到着火点以下；盖住是隔绝氧气；切断燃料是拿走可燃物；二氧化碳灭火器喷出的气体盖住火焰隔绝空气。选一个火场，试各种办法，注意有的办法在特定火场里会适得其反。 {#s3e .explain}

::: html step3-1
s3stage: 火场与三角形：被抽掉的那条腿会变灰；火焰熄灭才算灭火成功
s3canvas: 火场示意图：采取灭火办法后，对应的三角形一条边变灰，火焰熄灭或继续
s3sc: 火场
s3m0: 浇水降温
s3m1: 盖住隔绝空气
s3m2: 切断或移走可燃物
s3m3: 二氧化碳灭火器
s3reset: 重新点火
:::

结论：灭火 = 抽掉一条腿，但要选对办法。条件：本页只列了四种场景和四种办法；真实灭火还要考虑人员安全、火势大小和火源类型（如电器火不能用水）。 {#s3result .readout i18n=text}

::: strings
s3ro0: 选一个办法试试。
s3roOut: {m}：抽掉了「{leg}」这条腿，火灭了。
s3roUnsafe: {m}：危险！{why}
s3roStill: {m}：这里不管用——{why}
s3whyOilWater: 水比油重，沉到热油下变成蒸汽，把燃烧的油溅得到处都是，火反而扩大。应该盖上锅盖。
s3whyOilFuel: 锅里的油没法「移走」，等不及；关火并盖上锅盖才行。
s3whyGasWater: 水只能降温，气体还在不断漏出来，一有火源又会再燃。要先关阀门。
s3whyGasCover: 没法把一股持续喷出的气体「盖住」，要先关阀门。
s3whyGasCo2: 火焰可能暂时被盖灭，但气体还在漏，随时会再点着或积聚爆炸。要先关阀门。
s3whyForestCover: 山林面积太大，没法整片盖住。
s3whyForestCo2: 灭火器的量太小，对大面积山火几乎没用；要用防火隔离带、大量洒水。
leg_water: 温度
leg_cover: 氧气
leg_fuel: 可燃物
leg_co2: 氧气
:::

## 同样一块木头，劈碎以后为什么烧得更快？ {#step4 h2=s4t}

::: strings
nav4: 4 烧得多快
:::

第 4 步 · 烧得多快 {#s4k .step-kicker i18n=text}

这一步要回答：可燃物与氧气接触的面积越大，燃烧越快吗？把一块方木切成 k×k×k 个小方块，总质量不变，但总表面积变成原来的 k 倍；再调通风（空气流量倍数）。按「点火」，看木块变黑的速度和下面燃尽曲线（剩余质量比例随时间）。 {#s4e .explain}

::: html step4-1
s4stage: 上：被切成 k×k 格的木块正面，越亮表示烧得越多；下：剩余质量比例随时间的曲线，灰线是 k = 1 通风 1 倍的参照
s4canvas: 切成小块的木头燃烧：块越小、通风越好，剩余质量下降越快
s4k2: 切成 k×k×k 块
s4a: 通风（空气流量倍数）
s4go: 点火
s4reset: 复原木块
:::

结论：燃烧速率与接触面积、氧气供应成正比，所以粉末最易烧、木屑比原木快。条件：本页取 烧完时间 = 60 s ÷ (k × 通风倍数) 的教学模型；面粉、煤粉等细粉悬浮在空气里甚至会爆炸，不要尝试。 {#s4result .readout i18n=text}

::: strings
s4ro: 总表面积 ×{k}，通风 ×{a}：烧完需约 {T} s（参照 60 s）；现在第 {t} s，剩余 {rem}%。
:::
