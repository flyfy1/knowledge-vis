## 反应像翻山：先上坡，再下到生成物 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 能量山
:::

::: html step0-1
:::

这一步要回答：为什么有些反应物“一碰就反应”，有些却要加热才动？图的横轴是反应进程（从反应物到生成物），纵轴是体系的能量（kJ/mol）。反应物位于左边低处，生成物在右边，中间有一座山，山顶比反应物高出的能量就是**活化能** Eₐ；生成物与反应物的能量差是**反应热** ΔH（负值为放热，生成物更低）。让一个分子带着能量 E 出发：E ≥ Eₐ 才能翻过山顶，否则就被推回来。小球的运动按能量守恒（动能 = E − 当前位置的势能）计算。 {#s0e .explain}

::: html step0-2
s0o: 固定 Eₐ = 90，把 E 从 62 调到 97 再点“出发”：小球在 E < Eₐ 时爬到半山腰折返，E ≥ Eₐ 时翻过山顶；再改 ΔH，看终点高低变化但山顶位置（Eₐ）不变。
lEa: 活化能 Eₐ（kJ/mol）
lDh: 反应热 ΔH（kJ/mol）
lE: 分子的能量 E（kJ/mol）
bLaunch: 让分子带着能量 E 出发
bReset: 重置：分子回到起点
:::

::: strings
r0: Eₐ = {ea} kJ/mol，ΔH = {dh} kJ/mol（{kind}）；分子能量 E = {e} kJ/mol：{res}；逆反应活化能 Eₐ′ = Eₐ − ΔH = {er} kJ/mol。
axisProg: 反应进程
kExo: 放热反应
kEndo: 吸热反应
kZero: 热效应为零

:::

## 谁能爬上去？只有分子群里能量最高的一小部分 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 谁爬得上去
:::

::: html step1-1
:::

这一步要回答：同一温度下，分子能量参差不齐，有多少够得上 Eₐ？在温度 T 下，能量大于 E 的分子比例按玻尔兹曼因子下降：比例(≥E) = e^(−E/RT)（R = 8.314×10⁻³ kJ/(mol·K)，是气体常数；RT 是热运动的能量尺度，300 K 时约 2.5 kJ/mol）。图的纵轴是对数坐标：比例(≥E) 是一条直线，温度越高越平。竖线是 Eₐ，它与直线交点的高度就是能反应的分子比例。灰线是 300 K 的参考。 {#s1e .explain}

::: html step1-2
s1o: 固定 Eₐ = 60，把 T 从 300 K 升到 350 K：看交点上移了几个数量级，对照读数里的比例变化倍数；再把 Eₐ 加到 100，比较同样升温带来的倍数变化。
lT: 温度 T（K）
:::

::: strings
r1: T = {t} K：RT = {rt} kJ/mol；能量 ≥ Eₐ 的分子比例 e^(−Eₐ/RT) = {frac}；相比 300 K（{f300}）是 {ratio} 倍。
:::

## 阿伦尼乌斯：速率常数随温度指数增长 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 阿伦尼乌斯
:::

::: html step2-1
:::

这一步要回答：温度每升高一点，反应快多少？只有爬得上去的分子才反应，速率常数 k = A·e^(−Eₐ/RT)（A 是碰撞频率相关的常数，本页取 A = 10¹³ s⁻¹ 量级的相对值 1）。左图是 k 随 T 的曲线（相对于 300 K 的倍数）；右图把 ln k 对 1/T 作图，是一条斜率为 −Eₐ/R 的直线（阿伦尼乌斯图）。点“记录”会把当前 T 下的 ln k 加上 ±2% 的模拟测量误差作为一个数据点；用几个点拟合斜率就能反推 Eₐ。 {#s2e .explain}

::: html step2-2
s2o: 固定 Eₐ，在 300–420 K 间记录至少 4 个不同 T 的点，看拟合的 Eₐ 是否接近滑块设定值；再改 Eₐ，看直线变陡；读数里的“升温 10 K 倍数”在 300 K 附近大约是几倍？
bAdd: 记录一个数据点 (1/T, ln k)
bClear: 清除全部数据点
:::

::: strings
r2: T = {t} K：k/k₃₀₀ = {kr}；升温 10 K 后 k 变为 {x10} 倍；已记录 {n} 个点，拟合 Eₐ ≈ {efit} kJ/mol（设定 {ea} kJ/mol）。
needMore: 至少 2 个点才能拟合
:::

## 催化剂：把山挖矮，但不改终点 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 催化剂
:::

::: html step3-1
:::

这一步要回答：催化剂怎样让反应变快？催化剂给反应换了一条路径，山顶变低（Eₐ 减小），但反应物和生成物的能量没变（ΔH 不变）。k = A·e^(−Eₐ/RT) 中指数变小，k 变大：加速倍数 = e^(ΔEₐ/RT)。逆反应的山也同样变矮，同样加快同样的倍数，所以催化剂不改变平衡位置（只是更快达到）。灰线是无催化剂的路径，彩线是有催化剂的路径。 {#s3e .explain}

::: html step3-2
s3o: 把“降低的活化能”从 0 拉到 40：山峰降低而两端不动；看加速倍数怎样随之放大；把 T 升高，同样的催化剂的加速倍数是变大还是变小？
lDea: 催化剂降低的活化能（kJ/mol）
:::

::: strings
r3: 降低 ΔEₐ = {d} kJ/mol，T = {t} K：正、逆反应都加速 {sp} 倍；平衡常数比（有催化剂/无催化剂）= {kr}。
:::

## 逆反应也要翻山：山高不同，快慢不同 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 逆反应与平衡
:::

::: html step4-1
:::

这一步要回答：同一座山，从生成物翻回去有多难？逆反应的活化能 Eₐ′ = Eₐ − ΔH。正、逆反应速率常数之比 k正/k逆 = e^(−ΔH/RT)（本页取两者 A 相同，等于忽略熵的贡献，只是教学简化）。放热反应（ΔH < 0）逆反应更难，所以 k正 > k逆；吸热则相反。升高温度使这个比值向 1 靠近。图中两根柱是 k正 与 k逆（对数坐标）。 {#s4e .explain}

::: html step4-2
s4o: 把 ΔH 从 −50 调到 +50：k正 柱从高于变成低于 k逆 柱；固定 ΔH，把 T 升高：两柱的差距缩小，对照读数里的比值。
:::

::: strings
r4: Eₐ = {ea}，Eₐ′ = {er} kJ/mol，T = {t} K：k正 = {kf}，k逆 = {kb}（相对值）；k正/k逆 = {ratio}。
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 反应物要翻过能量山，山顶比反应物高出的能量是 Eₐ；② 温度下，能量 ≥ Eₐ 的分子比例是 e^(−Eₐ/RT)；③ k = A·e^(−Eₐ/RT)，ln k–1/T 是斜率 −Eₐ/R 的直线；④ 催化剂降低 Eₐ，正逆反应同样加速，不改变 ΔH 和平衡位置；⑤ 逆反应活化能是 Eₐ − ΔH。 {#s5e .explain}

::: html step5-2
qq: 一个 Eₐ = 50 kJ/mol 的反应在室温附近（300 K）升温 10 K，速率大约变成多少倍？
qo0: 约 1.1 倍
qo1: 约 2 倍
qo2: 约 100 倍
s5m: 本页用玻尔兹曼因子和阿伦尼乌斯公式的最简形式：只考虑能量足够，忽略碰撞取向因子、量子隧穿、A 随温度的变化与多步反应；能量分布取指数形式（自由度简化）；ΔH 与 Eₐ 在不同温度下视为常数；A 相同等于忽略熵；第 2 步的测量误差是人为加入的；第 0 步小球是能量守恒的教学示意，不是真实分子轨迹。
lk0: 反应速率页：从碰撞角度看催化剂如何让更多碰撞成功
lk1: 化学平衡页：升温为什么使平衡移动，与这里 k正/k逆 的比值相联系
lk2: 反应速率页：同一件事的温度一节，用粒子碰撞数来数
:::
