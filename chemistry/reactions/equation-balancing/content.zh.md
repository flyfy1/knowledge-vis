## H₂ + O₂ → H₂O 这样写，哪里不对？ {#step0 h2=s0t}

::: strings
nav0: 0 为什么要配平
:::

第 0 步 · 为什么要配平 {#s0k .step-kicker i18n=text}

这一步要回答：把氢气和氧气生成水写成 H₂ + O₂ → H₂O，为什么还不能算对？**化学方程式**用化学式和箭头表示反应：箭头左边是**反应物**，右边是**生成物**。化学式前面的数字叫**系数**（有几个这样的分子，等于 1 时省略不写）；化学式里的小下标则是一个分子里的原子数，配平时**只改系数，不改下标**。每种原子各有一杆小天平，左边和右边的个数不等就会翘起来。拖系数，让每杆天平都平。 {#s0e .explain}

::: html step0-1
s0stage: 每个元素一杆小天平：左盘是反应物侧该原子的总数，右盘是生成物侧；平了变绿，翘了变粉
s0canvas: 氢和氧两杆小天平，系数改变时两侧原子数与横梁倾斜随之变化
coef1: 第 1 个物质的系数
coef2: 第 2 个物质的系数
coef3: 第 3 个物质的系数
:::

结论：配平的要求是每种原子左右总数相等。条件：只改系数、不改化学式；本页反应都按理想的完全反应处理。 {#s0result .readout i18n=text}

::: strings
s0ro: {eq}：{tally}。{verdict}
s0ok: 两杆都平了：这个方程式配平了。
s0no: 还没平：有元素左右个数不等，先改系数。
:::

## 一个反应里有好几种元素，先配哪一种？ {#step1 h2=s1t}

::: strings
nav1: 1 从哪个元素下手
:::

第 1 步 · 从哪个元素下手 {#s1k .step-kicker i18n=text}

这一步要回答：甲烷燃烧 CH₄ + O₂ → CO₂ + H₂O，几种原子都不平时，按什么顺序配最省事？经验是先配只出现在一种反应物、一种生成物里的元素（这里是 C、H），最后才配到处都有的氧。拖滑杆走完 4 个阶段，看哪一杆天平在哪一步被调平。 {#s1e .explain}

::: html step1-1
s1stage: 三杆小天平：碳、氢、氧；滑杆走到第几阶段，系数就是该阶段的结果
s1canvas: 甲烷燃烧的三杆小天平，随阶段依次被调平：先碳、再氢、最后氧
s1st: 配平阶段
:::

结论：先配出现次数少的元素，最后配氧或氢这类到处都有的。条件：这是一条经验顺序，不是唯一方法；有的反应需要先配奇数。 {#s1result .readout i18n=text}

::: strings
st0: 起点：所有系数都是 1
st1: 先看碳：左 1 个、右 1 个，已经平，系数不用动
st2: 再配氢：左 4 个、右 2 个，把 H₂O 的系数改成 2，氢平了
st3: 最后配氧：右边 CO₂ 里 2 个 + 2 个 H₂O 里 2 个 = 4 个，把 O₂ 的系数改成 2，氧也平了
s1ro: 阶段 {st}：{note}。当前 {eq}，{tally}。
:::

## Fe + O₂ → Fe₂O₃，氧一边是 2、一边是 3，怎么办？ {#step2 h2=s2t}

::: strings
nav2: 2 奇数对偶数
:::

第 2 步 · 奇数对偶数 {#s2k .step-kicker i18n=text}

这一步要回答：氧原子左边每个 O₂ 带 2 个，右边每个 Fe₂O₃ 带 3 个，怎样才能相等？办法是找 2 和 3 的最小公倍数 6：让左边有 6 个氧、右边也有 6 个氧，再回头配铁。拖系数试，卡住了点「给个提示」，会告诉你下一个该改哪个系数。 {#s2e .explain}

::: html step2-1
s2stage: 铁、氧两杆小天平；系数改变时，两边原子数立刻重算
s2canvas: 铁和氧两杆小天平，系数调到 4、3、2 时同时平衡
s2hint: 给个提示
s2reset: 系数全设为 1
:::

结论：奇数对偶数时，用最小公倍数找系数。条件：要求系数是正整数；有解的反应才能这样配。 {#s2result .readout i18n=text}

::: strings
s2ro: {eq}：{tally}。{verdict}
s2hintMsg: 提示：下一个该把第 {i} 个物质的系数改成 {v}（最小整数解里它是 {v}）。
s2solved: 配平了，而且是最简整数比。
s2solvedBig: 平了，但各系数还可以同除以 {g}，化成最简整数比。
:::

## 4 H₂ + 2 O₂ → 4 H₂O 也平，为什么答案写 2 : 1 : 2？ {#step3 h2=s3t}

::: strings
nav3: 3 最简整数比
:::

第 3 步 · 最简整数比 {#s3k .step-kicker i18n=text}

这一步要回答：系数同时乘 2、乘 3 之后仍然平，为什么还要写最简的那一组？因为配平给出的是分子个数的**比例**，约定写成最小的整数比（各系数没有大于 1 的公因数）。拖倍数 k，看原子数同步放大，天平始终是平的。 {#s3e .explain}

::: html step3-1
s3stage: 氢、氧两杆小天平：倍数 k 变大，两侧原子数同比放大，仍然平衡
s3canvas: 氢氧反应的小天平：倍数变化时数量变大但始终平衡
s3k2: 倍数 k
:::

结论：配平结果取最小的整数比。条件：系数必须是正整数（不能有半个分子）；比例由原子守恒决定。 {#s3result .readout i18n=text}

::: strings
s3ro: {eq}：{tally}。{verdict}
s3simple: 最简整数比（系数没有公因数）。
s3notSimple: 平衡，但系数有公因数 {g}，还可以约简。
:::
