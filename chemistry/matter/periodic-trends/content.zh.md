## 为什么：核电荷越大拉得越紧，层数越多越松 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 为什么
:::

::: html step2-1
:::

这一步要回答：规律背后的原因是什么？最外层电子感受到的是被内层电子“屏蔽”后的**有效核电荷** Zeff = Z − S（Z 是核电荷数，S 是屏蔽常数，用斯莱特规则估算：同层电子约 0.35、内一层 0.85、更内层 1.00）。电子离核的距离大致与 n\*²/Zeff 成正比（n\* 是有效主量子数：第 1–3 层 1、2、3，第 4 层取 3.7）。横轴是 n\*²/Zeff，纵轴是实测半径；直线是最小二乘拟合。同周期内 Z 增加、层数不变，Zeff 增大，半径缩小；下一周期多一层，半径突然变大。 {#s2e .explain}

::: html step2-2
s2o: 选 Li、Be、B……Ne 一路拉过去：Zeff 一路增加，点沿直线向左下移动；再选 Na：Zeff 回落、层数加一，点跳回右上；看读数里的预测半径与实测半径差距。
:::

:::

## 沿着一个族往下走：多一层，一切都变松 {#step3 h2=s3t pre=1}

::: strings

:::

::: html step3-1

这一步要回答：同一族自上而下，性质怎么变？同族元素最外层电子数相同，但每往下一个周期就多一个电子层，最外层电子离核更远，被内层屏蔽得更多。选一个族和一个性质，下面的柱子从上到下对应第 2、3、4 周期（稀有气体含第 1 周期的 He）。总趋势：半径变大，电离能变小，电负性变小。 {#s3e .explain}

::: html step3-2

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 周期表上的性质按行、按列渐变；② 沿周期：Zeff 增大，半径变小，IE₁ 和 χ 变大；③ 沿族向下：多一个电子层，半径变大，IE₁ 和 χ 变小；④ 有例外（IE₁ 在 Be→B、N→O 处回落）；⑤ 趋势可以预测下一个元素的大致性格，但不能替代数据。 {#s5e .explain}

::: html step5-2
qq: 下面哪组按原子半径从小到大排列？
qo0: Na < Mg < Al
qo1: K < Na < Li
qo2: F < O < Li
s5m: 本页只含前四周期的主族元素（共 26 个），省略了过渡金属；半径用共价半径（Cordero 等，随成键环境略变，稀有气体的值是估计的）；IE₁ 取教科书常见值；电负性用鲍林标度；斯莱特规则是粗略的屏蔽估算，拟合的相关系数只说明趋势一致，并不等于理论上的精确公式；预测题里的“趋势”只是总体规律。

:::

::: strings
qwhy: F、O 在第 2 周期靠右，Zeff 大、半径小；Li 在同周期最左，半径最大（第 1 步）。Na、Mg、Al 同周期，半径是 Na > Mg > Al；K、Na、Li 同族，半径自下而上变小，所以应是 Li < Na < K。
:::
