分子构型 · 电子对互相躲开

中心原子周围的电子对彼此排斥，自己排成最分散的队形；水为什么弯、甲烷为什么是正四面体，都从这里来。

N 个电子对，怎么排才离得最远？

这一步要回答：中心原子周围的电子对（价层电子对互斥模型，VSEPR）会排成什么形状？每个电子对是一个带负电的“电子区域”（一个单键、一个双键、一个孤对电子都各算一个区域），它们彼此排斥，所以在以中心原子为球心的球面上散得尽可能开。右图把 N 个点放在球面上，每对点按 1/r² 的力互相推开（r 是两点间距离），点“重播”看它们从随机位置逐步挪到最稳的位置。拖动画布或旋转滑块可以转动视角。

依次把 N 设为 2、3、4、5、6，点重播：看最终队形是直线、平面三角形、正四面体、三角双锥、正八面体；读数里的最小夹角应分别是 180°、120°、109.5°、90°、90°。

排斥能是怎样一步步降下来的？

这一步要回答：电子对真的会走到“最稳”的位置吗？每个队形有一个总排斥能 E = Σ qᵢqⱼ/r（对所有点对求和，q 是每个区域的“电荷”，这里都取 1）。从 5 个不同的随机起点出发，每一步让每个点沿着受力方向挪一小步（再投回球面），E 就一步步下降。右图每条线是一个起点；虚线是各起点里找到的最低能量。滑动“已迭代步数”，左边显示第 1 个起点此时的队形。

拖动迭代步数从 0 到 400：左边队形逐渐规整，右边圆点沿曲线下滑；看 5 条线是否都落到虚线上（有时有个别起点停在更高的局部低点），点“换 5 个新起点”再试。

孤对电子：不成键，但占地更大

这一步要回答：为什么水是弯的、氨是三角锥？中心原子的 N 个区域里，有些连着别的原子（成键对，青色小球），有些是孤对电子（没有成键的电子对，粉色大球）。孤对电子只受中心原子束缚，云更“胖”，排斥更强（本页取每个孤对的“电荷”为 1.2，成键对为 1）。分子的形状只看原子的位置，不看孤对。滑块 N 和孤对数 L 一起决定 AXₘEₙ 类型和形状；模拟取 30 个随机起点中能量最低的那个。

固定 N = 4，把 L 从 0 → 1 → 2：形状从正四面体变成三角锥再变成弯曲形，成键角从 109.5° 缩小；再设 N = 5、L = 1、2、3，看孤对是否都排在“赤道”位置。

几种真实分子：模型和实验对得上吗？

这一步要回答：用同一套“电子对互斥”规则，真实分子的形状怎么来？选一个分子，页面按它的中心原子周围的成键对数和孤对数（N、L）运行同一模拟，并把模型成键角与教科书里的实验值并列。双键或三键各算一个电子区域。模型只用一个参数（孤对更胖），所以像 H₂O 的 104.5°、NH₃ 的 107° 能大致对上，但并不精确。

依次点 CH₄ → NH₃ → H₂O：成键角越来越小，孤对数 0 → 1 → 2；再点 SF₄ 和 XeF₂，看孤对排在哪个位置，以及线形的 XeF₂ 为什么有 3 个孤对。

形状决定极性：键有极性，分子不一定有

这一步要回答：为什么 CO₂ 不极性而 H₂O 极性？每个键有一个键偶极（箭头指向电负性更大的原子，长度 = 电负性之差）。分子的偶极是所有键偶极的矢量和（孤对电子的贡献本页忽略）：形状对称时箭头互相抵消，和为 0；不对称时合成一个净偶极。电负性取鲍林值（C 2.55、H 2.20、N 3.04、O 3.44、F 3.98、B 2.04、S 2.58、Xe 2.6）。

依次点 CO₂、BF₃、CH₄（键有极性，但和为 0）与 NH₃、H₂O（有净偶极）；转动视角，看合成箭头（橙色）朝哪个方向。

回顾与自测

回顾：① 价层电子区域互相排斥，排成最散的队形：2 个直线、3 个平面三角形、4 个正四面体、5 个三角双锥、6 个正八面体；② 排斥能随迭代下降到最低；③ 孤对更“胖”，把成键角压小，形状只看原子位置；④ 真实分子的角度与模型大致吻合；⑤ 分子极性 = 键偶极的矢量和，由形状决定。

水分子中氧原子有 2 个成键对和 2 个孤对电子。它的形状是？

本页是 VSEPR 的点电荷球面模型：把每个电子区域当作球面上的一个点，孤对取 1.2 倍“电荷”；它不含轨道、杂化、键长差异、多重键更“胖”以及原子大小的影响；N = 6 且孤对数 ≥ 2（如 XeF₄ 的方形平面）本页的简单模型算不准，因此第 2 步限制在 1 个孤对以内；真实分子是量子体系，成键角还受取代基影响。动画是梯度下降的教学演示，不是电子运动。
