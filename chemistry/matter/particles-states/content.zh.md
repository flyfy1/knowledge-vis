## 先看清一群粒子：固体里的粒子在原地抖 {#step0 h2=s0t h2part=1}

::: html step0-1
s0k: 第 0 步
s0e: 这一步要回答：放大到粒子尺度，一块「固体」里面的粒子在干什么？图上的小圆点就是**粒子**——构成物质、肉眼看不见的小单元，本页画成小圆点。它们排成整齐的队形、彼此挨着，这是**物态**（固、液、气三种存在状态的总称）里的「固态」。按 ▶ 播放：每个粒子都在自己的座位上**原地抖动**——画面是真模拟逐帧算出来的，不是静止贴图；暂停时画面停在当前帧。点画布上的一个粒子把它高亮跟踪：它离不开、也回不到自己的座位，只能在原地闹。结论：**固体 = 粒子排成队形、原地振动**；形状固定，是因为队形固定。

## 加热 = 闹得更凶：温度是粒子平均动能的读数 {#step1 h2=s1t h2part=1}

::: html step1-1
s1k: 第 1 步
s1e: 这一步要回答：加热改变了粒子的什么？拖动**温度滑杆**（本页唯一的热源）升温，看粒子本身：同一批固体粒子抖动的幅度与速率肉眼可见地变大，**动能**（动得越凶、动能越大，本页只作定性用语、不给公式）跟着变大。读数行里有**温度（示意）**：它不是从滑杆上抄来的，而是由粒子们的平均速率实算、再映射到 0–120 的示意刻度；下面的「平均速率」是同一批速度的另一读法——两个数同升同降，因为它们量的是同一件事。**温度**，在这里就是粒子平均闹腾程度的读数。把滑杆拖回去降温，抖动随之变弱，可逆。结论（只到定性）：**温度越高，粒子的平均动能越大**——适用条件：同一批粒子、还没发生物态变化时。

s1hint: 滑杆改的是模型的热运动强度（模型参数），不是换一张图——温度读数永远从粒子速度里算出来。
:::

## 熔化：队形散了，温度却停住一截 {#step2 h2=s2t h2part=1}

::: html step2-1
s2k: 第 2 步
s2e: 这一步要回答：继续加热，固体为什么会「化」？把滑杆继续往右推，越过熔点（示意读数约 33）：粒子抖到挣脱座位，开始贴身滑动，整齐队形散掉、间距略变大——这就是**熔化**，变成了液体（仍挤在一起、能流动、贴着容器底）。关键现象：熔化途中有一段「滑杆在动、温度读数停住」的平台段——加热的能量先花在拆队形上，读数行会点名「平台」。粒子一个没少，总数读数在位。结论：**熔化 = 队形瓦解、粒子能互相滑动**；熔化过程吸热而温度不变（现实中晶体熔化也是这条规律）。提醒一句：这个平台是模型按设定把加热分流到「拆队形」的定性呈现，终章「模型边界」里会明说。
s2hint: 把滑杆推过平台段之后，读数才恢复上涨——能量拆完队形，才轮到让粒子更快。
:::

## 蒸发：表面动得最凶的粒子逃走了 {#step3 h2=s3t h2part=1}

::: html step3-1
s3k: 第 3 步
s3e: 这一步要回答：一杯水不烧也会慢慢变干，粒子去哪了？现在粒子是液体（滑杆在中段）。盯住液面：动得最凶的少数粒子偶尔挣脱邻居的拉扯，飞到液面上方的空间里——这就是**蒸发**：只发生在表面、任何温度下都有。读数给「液里 / 空中 / 总数」三数，总数恒定不变。打开「盖上盖子」：逃逸的粒子撞盖返回，空中数涨到一定程度就涨停——逃逸与返回达成平衡（定性一瞥）。结论：水变干不是消失，是粒子搬到了空气里；**蒸发 = 表面动得最凶的粒子逃逸**。逃逸会带走能量：湿手被风一吹更凉，就是蒸发致冷。
lidLab: 盖上盖子
s3hint: 空中数涨停时，逃出去的和返回来的一样快——蒸发没停，是达成了平衡。
:::

## 沸腾成气，再降温走回来：同一批粒子的循环 {#step4 h2=s4t h2part=1}

::: html step4-1
s4k: 第 4 步
s4e: 这一步要回答：烧开时整壶水变气，和蒸发差在哪？降温又会怎样？把滑杆推过沸点（示意读数约 71）：粒子全员挣脱彼此的拉扯，满容器乱飞、间距拉大成气体——**沸腾**是全体事件，发生在液体各处；和第 3 步当场对照：蒸发只是表面少数粒子的逃逸。然后把滑杆拖回降温：同一批粒子慢下来，先聚回液体——这个过程叫**液化**（气体降温变回液体）；再继续降温，粒子排回队形、变回固体。一轮循环走完：固 → 液 → 气 → 液 → 固，粒子还是原来那一批，一个没多、一个没少。结论：**固、液、气是同一批粒子的三种队形**；物态变化可逆、粒子本身不变——这是物理变化与化学变化的分界（后续「[[molecules-atoms]]」页会展开，这里先埋一句）。
s4hint: 降温走完一轮再看总数：和出发时一模一样——变的只是队形与间距。
:::
