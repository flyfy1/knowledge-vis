同样是 C₄H₁₀，却是两种不同的分子

这一步要回答：分子式相同的分子一定是同一种物质吗？不一定。同分异构体是分子式相同、原子连接方式（骨架）不同的分子。烷烃（只含碳碳单键和碳氢键的链）的碳骨架就是一棵“树”：每个碳最多连 4 个键，剩下的键连氢。图中圆圈代表碳原子，圆圈里的数字是它连的氢原子数；线是碳碳键。读数从图自动数出 C 和 H 的个数，并与实测沸点对照：骨架不同，物理性质也不同。

先看 n = 4 的两个异构体：数一数读数里 C、H 个数是否相同、沸点是否相同；再把 n 调到 5、6，逐个翻看（第几个异构体），观察分支越多沸点怎样变化。

数一数：n 个碳到底能拼出几种骨架？

这一步要回答：碳原子数增加，异构体数增长得有多快？程序用“每次给一棵树的某个碳添一个新碳（该碳最多 4 个键）”的办法生成所有骨架，再用树的规范形式（把树从中心起逐层描述，同构的树描述相同）去掉重复，剩下的就是互不相同的骨架。画布里每个小图是一种骨架。n = 1…8 时个数是 1、1、1、2、3、5、9、18：增长越来越快。

把 n 从 2 拉到 8：数小图个数，并核对读数里的数目；看 n = 4、5、6 时个数怎样增加，再估计 n = 9、10 大约会有多少。

画法不同，还是真的不同？用“规范形式”来裁判

这一步要回答：两张画得不一样的图，是同一个分子吗？同一个分子可以画成不同的样子（旋转、翻转、换一个碳当起点），不同的分子也可能看起来很像。判定方法：把两棵树都化成规范形式（不依赖画法的描述），相同就是同一个分子。页面随机给你一对图，你判断是“同一个分子”还是“不同的分子”，再核对规范形式的结果。

先自己数一数每张图里最长的碳链和分支位置，再判断；答完看反馈里两张图的“最长碳链长度”和规范形式是否一致；多做几题，注意“看起来不一样”其实相同的情形。

官能团异构：原子种类更多，连法差别更大

这一步要回答：加入氧原子后，同一分子式能有几种拼法？图中圆圈是碳（灰）和氧（红），数字是连的氢数；氧最多连 2 个键。C₃H₈O 有 3 种：1-丙醇（OH 在链端）、2-丙醇（OH 在中间碳上）、甲乙醚（氧夹在两个碳之间，是醚）。C₂H₆O 有 2 种：乙醇和二甲醚。分子式由图自动数出；沸点差别很大，因为含 O–H 的醇分子之间能形成氢键，醚不能。

依次点 1-丙醇、2-丙醇、甲乙醚：确认读数里的分子式相同、沸点不同；再点乙醇和二甲醚，比较沸点差（相差上百度）。

顺反异构：绕单键能转，绕双键转不动

这一步要回答：为什么 2-丁烯有顺、反两种，而丁烷没有？看中间那个碳碳键：两端各连一个甲基。绕单键扭转时，能量只有小小的起伏（本页取最高 12 kJ/mol），室温热运动就足以翻越，所以各种扭转形态是同一种分子；绕双键扭转要拆开其中一半的键，能量壁垒高得多（本页取 265 kJ/mol），室温下几乎不能转，顺式（θ = 0°，两个甲基同侧）和反式（θ = 180°，异侧）因此是能分开的两种物质。能垒越过的相对机会按 e^(−ΔE/RT) 估算（R = 8.314×10⁻³ kJ/(mol·K)，T = 298 K，同活化能页）。

先选单键，把 θ 从 0° 拉到 180°：能量只升到一个小丘；再选双键，同样拉：能量冲到几百 kJ/mol；对照读数里的“相对机会” e^(−ΔE/RT)。

回顾与自测

回顾：① 同分异构体：分子式相同、连接方式不同，物理性质也不同；② 烷烃骨架是树，n = 4、5、6、7、8 时有 2、3、5、9、18 种；③ 判断两张图是否同一个分子要看规范形式，不看画得像不像；④ 含氧的官能团异构（醇与醚）沸点差别很大；⑤ 双键不能自由转动，所以有顺反异构，单键可以转，所以没有。

C₅H₁₂ 一共有几种不同的碳骨架（同分异构体）？

本页的异构体指碳骨架（构造异构），只含饱和链烷烃和第 3 步的醇与醚；不涉及环状结构、含 C=C 的结构异构、手性（镜像异构）和构象能量的细节；沸点为常见手册值，仅作对照；第 4 步的扭转能是教学函数：单键取 (12/2)(1 − cos3θ)，双键取 (265/2)(1 − cos2θ)；树的画法是自动布局，可能有重叠或看起来很奇怪，但结构（规范形式）是严格计算的。
