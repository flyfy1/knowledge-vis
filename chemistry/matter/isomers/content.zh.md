## 画法不同，还是真的不同？用“规范形式”来裁判 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 是同一个吗
:::

::: html step2-1
:::

这一步要回答：两张画得不一样的图，是同一个分子吗？同一个分子可以画成不同的样子（旋转、翻转、换一个碳当起点），不同的分子也可能看起来很像。判定方法：把两棵树都化成**规范形式**（不依赖画法的描述），相同就是同一个分子。页面随机给你一对图，你判断是“同一个分子”还是“不同的分子”，再核对规范形式的结果。 {#s2e .explain}

## 官能团异构：原子种类更多，连法差别更大 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 官能团异构
:::

::: html step3-1
:::

这一步要回答：加入氧原子后，同一分子式能有几种拼法？图中圆圈是碳（灰）和氧（红），数字是连的氢数；氧最多连 2 个键。C₃H₈O 有 3 种：1-丙醇（OH 在链端）、2-丙醇（OH 在中间碳上）、甲乙醚（氧夹在两个碳之间，是醚）。C₂H₆O 有 2 种：乙醇和二甲醚。分子式由图自动数出；沸点差别很大，因为含 O–H 的醇分子之间能形成氢键，醚不能。 {#s3e .explain}

## 顺反异构：绕单键能转，绕双键转不动 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 顺反异构
:::

::: html step4-1
:::

这一步要回答：为什么 2-丁烯有顺、反两种，而丁烷没有？看中间那个碳碳键：两端各连一个甲基。绕**单键**扭转时，能量只有小小的起伏（本页取最高 12 kJ/mol），室温热运动就足以翻越，所以各种扭转形态是同一种分子；绕**双键**扭转要拆开其中一半的键，能量壁垒高得多（本页取 265 kJ/mol），室温下几乎不能转，顺式（θ = 0°，两个甲基同侧）和反式（θ = 180°，异侧）因此是能分开的两种物质。能垒越过的相对机会按 e^(−ΔE/RT) 估算（R = 8.314×10⁻³ kJ/(mol·K)，T = 298 K，同活化能页）。 {#s4e .explain}

::: html step4-2
s4o: 先选单键，把 θ 从 0° 拉到 180°：能量只升到一个小丘；再选双键，同样拉：能量冲到几百 kJ/mol；对照读数里的“相对机会” e^(−ΔE/RT)。
lTw: 绕中间键扭转的角度 θ（°）
bSingle: 单键（如丁烷中间的 C–C）
bDouble: 双键（如 2-丁烯中间的 C=C）
:::

::: strings
r4: {kind}：θ = {th}°，扭转能 {e} kJ/mol；最高能垒 {bar} kJ/mol，室温下相对越垒机会 e^(−ΔE/RT) = {p}；{res}。
kSingle: 单键
kDouble: 双键
resFree: 能自由转动，不同扭转形态是同一种分子
resLocked: 几乎转不动，顺式与反式是两种可分离的分子
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 同分异构体：分子式相同、连接方式不同，物理性质也不同；② 烷烃骨架是树，n = 4、5、6、7、8 时有 2、3、5、9、18 种；③ 判断两张图是否同一个分子要看规范形式，不看画得像不像；④ 含氧的官能团异构（醇与醚）沸点差别很大；⑤ 双键不能自由转动，所以有顺反异构，单键可以转，所以没有。 {#s5e .explain}

::: html step5-2
qq: C₅H₁₂ 一共有几种不同的碳骨架（同分异构体）？
qo0: 2 种
qo1: 3 种
qo2: 5 种
s5m: 本页的异构体指碳骨架（构造异构），只含饱和链烷烃和第 3 步的醇与醚；不涉及环状结构、含 C=C 的结构异构、手性（镜像异构）和构象能量的细节；沸点为常见手册值，仅作对照；第 4 步的扭转能是教学函数：单键取 (12/2)(1 − cos3θ)，双键取 (265/2)(1 − cos2θ)；树的画法是自动布局，可能有重叠或看起来很奇怪，但结构（规范形式）是严格计算的。

lk1: 活化能页：能垒与 e^(−ΔE/RT)，同样的越垒几率估算
lk2: 粒子与物态页：沸点高低与分子间作用力
:::
