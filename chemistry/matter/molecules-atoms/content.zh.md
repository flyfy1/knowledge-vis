## 分子式 H₂O 里的小数字是什么意思？ {#step0 h2=s0t}

::: strings
nav0: 0 读分子式
:::

第 0 步 · 读分子式 {#s0k .step-kicker i18n=text}

这一步要回答：H₂O 里的小数字 2 说的是什么？**原子**是化学变化里不能再分的最小粒子；**分子**是几个原子连成的一个小团，是保持物质化学性质的一个单位。分子式里元素符号右下角的小数字，是**这一个分子里**该原子的个数。选一种分子，再拖「分子个数」：分子式前面的系数表示有几个这样的分子。 {#s0e .explain}

::: html step0-1
s0stage: 球棍图：不同颜色的球是不同元素的原子，棍表示它们连在一起
s0canvas: 分子的球棍示意图：所选分子重复所选个数，每个原子带颜色
s0mol: 选一种分子
s0n: 分子个数（系数）
:::

结论：小数字数的是一个分子里的原子，系数数的是分子个数，二者别混。条件：图中的键角和球大小是示意，不是真实尺寸。 {#s0result .readout i18n=text}

::: strings
s0ro: {n} 个 {name}：每个分子里的原子 {per}；合计原子 {tot}。
:::

## 水烧成水蒸气，水分子变了吗？ {#step1 h2=s1t}

::: strings
nav1: 1 水烧开
:::

第 1 步 · 水烧开 {#s1k .step-kicker i18n=text}

这一步要回答：把水加热到沸腾变成水蒸气，是分子本身变了，还是分子之间的距离变了？拖温度滑杆，看 12 个水分子（每个都是一个氧原子连两个氢原子）怎么运动。温度越高分子抖得越凶；到 100 ℃ 附近分子挣脱彼此、散开成气体。数一数每个小团还是不是 H₂O。 {#s1e .explain}

::: html step1-1
s1stage: 12 个水分子的示意图（粒子运动是示意，不是真实速度）：每个小团由一个氧原子和两个氢原子组成
s1canvas: 12 个水分子：低温时挤在一起抖动，到 100 ℃ 附近散开成气体，每个分子都还是 H₂O
s1t2: 温度
:::

结论：物态变化是分子间距离和运动方式变了，分子本身没变，仍是 H₂O（物理变化）。条件：常压，水沸点 100 ℃；本页粒子排布是示意。 {#s1result .readout i18n=text}

::: strings
s1ro: {T} ℃：{state}。分子 {n} 个，每个仍是 H₂O；原子合计 {atoms}。
s1liq: 液态：分子挨着、只在原处抖动
s1boil: 沸腾附近：分子正在挣脱，散开
s1gas: 气态：分子彼此远离、自由飞行
:::

## 水通电以后，水分子去了哪里？ {#step2 h2=s2t}

::: strings
nav2: 2 水通电
:::

第 2 步 · 水通电 {#s2k .step-kicker i18n=text}

这一步要回答：给水通电，水分子会怎样、产生了什么？电流把水分子拆开，氢、氧原子重新两两结合：2 H₂O → 2 H₂ + O₂。设定水分子个数，按「通电」，一次次反应后水变少、氢分子和氧分子变多，看氢分子数是氧分子的几倍。 {#s2e .explain}

::: html step2-1
s2stage: 电解槽示意：左边收集氢气，右边收集氧气；每次反应拆开 2 个水分子
s2canvas: 电解槽示意图：水分子逐个被拆成氢分子和氧分子，氢分子数是氧分子数的 2 倍
s2n: 水分子起始个数
s2run: 通电，开始反应
s2reset: 重新装水
:::

结论：化学变化中分子被拆开、原子重新结合成新分子（新物质）。H₂ 与 O₂ 的个数比 2 : 1。条件：理想反应，100% 完全分解，不计电极与损耗。 {#s2result .readout i18n=text}

::: strings
s2ro: 已发生 {e} / {max} 次反应：H₂O {w} 个，H₂ {h} 个，O₂ {o} 个；H₂ ÷ O₂ = {ratio}；原子总数 H {ah}、O {ao}。
s2zero: 还没通电；水分子 {w} 个。
:::

## 怎么判断一个变化是物理变化还是化学变化？ {#step3 h2=s3t}

::: strings
nav3: 3 物理还是化学
:::

第 3 步 · 物理还是化学 {#s3k .step-kicker i18n=text}

这一步要回答：看一个变化，凭什么说有没有生成新物质？看反应前后的**分子种类**有没有变：分子种类不变（只是位置、间距、混合）是**物理变化**；出现了新种类的分子是**化学变化**。选一个变化，先猜，再看判定。 {#s3e .explain}

::: html step3-1
s3stage: 反应前（左）与反应后（右）的分子清单：每行是一种分子及个数
s3canvas: 变化前后的分子种类清单对比：种类相同是物理变化，出现新种类是化学变化
s3sc: 选一个变化
s3phys: 我猜：物理变化
s3chem: 我猜：化学变化
:::

结论：判据是分子种类（有没有新物质）。条件：本页只列了分子；离子化合物与金属的变化判据需另讲。 {#s3result .readout i18n=text}

## 分子重组时，原子会多出来或少掉吗？ {#step4 h2=s4t}

::: strings
nav4: 4 原子账本
:::

第 4 步 · 原子账本 {#s4k .step-kicker i18n=text}

这一步要回答：甲烷燃烧 CH₄ + 2 O₂ → CO₂ + 2 H₂O 时，分子种类和个数都在变，原子总数变吗？拖「已反应次数」，上排柱子是分子（会变），下排柱子是各元素原子总数（C、H、O）。 {#s4e .explain}

::: html step4-1
s4stage: 上：各种分子的个数；下：各元素的原子总数（始终一条线）
s4canvas: 甲烷燃烧的两组柱状图：分子个数随反应改变，原子总数不变
s4reset: 回到反应前
:::

结论：分子变，原子账不变。条件：理想反应、4 个甲烷分子起步、氧足量；不含不完全燃烧。 {#s4result .readout i18n=text}

:::
