## 把一个原子放大：中间一个核，外面一大片空 {#step0 h2=s0t h2part=1}

## 质子数决定它是谁 {#step1 h2=s1t h2part=1}

::: html step1-1
s1k: 第 1 步 · 身份
s1e: 这一步要回答：碳和氧差在哪，是什么让它「是」碳？核里有两种粒子：**质子**（带正电的粒子）和**中子**（不带电、只添重量的粒子）。数一数质子有几个，这个数叫**核电荷数**（每个质子带一份正电荷，核的总正电正好等于质子数）。用下面的 − / + 按钮给核增减质子（一次一个），看元素名怎么变。
s1bridge: 先按一次 +1：只多一个质子，元素身份就立刻换掉；中子只会改变质量，不会改变它是谁。
zLab: 质子数 Z（核电荷数）
s1hint: 本页只排到钙：Z 钳在 1…20。名字与符号是查表给的数据，但身份判定不靠查表——Z 是几号，它就是几号元素。
:::

::: strings
s1ro: 质子数 Z = {z} → 它是 <b>{name}</b>（符号 {sym}）。中子数 N = {n}（这是该元素最常见的中子数），质量数 A = Z + N = {a}（质量数 = 质子数 + 中子数，就是核里粒子的总数）。电子数先跟质子数一样多：{e} 个（中性原子，第 4 步再让它变）。中子只改变质量数 A，不改变它是谁——身份只认质子数。
:::

s2bridge: 先选 Na 或 Cl，再按一次电子 + / −：电子会先填里层，外层排布才跟着改变。

## 最外层决定活泼不活泼 {#step3 h2=s3t h2part=1}

::: html step3-1
s3k: 第 3 步 · 脾气
s3e: 这一步要回答：排布里哪一位说了算，为什么氖「高冷」、钠「一点就着」？点对照组的原子逐个看。读数只报三件事：**最外层电子数**（排布式里最后一个数）、这一层满没满、还差几个。图上最外层整层会高亮。用词都是「容易 / 不容易」：这是按最外层满不满做的定性判断，不是「一定会反应」的断言。
s3bridge: 先比较最外层是否填满：填满时更稳定；没填满时，离填满还差几个会提示它更容易得失电子。
cmpLab: 对照组：
:::

::: strings
s3ro: {sym}（{name}）：排布 {cfg}。最外层 {outer} 个，本层容量 {cap}，{full}。判定：<b>{verdict}</b>
fullYes: 已填满
fullNo: 还差 {gap} 个才满
vStable: 稳定——最外层已满，不容易得到电子、也不容易失去电子
vLose: 容易失去电子——最外层只有 {outer} 个，甩掉它们比凑满 {cap} 个近得多
vGain: 容易得到电子——只差 {gap} 个就满了，抓几个比甩掉 {outer} 个近
:::

## 电子得失之后：离子 {#step4 h2=s4t h2part=1}

::: html step4-1
s4k: 第 4 步 · 离子
s4e: 这一步要回答：原子失去或得到电子，会变成什么？先选原子，再拖电子数滑杆。总电荷由一个式子定死：**电荷 = 质子数 − 电子数**（每个质子算 +1、每个电子算 −1）。带了净电荷的原子叫**离子**：带正电的叫阳离子、带负电的叫阴离子。看画布上排布和符号右上角的电荷怎么一起变。
s4bridge: 按 He、Ne、Na、Cl 的顺序比较：最外层满时稳定；不满时，离满得越近，得失电子的方向越容易看懂。
preset4Lab: 一步到位看离子：
:::

::: strings
s4ro: {sym}：质子 {z} 个，电子 {e} 个，排布 {cfg}（离子的排布 = 得失电子之后，剩下的电子重新分层）。电荷 = {z} − {e} = <b>{q}</b>。{kind}
kindNeutral: 电荷为 0：还是中性原子，不叫离子。
kindCation: 带正电：这是阳离子，写成 {ion}。
kindAnion: 带负电：这是阴离子，写成 {ion}。
kindBare: 电子全失光了：只剩裸核，质子还在。
s4explore: 探索区：电子多到第四层超过 8 个，已经超出初中 2 / 8 / 8 简化规则能表达的范围。这里的排布式只为数清电子、算对电荷，别把它当作真实分层——真实排布更细，高中会展开。
:::

## 一个原子的身份证与脾气，都写在数里 {#step6 h2=s6t h2part=1}

::: html step6-1
s6k: 第 6 步 · 收束
s6e: 这页把一个原子拆成了三个数：**质子数 Z** 定身份、**电子数 e** 定排布与电荷、**最外层电子数**定脾气。三个数全部由页面同一组纯函数当场算出——画布、读数、自测用的是同一套账，你在哪一步改数，别处的结论都跟着重算。原子内部的结构先到这里；一群原子凑在一起会发生什么（结合成分子、反应中谁得谁失），是后面的页面要讲的。
card1t: 模型边界一：尺度
card1b: 核与电子的尺寸是放大示意：真实核直径只有原子直径的约十万分之一，本页画布上放大了上万倍（第 0 步的实测口径）。
card2t: 模型边界二：层圈不是跑道
card2b: 同心圈只是电子的住址分区，是示意画法：电子实际不是沿着圈跑的。真实电子的运动图景，要到以后更深的模型里才展开。
card3t: 模型边界三：简化排布
card3b: 2 / 8 / 8 是初中简化排布规则，本页也只算 Z = 1…20；更重的元素、更细的分层不在本页口径内。中子只按最常见同位素取定值，只影响质量数。
linkParticles: → 回粒子页第 1 步：一群粒子的温度——温度是粒子平均动能的读数（粒子页讲「一群」，本页讲「一个」）
s6next: 后续页面（先在此占个位，暂不挂链）：原子怎么结合成分子与化学键、化学反应里质量为什么守恒——都会用到本页的三个数。
:::
