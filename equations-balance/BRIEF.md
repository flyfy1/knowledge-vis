# BRIEF：方程天平——两边同做一件事（equations-balance）· 小学高段—初中衔接数学

## 定位
- slug `equations-balance`，category math，stage primary。受众：小学高年级 + 初一预备 + 家长。排在 negative-numbers（带符号的量）与 fractions（分数是一个数）之后、linear-functions（方程长成直线）之前：前两页给了「数」的地基，本页第一次把等号用起来，后一页再让方程动起来。
- 核心直觉一句话：**方程就是一架平衡的天平——等号两边一样重；对两边同时做相同的事（加、减、乘、除同一个量），天平不倒，x 的值就藏不住了。**
- 已知：整数加减、negative-numbers 的带符号位置感、fractions 的「分数是一个数」。唯一新问题：一个式子里有个不知道的数，怎么有章法地把它单独逼出来？

## 诚实口径红线（全页适用，评审逐条对账）
1. **同源实算**：全页只有一个状态真源（见「数据与判定口径」），两盘重量、平衡与否、倾斜方向、读数、算式回显全部由纯函数从该状态算出，禁止第二套缓存口径、禁止按字符串判定。
2. **平衡判定用精确等式**：本页所有量都是整数，`isBalanced` 用严格相等（容差 = 0，不许写 epsilon 含糊过去）。同除只允许整除的除数（由 `availableDivisors` 算出），不许出现小数中间状态。
3. **倾斜角是示意量**：横梁倾斜角由重量差线性映射并钳幅，只是画得醒目，**文案必须明示**「倾斜角度是示意，画得夸张了；是否平衡只看两边重量是否相等」（中英双份，放在 step0 图下与 step1 读数旁各一次）。重量差是实算量、倾斜角是示意量，两者不许混着说。
4. **未知数的值不许提前泄漏**：揭晓前，x 的值不得出现在任何可见文本、读数、DOM 属性（data-*、title 等）里；盒子所在盘的**总重量读数**在揭晓前不显示（只显示组成：「1 个盒子 + 3 个单位」）。揭晓区与自测解析一律**门控渲染**（答对/达标前 DOM 里不存在，不是 hidden 遮盖）。构建自查须含泄漏审计（见验收清单）。
5. **不许出现「移项变号」口诀**：全页（含自测选项与解析）不以法则形式教授或使用「移项」；唯一允许的方法语言是「对两边同时做相同的事」。自测的错误选项也不许把口诀写成看似可用的方法（用「只动一边」类错误代替）。

## 步骤（每步含五必填项 + 现象/读数来源/过关口径；步 id 0 起：step0–step6）

### step0 认识天平：一盒不知道多重的东西
- **已知**：整数的加法与比较大小；生活经验：跷跷板、称东西。
- **唯一问题**：一盒密封的东西（不许打开）到底多重，不用秤、只用天平和砝码能不能知道？
- **输入与求量**：输入 = 左盘一只密封盒 + 一堆 1 单位砝码；求量 = 盒子的重量（整数单位）。
- **学习者看到什么现象**：一架天平的大图，图下逐个标明部件：左盘、右盘、横梁、中央指针。盒子放左盘，横梁明显倾向左边（指针偏离中线）；往右盘逐个加砝码，横梁一格一格回正，加到某个数时指针正对中线、横梁水平——平衡了。
- **动手做什么**：点「＋ 放一个砝码 / － 取走一个」逐个增减右盘砝码，自己把天平调平（可反复试）。平衡后点「换一盒」（盒子在一组预置值 [6, 4, 9] 间轮换，画面上盒子外观不变），再称一次。
- **读数从哪个纯函数来**：右盘砝码数 = 状态里的单位计数（实数）；平衡与否 = `isBalanced(state, xv)`；倾斜方向 = `weigh` 两盘比较。**平衡前读数只许说哪边重**（「左边还重些」/「右边反超了」），不许说差多少——差值就是盒重减砝码数，说了即泄漏。平衡那一刻才给出结论读数：「右盘 N 个单位，天平平了 —— 这盒东西就重 N 个单位。」
- **过关/判定口径**：无硬门槛；观察清单自检：亲手调平 ≥1 次（清单显示 1/1）。调平判定 = `isBalanced` 严格相等。
- **结论与适用条件**：每盒东西都有一个确定的重量，只是没称之前不知道；数学里把这种「暂时不知道、但确定有」的量用字母记，本页用 **x**。适用条件：本页盒子重量都是整数个单位。
- **新术语首现**：天平、盘、砝码（单位）、平衡、未知数 x —— 见术语表。

### step1 两边同加同减：天平为什么不倒
- **已知**：step0 已称出盒重并给它起名 x；平衡 = 两边一样重。
- **唯一问题**：天平已经平了，我往盘子里再放东西，怎么放它才不倒？
- **输入与求量**：输入 = 初始平衡状态（左盘：1 盒 + 2 单位；右盘：盒重对应的单位数，由状态实算呈现为砝码堆，盒重取 step0 的 6，即右盘 8 单位——式子回显 `x + 2 = 8`）；求量 = 哪些放法保持平衡、哪些不保持。
- **学习者看到什么现象**：天平居中、指针归零。每次操作后横梁或保持水平、或明显倾斜（倾斜角示意，图旁有明示文案），读数行同步给出两盘**组成**与平衡结论。
- **动手做什么**：四个操作钮：「两边各加 1 个单位」「两边各加 1 个盒子」「两边各取走 1 个单位」（两边都不足时该钮禁用并给原因）、「只给左盘加 1 个单位」（故意做错的反例钮，标签写明「只加左边试试」）。可反复操作，有「回到初始平衡」重置钮（清操作历史、清读数、停动画）。
- **读数从哪个纯函数来**：每次操作经 `applyOp(state, op)` 产生新状态；组成串由 `compositionString(state)` 渲染；式子回显由 `exprString(state)` 渲染（如 `x + 5 = 11`）；平衡结论由 `isBalanced` 实算。盒重 xv 本步已知但**总重读数仍不显示**（习惯口径与 step3 一致：看组成，不看总重）。
- **过关/判定口径**：观察清单 3 项（页面跟踪、显示 k/3）：试过「两边同加」✓、试过「两边同减」✓、试过「只加一边并看见它倒」✓。清单只是自检提示，不拦路。
- **结论与适用条件**：对天平两边同时加上（或取走）**同样多的**东西，平衡不变；只动一边，平衡就破坏。适用：加减的量两边必须真的一样多（同为单位数或同为盒子数）。
- **新术语首现**：等式（equation 的白话引入：带等号、两边相等的式子）、同加同减（操作名，非术语但需就近一句话口径）。

### step2 两边同乘同除：把两边放大、缩小
- **已知**：step1 的「同加同减不倒」；乘法是连加、除法是平分（area-model / division-remainder 的旧知）。
- **唯一问题**：把两盘的东西同时翻倍、或同时只留一份，天平还平吗？
- **输入与求量**：输入 = 初始平衡状态（左盘：1 盒 + 1 单位，右盘：4 单位，即 `x + 1 = 4`，xv=3）；求量 = 同乘 / 同除后是否仍平衡，以及同除在什么时候做不到。
- **学习者看到什么现象**：点「两边同时 ×2」：两盘的盒子与砝码当场复制一份（动画呈现复制过程、堆叠变高），指针仍归零。连点到 ×3。再点「两边同时 ÷2 / ÷3」（只出现 `availableDivisors` 给出的除数钮）：每盘的东西被分成 k 等份、只留一份（动画呈现分组与留一份），仍平衡。若当前状态无 >1 的公约数，除法钮整组禁用并读数说明「现在两边没办法再同时整除」。「只乘左边 ×2」反例钮照例让天平倒给学习者看。
- **动手做什么**：同乘 2、同乘 3、同除（可用除数钮）、只乘一边（反例）、重置。
- **读数从哪个纯函数来**：`applyOp` 的乘/除分支；除数集合 = `availableDivisors(state)`（a、b、c、d 四个计数之 gcd 的 >1 约数，0 计数不参与 gcd）；组成串与式子回显同 step1（`2x + 2 = 8` 等）；平衡结论 `isBalanced`。内容上限口径：任一计数将超过上限（盒子 ≤6、单位 ≤24）时同乘钮禁用并说明，防止画布堆爆。
- **过关/判定口径**：观察清单 3 项：同乘 ✓、同除 ✓、只乘一边看到倾斜 ✓。
- **结论与适用条件**：两边同时乘以同一个**非零**数、或同时除以一个**能整除**的数，平衡不变。适用条件写死：乘的数不能是 0（两边都变 0 虽然也平，但把信息全抹了，本页不提供 ×0）；除法必须整除，本页不切半个砝码。
- **新术语首现**：同乘同除、整除。

### step3 一步方程：把 x 单独留在左边
- **已知**：step1/2 的两条结论（同加同减、同乘同除都不倒）。
- **唯一问题**：`x + 3 = 7` —— 怎么操作，才能让左盘只剩盒子一个、把 x 的值逼出来？
- **输入与求量**：输入 = 初始状态（左盘：1 盒 + 3 单位；右盘：7 单位，xv=4）；求量 = x 的值。
- **学习者看到什么现象**：天平初始平衡。学习者每做一次「两边同时」的操作，两盘同步变化、式子回显同步改写（如同减 3 后式子变 `x = 4` 的组成形态：左盘只剩 1 盒、右盘 4 单位）。一旦左盘只剩单独一个盒子，天平上方亮起「左盘只剩 x 了 —— 可以开盒了」的提示，「开盒揭晓」钮由禁用变可用。
- **动手做什么**：操作面板：同加（步进器选 1–9）/ 同减（步进器选 1–9，两边不足自动禁用并说明）/ 同乘 2·3 / 同除（可用除数）/ 重置本步。可走错路（如先同加 2），天平照样平、只是没到目标，随时可继续调整或重置。
- **读数从哪个纯函数来**：状态与回显同前；目标判定 = `isIsolated(state)`（a=1 且 b=0 且 c=0）；揭晓后验算由 `evalSide` 实算：把 x=4 代回原式，左 = 4 + 3 = 7 = 右，页面逐项写出验算式。揭晓前验算区与盒重**门控不渲染**。
- **过关/判定口径**：达标 = `isIsolated` 为真且点过揭晓；揭晓后显示「x = 4」与验算式，并标注「这是你自己操作出来的，不是猜的」。未达标时揭晓钮禁用、验算区 DOM 不存在。
- **结论与适用条件**：解方程 = 用「两边同做一件事」一步步把 x 单独留在一边，另一边剩下的数就是 x 的值；最后**代回验算**确认。本页方程都是一步可解、整数答案。
- **新术语首现**：解方程（solve）、方程的解（solution）、代回验算（check by substituting）。

### step4 两步方程：先减后除，顺序自己定
- **已知**：step3 已完整解过一个一步方程并验算。
- **唯一问题**：盒子有 2 个、还混着砝码（`2x + 3 = 11`），一次操作不够，该先做哪件、后做哪件？
- **输入与求量**：输入 = 题库三题（固定、由 `solveLinear` 预先断言有整数解）：`2x + 3 = 11`（x=4）、`3x + 6 = 15`（x=3）、`4x + 1 = 9`（x=2）；求量 = 每题的 x。
- **学习者看到什么现象**：与 step3 同一套天平与操作面板，但初始左盘是多个盒子 + 单位。学习者可先同减再同除（如 2x+3：−3 → 2x=8 → ÷2 → x=4），也可先同除（3x+6 那题 ÷3 → x+2=5 → −2 → x=3）——**两条路都通**，页面不规定顺序，只认最终把 x 单独留下。每步操作后式子回显实时改写，操作历史以小字轨迹保留（第 k 步：两边同减 3），让「我做了什么」看得见（交互可理解性：呈现累积）。
- **动手做什么**：全套操作钮（同 step3）+「换一题」钮 + 重置。**换题口径（状态一致性红线）**：换题 = 整步状态全量重置（新题的初始状态、清空操作历史、清空读数与揭晓区），不许有上一题的判定/读数残留；解题中途换题不弹确认（本页无不可逆数据），但必须清干净。
- **读数从哪个纯函数来**：同 step3；当前题的答案由 `solveLinear(a,b,c,d)` 实算校验（构建期断言三题均为整数解），页面运行期不显示答案，只用它做构建自查与自测对账。达标判定仍是 `isIsolated` + 揭晓后 `evalSide` 验算。
- **过关/判定口径**：每题独立达标（清单显示已解 k/3 题）；达标口径同 step3。
- **结论与适用条件**：两步方程就是把「两边同做一件事」用两次；先减后除、先除后减都行，认准目标「让 x 单独留在一边」。本页题目限：系数与常数均为正整数、答案为正整数；**答案是负数或分数的方程不在本页**（终章给出深链：负数见 negative-numbers、分数也是数见 fractions）。
- **新术语首现**：两步方程、系数（盒子前面的个数，如 2x 的 2，本步首现即给白话）。

### step5 自测（答对才揭晓，解析回扣对应步）
三题，题面由状态拼装、答案由 `solveLinear` 实算、判定按数值相等（不得写死判定字符串、不得按选项位置判定）；选项顺序固定，答对锁定该题并**门控渲染**解析，答错只给回指对应步的提示、不给答案。答题后回头改前面各步参数，不冲已锁定判定（状态一致性红线）。
1. **一步方程**（回扣 step3）：小天平图 + 式子 `x + 5 = 12`，求 x。四选一（7 / 17 / 5 / 12）。解析门控：答对后写出完整两步：「两边同时减 5 → x = 7；代回：7 + 5 = 12 ✓」——操作串由题面状态经 `applyOp` 演示生成或按同口径文案渲染，数值全部实算。
2. **两步方程**（回扣 step4）：`2x + 4 = 14`，求 x。四选一（5 / 9 / 7 / 3）。解析：「两边同减 4 → 2x = 10；两边同除以 2 → x = 5；代回：2×5 + 4 = 14 ✓」。
3. **方法判断**（回扣 step1/3）：「要解 `x + 6 = 10`，下面哪一步是对的？」四选一：两边同时减去 6 ✓ / 只把左边的 6 拿走 / 只把右边的 6 拿走 / 两边同时加上 6。选错项的反馈按项给：只动一边的 → 「天平会倒：只动一边，两边就不一样重了（回 step1 看）」；同加 6 的 → 「方向反了：加 6 会让左边的 6 变得更多，离只剩 x 更远（回 step3 看）」。**本步不出现「移项」字样**（红线 5）。

### step6 终章：等号是一架天平
- 回扣收束：一句话结论「解方程没有什么口诀：守住一架天平——不管做什么，对两边同时做相同的事，直到 x 单独留在一边。」配一张小图：`2x + 3 = 11` 从原式到 x=4 的三帧组成变化（静态回放 step4 的轨迹要点）。
- 互链区（3 条，带步锚，链接文字写明去学什么；锚点已逐个实核）：
  - `../negative-numbers/#step3`「带负号的数怎么加减：沿数轴走 →」——以后会遇到答案是负数的方程（如 x + 9 = 4），带符号的量怎么算在那页（锚点已核：CONCEPT-MAP 第 99 行 negative-numbers#step3「撤回向左走」，该步讲沿轴加减）。
  - `../fractions/#step1`「分数也是一个数 →」——系数是分数的方程（如 ½x = 3）里，½ 不是两个数、是一个数，解法仍是两边同做一件事（锚点已核：CONCEPT-MAP 第 68 行 fractions#step1「分数 = 数轴上的一个数」）。
  - `../linear-functions/#step2`「方程会长成一条直线 →」——等号两边都带 x 时（如 x + 2 = 2x − 1），先在那页看式子怎样长成直线 y=kx+b；两条线相遇就是方程的解，在该页紧接着的第 3 步（锚点已核：CONCEPT-MAP 第 80 行 linear-functions#step2「一次函数：斜率与截距」，该步 y=kx+b 实时拼装；相遇在该页 step3，落点步为其前置步）。
- 正文内链（规则 12，首提处）：step4 结论里首提「答案是负数/分数的方程」处即给前两条深链（不等到终章才给）；step6 回指 negative-numbers 时用 #step3 同一锚点。

## 新术语首现表（规则 11：每步首现处就近给白话；后续步再出现须再带一句短口径）
| 术语 | 首现步 | 就近白话口径（中/英要点） |
|---|---|---|
| 天平 / 平衡 balance | step0 | 两边一样重时横梁水平、指针指中；一样重就叫平衡 |
| 砝码（单位） unit weight | step0 | 本页最小的重量块，每块记 1 个单位，不用克、千克 |
| 未知数 x unknown | step0 | 暂时不知道、但确定有的那个数，先用字母 x 占位 |
| 等式 equation | step1 | 带等号、左右两边相等的式子；等号就是天平的指针归零 |
| 两边同时（同加/同减） | step1 | 对左右两盘做一模一样的操作：同加同减、同乘同除，总称「两边同做一件事」 |
| 整除 divide evenly | step2 | 除完没有剩余、不出现半块；除不尽的本页不做 |
| 系数 coefficient | step4 | 盒子前面的个数：2x 就是 2 个盒子，2 叫系数 |
| 解方程 / 方程的解 solve / solution | step3 | 把 x 单独逼出来的过程叫解方程；逼出来的那个数叫方程的解 |

## 数据与判定口径（构建者必须照此实现，评审按此对账）
- **状态模型（唯一真源）**：每步一个状态对象 `{ a, b, c, d, xv, revealed }`，含义：左盘 = a 个盒子 + b 个单位，右盘 = c 个盒子 + d 个单位；xv = 每盒重量（整数）；revealed = 是否已揭晓。式子即 `a·x + b = c·x + d`（渲染时省略系数 1 与 0 项，由 `exprString` 统一拼装）。
- **纯函数清单（实现与自查共用同一份，不许另写一份判定）**：
  - `weigh(state, xv)` → `{L: a*xv + b, R: c*xv + d}`（整数运算）。
  - `isBalanced(state, xv)` → `weigh().L === weigh().R`（严格相等，容差 0）。
  - `tiltDeg(state, xv)` → `clamp((L − R) * 2, −14°, +14°)`，**仅供渲染横梁角度，是示意量**；任何文案/读数不许把角度当作平衡证据。
  - `compositionString(state)` → 如「左盘：1 个盒子 + 3 个单位 · 右盘：7 个单位」（双语经字典），揭晓前唯一的盘面读数形态。
  - `exprString(state)` → 如 `x + 3 = 7` / `2x = 8`（系数 1 省略、0 项省略、两边都空的非法状态不出现）。
  - `applyOp(state, op)` → 新状态；op ∈ {addUnits(n), subUnits(n), addBoxes(n), subBoxes(n), mul(k), div(k)}，均作用于两边。合法性：sub 类要求两边对应计数 ≥ n，否则返回原状态并由 UI 给禁用原因；mul 要求乘后计数不超上限（盒子 ≤6、单位 ≤24）；div 要求 k ∈ `availableDivisors(state)`。
  - `availableDivisors(state)` → a、b、c、d 中非零计数之 gcd 的全部 >1 约数（升序）；空集时除法钮禁用。
  - `isIsolated(state)` → `a === 1 && b === 0 && c === 0`（x 单独留在左盘；右盘剩 d 即候选解）。
  - `evalSide(aCoef, constant, xv)` → `aCoef * xv + constant`，供揭晓验算逐项展示。
  - `solveLinear(a, b, c, d)` → `(d − b) / (a − c)`，构建期断言整除且为正整数，仅用于题库/自测的答案实算与自查对账，**运行期不把结果写进任何 DOM**（自测判定在内存中比对数值）。
- **各步初始状态（写死，评审按此复现）**：step0 盒重序列 [6, 4, 9]（换盒轮换，砝码从 0 起逐个加）；step1 `{a:1,b:2,c:0,d:8,xv:6}`；step2 `{a:1,b:1,c:0,d:4,xv:3}`；step3 `{a:1,b:3,c:0,d:7,xv:4}`；step4 题库 `[{a:2,b:3,c:0,d:11,xv:4}, {a:3,b:6,c:0,d:15,xv:3}, {a:4,b:1,c:0,d:9,xv:2}]`；step5 题面 `x + 5 = 12`（解 7）、`2x + 4 = 14`（解 5）。
- **自查断言集（构建报告须逐项给输出证据）**：
  - 随机状态 200 组：任意 `addUnits/subUnits/addBoxes/mul` 合法操作前后 `isBalanced` 不变（初始平衡 ⇒ 操作后平衡）；只动一边的模拟操作（直接改 b）必使平衡翻转（在 L≠R 的构造下）。
  - `availableDivisors`：{2,3,0,11} → 空集；{3,6,0,15} → [3]；{2,4,0,8} → [2]；{1,3,0,7} → 空集。
  - `isIsolated`：{1,0,0,7} 真；{1,3,0,7}、{2,0,0,8}、{1,0,1,4} 假。
  - `solveLinear` 对题库三题 + 自测两题：4、3、2、7、5，且整除断言成立。
  - 泄漏审计：step3/4 在未揭晓时，抓取全部可见文本节点与全部元素属性，断言不含 xv 的值串作为盒重出现（校验法：用 xv=4 而各常数与之不重合的题面组合，并人工复核读数模板只走 `compositionString`）；自测解析区在答对前 `innerHTML` 为空（三时点：初始、答错后、切语言后）。
  - 边界：单位加到上限 24、盒子乘到上限 6 时对应钮禁用且有文案；subUnits 超过现有计数被拒；step0 砝码加到盒重 ±3 的范围行为正确（指针方向翻转点与 `weigh` 比较一致）。
- **动画口径**：操作后横梁以动画转到 `tiltDeg` 新角度（rAF，约 400ms）；动画中再点操作，立即以当前状态重设目标（取消旧动画、不排队、不残留旧判定）；复制/分组动画同理，结束态必须与状态严格一致（动画只是渲染，不得参与判定）。静止不空转。

## 模拟设定 / 模型失配（清晰度规则 8：必须明说，写进 step0 或终章正文）
- 本页是**理想天平**：横梁无摩擦、无重量、指针零误差；真实天平有灵敏度极限，两边差 1 个单位以内未必看得出倾斜——本页按「差 1 就判定不平」处理，属教学简化，正文须点明。
- 砝码只有整数单位、盒子重量恒为整数；现实中的重量是连续的，本页不处理小数重量。
- 天平装不下「负的重量」：常数为负的方程（如 2x − 3 = 5）在本页用「先同加」的讲法也绕不过盘面表示，故本页题目只用正的常数与正的答案；负数答案的方程留给与 negative-numbers 衔接的后续页。
