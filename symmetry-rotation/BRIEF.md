# BRIEF：对称与旋转（symmetry-rotation）· 小学数学

## 定位
- slug `symmetry-rotation`，category math，stage primary。受众：小学中高年级 + 家长。接 area-model / perimeter-area（图形与正方形）之后。
- 核心直觉一句话：**对称轴是「对折后严丝合缝」的那条折痕；旋转对称是「转过一个角度又和自己一模一样」——一个靠翻，一个靠转，都是在问图形怎样动一下还能变回自己**。
- 已知：正方形、长方形、三角形等基本图形。唯一新问题：一个图形有哪些「动一下变回自己」的办法？

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **对折试一试**：已知基本图形；唯一问题：沿哪条线对折，两边能完全重合？控件：选图形（等腰三角形、正方形、长方形、普通三角形），画布给出若干候选折线（含斜的、偏的假线），点一条 → 播放对折动画（半边翻折过去），重合则点亮「这是一条对称轴」，不重合则露出对不齐的边角。对每个图形把全部候选线试完，收集到的对称轴计数实时累计。结论：对称轴 = 对折后完全重合的折痕，不是「看着差不多」的线；适用条件：只对平面图形谈。
2. **对称轴数一数**：唯一问题：对称轴有几条，是图形说了算——来数一遍账。控件：图形画廊（正方形 4、长方形 2、等边三角形 3、等腰三角形 1、平行四边形 0、圆 无数条），先点选预测条数（0/1/2/3/4/无数），再逐条「亮出」折线核对；**平行四边形是陷阱位**：看着最像有，其实一条都没有，但它藏着第 3 步的悬念（转半圈能重合）。字母彩蛋：A（1 条）、H（2 条）各一枚放画廊末尾。结论：正方形 4 条最多（圆除外）；条数由图形决定、不由感觉决定。
3. **转一转**：唯一问题：不翻面、只在平面里转，转多少度能和自己重合？控件：风车画布，选叶片数（2/3/4 叶风车 + 一片普通树叶形作 0 对照），角度滑杆 0–360 连续拖 + 「找最小重合角」按钮（吸附到最近的正确角并点亮）；每种图形的最小重合角账本：2 叶 180°、3 叶 120°、4 叶 90°、树叶 360°（即转一整圈，只有这一种）。结论：旋转对称 = 转过 360°÷n 就重合，n 叫重合次数；与第 2 步回收悬念：平行四边形转 180° 也重合——它没有对称轴，却有旋转对称，**翻和转是两回事**。
4. **万花筒**：唯一问题：只画一小块，整幅图案为什么自己长出来？控件：在一个扇形小区里点几个点/选一个小图案（点、短线、小三角），镜像+旋转自动复制到所有扇区；滑杆/切换：扇区数（4/6/8）、镜像开/关。关镜像只剩旋转复制、开镜像每区再翻一份——亲手对比两种花纹的差别。结论：万花筒 = 旋转对称 + 镜像（轴对称）的合谋；扇区数 n 时一份原件长成 2n 份（开镜像）或 n 份（关镜像）。纯计数断言以页面逻辑自查。
5. **自测 + 终章**：①判断题「长方形转 90° 就能和自己重合」（错，180°）；②选择题：下列图形里**只有旋转对称、没有对称轴**的是哪个（平行四边形 vs 长方形 vs 等边三角形）；③操作题：3 叶风车转到第几个刻度第一次重合（滑杆答题，120°）。终章三卡收束（对折=轴对称 / 转=旋转对称 / 万花筒=两者合谋）+ 深链：perimeter-area#step1（正方形为什么处处特别：它对称轴最多、周长固定时面积也最大）、area-model#step1（地砖图案里的对称，自己打开目标页核对锚点）。
