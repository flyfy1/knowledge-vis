排序与大 O · 增长的形状

排序算法之间的差别，不在能不能排，而在「比较了多少次」如何随数据量增长。大 O 记的不是秒表，而是增长的形状：n 翻倍时工作量翻几倍。这一页的每个计数都由真实排序代码当场数出来——公式牌上的每个数，都能拿种子自己复算。

第 1 步 · O(n²) 家族

冒泡与选择：笨办法的账要算清

选择比较数 ≡ n(n−1)/2 · 冒泡交换数 = 逆序数 · 冒泡（带早停）已排序输入比较数 = n−1

算法最好 平均最坏 计数口径（与本页实现同源）
冒泡O(n)O(n²)O(n²)带早停；交换数 = 逆序数
选择O(n²)O(n²)O(n²)比较数恒 = n(n−1)/2，与数据无关

第 2 步 · 分而治之

归并与快排：把大问题切小

两个面板各自独立、计数互不延续——归并这边数的是它自己的比较与移动，切到快排看到的是快排自己的比较与交换，两边的进度互不影响。

归并：每层 ≈ n 次比较 × log₂n 层 ≈ n·log₂n

切分长这样：一路从中间切开（左半 ⌊n/2⌋），直到每段只剩 1 个。切分本身不产生比较、不计数，所以它不单独成帧——下面的动画从第一次合并开始，正是把这棵切分树自底向上逐段合并回来。

快排（本页规则）：pivot = 最后一个元素，Lomuto 分区；随机模式从区间内等概率抽一个当 pivot

pivot 规则

算法最好 平均最坏 计数口径（与本页实现同源）
归并O(n log n)O(n log n)O(n log n)切分固定取左半 ⌊n/2⌋；移动 = 写入主数组次数
快排O(n log n)O(n log n)O(n²)pivot 取末元（本页规则）；最坏 = 已排序输入
