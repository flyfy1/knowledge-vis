# BRIEF：一次函数（linear-functions）· 初中数学

## 定位
- slug `linear-functions`，category math，stage junior。受众：初中生 + 家长。接 pythagoras（初中数学首批）之后，坐标系与函数的第一页。
- 核心直觉一句话：**y=kx+b 不是符号游戏：k 是每走一步抬高多少（坡的陡缓），b 是还没出发就站在多高（起点）——拖直线改方程，和拖方程看直线，是同一件事的两面**。
- 已知：数轴、平面直角坐标系初步、勾股（无关但同为 junior 页）。唯一新问题：直线和它那行方程，怎么一一对上？

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **爬坡**：已知坐标系与点；唯一问题：一排台阶每一级都抬高一样多，连起来是什么样？控件：坡道画布，滑杆选「每向前 1 格抬高几格」k（−3…3，含 0 与分数 1/2 的刻度步），格点逐个落点（x=0…5），点自己排成一条直线；读数同步显示每点坐标表。预期观察：k 越大坡越陡、k 为负往下走、k=0 是平地。结论：等步长等抬高 → 直线；k 就叫**斜率**。适用条件：抬高量恒定才成直线（埋伏笔：不恒定就是曲线，看抛物线页）。
2. **起点**：唯一问题：同一条坡，从不同高度出发有什么不一样？控件：固定 k=1，滑杆拖起点 b（−3…3），整条线上下平移；读数：x=0 处与纵轴的交点坐标 (0, b)。预期观察：坡的陡缓不变、线整体平移、交点跟着 b 走。结论：b 叫**截距**，是 x=0 时的 y——还没出发就站在多高。
3. **方程长出来**：唯一问题：把「陡缓」和「起点」合起来，能不能写出一句算出每个点的式子？控件：k、b 双滑杆同屏，画布直线 + 方程 y=kx+b 实时拼装（k、b 数字随滑杆变，含负号与 1 的书写约定：k=1 不写系数、b 为负写成 −|b|、b=0 不写）；点探针：点直线上任意格点，显示「代入验算：y = k×x + b = …」逐项对账。预期观察：拖任一滑杆，线与方程同步变；验算永远等。结论：直线上每个点都满足同一方程，方程就是这条线的「说明书」。
4. **两条线相遇**：唯一问题：两条线什么时候相交、交点是什么意思？控件：第一条线固定 y=x+1，第二条 k₂、b₂ 可调；交点实时标记 + 坐标读数；特例路径必须可达：k₂=1 且 b₂=1 → 两线重合（读数明说重合、无数交点）；k₂=1 且 b₂≠1 → 平行（读数明说平行、永不相交）；其余 → 唯一交点并显示「交点同时满足两个方程」。预期观察：交点坐标应由页面状态纯渲染并自查（联立解 (b₁−b₂)/(k₂−k₁) 与画布一致）。结论：交点 = 两条线共同的点 = 两个方程共同的解——这是后面方程组页的种子（口径只到这里，不引入二元一次方程组术语展开）。
5. **自测 + 终章**：①看图选方程：给一条过 (0,2)、斜率 −1 的线，三选一选方程；②给方程 y=2x−1，拖直线（k、b 双滑杆答题模式）把它摆出来，判定容差 = 整数精确；③应用题读图：出租车计价图（起步价 b + 每公里 k），读「3 公里多少钱」与「付了某钱能坐几公里」各一问，用图上探针答题。终章三卡（斜率=陡缓 / 截距=起点 / 交点=共同解）+ 深链：pythagoras#step5（距离公式里再见坐标）、parabola（未上线，先不链出；终章只链已上线页）、velocity-vt（未上线，不链）——深链只指向已上线页并打开核对。
