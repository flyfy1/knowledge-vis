# BRIEF：多边形内角和（polygon-angles）· 初中数学
- category `math`，stage `junior`（已注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，记录不确定性）。去重：circle-angles 讲圆周角，pythagoras 讲勾股；本页是多边形内角/外角和，无重叠。
- 核心：三角形内角和 180°（撕角拼平角）；n 边形剖成 n−2 个三角形；外角和 360°；凹多边形同样成立；由内角反推边数。

## 步骤（五必填项）
0. 三角形。问题：三个角和？输入顶点 C 位置、拼合进度；观察：三个扇形从原位移动旋转并排成半圆（平角），读数由坐标算出角和 180°。
1. 四边形。问题：四个角和？输入顶点 D（保持凸）；观察：对角线分出两个三角形，四角和恒 360°。
2. n 边形。问题：剖成几个三角形？输入 n（3–12）；观察：n−2 个三角形、读数公式值与坐标算出值一致。
3. 外角和。问题：走一圈共转多少度？输入正/不规则凸多边形、n、走了几条边；观察：外角弧点亮、累计环到 360°；不规则为圆上抖动角度的凸多边形，外角各不同，总和仍 360°。
4. 凹多边形。问题：公式要求凸吗？输入向里压程度；观察：一个角超过 180°（红色），五角和仍 540°（简单多边形）。
5. 终章。问题：已知内角求边数；输入内角 60–178；n=360/(180−a)，整数才画出正多边形，否则说明无解；深链 pythagoras#step0、symmetry-rotation#step2、circle-angles#step1（均已核对存在）。

## 新术语首现表
内角（步 0 定义）；对角线（步 1）；外角（步 3 定义）；凹/凸（步 4 带口径）；正多边形（步 2、5）。

## 模拟设定 / 模型失配
平面简单多边形；角度由顶点坐标计算（符号转角法）；曲面上三角形内角和不是 180°（页内说明，不展开）；步 0 的“撕下来”是按角度旋转移动扇形的示意。
