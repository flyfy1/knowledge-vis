How to read this space

Each planet is a real atlas concept. Colors identify editorial topic groups. Lines are documented relationships; bright lines touch your selection, dashed amber lines trace a shortest connection path. Layout uses undirected shortest paths, treating all relationship types equally, then fits them approximately in 3D. Disconnected components are spaced apart. This is neither orbital physics nor a prerequisite sequence. Camera perspective changes apparent distance and size; use the hop count for an exact graph measure.
