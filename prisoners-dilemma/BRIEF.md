# BRIEF：囚徒困境与演化博弈（prisoners-dilemma）· The Prisoner’s Dilemma & Evolutionary Games
- category `math`，stage `university`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：game-theory 是静态 2×2 完全信息博弈（占优、纳什、混合策略），其 BRIEF 明确不含重复博弈与演化动态；本页是 PD 的重复/演化部分，仅第 0 步触及占优，重合 <25%。
- 核心直觉：一次博弈背叛占优但互背叛劣于互合作；重复足够多轮、δ≥(T−R)/(T−P) 时回报性合作可维持；复制者动态里背叛者先繁荣后被以牙还牙取代；噪声下加宽容。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **一次博弈**
   - 已知：收益矩阵的读法。
   - 唯一问题：为什么两人都想合作却都背叛？
   - 输入与求量：输入对方的选择与我的选择；收益 5/3/1/0；求最佳回应与得分。
   - 控件操作与预期观察：点对方 C/D → 绿格标出我的最佳回应（总是 D）；再点我的选择看得分；清除选择重置。
   - 适用条件：一次性、完全信息、无沟通。
1. **对局重复**
   - 已知：一次博弈的结论。
   - 唯一问题：同样两人连打多轮会怎样？
   - 输入与求量：输入两方策略（5 选 1）、轮数 1–30、随机种子；求每轮选择与累计得分。
   - 控件操作与预期观察：换策略/轮数：TFT 对 AllD 只第一轮吃亏；重掷随机玩家。
   - 适用条件：无噪声；随机玩家用种子复现。
2. **循环赛**
   - 已知：策略的得分。
   - 唯一问题：谁在所有对手面前总分最高？
   - 输入与求量：输入轮数 1–50；求 5×5 得分表与总分。
   - 控件操作与预期观察：n=1 全叛第一；n 大时 TFT/Grim 追上并反超（排名翻转）。
   - 适用条件：仅 5 种策略的小比赛，换对手排名会变；随机取 40 局平均。
3. **未来的影子**
   - 已知：重复博弈。
   - 唯一问题：继续概率多大时合作才划算？
   - 输入与求量：输入 δ（0–0.9）；求 3/(1−δ) 与 5+δ/(1−δ) 及 δ*=0.5。
   - 控件操作与预期观察：拖 δ：δ<0.5 红线在上，δ>0.5 绿线在上；δ=0.5 两者同为 6。
   - 适用条件：对手在被背叛后永远报复（Grim/TFT 近似）。
4. **种群演化**
   - 已知：策略得分表。
   - 唯一问题：放进大种群，比例怎么随世代变？
   - 输入与求量：输入初始全叛占比、TFT 占比、轮数；求 80 代复制者动态。
   - 控件操作与预期观察：n=1 全叛吞没；n=20 全叛先繁荣再被 TFT 取代；重放 5 s 轨迹累积。
   - 适用条件：无限大均匀混合、无突变、按得分比例复制。
5. **犯错与宽容**
   - 已知：以牙还牙。
   - 唯一问题：有噪声时要不要原谅？
   - 输入与求量：输入出错概率 e（0–0.2）、宽容度 g（0–1）；求自我对局每轮平均得分。
   - 控件操作与预期观察：拖 e：TFT 掉得比 GTFT 快；g=0 两线重合；终章含回顾与 3 条互链。
   - 适用条件：只展示自我对局，未展示被剥削；3000 轮种子平均。

## 模拟设定与模型失配
种子化伪随机；非真实人类实验。三策略种群无突变、无空间；PD 收益 5/3/1/0 满足 T>R>P>S 且 2R>T+S。演化是比例动力学，不预测真实社会。探针独立核对收益、TFT/AllD 手算得分、δ* 交点、n=1 全叛吞没、n=20 TFT 占优与噪声下 GTFT>TFT。
