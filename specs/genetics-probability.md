# Genetics & Probability · Review Spec

- **入口**：`genetics-probability/`
- **分类**：probability + biology；学段 senior；双语
- **状态**：live，静态页面，无外部依赖

## 核心模型

单性状：`gametes(AA)=[A:1]`，`gametes(Aa)=[A:1/2,a:1/2]`，`gametes(aa)=[a:1]`。两边配子独立相遇，组合为 `AA / Aa / aa`；完全显性时表型为 `A_ / aa`。

双性状：以 `AaBb × AaBb` 为默认示例，重组率 `r∈[0,0.5]` 控制配子权重：`P(AB)=P(ab)=(1-r)/2`，`P(Ab)=P(aB)=r/2`。当 `r=0.5` 时四种配子均为 1/4，表型为 `9/16,3/16,3/16,1/16`。

条件概率：固定四格 `AA, Aa, Aa, aa`。显性证据集合为 `{AA,Aa,Aa}`，隐性为 `{aa}`，携带者为 `{Aa,Aa}`。目标概率按保留格子的重数计算，例如 `P(Aa | A_)=2/3`。

## 视觉检查点

1. 第 0 步：亲本选择、配子卡、箭头、后代预览在窄屏仍可读。
2. 第 1 步：四格与两组比例条同屏；点击格子后状态区更新。
3. 第 2 步：重组率移动时配子卡、16 格权重和条形图同步变化。
4. 第 3 步：过滤格降低透明度，目标格有琥珀色边框；公式与新分母同步。
5. 第 4 步：错误选项标红、正确选项标绿，完成后出现闭环卡。

## 边界

这是孟德尔、完全显性、等可能结合的教学模型，不代表连锁、互作、不完全显性等复杂情形。双性状 `r` 是连锁对照变量，独立分配只在 `r=50%` 成立。
