## Terms / dependencies
Step 0: AND = a bit is 1 only if all operands have 1; ordered indices = slot assignments, not unordered values. Step 1: mask = integer encoding on/off bits; f[m] = number of ordered pairs whose AND is exactly m. Step 2 redefines f locally, B = used bit width (at least 1), U=2^B, submask = uses only allowed 1-bits, g[s] = sum of f over submasks of s, complement = (U−1)^x. Processed-bit invariant: g[s] sums exact pair masks made by clearing any processed bits in s, with other bits unchanged. Each update splits a disjoint family by the current bit, so addition has no duplication. Step 3 locally redefines contribution and complement. Step 4 repeats variable definitions and bounds.
