# #1147 Longest Chunked Palindrome Decomposition

Official source: https://leetcode.com/problems/longest-chunked-palindrome-decomposition/
The saved public response is HTTP 200, Hard, free, with full statement and templates.
Python3: `Solution.longestDecomposition(self, text: str) -> int`.
TypeScript: `longestDecomposition(text: string): number`.
The input is 1..1000 lowercase English letters. Return the maximum number of
nonempty contiguous chunks, covering the entire input in order, whose chunk
sequence equals its reversal. The required result is a count, not a partition.

## Exact cases and distinctions

The oracle exhausts every inter-character cut subset for these small inputs.
The listed partitions achieve independently verified maxima:

| Text | Chunks | Maximum |
| --- | --- | --- |
| a | a | 1 |
| aa | a / a | 2 |
| aaaa | a / a / a / a | 4 |
| abc | abc | 1 |
| aba | a / b / a | 3 |
| abba | a / b / b / a | 4 |
| abca | a / bc / a | 3 |
| abcab | ab / c / ab | 3 |
| abcabc | abc / abc | 2 |
| abcxabc | abc / x / abc | 3 |
| volvo | vo / l / vo | 3 |
| merchant | merchant | 1 |

Corresponding chunks are equal in their original orientation; they are not
character-reversed. Neither an outer chunk nor the middle chunk needs to be a
character palindrome (`abc / abc`, `a / bc / a`). There is no deletion or
reordering. Empty chunks are illegal. An exhausted internal remainder contributes
zero; a nonempty remainder with no disjoint matching prefix/suffix contributes
one. These are internal cases, not permission for an empty original input.

The official long examples retain their stated counts 7 and 11 and their exact
chunk witnesses in the evidence. Their witnesses are independently checked for
nonemptiness, concatenation and symmetry; their optimality is not independently
exhausted here. The official `merchant` example is small enough to exhaust.

## Proof obligation: shortest matching outer chunks

A future explanation using the shortest equal, disjoint prefix/suffix P must
establish optimality, not just show a match or appeal to the examples. Let F(S)
be the optimum and let p = |P| <= |S|/2. The required recurrence is
`F(S) = 2 + F(S[p:-p])`; absent such a P, a nonempty S has optimum 1.

An exchange/refinement argument can discharge the obligation as follows:

1. P has no shorter nonempty border (equal prefix/suffix). Such a border would
   itself be a shorter disjoint prefix/suffix of S, contradicting minimality.
2. Because P exists, a single-chunk partition is not optimal. Any optimal
   partition therefore has equal disjoint outer chunks Q with length q >= p.
3. Q starts and ends with P. If p < q < 2p, the two occurrences overlap and give
   P a border of length 2p-q, contradicting step 1. If q >= 2p, write Q = P V P.
   Splitting both outer Q chunks symmetrically into P, V, P (or P, P when V is
   empty) produces a valid partition with strictly more chunks. That contradicts
   optimality. Hence every optimal outer Q has q = p.
4. The remaining inner partition must be optimal too, otherwise replacing it
   improves the whole partition. Conversely, surrounding any optimal inner
   partition by P yields a valid full partition. This establishes the recurrence.

This is a mathematical argument offered for later independent lesson review,
not an adopted design or an official editorial quotation. The script separately
checks the recurrence and shortest-outer-chunk property for all 254 binary
strings of lengths 1..7 against 10,922 complete cut partitions. Finite agreement
supports these cases; it does not substitute for the general argument.
