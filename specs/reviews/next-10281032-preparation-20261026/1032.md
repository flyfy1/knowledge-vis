# #1032 Stream of Characters

Dispatcher-only contract reference. [Official statement](https://leetcode.com/problems/stream-of-characters/).
One ordinary public GraphQL response returned HTTP200, Hard, free, matching the
frozen catalog. Full original content, metadata and language templates are in
`1032-official-response.json`; exact request/hash in `1032-official-access.json`.

## Original input and interface

Construct `StreamChecker(words)`, then call `query(letter)` once for each new
lowercase English character. Each call appends that character to the same stream
and returns whether any **nonempty suffix ending now** equals a dictionary word.
It is a Boolean existence question, not a count, longest-match result or search
for any past substring. Successful queries do not consume or clear characters.

Constraints: 1–2000 words, each 1–200 characters; words and query characters use
lowercase English letters; at most 40,000 query calls. Distinct words are not
required. No query-count lower bound is stated. The constructor's `null` in the
serialized example is not a result from `query`.

Python3: `StreamChecker.__init__(self, words: list[str])`,
`StreamChecker.query(self, letter: str) -> bool`.
TypeScript: `constructor(words: string[])`, `query(letter: string): boolean`.
The raw metadata also carries unrelated top-level `starts`/`ends` fields; these
conflict with neither the class constructor/method declarations nor the templates,
but they are not the stated public inputs. Use the mutually consistent statement,
class metadata and language interfaces; do not invent those extra arguments.

## Small distinguishing checks

| Words / successive letters | Per-query answers | Point |
| --- | --- | --- |
| `["ab"]` / `aba` | F,T,F | An earlier match is no longer a current suffix. |
| `["aa"]` / `aaa` | F,T,T | Overlapping matches survive a successful query. |
| `["ab","abc"]` / `abcf` | F,T,T,F | A word may end before a longer word with that prefix. |
| `["a","ba"]` / `ba` | F,T | Multiple matching words still return one Boolean. |
| `["ab"]` / `ba` | F,F | Character direction matters. |
| `["ab"]` / `cab` | F,F,T | Matching need not cover the whole stream. |

The direct tiny oracle retains each full stream prefix and lists every dictionary
word that literally matches its suffix. It checks all official query results,
the introductory example, duplicates, short histories and an empty query sequence.
It is intentionally not a scalable implementation or a prescribed author choice.

## Provisional teaching and review risks

Make the current stream endpoint and matched suffix visible. A dictionary prefix
is not automatically a whole word; any terminal word suffices, even when other
words continue beyond it. If a lesson chooses reversed words or a trie, align its
reading direction and terminal markers with these literal suffix witnesses.
Do not retain only the last letter, clear state after a match, or leak history
between independently constructed objects. Explain reset versus one query step.

The longest dictionary word bounds which history suffix can affect one answer,
but that observation alone does not establish an implementation's efficiency.
The direct oracle does not measure 40,000 calls or 2000 long words. Keep original
constructor/query interactions distinct from any batch test harness. No optimized
solver, automaton choice, performance pass or lesson acceptance is claimed.
