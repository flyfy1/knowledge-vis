### Independent correctness and causal mapping

The independently predicted `&(f,|(t,f))` returned exactly `False` (inner OR true, outer AND false); `!(t)` returned exactly `False`, refuting the any-true-literal shortcut. Also checked `t → True`, `f → False`, `&(t) → True`, `|(f) → False`, 6,665 nested NOTs around false (19,996 characters) → true, and a 20,000-character AND ending with false → false. The broader logic suite also reuses one bound Solution method across inputs.

Concrete mapping of the visible first-close transition: at index 7 of `&(t,!(f))`, `stack.pop()` removes `f`; this sets `has_false=True` while `has_true=False`. The loop stops at `(`. Two pops remove that `(` and `!`; `not has_true` is true and append pushes `t`. The earlier `[&, (, t]` remains, yielding `[&, (, t, t]`. On index 8, AND sees no false child and reduces to `t`. A comma consumes one character without changing either stack. This matches the browser's complete-character frame boundary and all simultaneous progress/event/history readouts. Final-result wording is withheld until the scan is finished, including for a completed inner group.

The invariant is sufficient: the processed prefix is stored with commas omitted and completed subexpressions compressed to literals. Valid grammar ensures an operator immediately below each matched opening delimiter and only literal children above it when closing. NOT has exactly one child, while AND/OR are order independent, so popping in reverse order does not change the value. Empty prefix, lone literals, one-child AND/OR, nested groups and final single-literal termination are covered. Invalid/empty expressions are outside the official domain.

The substitution baseline really searches and copies the shrinking string repeatedly. Nested NOTs remove three characters each time, giving quadratic worst-case search/copy work and linear peak live space; a lone literal simply returns in constant work. Canonical Python reads each character once and pushes/pops each token at most once, giving O(n) time and O(n) auxiliary space. Wide literal lists and deep syntax both attain linear retained state. Browser snapshots and histories have additional allocation and are clearly excluded from submission costs. `core.js` also uses `unshift` to restore children to reading order; its teaching trace is correctly labeled as separate from Python execution and its cost claim.
