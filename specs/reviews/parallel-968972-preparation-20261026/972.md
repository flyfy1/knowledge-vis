# #972: statement, interface and teaching preflight

[Official problem](https://leetcode.com/problems/equal-rational-numbers/).
[Saved official payload](972-official-access.json); [dispatch gate](README.md).

**Verified original input/output.** Two strings `s` and `t` represent non-negative
rationals. Allowed forms are an integer, an integer followed by a decimal point
and a possibly empty finite suffix, or that decimal form followed by a nonempty
parenthesized repeating block. Integer-part length is 1–4, with no leading zeros
except 0; finite suffix length is 0–4; a present repeating block has 1–4 digits.
Each part contains digits. Return whether the two exact numbers are equal.
Python3: `Solution.isRationalEqual(self, s: str, t: str) -> bool`; TypeScript:
`isRationalEqual(s: string, t: string): boolean`.

All three official pairs return true:
`"0.(52)" / "0.5(25)"`, `"0.1666(6)" / "0.166(66)"`, and
`"0.9(9)" / "1."`. Preserve these original strings, including the empty suffix
in `"1."`, when presenting input and intermediate parsing.

**Teaching risks and proposed questions (not an implemented proof):**

- Use text input/representation for the original strings. A number control or
  conversion through float destroys parentheses and can normalize trailing digits
  or the decimal point before the learner can see how parsing works.
- Separate integer, finite and repeating parts visibly, retaining digit lengths
  and leading zeros inside fractional blocks. The block value alone cannot encode
  its position or period length. Absent repetition differs from a repeat of zero.
- Derive an exact rational contribution from the repeating tail using a concrete
  shift/subtract or geometric-series argument. Define the decimal shift and period
  length before introducing denominator factors; do not present an unexplained
  fraction formula as the reasoning bridge.
- Compare exact values rather than truncated digit samples or arbitrary floating
  tolerances. Python integer arithmetic supports an exact fraction approach; a
  normalization helper, if chosen later, still needs its behavior and cost explained.
- Periods can be written at different lengths and starting positions. Equality is
  not equality of raw strings, repeating blocks or the number of displayed digits.
- Repeating 9s can carry into the finite or integer part. Explain why the infinite
  tail is an exact value, not merely “very close”, and show the official `0.9(9)`
  versus `1.` case. Do not hard-code only the all-nine integer-boundary example.
- Distinguish a finite animation prefix from the infinite value it illustrates.
  Keep any truncation limit labeled; add a contrasting unequal case when the author
  develops examples rather than relying only on the three true official pairs.

No parser, fraction formula implementation, float counterexample claim under these
bounds, arbitrary epsilon, UI controls or equality tests were implemented here.
Those choices and their correctness evidence belong to the later candidate review.
