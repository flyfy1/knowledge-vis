Concrete Python mapping: at hand-case frame 2 the path is a→b, prefix ab and no answer yet. Python has selected `node = parent[ch]` and marked b as `#`. `word = node.pop("$", None)` then `answer.append(word)` accounts for frame 3: ab changes from pending to emitted and joins the output while d/a letter entries stay. Recursing down to d accounts for frame 4; restoration `board[r][c] = ch` accounts for frame 8, removing d from the visible used path and returning to prefix ab. Python's absent-key rejection also rejects `#`, while the simulator separates reuse into a more explanatory event and retains original board letters visually. This is a faithful state abstraction, explicitly labeled as a simulation.

The independent invariant is: every live successful recursion stack spells its trie prefix using distinct orthogonally adjacent cells. Missing prefix edges cannot lead to dictionary words; used cells cannot extend a legal path. Marker removal only suppresses duplicate answers, and every original letter edge remains available. Exit restores the caller's board state; every start is tried. Depth is bounded by L plus one rejected call, and finite neighbors/starts establish termination. No board or words mutation escapes a normal completed call.

Cost was audited against actual code: building letter dictionaries takes O(S) expected time/space. Per start, at most four first neighbors and at most three new choices after excluding the preceding used cell give a safe O(4·3^(L−1)) bound, including a constant-factor failed frontier. Thus O(S+B·4·3^(L−1)) expected time and O(S+L) auxiliary space are defensible; output adds O(W) references. Full simulator snapshots are correctly excluded from submission complexity. The optimization removes repeated dictionary-prefix exploration across words; it does not make board path enumeration linear.
