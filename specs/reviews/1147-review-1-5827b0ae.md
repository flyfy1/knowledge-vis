### Independent calculations, invariant and code

Executed actual solution.py with Python bytecode writes disabled, not only core.js. My independently written exhaustive partition enumerator agreed on `acxyac`→3, `abca`→3, `abcb`→1, `abcabc`→2, `abababa`→7 and `abccab`→4 (`independent.json`). The first three predictions were recorded before source reveal; the last three were additional code checks with explicit expectations before execution. For acxyac, a≠c then ac=ac gives fixed=2, remainder xy, which adds 1. For abcb, length 1 gives a≠b and length 2 gives ab≠cb; no longer disjoint pair exists, so return 1. Repeated interior letters do not authorize arbitrary cuts. These are preset-only UI **code checks**.

Invariant: committed chunks on the left, unresolved text[left:right], and reverse-order matching chunks on the right concatenate to the original text; committed count + OPT(unresolved) equals the original optimum. Failure changes only candidate size; success removes equal disjoint ends and adds exactly two. Size grows until a match or until no disjoint ends remain. Each successful round shortens the interval; therefore termination follows. Empty middle adds zero (aa→2); nonempty unmatched middle adds one (merchant→1). A one-letter input yields 1. Strings are immutable and source contains no mutation of input.

Concrete visual-to-Python mapping: volvo's second operation compares text[0:2] with text[3:5], then `chunks += 2`, `left += size`, `right -= size`; next outer iteration resets size=1. The visible AFTER interval [2,3) and count 2 represent the same instant as these assignments. The following operation's `2*size > right-left` returns 3. The frame retains the last nonempty middle for display but explicitly says it is counted and finished, so it does not imply further computation.

The greedy proof is correct: any longer mirrored outer chunk starts and ends with the shortest border u. Overlap would make u have a shorter border; absent overlap, refine each copy symmetrically into u,w,u. An optimal decomposition cannot leave that refinement unused. A decomposition with a single chunk cannot be optimal if a disjoint border exists, since cutting its equal ends already improves its count. The lesson's proof can be reconstructed, though its overlap argument is terse for the stated reader.

Cost matches actual Python: unsuccessful lengths allocate progressively larger slices; one round through t costs O(t²). Consumed lengths plus the final failed round have O(n) total, bounding the sum of squares by O(n²). The valid a^500 b^500 case attains quadratic slice-copy work despite early character mismatches. At most O(n) live temporary slice characters; scalar variables are constant in number; no recursive stack. The displayed exhaustive baseline is O(n·2^n) time/O(n) space on the valid nonempty domain. Saved UI frames are explicitly excluded from submission space.
