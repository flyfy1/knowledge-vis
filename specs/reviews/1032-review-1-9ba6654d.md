Operation 5 looks up a from that child and sees `#`, returning True. With x appended, the buffer becomes bx and local node resets to root; missing x returns False without clearing bx. This distinguishes persistent dictionary/buffer from temporary scan state. Constructor only reads the input word list; duplicate terminals are idempotent. Instances use independent dictionaries/deques.

The invariant is precise for each completed edge, including k=0. A missing edge does not become the successful path: the UI separately names the attempted path. Expected constant-time dictionary operations justify O(min(t,L)) worst scan length per query and O(S+L) retained space. Here each queried stream has t≥1; zero queries incur construction alone.
