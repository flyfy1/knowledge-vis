# #1044 Longest Duplicate Substring

Dispatcher-only reference to the [official problem](https://leetcode.com/problems/longest-duplicate-substring/).
Ordinary public GraphQL returned HTTP200, Hard/free, matching the fixed catalog.
Raw response, full statement and language templates are preserved beside this note.

Given lowercase-English string`s`, length2 through30000, return any longest
contiguous substring with at least two distinct occurrence starts. Occurrences
may overlap. If no nonempty duplicated substring exists, return`""`. The output
is the substring itself, not a length, pair of indices or list of all winners.
No lexicographic or earliest-occurrence tie rule is required.

Python3: `Solution.longestDupSubstring(self, s: str) -> str`.
TypeScript: `longestDupSubstring(s: string): string`.

## Direct distinguishing examples

| Input | All accepted maximum-length words | Occurrence starts |
| --- | --- | --- |
| `banana` | `ana` | 1,3; the intervals overlap. |
| `abcd` | empty string | No repeated nonempty substring. |
| `aaaa` | `aaa` | 0,1; disjoint-only matching would be wrong. |
| `ababab` | `abab` | 0,2. |
| `abcdabefcd` | `ab` or `cd` | 0,4 or2,8; either answer is valid. |
| `aa` | `a` | The smallest legal repeated input. |

Nine hand-sized cases are checked by enumerating every literal substring and its
start positions, then independently checking maximum length with direct character
comparison for every pair of starting positions. The same two tiny methods agree
for all 124 binary strings of lengths2 through6. This is an oracle contract check,
not an optimized solver or a claim about length30000.

## Provisional learning/review risks

Make contiguity, distinct starts and allowed overlap explicit. Highlight both
intervals of a witness without implying they must be disjoint. Merely finding a
duplicate does not establish maximality. Exact-output tests must accept any
maximum-length winner; a deterministic demo tie choice should be labeled as its
own presentation choice, not an official requirement. Keep indices visibly
separate from the returned string and show why the no-match result is empty.

If an eventual lesson uses a hash, equality of fingerprints is not by itself
proof of equal text. The actual collision strategy and any literal verification
must match both trace and callable. If it searches over lengths, its decision
predicate must mean that a real duplicate of that length exists, with a correct
witness; a false hash match can invalidate the search. These are conditional review
risks, not a mandated algorithm. Do not treat substring slicing or string-key
comparison as automatically constant-time when explaining costs. No rolling-hash,
suffix structure, complexity guarantee or maximum-input performance is selected
or accepted by these dispatcher notes.
