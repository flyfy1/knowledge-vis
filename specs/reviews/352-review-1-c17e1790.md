Invariant reconstructed independently: sorted starts; each inclusive range contains only seen values; their union equals all seen values; next.start > previous.end+1. Lower bound produces a predecessor starting below x and successor starting at/above x. A predecessor containing x causes no change. Otherwise its end can touch x only at end+1=x. A successor can join only at start=x or x+1. Earlier/later ranges cannot reach x because the invariant already separates them from these neighbors. The slice replaces exactly the touched ranges, preserving untouched order and gaps. Empty state establishes the invariant; finite insertion sequences preserve it. Binary search terminates as hi−lo strictly decreases, including p=0 and p=k. A duplicate equal to a range start uses the successor replacement branch; a duplicate inside a range uses the predecessor early return. Both preserve coverage.

Cost claims agree with the actual implementation: O(log(k+1)) comparisons to locate p, O(k+1) worst-case list shifts/allocation per insertion, O(k+1) query copying, O(k) retained ranges and O(k+1) output/worst temporary storage. The baseline repeats sorting on queries; it is explicitly described as a reasonable competing tradeoff under the official query bound. The lesson does not falsely promise universally faster insertions. The maximum 5001 separated ranges follows from selecting alternate integers among 10001 values.
