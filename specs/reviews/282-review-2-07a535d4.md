## Findings

### L282-COST-001 (required, open)

- **Location:** `lesson-entry.json` complexity and step 05 complexity paragraph.
- **Reproduction:** Execute the actual canonical Python solver and inspect `dfs(index, expression, value, last)`. Every recursive child receives a newly concatenated immutable `expression` string, while each ancestor frame retains its own prefix until the child returns. A depth-n call chain therefore retains prefixes of lengths 1 through n, using Θ(n²) live auxiliary characters in the worst case (excluding the result list); `answer` is correctly separate output space.
- **Expected:** The rubric requires the stated time/space cost to describe the actual canonical solution and its labeled comparison.
- **Actual:** The lesson states `O(n)` recursion auxiliary space, which would fit a mutable path buffer plus stack, but this implementation uses immutable per-frame strings and has Θ(n²) auxiliary string storage along a deep path. Time `O(n·4ⁿ)` is consistent with expression construction/evaluation work.
- **Severity/reason:** Required correctness/cost finding under the Python-and-cost dimension; a basic reader may copy an undercounted memory guarantee.
- **Owner/next action:** Correct the complexity claim and explanatory text (or change the implementation to a mutable path representation), then submit a new candidate for focused independent re-review. Do not alter this frozen candidate during review.
