## Graph contract and repeated-node reasoning

The archived official statement permits arbitrary start/end and repeated nodes
and edges in a connected undirected adjacency-list graph, with 1≤n≤12. Its Python3
snippet matches `Solution.shortestPathLength(self, graph: list[list[int]]) -> int`.
The [canonical source](847-acceptance-20261026/solution.py) initializes all starting
nodes at distance 0, stores `(endpoint, visited_mask)` in `seen`, and stores distance
in the FIFO queue. Traversing an actual edge changes endpoint, ORs the neighbor
bit, and adds one move. Revisiting a vertex is legal: its mask can remain unchanged
while the endpoint changes. Only an already-seen *pair* is skipped.

The report explicitly explains why neither node-only nor set-only deduplication
is sound. The four-node star needs 1→0→2→0→3, revisiting center 0 for four edges;
node-only pruning prevents that cover. On a four-node path, the same visited set
{0,1,2} leaves costs 1 and 3 from endpoints 2 and 0 respectively. Equal pairs have the
same legal suffixes, and FIFO shortest arrival dominates later arrivals. The first
full mask dequeued gives the minimum; a singleton returns 0 immediately.

The UI intentionally records complete layers while Python can return within one
layer. The report verifies star new-pair counts 4/6/6/3/3 and cumulative counts
4/10/16/19/22, including a mask-preserving revisit. Teaching witnesses, cumulative
counts and layer instant are distinguished from all possible walks. Cost is
O((n+m)2^n) expected time and O(n2^n) auxiliary space; dense graphs give
O(n²2^n) time. Hash expectations and the bounded mask size are qualified.
