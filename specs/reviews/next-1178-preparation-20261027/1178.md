# #1178 Number of Valid Words for Each Puzzle

Official source: https://leetcode.com/problems/number-of-valid-words-for-each-puzzle/
The saved ordinary public response is HTTP 200, Hard, free, with full content,
metadata and available language templates.
Python3: `Solution.findNumOfValidWords(self, words: list[str],
puzzles: list[str]) -> list[int]`.
TypeScript: `findNumOfValidWords(words: string[], puzzles: string[]): number[]`.

## Original contract

For each puzzle, count input word entries that contain its first character and
whose every character occurs somewhere in the puzzle. Return counts in puzzle
input order. Word order is irrelevant to validity, and the mandatory character
may appear anywhere within a word. A word need not use every puzzle character.
Repeated word letters do not consume a finite stock of letters.

There are 1..100,000 words of length 4..50, and 1..10,000 puzzles. Every puzzle
has exactly seven distinct characters; all input characters are lowercase English
letters. Word characters may repeat. Neither word-list uniqueness nor puzzle-list
uniqueness is required by the stated constraints, so repeated entries must keep
their multiplicity/order. Do not use one-character word fixtures despite a valid
word's distinct-letter set being allowed to have size one: `aaaa` is legal.

## Hand-checked distinctions

The script scans each original word, checks required-character membership, and
checks each of its characters directly against the puzzle string. It uses neither
mask-frequency tables nor submask iteration to produce expected counts. Both
complete official examples are included. Other concrete cases are:

- Words `[aaaa, aaaa, aaab, abba, baab, bbbb]` give 5 for `abcdefg` and 4 for
  `bacdefg`. Duplicate entries and words sharing the same character set still
  contribute separately; grouping them cannot discard their frequencies.
- `[aaaa, aaab]` gives `[2,2,1,2]` for puzzles
  `[abcdefg, agfedcb, bacdefg, abcdefg]`. Reordering the other six letters changes
  nothing; changing the first letter can change validity. Capture that first
  letter before any canonical sorting. Repeated puzzle positions remain present.
- A 50-character all-a word and a 49-character repetition of `abcdefg` are valid
  for `abcdefg`. `abcdefgh` has eight distinct letters and is invalid; `zzzz` is
  also invalid. A word longer than seven characters is not automatically invalid.
- `[baaa, bbbb, cbbb, cccc]` gives `[1,3,2]` for
  `[abcdefg, bacdefg, cabdefg]`. The required letter need not be the word's first.
- `[aaaa,aabb]` contributes 2 for `abcdefg`, despite leaving many letters unused.

## Representation and enumeration proof obligations

Validity depends only on a word's distinct-letter set, but the requested answer
counts original word entries. If a future implementation groups equivalent sets,
it must preserve the number of entries in every group. A set with more than seven
distinct letters cannot fit any legal puzzle; rejecting by raw word length would
be incorrect. If using integer masks, the letter encoding must preserve set
membership/union rather than character multiplicity.

For a puzzle with first letter f and remaining six-letter set R, every valid
word-letter set W corresponds uniquely to `T = W - {f}`, a subset of R.
Conversely `{f} union T` is an eligible letter set for every subset T of R.
These maps are inverse, so there are exactly 64 eligible sets. The empty optional
subset is necessary: it accounts for words such as `aaaa`. Counting distinct
sets alone is insufficient; each eligible set contributes its word frequency.
This is a bijection argument, not an assertion that a particular submask loop
visits all sets once or terminates correctly.

A bounded check constructs all 64 sets containing a, creates two legal word
entries per set, and adds one eight-distinct-letter word. Direct scans over these
129 entries return `[128,64,0]` for `[abcdefg,bacdefg,hbcdefg]`. The middle result
includes the 32 sets also containing b, each with multiplicity two. This finite
check is independent of a bitmask implementation and does not certify one.

## Limits

The script was read and run: seven hand fixtures / 22 puzzle queries plus the
three 64-set construction queries passed. This small direct oracle is not proposed
for the full product of up to 100,000 words and 10,000 puzzles. No optimized lesson
implementation, full-size performance, UI design, author prompt injection,
independent learner review or acceptance is claimed.
