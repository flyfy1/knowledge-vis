- **Costs audited:** the baseline really enumerates n! full permutations and short-circuits pairwise checks, so O(n²·n!) is an upper bound. Canonical recursion scans n candidate columns per incomplete prefix with average O(1) set operations, giving O(n·V+S). Three sets plus recursion are O(n), with only an integer returned.
