## 冷走判定

当前实现可读、参数与阶段反馈清楚，但未达到用户要求的“像电流通电”的吸引力；应在现有 buck/boost 两节上 build 一个小型动态视觉样板，而不创建新产品或通用动画框架。目标用户是第一次探索转换器的学习者；立即任务是在拖动占空比后看到“哪些回路此刻通、储能如何变、输出为什么变”；最小有用结果是在手机同屏内辨别 buck OFF 续流、boost ON 储能与 OFF 向输出供能。

## 用户感知缺口

1. **路径不连贯**：亮色箭头是分散短段，不能让眼睛沿闭合回路追踪能量去向。Boost ON 的两条独立回路尤其需要同时可感知。
2. **因果没有留在舞台上**：拖D改变读数；电路本身没有D占比、储能/电容支路的动态反应。第一次推进仍处ON，电路看起来完全没变，用户可能误判按钮无效。
3. **说明、控制、回路分离**：手机输入控制下有多段模型说明，完整回路和输出读数在下面；拖滑杆时无法直接看到反应。
4. **电容机制只在文字中**：Buck充/放电由iC符号决定，不等同ON/OFF；目前图无可见的电容支路差异，读完长文字才懂。
5. **没有可控时间体验**：既没有实际通电感，也没有可见的教学时间/物理时间桥梁，不能用肉眼理解周期。

## 独立设计建议：条件通过，供 dispatcher 归档裁决

最高回报20%：在 buck/boost 各自建立“控制 → 全回路 → 阶段/储能 → 输出”同屏小闭环。保留现有课程/模型/入口；不拓展全站。

### P0：样板验收必要条件

- 完整导通路径使用静态强亮底轨 + 方向箭头；阻断路径保留暗线且在开关/二极管处明确断开。动态粒子或短虚线只能出现在当前实际通路，不跨开路或逆穿二极管。
- Buck OFF 的续流回路完整闭合；Boost ON 同时显示源→L→S和C→负载两个隔离回路；Boost OFF 显示源与L向输出供能。精确路径由science reviewer核验。
- 电容支路由当前q.ic的正、零、负决定方向；零时无净电流粒子。L储能随q.energy可感知变化，配固定位置“储能↑/放能↓”标签，避免仅靠颜色。采用连续采样时展示量仍来自同一模型时间。
- D滑杆直接改变PWM ON/OFF宽度、相位停留时间、稳态输出读数；Vin滑杆直接改变相关读数/能量幅度。参数变化明确为新稳态，历史清空，不暗示启动或控制器响应。
- 舞台附近写清“教学慢放；实际20kHz”；粒子为传统电流方向示意，运动速率不是电子真实速度，也不表示绝对电流。占空比不等50%时不可固定ON/OFF各半的教学时长。
- 手机320/390：全回路、阶段、关键输出可在同一舞台看见。不得仅删除min-width把所有16px SVG字压成约6px；应采用紧凑拓扑/标签布局、外置组件说明、必要时为手机独立几何。说明可折叠，但模型假设与时间语义要易找到。
- 单一明确的播放/暂停入口，逐步推进与重置语义一致；减弱动态偏好保留静态路径、箭头、阶段和读数。减弱后仍须有可观察的拖动反馈。
- EN/中全状态同等；固定布局避免阶段切换闪跳、滑杆失焦或页面滚动跳动；键盘可操作。

### P1：验证后可加

- 电感固定轮廓内用填充强度/稳定几何表示相对储能；电容旁以入/出箭头和充/放标签说明电流差。
- 阶段条与历史图游标共享时间，能让用户把“回路在换”和“曲线在涨/跌”联系起来。
- 开关接通允许一次不闪烁的短强调。必须由真实阶段边界触发，不能每次rerender重播。

### P2

- 可选电感静态磁场轮廓、一次性完成反馈。只有在核心路径和320px文字已清楚后考虑。

### Deferred

- 全站动画平台/更多课程同步修改：尚未验证样板收益。
- 真实20kHz可见闪烁、声效：不可感知且无教学价值；用明确标注的慢放。
- 电子漂移/真实载流子模拟、绝对电流对应粒子速度：当前理想集中参数模型不能支持该精度；需新物理模型与用户需求。
- 三维线圈/WebGL/外部素材：增加成本与设备负载，SVG已足够完成闭环；仅当手机实测证明必要再考虑。
- PWM音频/生产发布：不在当前样板验收范围。

## 样式与生命周期合同建议

复用现有 token：`--canvas:#0a0e14`、`--surface:#111826`、`--secondary:#0d1420`、`--border:#596d85`、`--ink:#e6edf6`、`--muted:#b1c0d2`、`--cyan:#67d7f9`、`--amber:#f5b04c`、`--green:#7ee2a8`、`--on-accent:#08131a`；不自行添加近似颜色。cyan通路/方向，amber当前阶段与储能变化，绿色只在确有独立语义时使用。文字正常可读，不把glow/blur覆盖到文字/控制上。组件轮廓与支路方向靠形状和文字，不只颜色。

用户明确要求动态视觉，因此可以有经过批准、仅在可见舞台运行的教学动画，作为技能默认“zero ambient loops”的有界例外。实现前必须指定稳定SVG identity、单一模型时间、播放与暂停、清理和取消策略。当前`updateConverter()`每次替换diagram.innerHTML（课程源在冷走结论后才读）；若保持该方式，CSS动画会在滑杆/resize时重播，且高频重建DOM不可接受。应保留稳定舞台或显式管理重建边界。

只允许一条拥有者清晰的clock/rAF驱动模型相位；locale、参数重置、reset、resize、页面隐藏、离屏、reduced-motion切换时不得遗留第二循环。离屏停止绘制，返回后的相位规则需明示；不能后台累计后突然快放。粒子装饰aria-hidden，避免高频aria-live播报。与现有进度/状态共享权威值，不能另立视觉时钟漂移。
