## Product fit and teaching judgment

The reader knows basic Python and needs to understand why pruning swaps still preserves an optimal route. The existing proof defines cycles but asks the reader to mentally instantiate the reassignment of identical letters. The proposal supplies that missing concrete experience without adding another algorithm or route. Its example already appears as preset F (`aabc → abca`), so clearly distinguish this **proof assignment** from the existing BFS experiment; neither should control the other.

The highest-return slice is the transition from the first snapshot to the second: token positions and actual string stay unchanged, while the two destinations change and the physical-swap counter stays zero. The following two real swaps supply a useful contrast. Four snapshots are enough; arbitrary input, a matching editor and animated graph machinery would add learning and implementation costs without helping this advisory.

Arithmetic and reasoning are sound. The destination arrays are `[3,0,1,2]`, `[0,3,1,2]`, `[0,1,3,2]`, `[0,1,2,3]`; their fixed-assignment costs are 3,2,1,0 and physical swaps spent are 0,0,1,2. Cost 3 belongs to an unnecessarily restrictive assignment, not the original problem's lower bound. Reassigning the two equal-letter destinations splits off an already-correct position legally. In a maximum-cycle assignment, the predecessor of the first mismatch is an eligible misplaced suffix position; physically swapping it splits off that mismatch. This is an existence argument, so retaining **all** eligible `j` remains essential. The example must not suggest choosing the leftmost candidate greedily.

A compact cycle list may accompany it, but may not replace the mapping. Reuse the specified tokens, 48px controls and 3px focus treatment. 3. **Keep the state small and separate.** Use one example-row index, preserved through the existing locale rerender. Existing `hand`, BFS `preset/at/frames`, prediction `selected/revealed`, and `copyState` remain independent. Make “Did any letters move?” a short pre-transition prediction prompt followed by the next snapshot's explanation; a second answer-selection/scoring system is unnecessary. Any added feedback state requires an explicit reset/locale contract rather than borrowing the existing quiz state.
4. **Translate the complete causal claim.** Both locales must say that reassignment moves no letters, costs zero physical swaps, and does not lower the original answer from 3 to 2. Both must retain the distinction between an eligible optimal choice existing and knowing which choice it is. The proposal's English general-proof discussion is review material, not a substitute for equivalent learner-facing Chinese.
