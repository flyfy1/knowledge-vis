# Computer Graphics

## Route
- slug: `computer-graphics`
- category: `computing`

## Causal contract
1. Rotation and scale transform a point in a new coordinate frame.
2. Integer stepping selects discrete pixels along a continuous line.
3. Diffuse brightness is `albedo × max(0, n·ℓ)`.

## Scope
A static 2D teaching model. It omits full GPU pipelines, antialiasing, shadows, indirect light and full ray tracing.
