# BRIEF：牛顿运动定律（newton-laws）· Newton’s Laws of Motion
- category `physics`，stage `senior`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：站内无牛顿定律专页；momentum-collision 讲动量，lever-pulley 讲杠杆，orbital-motion 讲轨道，核心不重合（<20%）。
- 核心直觉：a = F合/m：力加倍加速度加倍，质量加倍加速度减半；摩擦与重力分量先抵掉一部分，剩下的合力才加速；作用力与反作用力等大反向且作用在两个物体上。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **推与加速**
   - 已知：速度是位置对时间的变化；能读频闪图。
   - 唯一问题：推力变大，箱子的运动怎么变？
   - 输入与求量：输入 F（0–20 N），m=2 kg；求 a=F/m、3 s 末速度与位移。
   - 控件操作与预期观察：拖 F：残影间距增宽的速度变化；重放按钮让箱子按真实时间走 3 s。
   - 适用条件：无摩擦、质量恒定、力沿运动方向。
1. **质量的作用**
   - 已知：a=F/m 的第 0 步结论。
   - 唯一问题：同样的推，重的和轻的差在哪？
   - 输入与求量：输入 F、m；求 a 及质量加倍时的预测值。
   - 控件操作与预期观察：固定 F 改 m；m 加倍 a 减半，读数同时给出预测对照。
   - 适用条件：无摩擦、质量恒定。
2. **摩擦与合力**
   - 已知：a 由合力决定的想法。
   - 唯一问题：有摩擦时，推力还全部用来加速吗？
   - 输入与求量：输入 F（0–30）、μ（0–0.8），m=3；求摩擦力、合力、a、状态。
   - 控件操作与预期观察：加大 F：F≤μmg 时箱子不动，超过才加速；红橙箭头长度跟随。
   - 适用条件：静、动摩擦同一个 μ；忽略空气阻力。
3. **斜面**
   - 已知：力可以分解。
   - 唯一问题：斜面把重力的下滑“劲”变成多少？
   - 输入与求量：输入 θ（0–60°）、μ（0–1）；求 g sinθ、摩擦减速、a。
   - 控件操作与预期观察：加大 θ：绿色下滑分力变长、残影加速下滑；加大 μ：红色摩擦变长，直到卡住。
   - 适用条件：质点、平直斜面、μ 常数；a 与质量无关。
4. **作用力与反作用力**
   - 已知：力是对物体的推或拉。
   - 唯一问题：互相推开的两物体，各自加速度由什么决定？
   - 输入与求量：输入 F、两车质量；求 a₁、a₂、速度、总动量、a 比与质量反比。
   - 控件操作与预期观察：改任一质量：轻车跑得远；动量读数两侧等大反向，总动量 0。
   - 适用条件：无摩擦轨道，推开 0.5 s 后匀速。
5. **电梯里的秤**
   - 已知：F=ma 与重力。
   - 唯一问题：秤读的是什么，为什么会变？
   - 输入与求量：输入体重 m（40–100 kg）、电梯加速度 a（−9.8…6）；求 N=m(g+a)。
   - 控件操作与预期观察：向上加速读数高于体重线，向下加速低于，a=−9.8 为 0；终章含回顾与 3 条互链。
   - 适用条件：电梯质点模型、g 恒定。

## 模拟设定与模型失配
质点、恒定质量、静摩擦与动摩擦取同一个 μ、g=9.8、不计空气阻力。频闪间隔 0.5 s 与重放时钟是教学表示，重放按真实 1:1 时间；所有数字由 flatForces、slope、pushApart、scaleReading 纯函数给出。真实摩擦随速度和接触面变化，真实秤读的是弹簧压缩而非“重力”。

## 技术
纯静态零依赖；读数全部由 app.js 中的纯函数按当前参数实时计算（探针独立手算核对）；中英文字典键集一致；canvas 文字经 t()；DPR/resize 幂等；播放类控件可重放、减弱动态时直接显示终态、页面隐藏时停止。
