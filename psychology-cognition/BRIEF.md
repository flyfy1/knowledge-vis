# Psychology & Cognition · build brief

Four-step bilingual teaching model: working-memory capacity, attention bottlenecks, encoding/retrieval cues, and proactive/retroactive interference.

- Core API: memoryRecall, attentionAccuracy, retrievalProbability, interferenceRisk.
- Scope: a teaching model for intuition, not an intelligence test, clinical tool, diagnosis, or treatment recommendation.
- Validation: node tests/core.cjs, node --check app.js, and browser smoke for sliders, language, and quiz.
