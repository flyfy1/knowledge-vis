# BRIEF：驻波（standing-wave）· 高中物理

## 定位
- slug `standing-wave`，category physics，stage senior。受众：高中生 + 家长。前置：正弦波的波形与读法（站内三角页）、干涉页的叠加概念（本页自足交代，不假设读过）。
- 核心直觉一句话：**两列一模一样、迎面跑的波叠加，波形不再奔跑，而是原地起伏：每个点的振幅被一条不动的包络定死——包络压到零处是永远不动的波节，顶到 2A 处是波腹；把弦两端钉死，边界条件只放行 L=nλ/2 的波长，频率因此排成整数台阶，外力踩中台阶就是共振**。
- **与干涉页的分工（写文案时不得越界互抄）**：干涉页讲**两个波源、同向传播的二维空间图样**——判定量是观测点到两源的**路程差**，产物是空间里不动的双曲线族；本页讲**一列波与它自己的反向同伴在一维上迎面叠加**——判定量只是**位置 x**（在包络上站在哪），产物是**时间里的原地振动**：图样不在空间里铺开成族，而是同一根弦上每点振幅不同、波形不迁移。两页静点机理不同：干涉页静点源于两源路程差恒为半整数倍波长；本页波节源于两列反向波在该点每一刻都恰好互为相反数。正文首次提干涉时按规则 12 深链并用一句话点明这个分工（见终章互链），除此之外不复述路程差/双曲线内容。
- 已知：正弦曲线、波长 λ/振幅 A/周期 T 的读法、一列波每点位移随时间按正弦变化。唯一新问题：一列波迎面撞上它自己的反向同伴，为什么波形会「停下来」原地振动，而且有的点永远不动、频率还会被弦长筛成整数台阶？

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **对跑叠加现场**：已知：一列简谐波向右跑，每点位移 y₁=A·sin(ωt−kx)（k=2π/λ，本页 T、A 沿用干涉页口径，数值在页内自足交代；正弦波形从哪来在首现处深链 ../trig/#step2「把身高摊开，就是正弦波」）。唯一问题：再放一列一模一样、迎面跑来的 y₂=A·sin(ωt+kx)，叠起来每一点怎么动？输入：两列波方程与 A、λ；求量：合位移随位置与时间的图样。控件：一条水平绳的侧面视图动画，两列分量波以两色半透明可分别显隐（开关：只看右行 / 只看左行 / 看合成），合成波形为粗线；在当前波峰处留一个位置标记（参考竖线），播放/暂停；拖观测点 P 看其位移—时间小图。预期观察：合成后波峰**不左右迁移、只原地升降**（标记处波峰始终在同一 x 附近起伏，与第 0 步干涉页「纹在跑」形成对照）；有的点振幅比 A 还大、有的点纹丝不动；P 仍按正弦振动但振幅随位置而异。结论：合位移 y=y₁+y₂=**2A·cos(kx)·sin(ωt)**——「空间包络 × 时间振动」可以拆开：包络决定每点振多高、sin(ωt) 决定全体何时一起到顶。适用：两列波同频、同幅、反向、简谐，线性叠加。
2. **波节与波腹：振幅由包络实算**：已知第 1 步的包络因子 2A·cos(kx)。唯一问题：哪些点永远不动、哪些点振幅最大、任意一点的振幅怎么算？输入：位置 x 与 λ；求量：该点振幅 A(x)=2A·|cos(kx)|。控件：包络线（虚线 ±2A·cos(kx)）叠印开关（动画继续时包络纹丝不动）；拖 P 沿绳移动，读数给 x、x/λ、A(x) 实算值，并与 P 的位移—时间曲线实测极值当场对账；预设钮「把 P 放到波节（x=λ/4）」「把 P 放到波腹（x=0）」。命名就近落地：A(x)=0 的点叫**波节**（位置 x=(2m+1)λ/4，m=0,1,2…），A(x)=2A 的点叫**波腹**（x=mλ/2）；相邻波节间距 λ/2、波节与相邻波腹间距 λ/4，图上标出。预期观察：拖 P 时读数 A(x) 与包络高度处处吻合、与时序极值对账一致；波节处时序曲线压成直线。结论：驻波每点的振幅 = 包络在该点的高度，与时间无关；除波节外每点同相振动、跨过一个波节相位翻转 π（hint 一句带过即可）。适用：同第 1 步条件。
3. **弦两端固定：边界把波长筛成台阶**：已知第 2 步包络与波节位置。唯一问题：把这段绳换成两端钉死的弦（x=0 与 x=L 必须永远是波节），什么样的波长还能存在？输入：弦长 L 与试探波长 λ；求量：能成立的 λ 的集合。机理须一句话交代因果：弦上的波跑到固定端反射回来，**固定端把端点钉住、位移恒为 0，反射波相对入射波相位翻转 π**，去程与反射程叠成的驻波包络因此改写为 2A·|sin(kx)|、波节落在 x=mλ/2（两端天然是波节）；再要求 x=L 也是波节，得 **L=n·(λ/2)**，n=1,2,3…。控件：拖 L 滑杆与拖 λ 滑杆两路；当 L/(λ/2) 不是整数时，图上画出该 λ 的包络在 x=L 处的非零位移并标红提示「这个波长住不下：右端被包络要求振动，但它被钉死了」；恰为整数时整弦亮起并标「模式 n 成立」；「吸附到最近台阶」钮把 λ 跳到最近的 2L/n。读数给 L、λ、q=L/(λ/2)、最近整数 n 与偏差 |q−n|。预期观察：连续拖 λ 时只有离散台阶处全弦成立——波长被弦长筛成离散集合 λ_n=2L/n。结论：两端固定的弦只允许 λ_n=2L/n 的驻波**模式**；离散性来自边界条件，不是波自己的偏好。适用：理想弦——均匀、两端刚性固定、波速恒定。
4. **谐波族：同一根弦的整数台阶**：已知第 3 步的模式条件 λ_n=2L/n。唯一问题：这组模式排成一列长什么样、对应的频率是什么关系？输入：定长 L、波速 v（页内给定并明说：v 由弦的张紧程度与粗细决定，本页取定值、是模拟设定）；求量：各模式频率 f_n。控件：模式钮 n=1…5 一键切换，整弦形状按 sin(nπx/L) 实算动画；叠印对比开关（n=1 与当前 n 同图比节点数）；读数给 λ_n=2L/n、f_n=v/λ_n、f_n/f₁、波节数（n+1，含两端）、波腹数（n）。命名就近落地：n=1 是**基频**（基波），n≥2 是**谐波**（第 n 次谐波）；泛音只一句纯文本带过：乐器音色由各次谐波的配比决定，本页不展开。预期观察：n 每加 1，弦上多一个波节、频率恰翻一整数倍——形状与频率两本账都是整数台阶。结论：f_n=n·f₁（f₁=v/2L）；模式的形状、节点数、频率全部由同一个 n 数清。适用：同第 3 步理想弦、v 取定值。
5. **共振：外力踩中台阶**：已知第 4 步的固有频率族 f_n=n·f₁（**固有频率**首现就近定义：系统自己能稳定振动的那些频率）。唯一问题：在弦一端用很小的力以频率 f 持续强迫振动，什么时候振幅会长到很大？输入：驱动频率 f（可调）；求量：稳态振幅的响应。控件：驱动频率滑杆连续扫过 f₁、2f₁、3f₁；扫到某 f_n 附近时整弦点亮成对应模式形状、振幅读数冲峰，偏离即塌；响应曲线（横轴 f、纵轴稳态振幅）在曲线上标出实算的 f_n 峰位。**模型口径必须明说**：峰位 f_n 由第 4 步公式实算，峰高与峰宽是示意参数（取决于阻尼，本页取小阻尼定值），不是实测数据——按 SPEC 清晰度 §8 在读数旁注明「示意模型」；阻尼变大则峰变矮变宽，定性一句。秋千类比只许一句（如「像推秋千：每一下都踩在它自己摆动的节拍上，劲才攒得起来」），删掉它因果仍须完整（SPEC §6）。预期观察：只有 f 命中某个 f_n 时振幅显著增大、且弦形正是那个模式——共振是「选模式」，不是「越大力越响」。结论：**共振** = 驱动频率等于某个固有频率时振幅显著增大。适用：小幅驱动、阻尼较小；驱动点不在该模式波节上（一句条件即可，不展开）。
6. **自测**（每题判定必须借页面纯函数实算，不得写死答案文案）：①λ=4（单位长度）的驻波，x=1 处是波节还是波腹？（波节——以 A(1)=2A·|cos(2π/λ·1)|=0 判定）；②两端固定的弦 L=6，能存在的最长波长是多少？（λ₁=2L=12——以第 3 步模式口径 q 判定）；③判断题「波节处没有波传到，所以不动」（错：两列波都到达波节、每一刻位移恰好互为相反数——与干涉页静点同理，一句回指）；④弹吉他时按住弦的中点（发声长度减半），基频变为原来的几倍？（2 倍——以 f₁=v/2L 实算对账）。
7. **终章**：三卡（对跑叠加生出包络 / 波节波腹由包络定死 / 边界筛出整数台阶、共振是踩中台阶）+ 互链区（规则 12，锚点已按 CONCEPT-MAP 与实页核对）：①../interference/#step1「干涉：两个波源、路程差定加强与抵消——那是空间里的强弱图样；本页是一列波迎面撞上自己的反向同伴，是时间里的原地振动」；②../interference/#step2「干涉的稳定图样：双曲线族——与本页一维的驻波包络对照看」；③../trig/#step2「正弦波从哪来：圆的侧影摊开成波——本页两列对跑的波都是它」。纯文本埋线一句：管乐器是空气柱里的驻波，一端封闭时台阶换成 λ/4 的奇数倍，在声音线展开，本页不链。

## 判定口径（写死，构建与评审都按此对账）
- 合位移一律由两列波方程实算 y=A·sin(ωt−kx)+A·sin(ωt+kx)，解析对照恒等式 2A·cos(kx)·sin(ωt)：多位置多时刻采样，两式数值差 <1e-9，不得用示意幅度冒充。
- 波节/波腹判定：波节处任意时刻 |y|<1e-9（解析恒零点采样多时刻）；波腹处时序极值 =2A（采样容差内）；任意点振幅读数 A(x)=2A·|cos(kx)|（第 3 步起弦坐标改用 2A·|sin(kx)|，改元原因已在第 3 步正文交代）与该点时序实测极值对账差 <1%。
- 模式判定：q=L/(λ/2)；|q−round(q)|≤0.02 且 round(q)≥1 时判「模式成立」、n=round(q)；恰在台阶上时 sin 包络在两端及全部内部波节处位移恒 0（采样验证）；离台阶时右端包络值非零量须如实画出、不得吸附造假（吸附只经「吸附到最近台阶」钮显式触发）。
- 频率账：f_n 由 v 与 λ_n=2L/n 实算，f_n/f₁ 与整数 n 的差 <1e-9；波节数/波腹数由当前 n 直接数清并与图上计数一致。
- 共振响应：峰位 = 实算 f_n；峰高/峰宽为示意参数，读数与正文必须标注「示意模型、非实测」，不得把示意峰高写成定律断言。
