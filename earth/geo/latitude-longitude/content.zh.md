## 怎样用两个数，说出地球表面上任意一个地方？ {#step0 h2=s0t}

::: strings
nav0: 0 两个角度
:::

第 0 步 · 两个角度 {#s0k .step-kicker i18n=text}

这一步要回答：为什么两个角度就能定位地球上任何一个点？**纬度**是从赤道向北或向南量的角度（0°–90°），纬度相同的点连成与赤道平行的圈，叫纬线；**经度**是从本初子午线（经过英国格林尼治）向东或向西量的角度（0°–180°），经度相同的点连成从北极到南极的半圆，叫经线。选一个城市，或拖滑杆设定纬度、经度，再拖「转动地球」看另一面。 {#s0e .explain}

::: html step0-1
s0stage: 地球（从斜上方看）：每 30° 画一条纬线和一条经线；橙点是所选的点，橙色弧线是它所在的纬线和经线；城市位置为近似值
s0canvas: 带经纬网的地球仪：所选点由所在的纬线和经线交叉定位
s0city: 选一个城市
s0lat: 纬度（北为正）
s0lon: 经度（东为正）
s0view: 转动地球（视角经度）
:::

结论：纬度 + 经度 = 一个确定的点；北极南极的经线汇在一点，所以极点处经度没有意义。条件：地球近似球体；城市坐标取近似值。 {#s0result .readout i18n=text}

::: strings
s0ro: {name}：{lat}，{lon}。在纬线（离赤道 {la}°）与经线（离本初子午线 {lo}°）的交叉处。
s0hid: （这个点现在在地球背面，转动地球就能看到。）
:::

## 一度经度到底有多远，各个纬度一样吗？ {#step1 h2=s1t}

::: strings
nav1: 1 越往北圈越小
:::

第 1 步 · 越往北圈越小 {#s1k .step-kicker i18n=text}

这一步要回答：沿纬线走 1° 经度，距离在赤道和在高纬度一样吗？纬线圈的周长是 2πR·cos φ（R ≈ 6371 km 是地球半径，φ 是纬度），越靠近极点圈越小，所以 1° 经度对应的实际距离也越短；而 1° 纬度（沿经线走）到处都约 111 km。拖纬度，看被高亮的纬线圈和读数。 {#s1e .explain}

::: html step1-1
s1stage: 左：高亮的橙色圈是所选纬度的纬线；右：cos φ 曲线（纬线周长与赤道的比例），橙点是当前纬度
s1canvas: 地球上的一条高亮纬线和 cos 曲线：纬度越高纬线圈越小
s1lat: 纬度（北为正）
:::

结论：1° 纬度处处约 111 km，1° 经度 = 111.2 km × cos 纬度，在极点缩为 0。条件：把地球当作半径 6371 km 的球体；真实地球略扁。 {#s1result .readout i18n=text}

::: strings
s1ro: 纬度 {lat}°：这条纬线一圈长 {len} km（赤道的 {pct}%）；沿它走 1° 经度约 {dlon} km，而沿经线走 1° 纬度约 {dlat} km。
:::

## 把球面摊成长方形地图，哪里会被拉变形？ {#step2 h2=s2t}

::: strings
nav2: 2 剥橘子皮
:::

第 2 步 · 剥橘子皮 {#s2k .step-kicker i18n=text}

这一步要回答：球面不能不变形地摊平，那变形发生在哪里？想象把地球像橘子皮一样剥开：每条纬线的真实长度是 2πR·cos φ，所以「橘子皮」两侧是弯的（图上拖到最左）；如果硬要摊成矩形的世界地图，每条纬线都得被拉到赤道那么长，高纬度处横向被拉伸的倍数是 1 / cos φ。拖「摊平程度」，看橙色的圆（球面上真实的圆）被拉成了什么样。 {#s2e .explain}

::: html step2-1
s2stage: 地图：横轴经度、纵轴纬度；左端是橘子皮（每条纬线保持真实长度），右端是矩形地图；橙色椭圆是球面上同样大小的圆被拉伸后的样子
s2canvas: 地球摊平的过程：橘子皮形状逐步拉成矩形，高纬度的圆被横向拉长
s2u: 摊平程度（0 橘子皮 → 100 矩形）
s2lat: 被观察的圆所在纬度
:::

结论：矩形世界地图把高纬度地区横向拉大 1/cos φ 倍，所以格陵兰看起来比实际大得多；任何平面地图都要在形状、面积、距离中取舍。条件：这里比较的是「橘子皮（正弦）」和「等距矩形」两种摊法，还有许多别的投影。 {#s2result .readout i18n=text}

::: strings
s2ro: 摊平程度 {u}%：在纬度 {lat}°，横向被拉伸为真实的 {k} 倍，面积被放大为 {k} 倍。
s2none: 还没拉伸：每条纬线都保持真实长度，圆还是圆（但地图边缘是弯的）。
:::

## 两个城市之间，最短的路在地图上为什么是弯的？ {#step3 h2=s3t}

::: strings
nav3: 3 走哪条路最近
:::

第 3 步 · 走哪条路最近 {#s3k .step-kicker i18n=text}

这一步要回答：在球面上两点之间的最短路线是什么，为什么在矩形地图上看是弯的？球面上最短的路是过这两点和球心的平面截出的圆弧，叫**大圆航线**，长度用半正矢公式（haversine）算。如果在矩形地图上直接用度数当平面坐标去量，会得到偏大的距离。选两个城市，比较两个数。 {#s3e .explain}

::: html step3-1
s3stage: 上：地球上的两城市和大圆路线（橙）；下：矩形地图——橙色曲线是大圆航线，灰色虚线是在地图上直接连的直线
s3canvas: 两个城市之间的大圆航线：球面上是最短的圆弧，在矩形地图上是弯曲的
s3a: 出发城市
s3b: 到达城市
:::

结论：球面最短路是大圆弧；矩形地图上的直线并不最短，尤其在高纬度和跨经度大时差别明显。条件：球形地球（R = 6371 km），不含地形与航空管制；「按度数量」是把 1° 都当成 111.2 km 的粗略做法。 {#s3result .readout i18n=text}

::: strings
s3ro: {a} → {b}：大圆距离 {gc} km；把地图当平面、直接按度数量得 {flat} km，差了 {diff}%。
s3same: 出发和到达是同一个城市，距离为 0。
:::

## 为什么往东走，时间会变早？ {#step4 h2=s4t}

::: strings
nav4: 4 经度与时间
:::

第 4 步 · 经度与时间 {#s4k .step-kicker i18n=text}

这一步要回答：经度和时间有什么关系？地球 24 小时自转 360°，所以每 15° 经度对应 1 小时。**地方太阳时**是以太阳正在头顶的时刻为正午的时间：世界时（UTC，本初子午线的时间）加上 经度 ÷ 15。拖世界时，看白天和黑夜的分界怎样在地图上向西移动；选一个城市看它的地方太阳时。 {#s4e .explain}

::: html step4-1
s4stage: 矩形地图：亮的一半是白天（假设春秋分，太阳直射赤道），暗的一半是夜；橙色竖线是正午所在的经线；点是各城市
s4canvas: 世界地图上的昼夜分界随世界时向西移动，每 15° 经度差 1 小时
s4utc: 世界时（UTC）
s4city: 城市
:::

结论：经度每向东 15°，地方太阳时多 1 小时；白天夜晚的分界随地球自转西移。条件：用「春秋分、地方太阳时」简化，真实时区按国家和地区规定，夏令时与季节也会改变昼夜分界的形状。 {#s4result .readout i18n=text}

::: strings
s4ro: 世界时 {utc}：正午在东经 {noon}°；{city}（{lon}）的地方太阳时 {local}，{dn}。
s4day: 那里是白天
s4night: 那里是夜里
:::
