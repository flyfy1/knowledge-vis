## 两种波速度不同，一前一后，差多少就是多远 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 P 波与 S 波
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 先到的与后到的
:::

这一步要回答：怎样从一张地震图读出震源有多远？地震发出两种体波（穿过地球内部的波）：**P 波**是压缩波（质点沿传播方向前后挤压），速度较快；**S 波**是剪切波（质点垂直于传播方向横向摆动），速度较慢，也更强。这里在地壳中取 vₚ = 6.5 km/s、vₛ = 3.7 km/s（近似值）。同时出发，距离 d 处的到达时间差 Δt = d·(1/vₛ − 1/vₚ)，每 1 km 约 0.116 s，所以 Δt 越大震源越远：d ≈ 8.6 km/s × Δt。**观察：**拖动距离，点「重放」让地震图一点点写出来；青线标 P 到达，橙线标 S 到达，绿色横条是 S−P 时间。这是理想化的示意波形，不是实测记录。 {#s0e .explain}

## 知道各台站的距离，怎样找到震中？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 三个台站定震中
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 用距离画圆
:::

这一步要回答：一个台站只告诉你“多远”，不告诉你“哪个方向”，怎样确定震中位置？每个台站由 S−P 时间算出距离，以台站为圆心画一个圆，震中一定在圆上；三个台站的三个圆交于一点，就是震中（红点）。**观察：**拖动震中位置，三个圆始终相交于红点；再增大“计时误差”（假定三个台站的 S−P 各有 +、−、+半的偏差），三个圆不再交于一点，出现一个小三角形——这就是定位不确定度，台站越多越准。这里是平面近似，震中和台站都在地表平面上，每个台站的 S−P 来自第 0 步的公式。 {#s1e .explain}

## 为什么地震波不走直线？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 波线在地球里拐弯
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 波在地球里拐弯
:::

这一步要回答：地球内部的波线为什么是弯曲的？地球内部越深，P 波速度通常越快；像光从空气进入水一样，速度变化使波线折射（[[reflection-refraction#step1|折射定律]]）。球层中的折射有个守恒量：射线参数 p = r·sinθ/v，沿着射线保持不变。因此波线向速度更快的深处走时，会逐渐**向上弯曲**，最后回到地面。从震源（红点）以不同出射角射出的波线，到达地表的位置（小点）沿弧线散开；而那些深到**核幔边界**（深度 2891 km）的射线，会进入速度突然变慢的外核，被大幅折射。**观察：**拖动出射角，白色粗线是那条波线，读数给出它的落点角距、走时和最深深度；注意地表小点之间出现的空缺，也就是“影区”。这里是简化的 P 波速度模型，只追踪透射波。 {#s2e .explain}

## 为什么有的地方收不到某种波？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 影区与液态外核
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 影区与外核
:::

这一步要回答：为什么在地球另一侧某些距离收不到直达 P 波，S 波更是完全收不到？P 波射线进入外核后大幅折射，落在较远处，所以直达 P 波在 104° 到 140° 左右的距离出现**影区**（本简化模型约 93°–113°，数值不同）。S 波是剪切波，在液体里不能传播，所以到不了外核——S 波影区从约 103° 起一直延伸到对面。观测中 S 波这样消失，正是**外核是液体**的证据；而 P 波穿过地核后以 PKP 的名字重新出现。**观察：**切换 P 波/S 波，拖动台站的角距离：看这个距离上能不能画出落点；读数给出到达的震相和走时。 {#s3e .explain}

## 震级加 1，能量多多少？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 震级与能量
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 震级与能量
:::

这一步要回答：为什么震级相差不大，破坏力却相差悬殊？**震级** M 是一个对数标度：地震仪记录的最大振幅每增大到 10 倍，震级增加 1。释放的能量按经验公式 E ≈ 10^(1.5M + 4.8) 焦耳，震级每增加 1，能量约增加 31.6 倍（10^1.5）；所以震级差 2 就是约 1000 倍能量。**观察：**拖动震级：青线（振幅，每格 10 倍）和橙线（能量，每格 31.6 倍）的斜率不同；读数换算成 TNT 当量作参照。这是经验公式，不同地区、不同震级标度略有差异。 {#s4e .explain}

## 看到 S−P，你能说出震中多远吗？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 读震相
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 读一张震相
:::

这一步要回答：给你一张地震图，怎么估震中距？图上青色和橙色标记已经去掉了数值：请读出 P 波（小的、先到）和 S 波（大的、后到）的起点，用时间轴（每格 10 秒）估计 S−P，再用第 0 步的关系 d ≈ 8.6 km/s × (S−P) 拖动估计距离，点「检查」。误差在 ±8% 以内算对。「换一张」会清除你的估计与检查状态。**观察：**先看到 P 的小抖动，再看到明显增大的 S；两者间隔越大距离越远。 {#s5e .explain}
