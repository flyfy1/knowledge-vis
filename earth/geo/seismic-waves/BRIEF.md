# BRIEF：地震波探地心（seismic-waves）· Seismic Waves Probing the Earth’s Core
- category `earth`，stage `senior`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：geology-plate-tectonics 讲板块边界与地震的野外证据（4 步），不含波的传播；reflection-refraction 讲折射。本页是地震波如何探测内部结构，核心不同。
- 核心直觉：P/S 波速不同，S−P 给距离；三圆交会定震中；射线参数守恒使波线弯曲；P 影区与 S 波被液态外核挡住；震级对数标度。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **P 波与 S 波**
   - 已知：波与速度。
   - 唯一问题：怎样从地震图读出震源距离？
   - 输入与求量：输入 d（20–600 km）；vP=6.5、vS=3.7；求 S−P 与反推距离。
   - 控件操作与预期观察：拖 d、重放 6 s 写出地震图；青 P、橙 S、绿 S−P。
   - 适用条件：地壳恒定波速的近似。
1. **三个台站定震中**
   - 已知：S−P 距离。
   - 唯一问题：怎样确定震中方向？
   - 输入与求量：输入震中 (x, y)、计时误差；求三个台站的 S−P 与距离圆。
   - 控件操作与预期观察：拖震中：三圆交于红点；加误差出现小三角形。
   - 适用条件：平面近似；误差系数 +1/−1/+½。
2. **波线在地球里拐弯**
   - 已知：折射定律。
   - 唯一问题：为什么波线不走直线？
   - 输入与求量：输入出射角 1–89°；求落点角距、走时、最深深度与射线扇空缺。
   - 控件操作与预期观察：拖角度：白线为所选射线；扇中青=只穿地幔、橙=穿地核；小点间有空缺。
   - 适用条件：简化 P 波速度分层，只追踪透射波。
3. **影区与液态外核**
   - 已知：射线扇。
   - 唯一问题：为什么有的距离收不到某种波？
   - 输入与求量：输入 P/S 切换与台站角距离 0–180°；求到达震相与走时。
   - 控件操作与预期观察：切 P/S、拖角距：S 在核幔边界被挡（>~104° 无）；P 影区；PKP 重新出现。
   - 适用条件：模型影区约 93–113°（真实约 104–140°）。
4. **震级与能量**
   - 已知：对数。
   - 唯一问题：震级差 1，能量差多少？
   - 输入与求量：输入 M（2–9.5）；求 E=10^(1.5M+4.8) J 与 TNT 当量。
   - 控件操作与预期观察：拖 M：振幅线每级×10，能量线每级×31.6。
   - 适用条件：经验公式。
5. **读震相**
   - 已知：第 0 步公式。
   - 唯一问题：看到 S−P 能估多远吗？
   - 输入与求量：输入估计距离 20–800 km；检查 ±8%；换一张。
   - 控件操作与预期观察：检查给反馈；换一张清除估计与检查状态；终章含回顾与 3 条互链。
   - 适用条件：5 张预设图。

## 模拟设定与模型失配
一维球对称粗略速度分层，只追踪透射波（忽略反射、衍射、内核 S 波），影区角度与真实地球不同（页面如实说明）；示意地震图非实测；探针独立核对 S−P 公式、能量公式、射线参数、射线扇空缺与 S 波不进入外核。
