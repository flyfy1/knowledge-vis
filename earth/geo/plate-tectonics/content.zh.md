## 地球不是一整块壳 {#step0 h2=s0t}

::: strings
nav0: 0 先看地图
:::

第 0 步 · 先看地图 {#s0k .step-kicker i18n=text}

岩石圈像一块块硬壳，漂在会缓慢流动的软流圈上。板块每年只走几厘米，却能在百万年尺度上打开海洋、抬起山脉。拖动下方时间，观察同一条边界如何积累地质后果。 {#s0e .explain}

::: html step0-1
time: 地质时间
start: 开始探索 ↓
:::

## 同一股热，三种走向 {#step1 h2=s1t}

::: strings
nav1: 1 三种边界
:::

第 1 步 · 三种边界 {#s1k .step-kicker i18n=text}

选择边界类型，再改变板块速度。分离会造新壳，汇聚会消耗旧壳，错动则把应力锁在断层两侧。动画中的箭头是相对运动，颜色是最常见的地表结果。 {#s1e .explain}

::: html step1-1
divergent: 分离 · Divergent
convergent: 汇聚 · Convergent
transform: 转换 · Transform
:::

提示：把速度调到 0，再想一想为什么“没有地震”不等于“没有应力”。 {#s1h .hint i18n=text}

## 慢，不代表没有力量 {#step2 h2=s2t}

::: strings
nav2: 2 速度与热量
:::

第 2 步 · 速度与热量 {#s2k .step-kicker i18n=text}

板块速度决定单位时间搬运多少面积；地幔热流决定岩石有多容易变形。两个旋钮共同改变三条可观测量：海底扩张、应力积累与火山活动。先猜，再拖杆验证。 {#s2e .explain}

::: html step2-1
speed: 板块速度
heat: 地幔热流
spread: 海底扩张
stress: 应力积累
volcano: 火山活动
:::

模型是教学用的相对量：它刻意把“速度 × 时间”和“热量 → 可变形性”放在同一张账本里，帮助你看见因果方向，而不是给出真实预测。 {#s2h .hint i18n=text}

## 从箭头走到野外证据 {#step3 h2=s3t}

::: strings
nav3: 3 证据链
:::

第 3 步 · 证据链 {#s3k .step-kicker i18n=text}

把三种可见证据连回机制。点击卡片，检查它由哪一种边界驱动；再点“重新组合”，看看你能否用三条证据讲出一个完整故事。 {#s3e .explain i18n=text}

::: html step3-1
shuffle: 重新组合证据
check: 检查我的连接
:::

板块构造的核心不是“地表在移动”这句口号，而是一个可检验的闭环：**热量驱动流动 → 边界改变岩石圈 → 岩石记录运动**。 {#finale .finale}
