## 北半球的夏天，地球是离太阳最近的时候吗？ {#step0 h2=s0t}

::: strings
nav0: 0 离得近就热？
:::

第 0 步 · 离得近就热？ {#s0k .step-kicker i18n=text}

这一步要回答：夏天热，是因为地球那时离太阳更近吗？地球绕太阳一圈叫**公转**，一圈约 365 天，轨道是一个很扁的椭圆。**天文单位 AU** 是日地平均距离（约 1.5 亿千米）。拖日期，看日地距离怎么变，再看北半球那时是什么季节。 {#s0e .explain}

::: html step0-1
s0stage: 上：按真实比例的轨道（几乎是正圆），橙点是地球；下：日地距离随日期的曲线（纵轴放大了很多倍才看得出来）
s0canvas: 地球轨道图和日地距离曲线：距离一年只变化约 3%，最近在 1 月初
s0day: 日期
s0play: 让一年转起来
:::

结论：日地距离一年只变化约 ±1.7%，最近在 1 月初（北半球冬天），最远在 7 月初（北半球夏天）——距离不是季节的原因。条件：用近似公式 r = 1 − 0.0167 cos(2π(N − 2)/365.25) AU，N 是从 1 月 1 日起的天数。 {#s0result .readout i18n=text}

::: strings
s0pause: 暂停
s0ro: {date}：日地距离 {au} AU（{mkm} 百万千米）；{note}
s0near: 这时离太阳比较近，可北半球偏冷——所以季节不是由距离决定的。
s0far: 这时离太阳比较远，可北半球偏热——同样说明季节不是由距离决定的。
s0mid: 这时日地距离接近平均值。
:::

## 地轴斜着，绕太阳一圈时会发生什么？ {#step1 h2=s1t}

::: strings
nav1: 1 斜着的地轴
:::

第 1 步 · 斜着的地轴 {#s1k .step-kicker i18n=text}

这一步要回答：地球绕太阳转，地轴的朝向有什么特点，它怎样让太阳直射点来回移动？**地轴**是地球自转的假想转轴，它和公转轨道面的垂线之间有约 23.4° 的夹角，而且一年里始终指向同一个方向（几乎指向北极星）。所以公转到不同位置，北半球有时朝向太阳、有时背向太阳。**太阳直射点的纬度**（也叫赤纬 δ）就是太阳正好在头顶的那条纬线。拖日期或按播放。 {#s1e .explain}

::: html step1-1
s1stage: 斜视图：椭圆是公转轨道（纵向压扁了），太阳在中间；每个地球的亮面朝向太阳，直线是地轴（方向永远不变），N 是北极
s1canvas: 地球绕太阳公转的斜视图：地轴方向不变，不同位置北半球朝向或背离太阳
s1day: 日期
s1play: 让一年转起来
:::

结论：一年里直射点在北纬 23.4° 与南纬 23.4° 之间往返一次；地轴倾斜 + 方向不变是原因。条件：用近似 δ = ε·sin(2π(N − 79.5)/365.25)，ε = 23.44°；地轴方向的缓慢进动忽略。 {#s1result .readout i18n=text}

::: strings
s1pause: 暂停
s1ro: {date}：太阳直射点在纬度 {dec}°{ns}；{tilt}
s1toN: 北半球朝向太阳。
s1toS: 南半球朝向太阳。
s1eq: 两个半球受到的照射差不多（接近二分日）。
:::

## 同一个地方，夏天和冬天正午的太阳一样高吗？ {#step2 h2=s2t}

::: strings
nav2: 2 正午太阳多高
:::

第 2 步 · 正午太阳多高 {#s2k .step-kicker i18n=text}

这一步要回答：正午时太阳离地平线多高，和季节有什么关系，为什么这决定冷热？正午太阳高度 h = 90° − |纬度 − 直射点纬度|。太阳越高，同样一束阳光铺在地面上的面积越小，单位面积受热越多：相对强度 ∝ sin h。选纬度、拖日期，看太阳高度和曲线。 {#s2e .explain}

::: html step2-1
s2stage: 上：站在所选纬度看正午的太阳（虚线是地平线）；下：一年中正午太阳高度的曲线，橙点是所选日期
s2canvas: 正午太阳的高度示意和一年的高度曲线：夏天高，冬天低
s2lat: 观察者的纬度（北为正）
s2day: 日期
:::

结论：太阳越高，单位面积地面受到的阳光越多，所以夏天热；冬天太阳低，阳光「斜着摊开」。条件：只看正午的几何，不含大气吸收、云和地面热惯性（所以最热的日子要比夏至晚一些）。 {#s2result .readout i18n=text}

::: strings
s2ro: 纬度 {lat}°，{date}：直射点 {dec}°，正午太阳高度 h = {h}°，太阳在{dir}；相对强度 sin h = {s}。
:::

## 为什么夏天白天更长，在极地甚至一整天不落？ {#step3 h2=s3t}

::: strings
nav3: 3 昼有多长
:::

第 3 步 · 昼有多长 {#s3k .step-kicker i18n=text}

这一步要回答：昼长怎么随纬度和日期变化？太阳直射点移到北半球时，北半球更多的纬线圈落在被照亮的那半个地球上，白天就长。昼长 = 2 × arccos(−tanφ·tanδ) ÷ 15°（单位小时，φ 是纬度，δ 是直射点纬度）。右边的圆是 24 小时钟，黄色弧是白天；按播放，一年的昼长曲线会一点点画出来。 {#s3e .explain}

::: html step3-1
s3stage: 上：昼长曲线，橙点是所选日期（虚线是赤道的 12 小时参照）；下：24 小时圆环，黄色弧是白天
s3canvas: 一年昼长曲线与 24 小时圆环：夏天昼长，冬天昼短，极圈内有极昼和极夜
s3lat: 纬度（北为正）
s3day: 日期
s3play: 让一年转起来
:::

结论：直射点在哪个半球，那个半球昼长夜短；越靠近两极变化越大；赤道全年约 12 小时。条件：几何昼长，不含大气折射（实际昼长略长几分钟）和地形。 {#s3result .readout i18n=text}

## 如果地轴不斜，会有四季吗？倾斜得更厉害呢？ {#step4 h2=s4t}

::: strings
nav4: 4 没有倾斜会怎样
:::

第 4 步 · 没有倾斜会怎样 {#s4k .step-kicker i18n=text}

这一步要回答：把地轴倾角 ε 当作可调的变量，四季强弱怎样跟着变？这是一个「假如」实验：ε = 0° 时地轴竖直，直射点永远在赤道；ε 越大，直射点来回摆得越远，季节越分明。两条线分别是北纬 40° 和南纬 40° 的正午太阳高度，看它们怎样互为反季节。 {#s4e .explain}

::: html step4-1
s4stage: 一年中正午太阳高度：青线 = 北纬 40°，橙线 = 南纬 40°，竖线是所选日期；ε 变大时两条线摆动更大
s4canvas: 不同地轴倾角下北纬 40° 与南纬 40° 的正午太阳高度曲线：倾角为零时两条线持平
s4eps: 假想的地轴倾角 ε
s4day: 日期
:::

结论：倾角为 0 就没有四季，倾角越大季节越强；南北半球季节相反，因为直射点在一边时另一边的太阳就低。条件：只改倾角、公转轨道不变；极端倾角（如天王星约 98°）要另当别论。 {#s4result .readout i18n=text}

::: strings
s4ro: ε = {eps}°：北纬 40° 正午太阳高度在 {nmin}°–{nmax}° 之间变化，南纬 40° 在 {smin}°–{smax}° 之间；北纬 40° 昼长 {lmin}–{lmax} 小时。{now}
s4now: {date}：北纬 40° 此刻 {nh}°，南纬 40° 此刻 {sh}°。
:::
