## 离地球越远，引力（重力加速度）减弱得有多快？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 平方反比

<b>这一步回答：引力和距离是什么关系？</b>万有引力 F = GMm/r²，所以加速度 g(r) = GM/r²：距离翻倍，引力变成四分之一。以地球半径 R⊕ 为单位，地面（r = 1）g ≈ 9.81 m/s²，距地心 2 R⊕ 处只有约 2.45 m/s²。拖动距离，看曲线上的点和右边箭头的长度一起变。 {#s0e .explain}

## 从同一高度横着扔出去，速度不同，路径会怎样？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 横着扔
:::

::: html step1-1

s1k: 横向发射

<b>这一步回答：初速度怎样决定轨道？</b>单位取 GM = 1，在 r = 1 处沿切线发射。速度小于圆轨道速度 1：椭圆（太小就撞上中心天体）；等于 1：正圆；介于 1 与 √2 ≈ 1.414 之间：更扁的椭圆；达到逃逸速度 √2：抛物线，不再回来；更大：双曲线。轨迹是用逐步积分（速度 Verlet）算出来的。点“播放”或“一次画完”。 {#s1e .explain}

## 轨道为什么只在两个半径之间来回？逃逸速度从哪来？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 能量与逃逸
:::

::: html step2-1

s2k: 能量账本与逃逸速度

<b>这一步回答：为什么有近地点和远地点，逃逸的条件是什么？</b>总能量 E = ½v² − 1/r（单位质量）守恒。再加上角动量守恒，径向运动像在“有效势” V<sub>eff</sub>(r) = L²/(2r²) − 1/r 里滚动：总能量线（青）与曲线（橙）相交的两点就是近、远地点（绿点）。E &lt; 0 被束缚；E = 0（v = √2）是逃逸的临界；E &gt; 0 只有一个交点，飞出去不再回来。拖动发射速度。 {#s2e .explain}

<b>这一步回答：相等时间扫过的面积怎样？</b>把一圈轨道按时间分成 8 等份，每份与中心连线扫过一个扇形（交替涂色）。近处的扇形又宽又短，远处的又窄又长，但面积相同——角动量守恒的几何表述（开普勒第二定律）。读数给出三份扇形的面积（数值积分算出），应与 ½·L·T/8 相等。拖动发射速度改变椭圆的扁度。 {#s3e .explain}

## 卫星要多高，绕地球一圈才刚好是一天？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 卫星高度
:::

::: html step5-1

s5k: 终章 · 真实卫星
:::

<b>这一步回答：把定律用到真实卫星上。</b>圆轨道周期 T = 2π√(a³/GM)，a = R⊕ + 高度，地球 GM = 3.986×10¹⁴ m³/s²。国际空间站约 400 km，周期约 92 分钟；GPS 约 20,200 km，约 12 小时；高度约 35,786 km 时周期等于地球自转周期，卫星看起来悬在赤道上空不动——同步轨道。月球更远，约 27 天。拖动高度（对数刻度）找到绿线。 {#s5e .explain}
