## 同一颗太阳，不同的光斑 {#step0 h2=s0t}

::: strings
nav0: 0 纬度与入射
:::

第 0 步 · 纬度与入射 {#s0k .step-kicker i18n=text}

地球接收到的太阳功率近似是**太阳常数 × 投影面积**。纬度升高时，光线更斜，同一束能量摊在更大的地面上，所以单位面积获得的能量减少。 {#s0e .explain}

::: html step0-1
latitude: 纬度
sunAngle: 太阳高度角
insolation: 相对入射功率
start: 继续：追踪能量 ↓
:::

## 白色表面会把光退回去 {#step1 h2=s1t}

::: strings
nav1: 1 反照率

第 1 步 · 反照率 {#s1k .step-kicker i18n=text}

反照率 *α* 是被反射的比例。雪、云和沙漠的 α 较高，森林和海洋较低；剩下的 **1 − α** 才进入地表—大气系统。 {#s1e .explain}

reflected: 反射回太空
absorbed: 被吸收
:::

## 逃出去的热，决定平衡温度 {#step2 h2=s2t}

::: strings
nav2: 2 温室效应
:::

第 2 步 · 温室效应 {#s2k .step-kicker i18n=text}

地表吸收短波后，会以红外辐射散热。温室气体让一部分红外被吸收、再向各方向重发射；系统必须升温到**向外的能量 = 吸收的能量**才会稳定。 {#s2e .explain}

::: html step2-1
greenhouse: 温室气体遮挡率
effectiveTemp: 有效辐射温度
topOfAtmosphere: 大气顶
surfaceTemp: 模型地表温度
kelvin: 开尔文
escape: 直接逃逸红外
ofHeat: 占出射热
:::

这是辐射平衡的教学模型：它展示方向和反馈，不替代真实气候模型中的云、海洋和环流。 {#s2h .hint i18n=text}

## 把每个旋钮连回真实世界 {#step3 h2=s3t}

第 3 步 · 证据链 {#s3k .step-kicker i18n=text}

选择三张能组成因果链的证据卡：纬度改变入射，表面改变反射，大气改变出射。点“检查”后，再用一句话解释哪一环改变了能量账本。 {#s3e .explain i18n=text}

::: html step3-1
shuffle: 重新组合证据
check: 检查我的链条
:::

气候的第一条守恒关系很朴素：**吸收的太阳能 = 向外散掉的热**。纬度、反照率和温室效应，只是在账本的不同位置改变同一个平衡。 {#finale .finale}
