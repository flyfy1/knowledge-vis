## 气温越高，海水蒸发得越快吗？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 太阳晒海
:::

::: html step0-1

这一步要回答：水汽是怎么进到空气里的？太阳加热海面，水从液态变成气态的水汽，这个过程叫**蒸发**。空气最多能容纳多少水汽（饱和水汽压）随温度升高而迅速增大。拖动气温，看曲线上的圆点和蒸发的强弱（本页以 20 ℃ 为基准 1）。 {#s0e .explain}

## 水汽上升后，为什么会变成云？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 凝结成云
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 凝结成云
:::

这一步要回答：云是从哪个高度开始出现的？含水汽的空气上升时，每上升 1 千米温度约降 9.8 ℃，而其中的水汽露点（水汽开始凝结的温度）只降约 1.8 ℃。当空气温度降到露点，水汽凝结成小水滴，就是**云底**。拖动地面气温和露点，看两条线相交的高度。 {#s1e .explain}

::: html step1-2
s1cv: 上升空气的温度线与露点线，相交处是云底
t0: 地面气温（℃）
td0: 地面露点（℃）
:::

::: strings
s1ro: 地面气温 {T0} ℃、露点 {Td} ℃：气温与露点相差 {d} ℃，云底高度约 {z} 米（相交处，上升约 {zk} 千米）。
s1roDry: 气温等于露点：空气已饱和，贴着地面就起雾，云底高度 0 米。

## 云里的水滴，什么时候会掉下来？ {#step2 h2=s2t pre=1}

::: html step2-1

这一步要回答：云为什么会下雨？云里的小水滴太轻，会悬在空中；水汽不断凝结进来，小水滴合并变大，大到一定程度就掉下来成为雨。按“加一份水汽”，云里的水一格一格增多，装满 8 份就下雨（阈值是示意值）。 {#s2e .explain}

## 雨落到陆地后，多久会回到海里？ {#step3 h2=s3t pre=1}

::: strings

这一步要回答：降到陆地上的水去了哪里？一部分很快顺着河流流走（**径流**），一部分渗进土里成为地下水，再慢慢流出来（每天放出约 5%）。拖动“渗进土里的比例”，看累计回到海洋的水量怎样随天数增长，虚线是全部直接流走的情形。 {#s3e .explain}

## 整个循环里，水的总量变吗？各处的水会稳定在多少？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 整个循环

s4step: "第 4 步 · "
s4k: 整个循环
:::

这一步要回答：蒸发、降水、径流连起来后会怎样？三个“水库”：海洋 O、空气 A、陆地 L，共 1000 份水。每天：海洋蒸发进空气，空气降水（30% 落在陆地、70% 落回海洋），陆地的水经径流回海洋。按“开始”看三者怎样收敛到各自稳定值，总量始终不变；拖动气温改变蒸发。 {#s4e .explain}

这一步要回答：气温升高后，循环会怎样变化？用第 4 步的模型，拖动气温，看稳定时空气里的水量。因为空气能容纳的水汽随温度升高而增多，蒸发更快，稳定时空气里的水汽也更多。 {#s5e .explain}
