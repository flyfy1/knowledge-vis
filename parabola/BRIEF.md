# BRIEF：二次函数与抛物线（parabola）· 初中数学

## 定位
- slug `parabola`，category math，stage junior。受众：初中生 + 家长。接 linear-functions（直线：抬高恒定）之后——抬高量不再恒定，会发生什么？
- 核心直觉一句话：**投篮的弧线就是抛物线：y=ax² 里 a 管开口胖瘦与方向，把整条线平移，顶点（最高/最低点）跟着走；顶点、对称轴、与 x 轴的交点，全都能从式子直接读出来**。
- 已知：一次函数的斜率/截距、坐标系、平方。唯一新问题：每步抬高越来越多（或先降后升）的点，连起来是什么曲线、式子怎么写？

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **投篮**：已知投篮轨迹是弧线；唯一问题：球每 0.1 秒的位置连起来，是什么形状？控件：投篮动画（可重播/暂停在任意时刻），轨迹点逐个落下成点列，横轴时间/纵轴高度，最终描出完整弧线并标出最高点；再切换「水平距离—高度」口径同图对照（一句点明两种横轴都是同一条弧线形状）。预期观察：先升后降、左右大体对称、最高点只有一个。结论：这种先升后降、只有一个顶的弧线叫**抛物线**；最高点叫**顶点**。
2. **a 管胖瘦**：唯一问题：y=ax² 里的 a 改一改，弧线怎么变？控件：a 滑杆（−2…2，步进含 ±1/2、±1、±2，排除 0 并单设「a=0 会怎样」一句点破=退化成直线）；格点落点 + 连线，与 x² 原型虚线同屏对照。预期观察：a>1 变瘦、0<a<1 变胖、a<0 开口翻到向下、|a| 越大越瘦。结论：a 的符号定开口方向，|a| 定胖瘦；a=0 不是抛物线。
3. **顶点搬家**：唯一问题：式子写成 y=a(x−h)²+k，图怎么搬家？控件：h、k 双滑杆（a 固定 1 后可切换 −1），整条抛物线平移，顶点坐标 (h, k) 实时标记，**对称轴**虚线 x=h 跟随；方程拼装实时显示（h 为负写成 (x+|h|)² 的书写规范与一次函数页保持同一套约定）。预期观察：改 h 左右搬、改 k 上下搬、顶点永远在对称轴上。结论：顶点式直接把顶点坐标写在脸上；适用条件：任何抛物线都能写成顶点式（一般式 y=ax²+bx+c 与之等价转换只在终章一句带过，不展开配方）。
4. **落点与交点**：唯一问题：球从手里出去，落在哪里——抛物线与 x 轴的交点是什么？控件：投篮情境复用：给定弧线（顶点式参数可调 h/k/a 三选其二可调即可，别做成全参数沙盒），拖「篮筐/落点」位置，读交点：两交点/一交点（相切，顶点在轴上）/无交点（整条在轴上方或下方）三种情形都必须可达且读数明说；交点横坐标由求解给出（整数/简单根为准，允许显示一位小数并标注≈）。预期观察：交点就是 y=0 的 x——落地的那一刻。结论：与 x 轴交点个数（2/1/0）由弧线与轴的相对位置决定；这里只做读图口径，不引入判别式符号（Δ 留到高中页或终章一句「以后会学到一个专门判它的式子」）。
5. **自测 + 终章**：①看图选式：给顶点 (2,1)、开口向下的图，三选一选顶点式；②摆弧线：滑杆答题把顶点摆到 (−1, 3) 且开口向下，判定精确（h/k/符号）；③应用题：给定投篮弧线读图答「最高点几米」「球在几米处落地」（探针读数答题）。终章三卡（a 管方向胖瘦 / 顶点式脸上写顶点 / 交点是落地处）+ 深链：linear-functions#step0（抬高恒定是直线、抬高在变是曲线——打开核对锚点）、pythagoras#step5（坐标与距离）、symmetry-rotation#step2 如已上线则链「对称轴在那边见过」（未上线则不链，以上线状态为准）。
