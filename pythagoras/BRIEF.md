# BRIEF · 勾股定理（pythagoras）

- slug：`pythagoras`；分类 math；学段 junior（初中）；标题：勾股定理 / The Pythagorean Theorem
- 一句话直觉：直角三角形里，两条直角边的平方和等于斜边的平方；用面积看就是——挂在两条直角边上的两个小正方形，正好装满挂在斜边上的大正方形。
- 学习者画像：初中生，学过正方形面积、平方与开方的初步概念，没亲手证过定理。页面标准照 UI-I18N-SPEC（双语/骨架/规则 11/12）与 WORKFLOW 流水线；同级参照页：fractions（K12 语感）、trig（几何画布）。

## 步骤设计（0–6，每步五必填项）

### 第 0 步 · 3、4、5 的巧合？
- 已知：会量边长、会算一个数的平方（如 3²=9）。
- 唯一问题：3-4-5 直角三角形里 3²+4²=5² 是巧合，还是所有直角三角形都这样？
- 输入与求量：输入是三组候选三角形（3-4-5 直角、5-12-13 直角、2-3-4 非直角）；求量是每组的 a²、b²、c² 与 a²+b² 和 c² 的比较。
- 控件与预期观察：先猜（「每个直角三角形都成立 / 只是 3-4-5 的巧合」二选一，猜测要回显）再逐个点开三组三角形验算；读数逐组对账（9+16=25 ✓、25+144=169 ✓、4+9≠16 ✗ 并标明第三组不是直角三角形）。揭晓后猜测锁定、不得改口。
- 结论适用条件：先立悬念，不下结论；术语首现：**斜边**（直角对着的那条最长边）、**直角边**，就近白话。

### 第 1 步 · 用面积看：两个小正方形装满一个大正方形
- 已知：第 0 步的数字对账。
- 唯一问题：a²、b²、c² 不只是数字——它们是挂在三条边上的三个正方形的面积吗？
- 输入与求量：3-4-5 三角形三边各挂一个正方形（边长即该边）；求三块面积并验证小+小=大。
- 控件与预期观察：点「倒过去」播放填充动画：a² 与 b² 两块的填充逐格流入 c² 的正方形，进度 % 与已流入面积数同步增长，流满时读数「9 + 16 = 25，一格不差」。重置必须清填充、清进度、清读数回初态。
- 结论适用条件：面积视角只对「平方」成立，这正是定理写成平方和的原因；术语首现：**平方**的几何意义（边长×边长的一块面积）。

### 第 2 步 · 拼图证明：同一块大正方形，两种数法
- 已知：面积视角（第 1 步）、正方形面积公式、三角形面积 = 底×高÷2。
- 唯一问题：怎么不用量、不用凑数字，证明对任意直角边 a、b 都成立？
- 输入与求量：边长 (a+b) 的大正方形，四个全等直角三角形（边 a、b）摆进四角，中间留出斜置的 c² 正方形；用两种数法对账总面积。
- 控件与预期观察：「拼一步」步进 k/4 把四个三角形逐个摆入（历史保留、不许只换帧）；账本两栏同步展开——数法一：(a+b)² = a² + 2ab + b²；数法二：4×(ab/2) + c² = 2ab + c²；末步两栏相减得 a² + b² = c² 并高亮。滑杆换一组 a、b（如 5、12），账本全部数字重算仍对平。
- 结论适用条件：证明对一切直角三角形成立，不依赖具体数字；术语首现：**全等**（一模一样能重合）、**证明**与「验算」的区别（验算只管试过的，证明管全部）。

### 第 3 步 · 拖着验证：怎么拖都等
- 已知：定理已证明（第 2 步）。
- 唯一问题：把直角顶点拖到任意位置，等式还成立吗？斜边长度能不能直接开方算出来？
- 输入与求量：输入是拖动得到的任意 a、b（带读数）；求量是斜边 c 的两路值——尺子直量的长度与 √(a²+b²) 算出的长度，并排对账。
- 控件与预期观察：Canvas 拖动直角顶点，a、b、三个面积与 c 的两路读数实时更新、两路 c 始终一致（差值显示 0.00）；轨迹保留访问过的点影。再开「松开直角」开关把角拖成钝角/锐角：等式变不等式，读数改判「c² > a²+b²，钝角」或「c² < a²+b²，锐角」——为第 4 步埋伏笔。边界：a 或 b 拖到接近 0 时读数不许出现 NaN/负数。
- 结论适用条件：等号只属于直角；术语首现：**平方根**（开方是平方的逆运算，就近白话）。

### 第 4 步 · 反过来判：给三边，判是不是直角
- 已知：第 3 步的三种情形（=、>、<）。
- 唯一问题：只给三条边长、不给图，怎么判一个三角形是直角、锐角还是钝角？
- 输入与求量：输入随机三边组（保证能构成三角形）；求量是最大边平方与其余两边平方和的比较结果。
- 控件与预期观察：测验式——学习者先点判（直角/锐角/钝角）再揭晓，账本摊开 c² 与 a²+b² 两数与差值；计分「答了 n 题、对 k 题」；**揭晓后选项禁用**（波 1 freqresp 教训内置），「下一题」才恢复。术语首现：**逆定理**（定理反过来说也成立：平方和相等 ⇒ 必有直角）。
- 结论适用条件：比较时必须拿最长边当 c；三边先要能构成三角形。

### 第 5 步 · 拿去用：梯子、屏幕与两点距离
- 已知：会用定理求斜边，也会反着求直角边（c²−a² 再开方）。
- 唯一问题：知道斜边和一条直角边，另一条怎么求？这在生活里管什么用？
- 输入与求量：情境一梯子长 5 m，输入底端离墙距离 d，求靠墙高度 √(25−d²)；情境二坐标格上两点，输入两点位置，求直线距离 √((Δx)²+(Δy)²)。
- 控件与预期观察：梯子滑杆拖 d 从 0.5 到 4.9，图形与高度读数实时变，d 接近 5 时高度趋 0 要有提示；格点图拖动第二个点，Δx、Δy 与距离三读数同步，距离线保留拖动轨迹。两情境共用一句结论：求的是「横平竖直两段路之外的直线捷径」。
- 结论适用条件：梯子模型把墙与地面当直角；术语首现：**距离公式**（就是勾股定理穿了个坐标外套）。

### 第 6 步 · 终章：勾股数与 √2
- 已知：全页。
- 唯一问题：哪些整数组合天生就是直角三角形？斜边一定要是整数吗？
- 输入与求量：勾股数族（3-4-5 的倍数族、5-12-13、8-15-17）；反例 1-1-√2。
- 控件与预期观察：滑杆 k=1..6 生成 3k-4k-5k 一族并逐行验算入表（历史累积成表）；点开 1-1 直角三角形，斜边读数 √2 ≈ 1.414… 并注明它写不尽、不是分数（呼应 fractions 页的「三张脸」里没有它）。终章互链区（2–4 条，带步锚点）：trig `../trig/#step1`（单位圆里 cos²θ+sin²θ=1 就是勾股定理的自检）、fractions `../fractions/#step6`（√2 为什么不是分数）、eigen `../eigen/#step0`（向量的长度也是开方求和——先去看看向量是什么；若锚点概念不符以 CONCEPT-MAP 为准修正）。
- 结论适用条件：勾股数是整数特例，不是定理的边界；术语首现：**勾股数**、**无理数**（写不成分数、数轴上却有确切位置）。
