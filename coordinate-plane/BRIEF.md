# BRIEF：坐标系与点的位置——给每个位置一个地址（coordinate-plane）· 初中数学

## 定位
- slug `coordinate-plane`，category math，stage junior。受众：初中生（七年级上游）+ 家长。
- 在知识线中的位置：**已上线页 linear-functions 的缺失上游**。一次函数页直接从「坐标系里点排成直线」起步，默认学生已经会读坐标、认象限；本页把这块地基补上。再往上游，数轴的一维地址来自 negative-numbers 页（在建未上线，本页只文字埋线、不挂链，见终章口径）。
- 核心直觉一句话：**位置可以被数钉死——一条线上的位置用一个数，平面上的位置用一对数；这一对数有顺序、不能写反，写反就是另一个地址；四个象限的符号不是背出来的，是两根轴各自的正负拼出来的**。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件；步 id 0 起：step0–step5）

### step0 一维地址：一条线上的点，一个数就够
- **已知**：整数与数轴的初步印象——一个数对应数轴上一个点（fractions 页已学「分数是数轴上的一个数」；负数那页正在把数轴向左补完，本步的轴直接画完整的 −6…+6，不依赖它先上线）。
- **唯一问题**：只用一个数，能不能把一条线上的位置说死？
- **输入与求量**：输入 = 一条横数轴（原点 O、向右为正、刻度 −6…+6）；求量 = 轴上任意一个点的位置说法。
- **控件操作与预期观察**：画布上一条数轴 + 一个可拖点（吸附整数刻度，口径见判定节）。拖点或点刻度放点，读数行实时给出：「点在原点**右边 4 格**，记作 **+4**」/「点在原点**左边 3 格**，记作 **−3**」/「点就在原点，记作 **0**」——方向词与带符号数永远成对出现。另设一颗「换原点」演示钮：点一下，原点悄悄挪到原 +2 处、同一个点（位置不动）读数当场变成 +2，读数行补一句「点没动，地址变了——地址是相对于原点说的」。**预期观察**：一个数 = 方向 + 距离，一维位置被一个数钉死；但这个数离了原点就没意义。
- **结论与适用条件**：一维位置 ⇔ 一个带符号的数，前提是原点与正方向事先说定。适用范围：只管一条线上的点；点离开这条线（跳到平面上），一个数立刻不够——下步当场撞上。

### step1 一个数不够：平面上的点要一对数
- **已知**：step0 的一维地址；生活经验：电影院/教室找座位要报「第几排第几座」。
- **唯一问题**：把点放进平面，只报一个数，会发生什么？
- **输入与求量**：输入 = 一张 7 列 × 5 行的座位网格图（列号 1–7、行号 1–5 都标在边上），目标座位藏在其中（页面随机或预置一个，如第 3 列第 2 行，先不告诉学生）；求量 = 用数把这个座位唯一定死。
- **控件操作与预期观察**：第一阶段只给一个输入口：点「只报列号 3」——整列第 3 列全部亮起，读数行：「一列有 5 个座位，目标可能在其中任何一个——一个数只定出一条线，定不死一个点。」再点「只报行号 2」——整行亮起、同理。第二阶段两个都报：列 3 与行 2 的亮带交叉，交叉格单独高亮、目标现身，读数行：「两个数一交叉，点就被钉死了。」学生可换不同的列/行组合重玩（亮带与交叉点由所选行列实算）。**预期观察**：一个数 → 一条线；两个数 → 一个点。先给一个数时「差多少个候选」要以数字明示（5 个 / 7 个），让「不够」是数出来的、不是听说的。
- **结论与适用条件**：平面位置需要**一对数**：一个管横、一个管纵。适用范围：任何「横竖两个方向」的定位（座位、棋盘、地图网格同理）；两个数各管什么、按什么顺序写，下步立规矩。

### step2 坐标系登场：先横后纵，(x, y) 是地址
- **已知**：step1 的一对数；step0 的数轴（马上要立起来一根）。
- **唯一问题**：这一对数按什么统一规矩写，全世界的人才不会读错？
- **输入与求量**：输入 = 两条数轴十字交叉成的平面直角坐标系（横轴 x、纵轴 y、交点原点 O，刻度 −6…+6）；求量 = 图上任意格点的标准写法。
- **控件操作与预期观察**：先有一段「搭坐标系」微动画（播放钮）：横轴躺平、纵轴立起、原点对齐，两根轴先后亮起（轨迹保留、带 k/2 步进度即可，本页无长动画，简单呈现即可）。然后进入读点模式：画布上预置 4 个点（含第一象限与带负坐标的点各至少一个），点选任意一点，从原点出发的路径动画先沿 x 轴走、再沿 y 轴走（两段不同色、先后亮起），读数行拼出：「先横走 **3**，再纵走 **−2** → 这个点的坐标是 **(3, −2)**；3 叫**横坐标**，−2 叫**纵坐标**」。学生随后可拖动一个自由点满图跑（吸附整数格），读数永远按同格式实算跟随。**预期观察**：「先横后纵」在路径动画里被走出来、不是口号；坐标 = 从原点出发的走法记录。
- **结论与适用条件**：平面直角坐标系里每个格点有唯一坐标 (x, y)：x 是横坐标、y 是纵坐标，写成**有序数对**，顺序全世界统一先横后纵。适用范围：本页只练整数格点；格与格之间的点坐标可以是分数/小数，读法相同（后续函数页会遇到），本页不展开。

### step3 顺序不能反：(3, 2) 和 (2, 3) 不是一家
- **已知**：step2 的坐标读写与「有序」二字（当时只是规矩，这步来验它为什么必须有序）。
- **唯一问题**：把坐标的两个数写反，还是同一个点吗？
- **输入与求量**：输入 = 坐标系 + 点 A（初始 (3, 2)）；求量 = A 的「换位点」A′(2, 3) 与 A 的关系：重合，还是另一个点？
- **控件操作与预期观察**：A 与 A′ 双点同屏（不同色、都带坐标标签），虚线连 A—A′，并画出对角参考线 y=x（只作镜面示意，标签写「对角线」，不引入函数记号 y=x 的展开——图上标「这条斜线上的点横纵相等」即可，记号可出现但不要求学生会读函数式）。点「交换 A 的坐标」钮：A 当场跳到 (2, 3)（与 A′ 原位置重合一帧后 A′ 让位消隐，或 A′ 同步换回 (3, 2)——实现二选一，报告里注明），让学生亲眼看到「写反 = 点搬家」。再开放 A 的双滑杆/拖动（x、y 各 −6…6）：A′ 永远由 A 的坐标交换实算跟随；当且仅当拖到 x=y 的点（如 (2, 2)、(−4, −4)），两点当场合体，读数行明说「横纵相等时，换位还是自己——只有这种点写反才不变」。其余任何位置读数行给两点间格距（横差几格、纵差几格，由坐标实算）。**预期观察**：换位点关于对角线像照镜子一样落在另一侧（现象陈述即可，不讲「轴对称变换」术语）；绝大多数点写反就错位，只有对角线上的点例外。
- **结论与适用条件**：(a, b) 与 (b, a) 一般是**两个不同的点**，a=b 时才重合——所以坐标必须是有序数对，顺序是地址的一部分。此结论对一切实数坐标成立，不限本页整数格点。

### step4 四象限：符号是拼出来的，不是背的
- **已知**：step2 的坐标读写；step0 的正负号来自「在原点的哪一边」。
- **唯一问题**：坐标系被两根轴切成的四块区域，每块里的点，坐标符号有什么规律？
- **输入与求量**：输入 = 坐标系（四区先不着色）+ 可拖点；求量 = 每个区域的符号组合，以及区域边界（轴）上的点归谁。
- **控件操作与预期观察**：拖点满平面跑（吸附整数格），读数行三件套实时同步：坐标 (x, y)、符号拼图「x 是 **+**，y 是 **−**」、所在区域名。点首次进入某个新区时，该区域淡着色并浮出它的符号牌（如「(−, +)」），四块集齐后整图留色，读数行收口一句「四个区域的符号，全是两根轴正负的拼图」。特意引导撞边界：把点拖到轴上，读数行改口径——「点在 **x 轴**上：y = 0，**不属于任何象限**」（y 轴、原点同理各有专句，原点为「原点不属于任何象限」）。另设「只给符号找区域」反向小练（嵌在本步、不计分）：页面给出符号组合（如 (−, −)），学生点一个区域，判定对错即时反馈。**预期观察**：象限顺序按逆时针：一 (+, +)、二 (−, +)、三 (−, −)、四 (+, −)；规律不用背——x 的符号看左右、y 的符号看上下，拼起来就是。
- **结论与适用条件**：**象限**由符号判定：第几象限只取决于 x、y 各自的正负，与坐标大小无关；**坐标轴上的点不属于任何象限**（因为有一个坐标是 0、没有正负）。适用范围：一切坐标系，无例外——这是定义，不是经验规律。

### step5 自测 + 终章
- **自测三题**（判定口径见判定节，全部整数精确、无容差）：
  1. **读坐标**：图上给定一个点（第三象限，如 (−4, −3)），三选一选出它的坐标，选项须含 (x, y) 与 (y, x) 两个互为换位的干扰项。
  2. **按坐标放点**：给出坐标 (−2, 3)（第二象限），学生在空白坐标系里点格放点，点中目标格才算对；放错当场指出他放的点实际坐标是多少（由点选格实算回读）。
  3. **换位陷阱**：问「(4, 1) 和 (1, 4) 是同一个点吗？」二选一；答后图上双点同时亮出作证（接 step3 的结论，不靠文字说服）。
  三题答对锁定、答错可重试并给指向对应步的提示句（题 1→step2、题 2→step2/4、题 3→step3）。

## 新术语首现表（首现处就近一句话解释；规则 11：每步首现都要就近带口径）
| 术语 | 首现步 | 当场白话口径 |
|---|---|---|
| 原点 | step0（数轴语境） | 地址的起算点，记作 0（O）；所有位置都相对于它说 |
| 横轴 / 纵轴（x 轴 / y 轴） | step2 | 横着的数轴叫横轴（x 轴），立起来的叫纵轴（y 轴）；它们本身就是 step0 那条数轴 |

## 判定口径（写死，构建与评审都按此对账）
- **坐标域**：x、y ∈ [−6, 6] 的整数格点（13×13 格网），全页统一，不许某步偷偷扩域。
- **拖点吸附**：指针像素 → 格坐标用最近格取整（round），再钳制到 [−6, 6]；**状态只存吸附后的整数坐标**，落点、标签、读数全部由这份整数状态纯渲染，禁止从画布像素反推读数。吸附发生在 pointermove 全程（拖动中读数实时跟随吸附值），不是松手才吸附。
- **坐标读数**：格式恒为 `(x, y)`（半角括号、逗号后一空格），负号统一 U+2212（−），0 不带 + 号；中英两版同格式。读数 = 纯函数 `fmtCoord(x, y)`，自查断言覆盖四象限 + 两轴 + 原点共 7 类点。
- **象限判定函数**：纯函数 `quadrant(x, y)`：`x===0 && y===0` → 原点；`x===0 || y===0` → 轴上（再分 x 轴 / y 轴）；其余按符号：(+,+)→一、(−,+)→二、(−,−)→三、(+,−)→四。返回类别供读数行与着色共用，禁止各处各写一份判断。自查断言：四象限各 2 点 + x 轴 2 点 + y 轴 2 点 + 原点 = 13 例全过。
- **换位点**：A′(y, x) 由 A 的状态交换实算（纯函数 `swap`），不独立存状态；重合判定恒为 `x===y`（整数精确）。两点格距读数 = |x₁−x₂|、|y₁−y₂| 分别陈述，不合成距离（距离是 pythagoras 的活，本页不抢）。
- **step1 候选计数**：只报列 → 候选数 = 行数（5）；只报行 → 候选数 = 列数（7）；由网格行列数实算写进读数模板，不许写死数字。
- **自测判定**：题 1 选项判定 = 与目标坐标严格相等；题 2 = 学生点选格与目标格整数精确相等（无容差、无「差不多」）；题 3 = 布尔判定。答对锁定、答错保留题目可重试；答题后改语言，反馈按新语言重渲染且判定不丢。

## 模拟设定 / 模型失配（须在页内或本 BRIEF 明示的简化）
- 本页是**整数格点的世界**：座位、棋盘都是天生离散的，拿它们引入坐标不失真；但真实位置（地图经纬、测量）坐标多为非整数——页内在 step2 结论处明示「格子之间的点也有坐标，可以是分数、小数」，避免学生把「坐标 = 整数对」当定义。
- 座位图的「行/列」编号从 1 起、没有负数，它是坐标系的生活原型而非坐标系本身；step2 须有一句桥接：「给网格配上原点和正负，座位号就升级成坐标」，防止学生把「第 3 列第 2 行」与坐标 (3, 2) 的来源关系误当成同一套编号规则（座位无负、坐标有负）。

## Codex coordinate-swap bridge — 2026-10-29

Step 3 now isolates one coordinate at a time: changing x moves the swap twin's y, changing y moves its x, and only x=y leaves the two points together. The relationship is observable before the learner names the diagonal exception.
