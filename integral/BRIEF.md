# BRIEF：定积分（integral）· 高中数学

## 定位
- slug `integral`，category math，stage senior。受众：高中生 + 家长。与 derivative 是姐妹页：导数把大问题缩到一点，定积分把无数小块加回整体。还回收 velocity-vt 的「切条数面积」——那页说「以后有个名字叫积分，这就是它」。
- 核心直觉一句话：**定积分就是把曲线下的面积切成越来越细的长方形条、把条面积加起来；条无限细时，和收敛到的那个数就是曲线下的真面积——累加的过程本身就是积分**。
- 已知：面积公式、极限的描述性直觉（导数页）、v-t 图面积=路程。唯一新问题：曲边围成的面积没有公式，怎么算出精确值？

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **曲边面积没公式**：已知长方形/三角形/梯形面积都会算；唯一问题：y=x² 在 [0,1] 下方的曲边面积，哪个公式都不对口。控件：曲线与曲边区域图 + 三种粗估（1 个大长方形按左高/右高、1 个梯形、三角形）逐一显示估值（右高长方形 1、梯形 0.5、三角形 0.5 均明显偏离），读数明说「只能估、且估法不同答案不同」。预期观察：现成公式只能夹出大概。结论：需要的不是某个公式，而是「越切越准」的办法。
2. **黎曼和：切条加起来**（核心步）：唯一问题：怎样让估算自己变准？控件：同一区域，条数 n 滑杆 1→2→4→8→16→32（对数档），左端点/右端点/中点三种取高口径可切；每条长方形实算面积并累计读数（须与解析和公式对账，如左和 Ln=(n−1)(2n−1)/(6n²)、右和 Rn=(n+1)(2n+1)/(6n²)，n=4 时 0.21875/0.46875）；左右和把真值夹在中间的区间随 n 变窄可视化（误差带读数 R−L=1/n）。预期观察：n 翻倍，夹缝约减半，左右和从两侧贴近同一个数。结论：细到极限、左右都贴到的那个数（这里 =1/3），就是**定积分** ∫₀¹x²dx。适用条件：先连续曲线；取高口径影响接近速度、不影响极限。
3. **积分就是累加：回收 v-t**：唯一问题：积分除了「面积」还管什么？控件：同一台切条机换上 v-t 情境（速度曲线 v=t 在 [0,2]），条面积单位换成「速度×时间=路程」，读数收敛到 2 m（解析 ½·2·2）；切回 y=x² 时单位换回面积。预期观察：几何的面积与物理的路程是同一次累加。结论：定积分 = 把每一小段的「高×宽」加总；高是什么、积的就是什么的累积量。深链 velocity-vt#step2 回收。
4. **与导数接头：微积分基本定理**：唯一问题：数条数到 n=32 还差得远，精确值 1/3 是怎么「算」出来的？控件：面积函数 A(x)=「从 0 累加到 x 的面积」可拖 x 探针，A 曲线同步描出（数值累加绘制）；拖动时显示 A 的增长快慢——A 在 x 处的导数读数与原函数 x² 在该点的值对账（A′(1)≈1=1²）；收口给出：A(x)=x³/3 恰好满足导数 =x²，于是 ∫₀¹x²dx=A(1)−A(0)=1/3，精确值不用数无穷条。预期观察：累加出来的 A 曲线就是原函数的「原函数」。结论：**求积分 = 找导数是自己的函数（原函数），积分与导数互为逆运算**（牛顿—莱布尼茨公式，名字与记号 ∫、dx 在此处正式首现解释）。
5. **自测 + 终章**：①∫₀²x dx 用几何法（三角形）答 2；②同一曲线 n=4 左和与右和谁大谁小、真值在哪（选项判定夹逼）；③判断「定积分算出来的永远是面积」（错：是累加量，可为路程等；且曲线在轴下方时带符号——口径只到「下方记负、是带符号的累加」一句，不展开负面积练习）。终章三卡（切条累加 / 左右夹逼到极限 / 求积分就是找原函数）+ 深链：derivative#step3（导函数的逆问题）、velocity-vt#step2；终章一句埋线旋转体/概率密度纯文本无链。
