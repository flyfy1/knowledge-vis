# BRIEF：位值与计数器（place-value）· 小学数学
- category `math`，stage `primary`（已注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，记录不确定性）。
- 核心：位值（同一数字不同数位差 10 倍）、满十进一、0 占位、从高位比大小、×10 左移一位。

## 步骤（五必填项）
0. 计数器读数。已知：珠子；问题：珠数如何读成数？输入四列珠数；观察：计数器珠子随滑杆增减，读数 = Σ珠数×位值，零列不写；适用：十进制四列。
1. 满十进一。问题：一列到 10 会怎样？输入：个位/十位/百位加 1、连加 10 次（定时器）、清零；观察：第 10 次时该列清空、左列加 1，进位列橙色；到 9999 提示溢出；清零停定时器、清读数。
2. 位置决定大小。问题：同一数字不同数位差多少？输入数字 d（1–9）、数位（个/十/百）；观察：d 个方块 / 长条 / 方板，读数 d×位值 = 方块数。
3. 零占位。问题：305 的 0 能去掉吗？输入百/十/个位、去掉十位的 0/恢复；观察：并拢后 305→35，差 270；十位非 0 时按钮禁用并说明。
4. 比大小。问题：先比哪一位？输入 A、B（0–9999）；观察：橙色=第一个不同位，灰=相同位，暗=不必再比；相等时给出相等结论。
5. 终章。输入 N；N、10N、100N 三行数字左移、空位补 0（橙色）；深链：exp-log#step0、area-model#step3、division-remainder#step0（均已核对存在）。

## 新术语首现表
位值（步 0）；进位（步 1）；占位（步 3）；第一个不同的数位（步 4）；×10（步 5）。

## 模拟设定 / 模型失配
