# BRIEF：找规律（patterns-sequences）· 小学数学
- category `math`，stage `primary`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（自查 self-check，未做独立评审）。模板页：cell-structure（头部/步骤骨架/语言切换/深色令牌）。页面可见标识：页脚双语署名行；specs/visual-page-provenance.md 只规定 Codex 版本标识，对 Claude 版没有明确要求，故仅加页脚署名并在此记录不确定性。
- 核心：数前几项 → 求相邻总数的增量 → 增量不变则总数 = 增量×n + 起头；增量逐次变大则不是直线。接高中数列与求和。

## 步骤（五必填项）
0. 数一数：已知正方形与火柴；问题：n 个正方形连排用几根？输入 n，求总根数；控件：滑杆 n、「逐根数一遍」（逐根点亮并编号）、重置；观察：编号累积到 3n+1；适用：相邻正方形只共用一条边的单排。
1. 找增量：已知第 0 步总数；问题：每多一个多几根？输入：点「再摆一个」，求增量；观察：橙色新火柴恒为 3，数列上方弧线标 +3；适用：新加部分形状相同。
2. 拆成组：已知增量为 3；问题：如何不画直接算第 100 个？输入 n（滑杆或大数框 ≤2000）；观察：灰 1 根起头 + 每格 3 根同色；读数 1+3n 与逐根构造计数对照；适用：同上。
3. 换图形：已知拆组法；问题：三角形、六边形是否同样管用，增量由什么决定？输入：图形种类、n；观察：折线图三条直线斜率 2/3/5，其他两条淡显对照；适用：链状、邻居共一边。
4. 增量会变：已知增量不变得直线；问题：增量不一样时呢？输入行数 n；观察：柱子越涨越快，增量 +2,+3,…逐次加一；适用：点阵台阶。
5. 终章：问题：能否反过来用？输入 S，按 S=3n+1 反推 n 并判定是否整数；回顾 + 模型范围 + 3 条深链（linear-functions#step0、area-model#step2、equations-balance#step3，均已核对存在）。

## 新术语首现表
第 n 个图（步 0 就近定义）；增量（步 1 就近定义：后一个总数减前一个，并在步 3、4 再带口径）；起头（步 2）；台阶/点阵（步 4）。

## 模拟设定 / 模型失配
火柴数全部由线段几何去重后计数得到，公式值与之交叉核对。失配：真实火柴有粗细、不会完美共用；规律从前几项推出，未验证到更大 n 之前只是猜想；换排法即换规律。
