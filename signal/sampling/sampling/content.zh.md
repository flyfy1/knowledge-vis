第 0 步 · 先被骗一次 {#s0k .step-kicker i18n=text}

下面这个轮子一直在以 **2.5 转/秒**匀速正转，从没变过。你能动的只有「摄像机」的帧率：拖动滑杆，亲眼看它慢下来、停住、然后**倒转**。轮子没变，变的是采样——每台摄像机、每双眼睛，都是隔一段时间才「偷看」世界一眼。 {#s0e .explain}

## 一排点，能记住一条波吗 {#step1 h2=s1t}

::: strings
nav1: 1 采样是偷看
:::

第 1 步 · 采样是什么 {#s1k .step-kicker i18n=text}

本步是一条理想连续正弦波。**采样**是在时刻 tₙ = n/fₛ 秒记录 x[n] = x(tₙ)：n 是整数索引，f 是每秒周期数（Hz），fₛ 是每秒采样次数。点精确落在原波上。直线连点或阶梯保持只是**显示插值**，通常不等于原连续波；提高采样率可改善这类示意，但理想精确重建还需要带限条件和相应重建滤波。 {#s1e .explain}

::: html step1-1
labF: 信号频率 f（Hz）
labFs: 采样率 f_s（Hz）
s1line: 直线连线
s1hold: 阶梯保持
:::

降低 fₛ，比较直线与阶梯：点仍在原波上，连接方式却给出不同曲线。这是显示近似；**不连线也不能排除别名**，因为不同连续波可能逐点相同。下一步直接对比两条共享样本的正弦。 {#s1hint .hint}

## 相同采样点，也能属于另一条波 {#step2 h2=s2t h2part=1}

::: strings
nav2: 2 假波诞生
:::

第 2 步 · 混叠诞生 {#s2k .step-kicker i18n=text}

::: html step2-1
:::

在原波上每隔 Δt=1/fₛ 秒取一个点，不同连续波可能给出完全相同的点，这叫**混叠**。默认原波 f=9 Hz、采样率 fₛ=10 Hz，粉红曲线采用带符号频率 g=−1 Hz，仍逐点穿过金色样点。负号表示 sin(2πgt)=−sin(2π|g|t)，不是负的频率大小。选一个样点 n，再改 f 或 fₛ：圈出的采样时刻与菱形标出的非采样时刻，都用下面同一模型对账。别名通常在 f 超过 fₛ/2 时发生，不必等到 fₛ 小于 f。 {#s2e .explain}

::: html step2-2
pairLegend: 金色圆圈：第 n 个真实样点。青色虚线与空心菱形：两次采样之间的 t=(n+¼)/fₛ，仅作比较，不是额外样本。原波灰色，折叠波粉红；菱形可能重合。
pairIndex: 选择整数样点 n（方向键 ±1）
pairSelected: 当前 n =
pairReset: 重置本步
s2pSlow: 经典慢波：f=9, f_s=10
s2pDC: 全钉同一点：f=f_s=10
s2pFold: 折叠：f=14, f_s=20
s2pClean: 无混叠：f=3, f_s=25
s2formulaNote: 本页取 k=round(f/fₛ)，先使带符号的 g=f−k·fₛ 落入 [−fₛ/2,fₛ/2]，再取频率大小 |g|。端点处代表方式可有歧义，见第3步。图必须用 g，而不能把 |g| 直接代入同相正弦。其他步骤也沿用这一折叠函数。
:::

为什么样点相同？在 tₙ=n/fₛ，两条波的相位差是 2π(f−g)n/fₛ=2πkn，恰好整数圈；正弦每转整圈回到同一值。因此对所有整数 n 都有 sin(2πftₙ)=sin(2πgtₙ)。离开采样时刻，这个整数圈条件不再保证成立。 {#pairWhy .explain .small i18n=text}

这只验证理想零初相位、单位振幅的两个正弦候选。有限几个重合点不能确定任意连续信号；即使此处两条曲线相同，也还有更高频别名。唯一重建需要事先已知带限、完整理想均匀样本和相应重建条件，不能靠折线或这幅有限图证明。 {#pairLimits .hint i18n=text}

先用默认9/10：预测圈内两值相同、菱形处可能不同，再移动 n 核对。选3/25时两条显示曲线为何完全相同？因为 k=0，g=f；这并不排除28 Hz等更高频候选。 {#pairQuestion .hint i18n=text}

「全钉同一点」是最阴险的预设：f 恰为 f<sub>s</sub> 的整数倍时，采样每次都撞在完全相同的相位上，所有点钉成一个值——**再快的波，看起来都静止**。这正是第 0 步轮子"停住"的真相。 {#s2hint .hint}

pairNext: 接着问：已知频带怎样排除别名？→ 第3步

## 奈奎斯特线：两倍，差一线都不行 {#step3 h2=s3t}

::: strings
nav3: 3 奈奎斯特线
:::

第 3 步 · 那条线 {#s3k .step-kicker i18n=text}

本步只比较理想单频正弦。**奈奎斯特条件**对已知带限信号说：若所有频率分量满足 |f| ≤ B 且 fₛ > 2B，完整的均匀样本序列可在这个带限范围内唯一重建。对本步 B=f，拖 fₛ 跨过 2f 比较；不限制候选频带时，高频别名仍可给出完全相同的点。直线连点只是显示插值，不能用它的振幅起伏判定精确重建。正好 fₛ=2f 时，点「钉在恰好2f」再改相位，检查边界歧义。 {#s3e .explain}

::: html step3-1
s3phase: 采样相位 φ（°）
s3snap: 钉在恰好 2f
:::

边界样本是 x[n] = A(−1)ⁿ sinφ：φ=90°时可见满幅交替，φ=0°时全零，但非零点也只确定 A sinφ，不能分别确定 A 与 φ。例如 A=1、φ=30° 和 A=0.5、φ=90°逐点相同。因此「碰巧有非零点」不是保证重建的条件；本页采用严格 fₛ>2B，假定理想均匀采样与完整样本，不含量化、噪声或有限记录误差。<a class="fourier-link" href="https://www.ti.com/lit/pdf/snaa079">依据：TI · 采样定理与重建 →</a> {#s3hint .hint}

第 4 步 · 换个视角 {#s4k .step-kicker i18n=text}

一个实正弦有正、负频率分量；此图仅画**正频率峰的位置**，不是完整幅相谱。理想均匀采样使双边频谱以 fₛ Hz 为间隔复制；已知带限 B&lt;fₛ/2 时，选取双边基带并作理想重建。这里显示的 [0,fₛ/2] 只是正频率那一半，不能单靠峰位置还原波形。拖 fₛ 看复制峰怎样折入此区。<a class="fourier-link" href="../../transforms/fourier/#step5">到傅里叶页比较频谱 →</a> <a class="fourier-link" href="../../transforms/z-transform/#step5">到Z页换算：复制间距：fₛ Hz，或对应的 2π/T rad/s →</a> {#s4e .explain}

::: html step4-1
:::

注意混叠的本质：它不是"信号被弄脏了一点"，而是**高频的信息被原样搬进低频、还冒充低频**。采样一旦完成，原峰和混叠峰长得一模一样，事后没有任何滤波器能把它们分开——只能在采样之前防。 {#s4hint .hint}

## 采样之前，先学会眯眼 {#step6 h2=s6t}

::: strings
nav6: 6 先眯眼
:::

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

抗混叠要在抽取前抑制来不及表示的高频。两侧使用同一原图和抽取管线：右侧先做两遍**有限盒式卷积模糊**。比较纹路能否减弱、细节损失多少。盒式滤波有旁瓣，不能保证所有混叠都消失；结果随图案和步长而变。这是图像抽取示例，不是理想砖墙低通。 {#s6e .explain}

::: html step6-1
s6direct: 直接抽取
s6blur: 先模糊再抽取
patScene: 风景 + 细条纹
:::

音频中也要在模数转换前做抗混叠滤波。以20 kHz通带与44.1 kHz采样率为例，奈奎斯特频率为22.05 kHz，留下2.05 kHz过渡区供实际滤波器衰减；不是在20 kHz突然切断。这说明带宽预算，不是对44.1 kHz历史选择的推导。实际阻带衰减、可听上限与硬件性能另需指标。 {#s6audio .explain}
