## 先问一句：它还活着吗？ {#step0 h2=s0t}

::: strings
nav0: 0 会死的波
:::

第 0 步 · 钩子 {#s0k .step-kicker i18n=text}

这条波是 e<sup>σt</sup>·cos(ωt)：一首边唱边变音量的歌。σ 是它的「寿命参数」：σ < 0，声音越唱越弱，最后衰死；σ = 0，不强不弱永远唱下去——**这正是傅里叶变换的世界**，它只处理这种「永远在响」的音；σ > 0，声音越唱越响，涨爆出框。真实世界里，衰死和涨爆才是常态。傅里叶管不了它们，拉普拉斯就是来管这个的：**给每个频率 ω，再配一个 σ**。 {#s0e .explain}

::: html step0-1
s0sig: σ · 衰减（−）/ 增长（+）
s0om: ω · 频率
:::

把 σ 精确推到 0 停一秒：这条「不死」的波，就是<a class="fourier-link" href="../fourier/#step0">傅里叶页</a>里那些旋转圆画出来的东西。所有真实信号都会死，傅里叶却假设它们不死——它靠的是周期延拓的想象。拉普拉斯不装：它把 σ 写进变换里。下一站你会看到，平面就此多出一整个维度。 {#s0hint .hint}

start: 开始探索 ↓
:::

## 一张地形图：每个频率都有了寿命坐标 {#step1 h2=s1t}

::: strings
nav1: 1 s 平面
:::

第 1 步 · s 平面 {#s1k .step-kicker i18n=text}

信号就用最经典的一个：x(t) = e<sup>−at</sup>·u(t)（t < 0 时为 0，t ≥ 0 后指数衰减）。它的拉普拉斯变换是 X(s) = 1/(s + a)，其中 s = σ + jω。先把两根轴认清：**横轴 σ 管寿命**（越往左衰减越快，越往右越容易涨爆），**纵轴 ω 管频率**。固定 a，在整个 s 平面上把 |X(s)| 画成地形：**颜色越亮、地形越高**。有一根尖峰冲破天际——那是**极点**，立在 s = −a 处：分母在那里等于 0，变换在那里发散。拖动探针到处量：X(s) 的值由公式逐点算出，不是看图估的（渲染分辨率只是画布的事，见图下注）。还有个小秘密：这个信号的 |X(s)| 恰等于**到极点距离的倒数**——离尖峰越远，地形越平。 {#s1e .explain}

X(s) = 1 / (s + a)，s = σ + jω，x(t) = e^{−at}·u(t) {#s1formula .formula i18n=text}

::: html step1-1
s1aLab: a（极点在 s = −a，拖动看尖峰搬家）
:::

渲染口径：地形在离屏低分辨率网格上逐点按闭式 log<sub>10</sub>(1+|X(s)|) 计算、经 γ = 0.6 幂次提亮（单调映射，只变颜色、不变数值）后放大显示，色标上限钳制在 |X| = 99——极点处的真实值是 ∞，画面上「封顶」只是显示钳制。远处颜色深也不等于值是 0，只是被对数压低了。探针读数与对账一律走闭式原式，不用渲染网格插值。 {#s1note .hint}

对比一下傅里叶页：那里每个信号只有一条频谱曲线。这里不是一条线，是**一整张图**：横轴 σ 管寿命、纵轴 ω 管频率。第 2 步你会亲手在这张图上切一刀，看傅里叶是怎么从图里掉出来的。 {#s1hint .hint}

## 傅里叶，是 σ = 0 处的那一刀 {#step2 h2=s2t}

::: strings
nav2: 2 切片
:::

第 2 步 · 切片 {#s2k .step-kicker i18n=text}

在第 1 步的地形图上竖着切一刀：固定 σ = σ<sub>0</sub>，沿 ω 方向取一列值，就是右侧的曲线 |X(σ<sub>0</sub> + jω)|。把这一刀拖到 σ<sub>0</sub> = 0——切面正好贴着虚轴，这条曲线有个你认识的名字：**傅里叶幅度谱** 1/√(a² + ω²)，分毫不差。但小心：这一刀必须切在**收敛域**（σ > −a 的那半边）里。把 a 拖成负数，极点跑到右半平面，σ = 0 这一刀就掉出了收敛域——傅里叶谱**不存在**，页面不会给你画一条假的；而 σ<sub>0</sub> 再往右挪一点、回到收敛域里，拉普拉斯的切片照样好好的。 {#s2e .explain}

::: html step2-1
s2aLab: a（极点在 s = −a）
s2sLab: σ₀ · 切片位置
s2btn0: 切到 σ₀ = 0（傅里叶那一刀）
:::

这就是「有些信号没有傅里叶变换、却有拉普拉斯变换」的全部原因：傅里叶只允许站在 σ = 0 这一条线上看世界，线掉出收敛域，它就瞎了；拉普拉斯站满整个平面，总有一片区域能看。采样页里那句「恰好 2f 看相位」是采样版的边界故事，这里是变换版的。 {#s2hint .hint}

::: strings
s2roIn: a = {a} · σ₀ = <span>{s0}</span> · 此切片在收敛域内（σ₀ > {bd}）✓ · |X(σ₀ + j0)| = <span>{peak}</span>{fNote}
s2roOut: a = {a} · σ₀ = <span>{s0}</span> · 此切片 <b>不在收敛域内</b>（需要 σ₀ > {bd}）：积分发散，这条谱线不存在——不是没画出来，是它真的没有
s2fNote: " · 这正是傅里叶幅度谱 1/√(a²+ω²)，已与闭式逐点叠合"

cvSlice: 切片 σ₀

:::

## 同一个式子，两个信号 {#step3 h2=s3t}

::: strings
nav3: 3 同式异域
:::

第 3 步 · 同式异域 {#s3k .step-kicker i18n=text}

全页最重要的一场戏。信号 A：e<sup>−at</sup>·u(t)，活在 t ≥ 0；信号 B：−e<sup>−at</sup>·u(−t)，活在 t ≤ 0，符号还反着。算它们的拉普拉斯变换——**代数式一字不差，都是 1/(s + a)**。区别只在收敛域：A 要求 σ > −a，B 要求 σ < −a。切换信号看阴影翻面，再把探针拖到任意一点：同一个 s，对 A 收敛、对 B 可能发散。结论先说死：**只写变换式、不写 ROC，等于没说完**——没有 ROC，你根本不知道说的是哪个信号。 {#s3e .explain}

两个信号的 X(s) 都是 1 / (s + a) —— 式子相同，ROC 不同 {#s3formula .formula i18n=text}

::: html step3-1
s3btnA: 信号 A · 右边 e^{−at}·u(t)
s3btnB: 信号 B · 左边 −e^{−at}·u(−t)
s3aLab: a（两信号共用，极点同在 s = −a）
:::

为什么收敛只看 σ、不看 ω？因为 |e<sup>−st</sup>| = e<sup>−σt</sup>：积分收不收敛，只取决于实部 σ 把指数压不压得住，虚部 ω 只是让它在那儿转圈，不帮忙也不捣乱。所以 ROC 永远是竖条带——这也是探针判定只报 σ 的原因。考试里 ROC 画成别的形状，多半画错了。 {#s3hint .hint}

s3curB: 信号 B（左边）
s3ro: 当前信号：<b>{cur}</b> · 探针 σ = <span>{sig}</span>（ω = {om}）· 对信号 A（需 σ > {bd}）：<b>{va}</b> · 对信号 B（需 σ < {bd}）：<b>{vb}</b>
s3conv: 收敛 ✓
s3div: 发散 ✗
cvRoc: ROC（收敛）

## 系统的性格，写在极点的位置里 {#step4 h2=s4t}

::: strings
nav4: 4 拖极点
:::

第 4 步 · 拖极点 {#s4k .step-kicker i18n=text}

换上二阶系统 H(s) = 1/(s² + 2ζω<sub>0</sub>s + ω<sub>0</sub>²)。它的一对极点可以在 s 平面上拖：拖在实轴上方是一对共轭极点（系统会「嗡嗡」振荡着衰减）；拖回实轴上，极点变成实数——可以落在同一点（临界），也可以**掰开成两个**各走各的（过阻尼）。右边实时重画冲激响应 h(t)（闭式解，不是数值仿真）与它的 ±包络线：<strong>极点实部 σ<sub>p</sub> 就是衰减率</strong>——极点离虚轴越远，包络 e<sup>σ<sub>p</sub>t</sup> 压得越狠。拖到右半平面试试：包络反过来往上张，响应涨爆画框。 {#s4e .explain}

::: html step4-1
s4p1: 稳定衰减振荡
s4p2: 临界阻尼
s4p3: 过阻尼
s4p4: 等幅振荡
s4p5: 发散爆炸
s4tLab: 包络探针时刻 t
:::

口径：欠阻尼时 h(t) = e<sup>σ<sub>p</sub>t</sup>·sin(ω<sub>d</sub>t)/ω<sub>d</sub>，包络 E(t) = e<sup>σ<sub>p</sub>t</sup>/ω<sub>d</sub>；临界时 h(t) = t·e<sup>pt</sup>，曲线自身即包络；过阻尼两实极点 p<sub>1</sub>、p<sub>2</sub> 时 h(t) = (e<sup>p<sub>1</sub>t</sup> − e<sup>p<sub>2</sub>t</sup>)/(p<sub>1</sub> − p<sub>2</sub>)，包络取两分量绝对值之和 (e<sup>p<sub>1</sub>t</sup> + e<sup>p<sub>2</sub>t</sup>)/|p<sub>1</sub> − p<sub>2</sub>|。全部闭式，评审可逐点复算。 {#s4note .hint}

再说一句读数里的「—」：两个实极点**异号**（一正一负）时，ω<sub>0</sub> = √(p<sub>1</sub>p<sub>2</sub>) 是虚数、ζ 也就没有定义——这一格如实给「—」，不是没算出来；一极点恰在原点时 ω<sub>0</sub> = 0，同样无定义。遇到「—」就直接看极点坐标与状态判读：只要有极点落在右半平面，系统就是不稳定的。 {#s4dash .hint}

::: html step4-2
s4linkTxt: 控制页里 PID 拼命在做的事，就是把闭环极点往左半平面摁：摁得越深，车站得越稳、回正越快——去那页亲手摁一摁 →
s4lkC: 反馈与控制 →
:::

手感练习：先把极点拖到贴近虚轴（σ<sub>p</sub> ≈ −0.1），看它把尾音拖得老长；再一口气拖到 σ<sub>p</sub> = −2.5，尾音立刻被掐断。ζ 越小振荡越「飘」，ζ ≥ 1 就完全振不起来了——预置五档挨个点一遍，比背定义快。 {#s4hint .hint}

## 给一条 ROC，断因果与生死 {#step5 h2=s5t}

::: strings
nav5: 5 判读台
:::

第 5 步 · 判读台 {#s5k .step-kicker i18n=text}

最后练判读。给一个 H(s) 和一条 ROC（极点把平面切成三条竖带，选一条），三件事当场断清：h(t) 是**右边、双边还是左边**信号；系统**因果**吗；系统**稳定**吗。判据只有两条，请记牢：**因果 ⟺ ROC 在最右极点之右**（此时每个分量都是右边信号）；**稳定 ⟺ ROC 包含虚轴 σ = 0**。换个 H(s) 注意极点跑到右半平面时：想要稳定，就只能选包含虚轴的那条带——而那注定不是因果的。鱼和熊掌，ROC 说了算。 {#s5e .explain}
