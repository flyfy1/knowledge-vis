## 傅里叶谱能告诉你「何时」吗？ {#step0 h2=s0t}

::: strings
nav0: 0 频谱的盲区
:::

第 0 步 · 频谱的盲区 {#s0k .step-kicker i18n=text}

这一步要回答：只看傅里叶频谱，能分辨「先低音后高音」和「先高音后低音」吗？**傅里叶频谱**把整段信号拆成各个频率（单位 Hz，即每秒振动次数）的正弦分量，并给出每个分量的强度。下图 A 是先 12 Hz、后 40 Hz 的信号，B 是把 A 在时间上整段倒放。拖动「换音时刻」：两条波形随之改变，而下方频谱里青色柱（A）与橙色点（B）始终重合。 {#s0e .explain}

::: html step0-1
cv0: 信号 A、倒放信号 B 及两者的幅度谱
s0uL: 换音时刻（占整段 1 s 的比例）
s0reset: 重置换音时刻
:::

幅度谱 = 各频率分量的大小。把实信号在时间上整段倒放，幅度谱不变，只有各分量的相位变——所以幅度谱本身分不出先后。 {#s0term .term i18n=text}

::: strings
s0A: A：先 12 Hz 后 40 Hz
s0B: B：A 倒放（先 40 Hz 后 12 Hz）
s0Spec: 幅度谱（0–64 Hz）
s0LegA: 青色柱 = A 的谱
s0LegB: 橙色点 = B 的谱
s0ro: 换音时刻 {u}：A 的 12 Hz 分量强度 <b>{lo}</b>，40 Hz 分量强度 <b>{hi}</b>（1 表示整段都是单位振幅正弦）。A、B 两谱的最大差异 <b>{d}</b>（只剩舍入误差），而两条波形的均方根差是 <b>{r}</b>（明显不同）。
:::

## 给傅里叶装一个滑动的小窗口 {#step1 h2=s1t}

::: strings
nav1: 1 加窗的代价
:::

第 1 步 · 加窗的代价 {#s1k .step-kicker i18n=text}

这一步要回答：只分析一小段信号，能同时看清「何时」和「多少 Hz」吗？**短时傅里叶变换（STFT）**每次只对窗口内的信号做傅里叶分析，窗口沿时间滑动，结果画成**谱图**：横轴时间、纵轴频率、越亮表示该频率分量越强。窗口是高斯形，长度 L 个采样点（采样率 256 点/秒）。拖动「窗口长度」，信号保持不变：观察亮带是变粗还是变细，以及 12 Hz 亮带在 0.5 s 换音处消失得多快。 {#s1e .explain}

::: html step1-1
cv1: 信号的谱图与窗口形状
s1LL: 窗口长度 L
s1reset: 重置窗口长度
:::

半高全宽 = 亮带高于峰值一半处的整个宽度，越小说明频率定位越准（在图上量出）。σt = 高斯窗的标准差，用来度量窗口在时间上有多宽（由 L 算出，不是从图上量的）。 {#s1term .term i18n=text}

::: strings
s1Guide: 虚线 = 真实音调 12 / 40 Hz 与换音时刻
s1Win: 窗口形状（按真实时长）
s1ro: 窗口长 <b>{T} ms</b>。频率方向：12 Hz 亮带在 t = 0.25 s 处的半高全宽约 <b>{w} Hz</b>；时间方向：窗口的时间宽度 σt = <b>{st} ms</b>（按 L 算出）。窗口变长，频率更准、时间更糊；变短则相反。
:::

## 小波：窗口随频率伸缩 {#step2 h2=s2t}

::: strings
nav2: 2 伸缩的小波
:::

第 2 步 · 伸缩的小波 {#s2k .step-kicker i18n=text}

这一步要回答：小波怎样做到「高频窗口窄、低频窗口宽」？**小波**是一小段会衰减的振荡（这里是 Morlet 小波：高斯包络乘以余弦）。选定分析频率 f，小波就被拉伸或压缩，使包络内始终含约 2 个周期；把它沿信号滑动，每个位置算一次「相似度」，即**小波系数**（取幅度，1 = 与单位正弦完全吻合）。拖动「分析频率」，位置不变：看橙色小波变胖还是变瘦、青色曲线的凸起落在哪半段；再拖「小波位置」或按「扫描」：亮线是小波已经扫过的部分。 {#s2e .explain}

::: html step2-1
cv2: 信号、滑动的小波和小波系数曲线
s2fL: 分析频率 f
s2tL: 小波位置
s2reset: 重置并停止
:::

本页统一用 ω₀ = 6 的 Morlet 小波：窗口宽度正比于 1/f，所以每个频率下小波「形状」相同，只有大小不同。 {#s2term .term i18n=text}

::: strings
s2play: ▶ 扫描
s2pause: ⏸ 暂停
s2Sig: 信号（先 12 Hz 后 40 Hz）与橙色小波
s2Wav: 橙色 = 当前位置的小波
s2Coef: 小波系数幅度（亮线 = 已扫过）
s2ro: 分析频率 <b>{f} Hz</b> → 包络标准差 <b>{s} ms</b>（有效窗口约 {d} ms，f 越大越短）。当前位置系数 <b>{c}</b>；已扫过 {k} / {n} 个采样点。
:::

## 固定窗口 vs 伸缩窗口 {#step3 h2=s3t}

::: strings
nav3: 3 尺度图
:::

第 3 步 · 尺度图 {#s3k .step-kicker i18n=text}

这一步要回答：一个长而低的音加两下短而高的点击，两种窗口都能看清吗？信号是 8 Hz 的长音（约 0.1–0.5 s）加相隔 80 ms 的两次 48 Hz 点击（约 0.66 s 与 0.74 s）。上图是固定窗口的谱图（STFT），下图是小波的**尺度图**（把每个频率的小波系数排成图，频率轴为对数）。分别拖动「STFT 窗口长度」和「小波周期参数 ω₀」（ω₀ 越大，小波包络内的周期越多），保持另一项不变：观察 8 Hz 亮带是否变细、两次点击能否分成两团。每张图按自己最亮的格子归一，图间不比较亮度。 {#s3e .explain}

::: html step3-1
cv3: 同一信号的谱图与尺度图
s3LL: STFT 窗口长度 L
s3WL: 小波周期参数 ω₀
s3reset: 重置两个参数
:::

σt（时间宽度）与 σf（频率宽度）的乘积对高斯窗固定为 1/(2π)：改变窗口只是在两者之间挪动精度，不能同时变小。 {#s3term .term i18n=text}

::: strings
s3Stft: 上：固定窗口谱图 (STFT)
s3Cwt: 下：小波尺度图 (ω₀ 可调)
s3ro: σ 是窗口幅度包络的标准差，用来度量窗口宽度。STFT：所有频率同一窗口，σt = <b>{st} ms</b>、σf = <b>{sf} Hz</b>。小波：8 Hz 处 σt = <b>{t1} ms</b>、σf = <b>{f1} Hz</b>；48 Hz 处 σt = <b>{t2} ms</b>、σf = <b>{f2} Hz</b>。经验判断：窗口 σt 小于两事件间隔（80 ms）的一半时，两次点击才较易分成两团。
:::

## 用最少的数描述突变 {#step4 h2=s4t}

::: strings
nav4: 4 Haar 与稀疏
:::

第 4 步 · Haar 与稀疏 {#s4k .step-kicker i18n=text}

这一步要回答：一条带尖锐跳变的信号，要保留多少个系数才够？把信号展开成一组正交基的系数（Haar 小波基，或傅里叶余弦/正弦基，各 128 个系数），只保留绝对值最大的 K 个，其余置零再还原。**RMSE（均方根误差）**：还原信号与无噪声原信号逐点差的平方取平均再开方，越小越好。拖动「保留数 K」：看橙色（Haar）与青色（傅里叶）在脉冲边缘的差别，以及哪个 RMSE 先降下去；再拖「噪声」：灰线变毛，但只留少量大系数的还原会滤掉一部分。 {#s4e .explain}

::: html step4-1
cv4: 原信号与两种基的稀疏还原
s4KL: 保留系数个数 K
s4NL: 噪声标准差
s4reset: 重置 K 与噪声
:::

信号 = 弱正弦 + 第 45–76 点的宽脉冲 + 第 100–103 点的窄脉冲；宽脉冲边界在奇数位置（45、77），避免 Haar 因对齐占便宜。K 很小时傅里叶略占优，K 增大后 Haar 反超（噪声大时差距缩小）。 {#s4term .term i18n=text}

::: strings
s4In: 输入（灰 = 含噪声，绿 = 无噪声原信号）
s4H: Haar 还原（RMSE {e}，绿线 = 原信号）
s4F: 傅里叶还原（RMSE {e}，绿线 = 原信号）
s4Leg: 横轴：128 个采样点；两者都只保留 K 个系数。
s4ro: 保留 <b>{K} / {n}</b> 个系数，噪声标准差 {sd}。输入本身与原信号的 RMSE <b>{ri}</b>；Haar 还原 <b>{rh}</b>；傅里叶还原 <b>{rf}</b>；当前较小者：<b>{who}</b>。这个比较只对本页这条信号成立：换成纯正弦，傅里叶只需 1 个系数就会胜出。
s4w_h: Haar
s4w_f: 傅里叶
s4w_e: 相同
:::

## 收束：频率、时间与窗口 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

回顾这条线：傅里叶谱回答「有什么」，加窗和小波让它同时回答「什么时候有」，稀疏表示则回答「最少用多少个数描述它」。 {#s5e .explain i18n=text}

::: html step5-1
c1t: 谱不含先后
c1b: 幅度谱对时间倒放不变，先低后高与先高后低同谱（第 0 步，适用于实信号的幅度谱）。
c2t: 窗口的取舍
c2b: 窗口越长频率越准、时间越糊；对高斯窗 σt·σf = 1/(2π) 固定（第 1、3 步）。
c3t: 窗口随频率伸缩
c3b: 小波使 σf/f = 1/ω₀ 不变：高频给出细的时间定位，低频给出细的频率定位（第 2、3 步）。
c4t: 稀疏取决于信号
c4b: 在本页这条无噪声信号上，含突变的部分让 Haar 更省系数；平滑周期信号则傅里叶更省，没有通用赢家（第 4 步）。
modelT: 模型与局限
modelB: 全页是离散教学计算：采样率 256 Hz、256 点（第 4 步 128 点）；窗口为高斯窗或 Morlet 小波（ω₀ 默认 6）；信号边界外补零，所以边缘处的系数偏小；谱图和尺度图是示意，不是仪器测量。Haar 对比只覆盖一条人工构造的信号。
:::
