## 一串旋转的圆，画出一个小人 {#step0 h2=s0title}

::: strings
nav0: 0 钩子
:::

第 0 步 · 先看结论 {#s0kicker .step-kicker i18n=text}

::: html step0-1
s0explain: 先别管原理，看画面上方和左方那两串转动的圆：上面一串管**横坐标**，左边一串管**纵坐标**，两条投影虚线的交点，就是正在描出小人轮廓的笔尖。这就是傅里叶变换最震撼的一面——**任何图形，都能拆成一堆旋转的圆**。本页会从一条正弦波开始，一步步讲清它为什么成立；最后一步，你还能**亲手画一个图形**，让圆圈们把它画出来。
labelN: 谐波项数 N
readoutError: 重构误差
:::

先别动手，看 N 自己从 1 慢慢涨到 40：圆越多，误差越小、小人越像；想自己控制就拖滑杆（自动播放会停）。误差口径：重构点与原轮廓点之间的均方根误差 ÷ 图形尺寸 × 100%。数学上这一幕写出来就是：f(t) = Σ (a<sub>k</sub> cos kt + b<sub>k</sub> sin kt)——横、竖坐标各有一套这样的和，每一项对应一个圆。这些项有个名字叫**谐波**：频率是基频整数倍（1 倍、2 倍、3 倍……）的正弦成分，滑杆上的 N 数的就是用到的谐波个数。 {#s0hint .hint}

## 一条正弦波，只有三个旋钮 {#step1 h2=s1title}

::: strings
nav1: 1 波是什么
:::

第 1 步 · 波是什么 {#s1kicker .step-kicker i18n=text}

::: html step1-1
s1explain: 最简单的波是正弦波。它完全由三个参数决定：**频率**决定它抖得多快，**振幅**决定它摆多高，**相位**决定它从哪里开始。拖动滑杆试试——顺便点「听一听」，频率变高，声音真的会变尖。
labelFreq: 频率
labelAmp: 振幅
labelPhase: 相位
s1sound: 🔊 听一听这个波
s1freeze: ❄ 冻结波形
:::

小知识：声音就是空气的波。频率 1 Hz 在这里是为了看清波形；真实音调要快几百倍，所以播放时会把频率放大到可听范围。想看清「相位」是什么：先点「冻结波形」让波停下，再拖相位滑杆——整条波会整体左右平移，t = 0 参考线处的橙点高度正好等于 sin（相位）。 {#s1hint .hint i18n=text}

::: strings
s1soundStop: ⏹ 停止声音
s1unfreeze: ▶ 继续滚动
:::

## 复杂波形 = 简单波形相加 {#step2 h2=s2title}

::: strings
nav2: 2 波叠加
:::

第 2 步 · 波可以叠加 {#s2kicker .step-kicker i18n=text}

::: html step2-1
s2explain: 把几条正弦波在每个时刻的高度直接相加，就得到一条新波形。下面三条彩色波各自可调，最下方白色粗线是它们的和。大图里分量与总和用的是**同一把尺子**：任选一个位置量一量，总和的高度恰好等于三条分量高度之和（为了让总和不画出画布，整张图会一起等比缩放，但比例从不撒谎）。试试点「方波配方」：只用 1、3、5 倍频率、振幅按 1、1/3、1/5 递减，方波的雏形就出现了。
s2presetSquare: 方波配方（1 + 3 + 5）
s2presetRandom: 随机一组
:::

反过来想：如果任何复杂波形都能这样「加」出来，那它是不是也能被「拆」回这几条正弦波？这正是傅里叶变换在做的事。 {#s2hint .hint i18n=text}

第 3 步 · 关键一跳 {#s3kicker .step-kicker i18n=text}

第 4 步 · 圆圈套圆圈 {#s4kicker .step-kicker i18n=text}

::: html step4-1
s4explain: 把第 3 步的圆首尾相连：第二个圆骑在第一个圆的笔尖上，以 3 倍速旋转；第三个 5 倍速……每个圆贡献一条正弦波（回扣第 2 步），最后一个笔尖的高度轨迹，就是所有波的和。拖动滑杆增加圆的个数，看方波如何成形。
s4labelN: 圆的个数 N
s4overLabel: 当前过冲：
s4hint: 注意方波拐角处那个小小的「尖」：无论加多少个圆，它都不会消失，只会变得更窄。这叫**吉布斯现象**：过冲约为跳变高度的 **9%**（从 −1 跳到 +1，跳变是 2，尖会冲到约 1.18）。这是数学写死的常数，不是画得不够精细。
:::

## 换个视角：从波形到频谱 {#step5 h2=s5title}

::: strings
nav5: 5 频谱视角
:::

第 5 步 · 傅里叶变换本体 {#s5kicker .step-kicker i18n=text}

::: html step5-1
s5explain: 前四步我们都在「拼」。傅里叶变换做的是反向的「拆」：给它任意波形，它告诉你里面每个频率的正弦波各有多强。左边是波形（**时域**），右边是拆解结果（**频域**，叫频谱）。切换波形看一看：方波只含奇数频率，三角波的频谱衰减快得多，锯齿波则每个频率都有份。<a class="fourier-link" href="../../systems/frequency-response/#step0">拆出来的频谱拿来干什么：去看滤波器怎样按频率挑食 →</a>
s5square: 方波
s5triangle: 三角波
s5saw: 锯齿波
s5ecg: 模拟心电图
s5timeTitle: 时域：波形 x(t)
s5specTitle: 频域：频谱（每个频率多强）
:::

注：右边柱高按当前波形**自身最强的成分归一化**（最强的那根顶格），看的是成分之间的比例；切换波形时纵轴尺度会跟着变，想比绝对强弱请看下方读数里的幅值。另外「模拟心电图」是教学合成的近似波形，不是真实心电数据；它这种脉冲型波形的能量摊在很多频率上、没有单一主导成分，所以下方读数里每个幅值都偏小、最强的也不在基频处——这正是脉冲型波形的特征，不是算错了。 {#s5hint .hint}

::: html step5-2
s5formulaText: 别怕，这个公式只是在说一句话：**拿一台转速为 f 的「圆」去和波形逐点相乘再加总**，测出波形里频率 f 的成分有多强、相位差多少。其中的 e<sup>−2πift</sup> 不是别的——它就是第 3 步那个在单位圆上旋转的点（数学家把「旋转」写成了指数的形式）。对每个 f 都测一遍，就得到整条频谱。再补一句桥：本页演示的都是**周期波形**，周期信号只在基频的整数倍上才有成分，所以频谱是一根根分立的柱子——这正是上面公式在周期信号上的样子（数学上叫傅里叶级数）；换成非周期的信号，柱子会密到连成一条连续的曲线。
:::

第 6 步 · 终章 {#s6kicker .step-kicker i18n=text}

::: html step6-1
s6explain: 在下面画布里用鼠标或手指**画一条闭合曲线**（比如一颗心、一个星星、你的名字首字母），或者点一个预设图形。页面会把轮廓点的**横坐标和纵坐标分开**，各做一次真正的离散傅里叶变换（DFT）：上方一串圆负责横坐标，左方一串圆负责纵坐标，两条投影虚线的交点就是笔尖。拖动 N 看误差读数不断下降——**傅里叶变换，就是把一条曲线拆成横竖两个方向上的旋转之和。**
:::
