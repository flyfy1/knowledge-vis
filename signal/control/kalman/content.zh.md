## 读数在抖，实际位置在哪里？ {#step0 h2=s0t}

::: strings
nav0: 0 从抖动读数估位置
:::

第 0 步 · 从测量估位置 {#s0k .step-kicker i18n=text}

这一步要回答：**带误差的测量，能帮我们更准地估计位置吗？**一个点沿直线移动。图的横轴是时间步，纵轴是位置；十字标是每次测到的位置。测量会随机偏离真实位置，这种随机误差叫噪声。先猜真实位置随时间怎样变化，再点「运行卡尔曼」。最后点「揭晓真实位置」，比较估计和真值。手机定位也要处理类似问题，但实际系统更复杂。 {#s0e .explain}

::: html step0-1
s0run: 运行卡尔曼
s0reveal: 揭晓真实位置
s0reset: 重置
:::

本场景的数据这样生成：真实位置每步加一个随机扰动（σ = 0.25），称为随机游走；第 45 步另加一次 +3 的突变。测量 = 真值 + 高斯噪声（σ = 1.0）；高斯噪声通常偏得少，偶尔偏得多，正负对称。随机数种子为 7，即固定生成起点，重跑可得同一批数据。第 0 步设 Q = 0.0625、R = 1：Q 是模型每步未能预测的扰动方差，R 是测量误差方差。方差是标准差的平方。这些参数匹配随机噪声，但模型未预知那次突变；第 3 步会换场景调参数。 {#s0hint .hint}

::: html step0-2
start: 开始探索 ↓
:::

## 取平均以后，为什么还会跟不上？ {#step1 h2=s1t}

::: strings
nav1: 1 直接测量与平均
:::

第 1 步 · 比较两种简单方法 {#s1k .step-kicker i18n=text}

这一步要回答：**直接用测量，和先取平均，各有什么代价？**仍看上一批数据。直接用测量，能立刻反映变化，也会保留全部测量噪声。滑动平均是取最近 W 个测量的平均值：随机误差能相互抵消一些，但旧位置也会混进结果。第 45 步突变后，窗口要经过 W 步才完全换成突变后的测量。窗口装满后，每个测量的权重都是 1/W；开始时数据不足，就对已有测量取平均。 {#s1e .explain}

::: html step1-1
s1wLab: W · 平均最近多少个测量
s1showRaw: 原始测量（连线）
s1showMa: 滑动平均
s1showKf: 卡尔曼估计
:::

先增大 W，观察曲线是否更平滑，以及第 45 步之后是否更慢跟上。再减小 W，对照 RMSE 读数。平滑程度和准确程度要分开看；不同 W 可能改变方法的排名。卡尔曼用预测与测量各自的不确定度计算新测量的权重，下一步会拆开这个计算；权重也可能逐渐稳定。 {#s1hint .hint}

::: strings
s1ro: 同一批数据的位置 RMSE（均方根误差：每个误差平方、取平均、再开方，与位置同单位，越小越准）：原始测量 = <span>{rr}</span> · 滑动平均（W = {w}）= <span>{rm}</span> · 卡尔曼估计 = <span>{rk}</span>
:::

## 新测量来了，预测该改多少？ {#step2 h2=s2t}

::: strings
nav2: 2 预测—更新
:::

第 2 步 · 预测—更新 {#s2k .step-kicker i18n=text}

这一步要回答：**拿到新测量后，位置估计该改多少？**滤波器保存位置估计 x̂，以及估计误差的方差 P；P 越大，表示它认为估计越不确定。图中的高斯曲线是钟形的，横轴是可能的位置，曲线越高表示附近的位置越可能；中心是 x̂，宽度由标准差 √P 决定。**先预测：**本模型假设下一位置平均不变，所以 x̂⁻ 沿用 x̂，但 P 要加上扰动方差 Q；上标 ⁻ 表示尚未用新测量。**再更新：**z 是新测量，R 是它的误差方差。K 叫卡尔曼增益，表示朝 z 修正多大比例。更新后的估计称为后验，供下一轮继续预测——这正是贝叶斯更新的节奏：<a class="fourier-link" href="../../../probability/inference/bayes-updating/#step3">昨天的后验，是今天的先验 →</a>。下面用 Q = 0.0625、R = 1，与第 0 步相同。公式依次回答：预测是什么、修正比例多大、更新后得到什么。 {#s2e .explain}

预测：x̂⁻ = x̂ ， P⁻ = P + Q ｜ 增益：K = P⁻ / (P⁻ + R) ｜ 更新：x̂ = x̂⁻ + K·(z − x̂⁻) ， P = (1 − K)·P⁻ {#s2formula .formula}

::: html step2-1
s2trajTitle: 累积轨迹：每处理一个测量，下面就多一个点（横轴 = 步数 k，纵轴 = 位置）
s2nextPred: 预测一步 →
s2play: 连播 10 步
s2reset: 重置
:::

操作顺序：先点一次「预测一步」——看上方曲线变宽，也看下方轨迹带末端张开（这就是 P 变大）；再点「用测量更新」——带收窄，新的估计点落到轨迹上。想看长期效果就点「连播 10 步」：它让滤波器一口气吃 10 个测量，盯着下方轨迹带——估计点一个接一个长出来、带越来越窄，P 降到稳态附近后基本不再下降，这就是「连播」要看的东西。注意：P 是按模型算出的不确定度，不是实际误差的实时测量；真实位置在第 45 步跳变时 P 不会自动变大，估计只能靠后面的测量一步步追回来。P⁻ 越大（R 固定）K 越大；R 越大（P⁻ 固定）K 越小。下一步可调 Q、R，查看参数怎样影响结果。 {#s2hint .hint}

## Q 与 R 怎样改变修正幅度？ {#step3 h2=s3t}

::: strings

第 3 步 · 调整 Q 与 R {#s3k .step-kicker i18n=text}

这一步要回答：**怎样设定对预测和测量的信任，才能既跟上变化又少抖动？**换一个模拟场景：真实位置缓慢随机变化（每步扰动 σ = 0.05），第 40 步突然增加 +4；灰虚线标出突变时刻，测量噪声 σ = 1。数据不随滑块改变。滑块只改滤波器的假设：**Q** 是模型每步未能预测的扰动方差，**R** 是测量误差方差。除 RMSE 外，再看两个恢复指标：**进入步数**是首次满足估计与真值相差不超过 ±0.5 时，距突变已过的步数；**带内占比**是从突变当步起，误差在此范围内的步数占比。前者越小越快，后者越大越稳。 {#s3e .explain}

## 为什么修正比例会逐渐稳定？ {#step4 h2=s4t}

::: strings
nav4: 4 权重何时稳定
:::

第 4 步 · 稳态 {#s4k .step-kicker i18n=text}

这一步要回答：**Q、R 一直不变时，K 会怎样变化？**本例跑 300 步，Q = 0.04、R = 2。上图比较两种初始方差 P₀：初值不同，但更新后的 P 都逐渐接近同一个值，这叫收敛；稳定后的值称为固定点。原因是本模型的 P 只由上一步的 P、Q、R 计算，不使用测量值。固定点满足 P = (P + Q)·R / (P + Q + R)：意思是更新一轮后 P 仍不变。这是本例的代数 Riccati 方程，虚线标出它的解。上图纵轴按倍数分隔，等距不代表等差。 {#s4e .explain}

::: html step4-1
:::

对比两张图：上图说明 P 和 K 在本例中趋于稳定，下图说明固定 K 后的位置更新就是指数平滑。稳定的 α 可以由 Q、R 算出，不必只靠试调。这个结论针对本页的一维随机游走模型；其他运动模型未必等价于这种平滑器。**真实运动突然变化，不会自动改变这里的 P 或 K**；要改变它们，需要调整模型、Q、R，或改变可用测量。下一步换成同时预测位置和速度的模型。 {#s4hint .hint}

## 这套更新为什么成立，又能用在哪里？ {#step6 h2=s6t}

::: strings

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

这一步要回答：**前面的加权有何依据，怎样接到真实应用？**先看贝叶斯更新：用新证据修正已有判断。预测分布叫先验；似然表示不同真实位置对这次测量的支持程度；结合两者得到的分布叫后验。先验和测量误差都是高斯、且误差独立时，第 2 步的更新均值就是按精度加权的结果。精度是 1/方差：方差越小，权重越大。本站贝叶斯页用离散的二元假设展示相同的更新思想，无需先读过。再看控制：例如先估计小车位置和速度，再据此决定加速或刹车。在线性模型、二次代价和高斯噪声等条件下，卡尔曼估计可与最优控制组成 LQG（线性二次高斯控制）；二次代价指用误差和控制量的平方衡量代价。 {#s6e .explain}

::: html step6-1
s6card1T: 阿波罗导航
s6card1: 在 1960 年代的阿波罗导航中，卡尔曼滤波的扩展形式用于估计飞船运动。做法与本页相通：先用运动模型预测位置和速度，再用带误差的观测修正估计。航天器运动更复杂，需要更完整的模型。
s6card2T: 手机与传感器融合
s6card2: 手机定位可结合 GPS 位置与惯性传感器信息：加速度计测加速度，陀螺仪测转动。把不同传感器的信息结合起来，叫传感器融合。卡尔曼类方法可先用运动信息预测，再用位置测量修正，并根据各自误差分配权重。地图蓝点还可能经过道路匹配等处理，不能仅凭它的平滑程度判断用了哪种算法。
s6card3T: 非线性世界
s6card3: 汽车转弯时，运动关系可能不再是本页这样简单的线性关系；线性指输出是输入的加权和，曲线关系则可能是非线性的。常见扩展有：扩展卡尔曼滤波 EKF，在当前估计附近用线性关系近似；无迹卡尔曼滤波 UKF，让一组有代表性的点通过非线性模型；粒子滤波，用许多候选状态及其权重近似分布，并按观测调整权重。它们都有各自的近似和代价。在线性、高斯且模型与噪声假设正确时，标准卡尔曼滤波给出最小均方误差估计。异常测量、错误模型仍可能让实际结果很差。
s6fin: 回到最初的定位问题：**先预测位置，再按不确定度用测量修正，重复进行。**本页用模拟真值检查估计是否准确；实际定位通常没有这样的答案可对照。P 报告的是模型计算的不确定度，参数或模型不合适时，它也可能过于自信。手机在高楼间定位跳动，可能涉及信号反射等多种原因，不能据此断定 P 正在增大。读算法的输出时，要同时问：估计是什么、假设是什么、实际误差如何验证。
