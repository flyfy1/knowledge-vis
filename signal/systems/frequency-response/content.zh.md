## 盒子在按频率挑食 {#step0 h2=s0t}

::: strings
nav0: 0 挑食的盒子
:::

第 0 步 · 钩子 {#s0k .step-kicker i18n=text}

先看一个说不清原理的盒子。上图是一段波形：**慢而干净的正弦**，被一层**快而细密的噪声**糊住了。送进盒子之后再看输出——噪声大半消失，慢波几乎原样还在。盒子没见过这段波形，它凭什么知道哪部分该留、哪部分该扔？<a class="fourier-link" href="../../transforms/fourier/#step5">这些频率成分是谁拆出来的：傅里叶页的频谱步 →</a> {#s0e .explain}

::: html step0-1
:::

答案是它**只按频率办案**。下面逐档喂它纯正弦：频率拉高，输出一档比一档矮。每个频率都量一次，把「输出幅值 ÷ 输入幅值」记成一个点——扫完这一排点，盒子的食谱就显形了。 {#s0e2 .explain}

::: html step0-2
s0fLab: 试探正弦的频率 f
:::

口径就近说明：上方**输出波形**由解析稳态叠加画出（两个分量各乘闭式 |H|、各加闭式 φ 再相加），下方**放行率读数**由 ODE 时域仿真实测——同屏两个引擎、口径不同，第 1 步会把它们并排成两张牌对账。 {#s0engNote .hint}

这个盒子其实就是后面整页的主角：一阶 **RC 低通**。它对每个频率的放行率排成的曲线，就叫**频率响应 |H(ω)|**；它让每个频率迟到多少，是另一条曲线 φ(ω)。这一页要做的事，就是把这两条曲线量出来、读懂、再反过来用它们设计滤波器。 {#s0hint .hint}

start: 开始探索 ↓
:::

## 正弦进、正弦出：只改两件事 {#step1 h2=s1t}

::: strings
nav1: 1 正弦进正弦出
:::

第 1 步 · 频率响应是什么 {#s1k .step-kicker i18n=text}

把盒子打开：一个电阻 R 和一个电容 C，输出取电容两端的电压——最经典的一阶 **RC 低通**。给它喂 cos(ωt)，等暂态过去，输出**仍然是同频正弦**，只改两件事：幅值乘上 |H(ω)|，相位被推迟 φ(ω)。下面两张牌并排记着同一个频率的答案：一张是**公式算的**（解析牌），一张是**拿示波器从仿真波形上量的**（实测牌：页面真的用 RK4 数值积分了电路方程，再从稳态波形投影量出幅值与相位）。两张牌对不上，任何一张都不可信。拖动 ω 一档档扫，扫过之处会在下方的 |H| 曲线上逐点点亮。 {#s1e .explain}

::: html step1-1
:::

H(jω) = 1 / (1 + jωRC)，τ = RC = 1 s，ωc = 1/τ = 1 rad/s {#s1formula .formula i18n=text}

::: html step1-2
s1wLab: 输入角频率 ω
s1cardA: 解析牌 · 公式算的

特别看一眼 ω = ωc = 1：|H| 恰好是 1/√2 ≈ 0.707，φ 恰好是 −45°——这个频率叫**截止频率**，下一页整张波特图都围着它转。还有一个口径要说清：所谓「实测」，测的是**稳态**——刚接通那一小段暂态不算数，本页仿真先让电路跑过 6τ + 若干周期再量，评审复核时用的也是同一口径（方法写在实测牌下方）。 {#s1hint .hint}

::: strings

第 2 步 · 波特图 {#s2k .step-kicker i18n=text}

把第 1 步量出来的两条曲线换上**对数频率轴**、幅值改用**分贝**（dB = 20·log₁₀|H|)，就是工程师天天看的**波特图**。拖动 R、C，截止频率 ωc = 1/(RC) 跟着跑：−3 dB 点（|H| = 1/√2 处）标在幅值图上，高频段的渐近线以 **−20 dB/dec**（频率每涨 10 倍，幅值掉 20 dB）贴着曲线，相位图上 φ(ωc) = −45° 的点也标出来——三处标注全由当前 R、C 现场算。 {#s2e .explain}

## 移动平均的零点：点名枪毙一个频率 {#step3 h2=s3t}

::: strings
nav3: 3 移动平均的零点
:::

第 3 步 · 数字滤波器 {#s3k .step-kicker i18n=text}

换到离散时间：n 是整数样本索引，本步 ω 是数字角频率（rad/样本，也常记作 Ω），不是前面RC模型的 rad/s。若采样率 Fₛ 已知，则 ω = 2πf/Fₛ；未给 Fₛ 就不能指定对应的 Hz。移动平均把最近 M 个样本取平均；当 ω = 2πk/M 且 k 不是 M 的整数倍时，M项正负抵消，响应为零。ω=0或2π的整数倍处则 |H|=1，不是零点。先预测，再用首零点预设和实测样本对账。 {#s3e .explain}

## 相位也是性格：波形会被迟到毁掉 {#step4 h2=s4t}

::: strings
nav4: 4 相位毁波形
:::

第 4 步 · 相位 {#s4k .step-kicker i18n=text}

前三步只盯着 |H|。现在看另一半性格：**相位**。两个盒子同场竞技：**纯延迟**（|H| 恒为 1、一个频率都不砍，相位 −ωτ<sub>d</sub> 随频率线性增长）和 **RC 低通**（|H| 砍高频，相位 −atan(ωτ) 是弯的）。同一段脉冲串送进去：纯延迟的输出只是整体迟到、**形状一模一样**；RC 的输出边沿被抹圆、拖尾——因为不同频率分量迟到的量不一样，排好的队形被拆散了。下方画着两条相位曲线和 RC 的**群延迟** τ<sub>g</sub>(ω) = −dφ/dω（由相位公式数值微分算出）：它随频率变化，正是队形散掉的原因。 {#s4e .explain}

::: html step4-1
s4sigLab: 测试信号
s4sigPulse: 脉冲串
s4sigSquare: 方波
s4tauLab: 纯延迟 τd / RC 的 τ（同一滑杆）
:::

只看 |H| 会得出两个错觉：延迟「什么都没改」（它改了时间本身），RC「只是变安静」（它把波形弄散了）。音频里相位失真让声音发闷，图像里等价的效应让边缘发虚——**幅值决定每个频率还在不在，相位决定它们回来时还认不认得彼此**。还一句口径：上方 RC 波形是从零状态先**预积分 8 s**、暂态基本过去后取出的 0–8 s 稳态段，不是上电瞬间从零爬起的暂态全过程——要比的是稳态下「保形 vs 变形」，先把开关刚合上那一段排除在外。 {#s4hint .hint}

## 高通、带通与共振：同一套数学的三种挑食 {#step5 h2=s5t}

::: strings
nav5: 5 高通与带通
:::

第 5 步 · 换个接法 {#s5k .step-kicker i18n=text}

还是 R 和 C，只把输出改取**电阻两端**的电压，低通当场变**高通**：|H(jω)| = ωτ/√(1+(ωτ)²)——低频被拦、高频放行，−3 dB 点还在同一个 ωc = 1/τ。拖 τ 看截止点左右跑，和第 2 步的低通波特图对照着记：一对镜像。 {#s5e .explain}

::: html step5-1
s5tauLab: RC 高通的 τ（ωc = 1/τ）
:::

再进一步：把低通和高通背靠背，只放行**中间一段**频率，就是**带通**。标准二阶带通 H(jω) = 1 / (1 + jQ(ω/ω₀ − ω₀/ω))：峰在 ω₀ 处、峰高 1，**Q 品质因数**决定峰的胖瘦——Q 越大峰越尖。读数里有一项现场对账：从曲线上量出的半功率带宽 Δω（|H| 降到峰值 1/√2 的两点之距）应当满足 **Q = ω₀/Δω**，量出来的和滑杆设定的对不对得上，数字说了算。这里展示的是归一化带通输出；弹簧的位移/力响应有不同的分子，峰位和峰高不能直接照搬。<a class="fourier-link" href="../../../atlas/?trail=response&amp;node=resonance#response-lab">去知识地图对比：阻尼、位移峰与极点 →</a> {#s5e2 .explain}

::: html step5-2
s5f0Lab: 带通峰频 f₀
s5qLab: 品质因数 Q
:::

收音机调台就是带通在干活：峰对准电台频率，Q 决定能不能把相邻电台分开。Q 太小，两个台糊在一起；Q 太大，峰尖到连本台的高频成分都被削掉——挑食也要挑得恰到好处。 {#s5hint .hint}

## 设计台：按指标造一个滤波器 {#step6 h2=s6t}

::: strings
nav6: 6 终章 · 设计台
:::

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

最后一页是考场。任务：一段信号里，**50 Hz 是有用信号，500 Hz 是干扰**。工具箱里有三件工具，参数归你调，点「验收」，页面按所选滤波器的 |H| 公式**现场算**两个频率处的衰减并判定——达标多少、差多少 dB，当场报数，不预置结论。先剧透一句：一阶 RC 无论怎么调都过不了（衰减斜坡太缓），这是第 2 步 −20 dB/dec 的直接后果；二阶和移动平均各有活路——移动平均的活路藏在零点里：采样率 4000 Hz 时，零点在 k·(4000/M) Hz，想让 500 Hz 落在零点上，M 该取多少？ {#s6e .explain}

两句口径：一，二阶选项是**理想级联**——两级 RC 之间假定有缓冲放大器隔离，|H| 就是一阶的平方；真实无源级联有负载效应，后级会拖累前级，曲线形状会变（做硬件时要么加缓冲，要么按整体网络重算）。二，移动平均的衰减由 Dirichlet 公式按 Fs = 4000 Hz 折算数字频率 ω = 2πf/Fs 后真算；500 Hz 恰在零点上时衰减是数值零，读数以「＞120 dB」封顶显示。 {#s6note .hint}
