## 滑动平均：卷积最朴素的样子 {#step1 h2=s1t}

::: strings
nav1: 1 滑动平均
:::

第 1 步 · 先看它干活 {#s1k .step-kicker i18n=text}

这是一条带噪声的曲线（像气温或股价）。让一个**窗口**沿着曲线滑动，每到一处就把窗口里的数**取平均**，输出曲线立刻平滑了。窗口越宽越平滑——但峰谷也被磨钝、位置还往后拖。记住这个动作：**一个权重窗口，一边滑一边算加权和**，这就是卷积的全部骨架。 {#s1e .explain}

::: html step1-1
s1win: 窗口宽度 W
:::

这里每个点的权重都是 1/W（核 = [1,1,…,1]/W）。把权重换成别的分布，就是一般的卷积——下一步就把这个「滑着算」的过程拆开，一步一步算给你看。 {#s1note .hint i18n=text}

## 翻转、滑动、相乘、求和 {#step2 h2=s2t h2id=s2-title}

::: strings
nav2: 2 拆开算账
:::

第 2 步 · 拆开算账 {#s2k .step-kicker i18n=text}

离散卷积把核**翻转**成 g[−k]，再按输出索引 n **平移**，列 k 上就成了 g[n−k]。只把重叠处**逐项相乘并求和**，得到 y[n]。这里 f 从 k=0 到4，g 从 j=0 到2，范围外都补0。改任意数字，或直接选择输出 n 检查边缘；也可用原来的「单步」看对齐、乘积、求和三阶段。 {#s2e .explain}

s2f: 输入序列 f
s2g: 核 g
convSelect: 检查输出索引 n（方向键 ±1）
convSelected: 当前 n =
:::

直接选 n 会暂停、清除播放计时积累并显示本项的计算结果。图中先前已填的输出格按当前数组重算，不代表做过哪些学习步骤。n、k、j 都是离散索引，不是秒。 {#convSeekNote .hint i18n=text}

::: html step2-2
s2step: 单步 →
s2reset: 重置
:::

零延拓：f[k] 只在 0…4、g[j] 只在 0…2 存储值，其他索引视为0。要求 0≤k≤4 且 0≤n−k≤2，得到 k∈[max(0,n−2),min(4,n)]。这是索引重叠，不保证乘积或和非零；n=3 就可能正负抵消。输出可能非零的范围为0…6，外面没有重叠，y[n]=0；这里不循环绕回，也不裁成 same/valid。 {#convBounds .hint i18n=text}

输入实际值限定在−99…99；清空或非有限输入按0计算，提交时显示实际存储值。图格沿用概览舍入（约至两位小数，极小值可能显示0）；算式与索引列表最多9位有效数字，极小值用科学记数，含浮点舍入误差。请用下方列表核对小屏或小数细节。 {#convPrecision .hint i18n=text}

用默认数组检查 n=0、2、3、6：边缘为什么只有1对，中段有3对？n=3 明明重叠却为何输出0？把一项改成小数，再逐项对账；重置会恢复默认数组并暂停。 {#convQuestion .hint i18n=text}

::: html step2-3
convSourceTitle: 卷积、相关与边界依据
convCorrelation: 本步是实数、从索引0开始的完整线性卷积 y[n]=Σₖ f[k]g[n−k]。NumPy 官方文档给出同一定义与 N+M−1 长度。作比较，相关的一种滞后约定是 r[ℓ]=Σₖ f[k]g[k−ℓ]：随 k 增加，第二下标增加，而卷积中 n−k 减少；两种公式通常不同，特殊输入也可能算出相同值。相关还有相反滞后约定，这里不做第二套实验。连续卷积另在第3步用积分说明；本步不是连续时间近似。
s2formulaNote: 公式 (f \* g)[n] = Σ<sub>k</sub> f[k] · g[n − k] 里 g[n − k] 的减号，就是「翻转」的来源：n 固定时，k 增大、n−k 减小，核是倒着和 f 对齐的。动画里核的左右顺序与输入框相反，正是这一翻。
:::

## 滑动着求重叠面积 {#step3 h2=s3t}

::: strings
nav3: 3 重叠面积
:::

第 3 步 · 连续版 {#s3k .step-kicker i18n=text}

把序列换成连续的脉冲，同一套动作变成：让一个脉冲滑过另一个，**重叠部分的面积**就是该位移下的输出。拖动位移 τ，看下方输出曲线如何被逐点「长」出来。矩形 × 矩形会卷出一个**三角形**：底宽 = 两个脉冲宽度之和，峰值 = 完全重合时的重叠面积。 {#s3e .explain}

::: html step3-1
s3shift: 位移 τ
s3rr: 矩形 × 矩形
s3rt: 矩形 × 三角
:::

连续卷积写作 (f \* g)(τ) = ∫ f(t) · g(τ − t) dt：对每个位移 τ，把两条曲线逐点相乘再积分——积分的正是重叠部分的面积。换成三角脉冲，输出的边会变圆润：形状相乘再累加，棱角总被磨掉一些。 {#s3note .hint i18n=text}

::: strings
s3ro: τ = {tau} · 重叠面积（= 输出值）= {area}
cFixedF: f（固定）
cSlideG: g（滑动）
cOverlap: 重叠
cOut: 输出 (f \* g)(τ)
:::

## 与傅里叶相遇：卷积 = 频域里逐点相乘 {#step6 h2=s6t}

::: strings
nav6: 6 遇见傅里叶
:::

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

最后一件事，也是卷积和上一页的接头暗号：**时域里老老实实算的卷积，恰好等于把两者做傅里叶变换、逐个频率相乘、再变回来。**下面这张图里叠着两条曲线：青色实线是逐点苦算的结果，橙色虚线走的是频域捷径——两者叠画在同一张图里，下方给出两者的最大误差。换信号、换核，随便试，误差都应该近乎为零。 {#s6e .explain}
