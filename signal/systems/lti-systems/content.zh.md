## 扇一巴掌，听回声 {#step0 h2=s0t}

::: strings
nav0: 0 扇一巴掌

第 0 步 · 钩子 {#s0k .step-kicker i18n=text}

下面有三个黑箱，里面装的系统各不相同，先不告诉你是什么。认识一个系统最狠的办法，是给它**最短促、最标准的一击**：在 n = 0 送进去一个高度为 1 的尖峰、其余时刻全是 0——这就是**冲激 δ[n]**。箱子被这一击激起的全部动静，就是它的**冲激响应 h[n]**。逐个扇一巴掌，先听回声猜性格，再揭晓它是谁。 {#s0e .explain}

## 先认识这一巴掌：δ[n]，和万物分解 {#step1 h2=s1t}

::: strings
nav1: 1 δ 与分解

第 1 步 · δ 与分解 {#s1k .step-kicker i18n=text}

先把一巴掌本身看清楚。**筛选**：拿任意信号 x[n] 去乘 δ[n−k]（把冲激挪到第 k 时刻），乘积里其它针全被 0 压掉，只剩第 k 根、高度正是 x[k]——冲激像一把镊子，能从信号里夹出任意一个样本。下面拖 k 逐根夹一遍。再看**分解**：把 x 的每一根针都写成它自己的冲激分量，x[n] = Σ<sub>k</sub> x[k]·δ[n−k]——一排冲激，各自的高度就是信号的样本值。逐根打开开关，看叠加和怎样一根根长成 x 本人。 {#s1e .explain}

x[n] = Σₖ x[k] · δ[n − k] {#s1formula .formula i18n=text}

## h[n]：认识它，就认识系统对一切输入的回答 {#step2 h2=s2t}

::: strings
nav2: 2 h 是指纹

第 2 步 · h 是指纹 {#s2k .step-kicker i18n=text}

现在给系统录指纹。选一个系统，第一个动作永远一样：**送 δ[n]，把回答记作 h[n]**。然后送进一段真信号 x[n]（灰针）。按第 1 步的分解，x 是若干份冲激分量的和；如果系统是**线性**的，第 k 份分量 x[k]·δ[n−k] 的回答必是 x[k]·h[n−k]（放大 x[k] 倍的那份 h）；如果还是**时不变**的，每份回答都平移 k 步、模样不变。于是输出 = **所有「缩放平移的 h」叠起来**。画里半透明的每一坨就是一份，橙针是总和。图下还有一行对账：同一段输入再按系统定义式直接递推一遍，两条路逐点比——差多少，当场报数。 {#s2e .explain}

## 两条公理，当场可证伪 {#step3 h2=s3t}

::: strings
nav3: 3 公理检验台
:::

第 3 步 · 公理检验台 {#s3k .step-kicker i18n=text}

第 2 步的魔法不是免费的，它押在两条公理上：**线性**（输入的加权组合 → 输出的同样加权组合）和**时不变**（同样的输入晚来几步，输出也只是晚来几步）。这两条不是写在定义里的装饰，是可以当场验、也可以当场垮的契约。下面是检验台：三个受检系统轮流上台，两项检验都给出**具体的偏差数字**——通过的只剩浮点尾数（10<sup>−16</sup> 量级），垮掉的大得明明白白。 {#s3e .explain}

::: html step3-1
s3sysAcc: 累加器（自称 LTI）
s3sysSq: 平方器 y[n] = x[n]²
s3sysTv: 时变增益 y[n] = g[n]·x[n]
s3supT: 检验一 · 叠加性（线性）
s3supE: 取两段输入 x<sub>1</sub>、x<sub>2</sub>，权重 a = 2、b = −1。左路：先把输入组合成 2x<sub>1</sub> − x<sub>2</sub> 再送进系统；右路：两段输入分别过系统，再把输出按 2、−1 组合回来。线性成立 ⟺ 两路逐点相同。
s3tiT: 检验二 · 时不变性
s3tiE: 同一段输入 x<sub>1</sub>：一路直接过系统；另一路先延迟 D = 3 步再过系统。时不变成立 ⟺ 后一路的输出恰好是前一路输出延迟 3 步的样子，逐点相同。（时变增益台的 g[n] = 0.25 + 0.0625n：增益随时刻爬升——它对输入仍是线性的，变的只是「什么时候送进来」。）
s3fakeT: 公理垮了会怎样：平方器的「伪 h」
s3fakeE: 不管公理、硬给平方器也录一份「h」：送 δ 得到 δ² = δ，于是这份伪 h 对任何输入的「预测」就是输入本身；可真实输出是 x[n]²。两条线摆在一起——公理不在的地方，预测当场破产。
:::

看三位受检者的成绩单：累加器两项全过——它是真 LTI，h 的魔法对它全额生效。平方器**过了时不变、垮了叠加**：它没有记忆、不挑时刻，但 (2x<sub>1</sub> − x<sub>2</sub>)<sup>2</sup> ≠ 2x<sub>1</sub><sup>2</sup> − x<sub>2</sub><sup>2</sup>，交叉项就是偏差的来源。时变增益正相反：**过了叠加、垮了时不变**——g[n] 只随时刻变、不碰输入，所以对输入仍是线性的；但早送三步和晚送三步，乘到的增益不是同一个。两条公理各管一摊，缺一不可。 {#s3hint .hint}

## 阶跃响应 s[n]：h 的亲戚，互为累积与差分 {#step4 h2=s4t}

::: strings
nav4: 4 阶跃响应
:::

第 4 步 · 阶跃响应 {#s4k .step-kicker i18n=text}

再送一种最省事的输入：**阶跃 u[n]**（n &lt; 0 为 0，n ≥ 0 恒为 1），回答记作**阶跃响应 s[n]**。它和 h 是近亲：阶跃本身就是冲激的累积和（把 δ 从头攒起来正好是台阶），按线性与时不变，回答也跟着累积：**s[n] = h[0] + h[1] + … + h[n]**；反过来，对 s 差分一次就剥回 h。下面双向都算给你看：左图是 h（上面叠着 diff(s) 的空心点），右图是 s（上面叠着 cumsum(h) 的空心点），两组最大差都写在读数里。 {#s4e .explain}

s[n] = Σₖ₌₀ⁿ h[k] ， h[n] = s[n] − s[n−1] {#s4formula .formula i18n=text}

::: html step4-1
s4sysAcc: 指数衰减累加器
s4sysMa: 3 点滑动平均
s4aLab: a · 累加器的衰减（仅累加器用）
s4ovH: 把差分 diff(s) 叠到 h 上对照

工程现场为什么更爱测 s：要直接测 h，得扇一记「无限强、一瞬间」的巴掌，现实里做不出来；测 s 只需**合上开关、看它怎么爬**——通上直流、打开阀门都行。所以数据手册和实验室里常住的是阶跃响应；需要 h 时，差分一次就剥出来（左图叠的那层点就是这么来的）。 {#s4hint .hint}

s5memT: 体检三 · 记忆：h 拖多长的尾巴？
s5memE: 记忆看的是 h 的**支撑有多长**：滑动平均的 h 一出窗就严格归零——一巴掌的影响只活 3 步，叫有限冲激响应（FIR）；累加器的 h 是 a<sup>n</sup>，理论上永不归零——多少步之后都还剩一丝回声，叫无限冲激响应（IIR）。
:::

三张体检表连起来看：因果决定 h 的左边界，记忆决定 h 的右边界（有限或无限），稳定决定 h 的绝对值总和。工程上选系统，本质就是在这三张表上做取舍——要实时就必须因果，要不发散就得让 Σ|h| 收住，想要结构简单，就得忍受一条长尾巴（或者反过来）。 {#s5hint .hint}

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

终章把整页收拢到一台真系统上：一个**弹簧-阻尼**的离散模型——差分方程本身就是它的定义（一个 n 就是一个时间步）：θ 决定它摆动的快慢（刚度），r 决定余韵的长短（r 越贴近 1，阻尼越小、振得越久）。流程还是那一套：**先扇一巴掌把 h 数值录下来（录 120 根针），再送一段任意输入**——左路按方程直接递推；右路什么都不许用，只许拿刚录的 h 做叠加预测。两条线和它们的最大差都在下面，如实报数。 {#s6e .explain}

y[n] = x[n] + 2r·cosθ · y[n−1] − r² · y[n−2] {#s6formula .formula i18n=text}

s6rLab: r · 余韵长短（阻尼，越贴近 1 振得越久）
