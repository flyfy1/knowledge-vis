- category `math`，stage `senior`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：站内 coordinate-plane（坐标与距离）、linear-transform（矩阵变形）；无向量运算专页（与 atlas 的 vectors 节点同主题，本页是其互动讲解）。
- 核心直觉：向量=大小+方向，分量表示；加法首尾相接=分量相加；数乘与相减；点积与投影判断夹角；力的平衡（闭合三角形）；相对速度。
- 备注：atlas 已有节点 id "vectors"，故 conceptId 取 vectors-lesson。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **箭头与分量**
   - 已知：坐标。
   - 唯一问题：怎样用两个数描述一个箭头？
   - 输入与求量：输入 aₓ（−4…4）、a_y（−3…3）；求模与方向角。
   - 控件操作与预期观察：拖分量：橙色箭头与青/绿虚线分量。
   - 适用条件：二维直角坐标。
1. **向量加法**
   - 已知：分量。
   - 唯一问题：两向量合在一起是什么？
   - 输入与求量：输入 a、b 的分量；求 a+b、|a+b|、三角不等式。
   - 控件操作与预期观察：首尾相接与平行四边形一致；a 与步骤 0 共用。
   - 适用条件：二维。
2. **数乘与减法**
   - 已知：加法。
   - 唯一问题：数乘与相减的意思？
   - 输入与求量：输入 k（−2…2）；a、b 沿用步骤 1；求 k·a 与 a−b。
   - 控件操作与预期观察：k 为负翻向、k=0 零向量；a−b = a+(−b)。
   - 适用条件：页面写明 a、b 来自上一步。
3. **点积**
   - 已知：模与夹角。
   - 唯一问题：点积为何反映夹角？
   - 输入与求量：输入夹角 θ（0–180°），a=(4,0)、|b|=3；求 a·b 两种算法与投影。
   - 控件操作与预期观察：90° 时投影为 0，>90° 为负。
   - 适用条件：固定 a。
4. **绳子受力**
   - 已知：加法与分量。
   - 唯一问题：重物挂两绳，每根拉力多大？
   - 输入与求量：输入 W（10–100 N）、θ（5–80°）；求 T=W/(2 sinθ) 与合力核对。
   - 控件操作与预期观察：θ 越小拉力越大；右上小图首尾相接闭合；水平/竖直合力为 0。
   - 适用条件：静止平衡，绳质量不计。
5. **过河**
   - 已知：向量加法。
   - 唯一问题：怎样垂直过河？
   - 输入与求量：输入船头偏角 θ（−60…60°）；船速 4、水速 2、河宽 60 m；求实际速度、时间、漂移。
   - 控件操作与预期观察：θ=30° 垂直过河（时间 17.3 s），θ=0 漂 30 m；终章含回顾与 3 条互链。
   - 适用条件：均匀水流，恒定船速。

## 模拟设定与模型失配
纯几何与解析公式，无随机；探针独立核对加减数乘、点积、投影、T=W/(2 sinθ)、合力为零、过河 30° 直渡与 θ=0 漂 30 m。

## 技术
纯静态零依赖；读数全部由 app.js 中的纯函数按当前参数实时计算（探针独立手算核对）；中英文字典键集一致；canvas 文字经 t()；DPR/resize 幂等；播放类控件可重放、减弱动态时直接显示终态、页面隐藏时停止。
