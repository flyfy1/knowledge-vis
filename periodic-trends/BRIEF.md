## Steps
**0 Heat map.** Knows: elements have symbols. Question: is there a pattern in properties? Input property (r, IE₁, χ), element (slider or click); seek values and colour gradient. Controls: three property buttons recolour the 26-element table; slider/click selects element. Holds: main-group periods 1–4; noble-gas χ shown grey (no value).
**1 Along a period.** Knows: heat map. Question: how does the property change left to right? Input period, property; seek first→last change, count of rises/falls. Controls: period slider thickens one line; IE₁ shows dips Be→B, N→O. Holds: general trend, not strict.
**2 Why.** Knows: trend. Question: what causes it? Input element; seek Zeff (Slater), n*²/Zeff, fitted radius, r correlation 0.92. Controls: slide through Li→Ne (Zeff up, point moves left), then Na (jump). Holds: rough screening estimate.
**3 Down a group.** Knows: periods. Question: how do properties change down a group? Input group, property; seek ratio last/first. Controls: 4 group buttons and 3 property buttons; χ for noble gases has no value. Holds: elements in the 26-set only.
**4 Predict and compare.** Knows: trends. Question: how reliable are they? Input A/B pick; seek true larger value and whether the pair is an exception. Controls: Pick A/B (once per question), Another question, Reset (clears score, returns to question 1). Holds: deterministic question sequence; trend rule only for same period/group.
**5 Recap.** Quiz: F < O < Li (radii). Links: atomic-structure#step2, #step3, molecular-shapes#step4, electric-fields#step0.

## First-appearance terms
Atomic (covalent) radius, ionisation energy, electronegativity (0); period/group (0); effective nuclear charge, screening (2); Slater's rules (2); exception (1, 4).

## Simulation vs reality
26 main-group elements only; covalent radii are bonding-environment dependent; textbook IE₁ and Pauling χ; Slater is crude; correlation shows agreement, not a derivation.
