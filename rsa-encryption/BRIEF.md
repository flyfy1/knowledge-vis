# BRIEF：RSA 公钥加密（rsa-encryption）· RSA Public-Key Encryption
- category `computing`，stage `university`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：站内 hashing 讲哈希，division-remainder 讲余数（小学/初中），无公钥加密页；核心不重合。
- 核心直觉：乘易分解难；模算术与欧拉定理；e·d≡1 (mod φ)；加密 c=m^e mod n、解密 m=c^d mod n；窃听者成本（试除法真实运行）；密钥长度与 GNFS 量级。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **乘易分解难**
   - 已知：质数。
   - 唯一问题：相乘与分解的难度差多大？
   - 输入与求量：输入每个质数位数 k（1–30）；求相乘 1 步、试除法步数（k≤7 实测）。
   - 控件操作与预期观察：拖 k：红线按位数×10 增长；橙点是实测，k>7 为公式外推（标明）。
   - 适用条件：试除法是最朴素算法。
1. **钟表算术**
   - 已知：余数。
   - 唯一问题：模运算下反复乘同一数的轨迹？
   - 输入与求量：输入 n（5–40）、a；求闭环长度、φ(n)、a^φ mod n。
   - 控件操作与预期观察：改 n、a：互质时回到 1（欧拉定理）；有公约数时回不到。
   - 适用条件：整数、取模。
2. **造一对钥匙**
   - 已知：φ(n)。
   - 唯一问题：怎样由 p、q 造出公钥私钥？
   - 输入与求量：输入 p、q（5–43，相同则换下一个）、e 候选；求 n、φ、d 与扩展欧几里得表。
   - 控件操作与预期观察：换 p、q、e：表与密钥更新；读数验算 e·d=1+kφ。
   - 适用条件：小质数，BigInt 精确。
3. **加密与解密**
   - 已知：公私钥。
   - 唯一问题：怎样用钥匙传递一个数？
   - 输入与求量：输入明文 m（<n）；求 c、m′、全部 m 的解密检验与乘法次数。
   - 控件操作与预期观察：拖 m：橙点在乱点中跳，解密总回到 m；全部 0..n−1 逐个验证。
   - 适用条件：教科书 RSA，无填充。
4. **窃听者的账**
   - 已知：试除法。
   - 唯一问题：拆分 n 需要多少力气？
   - 输入与求量：输入 n 的大小（k=1…7）；开始/暂停/重置；求试除次数与合法加密乘法次数。
   - 控件操作与预期观察：真实在浏览器里试除：小 n 瞬间被拆；k=7 数百万次；重置清空进度。
   - 适用条件：绿条按对数长度画，仅比较量级。
5. **现实的密钥长度**
   - 已知：指数增长。
   - 唯一问题：现实密钥要多长？
   - 输入与求量：输入位数（64–4096）；求 GNFS 量级 10^x、所需年数。
   - 控件操作与预期观察：拖位数：2048 位≈10^35 次；虚线为 10^18 ops/s × 宇宙年龄；终章含回顾与 3 条互链。
   - 适用条件：量级估算，忽略常数；Shor 算法未模拟。

## 模拟设定与模型失配
教科书 RSA，小质数与 BigInt 精确；无填充、无签名；窃听者的试除在浏览器里真实运行（k≤7）；GNFS 量级为估算；探针独立核对 3233 的教科书例子（65→2790→65、d=2753）、40 对质数全部明文可解密、轨道 3 mod 14 与试除步数 ≈p/2。
