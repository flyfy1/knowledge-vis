# 热力学 · 一口气追踪能量

## 目标

让学习者沿着一条可核对的因果链走完：状态变量 → P–V 路径 → 第一律 → 等温/绝热差别 → 热机效率上限。每一次拖动都重新计算，页面不把结论写死在文案里。

## 教学契约

- **观察**：拖动 `n / T / V`，先看到状态读数，再用 `P = nRT/V` 解释压强响应。
- **记账**：选择等温或绝热膨胀，P–V 曲线下的面积为 `W = ∫P dV`；三项按 `ΔU = Q − W` 闭合。
- **比较**：两条曲线从同一初态出发，等温过程维持 `T`，绝热过程 `Q=0` 并因做功降温。
- **迁移**：把能量流装进热机，实时对照实际效率和卡诺上限 `ηC = 1 − Tc/Th`。
- **误解反馈**：状态相同不代表路径量相同；绝热膨胀会升温；绝对零度可以达到。这三个选择题都会给出指向账本/公式的反馈。

## 口径与边界

- 单位采用 kPa、L、K、mol；`1 kPa·L = 1 J`，模型将曲线面积除以 1000 后以 kJ 展示。
- 理想气体、准静态路径、定比热；绝热指数 `γ` 可调，`Cv = R/(γ−1)`。
- 热机为教学用两段等温循环，效率仍由实时能量流计算；不是工程级循环求解器。
- 页面支持中英双语，Canvas 只承担图形，所有关键读数同时以文本呈现。
