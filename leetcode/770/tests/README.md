# Reproduce the author checks

From the repository root, with the already-running preview at http://127.0.0.1:18770:

```bash
python3 -B leetcode/770/tests/check.py
node leetcode/770/tests/browser.cjs
node leetcode/770/tests/inspect.cjs
python3 -B scripts/register_leetcode_lesson.py 770 --validate-only
```

`browser.cjs` consumes `oracle-fixtures.json` generated by `check.py`. To rerun without modifying the frozen candidate, set the same writable output directory for all three tests:

```bash
OUTPUT_DIR=/tmp/leetcode-770-review python3 -B leetcode/770/tests/check.py
OUTPUT_DIR=/tmp/leetcode-770-review node leetcode/770/tests/browser.cjs
OUTPUT_DIR=/tmp/leetcode-770-review node leetcode/770/tests/inspect.cjs
```

The scripts create OUTPUT_DIR if needed. Set NODE_PATH to the supplied browser-package directory if it is not already set. Launch respects PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH. PREVIEW_URL can override the lesson URL; the default is the provided existing preview. These checks never start a server. The main browser test's local-request assertion intentionally expects the supplied 127.0.0.1:18770 origin.

Algorithm checks execute the canonical Solution.basicCalculatorIV method with its original argument/return contract and ensure eval lists are unchanged. The independent oracle uses Python AST plus raw term lists (combines only once at root); the canonical implementation instead uses recursive descent and combines each operation. Direct numeric eval independently checks generated polynomial meaning under seeded integer assignments. Every JavaScript frame is separately compared with the AST oracle for its exact consumed subexpression; sorted keys, nonzero coefficients, uniqueness and pair accounting are checked. The real browser also computes all generated cases through the actual loaded core.

Browser checks include all preset endpoints and reversal, every prediction choice and feedback invalidation, locale preservation, headings, source disclosure, real clipboard success, forced API denial plus native host-key manual copy/readback, exact download bytes, storage denial, source on file://, native selected-label width, keyboard controls and related links, 320/390/736/1440 widths, 200% CSS zoom reflow, forced colors, calibrated rendered contrast, asset failures and CSS bytes. Host clipboard shortcut is selected using process.platform and recorded in results. This host is Linux; a distinct non-source sentinel is seeded before every fallback test.

Screenshots require human visual inspection. The author's inspection is recorded in SELF-CHECK.md. Synthetic headless browser checks are not independent review or actual learner evidence.
