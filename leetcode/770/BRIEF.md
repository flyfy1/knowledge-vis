## First-use dependencies

## Proof, baseline and cost plan

Baseline Python uses Python AST only for this valid arithmetic grammar and expands a list of signed terms, merging solely at the end. Independent test oracle uses SymPy if available, otherwise the raw list baseline, separate from recursive-descent canonical implementation. Verify intermediate maps by evaluating their consumed token interval independently, plus sorted keys/zero suppression. Atom consumes one token or parenthesized expression; term consumes all multiplication; expr consumes additions/subtractions in order. Each consumes input and parentheses terminate recursion; distributivity and coefficient addition preserve exact meaning. Multiplication combines every pair, including negatives and repeated names; nonmatching keys never combine.

n = expression characters, E = total substitution name characters plus entries, D = max variable occurrences per intermediate term (0 allowed), P = max nonzero term count across canonical intermediates (0 allowed). Upper bound with identifier comparisons treated as key operations: O(E+n(P+1)^2(D+1)log(D+2)+P log(P+1)(D+1)); recursion may retain O(n) maps, so O(E+n(P+1)(D+1)) auxiliary references plus returned strings. Variable-name comparison is not constant character time; multiplying key-operation bound by maximum identifier length is conservative. Baseline substitutes R raw term count for P in a loose bound; R can exceed P enormously even when cancellations empty the map. No claim of linear/exponential-free symbolic expansion.
