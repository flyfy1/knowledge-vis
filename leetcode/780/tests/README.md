# Reproduce author checks

Run from the repository root with the existing preview at http://127.0.0.1:18770. No server is started by these tests. Python 3 and Node are required; Playwright resolves through the provided NODE_PATH. Browser runners honor PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH. PREVIEW_ROOT optionally changes the already-running origin.

```bash
OUTPUT_DIR=/tmp/780-review python3 -B leetcode/780/tests/test_solution.py
python3 -B leetcode/780/tests/test_copy.py
OUTPUT_DIR=/tmp/780-review node leetcode/780/tests/browser.cjs
OUTPUT_DIR=/tmp/780-review node leetcode/780/tests/boundary-browser.cjs
python3 -B scripts/register_leetcode_lesson.py 780 --validate-only
```

OUTPUT_DIR controls every generated report and screenshot; without it the tests use tests/evidence/. Use a separate directory when reviewing a frozen candidate. test_copy.py prints only to stdout. test_core.cjs is invoked by test_solution.py using independently produced forward-oracle fixtures on stdin. No Python package installation is needed.

The numerical baseline is forward BFS, not another reverse/modulo solution. Tests cover exhaustive sx/sy=1..7 and tx/ty=1..17, seeded small random inputs, seeded large paths generated solely by legal forward moves, official examples and independently calculated maximum/boundary cases. Intermediate model states are rechecked by forward reachability; frame arithmetic, sum decrease, determinism, deep snapshot isolation and exact source mirror are checked.

browser.cjs covers each preset in both locales, all frame rewind/replay operations, independent hand experiment, predictions, changed answers, state preservation on locale switch, source disclosure, real successful clipboard transfer and denied-write fallback with native Linux Control+C (Meta+C if hosted on macOS), downloads, denied storage, file:// initialization, local asset/console errors, rendered contrast, forced colors/reduced motion, all selected labels, 320/390/736/1440px layouts, 200% CSS zoom in Chromium, header identity and keyboard anchor geometry. boundary-browser.cjs adds actual Tab order, 48px targets, narrow terminal cases and large-number/hand screenshots.

Contrast calibration includes black/white, equal colors, RGB primaries and #747474 on black just below 4.5. Text pairs are measured from rendered colors with alpha-composited ancestor backgrounds. This checks the page's solid surfaces, not hypothetical images/gradients. The native selector arrow allowance is explicitly Chromium/Linux-specific.

Official verification files are retained separately from runtime assets. author-debug-notes.md and anchor-debug.png describe a pre-fix author reproduction. All other final screenshots are generated by these tests. Stage-only screenshots suppress the sticky nav only while capturing a full stage to avoid screenshot overlay artifacts. Normal viewport screenshots and anchor geometry retain the nav.

These are author self-checks. They do not constitute independent acceptance, a LeetCode submission, actual learner testing, real-device testing, or production verification.
