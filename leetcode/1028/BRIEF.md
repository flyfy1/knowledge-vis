4. Known: path invariant (restated). Question: where does 9 attach after prefix 7-4--2---1--9? Input: fresh path [7,4,2,1], next depth 2; seek removals, parent, side. Action: choose then reveal; change clears feedback; locale preserves it. Conditions: valid original tree, exercise independent of trace.
5. Known: ancestor path. Question: which Python lines implement parse/pop/attach? Input: official source; seek code mapping and real costs. Action: show/copy/download source with manual fallback. Conditions: L counts all string characters, n nodes, h root-to-deepest path node count. O(L) time, O(h) auxiliary excluding O(n) returned nodes.
