## Derivation and proof
Repeated innermost substitution is correct by grammar: each complete child is used only via its Boolean value. Each replacement can rescan/copy a length-n string; nested unary groups give Θ(n²) time, O(n) live memory. Canonical single scan retains unresolved structure instead. After each character stack equals scanned prefix with every completed subexpression replaced by its literal and commas omitted. Non-close appends op/parenthesis/literal, comma has no semantic value. At close, innermost still-open '(' is nearest on stack; all children above it are already literals by invariant. Pop exactly these; immediately below '(' is their operator. Existence flags suffice: AND true iff no f; OR true iff some t; unary NOT true iff no t. Push one result, restoring invariant without changing outer context. Finite scan and each token pushed/popped≤once imply O(n) time/O(n) auxiliary space. n1 literal returned unchanged; deep nesting no Python recursion; wide operator scans all children. Snapshot history uses extra teaching memory, not submission complexity. False short-circuit may determine a value but cannot skip unparsed nested syntax; all chars still scanned. Flat any-t rule fails &(t,!(t))→false.
