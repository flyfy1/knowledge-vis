# Author checks (not independent review)

Run from the repository root; use the existing preview service:

```sh
python3 -B leetcode/174/tests/check.py
node leetcode/174/tests/trace.cjs
NODE_PATH="$NODE_PATH" node leetcode/174/tests/browser.cjs
python3 -B scripts/register_leetcode_lesson.py 174 --validate-only
```

To preserve the frozen candidate, set OUTPUT_DIR to an external writable directory
for all three tests. `trace.cjs` consumes `fixtures.json` generated by `check.py`
in that directory. Browser uses installed Playwright through NODE_PATH and respects
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH. LESSON_URL can override the default existing
preview URL. No test starts a service. Downloads use Playwright temporary storage.

`check.py` executes the canonical Python callable and the displayed baseline,
checks no mutation, exact source mirror and official Python interface evidence.
The independent oracle enumerates routes via direct health feasibility and binary
searches starting health. It also provides every suffix-cell optimum to trace tests.
Exhaustive alphabets {-2,0,3} on 1×1, 1×3, 3×1, 2×2, 2×3, 3×2; 500 seed-174
random grids up to 4×4; official examples, unseen exercise, sum counterexample;
five maximum-dimension closed-form boundaries. No LeetCode submission was made.

`trace.cjs` compares all computed cells against the suffix oracle, checks right/
down dependencies, event count, integer transition, no mutation and deep snapshots.
`browser.cjs` uses real headless Chromium: both locales, every preset and event,
rewind/forward identity, reset/end/scrub, hand-health death, every prediction,
locale state preservation, copy success/denial, source/download parity, keyboard,
focus, local links, blocked storage, 320/390/736/1440 layouts, effective 200% CSS
zoom, forced colors, reduced motion, rendered contrast and local asset failures.
CSS zoom is a reproducible effective narrow layout test, not a physical-device test.
Screenshots must also be visually inspected. See SELF-CHECK.md for observations.

Official capture: evidence/official.json contains access timestamp, exact official
URL, public GraphQL endpoint, full statement, examples, constraints and actual
language selector stubs. It is review material, not a runtime dependency.
