Observed statement: Given digit string num and integer target, insert binary +, -, and/or * between digits; return all expressions evaluating to target. Operands cannot contain leading zeros; numbers may contain multiple digits.
Examples: 123,6 -> [1*2*3,1+2+3]; 232,8 -> [2*3+2,2+3*2]; 3456237490,9191 -> [].
Constraints: 1 <= num.length <= 10; num consists only of digits; -2^31 <= target <= 2^31-1.
