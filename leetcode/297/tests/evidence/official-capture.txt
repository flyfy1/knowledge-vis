Examples: root = [1,2,3,null,null,4,5] -> [1,2,3,null,null,4,5]; root = [] -> [].
Constraints: number of nodes in [0, 10^4]; -1000 <= Node.val <= 1000.
Interface observed in the public Code section and standard Python catalog: class Codec with serialize(self, root) -> str and deserialize(self, data) -> TreeNode.
