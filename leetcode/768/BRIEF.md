## Steps: five fields each
### 0 — Sort chunks by hand
Known: sorting numbers. Question: which cuts let separately sorted pieces concatenate into a sorted list? Input/output: fixed [2,1,3], toggle either of two cuts; show each original chunk, each sorted chunk, concatenation and validity (not a maximum claim). Action/observation: add cut after 0, observe 2 before 1; remove it and cut after 1, observe [1,2]|[3]. Conditions: nonempty contiguous chunks, order preserved; sorting cannot move values across cuts.
### 1 — What makes a cut safe?
Known: actual chunk sorting. Question: how can we test a cut without enumerating all partitions? Input/output: same [2,1,3], max([2])=2 > min([1,3])=1 fails; max([2,1])=2 <= min([3])=3 passes. Action/observation: read baseline and compare the two hand outcomes; counterexample [2,3,1,4] rejects adjacent-only test at cut 0. Conditions: values totally ordered; compare whole sides; baseline recomputes extrema in O(n²) time, O(n) temporary slicing space.
### 2 — Reuse extrema
Known: full-side cut test. Question: how do two linear scans avoid rescanning each side? Input/output: preset array, complete suffix-min construction followed by cut scan; suffixMin[i]=min(arr[i],suffixMin[i+1]), leftMax extended before each cut. Action/observation: append operation, rewind, reset/end, switch preset (explicit restart). Cards retain known suffix values; ledger retains all tested cuts with operands and outcomes. Conditions: all presets length <=5, complete trace, snapshots O(n²) distinct from solution O(n). Last suffix is arr[n-1]; no empty suffix or artificial sentinel. Singleton has no cut tests and final count 1.
### 3 — Why all safe cuts? Transfer
Known: comparison and extrema. Question: why does taking every safe boundary maximize the chunk count? Input/output: proof plus independent [1,3,2,2,4] exercise. Action/observation: select a count before reveal; explicit reveal exposes 3 chunks [1]|[3,2,2]|[4] and operands; changing choice hides feedback; locale preserves choice/reveal. Conditions: any legal cut forbids a cross inversion; every selected cut separates ordered value ranges, so all selected chunks sort together; any omitted safe cut can be added. Equality is permitted. Distractors: adjacent-only extra cut gives 4; rejecting equality is a general misconception but this quiz's count-2 option represents missing a safe cut. Exercise answer not leaked into trace presets.
### 4 — Python and honest costs
Known: mechanism and proof. Question: which source lines implement each visible operation? Input/output: canonical submission, map suffix loop, leftMax and comparison, answer initialized 1. Action/observation: inspect/copy/download exact file, fallback with full-source selection; revisit actual step anchors. Conditions: n>=1, no input mutation; O(n) time and O(n) auxiliary space, integer values within official limits. Baseline O(n²), simulation snapshots O(n²) for tiny inputs.
