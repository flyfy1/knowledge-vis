Observed statement: Given an integer array nums, return integer array counts where counts[i] is number of smaller elements to the right of nums[i].
Examples: [5,2,6,1] -> [2,1,1,0]; [-1] -> [0]; [-1,-1] -> [0,0].
Constraints: 1 <= nums.length <= 10^5; -10^4 <= nums[i] <= 10^4.
