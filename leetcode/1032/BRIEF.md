## Learning loop and five fields per step
1. Known: strings and last character. Question: does the stream end with a listed word right now? Input: words ab,cb; stream abx; output one Boolean per query. Action: append/rewind letters; inspect every completed prefix and match. Observe a→false, ab→true, abx→false. Conditions: nonempty suffix ends at newest letter. Define stream, suffix, query locally.
2. Known: suffix test. Question: which comparisons repeat across words? Input: same ab,cb and latest b then a; output a shared search. Action: inspect direct baseline, hand-read shared last b and branching previous letter. Observe backward b→a spells ab, b alone insufficient. Conditions: lowercase nonempty words, bounded longest word L. Define trie as shared-prefix character paths and terminal marker as complete word; reversing turns common suffix into common prefix. Wrong rules: substring-ever abx is false; a partial path b is false; do not reset stored history after a match (aa/aaa).
3. Known: reversed word paths. Question: why can scanning stop? Input: eight presets, newest L letters and reversed trie; output scan events and query results. Action: append/start scan, follow one edge per step, back/reset/end; compare buffer, path and complete history. Conditions: each frame after one append or edge test; no omitted events, up to 12 query letters; graph fixed per preset. Invariant derived: after k successful edges, path equals reversed length-k current suffix; terminal proves exact word; missing edge excludes every longer suffix; exhausting buffer without terminal proves false. Discarded letters older than L cannot belong to any word. Query always restarts at root; buffer persists. Simulation is JavaScript, not executing Python. Full tutorial snapshots are extra storage.
4. Known: suffix and terminal (restated). Question: words bc,abc; after prefix ab append c: where does search stop? Input: fresh words/stream, output visited characters, match and Boolean. Action: select, reveal, change clears feedback; locale preserves choice/reveal. Observe c→b terminal bc, true; no need to visit a for abc. Conditions: any suffix suffices, not longest. Distractors: require a leaf; use forward scan.
5. Known: reversed paths (restated). Question: how do actual Python lines implement it and what costs remain? Input: canonical source; output callable state and cost accounting. Action: source disclosure, copy with real manual fallback, download, related anchors. Conditions: S total word characters, L longest word, t letters received; O(S) build, O(min(t,L)) worst per query, O(S+L) space; dictionary expected O(1) lookups. Explain deque maxlen, reversed iterator, # outside alphabet, node.get, append. Boundaries one-letter words, duplicates, overlaps, early terminal, missing edge, initial zero calls. No empty word/Unicode extension.
