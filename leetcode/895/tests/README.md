# Reproduce author checks

From the repository root, use an existing preview at http://127.0.0.1:18770. Do not start a new server.

```bash
export OUTPUT_DIR=/tmp/leetcode-895-review
python3 -B leetcode/895/tests/check.py
node leetcode/895/tests/core.cjs
node leetcode/895/tests/browser.cjs
python3 -B scripts/register_leetcode_lesson.py 895 --validate-only
```

OUTPUT_DIR is optional; default is this folder's evidence/. The core checker consumes the fixtures generated by check.py in the same OUTPUT_DIR. Browser requires the available Playwright package via NODE_PATH. If PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH is set, the harness passes it to Chromium. Native fallback copying uses the browser host's Control+C on Linux/Windows or Meta+C on macOS, after a fresh read-back-verified sentinel for each locale.

Small cases use an independent physical-list oracle: recount all remaining values and remove the rightmost occurrence of a maximum-count value. Layers are reconstructed from the ranks of occurrences in that physical list, independent of the optimized transitions. Exhaustive valid operation prefixes of length at most 7 use values 0/1; seed 895 supplies 80 mixed sequences of 100 calls. Maximum-size tests use closed-form equal-value and distinct-value results (10000 pushes then 10000 pops), plus 20000 equal pushes. Every intermediate state is checked on small/seeded cases; maximum-size cases check output and endpoint invariants without quadratic state capture.

Browser tests exercise both locales, every preset and call, both endpoints, rewind/replay, reset, range navigation, each prediction option, reveal/change and locale retention, displayed/downloaded/automatic/native-fallback source transfer, blocked storage, offline simulation, keyboard activation/focus and related links. Widths 320/390/736/1440 each use CSS zoom 1 and 2. Screenshots are evidence to inspect, not an automatic claim of readability. Contrast uses sRGB luminance, includes black/white=21, identical=1, red/black=5.252 sanity references; solid text/disabled/selected/focus palette pairs only. No transparency is applied to controls locally.

This is author self-check evidence. Separate lesson review, real novice comprehension, physical devices, public delivery and LeetCode submission acceptance are unverified.

The native select uses A/B/C codes; its label gives their meanings and an adjacent readout renders the entire selected preset description with wrapping. The harness measures selected text plus computed padding and a host-specific 16px arrow reserve. The earlier overly long label's failed budget is retained in evidence/preset-before.json.

Related-page console diagnostics are recorded separately: visiting #32 requests a missing shared /favicon.ico. The #895 lesson's console/page/asset checks must remain empty; destination content/anchors still undergo keyboard navigation and semantic inspection. Shared files were not edited.
