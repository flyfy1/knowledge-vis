## Learning loop / five fields per step
1. Hand cuts: known string and dictionary; question which cuts yield sentences; input aaa with a,aa, desired every sentence; inspect all four masks, compare rejected longest-only rule; applies to nonempty lowercase input and reusable words.
2. Suffix state: known legal first words; question what can be reused across different prefixes; same aaa, desired F[i] all sentences for s[i:]; follow F[3] through F[0], observe branches retained; applies to strictly increasing cut indices and complete lists, including the empty-suffix sentinel.
3. Reversible lab: known recurrence; question what a single tested piece adds; preset plus index, desired partial and complete suffix lists; next/back/end/reset, inspect before/new/after and cumulative ledger; simulator follows canonical bottom-up loop with no omissions, snapshots cost is teaching-only. Preset resets only lab. F[i] is partial until all candidate ends processed.
4. Transfer: known suffix-list invariant; question F[0] for abab with ab,a,b,ba; choose before explicit reveal, change selection clears feedback; language preserves state. Fresh input independent of presets; answer requires combining every matching first word with every tail.
5. Code and boundaries: known complete recurrence; question why canonical code returns exactly all sentences at what cost; map loop, membership, tail iteration, join; copy/download original Python, inspect boundaries and related anchors. Applies to official bounds, expected hash lookup cost and output-sensitive storage.

Invariant: step1 every stored complete list contains exactly all legal sentences; restated locally in steps3/5.
