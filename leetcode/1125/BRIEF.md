## First-use dependency table (also redefined at each section)
- sufficient team / coverage: step1, union of skills meets every requirement.

- mask and bit: step3, one binary position per skill, bit j worth 2^j; OR retains any present skill.
- DP / invariant: step3, reusable table of shortest teams for exact coverage after a prefix of people; invariant is the statement true after every round.
- unknown: step3, unreachable coverage shown as ∅? No: use explicit localized “unreachable”, distinct from [] team for 000.

- n, m, L: step5, number of people, skills, input skill entries; list copy length at most m because strict improvements cannot add redundant people.

## Proof / costs / simulation limits
Induction: initially only empty team covers zero. Every legal team in prefix i+1 either omits i (old state) or uses i (old prefix team plus i). Replacing that old prefix team with a smaller representative of its exact coverage cannot worsen union with i. Both constructions are legal, so minimizing candidates attains the true optimum; no assumption that every arbitrary team is already optimal. Snapshot prevents same-round reuse. Keep ties unchanged, any optimum valid. Strict improvements add new skills; each stored team has ≤m members. Canonical dictionary lists and copying: O(L+n m 2^m) time, O(m 2^m+m) auxiliary space including round snapshot and candidate lists; input excluded, returned team O(m). Bit operations bounded by official 16 skills (machine-word model). Teaching snapshots retain O(n m 2^m) team data plus transition records, not submission space. Trace is a JavaScript teaching simulation, not execution of the displayed Python. All preset rounds and transitions shown; small presets only, no claims of timing at official maxima.
