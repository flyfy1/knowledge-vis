## First-use terms and dependencies
- Step 0: subsequence = deleting digits without reordering; merge/interleaving = weave two subsequences while preserving each order. Lexicographic order = compare first differing digit; for equal-length digit arrays it is numeric order. m/n = original lengths; k = desired length; take = digits from nums1.
- Step 1: stack = list whose tail can be removed; drop = remaining allowed deletions. Repeat local definitions at step entry. This is only monotone while drop remains; do not claim all final stacks are descending.
- Step 2: suffix = unconsumed tail, common prefix = equal digits before first difference. Empty suffix loses to nonempty, equal suffixes choose B deterministically.
- Step 3: invariant = a fact preserved after every operation; define locally. Selection exchange, merge exchange, and split coverage are separate obligations.
- Step 4: S = feasible split count, output/auxiliary/snapshot costs separately labeled. Explain list slicing and comparison costs.

## Baseline, proof and trace model
Baseline is an exhaustive search over next source indices and remaining result length. Branch to every possible next digit, then maximize complete length-k sequences. The count of leaves is sum_t C(m,t) C(n,k-t) C(k,t) (feasible t); factorial/exponential enumeration is only a small-input oracle. Independent tests enumerate subsequence combinations and all ordered interleavings, without greedy selection or suffix decisions.

Selection: a smaller retained digit before a larger new digit should be removed if a deletion remains: the replacement increases the first differing output digit and later digits can still fill the required length. Repeat at the tail. If no drops remain, future digits must be kept; if no larger digit arrives, erase the smallest-impact digits at the end. Exhaustive tests also verify each intermediate stack is the lexicographically greatest subsequence of the processed prefix at its current length.
Merge: unequal heads choose larger. Equal runs require looking ahead; exchanging source labels of equal emitted digits preserves their values until the first unequal digit, where taking from the lexicographically larger suffix lets its larger digit occur first. If one suffix ends during comparison, the longer suffix is larger. Fixed-count replacement: put a larger chosen subsequence into the same source slots of an optimal merge; its first changed slot improves the result. Therefore keeping only each source's best subsequence is safe. Every legal answer uses one feasible count t, so enumerating those splits completes the proof.

Trace is a bounded browser simulation with deep snapshots, not execution of Python. Stack traces retain every pop/push/trim for inputs ≤6; merge traces retain all emissions, comparisons and output for ≤6 digits. No skipped frames or timers. Trace presets are independent; changing one explicitly restarts that experiment. Prediction independent of trace controls. Python tests include official maximum lengths. Fresh transfer and head-only counterexample differ from initial hand example.
