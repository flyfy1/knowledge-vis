# BRIEF：磁铁（magnets）· 小学科学
- category `physics`，stage `primary`（已注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，记录不确定性）。
- 核心：磁场两端最强；异极相吸同极相斥，力随距离平方反比；铁屑/磁感线 N→S；指南针 N 端顺场；磁极成对。

## 步骤（五必填项）
0. 两端最强。问题：吸力哪里最强？输入探头沿侧面位置；观察：铁屑在磁极附近更亮/更密，曲线 B(x) 两端高中间低，探头点沿曲线移动，读数给出端点与中点相对强度；适用：点磁极模型，侧面 0.5 cm。
1. 吸还是斥。问题：同极异极之力与距离？输入相对两极（NS/NN）、间距 1–8 cm；观察：绿色箭头方向与长度，读数 F（相对值）按四个磁极两两库仑式求和，距离增大 F 迅速减小。
2. 铁屑显形。问题：磁场怎么“画”出来？输入摆法（单块/异极相对/同极相对）、铁屑或磁感线、每个 N 极线数；观察：异极相对时线直接连通，同极相对时互相顶开。
3. 指南针。问题：如何读方向？输入位置 x、y、一圈指南针开关；观察：针的红端顺磁感线方向（磁铁上方指向 −x，即由 N 侧指向 S 侧），读数角度和强度由场函数计算。
4. 掰断磁铁。问题：能分出单极吗？输入段数 1–4、拉开间距 0–2 cm；观察：贴合时内部异极抵消像整块，拉开后每段各有 N、S；读数 N 极数 = S 极数 = 段数。
5. 终章。输入判断（单块/异极/同极）、检查、换一题；磁极在检查前隐藏（灰色），检查后揭示；深链 pythagoras#step0、coordinate-plane#step2（均已核对存在，仅 2 条）。

## 新术语首现表
磁场（步 0 就近定义）；磁极 N/S（步 0）；磁感线（步 2 定义）；指南针/小磁针（步 3）；抵消（步 4）。

## 模拟设定 / 模型失配
磁铁简化为两端点磁极、平方反比律，真实磁铁近处更复杂；磁感线是画法而非实物；力与场用相对值（Q=1，长度单位厘米）。铁屑图样是由该模型计算出的方向小线段，不是物理实拍。
