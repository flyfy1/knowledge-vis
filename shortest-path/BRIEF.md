# BRIEF：最短路（迪杰斯特拉）（shortest-path）· Shortest Path (Dijkstra)
- category `computing`，stage `university`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：graph-algorithms 讲 BFS/DFS 遍历与 O(V+E)（无权），network-flow 讲最大流；本页是带权最短路（迪杰斯特拉/A*/贝尔曼–福特），核心不同；重合 <25%（仅都用图）。
- 核心直觉：路径代价=权重和；迪杰斯特拉每次确认暂定距离最小的点（确认顺序按距离递增）；需非负权；网格地图上权重改变路径；A* 启发值减少确认格数。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **路径的代价**
   - 已知：图的节点与边。
   - 唯一问题：带权图里什么叫最短？
   - 输入与求量：输入逐站选择；求你的代价与最短代价 20。
   - 控件操作与预期观察：只能走相邻未走节点；撤销/重置；A-C-F-E=20，A-B-D-E=28。
   - 适用条件：无向小图。
1. **洪水式确认**
   - 已知：路径代价。
   - 唯一问题：怎样不试遍所有路径？
   - 输入与求量：输入走一步/连续走/重来；求暂定距离与确认顺序。
   - 控件操作与预期观察：确认顺序距离递增；绿=已确认橙=候选红=刚确认。
   - 适用条件：权重非负；O(V²)。
2. **负权会让它出错**
   - 已知：确认的含义。
   - 唯一问题：权重可以为负吗？
   - 输入与求量：输入 B→A 权重（−3…3）；求迪杰斯特拉与贝尔曼–福特的 C。
   - 控件操作与预期观察：w<−1 时结果不一致（红圈），否则一致。
   - 适用条件：有向小图；探针枚举 w。
3. **地图上的最短路**
   - 已知：算法。
   - 唯一问题：穿过泥地还是绕开？
   - 输入与求量：输入泥地代价 1–9；求总代价、泥格数。
   - 控件操作与预期观察：代价≤3 穿过（m=1 为 13，m=2 为 17），≥4 绕行总代价 25。
   - 适用条件：14×8 网格，四向移动。
4. **A* 少看一些格**
   - 已知：地图。
   - 唯一问题：能否用终点方向少算？
   - 输入与求量：输入算法（迪杰斯特拉/A*）与泥地代价；求确认格数与代价对照。
   - 控件操作与预期观察：A* 格数更少、代价相同；m=1 时 14 vs 89，m=9 时 83 vs 97。
   - 适用条件：曼哈顿启发值不高估（每步≥1）。
5. **预测下一个**
   - 已知：确认规则。
   - 唯一问题：下一个确认哪个点？
   - 输入与求量：输入选择；检查；下一步；重来。
   - 控件操作与预期观察：答对为暂定距离最小者；下一步清除选择；终章含回顾与 3 条互链。
   - 适用条件：固定图 A–F。
