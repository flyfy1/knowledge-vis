## 稳稳 3%，还是 −10% 到 +20% 乱跳，你先选哪个？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 两个玩具选择
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 两个玩具选择
:::

<b>这一步回答：选之前，你知道自己在选什么吗？</b>选择 A：每年稳稳 +3%，没有惊喜也没有惊吓。选择 B：每年在 −10% 到 +20% 之间，结果不确定，平均约 +5%。先点一个，再看它的分布长什么样——选完才看分布，是这一步的规矩。 {#s0e .explain}

:::

## 两个平均一样的分布，风险差在哪里？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 方差是散开程度
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 方差是散开程度
:::

<b>这一步回答：风险能不能用一个数来量？</b>能：方差量的就是结果离平均有多散。平均都是 5%，一个挤在 5% 附近，一个铺到 −10% 到 +20%，后者的方差大得多。方差说的是散开程度，不是好坏——散得开，意味着既可能更好，也可能更糟。拖动波动幅度，看方差怎么变。 {#s1e .explain}

::: html step1-2
s1cv: 平均同为 5%，波动幅度越大，分布越铺开
lblSpread: 波动幅度（%）
:::

::: strings
s1ro: 平均仍是 5%，波动幅度 {w}%：均匀分布的方差约 {v}（方差 = 幅度² ÷ 3）。幅度越大，方差越大，单年结果越不可预测。
:::

## 跑一百次，两个选择的结果长什么样？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 一百次玩具试验
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 一百次玩具试验
:::

<b>这一步回答：一次的运气和一百次的规律有什么不同？</b>用固定种子跑 100 次玩具试验：A 每次都是 103（100 本金 +3%），柱子只有一根；B 的结果铺在 90 到 120 之间。点“再跑一次”换个种子，B 的柱子形状会变，但铺开的宽度不变——宽度是分布的性质，不是某一次的运气。 {#s2e .explain}

::: html step2-2
s2cv: 100 次试验的终值直方图：A 只有一根柱，B 铺成一片
btnAgain: 再跑一次
:::

::: strings
s2ro: 100 次试验：A 全部落在 103；B 有 {neg} 次低于 100（亏了），{pos} 次高于 103（跑赢 A）。B 的平均约 {mean}，但单次结果散得很开。
:::

## 要让人接受波动，得多给多少回报？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 风险溢价
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 风险溢价
:::

<b>这一步回答：多出来的回报是补偿，不是保证。</b>稳稳的 A 给 3%。波动的 B 平均给 5%，多出的 2% 就是风险溢价：为承担波动付的补偿。拖动 B 的平均回报，看溢价怎么变——溢价可以是 0（没人会选 B），也可以很高；但无论多高，它承诺的只是平均，不是每一年。 {#s3e .explain}

::: html step3-2
s3cv: A 的 3% 与 B 的平均回报之差，就是风险溢价
lblMeanB: B 的平均回报（%）
:::

::: strings
s3ro: A 给 3%，B 平均给 {m}%：风险溢价是 {p}%——为承担波动付的补偿。记住：补偿的是平均，不是每一年。
lblPremium: 风险溢价
:::

## 平均 5%，为什么有的年份还是亏的？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 承诺不等于到手
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 承诺不等于到手
:::

<b>这一步回答：期望和到手是两个东西。</b>10 个玩具年份里，B 的平均可以是 5%，但其中几年是负的——期望是所有可能结果的加权平均，到手的是某一年实际发生的那一个。点“再跑一次”：平均一直在 5% 附近，年份里的红柱子却总会出现。 {#s4e .explain}

::: html step4-2
s4cv: B 的 10 个玩具年份：红柱是亏的年份，虚线是平均
:::

::: strings
s4ro: 10 年里 {neg} 年是负的，10 年平均 {mean}%：承诺的是平均，拿到的是每一年。
lblLoss: 亏的年份
lblGain: 赚的年份
:::

## 风险、回报、承诺，三句话 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 总结
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 总结
:::

<b>这一步回答：以后看到“高回报”，先问哪三件事？</b>问：波动有多大（方差）？多出来的回报是平均还是保证？最坏的一年能不能接受？风险越大、承诺的平均回报通常越高，因为没人会白白承担波动——但承诺的只是平均。 {#s5e .explain}

::: html step5-2
s5cv: A 与 B 的对照：确定性、波动、承诺的平均
recapTitle: 回顾
recap1: 方差量的是散开程度，不是好坏：平均一样，散得越开，单年越不可预测。
recap2: 风险溢价是补偿：波动的 B 平均给得更多，多出的部分是为承担波动付的，不是保证。
recap3: 期望 ≠ 到手：平均 5% 的年份里照样有亏的年份；看分布，不要只看平均。
