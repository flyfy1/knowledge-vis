## 两个账户同起跑 10000，年收益 5%，30 年后差多少？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 先猜一个数
:::

::: html step0-1

<b>这一步回答：先猜，再看答案——猜错正是学习的机会。</b>两个账户都从 10000 起跑、年收益都是 5%、都放 30 年。唯一的区别：一个不收费，一个每年收 1%（按资产比例收）。先点一个猜测，再看实际差距。 {#s0e .explain}

## 收 1% 的费，公式里到底变了什么？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 费率从收益率里扣
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 费率从收益率里扣
:::

<b>这一步回答：费率直接从年收益率里扣。</b>复利公式 A = P(1+r)ᵗ。收 f% 的费，相当于 r 变成 r−f：A = P(1+r−f)ᵗ。拖动年收益率和费率，看两条曲线怎么分开——分开的幅度随时间越拉越大，这就是下一步要量的。 {#s1e .explain}

lblFee: 年费率 f（%）
:::

::: strings
s1ro: r = {r}%，f = {f}%：30 年后不收费 {nf}，收费 {ff}，差 {gap}（{pct}%）。
lblNoFee: 不收费
lblWithFee: 收费
:::

## 差距是线性长大，还是指数长大？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 时间把差距拉大
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 时间把差距拉大
:::

<b>这一步回答：指数长大。</b>差距 = P(1+r)ᵗ − P(1+r−f)ᵗ，两项都是指数，差也是越拉越大的曲线。拖动年数和费率：10 年时差距还小，30 年、40 年时差距陡然变大——费率伤害的不是某一年，而是整个复利过程。 {#s2e .explain}

::: html step2-2
s2cv: 差距随年数变化的曲线：越往后越陡
lblYears: 年数 t
:::

::: strings
s2ro: r = 5%，f = {f}%：{t} 年后不收费 {nf}，收费 {ff}，差 {gap}（{pct}%）。年数越长，差距占比越大。
lblGap: 差距
:::

## 费率不变，资产变大，费用会怎样？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 费率按资产比例收
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 费率按资产比例收
:::

<b>这一步回答：绝对费用跟着资产走。</b>年费率 1% 是比例，不是固定金额：资产 10000 时每年 100，资产 500000 时每年 5000。拖动资产规模，看每年费用怎么变——账户越大，每年被收走的绝对金额越大，哪怕费率一格都没动。 {#s3e .explain}

::: html step3-2
s3cv: 年费率 1% 下，每年费用随资产规模变化
lblAssets: 资产规模
:::

::: strings
s3ro: 资产 {a}，年费率 1%：每年费用 {fee}。资产翻倍，费用也翻倍——费率不变，绝对费用跟着资产走。
lblYearFee: 每年费用
:::

## 看到一个费率数字，应该怎么读？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 读费率要读年比例
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 读费率要读年比例
:::

<b>这一步回答：读成年比例，再乘上时间。</b>费率数字本身不告诉你代价，要把它读成“每年从资产里拿走百分之几”，再乘上你的持有年数、过一遍复利。拖动费率（r = 5%、30 年）：0.1% 吃掉约 3%，0.5% 约 13%，1% 约 25%，2% 约 44%。本页只教怎么读，不推荐任何产品。 {#s4e .explain}

::: html step4-2
s4cv: 30 年后终值被吃掉的比例，随费率变化
:::

::: strings
s4ro: 年费率 {f}%（r = 5%，30 年）：终值比不收费少 {g}%——小费率 × 长时间 = 大差距。
:::

## 费率的三句话 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 总结
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 总结
:::

<b>这一步回答：以后看到费率，先问哪三件事？</b>问：是年比例还是固定金额？乘上我的持有年数是多少？复利放大后还剩多少？1% 不是 1%，是 30 年后四分之一的终值。 {#s5e .explain}
