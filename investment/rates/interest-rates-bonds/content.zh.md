## 一张债券，到底对应未来哪些钱？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 债券是一串现金
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 债券是一串现金
:::

<b>这一步回答：债券 = 未来的现金流序列。</b>玩具债券：面值 1000，票息 5%，5 年到期。未来现金是：第 1–4 年每年 50，第 5 年 50 + 1000。债券的价格，就是这一串未来现金在今天值多少——这正是下一步的贴现。 {#s0e .explain}

::: html step0-2
s0cv: 玩具债券的未来现金流：第 1–4 年 50，第 5 年 1050
:::

::: strings
s0ro: 一张债券 = 未来一串现金：每年 50，到期再加 1000 本金，5 年未贴现合计 1250。
lblCoupon: 票息
lblPrincipal: 本金
:::

## 1000 要等 5 年，今天它值多少？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 贴现：未来的钱今天值多少
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 贴现
:::

<b>这一步回答：贴现是复利的倒过来。</b>现值 PV = FV / (1+r)ᵗ：把复利公式倒过来，未来的钱除以 (1+r)ᵗ。利率越高、等得越久，今天的价值越小。拖动利率和年数，看 1000 的现值怎么变——这就是债券定价的单个零件。 {#s1e .explain}

::: html step1-2
s1cv: 1000 的现值随等待年数下降（所选利率下）
lblRate: 利率 r（%）
lblYears: 年数 t
:::

::: strings
s1ro: {t} 年后的 1000，r = {r}% 时今天值 {pv}；r 越高、t 越长，今天值越小。
:::

## 拖动利率，整张债券的现值怎么走？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 利率滑杆与债券现值曲线
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 利率滑杆
:::

<b>这一步回答：利率一升，整条现值曲线往下走。</b>把第 0 步那串现金（每年 50、到期 1050）逐笔贴现再加总，就是债券现值。拖动利率：曲线全程向下——利率越高，每一笔未来现金今天都越不值钱，加总自然越小。注意利率 5% 那个点：现值正好是 1000，因为票息率等于利率。 {#s2e .explain}

::: html step2-2
s2cv: 玩具债券现值随利率变化的曲线
:::

::: strings
s2ro: 利率 {r}% 时，这张债券的现值是 {pv}（票息 5%、面值 1000 的债券，利率 5% 时现值正好 1000）。
lblBondPV: 债券现值
:::

## 利率升了，旧债券凭什么必须跌价？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 为什么是反向：新买家要新利率
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 为什么是反向
:::

<b>这一步回答：因为新买家只按新利率出价。</b>利率升到 8% 后，新债券按 8% 付息、1000 出售。旧债券只付 5% 的票息：如果还卖 1000，买它的人只拿到 5%，没人愿意——旧债券必须跌价，跌到买它的人同样能拿到 8% 为止。拖动新利率，看旧债券价格跌到多少。 {#s3e .explain}

::: html step3-2
s3cv: 新债券（8% 票息、1000）与旧债券（5% 票息、跌价后）的对比
lblNewRate: 新利率（%）
:::

::: strings
s3ro: 新利率 {r}% 时，旧债券（票息 5%）价格要跌到 {p}：按 {p} 买入，买它的人才能同样拿到 {r}% 的年化。
lblOldBond: 旧债券价格
lblNewBond: 新债券价格
:::

## 同样升 1%，长期债券为什么跌得更多？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 久期直觉：期限越长越敏感
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 久期直觉
:::

<b>这一步回答：钱要等越久，越怕利率变。</b>比较两张债券：2 年期和 10 年期，都是 5% 票息、1000 面值。利率同样上升时，10 年期那串现金里的大头（本金）要等 10 年，贴现受影响最大，所以跌得更多。这里只讲方向和相对大小，不算久期公式。拖动利率，看两条现值曲线分开。 {#s4e .explain}

::: html step4-2
s4cv: 2 年期与 10 年期债券现值随利率变化：长期跌得更多
:::

::: strings
s4ro: 利率 {r}% 时：2 年期债券现值 {p2}（相对面值 {d2}%），10 年期 {p10}（{d10}%）——长期债券跌得更多。
lblShort: 2 年期
lblLong: 10 年期
:::

## 利率与债券的三句话 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 总结
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 总结
:::

<b>这一步回答：以后听到“利率升、债券跌”，先问哪三件事？</b>问：这张债券的未来现金是什么？按新利率贴现后值多少？期限越长是不是跌得越多？债券价格不是情绪，是未来现金按新利率重算的结果。 {#s5e .explain}
