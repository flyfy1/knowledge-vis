# BRIEF：速度与 v-t 图（velocity-vt）· 初中物理

## 定位
- slug `velocity-vt`，category physics（以站内现有分类口径为准：读 pages.config.js 已上线物理页的 category 字段照抄），stage junior。受众：初中生 + 家长。本站初中物理第一页。
- 核心直觉一句话：**v-t 图不是画着玩的：线的高低是快慢，线下面的面积就是走过的路——把图切成小条一加，路自己算出来了（这是高中积分的第一颗种子）**。
- 已知：速度=路程÷时间、匀速直线运动、坐标系读图（一次函数页刚练过）。唯一新问题：速度在变的时候，走过的路怎么从图上读？

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **赛跑**：已知速度的意义；唯一问题：两个人谁快、谁先到，图和实景怎么对应？控件：双车赛跑动画（甲匀速 4 m/s、乙匀速 2 m/s，可播放/暂停/重播），上方实景跑道（位置实时标记），下方同屏 x-t 图两条线同步生长；探针拖时间刻度，读两车位置。预期观察：跑道上甲乙的间距越拉越大，x-t 图上甲线更陡；同一时刻两线高低差 = 位置差。结论：x-t 图的陡缓就是速度（回收一次函数页的斜率口径：陡=快）。适用条件：只谈直线运动、速度只取正（向前）。
2. **v-t 登场**：唯一问题：把「每一刻的速度」画成图，长什么样？控件：同一场赛跑切换到 v-t 口径：匀速 → 水平线（高度=速度）；再给丙车「起步加速」一段（速度从 0 匀加速到 4 m/s），v-t 是斜线；切换按钮在 x-t / v-t 间来回，同一运动两种图对照，读数同步。预期观察：匀速在 v-t 里是平的、在 x-t 里是斜的——别混。结论：v-t 图看高低（纵轴值=此刻速度），不是看陡缓（与 x-t 正相反，此处要明说防混淆）。
3. **面积就是路**：唯一问题：v-t 图下面那块面积，凭什么是路程？控件：匀速段 v-t 图下逐步切条演示：先整块矩形（面积=速度×时间=路程，逐项对账）；再把加速段切成 4 条、8 条、16 条窄矩形（台阶逼近按钮），台阶总和与三角形面积（½×底×高）对账，条越细差越小（读数显示台阶和与精确值之差）。预期观察：匀速时面积=长方形一乘就得；加速时切得越细、台阶填得越满。结论：v-t 图下面积 = 路程，恒成立（匀速是矩形、匀加速是三角形、一般的靠切细条加总——「高中会给这招一个名字：积分」一句埋线，不展开）。
4. **读图实战**：唯一问题：给一段真实点的行程图，能读出多少事？控件：分段 v-t 图（0–2s 加速到 4、2–5s 匀速、5–7s 减速到 0），探针拖时刻读瞬时速度；分段面积逐段点亮累计（梯形/三角形/矩形各段的面积读数与总路程累计）；「哪一段在加速/减速/匀速」三连问答即时判定。预期观察：每段面积加起来 = 总路程 20 m（构建者须把数值设计成整数自洽：½×2×4=4、3×4=12、½×2×4=4，合计 20）。结论：读 v-t 图三件事：看高低（快慢）、看升降（加速减速）、算面积（路程）。
5. **自测 + 终章**：①给一幅新 v-t 图（数值另一组、整数自洽），问某时刻速度（探针答题）；②问总路程（分段面积答题，选项或填入判定=精确整数）；③判断题「v-t 图线越陡速度越大」（错：陡的是加速度、纵轴值才是速度——反馈里点破但不展开加速度概念，只说「升得急说明速度变得快」）。终章三卡（x-t 看陡缓 / v-t 看高低 / 面积是路）+ 深链：linear-functions#step0（斜率在那页是爬坡、在这页是速度）、parabola#step0 如已上线链投篮点列（未上线不链）；终章埋线一句指向未来的 integral 页（未上线不做成链接）。
