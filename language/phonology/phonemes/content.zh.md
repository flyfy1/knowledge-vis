## 同一个声道，改变一个开关就换了音 {#step0 h2=s0t}

::: strings
nav0: 0 发音动作
:::

第 0 步 · 发音动作 {#s0k .step-kicker i18n=text}

这一层问：**发音器官**怎样把气流塑形成一个音？点选下面的音，观察舌头、嘴唇、声带和气流箭头。**清/浊**不是“音量大小”，而是声带是否振动。 {#s0e .explain}

::: html step0-1
mouthLabel: 口腔侧视图 · 舌位与声带
featuresTitle: 特征面板
:::

先看动作再记符号：**发音部位**说“在哪里”，**发音方式**说“怎样阻挡气流”，**清浊**说“声带是否振动”。同一个特征可以在很多语言里形成对立。 {#s0hint .hint}

::: html step0-2
next: 继续：寻找最小对立 ↓
:::

## 只改一个特征，词义就能换轨 {#step1 h2=s1t}

::: strings
nav1: 1 音位对立
:::

第 1 步 · 音位对立 {#s1k .step-kicker i18n=text}

两个词只差一个音、意义却不同，这组词叫**最小对立**（minimal pair）。切换词对，找出哪一个特征变了；下方连线把“声音差异”对应到“意义差异”。 {#s1e .explain}

::: html step1-1
:::

音位不是某一次录音的“声音颗粒”，而是能在这门语言里**区分意义的抽象类别**。/p/ 与 /b/ 的清浊差异，在 pat/bat 中有区分作用。 {#s1hint .hint}

::: html step1-2
next2: 继续：拆开一个音节 ↓
:::

## 音节不是一团声音：它有可见的槽位 {#step2 h2=s2t}

::: strings
nav2: 2 音节骨架
:::

第 2 步 · 音节骨架 {#s2k .step-kicker i18n=text}

选择一个词，再点它的音段。一个典型音节由**起首**、**核**、**韵尾**组成：核是必需的峰值，另外两格可以为空。 {#s2e .explain}

::: html step2-1
onset: 起首 Onset
nucleus: 核 Nucleus
coda: 韵尾 Coda
onsetLegend: 起首：核之前的辅音
nucleusLegend: 核：音节的峰值
codaLegend: 韵尾：核之后的辅音
:::

“音节”是结构，不只是时长。英语 splash 的 /spl/ 都在核 /æ/ 前面，所以一起属于起首；/ʃ/ 在核后，属于韵尾。点击音段，让结构和解释同步出现。 {#s2hint .hint}

:::

## 规则把同一个后缀，送到不同的表面位置 {#step3 h2=s3t}

::: strings
nav3: 3 语境变体
:::

第 3 步 · 语境变体 {#s3k .step-kicker i18n=text}

选择词根的末音，观察英语复数后缀的**同化**。底层后缀可记作 /s/ 或 /z/；在浊音后，声带状态会把它实现为 [z]，在清音后实现为 [s]。 {#s3e .explain}

::: html step3-1
rootLabel: 词根最后一个音
root_cat: cat /k/（清音）
root_dog: dog /g/（浊音）
suffixLabel: 复数后缀的底层形式
suffix_s: /s/
suffix_z: /z/
replay: ▶ 重放规则
:::

方括号 [ ] 记录**实际发出的表面音**，斜线 / / 记录音位类别。规则没有创造新词义，只让相邻音段在语境中更容易连贯发音。 {#s3hint .hint}

::: html step3-2

:::

## 把“特征 → 对立 → 变体”说完整 {#step4 h2=s4t}

::: strings
nav4: 4 自测
:::

第 4 步 · 自测 {#s4k .step-kicker i18n=text}

先独立作答，再看反馈。每道题只考一个关键关系：哪一项是最小对立、哪一个槽位是音节核、哪个后缀表面音受浊音同化。 {#s4e .explain}

::: html step4-1
newQuiz: 换一道题
takeawayTitle: 三句话带走
take1: **发音动作**描述身体怎样做；特征束把动作压缩成可比较的标签。
take2: **音位对立**描述哪些差异能区分意义；最小对立把抽象类别钉在词义上。
take3: **语境变体**描述同一类别在邻近音影响下怎样落地；/ / 与 [ ] 的层级不要混。
:::
