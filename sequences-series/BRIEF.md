# BRIEF：数列与求和（sequences-series）· Sequences & Series
- category `math`，stage `senior`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：patterns-sequences（同批小学）讲找规律与通项的发现；本页是等差/等比求和与极限（高中），核心不同；exp-log 讲指数，limits-epsilon 讲 ε–δ，不重合。
- 核心直觉：等差 aₙ=a₁+(n−1)d、倒序相加 Sₙ=n(a₁+aₙ)/2；等比 aₙ=a₁rⁿ⁻¹、Sₙ、|r|<1 极限 a₁/(1−r)；乘出来的增长终将超过加出来的增长。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **等差数列**
   - 已知：数列。
   - 唯一问题：每次加同样多，第 n 项怎么写？
   - 输入与求量：输入 a₁、d；求前 10 项与通项。
   - 控件操作与预期观察：拖 a₁、d：阶梯上升/持平/下降；通项更新。
   - 适用条件：实数；负项只标数字。
1. **倒序相加**
   - 已知：等差通项。
   - 唯一问题：1+…+n 有捷径吗？
   - 输入与求量：输入 a₁、d、n（2–14）；求长方形面积一半与逐项求和。
   - 控件操作与预期观察：每行青+橙宽度 = a₁+aₙ；两个结果相同。
   - 适用条件：与第 0 步共用 a₁、d（两组滑杆同步）。
2. **等比数列**
   - 已知：乘方。
   - 唯一问题：棋盘第 64 格多少粒？
   - 输入与求量：输入 r（1.1–3）、n（1–64）；求第 n 项与累计。
   - 控件操作与预期观察：r=2：前 12 格 2048 粒，第 64 格 9.2×10¹⁸；对照线性每格+1。
   - 适用条件：r>1；颜色按对数。
3. **等比求和与极限**
   - 已知：等比通项。
   - 唯一问题：无穷多项相加会无穷大吗？
   - 输入与求量：输入 r（−0.95…1.2）、n（1–20）；求 Sₙ、极限、差距。
   - 控件操作与预期观察：|r|<1 趋近 a₁/(1−r)；负 r 上下跳；|r|≥1 发散。
   - 适用条件：仅展示到 20 项，无严格证明。
4. **线性 vs 指数**
   - 已知：两种求和。
   - 唯一问题：加得多还是乘得快谁赢？
   - 输入与求量：输入 d（0–60）、g（0–10%）；首月都 100；求累计与反超月份。
   - 控件操作与预期观察：g=3% 开始落后随后反超；g=0 永不反超。
   - 适用条件：纯数学模型，40 个月。
5. **认出数列**
   - 已知：差与比。
   - 唯一问题：这是哪一类？
   - 输入与求量：选择 等差/等比/都不是；检查；换一列。
   - 控件操作与预期观察：检查显示通项与下一项；换一列清除选择；终章含回顾与 3 条互链。
   - 适用条件：5 组预设。
