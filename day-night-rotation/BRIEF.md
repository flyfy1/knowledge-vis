# BRIEF：昼夜交替（day-night-rotation）· 地球科学 / 小学

## 定位
- slug `day-night-rotation`，category `earth`（**新分类，站内未注册**——注册时由 Alberto 在 `pages.config.js` 的 `KNOWLEDGE_CATEGORIES` 新增 `{ id: "earth", name: { zh: "地球与太空", en: "Earth & Space" } }` 后条目再引用；构建者不得自己改 pages.config.js，分类徽标在本页构建期按未注册优雅降级处理——参照 particles-states 注册前 badge 为空的做法，不报错、不写死分类名），stage `primary`。受众：小学中高年级 + 家长。OUTLINE-v2 定位（W4）：天文小线起点——「手电照地球仪转一圈，晨昏线扫过的地方天就亮了」，后续接月相（moon-phases，储备）、公转与四季（seasons-orbit，储备）。

## 步骤（0 起共 7 步；每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
1. **地球仪上的小人**（3D 首登场）：已知白天亮、夜里黑；唯一问题：这个地球仪上的小人（标记点）那里，现在是白天还是黑夜，凭什么判断？控件：3D 地球缓缓展示（默认不自转或极慢展示转，首拖即停，对齐 space-diagonal 口径）、可拖动转视角；阳光已开（太阳在画面一侧，带平行光箭头示意）；标记点是赤道上的一枚醒目小旗/小人，带 HTML 覆盖层标签「小人住在这里」。**地轴**首现就近解释：画一条穿过南北极、略伸出球面的细轴线，标签 + 正文一句——「地轴是假想的转动轴，地球就绕着它转；它不是真插在地球里的一根棍子。」读数行：「小人那里：白天——他所在的那一面正对着太阳」（判定走纯函数，见判定口径）。**尺度失真口径句（本步正文，必须有，中英双份）**：「图上的太阳和地球的大小、距离都不是真实比例——真实的太阳能装下约 130 万个地球，离我们约 1.5 亿千米；真按比例画，这一页就只剩一个小点了。」结论：判断一个地方是白天还是黑夜，先看它朝向哪边。适用条件：本页太阳固定不动、只地球转（为什么这样设定，第 4 步回收一句）。
2. **开灯：半个地球亮了**：已知小人处是白天；唯一问题：把「灯」打开，亮的只有一半——亮和暗的分界线在哪、由什么决定？控件：3D 场景 + 2D 侧视辅助图（太阳在右、平行光箭头水平射来，地球圆面一半亮一半暗，分界线为过圆心的竖直线，由光线方向实算，见判定口径）；「关灯/开灯」钮：关灯时整个球面均匀暗（没有太阳，就没有昼夜之分，读数行明说）；转**视角**钮（或拖动）换角度看。预期观察：绕到哪个角度看，分界线都只跟阳光来的方向有关——转的是我的眼睛，不是光。**晨昏线**首现就近解释：「亮半边和暗半边的分界线叫晨昏线；站在这条线上的人，正迎来日出或正送走日落（第 2 步看清是哪一种）。」结论：**朝向太阳的半个地球是白天，背向的半个是夜里，分界线叫晨昏线**。适用条件：阳光视为平行光（太阳极远，近似成立，本条是真近似、不是失真，终章模型节回收）。
3. **转起来：一圈是一天**：已知分界由阳光方向定死；唯一问题：让地球自己转起来，小人会依次经历什么、几点天黑几点天亮？**自转**首现就近解释：「地球绕着自己的地轴转，叫自转。」控件：3D 场景（标记点随地球转）+ 2D 北极俯视辅助图（圆 = 从北极上空看的地球，阳光从右侧水平来，晨昏线是过圆心的竖直线，标记点在圆边上随转角移动，转角弧与 α 标注实时画）+「让地球转起来 / 暂停」播放键 + 时刻滑杆（0–24 时等价数字入口，与播放共用同一状态）。**播放必须见累积与进度（交互硬要求 2）**：场景下方一条 24 小时时间带，播放走过的时段逐段着色（白天段暖黄、夜里段深蓝，颜色由该时刻的昼夜判定纯函数给），并显示「已经转过约 X 小时 / 一圈 24 小时」；重播清空时间带。预期观察：小人从正对太阳（正午）转去，先黄昏、入夜、半夜，再清晨、日出，回到正午；时间带上亮段与暗段各占一半。读数行：「小人那里现在约 {T} 点——{白天/黄昏/夜里/清晨}」（T 与状态词全部由转角纯函数算，见判定口径）。结论：**地球自转一圈是 24 小时；在本页模型里，小人 6 点迎来日出、18 点送走日落，白天夜里各 12 小时**。适用条件：标记点在赤道上 + 本页地轴不倾斜的模型结果（别处、别季节不一定各半，第 4 步与终章明说）。
4. **站到小人头上：太阳为什么东升西落**：已知是地球在转、小人时刻可算；唯一问题：明明转的是地球，为什么站在地上看，动的是太阳——还偏偏从东边升、西边落？控件：视角切换钮「从太空看 / 站到小人头上」——后者切到 2D 小人天空图（地平线 + 半圆天顶，太阳点的位置由同一转角纯函数算，见判定口径；夜里太阳在地平线以下、变暗画在地下段并标注「在地平线下面，看不见」），读数与第 2 步同一时刻、两视角对照同屏（小字注：「同一个时刻，两个看法」）；播放键在此步同样可用。**地平线**首现就近解释：「站在地面上，眼睛能看到的天和地的分界线。」预期观察：太阳点从东边地平线升起、爬到最高（正午）、从西边落下，走的是一个拱；地球转得越快这拱走得越快——动的根源始终是地球。结论（因果链写死，不得写反）：**地球自西向东自转，把我们带着向东转，于是看起来像太阳反着走：从东边升起、向西边落下。太阳东升西落，是地球自转的表象**。适用条件：南北半球同理（方向口径全球一致，本页不展开半球差异）。
5. **朝哪个方向转，转一圈多久**：已知自转造成昼夜、表象是东升西落；唯一问题：地球到底朝哪个方向转，怎么知道、转反了会怎样？控件：「反着转一次」假想钮——按下后自转方向反转、时间倒着走（读数仍走同一纯函数、时刻递减），小人天空图（复用第 3 步小图）里太阳改从**西边**升起；钮旁文案标注「假想：如果反着转」；再按切回正常方向。第 2 步俯视图在此复用一小幅（标出自西向东的环形箭头）。预期观察：方向一反，日出方位就反——真实世界太阳从东边升，所以真实方向只能是自西向东。方向口径写死：**从北极上空往下看，地球逆时针转，这就叫自西向东**。周期结论：**自转一圈 = 一天（24 小时）**；转得越快，一天越短（滑杆调速只改播放速度、不改这个事实，控件旁注一句「调的是动画快慢，不是地球的真速度」防误读）。**公转埋线一句（正文，必须有）**：「地球还一边自转、一边绕着太阳转，绕一圈是一年——这叫公转；公转加上地轴是斜的，才有了四季，那是另一页的事，本页不展开。」（公转首现即带这一句定义；深链预留位见终章。）
6. **自测**：四题全答对才出终章提示（沿用全站自测锁定口径）；每题反馈须点名错在哪条直觉，不许只说「再想想」。①现在你这里是黑夜，最直接的原因是？（你所在的那一面背对太阳 ✓；太阳被云挡住了 ✗——云只挡一小会儿，没有云的夜里也一样黑；太阳下班休息了 ✗——太阳一直在发光，是我们转过去了；月亮把阳光挡住了 ✗——那叫日食，很少见，不是每天的夜。）②地球自转一圈，我们过完？（一天，24 小时 ✓；一年 ✗——那是公转一圈的时间；一个月 ✗——那是月亮绕地球一圈的大致时间。）③太阳早上从东边升起，是因为？（地球自西向东转，我们被带着转向太阳 ✓；太阳真的绕着地球从东往西跑 ✗——看起来像，其实转的是我们；风把太阳吹过去的 ✗——太阳的位置不由风决定，而且夜里没风也照样天黑。）④图上小人正对着太阳时，他那里是几点？（正午 12 点 ✓；半夜 0 点 ✗——那是小人背对太阳的时刻，回收第 2 步读数；早上 6 点 ✗——那是小人刚转到晨昏线上、日出的时刻。）
7. **终章**：三卡收束（转的是地球：昼夜是自转的结果 / 朝向太阳是白天、背向是夜里，晨昏线扫过谁谁天亮 / 太阳东升西落是表象，根源是自西向东的自转）。**模型实话节（必须有，中英双份）**：①本页把地轴画成竖直、阳光正对赤道，所以每个地方昼夜正好各 12 小时；真实地轴倾斜约 23.5°，各地的白天长短会随季节变化——那是四季页的内容。②本页「自转一圈 24 小时」按对着太阳算（叫太阳日）；对着遥远的星星转一圈其实是 23 小时 56 分，差的几分钟来自公转，本页不展开。③太阳的大小、距离、大陆形状都是示意（回收第 0 步尺度句）；阳光画成平行线则是真近似：太阳离得极远，照到地球的光几乎平行。互链区（规则 12）：**预留位两张纯文字预告卡，不挂链接**——「月亮为什么有圆缺：月相（筹备中）」「地球公转与四季：为什么夏天白天长（筹备中）」；登记注记：两目标页（moon-phases、seasons-orbit）均未上线，**不得裸链不存在的页或锚点**，待其上线后由 Alberto 补链并在 CONCEPT-MAP 登记（沿 pinhole-camera 终章登记注记的先例）。

## 状态与纯函数（写死，构建与自查都按此执行；全页单一事实源）
- **全局共享状态**：`state.theta`（地球已转角，度，0 起累积）+ `state.dir`（+1 正常 / −1 假想反转）+ `state.playing`。第 0–4 步的全部场景与辅助图都从这一份状态渲染；任一步改时刻（播放/滑杆/方向），其余步的图与读数同步更新——禁止各步各存一份时刻。
- **几何常量（写死）**：阳光方向 `SUN_DIR` 固定（自 +X 向 −X 平行照射）；地轴竖直（+Y，北极朝上）；标记点固定在赤道上。初始 `theta = 0` 定义为标记点正对太阳（正午）。
- **转角定义（写死）**：`alpha = ((theta mod 360) + 360) mod 360`，为标记点自正午位置起、沿自转方向转过的角度。
- `sunDot(alpha)`：标记点法线与阳光方向夹角的余弦 = `cos(alpha°)`（赤道 + 本几何下就是它，不许另造公式）；> 0 朝阳、< 0 背阳、= 0 在晨昏线上。3D 里的明暗由 DirectionalLight 的真实光照呈现，**判定与读数一律走本函数、不许读像素反推**；2D 图的晨昏线位置由 `SUN_DIR` 实算（侧视图 = 过圆心、垂直于光线的直线；俯视图同理），不许手绘固定假分界冒充实算。
- `localTime(alpha) = (12 + alpha / 15) mod 24`（浮点保留一位小数显示为「约 X 点」或换算为时:分，两语种同口径）；`alpha=0→12:00 正午、90→18:00、180→0:00 半夜、270→6:00`，构建自查须逐个断言。
- `phaseOf(alpha)`：昼夜状态判定——`sunDot > 0` 白天、`< 0` 夜里；在 `alpha` 穿过 270 的邻域标「日出/清晨」、穿过 90 的邻域标「日落/黄昏」（邻域宽度由构建定、写进报告，状态词与时间带颜色同源于本函数）。
- `apparentSun(alpha)`（第 3 步天空图）：拱角 `beta = alpha + 90`（度，mod 360）；太阳点位置 `(cos beta°, sin beta°)`——`beta=0` 东边地平线（日出）、`90` 天顶（正午）、`180` 西边地平线（日落）、`270` 地平线正下方（半夜）；`sin beta < 0` 时画在地平线以下并变暗。自查断言四点位置。
- **方向断言（构建自查必须有，防写反）**：正常方向下播放推进，`localTime` 递增；从正午播过四分之一圈（alpha 到 90），标记点到达的是**日落**侧（黄昏）而不是日出侧；俯视图中标记点沿逆时针（从北极看）移动。三条任一不符即方向写反、不得交付。

## 判定口径（写死）
- 昼夜判定只认 `phaseOf` / `sunDot`，3D 光照只负责好看，读数、时间带、状态词、自测答案全部同源于纯函数。
- 时刻显示口径全页统一：一位小数小时或时:分（构建二选一并全页贯彻，正文首现处注「图上的转速是动画速度，一圈代表真实的 24 小时」）。
- 自测答案全部能由纯函数/正文结论回算核对（题④的 12 点 / 0 点 / 6 点与 `localTime` 四断言点逐一对上），不许写与函数不符的死数。
- 边界值逐个核（规则：同屏读数互洽）：alpha 跨 360 回绕时时刻不得跳负、时间带不得残留上一圈颜色；暂停时拖滑杆，3D、两张 2D 图、读数四处同步；反转方向时时间带按倒走口径重绘、不许与正走颜色打架（构建定口径并写进报告）。
