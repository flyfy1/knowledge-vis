# BRIEF：串联与并联（series-parallel）· Series & Parallel Circuits
- category `physics`，stage `junior`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：simple-circuits（回路闭合/短路/串联电池）与 ohms-law（I–U–R、非欧姆、功率、内阻）不涉及电阻的串并联分流；本页核心不同（<25% 重合）。
- 核心直觉：串联：I 相同、R=R₁+R₂、电压按 R 分；并联：U 相同、1/R=1/R₁+1/R₂、电流按 R 反比；加灯泡的差别；拧下灯泡；混联 KVL/KCL；家庭并联与保险丝串联。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **串联**
   - 已知：I=U/R。
   - 唯一问题：串联时电流电压怎样分？
   - 输入与求量：输入 R₁、R₂（2–24 Ω），U=12 V；求 I、V₁、V₂。
   - 控件操作与预期观察：拖 R：电流圆点同速，V₁:V₂=R₁:R₂；可暂停；圆点只示意相对速度。
   - 适用条件：理想电源，恒定电阻。
1. **并联**
   - 已知：串联结论。
   - 唯一问题：并联时电流怎样分？
   - 输入与求量：输入 R₁、R₂；求 I₁、I₂、I。
   - 控件操作与预期观察：拖 R：R 小的支路更快、电流更大；总电流为和。
   - 适用条件：同上。
2. **总电阻**
   - 已知：串联并联。
   - 唯一问题：再接一个灯泡总电阻升还是降？
   - 输入与求量：输入灯泡个数 n（1–6），6 Ω 每个；求串联/并联的 R、I、每个灯泡功率。
   - 控件操作与预期观察：拖 n：串联电流下降且变暗，并联电流上升亮度不变。
   - 适用条件：灯泡阻值恒定。
3. **拧下一个灯泡**
   - 已知：总电阻。
   - 唯一问题：拿掉一个灯泡其他还亮吗？
   - 输入与求量：输入串/并联、拧下哪几个；求亮灯数与总电流。
   - 控件操作与预期观察：串联任一处断开全灭；并联其余不变；放回全部恢复。
   - 适用条件：三个相同灯泡。
4. **混联**
   - 已知：串联并联。
   - 唯一问题：混联怎么算？
   - 输入与求量：输入 R₁、R₂、R₃；求 R₂₃、R、I、各电压电流及守恒核对。
   - 控件操作与预期观察：拖三电阻：V₁+V₂₃=12 V，I₂+I₃=I 始终成立。
   - 适用条件：恒定电阻。
5. **家里的线路**
   - 已知：并联分流。
   - 唯一问题：家里为什么并联、保险丝为什么串联？
   - 输入与求量：输入四个电器开关；230 V、13 A 保险丝；求总电流。
   - 控件操作与预期观察：依次接入：水壶 7.8 A 安全，水壶+取暖器 16.5 A 跳闸；跳闸后按钮无效直到重新合上；终章含回顾与 3 条互链。
   - 适用条件：纯电阻稳态，忽略启动电流。
