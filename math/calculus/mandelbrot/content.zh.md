## 放大一千亿倍，还没到底 {#step0 h2=s0t}

::: strings
nav0: 0 钩子
:::

第 0 步 · 先玩起来 {#s0k .step-kicker i18n=text}

这就是 Mandelbrot 集的全貌：中央偏右一颗「心脏形」主体，左侧拖着一条细长的天线，周围还伸出芽苞、触须和螺旋。它来自一行公式：从 z = 0 出发，反复计算 **z ← z² + c**。c 是图上的点——迭代下去跑不远的点涂黑，跑掉的按跑掉的快慢上色。**现在就上手**：在图上拖出一个框放大（触屏上用一根手指拖框，效果一样），或用滚轮缩放、双击放大，看看细节是不是越挖越多。 {#s0e .explain}

## 反复按 z² + c：一个点的两种命运 {#step1 h2=s1t}

::: strings
nav1: 1 一个点的一生
:::

第 1 步 · 一个点的一生 {#s1k .step-kicker i18n=text}

先不管整张图，只盯住**一个点 c**：从 z₀ = 0 出发，一遍遍代入 z ← z² + c，轨道只有两种结局——要么很快冲出图上那个半径为 2 的圆（**逃逸**，这个 c 不属于集合），要么一直在圆内打转（**留下**，c 属于集合）。在图上点选或拖动 c，或用下面的预设，看轨道一步步长出来。 {#s1e .explain}

::: html step1-1
s1step: 单步 →
s1reset: 重置轨道
s1pEsc: 预设：逃逸的点
s1pStay: 预设：留下的点
s1pCycle: 预设：打转的点
:::

换一个 c（在图上点选、拖动，或按下面的预设）后，轨道会回到 z₀ 重新开始、不会自己继续往前长——再按「单步 →」或「▶ 播放」，看新轨道一步步长出来。圆不是装饰：第 2 步会证明，只要 |z| 一旦超过 2，就再也回不来了。所以「冲出圆」= 宣判逃逸。 {#s1hint .hint i18n=text}

播放会逐渐加速：前 10 步每帧走 1 步，之后每帧 2 步、第 30 步起每帧 5 步。加速只是「一帧多走几步」——每一步都真实计算并画在图上，读数始终对应当前这一步，没有跳步。 {#s1accel .hint i18n=text}

## 为什么偏偏是 2 {#step2 h2=s2t}

::: strings
nav2: 2 分界线
:::

第 2 步 · 分界线 {#s2k .step-kicker i18n=text}

判据只有一句话：**|z| 一旦超过 2，就永不回头。**算一笔账：若某一步 |z| &gt; 2 且 |z| ≥ |c|，则下一步 |z² + c| ≥ |z|² − |c| ≥ |z|·(|z| − 1)，而括号里的数大于 1——于是 |z| 每一步都被乘上一个越来越大的倍数，像雪球一样滚走，再也停不下来。所以画这张图时，每个点只需盯到它出圆为止。 {#s2e .explain}

::: html step2-1
s2iter: 最大迭代上限（观察多久才下判决）
:::

拖动滑杆看黑色区域的变化：上限太小（比如 5），很多其实会慢慢逃逸的边界点还没跑掉，就被冤枉成「留下」，黑区胖了一圈；上限拉大，黑区才收紧成真正的集合边界。放得越深，这条边界越难判——所以深缩放时迭代上限必须自动调高（第 0、4 步的读数里能看到）。 {#s2note .hint i18n=text}

::: html step2-2

:::

## 颜色 = 每个点挣扎了多久 {#step3 h2=s3t}

::: strings
nav3: 3 颜色从哪来
:::

第 3 步 · 颜色从哪来 {#s3k .step-kicker i18n=text}

黑白版只回答「在不在集里」。可图上的颜色也全是信息：**颜色由逃逸所需的迭代步数决定**——跑得越慢、越靠近边界，步数越大。切换下面三种着色看同一幅图：阶梯色带按整数步数上色，相邻色带之间会「咔哒」一下跳变（那是整数计数的断层）；平滑着色用公式把步数修成小数，断层就被抹平了。 {#s3e .explain}

::: html step3-1
s3bw: ① 黑白
s3band: ② 阶梯色带
s3smooth: ③ 平滑着色
pal0: 深空
pal1: 熔岩
pal2: 极光
s3formulaT: 平滑步数 ν = n + 1 − log₂(ln|zₙ|)
s3note: n 是逃逸时的整数步数，|zₙ| 是逃逸那一刻的模长：逃得越「勉强」，小数部分越大。把 ν 当作「带小数的步数」再上色，色带之间的台阶就消失了。本页所有图都用这个公式，与你看到的实现完全一致。
:::

第 5 步 · 自相似 {#s5k .step-kicker i18n=text}

## 每个点都是一张新图：朱利亚集 {#step6 h2=s6t}

::: strings
nav6: 6 朱利亚集
:::

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

最后把视角倒过来：不再让 c 满平面跑，而是**固定一个 c**，让平面上的每个点当 z₀ 去迭代同一条公式 z ← z² + c——得到的图叫这个 c 的**朱利亚集**。在左图上点选或拖动 c，右图实时重画。规律只有一条，而且不会说反：**c 在 Mandelbrot 集中，朱利亚集是连通的一整块；c 在集外，立刻碎成尘埃。** {#s6e .explain}

::: html step6-1
s6leftT: Mandelbrot 图 · 点选 c
s6rightT: c 的朱利亚集
j0: c = −0.123 + 0.745i（集内）
j1: c = −0.8 + 0.156i
j2: c = 0.5 + 0.5i（集外）
:::

沿着左图的边界慢慢拖：朱利亚集会在「连通的团」与「尘埃」之间千变万化——贴边界的 c 给出的图最精细。所以说 Mandelbrot 集是所有朱利亚集的地图：你在左边点到哪里，右边就是那里的风景。 {#s6note .hint i18n=text}

::: html step6-2
s6fin: 回头看这一页：一条 z ← z² + c，先决定一个点的命运，再给整个平面染色，放大下去又长出小岛和螺旋，最后发现它还是所有朱利亚集的索引。**同样是一行公式生出整个世界**——和傅里叶页里那些旋转的圆，是同一种震撼。
:::
