## “x 越来越靠近 a”时，f(x) 去了哪里？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 靠近是什么意思
:::

::: html step0-1
:::

这一步要回答：**极限**说的到底是什么？极限只关心 x 靠近 a 时 f(x) 的趋势，不关心 x = a 那一点的函数值（甚至函数在那一点可以没有定义，图上用空心圆表示）。选一个函数，把靠近程度 δ 调小（x = a ± δ，δ = 10^(−k)）：读数列出 x = a − δ 与 x = a + δ 处的函数值、整个窗口内函数值的最大差距。如果两边的值都靠向同一个数 L，就说极限是 L；否则极限不存在。图的纵轴固定显示，窗口越小，曲线越贴近水平线（若有极限）。 {#s0e .explain}

::: html step0-2
s0o: 依次选四个函数，把 k 从 0.2 慢慢拉到 4：前两个，两侧函数值越来越接近同一个数（极限存在，分别是 2 和 1）；第三个两侧分别停在 −1 和 +1；第四个函数值在 −1 到 1 之间来回振荡，永远不稳定。
lK: 靠近程度 δ = 10^(−k)
gHole: f(x) = (x²−1)/(x−1)，x → 1
gSinc: f(x) = sin x / x，x → 0
gJump: f(x) = |x|/x，x → 0
gOsc: f(x) = sin(1/x)，x → 0
:::

::: strings
r0: x = a − δ → {fl}；x = a + δ → {fr}；δ = {d}；窗口内函数值的最大差距 {range}；{verdict}
vLim: 两侧都靠向 {L}：极限存在，等于 {L}。
vNo: 窗口已经很小，两侧仍不靠近同一个数，或窗口内一直大幅变动：这里极限不存在。
vMid: 窗口还偏大，继续把 δ 调小再看。
:::

## ε–δ 博弈：对方给 ε，你找 δ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 ε–δ 博弈
:::

::: html step1-1
:::

这一步要回答：怎样把“无限接近”写成严格的说法？**ε–δ 定义**：说 lim(x→a) f(x) = L，意思是对任意给定的误差 ε &gt; 0，都能找到一个 δ &gt; 0，使得只要 0 &lt; |x − a| &lt; δ，就有 |f(x) − L| &lt; ε。图中橙色横带是 L ± ε（对方的要求），竖直的青色窗口是 a ± δ（你的选择）；窗口内曲线若冲出了横带，那一段画成红色——说明这个 δ 不行。读数会检查整个窗口，并告诉你可行的最大 δ。 {#s1e .explain}

::: html step1-2
s1o: 选 f(x) = 3x + 1，把 ε 设为 0.5：把 δ 从大拉到小，看红色部分消失的临界点（应是 ε/3）；再换成 f(x) = x²、1/x，找出各自的临界 δ；点“帮我找出最大的 δ”核对。
lEps: 对方给的误差 ε
lDelta: 你选的 δ
fLin: f(x) = 3x + 1，x → 2
fSq: f(x) = x²，x → 2
fInv: f(x) = 1/x，x → 1
bBest: 帮我找出最大的 δ
:::

::: strings
r1: 函数 {fn}：L = {L}，ε = {eps}，你的 δ = {d}：窗口内函数值偏离 L 最大 {dev}，{res}；可行的最大 δ ≈ {best}。
ok: 小于 ε，这个 δ 可行
bad: 超过 ε，这个 δ 不行
:::

## δ 要多小？取决于 ε，也取决于位置 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 δ 随 ε 和位置变
:::

::: html step2-1
:::

这一步要回答：δ 和 ε 是什么关系？取 f(x) = x² 在点 a：对每个 ε，最大可行的 δ 是 δ(ε) = √(a² + ε) − a（右侧更严，取两侧中较小者）。ε 越小 δ 越小：当 ε 很小时 δ ≈ ε/(2a)，其中 2a 就是 x² 在 a 处的斜率——斜率越大，同样的误差要求的 δ 越小。左图是 δ 随 ε 变化的曲线，右图是（固定 ε 时）δ 随位置 a 变化的曲线；圆点是当前设置。 {#s2e .explain}

::: html step2-2
s2o: 把 a 从 0.5 拉到 5：同一个 ε 要求的 δ 越来越小（曲线越陡）；固定 a，把 ε 减半，δ 大约也减半——对照读数里 ε/(2a) 的近似值。
lA: 位置 a（函数 f(x) = x²）
:::

::: strings
r2: a = {a}，ε = {eps}：最大可行 δ = {d}（精确公式 √(a²+ε) − a）；近似 ε/(2a) = {ap}；斜率 2a = {sl}。
:::

## 极限不存在：任何 L 都过不了 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 极限不存在
:::

::: html step3-1
:::

这一步要回答：怎样用 ε–δ 说明“极限不存在”？取 ε = 0.5，猜一个极限值 L（滑块），再找 δ：若找不到任何 δ 使窗口内函数值都在 L ± 0.5 内，这个 L 就被否决。跳跃 |x|/x 左右分别是 −1 和 +1，任何 L 至少离其中一侧 ≥ 1，而 0.5 比一半还小，所以无论怎么猜都不行；sin(1/x) 在 0 附近无限振荡，覆盖 −1 到 1，同样不行；1/x² 趋于无穷，没有有限的 L。读数还会把 L 从 −3 到 3 全扫一遍，统计有多少个 L 通过。 {#s3e .explain}

::: html step3-2
s3o: 选“跳跃”函数，拖动猜测的 L 从 −2 到 2：始终得到“找不到 δ”；读数里“通过的 L 个数”应为 0；再换另外两个函数试。
lCand: 猜测的极限值 L
gBlow: f(x) = 1/x²，x → 0
:::

::: strings
r3: 函数 {fn}，ε = 0.5，猜测 L = {L}：{res}；在 L ∈ [−3, 3] 上扫描 {n} 个 L（步长 0.01），其中 {pass} 个能找到 δ。
noDelta: 找不到 δ（窗口再小也有函数值偏离 L 超过 ε）
hasDelta: 可行的最大 δ ≈ {d}
:::

## 数列版：ε–N {#step4 h2=s4t pre=1}

::: strings
nav4: 4 数列版：ε–N
:::

::: html step4-1
:::

这一步要回答：数列的极限是怎么定义的？**数列极限**：说 aₙ → L，意思是对任意 ε &gt; 0，能找到一个 N，使得 n &gt; N 之后**所有**项都满足 |aₙ − L| &lt; ε。图中点是数列的各项，橙色带是 L ± ε（本页对三个数列都取 L = 0）。读数用最前 20000 项找出最后一个落在带外的位置，N 就是它。1/n 到某项之后全部进入带内；(−1)ⁿ/n 在 0 两侧振荡，但幅度缩小，也能进入；(−1)ⁿ 永远在 ±1 来回，ε &lt; 1 时永远有项落在带外，找不到 N。 {#s4e .explain}

::: html step4-2
s4o: 把 ε 从 1 慢慢减小到 0.02：看 1/n 和 (−1)ⁿ/n 需要的 N 变大（大约是 1/ε），而 (−1)ⁿ 在 ε &lt; 1 时没有 N。
sInv: 数列 1/n
sAlt: 数列 (−1)ⁿ/n
sNoLim: 数列 (−1)ⁿ
:::

::: strings
r4: 数列 {sn}，L = 0，ε = {eps}：{res}
nFound: N = {N}：第 {N1} 项起（n &gt; {N}）所有项都在 L ± ε 内（检查到 n = 20000）
nNone: 找不到 N：在前 20000 项里一直有项落到带外
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 极限看的是 x → a 时 f(x) 的趋势，与 f(a) 是否存在无关；② ε–δ：对任意 ε 都能找到 δ，使 0 &lt; |x − a| &lt; δ ⟹ |f(x) − L| &lt; ε；③ δ 随 ε 变小而变小，斜率越大 δ 越小；④ 极限不存在：任何 L 都有某个 ε 找不到 δ（跳跃、振荡、趋于无穷）；⑤ 数列版：n &gt; N 之后所有项都在 L ± ε 内。 {#s5e .explain}

::: html step5-2
qq: 已知对 ε = 0.1，δ = 0.03 可行（0 < |x − a| < 0.03 ⟹ |f(x) − L| < 0.1）。那么对 ε = 0.5，同一个 δ = 0.03：
qo0: 一定不行
qo1: 一定可行
qo2: 不一定，要重新找
s5m: 本页只用有限的采样来检查“窗口内所有点”（每侧 2000 个点），对连续的、性质良好的函数足够，但不是证明；第 3 步“不存在”的结论是对 ε = 0.5 和所给的几个函数，由扫描 L ∈ [−3, 3] 得到的；数列的 N 只检查到 n = 20000；δ 的“最大可行值”用二分法数值求出，与解析公式在第 1、2 步里对照；极限还有单侧极限、无穷极限等推广，本页没有涉及。
lk0: 导数页：割线逼近切线，斜率就是一个极限
lk1: 导数页：每个点都有导数——对每个 x 都要做一次 ε–δ
:::

::: strings
qwhy: 误差要求放宽到 ε = 0.5，窗口内函数值本来就在更窄的 0.1 以内，当然也在 0.5 以内；反过来，对更小的 ε（如 0.01）则不一定可行（第 1 步：把 ε 调小，红色部分会出现）。
:::
