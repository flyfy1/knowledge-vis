极限与 ε–δ · 你说多近，我就能多近

把“无限接近”变成一场有规则的博弈：对方先给出 ε（允许的误差），你要找出 δ（x 离 a 多近就够了）。

“x 越来越靠近 a”时，f(x) 去了哪里？

这一步要回答：极限说的到底是什么？极限只关心 x 靠近 a 时 f(x) 的趋势，不关心 x = a 那一点的函数值（甚至函数在那一点可以没有定义，图上用空心圆表示）。选一个函数，把靠近程度 δ 调小（x = a ± δ，δ = 10^(−k)）：读数列出 x = a − δ 与 x = a + δ 处的函数值、整个窗口内函数值的最大差距。如果两边的值都靠向同一个数 L，就说极限是 L；否则极限不存在。图的纵轴固定显示，窗口越小，曲线越贴近水平线（若有极限）。

依次选四个函数，把 k 从 0.2 慢慢拉到 4：前两个，两侧函数值越来越接近同一个数（极限存在，分别是 2 和 1）；第三个两侧分别停在 −1 和 +1；第四个函数值在 −1 到 1 之间来回振荡，永远不稳定。

ε–δ 博弈：对方给 ε，你找 δ

这一步要回答：怎样把“无限接近”写成严格的说法？ε–δ 定义：说 lim(x→a) f(x) = L，意思是对任意给定的误差 ε > 0，都能找到一个 δ > 0，使得只要 0 < |x − a| < δ，就有 |f(x) − L| < ε。图中橙色横带是 L ± ε（对方的要求），竖直的青色窗口是 a ± δ（你的选择）；窗口内曲线若冲出了横带，那一段画成红色——说明这个 δ 不行。读数会检查整个窗口，并告诉你可行的最大 δ。

选 f(x) = 3x + 1，把 ε 设为 0.5：把 δ 从大拉到小，看红色部分消失的临界点（应是 ε/3）；再换成 f(x) = x²、1/x，找出各自的临界 δ；点“帮我找出最大的 δ”核对。

δ 要多小？取决于 ε，也取决于位置

这一步要回答：δ 和 ε 是什么关系？取 f(x) = x² 在点 a：对每个 ε，最大可行的 δ 是 δ(ε) = √(a² + ε) − a（右侧更严，取两侧中较小者）。ε 越小 δ 越小：当 ε 很小时 δ ≈ ε/(2a)，其中 2a 就是 x² 在 a 处的斜率——斜率越大，同样的误差要求的 δ 越小。左图是 δ 随 ε 变化的曲线，右图是（固定 ε 时）δ 随位置 a 变化的曲线；圆点是当前设置。

把 a 从 0.5 拉到 5：同一个 ε 要求的 δ 越来越小（曲线越陡）；固定 a，把 ε 减半，δ 大约也减半——对照读数里 ε/(2a) 的近似值。

极限不存在：任何 L 都过不了

这一步要回答：怎样用 ε–δ 说明“极限不存在”？取 ε = 0.5，猜一个极限值 L（滑块），再找 δ：若找不到任何 δ 使窗口内函数值都在 L ± 0.5 内，这个 L 就被否决。跳跃 |x|/x 左右分别是 −1 和 +1，任何 L 至少离其中一侧 ≥ 1，而 0.5 比一半还小，所以无论怎么猜都不行；sin(1/x) 在 0 附近无限振荡，覆盖 −1 到 1，同样不行；1/x² 趋于无穷，没有有限的 L。读数还会把 L 从 −3 到 3 全扫一遍，统计有多少个 L 通过。

选“跳跃”函数，拖动猜测的 L 从 −2 到 2：始终得到“找不到 δ”；读数里“通过的 L 个数”应为 0；再换另外两个函数试。

数列版：ε–N

这一步要回答：数列的极限是怎么定义的？数列极限：说 aₙ → L，意思是对任意 ε > 0，能找到一个 N，使得 n > N 之后所有项都满足 |aₙ − L| < ε。图中点是数列的各项，橙色带是 L ± ε（本页对三个数列都取 L = 0）。读数用最前 20000 项找出最后一个落在带外的位置，N 就是它。1/n 到某项之后全部进入带内；(−1)ⁿ/n 在 0 两侧振荡，但幅度缩小，也能进入；(−1)ⁿ 永远在 ±1 来回，ε < 1 时永远有项落在带外，找不到 N。

把 ε 从 1 慢慢减小到 0.02：看 1/n 和 (−1)ⁿ/n 需要的 N 变大（大约是 1/ε），而 (−1)ⁿ 在 ε &lt; 1 时没有 N。

回顾与自测

回顾：① 极限看的是 x → a 时 f(x) 的趋势，与 f(a) 是否存在无关；② ε–δ：对任意 ε 都能找到 δ，使 0 < |x − a| < δ ⟹ |f(x) − L| < ε；③ δ 随 ε 变小而变小，斜率越大 δ 越小；④ 极限不存在：任何 L 都有某个 ε 找不到 δ（跳跃、振荡、趋于无穷）；⑤ 数列版：n > N 之后所有项都在 L ± ε 内。
