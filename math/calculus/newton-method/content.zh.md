这一步要回答：怎样用一条切线，从一个猜测点出发找到更接近零点的位置？**根**是使 f(x) = 0 的 x（曲线与横轴的交点）。这里 f(x) = x² − 2，根是 √2 ≈ 1.41421。在起点 x₀ 处作[[derivative#step1|切线]]（斜率就是导数 f′(x₀)），切线与横轴的交点记为 x₁ = x₀ − f(x₀)/f′(x₀)。**观察：**拖动起点 x₀，橙色是切线与垂线，绿点是 x₁，紫点是真正的根；看 x₁ 是否总比 x₀ 更靠近紫点。这个滑杆改的是猜测起点，不改函数。 {#s0e .explain}

这一步要回答：一刀不够时，重复切下去会怎样？**迭代**就是把输出当作下一次的输入：xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ)。点「走一步」逐刀观察，或点「连续走」自动执行（最多 12 步，可暂停）。灰色是以前的切线，橙色是最新一刀。**误差**指当前 xₙ 与真根的距离，「正确位数」≈ −log₁₀(误差)。可以换成别的函数试试，换函数或改起点会清空迭代记录。 {#s1e .explain}

## 每走一步，正确位数大约翻一倍 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 位数翻倍
:::

::: html step2-1

这一步要回答：牛顿法比「每次砍一半」的二分法快多少？橙柱是牛顿法走 k 步后正确的位数，紫柱是在区间 [1, 2] 上做 k 次二分后正确的位数（每次大约只多 0.3 位）。起点离根不太远时，牛顿法的误差满足 eₙ₊₁ ≈ C·eₙ²，平方使位数翻倍；最多画到 15 位，因为浮点数只有约 16 位有效数字。**观察：**改起点 x₀，看橙柱是否仍然在几步内冲到顶；起点离根越远，前几步越慢。 {#s2e .explain}

## 切线并不总是带你回家 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 失败的时候
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 会失灵
:::

这一步要回答：什么时候牛顿法会走丢？函数 f(x) = x³ − 2x + 2 只有一个实根（约 −1.77）。**切线水平**（f′ = 0）时切线不与横轴相交，无法迈出下一步；**循环**指迭代在几个点之间来回跳；**走丢**指没有在 60 步内到达根。试试预设：x₀ = 0 会在 0 与 1 之间永远来回；x₀ = 0.8165 附近切线几乎水平，一步就被抛得很远。红色是前几刀。**观察：**读数里的路径比较起点在哪一类。 {#s3e .explain}

## 三个根，起点落在哪个“盆地”就去哪 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 起点决定去向

::: html step4-1

这一步要回答：有多个根时，起点怎样决定牛顿法最后走向哪个根？f(x) = x³ − x 有三个根 −1、0、1。下方彩条把每个起点按它最终到达的根染色（紫 → −1，橙 → 0，青 → 1，灰 = 没有到达），白线是当前起点。同一种颜色连成的一段叫**吸引盆地**。**观察：**点预设或拖动，看在 ±0.577（切线水平处）附近颜色如何一段一段交错：起点稍稍移动，终点就可能完全不同。 {#s4e .explain}

## 开平方：牛顿法 vs 二分法 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 对比二分法
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 用一道计算题收口
:::

这一步要回答：同样算 √a，牛顿法比[[binary-search#step1|二分]]快在哪里？求 √a 就是解 f(x) = x² − a = 0，牛顿一步是 x → (x + a/x)/2。橙线是牛顿法的误差，紫线是在 [0, a] 上二分的误差（纵轴为对数，每下降一格是十分之一）；绿虚线是 10⁻¹⁰ 的容差线。**观察：**拖动 a，看橙线几步就穿过绿线，紫线要走几十步；读数给出各自需要的步数。 {#s5e .explain}
