## 次数越高一定越准吗？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 误差与收敛半径
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 收敛的边界
:::

这一步要回答：加更多项总是变好吗？纵轴是误差（对数刻度），横轴是 x。对 sin x，随着 n 增大，各处误差都下降。但 1/(1−x) 和 ln(1+x) 在 |x| &lt; 1 内越来越准，到了 |x| &gt; 1，加更多项反而误差越大：这就是**收敛半径**，这里为 1（红色虚线）——原因是函数在 x = ±1 附近有“奇点”（1/(1−x) 在 x = 1 无定义，ln(1+x) 在 x = −1 无定义），多项式无法越过它们。**观察：**切换函数，拖动 n：红线内误差逐渐降低，红线外误差随 n 增大。 {#s2e .explain}

## 多项式的每一项怎样由函数本身决定？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 系数从导数来
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 系数从哪来
:::

这一步要回答：系数 cₖ 是怎么定出来的？要让多项式在中心处与函数“长得一样”，函数值、斜率（一阶导数）、弯曲程度（二阶导数）……都要一致，于是 **cₖ = f⁽ᵏ⁾(0)/k!**（f⁽ᵏ⁾ 表示 k 阶[[derivative#step3|导数]]，k! 是 1×2×…×k）。柱高就是各项系数（青 = 正、红 = 负），亮色是已用到的项（次数 ≤ n）。**观察：**sin x 的系数只有奇次项且正负交替（1, −1/6, 1/120, …）；eˣ 的系数全是 1/k!；ln(1+x) 的系数是 ±1/k，衰减很慢——这也是它收敛慢的原因。 {#s3e .explain}

这一步要回答：用泰勒级数实际算一个数，需要多少项？eˣ 的级数 1 + x + x²/2! + x³/3! + …，柱高是各项的绝对值，绿虚线之后的项都很小，累加到该处误差已小于 5×10⁻⁷（约六位小数）。**观察：**拖动 x：x 越大，需要的项越多（x = 3 时要 16 项左右，x = 0.5 时只要 7 项）。读数里还有小角度近似：sin x ≈ x 在 x = 0.5 处只差 0.0206，对 x 更小时差得更少——这就是物理里常用的“小角近似”。 {#s4e .explain}

## 泰勒（局部）和傅里叶（整体）有什么不同？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 泰勒 vs 傅里叶
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 两种逼近的哲学
:::

这一步要回答：同一个函数，泰勒逼近和[[fourier#step0|傅里叶]]逼近有什么区别？取函数 g(x) = 1/(1 + x²)，它在整个数轴上光滑，但泰勒级数的收敛半径只有 1（奇点在 x = ±i，在实轴上看不见）。橙线是 n 次泰勒多项式：在 |x| &lt; 1 内越来越准，到 |x| &gt; 1 就发散；绿虚线是在 [−π, π] 上的余弦傅里叶部分和：用的是“整段区间上的平均贴合”，因此在整个区间内都变好，而不挑一个点。**观察：**增加 n，看橙线在 |x| = 1 外越来越离谱；增加傅里叶项数，看绿线在整个 [−π, π] 内都贴近青线。泰勒需要在一点的高阶导数，傅里叶需要在整段上的积分。 {#s5e .explain}

::: html step5-2
s5cv: 青：g(x) = 1/(1+x²)；橙：泰勒多项式（中心 0）；绿虚线：傅里叶余弦部分和（区间 [−π, π]）
ngL: 泰勒次数 n（偶数）
nfL: 傅里叶项数 N
recapTitle: 回顾
recap1: 泰勒：在中心 a 附近用 Σ f⁽ᵏ⁾(a)/k!·(x−a)ᵏ 逼近函数，次数越高在中心附近越贴；系数来自各阶导数。
recap2: 收敛有边界：1/(1−x)、ln(1+x) 的收敛半径是 1，超出后加项反而越差；sin、cos、eˣ 处处收敛。
recap3: 泰勒是在一点的局部逼近，傅里叶是在整段区间的整体逼近；小角近似 sin x ≈ x 是 1 次泰勒多项式。
modelTitle: 模型范围与局限
modelText: 模型范围：一元实函数，在实数轴上绘图；系数用解析公式给出；傅里叶部分是 1/(1+x²) 在 [−π, π] 的余弦级数，系数用数值积分（辛普森法）求出，只用到 12 项；误差读数是双精度计算的结果，当误差小于约 10⁻¹⁵ 时被舍入噪声主导；“收敛半径”只对 1/(1−x) 与 ln(1+x) 直接演示，没有展开复变函数的解释。
