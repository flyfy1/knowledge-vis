## 猎物多了捕食者多，捕食者多了猎物少 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 此消彼长
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 两个种群
:::

这一步要回答：两个互相牵制的种群，数量随时间怎么变？设猎物（青）数量为 x，捕食者（橙）数量为 y。**洛特卡–沃尔泰拉模型**：猎物自己按比例增长 a·x，被捕食者吃掉 b·x·y；捕食者靠吃猎物增长 d·x·y，自己按比例死亡 c·y。其中 x′、y′ 表示每单位时间的变化率（见[[derivative#step3|导数]]）。取 a = 1、b = 0.5、c = 0.75、d = 0.25。**观察：**改两个起点，点「重放」：两条曲线周期性起落，捕食者的峰总是落后于猎物的峰。滑杆改的是初始数量，不改规则。 {#s0e .explain}

## 哪里猎物不变？哪里捕食者不变？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 零线与平衡点
:::

::: html step2-1

s2k: 零线与平衡点
:::

这一步要回答：为什么是绕着那个点转？**零线**是某个变化率恰为 0 的位置：猎物不变要求 y = a/b = 2（青虚线）或 x = 0；捕食者不变要求 x = c/d = 3（橙虚线）或 y = 0。两条线的交点是**平衡点** (3, 2)：在那里两个种群都不变。零线把平面分成四块，每块里“猎物升/降、捕食者升/降”的组合固定，方向场因此绕圈。**观察：**拖动探测点，白色箭头是该处的 (x′, y′) 方向（长度只示意大小）；穿过虚线时，对应分量改变正负号。 {#s2e .explain}

## 为什么轨线是闭圈？有个量一直不变 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 守恒量与数值误差
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 守恒量
:::

这一步要回答：这个模型里有什么东西沿轨线始终不变？量 H = d·x − c·ln x + b·y − a·ln y 沿真实轨线恒定，因此轨线只能留在 H 的某条等值线上，也就闭成圈。下图下半部分画 H 随时间的变化；用 **RK4**（每步参考斜率取四次，精度高）时它几乎是一条水平线，用最简单的 **欧拉法**（每步只取当前斜率）时 H 会不断漂移，轨线螺旋向外——这不是生态学，是数值误差。**观察：**切换方法并调大步长 Δt，看 H 的漂移幅度。 {#s3e .explain}

这一步要回答：规则的哪些数字决定平衡点在哪？平衡点是 (c/d, a/b)：猎物的平衡值只看捕食者的“死亡率 c”与“转化率 d”，捕食者的平衡值只看猎物增长率 a 与“被吃率 b”。这有点反直觉：增加猎物增长率 a，抬高的是**捕食者**的平衡值。**观察：**拖动 a 和 c，看绿点移到哪里；三个彩色圈（起点在平衡点正下方）总是围着它转。 {#s4e .explain}

## 给猎物加“拥挤”，圈就变成螺旋 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 加上拥挤
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 更真实一点
:::

这一步要回答：如果猎物自己也会因拥挤而增长变慢，故事会怎样改写？把猎物增长改为 a·x·(1 − ε·x)，其中 ε 越大拥挤越强（容纳量 K = 1/ε，见[[logistic-growth#step2|容纳量 K]]）。**观察：**ε = 0 是前面的闭圈；ε &gt; 0 时轨线不再回到原来的圈，而是螺旋收向平衡点 (3, 2(1 − 3ε))；ε 越大收得越快。起点固定在 (6, 1)，读数给出起点与终点到平衡点的距离。控件改的是模型规则，不是显示方式。 {#s5e .explain}

::: html step5-2
s5cv: 带拥挤项的相平面：轨线螺旋收向平衡点
eL: 拥挤强度 ε

recap1: 洛特卡–沃尔泰拉：x′ = a·x − b·x·y，y′ = −c·y + d·x·y；平衡点 (c/d, a/b)；相平面上每条轨线是一种命运，圈越大振幅越大。
recap2: 时间曲线和相平面是同一个解的两种画法；H = d·x − c·ln x + b·y − a·ln y 沿轨线守恒，所以是闭圈；欧拉法会让 H 漂移。
recap3: 加上拥挤项后圈变成向平衡点收敛的螺旋：模型规则变了，相图就变。
