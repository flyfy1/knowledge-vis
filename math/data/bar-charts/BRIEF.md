# BRIEF：条形图（bar-charts）· 小学数学
- category `math`，stage `primary`（已注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页：cell-structure（头部/骨架），脚手架由本批共用生成脚本产出。可见标识：页脚双语署名；provenance 规范对 Claude 版无明确要求，已在此记录。
- 核心：柱高=数值；读差；纵轴起点改变视觉差距；平均线=高出与不足互相抵消；新数据拉动平均数。

## 步骤（五必填项）
0. 数变成柱。已知：数与长度；问题：柱高表示什么？输入某同学身高；观察：只有该柱变化（橙色）；适用：8 个示意数据。
1. 比高矮。已知第 0 步；问题：两柱相差多少？输入同学 A、B；观察：虚线拉平+括号标差，最高绿、最矮紫；适用：同一纵轴起点。
2. 轴从哪起。已知读差；问题：纵轴起点改变了什么？输入基线；观察：最高/最矮柱长之比远大于真实身高比，基线≥最矮值时柱被切没；适用：条形图以长度编码，截断轴会夸大差距。
3. 平均线。已知差与长度；问题：哪条线补平高出与不足？输入横线高度；观察：橙（高出）与紫（不足）面积并列，总和相等时即平均数 143.25（默认数据）；适用：任何数列，平均数不必是数据之一。
4. 多一个人。已知平均数；问题：新增数据后平均数变多少？输入新同学身高；观察：灰虚线（原）、绿实线（新），变化 = (x−原平均)/9；适用：加一个值。
5. 终章。输入自己的 2–12 个正数；画图并算平均/最大/最小；深链：probability-distribution#step1、clt#step0、coordinate-plane#step1（均已核对存在）。

## 新术语首现表
柱高/厘米（步 0 就近说明）；差（步 1）；纵轴起点/基线（步 2 定义）；高出/不足（步 3）；平均数（步 3：全部相加除以个数）；原平均/新平均（步 4）。

## 模拟设定 / 模型失配
数据为示意身高，非真实调查；读数全部由函数运行时计算。平均数不反映分散程度，也可能不等于任何一个数据；步 0 改动的数据会同步到后续各步（有意设计）。
