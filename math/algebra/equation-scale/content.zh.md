## 一盒不知道多重的东西 {#step0 h2=s0t}

::: strings
nav0: 0 认识天平
:::

第 0 步 · 认识天平 {#s0k .step-kicker i18n=text}

这一步要回答：**一盒密封的东西（不许打开）到底多重，不用电子秤、只用天平和砝码能不能称出来？**先认部件：天平有**左盘、右盘**，中间是**横梁**和**中央指针**——指针正对中线、横梁水平，就叫**平衡**（两边一样重）。右盘里的小块叫**砝码**，本页最小的一块记 1 个**单位**（不用克、千克）。盒子的重量暂时不知道、但确定有——数学里把这种量叫**未知数**，先用字母 **x** 占位。 {#s0e .explain}

::: html step0-1
:::

横梁倾斜的角度是示意，画得夸张了；判断平不平，只看两边重量是否相等。 {#tiltNote .note .tiltnote i18n=text}

::: html step0-2
s0add: ＋ 放一个砝码
s0remove: － 取走一个砝码
s0swap: 换一盒（重新称）
:::

结论：一盒东西的重量是**确定的**，没称出来不等于没有——这正是未知数 x 的意思。先说清本页的设定：这是一架**理想天平**（横梁无摩擦、指针零误差）；真实天平有灵敏度极限，两边只差一点点时未必看得出倾斜，本页按「差 1 个单位就不平」处理，是教学简化。本页砝码和盒重都是整数个单位。 {#s0hint .hint}

::: html step0-3
start: 开始探索 ↓
:::

## 天平已经平了，怎么放它才不倒 {#step1 h2=s1t}

::: strings
nav1: 1 两边同加同减
:::

第 1 步 · 两边同加同减 {#s1k .step-kicker i18n=text}

这一步要回答：**天平已经平衡，我再往盘子里放东西（或取东西），怎么操作它才不倒？**带等号、左右两边相等的式子叫**等式**——等号就是天平指针归零的那一刻。图里左盘是 1 个盒子 + 2 个单位，右盘 8 个单位（盒子在第 0 步称过，是 6 个单位，所以 6 + 2 = 8，两边一样重）。试四个操作钮，注意看：每次操作之后读数只报**组成**（几个盒子、几个单位），不报总重量——先把「看组成」的习惯练出来。 {#s1e .explain}

::: html step1-1
s1addU: 两边各加 1 个单位
s1addB: 两边各加 1 个盒子
s1subU: 两边各取走 1 个单位
s1one: 只给左盘加 1 个单位（只加左边试试）
s1reset: 回到初始平衡
:::

结论：对天平两边同时加上（或取走）**同样多**的东西，平衡不变；只动一边，平衡就破坏。这一招有个总称：**对两边同做一件事**——同加同减是它的第一种。注意读数旁那句：倾斜角度是示意，是否平衡只看两边重量是否相等。 {#s1hint .hint}

::: strings
s1ckAdd: 试过「两边同加」
s1ckSub: 试过「两边同减」
s1ckOne: 试过「只加一边」，看见它倒
s1lastAddU: 刚才：两边各加了 1 个单位。
s1lastAddB: 刚才：两边各加了 1 个盒子。
s1lastSubU: 刚才：两边各取走了 1 个单位。
s1lastOne: 刚才：只给左盘加了 1 个单位 —— 只动一边，平衡就没了。点「回到初始平衡」再试别的。
s1whySub: 取不了：两边各取走 1 个单位要求两边都有单位可取（左盘 {lb} 个、右盘 {rb} 个），有一边不够。
:::

## 把两边一起放大、一起缩小 {#step2 h2=s2t}

::: strings
nav2: 2 两边同乘同除
:::

第 2 步 · 两边同乘同除 {#s2k .step-kicker i18n=text}

这一步要回答：**把两盘的东西同时翻倍，或者同时只留一份，天平还平吗？**乘法就是连加、除法就是平分（以前学过）。图里是 x + 1 = 4（这个盒子重 3 个单位）。点「两边同时 ×2」，看两盘的东西当场复制一份；再点「两边同时 ÷k」——把每盘分成 k 等份（**整除**：分完没有剩余、不出现半块），只留一份。同样留了一个「只乘左边」的反例钮。 {#s2e .explain}

::: html step2-1
s2mul2: 两边同时 ×2
s2mul3: 两边同时 ×3
s2divLab: 两边同时除以：
s2one: 只乘左边 ×2（只乘一边试试）
s2reset: 回到初始平衡
:::

结论：两边同时乘以同一个**非零**数、或同时除以一个**能整除**的数，平衡不变。两个条件缺一不可：乘 0 会把两边都变成 0、信息全抹掉，本页不提供 ×0；除不尽的本页不做，我们不切半个砝码。 {#s2hint .hint}

::: strings
s2ckMul: 试过「两边同乘」
s2ckDiv: 试过「两边同除」
s2ckOne: 试过「只乘一边」，看见它倒
s2lastMul: 刚才：两边同时 ×{k} —— 两盘的东西都复制成了 {k} 份。
s2lastDiv: 刚才：两边同时 ÷{k} —— 每盘分成 {k} 等份，只留一份。
s2lastOne: 刚才：只把左边 ×2 —— 只动一边，平衡就没了。点「回到初始平衡」再试别的。
s2noDiv: 现在两边没办法再同时整除：两边的盒子数、单位数没有大于 1 的公约数了。
s2cap: 这个操作暂时停用：做完会超过画布上限（盒子最多 6 个、单位最多 24 个）。
:::

## 把 x 单独留在左边 {#step3 h2=s3t}

::: strings
nav3: 3 一步方程
:::

第 3 步 · 一步方程 {#s3k .step-kicker i18n=text}

这一步要回答：**x + 3 = 7 —— 怎么操作，才能让左盘只剩下盒子一个、把 x 逼出来？**把 x 单独逼出来的过程叫**解方程**，逼出来的那个数叫方程的**解**。工具还是那一招：用下面的操作钮对两边同做一件事（平衡＝两边一样重，不会倒）。走错路也没关系，天平照样平，只是还没到目标，随时能调整或重置。 {#s3e .explain}

::: html step3-1
:::

目标：让左盘只剩下 1 个盒子（x 单独在一边）。 {#goalLine .readout .goal i18n=text}

::: html step3-2
histTitle: 操作轨迹（你做过的每一步）
:::

## 用两次，先哪件后哪件自己定 {#step4 h2=s4t}

::: strings
nav4: 4 两步方程
:::

第 4 步 · 两步方程 {#s4k .step-kicker i18n=text}

这一步要回答：**盒子有好几个、还混着砝码（2x + 3 = 11），一次操作不够，该先做哪件、后做哪件？**盒子前面的个数叫**系数**（2x 的 2 就是系数，意思是 2 个盒子）。答案是：顺序自己定——先同减再同除、先同除再同减，两条路都通，页面只认最终把 x 单独留在一边。操作轨迹会逐条记下，让你看得见自己走了哪条路。 {#s4e .explain}

::: html step4-1
s4next: 换一题
:::

结论：两步方程就是把「两边同做一件事」用两次。本页的题只用正的常数和正的答案；答案是负数的方程（如 x + 9 = 4）里，带负号的数怎么加减在<a class="fourier-link" href="../../arithmetic/negative-numbers/#step3">负数那一页（沿数轴走）</a>；系数是分数的方程（如 ½x = 3）里，½ 不是两个数、是一个数，看<a class="fourier-link" href="../../arithmetic/fractions/#step1">分数那一页（分数也是一个数）</a>——解法仍然是两边同做一件事。 {#s4hint .hint}
