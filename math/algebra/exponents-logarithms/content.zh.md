## 翻倍的世界：差在「乘」，不在「加」 {#step0 h2=s0t}

::: strings
nav0: 0 翻倍的世界
:::

第 0 步 · 翻倍的世界 {#s0k .step-kicker i18n=text}

这一步要回答：**不是每次加一点、而是每次乘一个倍数的增长，长什么样？**一个细菌每小时翻一倍（×2）：1 个变 2 个、2 个变 4 个……图上青线是它，橙线是另一种活法：从 1 开始每小时 +2（1、3、5、7……）。同一张图、同一把尺子，播放或拖动探针，把两列数一路比到 10 小时。先把开头的问题摆明：**从 1 个细菌开始，每小时翻一倍，24 小时后会有多少个？**走完这一步，就能把这个数算完。 {#s0e .explain}

::: html step0-1
s0play: 播放 ▶
s0tLab: 时刻探针 t（小时）
:::

把数表读出声就是规律：<b>翻倍列每过 1 小时，数量 ×2；直线列每过 1 小时，数量 +2</b>。起步时两列咬得很紧，越往后翻倍列甩得越开——因为「乘」会把已经变大的数继续放大，而「加」每次只添同样多。这种「加上同样的时间、乘上同样的倍数」的增长，就叫**指数增长**（「指数」就是右上角那个小小的 t：它数的是乘了几次）。 {#s0conc .readout}

顺带把开头的问题算完：24 小时是 2<sup>24</sup> = 16,777,216 个——从 1 个细菌开始，一天就是一千六百多万。这不是细菌特别能生，是「翻倍」这种增长方式本身就这么猛。 {#s0hint .hint}

## 底数说了算：y = aˣ 的全家福 {#step1 h2=s1t}

::: strings
nav1: 1 底数说了算
:::

第 1 步 · 指数函数与底数 {#s1k .step-kicker i18n=text}

这一步要回答：**倍数不是 2、时间不是整数时，曲线长什么样？**把翻倍推广：底数（base，就是被反复乘的那个倍数 a）可以换，指数 x 可以是 0.5 这样的小数。拖动底数滑杆从 0.3 拖到 3，特别留意拖过 1 的那一刻；再拖曲线上的探针，读一读任意点的 a<sup>x</sup>——每个数都由 Math.pow 当场算出。 {#s1e .explain}

::: html step1-1
s1aLab: 底数 a（被反复乘的倍数）
s1xLab: 探针点的 x（可拖曲线上的点）
:::

不管 a 取多少，所有 a<sup>x</sup> 都**过 (0, 1)**（a<sup>0</sup> = 1，图上的橙点纹丝不动），而且**永远为正**——曲线贴着 x 轴但碰不到它。结论：形如 <b>y = a<sup>x</sup>（a &gt; 0、a ≠ 1）</b>的函数叫**指数函数**；底数 a 一个数就决定了它涨还是跌、涨得多陡。 {#s1conc .readout}

操作顺序建议：先把 a 停在 2 看探针读数（2<sup>0.5</sup> ≈ 1.414 这种非整数指数也有确定值）；再把 a 缓缓拖过 1——注意结论句会从「上升」翻成「平线」再翻成「下降」，图和话必须同步翻面。 {#s1hint .hint}

::: strings
s1roGrow: a = <span>{a}</span> &gt; 1：曲线<b>上升</b>——x 每增加 1，y 就乘上一个 {a}；a 越大爬得越陡。这就是第 0 步翻倍的一般形。
s1roFlat: a = <span>1</span>：y = 1<sup>x</sup> = <b>1</b>，恒为 1——不涨也不跌，是一条平线。所以指数函数的定义要把 a = 1 除外，它不配叫「增长」也不配叫「衰减」。
s1roDecay: 0 &lt; a = <span>{a}</span> &lt; 1：曲线<b>下降</b>——x 每增加 1，y 就乘上一个小于 1 的倍数，越乘越小。这正是衰减的样子：一杯药在体内的含量、一块放射性材料的质量，都是每过一段固定时间就乘上一个固定的小于 1 的倍数（减半只是其中 a 随时间标度取到 0.5 的特例，这里不展开）。
s1probe: 探针 x = {x}：{a}<sup>{x}</sup> = <b>{v}</b>（Math.pow 实算）。
cOrigin: (0, 1)
cOff: ↑ 图外
:::

把问答排成表：左边是问句，右边就是对数的写法 {#s2qaT .stage-title i18n=text}

::: html step2-2

揭晓记号：把「a 的几次方等于 b」的答案记作 <b>log<sub>a</sub>b</b>，读作「以 a 为底、b 的对数」——它问的就是「a 的几次方等于 b」。其中 a 是**底数**（还是第 1 步那个倍数），b 叫**真数**，就是被问的那个结果数。成立条件写在明处：**a &gt; 0、a ≠ 1、b &gt; 0**——真数必须为正，因为 a 的任何次幂都大于 0（曲线永远在 x 轴上方），所以 0 和负数根本问不出对数。 {#s2conc .readout}

试一试目标 0.5（底数 2）：交点跑到 y 轴左边，x = −1——真数小于 1 时，对数是负数。自测第 1 题就从这里来。 {#s2hint .hint}

## 三把尺子：对数把乘法翻译成加法 {#step3 h2=s3t}

::: strings
nav3: 3 三把尺子
:::

第 3 步 · 对数的运算律 {#s3k .step-kicker i18n=text}

这一步要回答：**对数凭什么能「把大数算小」？**下面是一台实测台，图上是 y = 2<sup>x</sup> 与四个点。逐把尺子点过去，每条运算律都当场用 Math.log 算给你看、三栏对账——律不是背出来的，是量出来的（证明不在这一页展开，这点明说）。 {#s3e .explain}

::: html step3-1
s3r1: 尺子一 · 乘变加
s3r2: 尺子二 · 幂变乘
s3r3: 尺子三 · 换把尺子量
:::

三条律合起来就是一句话：**对数把乘法世界翻译回加法世界**——乘变加、幂变乘。原来要算的乘法越大，这份翻译越值钱。 {#s3conc .readout}

历史上这份翻译真救过命：没有计算器的年代，天文学家和航海家靠对数表把费劲的大数乘法变成查表加法，这把「计算尺」用了三百年。顺带认识一个记号：底数取 10 的对数叫**常用对数**，记作 lg——第 2 步的 log₁₀1000 = 3，也就是 lg 1000 = 3。 {#s3hint .hint}

::: strings
s3ro1: 乘变加：log₂8 = <b>{l8}</b>，log₂4 = <b>{l4}</b>；真数相乘 8 × 4 = 32，log₂32 = <b>{l32}</b>。对账：{l8} + {l4} = <b>{l32}</b> ✓——<b>真数相乘，对数相加</b>：log<sub>a</sub>(M×N) = log<sub>a</sub>M + log<sub>a</sub>N。
s3ro2: 幂变乘：4³ = <b>64</b>，log₂64 = <b>{l64}</b>；另一边 3 × log₂4 = 3 × {l4} = <b>{p}</b>。对账：两边都是 <b>{l64}</b> ✓——<b>真数乘方，对数乘倍数</b>：log<sub>a</sub>(M<sup>k</sup>) = k × log<sub>a</sub>M。
s3ro3: 换把尺子：同一个数 32，用底数 2 这把尺子量，log₂32 = <b>{a}</b>；换底数 10 这把尺子量，log₁₀32 = <b>{b}</b>。数还是那个数，尺子不同、读数不同——两把尺子之间可以互相换算（这一页只展示这一例，换算公式不展开）。
:::

三道题的共同点：先把每个对数翻译回「几次方」的问句，再动手。翻译不出来时，回到第 2 步的图上拖一拖，答案就在交点的横坐标里。 {#s4hint .hint}

::: strings
q1ok: ✓ 对了：2<sup>−3</sup> = 1/2³ = <b>1/8</b>，所以 log₂(1/8) = <b>−3</b>。真数小于 1，对数就是负数——这和第 2 步把目标拖到 0.5 时看到的是同一件事。
q1no: ✗ 还不对。提示：2 的正数次幂都大于 1，到不了 1/8；试试负指数：2<sup>−3</sup> = 1/2³，是多少？
q2ok: ✓ 对：3⁴ = 81，所以 t = log₃81 = <b>4</b> 小时。指数问「乘出来是几」，对数问「乘了几次」——同一件事的正问和反问。
q2no: ✗ 再数一遍 3 的幂：3¹ = 3，3² = 9，3³ = 27，3⁴ = ……81 是第几个？
q3ok: ✓ 判断正确，这句话是<b>错的</b>：log₂8 = 3、log₂32 = 5，两者的差是 5 − 3 = <b>2</b>。24 是真数之差（32 − 8），不是对数之差。对数之差 2 对应的是倍数关系：32 = 8 × 4，而 4 = 2²——差 2 说的正是「多乘了两次 2」。
q3no: ✗ 这句话其实是错的。24 是 32 − 8，那是真数相减；对数要先各自算出来再减：log₂8 = 3，log₂32 = 5，3 和 5 的差是多少？

## 乘出来是指数，问回去是对数 {#step5 h2=s5t}

::: strings

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

指数和对数不是两个知识点，是同一个问题的正反两面。收口三张卡： {#s5e .explain}

::: html step5-1
c1h: 乘出来，是指数
c1: 指数函数 y = a<sup>x</sup> 回答「乘出来是几」：给定底数（每步的倍数）和指数（乘了几次），算出结果。它刻画的是「加上同样的时间、乘上同样的倍数」的增长——起步慢，后程猛。
c2h: 问回去，是对数
c2: 对数 log<sub>a</sub>b 回答「乘了几次」：给定底数和结果（真数），问回指数。它不是一种新运算，只是把指数的问句倒过来写的一个记号——写不尽的答案（如 log₂6）靠它才有准确的名字。
c3h: 对数把乘变加
c3: 在对数的世界里：真数相乘 → 对数相加；真数乘方 → 对数乘倍数。这就是它能把大数算小、把乘法变加法的原因，也是它当了三百年计算工具的原因。
s5fin: 这套「乘与问」到处都是：**复利**是钱按倍数生长（指数）；**分贝**和**里氏震级**是把跨度极大的量压进小小的刻度（对数）。认出「每次乘同一个倍数」，就认出了指数；要问「乘了多少次才到这么大」，问的正是对数。
s5eLine: 还有一位特殊的底数先埋在这里：e ≈ 2.71828……。函数 y = e<sup>x</sup> 有个惊人的性质——它在每一点的导数，恰好等于它在那一点的函数值自身。这条线日后讲导数时再回收。
s5lkLin: 回头对照：一次函数的斜率——「加等量、涨等量」的世界，和这一页的「乘倍数」正好是一对 →
:::
