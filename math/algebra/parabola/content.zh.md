## 投篮：把球每 0.1 秒的位置连起来 {#step0 h2=s0t}

::: strings
nav0: 0 投篮
:::

第 0 步 · 投篮 {#s0k .step-kicker i18n=text}

这一步要回答：球投出去以后，每 0.1 秒它在哪里？把这些位置一个一个落成点、再连起来，是什么形状？先按下「投篮」，看点列落下：横轴是时间（秒），纵轴是高度（米）。落完后可以切换横轴口径，把横轴换成水平距离，再看同一批点。 {#s0e .explain}

::: html step0-1
s0play: 投篮 ▶
s0modeT: 横轴：时间
s0modeD: 横轴：水平距离
:::

两种横轴画的是同一次投篮：球的水平速度不变，水平距离和时间成正比。横轴换成距离，点列横着拉长——还是同一次投篮的弧线、仍是一条抛物线，但图被横向拉宽，看起来就比时间口径时胖（横向拉伸相当于把式子里的 a 换了一个数，这正是第 1 步要讲的）；顶点高度、每个点对应投篮的哪一刻，这些事实都没变。看点列的顺序：**先看落点一个个出现（现象），再看它们连成的形状**。 {#s0hint .hint}

## y = ax²：a 管开口方向和胖瘦 {#step1 h2=s1t}

::: strings
nav1: 1 a 管胖瘦
:::

第 1 步 · a 管胖瘦 {#s1k .step-kicker i18n=text}

这一步要回答：最简单的抛物线 y = ax² 里，把 a 改一改，弧线会怎么变？拖滑杆换 a，看实线和虚线原型 y = x² 的对比——胖了还是瘦了、开口朝上还是朝下。顶点先钉在原点不动。 {#s1e .explain}

::: html step1-1
s1aLab: a 的取值（顶点固定在原点）
s1eqPre: 当前方程
s1zeroBtn: a = 0 会怎样？
:::

形如 y = ax²（a ≠ 0）这样、最高次是 2 次的函数，叫<b>二次函数</b>（quadratic function）；它的图象就是一条抛物线。 {#s1conc .readout}

规律收口：a 的<b>符号</b>定开口方向（正向上、负向下），<b>|a|</b> 定胖瘦（|a| 越大越瘦、越小越胖）。判断胖瘦永远拿虚线原型 y = x² 当尺子比。 {#s1hint .hint}

::: strings
s1zeroBack: 回到 a ≠ 0
s1roThin: a = {a}（比 1 大）：开口向上，比原型<b>瘦</b>——同样的 x，y 是原型的 {a} 倍，窜得更快。
s1roFat: a = {a}（在 0 和 1 之间）：开口向上，比原型<b>胖</b>——同样的 x，y 只有原型的 {a} 倍，涨得慢。
s1roOne: a = 1：这就是原型 y = x² 本人，虚线和实线完全重合。
s1roNegThin: a = {a}（比 −1 还小）：开口翻到<b>向下</b>；胖瘦看 |a| = {abs}（比 1 大），比原型瘦。
s1roNegFat: a = {a}（在 −1 和 0 之间）：开口翻到<b>向下</b>；胖瘦看 |a| = {abs}（比 1 小），比原型胖。
s1roNegOne: a = −1：开口向下的原型——像把 y = x² 关于 x 轴翻了个个儿。
s1roZero: a = 0：x² 项被乘成了 0，y 恒等于 0，图象就是 x 轴这条<b>直线</b>——不再是抛物线。所以二次函数立下规矩：<b>a 必须不为 0</b>。
:::

## 顶点式：让抛物线搬家，顶点写在脸上 {#step2 h2=s2t}

::: strings
nav2: 2 顶点搬家
:::

第 2 步 · 顶点搬家 {#s2k .step-kicker i18n=text}

这一步要回答：把整条抛物线搬个家，式子怎么跟着改？式子写成 <b>y = a(x − h)² + k</b> 的样子，叫<b>顶点式</b>：h 管左右搬、k 管上下搬，搬到哪，顶点 (h, k) 就跟到哪。顶点所在的竖线 x = h 是整条弧线的<b>对称轴</b>——让左右两边镜像对称的那条线。拖 h、k 两个滑杆，看顶点、对称轴和式子一起动。 {#s2e .explain}

::: html step2-1
s2aLab: 开口方向 a
s2aUp: a = 1（开口向上）
s2aDown: a = −1（开口向下）
s2hLab: h（顶点左右搬）
s2kLab: k（顶点上下搬）
s2eqPre: 顶点式
:::

书写约定（和一次函数页同一套）：h 是负数时，(x − h) 写成 (x + |h|)，比如 h = −1 写 (x + 1)²——读式子时顶点的横坐标是 <b>−1</b>，别被加号骗了。顶点式适用于任何抛物线：只要知道顶点和开口，式子就定下来了。 {#s2hint .hint}

::: strings
s2ro: 顶点 <b>({h}, {k})</b> 就写在式子里：括号里的 h 是顶点的横坐标，末尾的 k 是纵坐标。对称轴是竖线 <b>x = {h}</b>，顶点正好在这条线上。图上标出的一对点 ({lx}, {y}) 与 ({rx}, {y})：离对称轴一样远（都是 2 格），高度也一样——这就是「左右对称」看得见的样子。
cAxisLab: 对称轴 x = {h}
:::

## 落点与交点：弧线在哪里碰到地面 {#step3 h2=s3t}

::: strings
nav3: 3 落点与交点
:::

第 3 步 · 落点与交点 {#s3k .step-kicker i18n=text}

这一步要回答：抛物线和 x 轴（地面）交在哪里、有几个交点？交点就是 y = 0 的地方——投篮情境里，球落地的那一刻。拖 h、k 滑杆或切换开口方向，把弧线摆出两交点、一交点、无交点三种情形；再点（或拖动）弧线放一面探针旗，逐点看高度。 {#s3e .explain}

先看顶点相对 x 轴的位置，再拖 h/k：穿过 x 轴是两个落点，刚好碰到是一个，整条在上方或下方则没有。 {#s3bridge .hint i18n=text}

::: html step3-1
s3aLab: 开口方向 a
s3aUp: a = 1（开口向上）
s3aDown: a = −1（开口向下）
s3hLab: h（顶点左右）
s3kLab: k（顶点上下）
s3eqPre: 这条抛物线
:::

交点个数只看弧线和轴的相对位置：穿过去 = 2 个，顶点压轴 = 1 个，够不着 = 0 个。以后会学到一个专门判断交点个数的式子，到时候回头看这一页的图就全明白了。这一页先练读图：交点是读出来的，不用背判法。 {#s3hint .hint}

::: strings
s3roTwo: 与 x 轴有 <b>两个交点</b>：({x1}, 0) 和 ({x2}, 0)。交点就是 y = 0 的地方——放到投篮情境里，右边的那个就是球的<b>落点</b>。
s3roOne: 与 x 轴只有 <b>一个交点</b>：({x}, 0)——顶点正好压在轴上，弧线只和轴碰一下（相切），不多也不少。
s3roNoneAbove: 与 x 轴<b>没有交点</b>：整条弧线都在轴的上方，y 永远大于 0，落不了地。
s3roNoneBelow: 与 x 轴<b>没有交点</b>：整条弧线都在轴的下方，y 永远小于 0，碰不到轴。
s3probeIdle: 点（或拖动）图上的弧线放一面探针旗：看任意 x 处弧线有多高，旗子插到 y = 0 处就是交点。
s3probe: 探针在 x = {x}：弧线高 y = <b>{y}</b>。{tail}
s3tailZero: 正好为 0——旗子正插在交点上！
s3tailPos: 还在 x 轴上方，没有落地。
s3tailNeg: 已经在 x 轴下方了——真实投篮不会钻到地面以下，这里只是把图画全给你看。
cGround: 地面（y = 0）
cGroundS: 地面
:::

## 一条弧线，全写在式子里 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

回头看这一页：抛物线之所以能用一行顶点式写完，是因为它要交代的事也不多——开口的方向和胖瘦、顶点在哪里。剩下的每一点，都被这几件事唯一确定。 {#s5e .explain}

::: html step5-1
c1h: a 管方向与胖瘦
c1: a 的符号定开口（正向上、负向下），|a| 定胖瘦（越大越瘦）。a = 0 时弧线塌成直线，所以二次函数要求 a ≠ 0。
c2h: 顶点式把顶点写在脸上
c2: y = a(x − h)² + k：顶点 (h, k) 直接读，对称轴就是 x = h。一般的抛物线都能写成顶点式——先找到顶点，式子就有了骨架。
c3h: 交点是落点
c3: 抛物线与 x 轴的交点就是 y = 0 的地方，个数只有 2、1、0 三种：穿过、相切、够不着。投篮的落点、喷泉的落水点，都是交点。
s5fin: 补一句课本口径：常见的一般式 y = ax² + bx + c 和顶点式是同一条抛物线的两种写法——把顶点式展开、合并同类项就是一般式；反过来把一般式改写回顶点式（配方）是后面的功夫，这一页先把图象和顶点式对上号。
s5lkLin: 回看直线：一次函数第 0 步里，每步抬高恒定，点排成直线；这里抬高量一步一变，点就弯成了抛物线——去对照着看 →
s5lkPyth: 坐标的另一件本事：勾股定理第 5 步用坐标量两点之间的距离——顶点、交点都读出来以后，还能算它们彼此隔多远 →
:::
