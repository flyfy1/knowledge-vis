## 一条线上的点，一个数就够 {#step0 h2=s0t}

::: strings
nav0: 0 一维地址
:::

第 0 步 · 一维地址 {#s0k .step-kicker i18n=text}

这一步要回答：只用一个数，能不能把一条线上的位置说死？这是一条**数轴**：先定一个起算点，叫**原点**（origin，记作 O）——所有位置都相对于它说；再定正方向（这里向右为正）。拖动轴上的点（或点任意刻度放点），看读数怎样用一个带符号的数把它的位置说清。 {#s0e .explain}

::: html step0-1
s0shift: 把原点挪到 +2 处看看
:::

结论：一维位置 ⇔ 一个带符号的数，前提是**原点与正方向事先说定**。但这条本事只管一条线上的点——点要是跳到平面上，一个数还够不够？下一步当场撞给你看。 {#s0hint .hint}

::: html step0-2
start: 开始探索 ↓
:::

::: strings
s0unshift: 把原点放回原处
s0roPos: 点在原点**右边 {n} 格**，记作 <b>+{n}</b>——方向（右）加距离（{n} 格），一个数就把位置钉死了。
s0roNeg: 点在原点**左边 {n} 格**，记作 <b>−{n}</b>——负号管方向（左），数字管距离（{n} 格）。
s0roZero: 点就在**原点**，记作 <b>0</b>——不左不右，距离也是 0。
s0shiftNote: 注意：<b>点没动，地址变了</b>。原点挪到 {o} 之后，同一个点的读数成了 {r}。地址永远是相对于原点说的——原点一换，全体地址跟着变。
s0blocked: 先别挪：原点要是真的挪过去，这个点的读数会变成 <b>{r}</b>，跑出这条轴标出的 −6…+6 了。把点往中间挪一点，再点一次试试。
s0oldOrigin: 原来的原点
:::

## 平面上的点，要一对数才定得死 {#step1 h2=s1t}

::: strings
nav1: 1 一个数不够
:::

第 1 步 · 一个数不够 {#s1k .step-kicker i18n=text}

这一步要回答：把点放进平面，只报一个数，会发生什么？这是一片座位：**7 列 × 5 行**，其中藏着一个目标座位。先只报一个数试试——用滑杆选列号或行号，再点下面的按钮报出去，看亮起来的范围有多大。 {#s1e .explain}

::: html step1-1
s1colLab: 列号（从左往右数第几列）
s1rowLab: 行号（从下往上数第几行）
s1btnCol: 只报列号
s1btnRow: 只报行号
s1btnBoth: 两个都报
:::

结论：平面上的位置需要**一对数**——一个管横、一个管纵。座位、棋盘、地图网格都是这个道理。下一步给这对数立全世界统一的规矩。 {#s1hint .hint}

::: strings
s1roIdle: 还没报数。先想想：只给一个列号，能定死是哪一个座位吗？
s1roCol: 只报列号 <b>{c}</b>：第 {c} 列整列亮起来——这一列有 <b>{n} 个座位</b>，目标可能在其中任何一个。**一个数只定出一条线，定不死一个点。**
s1roRow: 只报行号 <b>{r}</b>：第 {r} 行整行亮起来——这一行有 <b>{n} 个座位</b>，目标可能在其中任何一个。**一个数只定出一条线，定不死一个点。**
s1roBothHit: 列 <b>{c}</b>、行 <b>{r}</b> 两个都报：两条亮带一交叉，交叉处只剩 <b>1 个座位</b>——目标现身！**两个数一交叉，点就被钉死了。**
s1roBothMiss: 列 <b>{c}</b>、行 <b>{r}</b> 两个都报：交叉处只剩 <b>1 个座位</b>——这一对数确实定死了一个座位，可惜不是目标那个。换一组列号、行号再报。
s1target: 目标
s1colsCap: 列号 →
s1rowsCap: 行号 ↑
:::

## 先横后纵：(x, y) 是点的地址 {#step2 h2=s2t}

::: strings
nav2: 2 坐标系登场
:::

第 2 步 · 坐标系登场 {#s2k .step-kicker i18n=text}

这一步要回答：这一对数按什么统一规矩写，全世界的人才不会读错？把第 0 步的数轴再立起来一根：横着的叫**横轴**（x 轴），立起来的叫**纵轴**（y 轴）；两条数轴垂直交叉、共用一个原点，铺成的这张「地址网」叫**平面直角坐标系**。给网格配上原点和正负，座位号就升级成了坐标。点图上的青色点，看它的坐标是怎样从原点一步步走出来的；再拖橙色点满图跑。 {#s2e .explain}

::: html step2-1
s2build: ▶ 搭一遍坐标系
s2pickLab: 点图上的青色点看走法，或拖动橙色点满图跑：
:::

结论：坐标 = 从原点出发的走法记录，写成**有序数对** (x, y)——有顺序的一对数，先横后纵，全世界统一。本页只练整数格点；格子之间的点也有坐标，可以是分数、小数，读法完全相同（后面的函数页会遇到）。 {#s2hint .hint}

::: strings
s2bPh1: 1/3：横轴躺平——就是第 0 步那条数轴
s2bPh2: 2/3：纵轴立起——同一条数轴，竖起来
s2bPh3: 3/3：原点对齐——地址网铺好了
s2ro: 先横走 <b>{xs}</b>，再纵走 <b>{ys}</b> → 这个点的坐标是 <b>{coord}</b>。第一个数 {xs} 叫**横坐标**，第二个数 {ys} 叫**纵坐标**。
:::

## (3, 2) 和 (2, 3) 不是一家 {#step3 h2=s3t}

::: strings
nav3: 3 顺序不能反
:::

第 3 步 · 顺序不能反 {#s3k .step-kicker i18n=text}

这一步要回答：把坐标的两个数写反，还是同一个点吗？青点是 A，橙点 A′ 是把 A 的坐标**交换**得到的「换位点」。点「交换 A 的坐标」，看 A 往哪儿搬家；再拖 A 满图跑（或用滑杆），盯住 A′ 怎样跟着动。图上那条斜线叫**对角线**——横纵相等的点连成的线，这一步只拿它当换位实验的镜面。 {#s3e .explain}

试着只改横坐标 x：A′ 的纵坐标跟着改；再只改纵坐标 y：A′ 的横坐标跟着改。只有 x=y 时，交换前后仍落在同一格。 {#s3bridge .hint i18n=text}

::: html step3-1
s3xLab: A 的横坐标 x
s3yLab: A 的纵坐标 y
s3swapBtn: 交换 A 的坐标 ⇄
:::

结论：(a, b) 与 (b, a) 一般是两个不同的点，**a = b 时才重合**——所以坐标必须是有序数对，顺序本身就是地址的一部分。这条对一切坐标都成立，不限于整数格点。 {#s3hint .hint}

::: strings
s3diag: 对角线：这条斜线上的点横纵相等
s3roDiff: A 是 <b>{a}</b>，换位点 A′ 是 <b>{b}</b>：横坐标差 <b>{dx} 格</b>、纵坐标差 <b>{dy} 格</b>——**两个不同的点**。写反 = 点搬家。
s3roSame: A 是 <b>{a}</b>：横纵相等，交换之后还是它自己——A 和 A′ 在这里**重合**。只有对角线上的点，写反了才不变。
:::

## 四象限：符号是拼出来的，不是背的 {#step4 h2=s4t}

::: strings
nav4: 4 四象限

第 4 步 · 四象限 {#s4k .step-kicker i18n=text}

这一步要回答：两根轴把平面切成的四块区域，每块里的点，坐标符号有什么规律？这四块区域叫**象限**（quadrant），按逆时针从右上数：一、二、三、四。拖点满平面跑（也可以点任意格点把点放过去），读数行会把它的坐标、符号和所在区域一起报出来；第一次走进一个新区，那个区域就会亮起来并挂上它的符号牌。 {#s4e .explain}

::: html step4-1
s4prac: **反向小练（不计分）**：只给符号，你能指出区域吗？看下面给出的符号组合，在图上点一点你认为对的区域（点任意格点即可作答；拖着点到处逛不算作答）。
s4new: 换一个组合
:::

结论：点在第几象限，只取决于 x、y 各自的正负，**与坐标大小无关**；坐标轴上的点不属于任何象限（因为总有一个坐标是 0）。这是定义，没有例外。 {#s4hint .hint}

s4roYAxis: 点 {coord} 在 **y 轴**上：x = 0——没有正负，**不属于任何象限**。
s4roOrigin: 点 {coord} 就是**原点**：两个坐标都是 0，**不属于任何象限**。
s4ro2: 四个区域全部走到了：它们的符号，全是两根轴正负的**拼图**——x 的符号看左右、y 的符号看上下，拼起来就是，不用背。

## 把一条线拆成：方向、长度与中点 {#step6 h2=s6t}

::: strings
nav6: 6 中点与距离
:::

第 6 步 · 中点与距离 {#s6k .step-kicker i18n=text}

这一步要回答：两点之间的直线，怎样同时读出方向、长度和正中央？拖动 A、B 或使用滑杆。青色箭头是从 A 指向 B 的向量；橙色虚线把它拆成横向 Δx 与纵向 Δy；绿色点 M 是中点，坐标是两端坐标逐项取平均。距离用勾股定理把两个分量合成，斜率则是 Δy/Δx；竖直线没有有限斜率。 {#s6e .explain}

::: html step6-1
s6canvasLabel: 可拖动的两点、向量分量和中点；读数见图下
s6AxLab: A 的横坐标 x
s6AyLab: A 的纵坐标 y
s6BxLab: B 的横坐标 x
s6ByLab: B 的纵坐标 y
s6components: 显示横、纵分量
reset: 重置本步
:::

结论：一条线段不是只有一个「长度」；它还带着方向分量。交换 A、B 会让 Δx、Δy 和斜率变号，但距离不变，中点也不变。这里的整数格只是练习入口，分数坐标遵循同一套公式。 {#s6hint .hint}

::: strings
s6ro: A = <b>{a}</b>，B = <b>{b}</b>；Δx = <b>{dx}</b>，Δy = <b>{dy}</b>；距离 |AB| = <b>{dist}</b>；中点 M = <b>{mid}</b>；斜率 = <b>{slope}</b>。
s6vertical: 未定义（竖直线）
s6check: 平方核对：|AB|² = <b>{lhs}</b>；分量平方和 {rhs}。
:::
