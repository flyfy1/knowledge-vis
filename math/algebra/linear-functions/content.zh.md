## 爬坡：每一步抬高一样多，点就排成直线 {#step0 h2=s0t}

::: strings
nav0: 0 爬坡
:::

第 0 步 · 爬坡 {#s0k .step-kicker i18n=text}

这一步要回答：一排台阶，每一级都抬高一样多，把台阶的角连起来是什么样？拖滑杆选「每向前 1 格抬高几格」，看格点一个一个落下（x 从 0 到 5），它们自己会排成什么形状。横轴是向前走的格数 x，纵轴是高度 y。 {#s0e .explain}

::: html step0-1
s0kLab: 每向前 1 格，抬高几格
s0play: 重新落点 ▶
:::

结论的适用条件：每一级抬高<b>必须一样多</b>，点才连得成直线。要是每一步抬高得不一样多，连起来就会弯——弯成什么样，是后面抛物线那一页的故事。 {#s0hint .hint}

::: html step0-2
start: 开始探索 ↓
:::

::: strings
s0roPts: 落下的点：{pts}
s0roNone: 点正在一个一个落下……
s0roKPos: k = {k}：每向前 1 格就抬高 {k} {unit}。这个「每走一步抬高多少」就叫<b>斜率</b>（slope）——它管坡的陡缓：k 越大坡越陡。等步长、等抬高，点必然排成一条<b>直线</b>。
s0roKNeg: k = {k}：每向前 1 格不是抬高、而是降低 {a} {unit}，坡往下走。这个「每走一步抬高多少」就叫<b>斜率</b>（slope）——斜率为负，就是下坡。等步长、等降低，点照样排成一条<b>直线</b>。
s0roKZero: k = 0：每走一步抬高 0 格，是<b>平地</b>。平地也是一条直线，它的斜率（每走一步抬高多少）就是 0。
:::

## 起点：换个高度出发，整条线一起平移 {#step1 h2=s1t}

::: strings
nav1: 1 起点
:::

第 1 步 · 起点 {#s1k .step-kicker i18n=text}

这一步要回答：同一条坡（陡缓不变，也就是斜率固定为 1），从不同高度出发，直线会有什么不一样？拖滑杆改起点高度，看整条线怎样上下平移，并盯住它和纵轴的交点。 {#s1e .explain}

::: html step1-1
s1bLab: 起点高度 b（还没出发、x = 0 时站的高度）
:::

读任何一条直线，先读截距：看它在纵轴上落在哪一点，那个高度就是 b。下一步会把斜率和截距拼成完整的方程。 {#s1hint .hint}

::: strings
s1ro: 直线在 x = 0 处穿过纵轴，交点是 <b>(0, {b})</b>。这个「x = 0 时的 y」就叫<b>截距</b>（intercept），记作 b = {b}：还没出发，就已经站在这个高度了。拖 b 时坡的陡缓（斜率）纹丝不动——b 只管把整条线上下平移。
:::

## 把陡缓和起点拼起来：y = kx + b {#step2 h2=s2t}

::: strings
nav2: 2 方程长出来
:::

第 2 步 · 方程长出来 {#s2k .step-kicker i18n=text}

这一步要回答：能不能写出一句式子，算出这条线上的每一个点？把第 0 步的斜率 k（每走 1 格抬高多少）和第 1 步的截距 b（x = 0 时的 y）拼起来，就是 <b>y = kx + b</b>。像这样「x 定下来，y 就被唯一确定」的对应关系，叫<b>函数</b>（function）。拖两个滑杆，线和方程一起变；再点直线上的格点，逐项验算给你看。 {#s2e .explain}

::: html step2-1
s2kLab: 斜率 k（每走 1 格抬高多少）
s2bLab: 截距 b（x = 0 时的 y）
s2eqPre: 这条线的方程
s2prev: ← 上一个点
s2next: 下一个点 →
:::

方程是这条线的「说明书」。书写约定：k = 1 时不写系数（写 x 不写 1x）；k = −1 写 −x；b = 0 时不写出来；b 为负写成减一个数。 {#s2hint .hint}

:::

::: strings
s2probeIdle: 点直线上的圆点（或用下面两个按钮换点），看代入验算：把点的 x 代进方程，算出的 y 应该正好是这个点的 y。
s2probeFar: 离直线太远了——请点贴在直线上的圆点。
s2probe: 验算点 <b>({x}, {y})</b>：{arith} ✓ 算出的 y 正好是点的纵坐标——这个点确实在直线上；这样的点有无数个，全都满足同一个方程。
:::

## 两条线相遇：交点是共同的解 {#step3 h2=s3t}

::: strings
nav3: 3 两条线相遇
:::

第 3 步 · 两条线相遇 {#s3k .step-kicker i18n=text}

这一步要回答：两条直线什么时候相交、交点又是什么意思？第一条线固定为 y = x + 1；拖滑杆改第二条线的斜率 k₂（陡缓）和截距 b₂（起点高度），看它们在哪里相遇——或者根本不相遇。两条线共同的那个点，叫<b>交点</b>（intersection point）。 {#s3e .explain}

::: html step3-1
s3k2Lab: 第二条线的斜率 k₂（陡缓）
s3b2Lab: 第二条线的截距 b₂（起点高度）
:::

判断口诀：先比斜率——斜率不同，必相交于一点；斜率相同，再比截距——相同则重合，不同则平行。 {#s3hint .hint}

::: strings
s3l1: 第一条线（固定）：{eq}
s3l2: 第二条线：{eq}
s3roPoint: 交点是 <b>({x}, {y})</b>：它同时在两条线上——把 x = {x} 分别代入两个方程，算出的 y 都是 {y}。所以交点就是两个方程<b>共同的解</b>。
s3roParallel: 两条线<b>平行</b>：斜率相同（都是 1），截距不同，怎么延长都不会相遇——两个方程没有共同的解。
s3roCoincident: 两条线<b>完全重合</b>：斜率、截距全都相同，其实就是同一条线——线上的每一个点都是交点，有无数个共同的解。
:::

## 一张说明书，管住一条线 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

回头看这一页：一条直线之所以能用一行方程写完，是因为它只有两件事要交代——有多陡、从哪开始。剩下的每一个点，都被这两件事唯一确定。 {#s5e .explain}

::: html step5-1
c1h: 斜率 k = 陡缓
c1: 每向前 1 格抬高多少。大了更陡、负了下坡、0 是平地。要是每一步抬高得不一样多，点就连成曲线——那是接下来抛物线那一页的故事。
c2h: 截距 b = 起点
c2: x = 0 时的 y，还没出发就站在多高。改 b 不改陡缓，只把整条线上下平移。生活里到处是 b：起步价、底薪、固定月费。
c3h: 交点 = 共同解
c3: 两条线相遇的点，同时满足两个方程。斜率不同才相交；相同则平行或重合。以后解方程组，找的就是这个点。
s5fin: 直线是所有函数的起点：先把「一个量怎样随另一个量变」看成图，再写成式子，最后用式子去算图上没画出来的点——这条路，通向后面所有的函数。
s5lkPyth: 坐标的下一站：勾股定理第 5 步把坐标用来量两点之间的距离——距离公式，其实就是勾股定理穿上坐标的衣服 →
:::
