## 数轴不够用：x² = −1 的解站在哪里？ {#step0 h2=s0t}

::: strings
nav0: 0 数轴不够用
:::

第 0 步 · 数轴不够用 {#s0k .step-kicker i18n=text}

这一步要回答：**方程 x² = −1 的解，到底站在哪里？**你已经知道：实数全排在一条数轴上，而任何实数的平方都 ≥ 0——正数平方是正数，负数平方也是正数，0 的平方是 0。下面这台探针让你亲手验：拖着 x 沿数轴走，上方描出的轨迹是 x² 的全部取值，它贴着数轴上方走，却永远够不到 −1 那条横线。找不到不是因为没找仔细——是这条线上根本没有它的位置。 {#s0e .explain}

::: html step0-1
s0xLab: 平方探针 x（沿数轴拖）
s0open: 把数轴竖起来当一条边：展开平面 ⤢
:::

结论：x² = −1 在实数里无解，缺的不是某个数、是一个**维度**。给数轴加一条垂直的轴，数就从「线上的点」升级为「平面上的点」；新轴上的单位记作 **i**。这一步先只承诺一件事：i² = −1 在本页会变成看得见的事实，不靠背。 {#s0conc .readout}

为什么非得加一整条轴，而不是只添一个点？因为数要能运算：添进来的点和原来的实数相加、相乘，结果还得有地方站——一张平面才装得下这一整套新数。下一站先把「平面上的点」这套读法认全。 {#s0hint .hint}

:::

## 复数是平面上的点：钉住它要么 (a, b)，要么（模，辐角） {#step1 h2=s1t}

::: strings
nav1: 1 点与箭头
:::

第 1 步 · 复平面上的点 {#s1k .step-kicker i18n=text}

这一步要回答：**一个复数，要几个数才能钉住？**图上是一个复平面：横轴是实轴、纵轴是虚轴。拖动点 z，读数四栏全部由它的坐标 (a, b) 当场实算：a 叫**实部**、b 叫**虚部**（注意：虚部是 b 这个实数本身，不带 i），写法记作 z = a + bi；从原点向 z 拉出的箭头，长度叫**模** |z|——就是勾股定理里那根斜边；箭头与实轴正半轴的夹角（逆时针量）叫**辐角** θ。辐角有很多个等价写法，本页统一取**辐角主值**：归到 (−180°, 180°] 里的那一个。 {#s1e .explain}

按顺序试三个点：先看 3+4i 的坐标怎样给出长度 5，再看纯实数只有方向 0°/180°，最后看单位圆上长度固定为 1、只改变方向。这样能把“坐标读法”和“长度＋方向读法”对上。 {#s1bridge .hint i18n=text}

结论：钉住一个点有两套办法——坐标 (a, b)，或者（模，辐角）。它们是**同一根箭头的两种读法**：前者说「向右走几、向上走几」，后者说「多长、朝哪个方向」。下一步加法用第一套读法最顺，乘法则要靠第二套——先都认熟。 {#s1conc .readout}

边界逐个验：把点拖到负实轴上，辐角读作 +180° 而不是 −180°——主值区间的右端是闭的。拖到单位圆上（虚线圈）时模恒为 1，只剩角度在变；这时箭头尖的坐标正是 (cos θ, sin θ)，这个读法的出处在[[trigonometry#step1|三角函数页第 1 步]]。 {#s1hint .hint}

## 加法 = 平移：和的坐标就是两边坐标各自相加 {#step2 h2=s2t}

::: strings
nav2: 2 加法是平移
:::

第 2 步 · 加法 {#s2k .step-kicker i18n=text}

这一步要回答：**两个复数相加，图上到底动了什么？**图上有两根可拖的箭头 z₁、z₂，第三根绿箭头是它们的和 z₁ + z₂，用**平行四边形法则**画出（以 z₁、z₂ 为邻边张成平行四边形，对角线就是和；等价地看，z₂ 的箭头首尾相接到 z₁ 的尖端，落点相同）。拖任意一根，下面三栏对账会逐栏核对：和的实部、虚部是不是恰好两边各自相加。 {#s2e .explain}

::: html step2-1
editRange2: 绘图范围：每个输入复数的两分量分别限制到 −4.2…4.2；和仍由两数实算。此范围只为绘图。
editTarget: 目标复数
editFirst: z₁ · 第一个数
editSecond: z₂ · 第二个数
:::

结论：加 z₂，就是把整幅图沿 z₂ 这根箭头**平移**那么远；和的横、纵坐标恰是两边各自相加。这与向量加法是同一件事——复数加法 = 分量相加 = 平移，只对加法成立。 {#s2conc .readout}

先埋一个反差：乘法**不是**分量相乘。(1 + i) × (1 + i) 若按分量乘会得 1 + 1i 之类怪东西，真实答案第 4 步在对账台上见——乘法动的是模和角，不是分量。 {#s2hint .hint}

::: strings

s2roSum: z₁ = <span>{z1}</span>，z₂ = <span>{z2}</span>，z₁ + z₂ = <b>{sum}</b>
s2roRe: 实部对账：{a1} + {a2} = <b>{s}</b> ✓（正是和的实部）
s2roIm: 虚部对账：{b1} + {b2} = <b>{s}</b> ✓（正是和的虚部）
:::

## 乘 i：什么都不改，只转 90° {#step3 h2=s3t}

::: strings
nav3: 3 乘 i 转 90°
:::

第 3 步 · 乘 i {#s3k .step-kicker i18n=text}

这一步要回答：**i 自己到底「是」什么？**选一个起点，按「× i」按钮连着按：每按一次，箭头就逆时针转 90°——盯住读数：模纹丝不动，辐角每次恰好 +90°（超过 180° 就按主值归回来）。落点和弧线全程留痕，连按四次，箭头回到原来的方向。下面还有一条单位点巡演：1 → i → −1 → −i → 1，落点逐个钉在坐标轴上。 {#s3e .explain}

::: html step3-1
s3startLab: 起点 z：
s3p1: 1（单位点）
s3p2: 3 + 2i
s3mul: × i（转 90°）
s3reset: 重置 ↺
:::

收口：**×i = 逆时针旋转 90°**，所以 i² = 转两次 = 掉头 = −1。**i² = −1 是转出来的，不是背出来的。**「i 是 √−1 的记号」和「i 是转 90° 的动作」是同一个 i 的两副面孔：前者是它的名字，后者是它的行为。 {#s3conc .readout}

换起点 3 + 2i 再连按四次：四个落点不在坐标轴上，但模始终是 √13、辐角每次 +90°、第四次严丝合缝回到 (3, 2)——周期 4 对任何起点都成立，因为转四次就是转一整圈。 {#s3hint .hint}

::: strings
s3prog: 已乘 i {k} 次（每 4 次回到原方向）
s3ro: 当前 z = <b>{z}</b>：模 = <b>{m}</b>（乘 i 前后一模一样）；辐角 = <b>{ang}</b>。
s3back: 转满一圈了：四次 90° 正好 360°，箭头回到起点方向——i 的幂以 4 为周期。
s3pow: 单位点巡演（全部由连乘实算）：i¹ = <b>{p1}</b>，i² = <b>{p2}</b>，i³ = <b>{p3}</b>，i⁴ = <b>{p4}</b>。看 i² 落在哪：从 1 出发转两次 90° 就是掉头 180°，落在 −1 上。
:::

## 一般乘法 = 模相乘、角相加：对账台 {#step4 h2=s4t}

第 4 步 · 一般乘法 {#s4k .step-kicker i18n=text}

这一步要回答：**乘上任意一个复数，模和角各发生什么？**先把两件事分开验明：乘一个正实数（如下方预设 2）只伸缩不转；乘一个模为 1 的数只转不伸缩。任意乘数 z₂ 则是两件事叠加。拖动 z₁（被乘）与 z₂（乘数），绿箭头是乘积 z₁·z₂；下面对账台三组读数全部实算：模对账、角对账、还有一条代数路 (a₁a₂ − b₁b₂, a₁b₂ + b₁a₂)——两条路同源互证。 {#s4e .explain}

结论：**乘法法则——模相乘、角相加**。乘上谁，就按谁的模伸缩、按谁的辐角旋转。条件写明：角度相加后必须按主值区间归一化（340° 与 −20° 是同一个方向，本页统一写 −20°）；乘数或被乘数是 0 时，乘积是原点、无辐角可言。 {#s4conc .readout}

本演台把两个点限制在模 ≤ 2.6 的圆盘内，免得乘积跑出图外——法则本身对任意大小的复数都成立。先用预设 1 + i 验一组：z₁ = 2 + i 时乘积辐角应比原来恰好多 45°、模恰好多乘 √2，对账台会当场打勾。 {#s4hint .hint}

## 终章：一张平面，两种运算 {#step6 h2=s6t}

::: strings

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

复数不是一条要背的法则，是把数放回平面之后自然长出来的运算。收口三张卡： {#s6e .explain}

::: html step6-1
c1h: 复数是平面上的点
c1: z = a + bi 与平面上的点、与从原点出发的箭头一一对应。钉住它有两种读法：坐标 (a, b)，或（模，辐角）——模是箭头的长度，辐角是它的方向（本页取主值 (−180°, 180°]）。
c2h: 加法是平移
c2: 和的坐标 = 两边坐标各自相加，图上就是沿着加数的箭头平移一次——平行四边形的对角线。加法只动位置，不动方向和长度的读法。
