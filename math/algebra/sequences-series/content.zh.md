## 每层多 d 块砖，第 n 层有多少块？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 等差数列
:::

::: html step0-1

s0k: 每次加同样多

这一步要回答：每次增加同样的量时，第 n 项怎样写？**数列**是按顺序排列的一列数，a₁ 是第一项。**等差数列**指相邻两项的差是常数 d（**公差**）。第 n 项：aₙ = a₁ + (n−1)·d。下图每根柱是一层砖数，橙色短线标出每次增加 d。**观察：**改首项 a₁ 和公差 d：d &gt; 0 柱子阶梯上升，d = 0 一样高，d &lt; 0 阶梯下降（负的砖数在图中不画高度，只标数字）。读数里的通项公式随之更新。 {#s0e .explain}

## 把 1+2+…+n 一次加完，有没有捷径？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 倒序相加
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 倒序相加
:::

这一步要回答：等差数列前 n 项的和 Sₙ 怎样一步算出？把数列正着写一遍（青色），再倒着写一遍（橙色），上下对齐相加：每一对的和都等于 a₁ + aₙ，一共 n 对，所以两倍的 Sₙ 等于一个宽 a₁+aₙ、高 n 的长方形的面积：**Sₙ = n(a₁ + aₙ)/2**。传说高斯小时候就这样算出 1+2+…+100 = 5050。**观察：**改 a₁、d、n：每一行的青+橙宽度总是 a₁+aₙ，对不起来的那种情况不会出现；读数用长方形面积的一半与逐项相加对照，两者相等。 {#s1e .explain}

## 棋盘第 64 格要放多少粒麦子？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 等比数列
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 每次乘同样的倍数
:::

这一步要回答：每次乘同一个倍数时，增长有多快？**等比数列**指相邻两项的比是常数 r（**公比**）。第 n 项：aₙ = a₁·rⁿ⁻¹。传说在 8×8 的棋盘第 1 格放 1 粒麦子，之后每格翻倍（r = 2）。上图是 64 格（颜色越深，该格粒数的对数越大），下图是各格粒数的对数曲线。**观察：**拖动公比 r 和格数 n：r = 2 时，前 12 格才 2048 粒，第 64 格却是 9.2×10¹⁸ 粒；对比读数里“每格只多 1 粒”的情形（等差，64 格才 64 粒）。增长是不是“乘”出来的，决定它是缓慢还是爆炸。 {#s2e .explain}

## 一直加下去，总数会不会无限大？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 等比求和与极限
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 无穷多项能有总和吗
:::

这一步要回答：把等比数列加到无穷多项，会怎样？前 n 项的和是 **Sₙ = a₁(1 − rⁿ)/(1 − r)**（r ≠ 1）。当 |r| &lt; 1 时，rⁿ 越来越小，Sₙ 越来越接近 a₁/(1 − r)，这个值叫**极限**（绿虚线）；当 |r| ≥ 1 时，Sₙ 不会趋近于一个数，称为**发散**。柱子是每一步的部分和 Sₙ（a₁ = 1）。r = 1/2 时 1 + 1/2 + 1/4 + … 一步步逼近 2。**观察：**拖动 r：|r| 越接近 1，收敛越慢；r 为负时柱子上下跳着靠近极限；超过 1 时一路上冲。调大项数 n 看间隙（读数最后一项）是否缩小。 {#s3e .explain}

s3cv: 等比数列的部分和 Sₙ（青柱）与极限（绿虚线）
:::

## 每月多存一点，和每月多存一成，谁先赢？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 等差 vs 等比
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 线性 vs 指数
:::

这一步要回答：等差增长和等比增长，累计谁更多？两个存钱计划第 1 个月都存 100：计划 A（青）每月比上月多存 d 元（等差）；计划 B（橙）每月存款是上月的 r 倍，即每月多存 g%（等比）。图是累计存款。**观察：**拖动 d 和 g：即使 g 只有 3%，开始时 B 落后于 A，但几十个月后总会反超（绿虚线标出第几个月）；g = 0 时 B 每月存 100 不变，永远追不上 A（d &gt; 0 时）。这是一个纯数学模型：真实世界的收入不会无限按比例增长。 {#s4e .explain}

## 这是等差、等比，还是都不是？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 认出数列
:::

s5step: "第 5 步 · "

这一步要回答：看到一列数，怎么判断它是哪一类？检查相邻项的**差**是否恒定（等差）、相邻项的**比**是否恒定（等比）。例如 3, 7, 11, 15 差恒为 4；2, 6, 18, 54 比恒为 3；1, 4, 9, 16 差是 3, 5, 7 在变、比也在变，两者都不是（它们是平方数）。前 4 项已给出，选一类并点「检查」，会显示通项公式并填出后面的数；「换一列」会清除选择。 {#s5e .explain}
