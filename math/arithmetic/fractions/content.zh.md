## 分母是切法，分子是取法 {#step1 h2=s1t}

::: strings
nav1: 1 分数是一个数
:::

第 1 步 · 分数是一个数 {#s1k .step-kicker i18n=text}

这一步要回答：**分数到底是一个数，还是上下叠着的两个数？**拖动滑杆改变切法，点条上的格子（或用按钮）改变取的份数。记住一句话：**分母 = 把整体切成几等份，分子 = 取了其中几份**。下面的细数轴会告诉你，这个分数作为一个数，落在 0 和 1 之间的哪个位置。 {#s1e .explain}

::: html step1-1
s1denLab: 切成几等份（分母）
s1minus: − 少取一份
s1plus: ＋ 多取一份
s1clear: 清空
s1full: 取满
:::

格子必须**真等分**——这一页每格的宽度都由同一个整体除以份数算出来，误差不超过 1 个像素。分数的世界里，「差不多一样大」不算数。 {#s1hint .hint}

::: strings
s1ro: 切成 <span>{b}</span> 等份，取了 <span>{a}</span> 份 → 这个分数是 <b>{a}/{b}</b>
s1roZero: 一份都没取 → <b>0/{b}</b>，也就是 0。点格子开始取。
s1roFull: 取满了 → <b>{b}/{b} = 1</b>，正好一整个。那取得比一整个还多会怎样？第 5 步见。
s1decEq: 换成小数：{f} = {dec}（除得尽，是精确值）
s1decAp: 换成小数：{f} ≈ {dec}（除不尽，后面是无限循环的小数，只能写近似值）
cOne: 整体 = 1

:::

## 切得细，比例不变 {#step2 h2=s2t}

::: strings
nav2: 2 等值分数
:::

第 2 步 · 等值分数 {#s2k .step-kicker i18n=text}

这一步要回答：**1/2、2/4、4/8 写法各不相同，为什么会是同一个数？**把 1/2 的每一格再切成 2 小格，得到 2/4；再切，得到 4/8。三行条的选中部分**右端对齐同一条竖线**——它们是同一个数穿了不同的衣服。穿衣服的规则叫**扩分**（分子分母同乘一个数），脱衣服叫**约分**（同除以公约数）。 {#s2e .explain}

::: html step2-1
s2expLab: 扩分（分子分母同乘）：
s2reset: 回到 1/2
s2redLab: 约分 12/18：
s2redStep: 约分一步
s2redGcd: 直接除以最大公约数
s2reset2: 重来
:::

一串等值分数是同一个数的不同写法，其中最简的那个（分子分母互质——也就是除了 1 以外没有共同的约数）像它的**身份证**。判断两个分数是否相等，靠的不是长相——是约分后身份证是否相同，或者交叉相乘是否相等（下一步）。 {#s2hint .hint}

::: strings
s2roExp: 扩分：{f0} 的分子分母同乘 {k} → <b>{f1}</b>。格子变多了，每格变小了，选中部分的总长一点没变。
s2roExpMax: 已经切得很细了（分母 {d}），再乘格子就挤成一团看不清——点「回到 1/2」重新来。
s2roRed: 约分一步：{f0} 的分子分母同除以 {p} → <b>{f1}</b>。
s2roRedDone: 约分完成：12/18 → <b>2/3</b>。2 和 3 没有大于 1 的公约数了（gcd(2, 3) = 1），2/3 就是 12/18 的最简分数。
s2gcd: 最大公约数 gcd(12, 18) = <b>{g}</b>：分子分母一次同除以 {g}，12/18 → 2/3，和一步步约分殊途同归。
cRows: 三行对照：选中部分的右端对齐

## 先对齐刻度，再比长短 {#step3 h2=s3t}

::: strings
nav3: 3 比大小
:::

第 3 步 · 比大小 {#s3k .step-kicker i18n=text}

这一步要回答：**分母不同的两个分数，怎么比大小才靠谱？**两个分母不同的分数，格子不一样细，不能只看分子猜大小。验明有两条路：**交叉相乘**（a/b 与 c/d 比，算 a×d 和 c×b，都是整数，不会算错）；**通分**（把两条都重切成最小公倍数 lcm(b, d) 份，格数直接比）。两条路必须得出同一个结论——这一步还会请你的眼睛先猜一次。 {#s3e .explain}

::: html step3-1
s3labA: 左边 a/b
s3labB: 右边 c/d
s3next: 换一对
s3guessQ: 先凭眼睛猜：
s3bLeft: 左边大
s3bSame: 一样大
s3bRight: 右边大
s3verify: 两路验明
:::

为什么不能只看分子？因为**分子数的是格子个数，格子的大小由分母定**。这就像问「3 厘米和 2 英寸哪个长」——先把单位对齐，答案才有意义。注意：页面若出现「分母越大分数越小」，那只在分子相同时才成立——这里比较的从来是完整的分数。 {#s3hint .hint}

::: strings

s3roGuess: 你的猜测：{g}。点「两路验明」验证——改主意也没关系，以最后一次点的为准。
s3guessLeft: 左边大
s3guessSame: 一样大
s3guessRight: 右边大
s3roCross: 交叉相乘：{a}×{d} = <b>{ad}</b>，{c}×{b} = <b>{cb}</b>。{ad} {rel} {cb}，所以 {a}/{b} {rel} {c}/{d}。
s3roLcm: 通分：最小公倍数 lcm({b}, {d}) = <b>{l}</b>。{a}/{b} = {A}/{l}（取 {A} 格），{c}/{d} = {C}/{l}（取 {C} 格）。格数 {A} {rel} {C}，结论相同。
s3verdictWin: 猜对了！眼睛、交叉相乘、通分——三方一致：<b>{a}/{b} {rel} {c}/{d}</b>。
s3verdictLose: 眼睛这次被不一样细的格子骗了。两条验算路一致：<b>{a}/{b} {rel} {c}/{d}</b>。

## 加法：先通分，再相加 {#step4 h2=s4t}

::: strings
nav4: 4 加法先通分
:::

第 4 步 · 加法 {#s4k .step-kicker i18n=text}

这一步要回答：**分数加法为什么不能「分子加分子、分母加分母」？**最常见的错法就是这么加。错在哪？把 1/2 和 1/3 两块**真实的长度**接起来，和错误答案 2/5 摆在一起看——差距自己会说话。正确做法只有一条：先通分，把两把刻度不一样的尺子换成同一把。 {#s4e .explain}

::: html step4-1
s4add: 加法：1/2 + 1/3
s4sub: 减法：5/6 − 1/3
s4wrong: 先看看常见的错法
s4right: 再看正确做法
s4reset: 重置
:::

通分不是老师定的规矩，是**没有办法的办法**：格子不一样细，分子就没法直接加减。先把刻度对齐（通分），剩下的就只是数格子。 {#s4hint .hint}

::: strings
s4roIdleAdd: 题目：1/2 + 1/3。先点「常见的错法」，再点「正确做法」，两边对比着看。
s4roIdleSub: 题目：5/6 − 1/3。减法和加法同一条规则：先通分，再相减。点「正确做法」看。
s4roWrong: 错法：分子加分子、分母加分母 → 2/5。可是把上面两块的真实长度接起来，明明到了 5/6 的位置——比 2/5 长出 <b>13/30</b>（= 5/6 − 2/5）。答案短了一大截，错得很明显。
s4roRightAdd: 正确做法：最小公倍数 lcm(2, 3) = <b>6</b>。1/2 重切成 3/6，1/3 重切成 2/6，刻度对齐后分子直接相加：3/6 + 2/6 = <b>5/6</b> ≈ 0.8333…。下面两条严丝合缝对齐，就是证明。
s4roRightSub: 减法同理：最小公倍数 lcm(6, 3) = <b>6</b>。1/3 重切成 2/6，从 5/6 里拿走 2 格：5/6 − 2/6 = 3/6，再约分 = <b>1/2</b>。

## 超过 1 的分数：两种写法 {#step5 h2=s5t}

::: strings
nav5: 5 超过 1 的分数
:::

第 5 步 · 假分数与带分数 {#s5k .step-kicker i18n=text}

这一步要回答：**分子比分母还大，这个分数还算数吗、该怎么读？**分子比分母还大，天不会塌——那只是**超过一个整体**的意思。7/4 就是「切 4 份取 7 份」：第一个整体取满（4 份），第二个整体再取 3 份。换一种写法：1 个整体又 3/4，写作 **1¾**，叫带分数。同一个数，两种写法，除法就是翻译官。 {#s5e .explain}

::: html step5-1
s5barsT: 一格一格数过去：几个整体装得下？
s5imp: 假分数写法
s5mix: 带分数写法
s5next: 换一个分数
s5candT: 分数作用在一个量上：一盒 12 颗糖
s5bLab: 取这盒糖的：
:::

假分数和带分数没有谁比谁高级：算账（加减乘除）时假分数顺手，报数（「一又四分之三杯水」）时带分数顺嘴。重要的是随时能互相翻译——翻译的钥匙就是除法：分子 ÷ 分母。 {#s5hint .hint}

::: strings
s5roImp: <b>{n}/{d}</b>：{n} ÷ {d} = {q} 余 {r} → 装满 {q} 个整体，还剩 {r} 份 → 带分数 <b>{q} {r}/{d}</b>（读作 {q} 又 {d} 分之 {r}）。
s5roInt: <b>{n}/{d}</b>：{n} ÷ {d} = {q}，整除！它就是整数 <b>{q}</b>——分数写法的整数，藏得挺深。
s5roMix: 带分数 <b>{q} {r}/{d}</b>：{q} 个整体（{qd} 份）再加 {r} 份，共 {n} 份 → 假分数 <b>{n}/{d}</b>。两种写法随时互换。
s5roMixInt: 整数 <b>{q}</b>：正好 {q} 个整体（{qd}/{d}），没有零头。
s5bro: 一盒 <span>12</span> 颗的 <b>{n}/{d}</b>：先把 12 平均分成 {d} 份，每份 12 ÷ {d} = <span>{per}</span> 颗；取 {n} 份 → {per} × {n} = <b>{taken} 颗</b>。图上亮起的正好 {taken} 颗，数一数。
cWhole: 整体 {i}
:::
