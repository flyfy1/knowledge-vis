## 数轴向左长：0 的另一边 {#step0 h2=s0t}

::: strings
nav0: 0 数轴向左长
:::

第 0 步 · 补完数轴 {#s0k .step-kicker i18n=text}

这一步要回答：**0 的左边一个数也没有吗？往左的格子该写什么？**你已经认识数轴：一个数是轴上的一个点（0 是**原点**，两边的分界）。0 的右边住着**正数**——平时写的数都是正数，前面的「+」可以省略。点「向左延伸」，看轴一格一格往左长：左边新长出的数就是**负数**，写出来前面带一个「−」。点任意一个刻度，还能看清它和对面的关系。 {#s0e .explain}

::: html step0-1
s0extLab: 向左延伸几格
s0play: 向左延伸 ▶
s0reset: 收回重来
:::

看出来了吗：左边不是空的，是右边的**镜像**——每往左长一格，对面那格就有一个和它离 0 一样远的数。所以「−」记的不是「少了」，而是**方向：在 0 的哪一边**。这一页只标整数刻度；小数和分数的负数住在格子与格子之间，道理相同，以后会遇到。 {#s0hint .hint}

start: 开始探索 ↓
:::

## 温度计：负数能比大小 {#step1 h2=s1t}

::: strings
nav1: 1 温度计比大小
:::

第 1 步 · 负数比大小 {#s1k .step-kicker i18n=text}

这一步要回答：**−5 和 −1，哪个更冷？**先认清工具：温度计就是**立起来的数轴**，液柱顶端对齐的刻度就是读数，单位是**摄氏度（℃）**；比 0℃ 还低的温度叫**零下**，「零下 5 度」写的就是 −5℃。拖动液柱（或用滑杆、预置钮）设定温度甲和温度乙，再点「比一比」——页面会把两个温度投影回横着的数轴上，用位置判大小。注意那个常见误会：「5 比 1 大，所以 −5 比 −1 暖和」——等下用落点亲自拆穿它。 {#s1e .explain}

::: html step1-1
s1aLab: 温度甲（℃）
s1bLab: 温度乙（℃）
s1tuneLab: 预置钮给谁：
s1tuneA: 甲
s1tuneB: 乙
s1p5: 零上 5℃
s1pM1: 零下 1℃
s1pM5: 零下 5℃
s1cmp: 比一比
:::

拆穿误会：−5 里的「5」只说明它离 0 有 5 格，个头大不代表数大。负数比大小只看一件事：**在数轴上谁更靠左，谁就更小**。−5 在 −1 的左边，所以 −5 更小、更冷。这一招在整页通用：越往左越小，越往右越大。 {#s1hint .hint}

s1vEq: 两个温度落在数轴上的同一点——<b>一样高，也一样冷</b>。

## 电梯：地面之上与之下 {#step2 h2=s2t}

::: strings
nav2: 2 电梯与楼层
:::

第 2 步 · 位置也带符号 {#s2k .step-kicker i18n=text}

这一步要回答：**楼层能不能也是一根轴？地下的层用什么数记？**这栋楼把地面层定为 0（就像数轴的原点、温度计的 0℃），往上是 +1、+2、+3，往下是 −1、−2。商场里写的 **B1、B2** 就是地下层：B 是 basement（地下室），B1 就是 −1 层、B2 就是 −2 层。按上下行按钮，或直接点想去的楼层，看电梯穿过地面时层数怎么变。 {#s2e .explain}

::: html step2-1
s2nLab: 每次走几层
s2up: ▲ 上行
s2down: ▼ 下行
s2reset: 回到地面并清轨迹
:::

地面就是楼里的 0。电梯下行穿过 0 之后，层数变负——和温度跌破 0℃、数轴走到原点左边是**同一件事**：先定一个 0，一个方向记正、反方向记负，位置就能用带符号的数记下来。这一页只记位置和升降的结果，加减算式到第 3 步正式上轴。 {#s2hint .hint}

## 沿数轴走：加减就是走路 {#step3 h2=s3t}

第 3 步 · 加减就是走路 {#s3k .step-kicker i18n=text}

这一步要回答：**带负数的加减，答案落在哪？能不能不背规则，看着走出来？**规矩只有一条：**加法 = 向右走，减法 = 向左走**。设好起点、方向和步数，点「走 →」：小人逐格走完全程，走过的路线留下**轨迹**，最后停下的那一格叫**落点**。注意图上的原点（0 的位置）——走路时心里数着它，就不会迷路。 {#s3e .explain}

小演示：把「向左走」撤回 {#s3uTitle .subhead tag=h3 i18n=text}

::: html step3-2

同样的事换到温度上：预报说今晚降温 −2 度（先当成一句口语：要往下掉 2 度的意思），后来取消降温——「取消一次下降」就是回升。撤回一次反方向的动作，等于顺着正方向做同样多。至于把它写成算式法则，是初中才立的规矩，这一页只看现象、不背法则。 {#s3hint .hint}

## 负数是为「反方向」发明的 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

这一步要回答：**这一整页到底在讲一件事，还是三件事？**看下面三张小图：横着的数轴、立起来的温度计、装进楼里的电梯——同一根轴，穿了三件衣服。每一次，都是先定一个 0，再让一个方向记正、反方向记负。 {#s5e .explain}

::: html step5-1
s5fin: 一句话收束：**量有方向：先定一个 0，一个方向记正、反方向记负。**温度、楼层是这样记的，海拔（以海平面为 0）、收支（以不赚不赔为 0）也是这样记的。负数不是「欠着的数」，而是为「反方向」发明的记号——0 的另一边，一直都有数。
