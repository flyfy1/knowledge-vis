# BRIEF：负数——温度计与电梯，0 以下的世界（negative-numbers）· 小学数学

## 定位
- slug `negative-numbers`，category math，stage primary。受众：小学高年级 + 初中预备 + 家长。排在 fractions（分数也是数轴上的数）之后、division-remainder（数轴跳格）旁边：那两页的数轴只活在 0 的右边，本页把数轴向左补完。
- 核心直觉一句话：**负数不是「欠着的数」，而是方向与位置——以 0 为界，往左（往下）的量用带「−」的数记**。同一根轴穿三件衣服：横着是数轴、立起来是温度计、装进楼里是电梯。
- 已知：整数 0–100 的读写与加减、fractions 的数轴落点（一个数 = 轴上一个点）、division-remainder 的沿轴跳格。唯一新问题：0 的左边（下边）是什么？那种「反方向的量」怎么记、怎么比、怎么算？

## 步骤（每步五必填项；步 id 0 起：step0–step5）

### step0 数轴向左长：0 的另一边
- **已知**：数轴上 0–10 的刻度与落点（fractions 已学：一个数是轴上一个点）。
- **唯一问题**：0 的左边一个数也没有吗？往左的格子该写什么？
- **输入与求量**：输入 = 一条只有右半截的数轴（0–10）；求量 = 左半截每个刻度该记的数，以及它与右半截的对应关系。
- **控件操作与预期观察**：点「向左延伸」播放（或拖动延伸滑杆 0→10 格）：数轴一格一格向左长出 −1、−2、…、−10，每长出一格，与它关于 0 对称的右侧格子同步亮起一对（如 −3 与 3 同亮），并连一条对称弧线；播放带进度（已长出 k/10 格，轨迹保留不消失）。点选任意刻度，读数行给出「−3 在 0 的左边 3 格，和 3 离 0 一样远，方向相反」。**预期观察**：左边不是空的，是右边的镜像——每格都有对面的一个。
- **结论与适用条件**：0 右边的叫正数、左边的叫负数，0 既不是正数也不是负数；负号「−」记的是方向（在 0 的哪一边），不是「少了」。本页只讨论整数刻度，小数/分数的负数住在格与格之间，道理相同、本页不展开。

### step1 温度计：负数能比大小
- **已知**：step0 的左右位置关系；生活经验：天气有「零下」。
- **唯一问题**：−5 和 −1，哪个更冷？（靶子误解：「5 比 1 大，所以 −5 比 −1 大/暖和」。）
- **输入与求量**：输入 = 立式温度计（就是立起来的数轴，刻度 −10℃–+10℃，0℃ 处有醒目界线）；求量 = 两个温度谁高谁低，并说出凭什么。
- **控件操作与预期观察**：拖动液柱（或点预置钮：零上 5℃ / 零下 1℃ / 零下 5℃）设定温度甲，再设定温度乙，读数行实时给出两值；点「比一比」：温度计旁并排亮出两根液柱，并把两值投影回一条横数轴，落在左边的即更小。**预期观察**：−5 的落点在 −1 的左边，所以 −5 更小、更冷——比大小看的是位置（越往左越小），不是数字部分的个头。拖动过程中液柱连续升降、读数同步，投影点随之左右移动。
- **结论与适用条件**：负数比大小：在数轴上越往左越小，越往右越大；「−5 比 −1 冷 4 度」这类差值只陈述现象（两点相距 4 格），不在本步引入减法算式。温度范围限本页刻度 −10℃–+10℃。

### step2 电梯：地面之上与之下
- **已知**：step0/1 的「0 为界、两边记号相反」；生活经验：商场有地下停车场 B1、B2。
- **唯一问题**：楼层能不能也是一根轴？地下的层用什么数记？
- **输入与求量**：输入 = 一栋楼的剖面图（地面层记 0，往上 +1、+2、+3，往下 −1、−2，即 B1=−1、B2=−2）；求量 = 电梯停在哪一层（带符号的层数）。
- **控件操作与预期观察**：电梯初始停在地面 0。按「▲ 上行 n 层 / ▼ 下行 n 层」（n 由步数滑杆 1–5 设定）或直接点目标楼层，电梯沿剖面动画移动（经过的层逐层点亮、轨迹保留），读数行同步给出「现在在 −2 层（地下 2 层 B2）」。可连续多次升降，层数由当前层实算累加。**预期观察**：地面就是楼里的 0；下楼穿过 0 之后层数变负，和温度计穿过 0℃、数轴穿过原点是同一件事。
- **结论与适用条件**：位置可以用带符号的数记：先定一个 0（地面），一个方向记正、反方向记负。本步只记位置与升降的累计结果，不写加减算式（算式在 step3 上轴）。

### step3 沿数轴走：加减就是走路
- **已知**：step0 的数轴、step2 的升降累计；正数范围内的加减。
- **唯一问题**：带负数的加减，答案落在哪？能不能不背规则、看着走出来？
- **输入与求量**：输入 = 起点（−5…+5）与一次「走法」（方向：向右/向左；步数 1–8）；求量 = 落点。算式由页面按「起点、走法」拼出并回显（如 3 向左走 5 步，页面写出 `3 − 5 = −2` 等结果揭晓后补全）。
- **控件操作与预期观察**：设起点、选方向、定步数，点「走」：小人（或电梯图标）在数轴上逐格走完全程，走过的格子留轨迹带、落点旗标，读数行给出落点与完整算式。至少能走通四类：正数起点向左越过 0（3 − 5 = −2）、负数起点向右回到正数（−2 + 5 = 3）、负数起点继续向左（−1 − 4 = −5）、负数起点向右未越 0（−4 + 3 = −1）。
  - **「减去一个负数」只给生活直觉、不立规矩**：本步结尾设一个「撤回」小演示（独立小钮「撤回刚才的向左走」）：先让小人从 2 向左走 3 步到 −1（算式 2 − 3 = −1），点「撤回这 3 步左走」——小人沿原路向右走回，页面把这句话说完：「把一次向左走撤回，等于向右走同样多步」；温度计版口径在 hint 里补一句：「预报说今晚降温 −2 度，后来取消降温——『取消一次下降』就是回升。」**红线**：不出现 `a − (−b) = a + b` 的法则断言、不出这类计算题、不讲证明；只到「撤回反方向 = 顺正方向走」的生活现象，法则留给初中页。
- **结论与适用条件**：加法 = 沿轴向右走，减法 = 沿轴向左走，落点只由起点与走法决定，与先迈哪只脚无关；结论限整数步、单次走法（连续多次走法是把单次接起来，本页自测至多两步）。

### step4 自测（答对才揭晓，解析回扣对应步）
三题，数值固定、答案由页面逻辑实算判定（不得写死判定字符串）：
1. **读数题**（回扣 step1）：温度计图液柱停在 −4℃，四选一读数（−4℃ / 4℃ / −6℃ / 0℃），答对解析：「零下要带负号，液柱在 0 以下 4 格。」
2. **大小题**（回扣 step1）：「−7℃ 和 −3℃，哪个更冷？」二选一，解析回数轴位置：「−7 在 −3 的左边，更左更小、更冷。」
3. **走路题**（回扣 step2/3）：「电梯从 B2（−2 层）上行 5 层，停在哪层？」四选一（3 / −3 / 7 / 0），解析画出 −2 向右走 5 步的轨迹。
- 每题答对锁定该题、揭晓解析；答错给指向对应步的提示（不给答案）。答题后改前面各步的参数，不冲已锁定的判定（状态一致性红线）。

## 数据与判定口径（构建者必须照此实现，评审按此对账）
- 全页状态只有一个真源：各步的标记位置（数轴延伸格数 k、温度甲/乙、电梯当前层、走路的起点/方向/步数），所有读数（包括投影点、算式回显、层数）纯渲染自该状态，禁止第二套缓存口径。
- 温度计映射：液柱位置 ↔ 温度值由刻度线性映射实算（−10…+10），读数取整到 1℃；预置钮给定的就是整数值，不得出现 4.999 式浮点尾巴（取整后渲染）。
- 比较判定：甲 < 乙 ⟺ 甲的数轴落点在乙的左边，由数值实算，不得按字符串或绝对值判定——自查必须包含 −5 < −1、−1 < 0、0 < 3、−3 = −3 四组。
- 走路落点 = 起点 + 带符号步数（向右为 +、向左为 −），整数运算；自查断言至少 5 组：3−5=−2、−2+5=3、−1−4=−5、−4+3=−1、0−3=−3。
- 电梯层数 = 各次升降的带符号累计，自查断言：0 下行 2 → −2；−2 上行 5 → 3；3 下行 5 → −2（穿过 0）。
- 边界：温度拖到两端（−10/+10）、延伸滑杆 0 与 10、起点 ±5、步数 8 时落点可达 −13…+13——走路画布横轴范围须覆盖 −13…+13 并在 BRIEF 评审时确认不裁切（或落点越界时轴自动扩围，二选一，构建报告须写明选了哪种）。
- 自测答案以本节口径实算：题 1 −4℃、题 2 −7℃ 更冷、题 3 停在 3 层。
