这一步要回答：√2 在数轴上的位置在哪？边长 1 的正方形，对角线的平方 = 1² + 1² = 2（勾股定理），所以对角线长 √2。拖动旋转角：把这条对角线以原点为中心转到数轴上，笔尖落在的那个点，就是 √2 在数轴上的位置。 {#s0e .explain}

## √2 能写成两个整数的比 p/q 吗？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 不是分数
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 不是分数
:::

这一步要回答：能不能找到分数恰好等于 √2？**分数**就是 p/q（p、q 是整数，q ≠ 0）。设最大分母 N：对每个分母 q 找最接近的 p/q，取误差最小的。拖动 N：误差越来越小，却始终不为 0；这里还算出 p² − 2q²，分数恰好等于 √2 要求它等于 0，但它的绝对值总是至少 1。 {#s1e .explain}

::: html step1-2
s1cv: 分母上限 N 内最接近 √2 的分数，与误差
NN: 分母的上限 N
:::

这只是观察，不是证明；经典证明用奇偶性：若 p² = 2q² 则 p、q 都是偶数，约分后矛盾。 {#s1note .note i18n=text}

这一步要回答：不会开方，怎样得到 √2 的近似值？已知 1² = 1 < 2 < 2² = 4，所以 √2 在 1 和 2 之间。每次取中点 m，如果 m² < 2，说明 √2 在 m 右边，左端点移到 m；否则右端点移到 m。按“二分一次”，区间每次缩小一半，一行行累积在图上。 {#s3e .explain}
