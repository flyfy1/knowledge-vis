## 分糖果：分不完的那一颗 {#step0 h2=s0t}

::: strings
nav0: 0 分糖果
:::

第 0 步 · 钩子 {#s0k .step-kicker i18n=text}

这一步要回答：**一堆东西平均分，分不完怎么办？**先把四个名字在糖果里认清：要分的总数叫**被除数**，分给几个人叫**除数**，每人分到的颗数叫**商**，最后剩下的叫**余数**。下面有 17 颗糖、4 个小朋友，一颗一颗轮流发——你来当发糖的人，发到发不下去为止。 {#s0e .explain}

::: html step0-1
s0totalLab: 糖的总数（被除数）
s0peopleLab: 分给几个人（除数）
s0deal1: 发一颗
s0play: 连播分发
s0reset: 重新分
:::

先记住分工：**商回答「每人几颗」，余数回答「还剩几颗」**。还有一件怪事：不管总数怎么改，余数总是比人数小。把滑杆顶到 30 颗、2 个人试试——余数最多也只有 1。这不是巧合，下一步专门看它。 {#s0hint .hint}

::: html step0-2
start: 开始探索 ↓
:::

## 余数为什么必须比除数小 {#step1 h2=s1t}

::: strings
nav1: 1 余数要比除数小
:::

第 1 步 · 分完的判据 {#s1k .step-kicker i18n=text}

这一步要回答：**分到什么程度，才算「分完了」？**先看一个偷懒的分法：17 颗糖分给 3 个人，每人才分 4 颗就收手，托盘里还剩 5 颗。剩 5 颗算分完吗？拖动「每人先分几颗」（这个数就是**商**），让余数自己说话：只要剩下的还够给每人再发 1 颗，就不算分完。 {#s1e .explain}

::: html step1-1
s1totalLab: 糖的总数（被除数）
s1divLab: 分给几个人（除数）
s1perLab: 每人先分几颗（商）
s1fix: 一键补分到分完
:::

所以「余数 &lt; 除数」不是老师定的规矩，而是**「分完了」的判据**：余数一旦大于或等于除数，就说明还能再分一轮，商就该再加 1。验算任何除法，先看这一条。 {#s1hint .hint}

::: strings
s1roMore: 账本：<b>{n} = {d} × {per} + {r}</b>。余数 <b>{r}</b> 比除数 <b>{d}</b> 还大——托盘里还够给每人再发 1 颗，<b>还没分完！</b>把商往上拖，或点「一键补分」。
s1roEqual: 账本：<b>{n} = {d} × {per} + {r}</b>。余数 <b>{r}</b> 正好等于除数 <b>{d}</b>——没有比除数小，托盘里还够给每人再发 1 颗，<b>还没分完！</b>把商往上拖，或点「一键补分」。
s1roDone: 账本：<b>{n} = {d} × {q} + {r}</b>。余数 <b>{r}</b> &lt; 除数 <b>{d}</b>：剩下的不够每人再发 1 颗了，这才叫分完。
s1roExact: 账本：<b>{n} = {d} × {q} + 0</b>。正好分完，余数是 0——0 当然也小于除数。
cTrayR: 托盘里还剩 {r} 颗（余数）
cGhost: 还能再给每人发 1 颗！
cDone: 分完了 ✓ 余数 < 除数
:::

## 除法是数轴上的跳格 {#step2 h2=s2t}

::: strings
nav2: 2 数轴跳格
:::

第 2 步 · 换一个看法 {#s2k .step-kicker i18n=text}

这一步要回答：**换个问法——总数里一共装着几个除数？**还是第 0 步的那组数：从 0 出发，每一格跳一个除数那么远，跳满一格算装下一个。跳到再跳就会越过总数为止，看最后停在哪、还差多少。 {#s2e .explain}

::: html step2-1
s2totalLab: 总数（被除数）
s2divLab: 每格跳多远（除数）
:::

这一步的两个滑杆——「总数（被除数）」和「每格跳多远（除数）」——和第 0 步是同一组数：改这里，第 0 步的分糖果也跟着变——两边永远在算同一道题。 {#s2shareNote .hint}

::: html step2-2
s2jump: 跳一格
s2play: 连播
s2reset: 重来
:::

::: strings
s2pause: 暂停
s2roIdle: 从 0 开始，每格跳 <b>{d}</b> 远。看 <b>{n}</b> 里面能跳满几格。点「跳一格」或「连播」。
s2roMid: 已跳 <b>{k}</b> 格，落在 <b>{pos}</b>；目标是 <b>{n}</b>，还能再跳。
s2roDone: <b>{n} = {d} × {q} + {r}</b>：跳满 <b>{q}</b> 格停在 {qd}，还剩 <b>{r}</b>——不够再跳一整格（还差 {need}）。商还是 {q}，余数还是 {r}，和第 0 步分糖果一模一样。
s2roExact: <b>{n} = {d} × {q}</b>：跳满 <b>{q}</b> 格正好落在 {n}，余数 0。
s2hint: 同一个除法，两种问法：分糖果问「每人几颗」，跳格问「总数里有几个除数」——答案的商和余数完全相同。跳格还是乘法的逆运算：跳 {q} 格 × 每格 {d} = {qd}，正是把行列合成总数那件事倒着走。乘法怎么「合」，去 <a class="fourier-link" href="../area-model/#step1">乘法是面积 · 第 1 步（点阵变地砖）</a> 看。

## 100 天后是星期几？ {#step3 h2=s3t}

::: strings
nav3: 3 星期推算
:::

第 3 步 · 余数有用 {#s3k .step-kicker i18n=text}

这一步要回答：**余数能拿来干什么正事？**今天星期二。往后数 100 天是星期几——一天天数太累，但星期是 7 天一循环：每过整整 7 天，星期几原地不变。所以只需把 100 拆成「几个整周 + 余数几天」，**只有余数决定答案往后挪几格**。拖动滑杆换天数，看落点怎么跳。 {#s3e .explain}

::: html step3-1
s3daysLab: 往后数几天
s3quickLab: 试几个：
:::

凡是「转圈」的问题都只看余数：星期（7 一圈）、钟表（12 一圈）、轮班、座位绕圈……先除以圈长，商是转了几圈，**余数才是落点**。 {#s3hint .hint}

::: strings
s3ro: <b>{n} 天 = 7 × {w} + {r}</b>：{w} 个整周过去，星期纹丝不动；再往后数 {r} 天，从星期二挪到 <b>{ans}</b>。决定答案的只有余数 {r}。
s3ro0: <b>{n} 天 = 7 × {w} + 0</b>：正好 {w} 个整周，余数 0——还是<b>星期二</b>。

:::

## 自测：分物与验算账本 {#step4 h2=s4t}

::: strings
nav4: 4 自测 · 验算账本
:::

第 4 步 · 自测 {#s4k .step-kicker i18n=text}

最后自己上手。两道题共用同一本账：**被除数 = 除数 × 商 + 余数，并且余数 &lt; 除数**。每道题都要答对才会揭晓解析；答错了，账本会指出错在哪一条。上面那块板就是账本本身——答对一题，它就填满一题。 {#s4e .explain}

::: html step4-1
s4q1: ① 23 本书，平均分给 5 个小朋友。每人分几本？还剩几本？
s4q1a: 每人 4 本，剩 3 本
s4q1b: 每人 5 本，剩 2 本
s4q1c: 每人 3 本，剩 8 本
s4q2: ② 验算题：☆ ÷ 6 = 7 …… 4。被除数 ☆ 是多少？
s4fin: 这一页从头到尾只有一本账：**被除数 = 除数 × 商 + 余数，余数 &lt; 除数**。分糖果、数轴跳格、推算星期，全是这本账的不同讲法；拿到任何一道除法，先写账，再验账，就不会被余数骗了。
lkArea: ← 回上一站：乘法是把行列「合」成总数（乘法是面积 · 第 1 步）——除法正是把它拆开
lkFrac: 分不完的那 1 颗还有下文：把它切开来分，就是分数——17 ÷ 4 = 4¼（分数 · 第 5 步）→
:::

::: strings
s4q1ok: 答对了！账本：<b>23 = 5 × 4 + 3</b>，余数 3 &lt; 人数 5——分完了，这就是答案。
s4q1fbB: 不对，用账本查：5 人 × 每人 5 本 = 25 本，可是书一共只有 23 本——<b>除数 × 商不能超过被除数</b>。这个选项直接不够分。
s4q1fbC: 不对，用判据查：剩 8 本比人数 5 还多，还够给每人再发 1 本——<b>没分完，余数必须小于除数</b>。
s4q2ok: 答对了！<b>被除数 = 除数 × 商 + 余数 = 6 × 7 + 4 = 46</b>。验算题不用猜，把账本倒着算一遍就行。
s4q2fbA: 42 = 6 × 7，只算了「整除的那部分」——别忘了账本最后还有 <b>+ 余数 4</b>。
s4q2fbC: 52 对不上账本：6 × 7 + 4 = <b>46</b>。把候选答案代回 被除数 = 除数 × 商 + 余数 验一遍，错的立刻露馅。
s4allDone: 两题都答对了——你已经能拿着账本自己验算任何一道除法题了。
