## 一个箭头，怎样用两个数写下来？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 箭头与分量
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 大小加方向
:::

这一步要回答：怎样用数描述“朝某个方向走多远”？**向量**既有大小又有方向，画成箭头。起点放在原点，终点坐标 (aₓ, a_y) 就是它的**分量**：向右走 aₓ，再向上走 a_y。长度（**模**）由勾股定理给出 |a| = √(aₓ² + a_y²)，方向角是与 x 轴正方向的夹角。**观察：**拖动两个分量：橙色箭头变化，青色和绿色虚线是水平、竖直两段；读数给出模和方向角。同一支箭头可以平移而不变，只要大小和方向不变。 {#s0e .explain}

::: html step0-2
s0cv: 橙色箭头 a 与它的水平分量（青）、竖直分量（绿）
axL: a 的水平分量 aₓ
ayL: a 的竖直分量 a_y
:::

## 两个向量合在一起，结果是哪个箭头？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 向量加法
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 首尾相接
:::

这一步要回答：两个向量相加是什么意思？把 b 的起点放在 a 的终点（**首尾相接**），从 a 的起点指向 b 的终点的箭头就是 a + b（绿色）；也可以画成平行四边形，两种画法结果相同。用坐标算，更简单：a + b = (aₓ + bₓ, a_y + b_y)，分量各自相加。**观察：**拖动 a 和 b 的分量，绿色和读数里的坐标始终一致；总有三角不等式 |a+b| ≤ |a| + |b|，只有两箭头同向时才取等号。这正是几个力的合成的做法（见[[newton-laws#step2|牛顿定律]]里的合力）。 {#s1e .explain}

::: html step1-2
s1cv: 首尾相接：a（青）接着 b（橙），合向量 a + b（绿）；虚线补成平行四边形
bxL: b 的水平分量 bₓ
byL: b 的竖直分量 b_y
:::

::: strings
s0ro: a = ({x}, {y})：模 |a| = √({x}² + {y}²) = {m}；方向角 {an}°。
yes: 成立
no: 不成立

:::

## 一个向量乘一个数，或者两个向量相减，是什么意思？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 数乘与减法
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 拉长、反向、相减
:::

这一步要回答：向量还能做什么运算？**数乘** k·a：箭头的长度变成 |k| 倍，k &gt; 0 同向，k &lt; 0 反向，k = 0 变成零向量。**相减** a − b 就是 a + (−b)：把 b 反过来再相加；结果是从 b 的终点指向 a 的终点的箭头（紫色虚线是 −b 的接法）。这里的 a、b 就是上一步滑杆设定的向量。**观察：**拖动 k：橙色箭头沿 a 所在直线伸缩、k 为负时翻到反方向；绿色 a − b 的坐标是各分量相减。 {#s2e .explain}

## 点积为什么能告诉你两个箭头夹角是锐角还是钝角？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 点积
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 两个箭头的“相像程度”
:::

这一步要回答：怎样把两个向量变成一个数，来反映它们有多同向？**点积** a·b = |a||b|cosθ（θ 是夹角），用坐标算就是 aₓbₓ + a_yb_y。它等于“b 在 a 方向上的**投影**长度（绿色粗线）乘以 |a|”。夹角小于 90° 点积为正，等于 90°（**垂直**）为 0，大于 90° 为负。这里 a = (4, 0)，|b| = 3，只改夹角。**观察：**拖动夹角：绿色投影越来越短，到 90° 缩成 0（垂直），再变成负；读数里用两种公式算出的点积完全一样。 {#s3e .explain}

::: html step3-2
s3cv: 固定 a（青）、可转动的 b（橙）与 b 在 a 上的投影（绿）
angL: a 与 b 的夹角 θ（°）
:::

::: strings
projLab: 投影
acute: 夹角是锐角，点积为正
perp: 垂直，点积为 0
obtuse: 夹角是钝角，点积为负
s3ro: θ = {ang}°：a·b = |a||b|cosθ = {mm}；用坐标 aₓbₓ + a_yb_y = {comp}；b 在 a 上的投影坐标 {p}。{kind}。
:::

## 一块重物挂在两根绳上，每根绳要多大的拉力？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 绳子受力
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 用向量解题
:::

这一步要回答：怎样用向量求平衡时的力？重物受三个力：重力 W 向下，两根绳的拉力 T₁、T₂（各沿绳的方向）。**平衡**意味着合力为零：T₁ + T₂ + W = 0，三个箭头首尾相接围成一个封闭的三角形（右上角的小图）。水平方向两根绳的分量互相抵消；竖直方向两根绳的分量之和等于 W，即 2T·sinθ = W，所以 T = W/(2 sinθ)。**观察：**拖动绳与水平线的夹角 θ：绳越平，拉力越大——θ 接近 0 时拉力趋向无穷，这就是为什么绳子拉得再紧也不可能完全水平；读数验算水平、竖直方向的合力为 0。 {#s4e .explain}

::: html step4-2
s4cv: 三个力 T₁（青）、T₂（橙）、W（红）作用在一点；右上小图是首尾相接成封闭三角形
wtL: 重物的重量 W（N）
thL: 绳与水平线的夹角 θ（°）
:::

::: strings
closed: 首尾相接，闭合
flat: 夹角很小，拉力已远大于重物重量

## 船怎样才能垂直过河，而不被冲到下游？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 过河
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 相对速度
:::

这一步要回答：船的实际速度怎么算？船相对水的速度 v船（4 m/s，橙）与水流速度 v水（2 m/s，向右，青）相加，得到相对河岸的实际速度（绿）：v实 = v船 + v水，这就是向量加法。船头与垂直河岸方向的夹角为 θ，向上游偏为正。河宽 60 m。**观察：**拖动 θ：θ = 0（船头垂直对岸）时绿色箭头向右偏，到对岸被冲下游；把船头向上游偏，当 sinθ = v水/v船 = 0.5（θ = 30°）时，水平分量刚好抵消，船垂直过河，但过河时间变长；θ 超过 30° 船会被推向上游。读数给出过河时间和被冲走的距离。 {#s5e .explain}

recap3: 力的平衡是合力为零（三角形闭合），相对速度是向量加法：v实 = v船 + v水。
