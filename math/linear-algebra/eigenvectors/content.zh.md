## 圆被捏成椭圆，只剩两个方向没转 {#step0 h2=s0t}

::: strings
nav0: 0 圆变椭圆
:::

第 0 步 · 钩子 {#s0k .step-kicker i18n=text}

单位圆上均匀插着 20 根箭头。让矩阵 A 作用一次：圆被捏成椭圆，箭头们普遍被**转走**了——但盯住橙色和粉色的那两对箭头：它们只变长、变短，**方向一条直线没偏**。拖动滑杆，把这场变形在「圆」和「椭圆」之间来回推。整个空间都被拧动了，为什么偏偏这两个方向纹丝不转？这一页就查它们。 {#s0e .explain}

## 转动输入箭头，找出不偏离原直线的方向 {#step1 h2=s1t}

第 1 步 · 亲手实验 {#s1k .step-kicker i18n=text}

青色 v 是输入箭头，橙色 Av 是矩阵变换后的箭头。拖图中的箭头，或调下方方向滑杆：看橙箭头有没有偏离穿过 v 的虚线。粉色短线连接这条直线与 Av 的尖端，表示**偏离原直线的部分**。让它缩小，再判断方向是否共线。**反向也算共线**：此时伸缩比例为负，称为负特征值。本图不是运动轨迹，方向角不是时间。 {#s1e .explain}

## 四个数随便调，λ 当场改命 {#step2 h2=s2t}

::: strings
nav2: 2 λ 的性格
:::

第 2 步 · 特征值的性格 {#s2k .step-kicker i18n=text}

这一站把矩阵的四个数 a、b、c、d 全交给你。λ₁、λ₂ 和两条特征方向线实时重算，旁边并排摆着两条**恒等式**：λ₁ + λ₂ 必须等于迹 tr A = a + d，λ₁λ₂ 必须等于行列式 det A——误差在 10⁻¹⁵ 量级，是浮点数最后的倔强。挨个点一遍预设巡演：**负特征值**把箭头翻过去；**两个 λ 都小于 1** 时圆整体缩水；**剪切矩阵**只有一个特征方向（重根、亏损，老实只画一条）；**旋转缩放**判别式小于零，实特征方向**压根不存在**——λ 是一对共轭复数，页面绝不画假方向给你，只给你看真实行为：一圈一圈的螺旋。 {#s2e .explain}

s2spiralStep: 下一步

s2qShear: 剪切：重根亏损

## 乘上一百次，主方向自己浮出来 {#step3 h2=s3t}

::: strings
nav3: 3 幂迭代
:::

第 3 步 · 幂迭代 {#s3k .step-kicker i18n=text}

不知道特征向量在哪没关系——有个笨办法：拿任意向量反复乘 A。每乘一次，结果就朝主特征方向（|λ| 最大的那个）**贴近一点**，因为沿主方向的分量每步放大 |λ₁| 倍，其余分量只放大 |λ₂| 倍，相对差距以 **|λ₂/λ₁|** 的倍率逐歩拉开。用滑杆把 λ₂/λ₁ 从 0.33 推到 0.95：两个特征值越接近，贴近得越慢，误差曲线拖出长长的尾巴。再点「等模反例」：λ₂ = −λ₁ 时两个分量谁也压不倒谁，向量在两个方向之间**永远横跳、永不收敛**——幂迭代的失效情形，页面如实标出，绝不假装收敛。 {#s3e .explain}

::: html step3-1
s3formula: x ← Ax / |Ax|，反复迭代 —— x 逐歩贴向 |λ| 最大的特征向量
s3chartT: 夹角误差随步数衰减（对数纵轴）
s3rLab: λ₂/λ₁ 之比 r（λ₁ = 2，方向固定 35°）
s3pFast: r = 0.33 快
s3pSlow: r = 0.90 慢
s3pSlower: r = 0.95 更慢
s3pFail: 等模反例 λ₂ = −λ₁
s3rand: 随机起点

误差每步大约乘上 |λ₂/λ₁|——这就是为什么 r = 0.95 的尾巴那么长：0.95¹⁰⁰ 还剩 0.006。数值库和谷歌的 PageRank 找的特征向量，主力正是这个幂迭代（配上各种加速技巧）。终章你会再见到它一次。 {#s3hint .hint}

## 主轴、正交与对角化：峡谷的真身 {#step4 h2=s4t}

::: strings
nav4: 4 主轴与对角化

第 4 步 · 对称矩阵 {#s4k .step-kicker i18n=text}

对称矩阵（b = c）有一条特权：**总可选出一对互相垂直的特征向量**（两个特征值不同时，特征向量自动互相垂直，别无选择；特征值相等的重根情形，同一个特征值名下是一整片平面，照样能从中挑出一对垂直的来）。图上叠的是二次型 xᵀAx 的等高线椭圆——还记得梯度下降页第 2 步的峡谷吗？椭圆的长轴、短轴，恰好就是两个特征方向；条件数 κ = λmax/λmin 就是峡谷的长宽比，特征值在这里正式以真身出场。点「转到特征坐标系」：整个画面转过 θ 角，让特征方向与坐标轴对齐，再看矩阵的读数——**交叉项消失**，A 在新坐标里变成对角阵 Λ，而重构 QΛQᵀ 与 A 的逐元误差是 10⁻¹⁶ 量级：对角化不是近似，是恒等式。 {#s4e .explain}

## 方差最大的方向，就是最大特征向量 {#step5 h2=s5t}

::: strings
nav5: 5 主成分
:::

第 5 步 · 数据的主成分 {#s5k .step-kicker i18n=text}

一团拉长的数据点（60 个，固定随机种子生成，已减去均值中心化）。拖动那根过原点的轴，读数是数据沿这根轴投影的**样本方差**（协方差口径：除以 n − 1，本步全文统一）——转到不同方向，方差随之涨落，涨到最大的那个方向，恰好是协方差矩阵的**最大特征向量**。点「显示主成分」让它自己对齐：第一主成分捕获的方差占比 = λ₁/(λ₁ + λ₂)，第二主成分与它垂直、由 λ₂ 管。把数据换到这对新轴上、再把小轴扔掉，数据就被压缩了——这就是 PCA（主成分分析）的全部本体。 <a class="fourier-link" href="../../../signal/control/kalman/#step5">这条主方向在卡尔曼里怎么用：只测位置估速度 →</a> {#s5e .explain}

::: html step5-1
s5formula: 协方差 C = (1/(n−1)) Σ pᵢpᵢᵀ，C 的特征向量 = 主成分方向，特征值 = 沿该方向的方差
s5show: 显示主成分
:::

为什么方差最大的方向值得当「主成分」？因为数据沿这个方向铺得最开、信息最密，扔掉垂直方向的小方差，损失的信息最少。照片压缩、人脸识别（特征脸 eigenfaces）、金融风险因子——背后都是这一步的协方差特征分解。 {#s5hint .hint}

## 稳态：λ = 1 的特征向量，与谷歌的起点 {#step6 h2=s6t}

::: strings
nav6: 6 终章 · 稳态
:::

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

最后一站，一张 4 个节点的小网：A、B、C、D 互相指着箭头。想象每个节点上站着一群人，每一步，每个人都沿出箭头**均匀随机**地走到下个节点——这就是马尔可夫链，转移矩阵 M 的每一列写明「从这一列的节点出发，落到各行的概率」，所以**每列之和必须恰好是 1**（人不会凭空消失）。从任意初始分布出发，反复乘 M：分布一步步变，最后**冻住不动**——冻住的分布 π 满足 Mπ = π，它正是 M 的一个特征向量，特征值恰好 λ = 1。点「换初始分布」再跑：起点天差地别，终点分毫不差。谷歌的 PageRank 就是把整个互联网当成这张图：稳态分布即网页排名（真实 PageRank 还加了阻尼：每步以 0.15 的概率随机跳到任意页，公式 π ← 0.85·Mπ + 0.15/N，保证链一定收敛；本页的小网本身可达且无周期，不加阻尼也收敛）。 {#s6e .explain}
