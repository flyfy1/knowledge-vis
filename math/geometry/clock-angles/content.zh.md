## 分针和时针每分钟各转多少度？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 谁转得快
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 谁转得快
:::

这一步要回答：两根针的转速是多少？钟面一圈是 360°。拖动滑杆让时间流逝（从 12:00 起的分钟数）：分针转一圈 60 分钟，所以每分钟转 360° ÷ 60 = 6°；时针转一圈 12 小时 = 720 分钟，每分钟转 360° ÷ 720 = 0.5°。图上的弧线是各自从 12 点位置起转过的角度。 {#s0e .explain}

::: html step0-2
s0cv: 钟面和两根指针转过的角度
elapsed: 12:00 之后的分钟数
:::

::: strings
s0ro: 时间 {time}（过了 {t} 分钟）：分针转过 {mb}°（6° × {t} 再减整圈），时针转过 {hb}°（0.5° × {t}）。
:::

## 几点几分，两针之间夹多少度？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 读夹角
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 读夹角
:::

这一步要回答：给定 h 时 m 分，两针夹角是多少？时针角度 = 30° × h + 0.5° × m（每个整点 30°，再随分钟慢慢走），分针角度 = 6° × m。夹角取两者之差，如果超过 180° 就用 360° 减去它（取较小的那个夹角）。 {#s1e .explain}

::: html step1-2
s1cv: 某一时刻的钟面与夹角
hour: 时
minute: 分
:::

::: strings
s1ro: {time}：时针 {hb}°，分针 {mb}°，差 {raw}°，所以较小夹角 = {ang}°。
:::

## 分针追上时针，12 小时里追上几次？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 两针重合
:::

::: html step3-1

这一步要回答：两针什么时候重叠？分针每分钟追上时针 5.5°，要追上一整圈 360° 需要 360 ÷ 5.5 ≈ 65.45 分钟，所以重合不在整点。按“开始”让时间自动流逝，每经过一次重合，下方时间轴上的标记就点亮并计数；也可用滑杆直接跳到第 k 次重合。 {#s3e .explain}
