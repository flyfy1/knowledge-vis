## 同一个圆锥，用平面切出来的截口会是什么形状？ {#step0 h2=s0t}

::: strings
nav0: 0 四种切法
:::

第 0 步 · 四种切法 {#s0k .step-kicker i18n=text}

这一步要回答：把一个圆锥用一个平面切开，切口曲线是什么，由什么决定？图上是圆锥的侧面（轴竖直，半顶角 α = 30°）和一块平面（侧面看是一条线）。设平面与轴的夹角为 φ：φ = 90° 切口是**圆**；φ 比 α 大但小于 90° 是**椭圆**；φ = α（平面平行于圆锥的一条母线）是**抛物线**；φ 比 α 小是**双曲线**（会同时切到上下两半圆锥）。拖「平面与轴的夹角 φ」，看左边平面转动，右边切口形状变化。 {#s0e .explain}

::: html step0-1
s0stage: 左：圆锥侧面（虚线是轴）与切平面（橙线）；右：这个平面切出来的截口曲线（形状按 e = cos φ ÷ cos α 画，大小不代表真实位置）
s0canvas: 圆锥与切平面：平面转动时，截口依次是圆、椭圆、抛物线、双曲线
s0phi: 平面与轴的夹角 φ
:::

结论：切口形状只由角度决定——φ 从 90° 减小，依次是圆（e = 0）、椭圆（0 < e < 1）、抛物线（e = 1）、双曲线（e > 1）。条件：平面不过圆锥顶点；过顶点时会退化成点或直线。截口大小取决于平面位置，本页不模拟。 {#s0result .readout i18n=text}

::: strings
s0ro: φ = {phi}°，圆锥半顶角 α = 30°：切口是{kind}，离心率 e = cos φ ÷ cos α = {e}。
:::

## 有没有一个数，能一口气分清这几种曲线？ {#step1 h2=s1t}

::: strings
nav1: 1 离心率 e
:::

第 1 步 · 离心率 e {#s1k .step-kicker i18n=text}

这一步要回答：能不能用一条统一的规则同时定义圆、椭圆、抛物线和双曲线？规则是：平面上到一个定点（**焦点** F）的距离，与到一条定直线（**准线**）的距离之比等于常数 e 的点，连成的曲线。这个常数 e 叫**离心率**。拖 e，看曲线从圆变椭圆、抛物线、双曲线；拖「点的位置」，读两段距离的比，验证它始终等于 e。 {#s1e .explain}

::: html step1-1
s1stage: 平面：红点是焦点 F，竖直虚线是准线，橙点 P 在曲线上；青线 PF 和粉线 PD（到准线的垂线段）的长度之比就是 e
s1canvas: 焦点、准线和曲线上的一个点：到焦点与到准线的距离之比恒等于离心率
s1elab: 离心率 e
s1p: 点 P 的位置
:::

结论：e = 0 是圆，0 < e < 1 椭圆，e = 1 抛物线，e > 1 双曲线；比值对曲线上每个点都一样。条件：本页固定半通径 ℓ = 1 来定尺度；e = 0 时准线在无穷远，曲线是以焦点为圆心的圆。 {#s1result .readout i18n=text}

::: strings
s1ro: e = {e}：{kind}；此刻 |PF| = {pf}，|PD| = {pd}，|PF| ÷ |PD| = {ratio}。
:::

## 用一根线、两颗图钉，怎样画出椭圆？ {#step2 h2=s2t}

::: strings
nav2: 2 两个焦点
:::

第 2 步 · 两个焦点 {#s2k .step-kicker i18n=text}

这一步要回答：椭圆和双曲线为什么有「两个焦点」，它们的定义是什么？**椭圆**：到两个焦点 F₁、F₂ 的距离之和等于定值 2a；**双曲线**：到两焦点的距离之差的绝对值等于定值 2a。设焦距的一半为 c，当 c < a 是椭圆，c > a 是双曲线，其中 b² = |a² − c²|。拖 a 和 c，再拖「点的位置」，读两段距离之和（或差）；曲线会被点走过的轨迹一点点描出来。 {#s2e .explain}

::: html step2-1
s2stage: 平面：两个红点是焦点，橙点 P 沿曲线移动，青线是 PF₁，粉线是 PF₂；黄色小点是 P 走过的位置（轨迹），淡线是整条曲线
s2canvas: 两个焦点与曲线上的点：椭圆上 PF₁ + PF₂ 恒为 2a，双曲线上 |PF₁ − PF₂| 恒为 2a
s2a: 半长轴 a（定值的一半）
s2c: 焦距的一半 c
s2tlab: 点 P 的位置
s2clear: 清除轨迹
:::

结论：椭圆是「两距离之和为定值」，双曲线是「两距离之差为定值」；c = 0 时两个焦点重合，椭圆成圆。条件：只画椭圆和双曲线的右支（左支关于 y 轴对称）；c 接近 a 时曲线退化。 {#s2result .readout i18n=text}

::: strings
s2ro: {kind}：a = {a}，c = {c}，b = {b}；|PF₁| = {d1}，|PF₂| = {d2}，{op} = {val}（2a = {a2}）。
s2sum: 距离之和
s2diff: 距离之差的绝对值
s2deg: 退化：c 与 a 几乎相等，曲线缩成线段或射线。
:::

## 为什么卫星天线是抛物面，椭圆形的房间里一个焦点的耳语会在另一个焦点听到？ {#step3 h2=s3t}

::: strings
nav3: 3 反射的秘密
:::

第 3 步 · 反射的秘密 {#s3k .step-kicker i18n=text}

这一步要回答：光线打到圆锥曲线形状的镜面上，会往哪里反射？**反射**的规则是入射角等于反射角（相对曲线在该点的切线）。抛物线有一个神奇性质：平行于轴的光线，反射后全部经过焦点；椭圆则是：从一个焦点射出的光线，反射后经过另一个焦点。选镜面，拖「光线」，打开「画多条光线」，看它们怎样聚到焦点。 {#s3e .explain}

::: html step3-1
s3stage: 镜面（粗线）和光线：绿色是入射光，橙色是反射光；红点是焦点；读数给出反射光线与焦点的距离
s3canvas: 抛物线镜面把平行光聚到焦点，椭圆镜面把一个焦点的光聚到另一个焦点
s3mode: 镜面形状
s3r: 光线
s3many: 画多条光线
:::

结论：抛物面把平行光聚到焦点（反过来，焦点处的光源变成平行光，如手电筒和车灯），椭圆把一个焦点的光送到另一个焦点。条件：理想镜面、二维截面；本页数值用曲线的隐式方程求法线，不是画出来的巧合。 {#s3result .readout i18n=text}

::: strings
s3ro: {mode}：光线在 ({x}, {y}) 处反射；反射光线到焦点的距离 = {miss}（应接近 0）；入射角与反射角相差 {dang}°。
:::

## 拿到一个二次方程，怎么不画图就知道它是哪种曲线？ {#step4 h2=s4t}

::: strings
nav4: 4 从方程认曲线
:::

第 4 步 · 从方程认曲线 {#s4k .step-kicker i18n=text}

这一步要回答：方程 Ax² + Bxy + Cy² + Ey = 1 对应哪种曲线？看**判别式** Δ = B² − 4AC：Δ < 0 是椭圆（A = C 且 B = 0 时是圆），Δ = 0 是抛物线，Δ > 0 是双曲线；有时是退化情形（两条平行线或没有图形）。拖 A、B、C、E，对比读数里的 Δ 和图上真正画出的曲线。 {#s4e .explain}

::: html step4-1
s4stage: 方程 A·x² + B·xy + C·y² + E·y = 1 的图像（−4 到 4 的方格内）；读数给出判别式 Δ 与类型
s4canvas: 二次方程的图像：判别式的符号决定曲线是椭圆、抛物线还是双曲线
s4a: 系数 A
s4b: 系数 B（xy 项）
s4c: 系数 C
s4elab: 系数 E（y 的一次项）
s4reset: 恢复默认（圆 x² + y² = 1）
:::

结论：二次项 Ax² + Bxy + Cy² 的判别式 B² − 4AC 决定曲线家族；B ≠ 0 表示曲线的轴不平行于坐标轴。条件：本页只含 y 的一次项 E；一般方程还有 x 的一次项，平移后同样分类。抛物线需要 B = 0 且 C = 0 或类似的完全平方形式，并且一次项不能「沿着」平方的方向。 {#s4result .readout i18n=text}

::: strings
s4ro: A = {a}，B = {b}，C = {c}，E = {e}：Δ = B² − 4AC = {d}，判定：{kind}。{note}
s4noReal: 图上没有曲线：方程在当前范围内没有实数解（比如 A、C 都取负号时）。
s4rot: xy 项使曲线整体旋转了。
s4none: ""
:::
