# BRIEF：圆周角定理（circle-angles）· 初中数学

## 定位
- slug `circle-angles`，category math，stage junior。受众：初中生（圆的第一课之后）+ 自学补课者。接 pythagoras（直角与判角）之后，与 symmetry-rotation（圆的无数条对称轴）隔页呼应。
- 核心直觉一句话：**站在圆周上看同一段弧，张角只有站在圆心看的一半——而且你站在圆周的哪个位置（同一段弧上）都一样；换到另一段弧上，角立刻变成它的补角**。圆心角是「圆心视角」，圆周角是「圆周视角」，两者被同一段弧锁死成 2:1。
- 已知：圆、半径、角的度量、等腰三角形两底角相等、三角形外角等于不相邻两内角之和（第 2 步证明前会在图上就近回收，不假设学生记得牢）。唯一新问题：圆周上一点对一段弧的张角，和圆心对同一段弧的张角，是什么关系、为什么？

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件；步骤 id 0 起：step0…step6）
1. **先认部件（step0）**：已知圆与角的基本概念；唯一问题：圆心角和圆周角到底差在哪——各自的顶点站哪、两边踩着谁？输入：画布上固定的圆 O、弦 AB 与圆周上一点 P；求量：无计算，先把命名认全。控件：拖动 P 沿圆周走（另有「P 的位置角」滑杆等价入口），P 走到哪，图上部件名牌跟到哪——圆心 O、半径 OA/OB、弦 AB、弧 AB（劣弧高亮）、圆心角 ∠AOB（顶点在圆心）、圆周角 ∠APB（顶点在圆周上、两边是弦 PA/PB）；读数行只报两个角的当前实测值（几何实算，见判定口径），先不下结论。结论适用条件：本页只谈平面圆；圆周角的两边必须是弦（顶点不在圆周上、或边不是弦的角不算圆周角，第 4 步边界处回收）。
2. **拖点实验：角纹丝不动（step1）**：已知第 0 步部件；唯一问题：P 在同一段弧上乱跑，∠APB 变不变？它和 ∠AOB 是什么倍数关系？输入：A、B 固定（圆心角先给 80°），变量是 P 在优弧上的位置；求量：∠APB 的实测值与 ∠AOB/2 的差。控件：拖 P 满优弧跑 + 位置角滑杆；读数行并排三项——圆心角 ∠AOB（不动）、圆周角 ∠APB（实算）、∠AOB 的一半；「记一笔」按钮把当前 P 位置与两个角记进账本（至少记 3 笔不同位置），账本里每笔的差都应 ≈0。再给「换圆心角」滑杆（40°–160°）改 ∠AOB 重复实验：P 的角立刻跟着变、仍是一半。预期观察：P 怎么跑，圆周角读数纹丝不动；圆心角一改，圆周角同步改、倍数不动。结论：**同弧所对的圆周角相等、且等于圆心角的一半**；适用条件：P 必须始终在同一段弧（优弧）上——换弧会发生什么，第 4 步专门处理，本步不许提前宣称「任意位置都一样」。
3. **为什么：一刀拆开（step2，证明步）**：已知等腰三角形底角相等、外角定理（本步开场在图上就近各用一句话回收并标注）；唯一问题：一半这个倍数是从哪儿来的，能不能画出来看？输入：沿用第 1 步的图（P 在优弧）；求量：把 ∠AOB 与 2∠APB 的等量关系在图上拼出来。控件：「作辅助线」分步按钮，一步一画，不许一次全出——①连 OP 并延长交圆于 D（过 P 的直径出现，两条半径 OP=OA=OB 依次点亮）；②图分成两个等腰三角形 △OAP、△OBP，等边同色、各自两底角用同色弧标出并写出实算度数；③外角登场：∠AOD 是 △OAP 的外角，图上用弧线把 ∠AOD 与两底角之和连起来，读数并排 ∠AOD = ∠OAP + ∠OPA（两数实算核对）；∠BOD 同理；④收口合并：∠AOB = ∠AOD + ∠BOD = 2(∠OPA + ∠OPB) = 2∠APB，等式每一项都对应图上正在高亮的角，点哪项亮哪个角。预期观察：不是读到一句「得证」，而是亲眼看到大角被一刀拆成两份、每份恰好是小角的一部分的两倍。结论适用条件：本证法覆盖圆心 O 落在圆周角内部的主情形；O 落在角外（P 换到另一段弧）时是减法版，第 4 步点名回收，本步末尾留一句悬念即可，不展开。
4. **直径特例：泰勒斯（step3）**：已知第 1、2 步结论；唯一问题：当 AB 本身就是直径（圆心角 = 180° 的平角）时，圆周角是多少？输入：AB 拉成直径，变量仍是 P 的位置；求量：∠APB 实测值。控件：拖 P 在半圆上任意跑（两侧半圆各试），读数恒 90°；「记一笔」账本复用；一句点题：180° 的一半就是 90°——不需要新定理，是第 1 步结论的直接特例。顺带回收：直角是本页与勾股页的接口（终章深链）。结论：**直径（半圆）所对的圆周角是直角**（泰勒斯定理）；适用条件：AB 必须是直径（过圆心），只是「很长的弦」不算——给一个反例位：把 AB 拖成不过圆心的长弦，角立刻不是 90°（滑杆把弦偏离圆心的距离调离 0 即见）。
5. **换一段弧：角翻倍互补（step4）**：已知前四步；唯一问题：P 跑到另一段弧（劣弧）上去，还是同一个角吗？输入：A、B 不动，P 跨过 A 或 B 换到劣弧上；求量：新 ∠APB 与原角、与 180° 的关系。控件：拖 P 跨界（跨过 A/B 的瞬间图上弧的高亮互换：原来「对着」的弧换成另一段）；读数三项——当前圆周角、另一段弧上的圆周角（图上放一个影子点 P′ 在优弧上同步显示）、两角之和；优弧/劣弧在图上用不同颜色 + 名牌标明，圆心角同时给出劣弧版（<180°）与优角版（>180°，reflex）读数，核对「劣弧上的圆周角 = 优角的一半」。预期观察：跨界一瞬间角从 40° 跳成 140°，且 40+140=180 恒成立。结论：**同弧所对圆周角相等；等弧/同弦在两段弧上的圆周角互补（和为 180°）**；第 2 步减法版证明在此回收一句：此时辅助线拆出的是差，∠AOB（优角）= 2∠APB 仍成立。适用条件：两个角必须对着同一条弦 AB 的两段弧；换一条弦不适用。
6. **自测（step5）**：①给圆心角 80°、P 在优弧，求圆周角（40°，选项含 160°/80° 干扰项）；②判断题「AB 是直径，P 在圆上任意位置（P≠A、B），∠APB 一定是 90°」（对）；③给优弧上圆周角 65°，求劣弧上圆周角（115°，考互补不是一半）；④操作题：把 P 拖到使 ∠APB = 45° 的位置（圆心角预设 90°，拖到优弧任意处即达标——判定按实算角落在 45°±1° 且 P 在优弧上，回收「位置任意」的核心直觉）。全部答对才点亮终章入口文案（提示语不得提前泄露答案，照 derivative 页门控口径：未全对时提示区不渲染含答案的句子）。
7. **终章（step6）**：三卡收束（同弧：一半且相等 / 直径：90° 泰勒斯 / 换弧：互补 180°）+ 互链区（深链锚点已按 CONCEPT-MAP 核对，构建时须再实开目标页按 id 复核一次）：①pythagoras#step4（CONCEPT-MAP 第 73 行「勾股逆定理与判角」——第 3 步的直角在这里接上：三边满足 a²+b²=c² 的三角形，其斜边恰好是外接圆直径）；②symmetry-rotation#step2（CONCEPT-MAP 第 81 行「转一转」步——圆是旋转对称的极端：绕圆心转任意角度都与自己重合，这正是 P 在圆周上「站哪都一样」的另一面）。本页新概念行（圆周角定理）由 Alberto 上线时登记 CONCEPT-MAP，构建者不碰该文件。

## 判定口径（硬性，构建与评审共用）
- **角度一律几何实算**：页面所有角度读数（圆心角、圆周角、外角、底角）必须由点的坐标用向量夹角（atan2/点积）现算，禁止用「圆心角÷2」反推圆周角显示、禁止写死 40°/90° 等结论值——第 1 步的「纹丝不动」必须是算出来的事实被学生撞见，不是渲染出来的台词。第 3 步 90° 同理，必须是直径情形下向量实算的结果。
- **证明步可核对**：第 2 步每个等式（等边、底角相等、外角=两底角和、合并=2 倍）旁边的度数全部实算并随图（若允许改圆心角）同步更新；等量关系用同色弧/同色边在图上标出，点等式项高亮对应角。评审会改圆心角到 100° 复核全部等式仍成立（容差 ±0.1°，读数保留 1 位小数）。
- 拖拽容差与吸附：P 拖到 A/B 附近（弧长 < 2°）时圆周角无定义（两弦退化），须钳制或给出「P 不能与 A、B 重合」状态，不得读出 NaN 或乱跳的角度；操作题④的达标判定容差 ±1° 明写在读数旁。
- 账本（记一笔）数据只来自实算读数；切语言时账本数字与条目保留、仅文案重渲染。

## 模拟设定 / 模型失配
- 本页是理想几何模型：圆是数学圆、无测量误差模拟；拖拽的位置角量化步长（滑杆 0.5°）会带来的读数末位抖动属显示量化，读数保留 1 位小数后应稳定，评审按 ±0.1° 容差判。
