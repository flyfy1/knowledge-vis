::: strings

这一步要回答：三角形内角和是多少？**内角**是多边形里面、两条边夹出的角。拖动顶点 C，三个角的大小各自变化；拖动“拼合”，把三个角撕下来，顶点移到同一点并排放：它们刚好拼成一个平角（一条直线），也就是 180°。 {#s0e .explain}

## n 边形能剖成几个三角形？内角和呢？ {#step2 h2=s2t pre=1}

这一步要回答：内角和与边数 n 的关系？从一个顶点出发，向不相邻的顶点连对角线，可以把 n 边形剖成 n − 2 个三角形，所以内角和 = (n − 2) × 180°。拖动边数 n，数一数三角形，对照由坐标算出的角和。 {#s2e .explain}

## 沿着多边形边走一圈，一共要转多少度？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 外角和
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 外角和
:::

这一步要回答：多边形的外角和是多少？**外角**是把一条边延长后，延长线和下一条边的夹角，等于 180° 减去内角。沿着边走一圈，每到一个顶点就转一个外角，回到出发时朝向原来的方向，一共转了一整圈 360°。拖动“走了几条边”，看累计转角；切换“不规则”，外角各不相同，总和仍是 360°。 {#s3e .explain}

这一步要回答：公式要求多边形是凸的吗？把五边形的一个顶点向里压：到一定程度它的内角超过 180°（凹进去）。拖动“向里压的程度”：这个角变大，另外几个角变小，五个角的和始终是 (5 − 2) × 180° = 540°，因为凹多边形同样能剖成三角形。 {#s4e .explain}

## 正多边形每个内角是 a°，它有几条边？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 终章
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 终章
:::

这一步要回答：已知内角能反推边数吗？正 n 边形每个内角 = (n − 2) × 180° ÷ n，外角 = 180° − 内角 = 360° ÷ n，所以 n = 360 ÷ (180 − 内角)。拖动内角 a，看 n 是不是整数：是整数才有对应的正多边形。 {#s5e .explain}
