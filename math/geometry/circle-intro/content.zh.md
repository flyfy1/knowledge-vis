## 周长是直径的多少倍？大圆小圆一样吗？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 π 从哪来
:::

::: html step3-1

s3k: π 从哪来

这一步要回答：这个倍数是不是固定的，等于多少？用圆里的正多边形去逼近圆：边数 n 越多，多边形的周长越接近圆周。图中折线是“多边形周长 ÷ 直径”随边数变化，它越来越靠近一个固定的数，就是 **π**（≈ 3.14159）。换半径不影响这个比。 {#s3e .explain}

## 圆的面积怎么算？ {#step4 h2=s4t pre=1}

::: strings

:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 圆的面积

这一步要回答：圆的面积为什么是 π × r × r？把圆分成 n 个扇形，一正一反交错拼起来，近似成一个长方形：长是半个周长，宽是半径 r。分得越细越像长方形。拖动扇形数 n，看拼出的“长 × 宽”接近 π r²。 {#s4e .explain}

::: html step4-2

rr4: 半径 r（厘米）
:::

:::
