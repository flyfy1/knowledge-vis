# BRIEF：圆的认识（circle-intro）· 小学数学
- category `math`，stage `primary`（已注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，记录不确定性）。去重：与 circle-angles（圆周角定理）核心不同，本页是圆的第一课，不含圆周角。
- 核心：圆=到圆心等距的点；直径=2 半径；周长/直径=π（多边形逼近）；面积=π r²（扇形拼长方形）。

## 步骤（五必填项）
0. 圆规画圆。已知：长度；问题：圆上的点有何共同点？输入半径、笔转角；观察：弧随角度累积，每隔 45° 的半径标记；读数由坐标算出笔到圆心距离恒 = r。
1. 圆的部件。问题：半径/直径/弦？输入半径、弦张角；观察：弦随张角变长，180° 时等于直径；读数比较弦与直径。
2. 滚一圈。问题：周长与直径的关系？输入轮径、转过圈数；观察：轮子滚动、橙色线段记录滚过长度，比值 3.14；假设：不打滑。
3. π 从哪来。问题：比值是否固定？输入边数 n、半径；观察：正多边形逼近、折线“周长÷直径”随 n 上升接近 π 但始终略小（96 边 3.1410），半径改变不影响曲线；周长由顶点坐标求和得到。
4. 圆的面积。问题：为何 π r²？输入扇形数、半径；观察：扇形交错拼成近似长方形，长→半周长，面积读数→π r²；n 小时形状不像长方形（如实呈现）。
5. 终章。输入已知量（r/d/C/A）与数值；算出其余三个（π 取 Math.PI，保留两位小数）；画出圆；深链 circle-angles#step0、symmetry-rotation#step2、area-model#step1（均已核对存在）。

## 新术语首现表
圆心、半径（步 0）；直径、弦（步 1）；周长（步 2）；π、圆周率（步 3）；扇形（步 4）。

## 模拟设定 / 模型失配
理想平面圆；滚动不打滑；π 的读数来自多边形逼近与计算机 π 值；日常取 3.14 属近似。
