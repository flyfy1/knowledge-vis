## 从正面、左面、上面分别看，各看到什么？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 三个方向看
:::

::: html step1-1

s1k: 三个方向看
:::

这一步要回答：同一堆积木，三个方向看到的平面图是什么？**主视图**是从正面看，每一列只看见最高的那一摞；**左视图**是从左边看，每一排看最高的；**俯视图**是从上面看，有积木的格子都画出来，格子里的数字是那里的块数。 {#s1e .explain}

## 三张视图之间，哪些长度一定相等？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 三图对齐
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 三图对齐
:::

这一步要回答：三个视图怎样对上？画三视图有三条规则：**长对正**（主视图和俯视图的宽度对齐）、**高平齐**（主视图和左视图的高度对齐）、**宽相等**（俯视图的前后深度等于左视图的宽度）。拖动“高亮第几列”，虚线把这一列在三张图里的位置连起来。 {#s2e .explain}

::: html step2-2
s2cv: 主视图（左上）、左视图（右上）、俯视图（左下）对齐
col: 高亮的那一列
:::

::: strings
s2ro: 高亮第 {c} 列：主视图里这一列高 {fh}；俯视图里这一列有 {tn} 个格子有积木；左视图的最高排高 {lh}（三图的最大高度一致：主视图 {fm}，左视图 {lm}）。
:::

## 只知道主视图和左视图，能确定积木怎么堆吗？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 看两张够吗
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 看两张够吗
:::

这一步要回答：两个视图足够还原立体吗？只给主视图和左视图时，每一格最高能放 min（该列主视图高，该排左视图高）块，都放满就是“最多”的情况。按“显示最多的堆法”，橙色积木是比你搭的多出来的，它们的主视图、左视图仍然完全一样。再加上俯视图，才能把没有积木的格子排除。 {#s3e .explain}

::: html step3-2
s3cv: 你搭的积木，和同样的两个视图下最多的堆法
showMax: 显示/隐藏最多的堆法
:::

::: strings
s3ro: 你搭了 {n} 块；只看主视图和左视图，最多可以有 {mx} 块（多 {extra} 块，主、左视图不变）；再加上俯视图的占格限制，最多 {mt} 块。
s3roNone: 你搭的这堆里，主视图和左视图已经把每一块都定下来了（最多 {mx} 块 = 你搭的 {n} 块），所以没有多出来的。换成“L 形”预设再试试。
:::

## 要给这堆积木刷漆，要刷几个面？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 终章
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 终章
:::

这一步要回答：怎样用三视图的想法数表面？每块积木有 6 个面；相邻两块贴在一起，就各少露出 1 个面。所以露在外面的面数 = 6 × 块数 − 2 × 贴合处数。上方预设可以换形状，看看表面积怎样随堆法改变。 {#s5e .explain}

::: html step5-2
s5cv: 积木与表面积
recapTitle: 回顾
recap1: 主视图看每列最高、左视图看每排最高、俯视图看哪些格有积木。
recap2: 长对正、高平齐、宽相等；两个视图常常不能唯一确定立体，需要第三个。
recap3: 数积木、数表面，都可以从“有几块、贴合几处”算出来。
modelTitle: 模型范围与局限
modelText: 这里只处理 3 × 3 格、每格最高 3 块的积木堆，所有积木都是边长相同的正方体，没有悬空的积木。立体图采用等轴测近似画法，不是严格的透视图。
