## 一根绳子围地：周长不变，面积在变 {#step0 h2=s0t}

::: strings
nav0: 0 绳子围地
:::

第 0 步 · 绳子围地 {#s0k .step-kicker i18n=text}

这一步要回答：**周长一样，面积就一样吗？**一根 **24 米**的绳子围一个长方形菜园。先把两个词分清：**周长**是绕图形一周的长度——就是这根绳子的长；**面积**是图形里面的大小——按 1 米 × 1 米的方格地砖来数，铺满要多少块。拖动右下角的圆点（或拉滑杆）改变长和宽，看着绳子账和地砖账各自动什么。 {#s0e .explain}

::: html step0-1
s0lenLab: 长（米）
:::

看仔细：拖动时**绳子账纹丝不动**（周长只管一圈有多长），**地砖账上蹿下跳**（面积管里面有多大）。两个量各管各的——这是这一页的全部秘密。 {#s0hint .hint}

:::

为什么越扁周长越长？面积钉死时，压扁一头就要拉长另一头，而**周长数的是两条长边加两条宽边**，拉长的那头在账上要出现两次。两个量各管各的账，谁也代替不了谁。 {#s2hint .hint}

收束成一句话：**周长量一圈，面积量里面。**下面三块地周长都是 24 米，面积却一个比一个大——这一页的全部内容，都在这张图里了。 {#s4e .explain}

::: html step4-1
c1h: 周长 = 一圈
c1: 周长是绕图形一周的长度，单位是米——像一根绳子、一道篱笆。它只管边界有多长，不管里面装了什么。
