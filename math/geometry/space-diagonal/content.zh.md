## 体内的斜线，属于哪个三角形？ {#step0 h2=s0t}

::: strings
nav0: 0 认出三角形
:::

第 0 步 · 观察 {#s0k .step-kicker i18n=text}

这一步要回答：穿过盒子内部的直线，怎样和底面联系起来？你已学过[[pythagoras#step2|直角三角形的勾股关系：两条直角边的平方和等于斜边的平方]]。空间对角线 d 就是穿过长方体内部、连接最远两个角的直线；底面对角线 e 是底面上两个相对角的连线。这里先固定长 a = 2、宽 b = 3、高 c = 6（同一长度单位）。先拖动画布改变视角，沿青色 e 到达底角，再沿绿色 c 向上，看橙色 d 怎样闭合这个竖直三角形；小方角表示两条线垂直。 {#s0e .explain}

## 同一条 e，接起两次勾股 {#step1 h2=s1t}

::: strings
nav1: 1 两次勾股
:::

第 1 步 · 计算 {#s1k .step-kicker i18n=text}

这一步要回答：已知长 a、宽 b、高 c，怎样求空间对角线 d（体内最远两个角的直线距离）？底面对角线 e（底面相对两角的连线）先由 a、b 算出，再与高 c 算出 d。先只改 a，保持 b、c 不变：看底面青色 e 和体内橙色 d 一起变长或变短；再只改 c，青色 e 不变，橙色 d 改变。滑杆改变真实棱长，不改变视角；所有长度用同一单位。 {#s1e .explain i18n=text}

试验顺序：先固定 b、c，只改 a，确认 e 和 d 一起变化；再固定 a、b，只改 c，确认 e 不动而 d 变化。这样能把“先求底面 e、再把 e 与 c 组合”这两次勾股分开看。 {#s1bridge .hint i18n=text}

::: html step1-1
aLab: 长 a（单位）
bLab: 宽 b（单位）
cLab: 高 c（单位）
book1: ① 底面直角三角形 · 求 e
book2: ② 竖直直角三角形 · 求 d
:::

当前值：显示保留 3 位小数；第二行使用未舍入的 e² = a² + b²，不拿显示的近似 e 再平方。长度表示距离，没有“越大越好”。 {#rounding .readout i18n=text}

为什么能接起来？底面内 a ⟂ b，底面外 e ⟂ c。两个真实存在的直角三角形，才允许勾股连用两次。 {#s1result .readout i18n=text}

::: strings
ledger1: "e = √(a² + b²)\n= √({a}² + {b}²) = √{base2} ≈ {e} 单位"
ledger2: "d = √(e² + c²) = √(a² + b² + c²)\n= √({base2} + {c}²) = √{sum} ≈ {d} 单位"
:::

## 这一次，先选再揭晓 {#step2 h2=s2t}

::: strings
nav2: 2 自己算一次
:::

第 2 步 · 自测 {#s2k .step-kicker i18n=text}

这一步要回答：另一个长方体的空间对角线 d（体内相对两角的直线距离）是多少？已知 a、b 是互相垂直的底边，c 是垂直底面的高。用上一步的两次勾股，先求底面对角线 e（底面相对两角的连线），再求 d；不沿三条棱绕路。选出 d 的值，答对才揭晓总结公式与适用条件。 {#s2e .explain i18n=text}

::: html step2-1
quizGiven: 新长方体：a = 1，b = 2，c = 2（单位）
quizLabel: 选择空间对角线的长度
locked: 先选一个答案，答对后点亮总结公式。
finale: 带走一个方法：先在底面求距离，再把这段距离与高组成直角三角形。空间里的距离，仍从平面勾股出发。
backPythagoras: ← 回到勾股第 4 步：用三边检验直角条件
proofLink: 回看勾股第 2 步：用面积理解公式为何成立 →
:::

::: strings
quizIdle: 提示：先算底面 e²，再加高的平方。
quizWrong: 再想一想：d² = (1² + 2²) + 2²。需要求的是长度，不是平方，也不是棱长之和。
quizCorrect: 答对了：d = 3 单位。两次勾股，走通了！
quizProof: 先有 e² = 1² + 2² = 5，再有 d² = 5 + 2² = 9，所以 d = 3 单位。
condition: 只对长方体或三条两两垂直的棱成立：底面内与竖直截面内的两个直角三角形必须真实存在，斜盒子不能直接套用。
:::
