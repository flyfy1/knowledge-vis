## 沿哪条线对折，两边能完全重合？ {#step0 h2=s0t}

::: strings
nav0: 0 对折试一试
:::

第 0 步 · 对折试一试 {#s0k .step-kicker i18n=text}

这一步要回答：**一条线凭什么叫「对称轴」？**先把词说清：把图形沿一条线对折，如果两边**完全重合**（重合 = 一点不差地叠在一起，边角都不多不少），这条线就叫**对称轴**；有对称轴的图形叫**轴对称**图形。下面每个图形都摆了几条候选线，真假混在里面——点一条，亲眼看半边翻过去：对得齐才是，差一丁点都不算。 {#s0e .explain}

:::

判据只有一条：**对折后完全重合**。看着像中线的线，翻过去才知道真假——正方形的每条候选线都值得亲手验一遍。 {#s0hint .hint}

## 不翻面，只转：转多少度能和自己重合？ {#step2 h2=s2t}

::: strings
nav2: 2 转一转
:::

第 2 步 · 转一转 {#s2k .step-kicker i18n=text}

这一步要回答：**图形绕着中心转多少度，能和原来完全重合？**中间的圆点是**旋转中心**（转的时候唯一不动的点）。拖滑杆转动图形，浅色的虚线轮廓是它原来的样子——转到某个角度，两者会严丝合缝，那就是**旋转对称**：不用翻面，转一转就变回自己。 {#s2e .explain}

::: html step2-1
s2shapeLab: 选一个图形：
s2angLab: 旋转角度（度）
s2find: 转到最近的重合角
:::

看法：拖滑杆慢慢转，盯着实心图形和虚线轮廓——对齐的那一刻就是一次重合。叶片越多，重合来得越勤。 {#s2hint .hint}

::: strings

rFan4: 四叶风车
rLeaf: 一片树叶
rPara: 平行四边形

s2roNo: 现在转了 {deg}°：还没重合，图形和虚线轮廓错开着。
s2roZero: 现在是 0°，还没开始转。拖动滑杆，或点「转到最近的重合角」。

s2ledgerLeaf: 账本：一片树叶转多少度都不重合，只有转满一圈 360° 才回到原样——它**没有旋转对称**，重合次数算作 1。
s2paraBack: 悬念回收：第 1 步里平行四边形一条对称轴都没有，可它转 180° 就能重合——**它没有轴对称，却有旋转对称。翻和转，是两回事。**

:::

## 只画一小块，图案自己长出来 {#step3 h2=s3t}

::: strings
nav3: 3 万花筒
:::

第 3 步 · 万花筒 {#s3k .step-kicker i18n=text}

这一步要回答：**万花筒只放一小块彩色玻璃，花纹为什么满满一整幅？**靠的是两种办法合谋：**镜像**（镜像 = 像照镜子一样翻出一个左右相反的副本，就是第 0 步的对折）把原件在每个扇区里再翻一份，旋转再把扇区转满一圈。下面发亮的扇区是「原件区」：往里放图案，看它怎么自己长满整幅画。 {#s3e .explain}

::: html step3-1
s3secLab: 扇区数：
sec4: 4 个扇区
sec6: 6 个扇区
sec8: 8 个扇区
s3mirLab: 镜像（每区再翻一份）：
mirOn: 开
mirOff: 关
s3motifLab: 往发亮的扇区里放：
mDot: 一个圆点
mSeg: 一条短线
mTri: 一个小三角
s3clear: 清空
:::

也可以直接点任意扇区：点的位置会自动折回原件区，点哪儿就在原件区对应的位置多一个圆点。 {#s3clickHint .hint i18n=text}

亲手对比：同一批原件，关掉镜像，花纹立刻「单薄」一半——少的那一半，就是镜像（对折）贡献的。 {#s3hint .hint}

::: strings

s3roWhyOn: 镜像开着：每个扇区里有正、反两份，所以一份原件出现 2 × {n} = {c} 次。
s3roWhyOff: 镜像关着：只有旋转在复制，一份原件出现 {n} 次。把镜像打开，对比一下花纹多了什么。
:::
