## 赢了要付自己的报价，报多少最划算？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 第一价格
:::

::: html step0-1

s0k: 第一价格密封拍卖
:::

<b>这一步回答：为什么在第一价格拍卖里不该按真实估值出价？</b>你的估值是 v，报价是 b。赢了得到 v − b，输了得到 0；报得越高赢面越大但赚得越少。假设对手的报价在 0 到 50 之间均匀分布，则赢的概率是 b/50，期望收益 (v − b)·b/50，最高点在 b = v/2。拖动两个滑杆，看橙色曲线上的点。 {#s0e .explain}

::: strings
nav1: 1 第二价格

::: html step1-1

<b>这一步回答：为什么第二价格拍卖里按真实估值出价从不吃亏？</b>赢家付的是对手的报价 r，不是自己的报价。真话（绿线）在 r 低于 v 时赢、高于 v 时输，正是你想要的；换成别的报价 b（橙线），只在 r 落在 b 与 v 之间（红色带）时结果不同，而且只会变差。拖动三个滑杆，核对“最大增益”从不为正。 {#s1e .explain}

## 卖家选哪种规则能多收钱？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 谁收得多
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 收益相等
:::

<b>这一步回答：两种规则平均下来谁让卖家收得多？</b>每一轮随机抽 n 个估值（0–100 均匀）。第一价格里每人按均衡压价，最高估值者付 v₁·(n−1)/n；第二价格里付第二高的估值 v₂。多拍几轮，两条平均线都会靠向同一个数 100·(n−1)/(n+1)——这就是“收益相等”。 {#s2e .explain}

<b>这一步回答：公开升价拍卖为什么价格停在“第二高估值”？</b>价格钟一路升高，估值低于价格的人依次退出；当只剩一人时拍卖结束，此时钟上的价格恰好是第二高的估值。所以英式拍卖的结果和第二价格密封拍卖相同。点“升价”或“自动”看谁退出。 {#s3e .explain}

## 东西的真值大家都不确定时，赢的人为什么常常亏？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 赢家的诅咒
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 终章 · 赢家的诅咒
:::

<b>这一步回答：为什么“估得最高的人”赢了反而吃亏？</b>假设物品真值 V 未知，每人得到带噪声的估计 V + ε。按估计报价时，赢家恰是噪声 ε 最大的人，平均多付 σ(n−1)/(n+1)。竞标者越多、噪声越大，亏得越多。把“压价”滑杆往上拉，抵消这个偏差——前面“压价”的思路在这里换了原因。 {#s5e .explain}
