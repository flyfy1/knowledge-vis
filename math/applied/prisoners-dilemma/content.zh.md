## 无论对方怎么出，背叛都更划算 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 一次博弈
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 为什么两人都背叛
:::

这一步要回答：为什么两个人明明都想要“一起合作”，却会一起背叛？每人有两个选择：**合作**（C）或**背叛**（D）。格子里青色数字是“我”的得分，紫色是对方的得分：双方合作各得 3；双方背叛各得 1；我背叛而对方合作，我得 5、对方得 0（反之亦然）。**占优策略**指不管对方怎么选都不比别的选择差的选择（概念见[[game-theory#step2|博弈论]]）。**观察：**先点对方的选择，绿色格子标出此时我的最佳选择：对方合作时背叛得 5 > 3，对方背叛时背叛得 1 > 0，所以背叛总是更好；但双方都背叛只得 1+1，比双方合作的 3+3 差。这是一次性对局，没有“下一次”。 {#s0e .explain}

## 同一对人要打很多轮，策略登场 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 重复博弈
:::

::: html step1-1
s1step: "第 1 步 · "

这一步要回答：同样的两人连打多轮，结果会怎样？**策略**是一条根据历史决定下一步的规则：**永远合作**、**永远背叛**、**以牙还牙**（第一轮合作，之后重复对方上一轮的选择）、**冷酷**（合作到对方第一次背叛，此后永远背叛）、**随机**（各一半）。上方方块每格是一轮，绿 = 合作，红 = 背叛；下方是累计得分。**观察：**选定 A 与 B 两个策略和轮数，看累计得分的曲线：以牙还牙对永远背叛只在第一轮吃亏，之后双方打成 1:1。改轮数、换对手并比较。 {#s1e .explain}

## “还会再见”要有多大把握，合作才划算？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 未来的影子
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 未来的影子
:::

这一步要回答：什么时候放弃一次背叛的甜头、坚持合作才划算？设每轮之后“还有下一轮”的概率为 δ，则预期还会打 1/(1−δ) 轮。对一个与“以牙还牙”或“冷酷”打交道的对手，持续合作每轮得 3，总价值 3/(1−δ)；如果这一轮背叛，立刻得 5，但之后对方报复，每轮只得 1，总价值 5 + δ·1/(1−δ)。两条线的交点是 δ\* = (T−R)/(T−P) = (5−3)/(5−1) = 0.5。**观察：**拖动 δ：左于 0.5，背叛的价值更高（红线在上）；右于 0.5，合作更值。这个结论只对“背叛后永远被报复”的对手成立。 {#s3e .explain}

## 谁得分高，谁在下一代占的比例就变大 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 种群演化
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 种群里的演化

这一步要回答：把这些策略放进一个大种群，比例会怎样随世代变化？每一代，每个策略的占比乘以它的平均得分再归一化——得分高的比例上升，这叫**复制者动态**。三角形里每个点是一种三策略比例（越靠近某个角，那种策略越多）：左下永远合作、右下永远背叛、顶角以牙还牙。橙色路径是 80 代的轨迹，白点是起点。**观察：**先看轮数 n：n 取 1 时永远背叛一路冲到右下角；n 取 20 左右，背叛者先靠剥削“永远合作”者繁荣，随后以牙还牙者占领种群。再改初始占比，看起点会不会改变结局。 {#s4e .explain}

## 有噪声时，要不要原谅？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 犯错与宽容
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 会犯错的世界
:::

这一步要回答：如果每个动作都有一定概率被误做成相反的（比如想合作却手滑背叛），“以牙还牙”还好使吗？**噪声** e 是每次动作出错的概率。两个以牙还牙互相遇到时，一次失误会引发长时间的互相报复；**宽容以牙还牙**在对方背叛后仍以概率 g 选择合作，便能打断这个循环。**观察：**拖动 e：红线（以牙还牙）掉得比绿线（宽容以牙还牙）快；调 g：g = 0 时两条线重合，g 太大又会被背叛者占便宜（本页只演示自我对局，没有演示被剥削）。纵轴是长期每轮平均得分，上限 3。 {#s5e .explain}

::: html step5-2
s5cv: 两个同类玩家对局的每轮平均得分随噪声变化

recapTitle: 回顾
recap1: 一次博弈中背叛是占优策略，双方背叛得 1+1，劣于双方合作的 3+3；重复足够多轮后，以牙还牙、冷酷等“先合作、会报复”的策略能把合作维持下来。
recap2: 合作要“划算”需要未来的影子：δ ≥ (T−R)/(T−P)；在种群里，背叛者先靠剥削繁荣，随后被会报复的合作者取代。
recap3: 有噪声时单纯报复会陷入互相报复，加一点宽容能恢复合作——但“谁最好”总取决于对手群体。
