# BRIEF：反馈控制（feedback-control）· 先看差多少，再决定推多少

## 定位

- slug `feedback-control`，category `engineering`，stage `senior`。受众：高中生、大学低年级和想建立控制直觉的自学者。
- 一句话直觉：**P 看现在差多少，I 记过去欠了多少，D 看未来趋势会不会冲过头。**
- 前置：不要求先学拉普拉斯；页面末尾链接到已有 `control` 倒立摆和 `laplace` 极点页作延伸。

## 教学链

0. **设定值与误差**：拖动 setpoint，看到误差先跳、输出后追；明确 `e = r − y`。
1. **P 看现在**：Kp 滑杆显示响应、控制量和 P 的稳态误差；可叠加固定基线。
2. **I 记账**：Ki 与 5 s 外部扰动；P/PI 对照，观察末段误差、控制力和积分饱和代价。
3. **D 看趋势**：Kd 与无 D 的基线对照，读超调、收敛时间和误差换向；文案明确噪声放大风险。
4. **调参实验室**：同时调 Kp/Ki/Kd，预设温和/均衡/激进；以三选一检查稳定性误解（正确项：D 可减超调但过大放大噪声）。
5. **收束**：同一公式映射到现在/过去/趋势三个时间尺度，明示二阶对象、固定步长和真实系统失配。

## 模型与边界

- 二阶对象：`m x'' + c x' + k x = u + d`，`m=1`、`c=1.25`、`k=0.8`，固定 `dt=0.01 s` 半隐式欧拉。
- 控制律：`e=r−y`，`u=Kp e + Ki∫e dt + Kd de/dt`；执行器限制 `|u|≤20`，积分状态有 `±8` 防饱和钳制。
- 扰动是 5 s 起、0.35 s 长的恒力脉冲；页面不把它冒充真实电机/液压动力学。
- 所有曲线、超调、末段误差、换向次数、收敛时间均从同一 `sim-core.js` 运行结果读取，禁止用预画公式替代模拟。

## 可访问性与双语

- 中/英文由 `data-i18n`、`data-i18n-html` 和 `knowledge-lang` 机制切换；语言切换保留滑杆与选择状态。
- 原生 range、radio、button 均可 Tab/键盘操作；canvas 同时配有读数文本，关键状态使用 `aria-live`。
- 共享深色视觉语言、可横向滚动的步骤导航、窄屏下单列控制。
