## 把质数乘起来一步到位，拆开却要试很久 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 乘易分解难
:::

这一步要回答：为什么“相乘”和“分解”的难度差这么多？**质数**是只能被 1 和自己整除的数。两个质数 p、q 相乘得 n = p·q，只需一次乘法（绿线）。反过来，已知 n 要找出 p 和 q，最朴素的办法是**试除法**：从 3 开始逐个奇数试能否整除，大约要试 p/2 次（红线，对数坐标）。横轴 k 表示 p、q 约有 k 位。橙点是在浏览器里真正跑出来的试除次数（k ≤ 7）；k &gt; 7 的红线是按公式外推，没有真的运行。**观察：**拖动 k：位数每增加 1，试除次数大约乘以 10；k = 30 时已是 10²⁹ 量级，即使每秒 10⁹ 次也要上千万亿年。试除法只是最笨的办法，更好的算法见第 5 步。 {#s0e .explain}

## “模”算术里，反复乘同一个数会走出怎样的轨迹？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 钟表算术
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 时钟上的算术
:::

这一步要回答：RSA 用的“取余”运算有什么规律？**a mod n** 是 a 除以 n 的余数，把数想成 0 到 n−1 围成的一圈（像钟面）。从 1 开始反复乘 a：1, a, a², …，每次都取模，在圈上跳来跳去，最终会回到出现过的数。当 a 与 n 互质（最大公约数为 1）时，一定会回到 1，形成一个闭环；**φ(n)**（欧拉函数）是 1 到 n 中与 n 互质的数的个数，欧拉定理说 a^φ(n) mod n = 1。**观察：**改 n 和 a：绿点是起点 1，青色路径是跳法；a 与 n 有公约数时回不到 1。读数给出闭环长度，它总是整除 φ(n)。这个性质是第 3 步解密成立的原因。 {#s1e .explain}

这一步要回答：怎样由 p、q 得到公钥与私钥？取两个不同质数 p、q（可选 5 到 43），令 n = p·q，φ(n) = (p−1)(q−1)。选一个与 φ 互质的**公开指数** e，再用**扩展欧几里得算法**求出 d，使 e·d 除以 φ 余 1（d 是 e 对 φ 的乘法逆元）。下表是算法的每一行：r₀、r₁ 是余数序列，q 是商，x、y 是系数，最后一行绿色的 x 经取模得到 d。**公钥**是 (e, n)，可以公开；**私钥**是 (d, n)，必须保密——别人只知道 n 却不知道 φ(n)，要算 φ(n) 就得先分解 n。**观察：**换 p、q、e，读数会验算 e·d = 1 + k·φ。 {#s2e .explain}

::: strings

这一步要回答：怎样用这对钥匙传递一个数？把要发送的信息变成一个小于 n 的整数 m（**明文**）。发送方用公钥算 **密文** c = m^e mod n；接收方用私钥算 m′ = c^d mod n，得回 m。原因：e·d = 1 + k·φ(n)，由第 1 步的欧拉定理（对 n = p·q 同样适用），m^(e·d) ≡ m。图中每个点是 (明文 m, 密文 c)——点云看起来杂乱无章，没有简单规律可循；橙点是你选的 m。底部显示 m → c → m′。计算用的是反复平方（读数给出所需乘法次数），不是把 m^e 真的算出来。**观察：**拖动 m，橙点在乱点中跳动，但解密总能回到 m；读数验证了全部 0 到 n−1 的明文都解密正确。 {#s3e .explain}

这一步要回答：现代的 RSA 密钥为什么是 2048 位甚至更长？今天已知最快的通用分解算法（数域筛）的运算量约为 exp((64/9)^(1/3)·(ln n)^(1/3)·(ln ln n)^(2/3))，增长得比多项式快、比试除法慢。图中是密钥位数与所需运算量（对数刻度）的关系，虚线是“一台每秒 10¹⁸ 次运算的机器连续算到宇宙年龄”的总运算量。这是量级估算，忽略了常数和实现细节。**观察：**拖动位数：512 位约 10¹⁹ 次运算（1999 年已被分解过），1024 位约 10²⁶，2048 位约 10³⁵。需要强调：这里教的是“教科书版”RSA，真实系统必须加随机填充（如 OAEP），并且量子计算机上的 Shor 算法能在多项式时间内分解整数，因此未来需要换用其他算法。 {#s5e .explain}
