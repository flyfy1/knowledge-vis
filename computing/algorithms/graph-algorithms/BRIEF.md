# 图算法 · 让边带你走

## 教学目标

- 用一张 6 节点无向图建立“节点 / 边 / frontier”的共同语言。
- 对比 BFS 的 FIFO 队列与 DFS 的 LIFO 栈，让遍历顺序由可观察状态产生。
- 允许用户切换一条边、拖动节点并从同一基线重放，形成“结构 → frontier → 顺序”的因果链。
- 从真实邻接表计数推导 `O(V + E)`，把复杂度读数和当前图同步。

## 交互契约

1. 起点下拉框或点击节点会重置遍历。
2. “切换这条边”与画布点击边保持同一数据源；边是无向的。
3. `走一步` 每次严格完成一次出队/出栈与邻居扫描；`连续播放` 只是重复同一动作。
4. 当前容器、已访问顺序、扫描计数和复杂度卡片都从 `app.js` 的同一状态派生。
5. 中英切换必须保留图数据和遍历状态，只重新渲染文案。
