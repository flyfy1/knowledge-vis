## 一串数字怎样代表一个词？ {#step0 h2=s0t}

::: strings
nav0: 0 词变成数
:::

第 0 步 · 词变成数 {#s0k .step-kicker i18n=text}

这一步要回答：为什么说「词可以变成一串数字，而且数字的位置有意义」？**词向量（embedding）**就是给每个词配一个固定长度的数字列表。本页先用手工设定的玩具特征：每个词 5 个数——性别、王室、年龄、是否人类、是否生物。选两个特征当横轴和纵轴，词就变成平面上的点：把横轴设为「性别」、纵轴设为「王室」，看 king 与 queen、man 与 woman 怎样对称；再换别的轴，看哪些词重合。选一个词，读出它的完整向量。真实的词向量由机器从大量文本里学出来，维度没有这样清楚的名字；这里的手工特征只是为了看清思路。 {#s0e .explain}

::: html step0-1
s0xL: 横轴
s0yL: 纵轴
s0wL: 查看的词
cv0: 词在所选两个特征平面上的位置
s0reset: 重置选择
:::

向量 = 一列有顺序的数；每个位置称为一个维度。 {#s0term .term i18n=text}

::: strings
s0Same: 白圈 = 所选词；重叠的词错开标注
s0ro: 「{w}」的向量 = <b>{v}</b>；横轴「{x}」、纵轴「{y}」；这个位置上共有 <b>{n}</b> 个词（重叠说明这两个特征分不开它们）。
:::

## 怎样衡量两个词有多相似？ {#step1 h2=s1t}

::: strings
nav1: 1 衡量相似
:::

第 1 步 · 衡量相似 {#s1k .step-kicker i18n=text}

这一步要回答：两个词向量「像不像」，用什么量来比？**点积** A·B 是各维乘积之和（下图第三行的柱子相加）；**余弦相似度** cos = A·B / (|A||B|) 只看两个向量的夹角，范围 −1 到 1，与长度无关；**欧氏距离**是两个向量端点之间的直线距离，受长度影响。选词 A、词 B，再拖动「放大 B」：保持 A 不变，看 B 的柱子整体变高，余弦相似度纹丝不动，而距离在变。最下方是 A 与所有词的余弦相似度（橙色 = 你选的 B）。 {#s1e .explain}

::: html step1-1
s1aL: 词 A
s1bL: 词 B
cv1: 词 A、词 B 的维度柱、逐维乘积与相似度排名
s1kL: 放大 B（倍）
s1reset: 重置
:::

|A| = 向量长度 = √(各维平方和)。余弦为 1 表示方向相同，0 表示垂直，−1 表示相反。 {#s1term .term i18n=text}

::: strings
s1A: 词 A：{w}（5 个维度）
s1B: 词 B：{w} ×{k}
s1P: 逐维乘积 A·B（柱子相加 = 点积）
s1Nn: 与「{w}」最相似的词（余弦，橙 = 词 B）
s1ro: 「{a}」与「{b}」×{k}：点积 {dot}；|A| = {na}，|B| = {nb}；余弦 <b>{cos}</b>；欧氏距离 <b>{d}</b>。
:::

## king − man + woman 为什么会得到 queen？ {#step2 h2=s2t}

::: strings
nav2: 2 类比算术
:::

第 2 步 · 类比算术 {#s2k .step-kicker i18n=text}

这一步要回答：向量做加减，为什么能做类比？每个词在图上是一个点。king 与 man 的差（橙色实线箭头）表示「从普通人变成王室」这个方向；把这个箭头平移到 woman（橙色虚线），终点就是 woman 加上同样的「王室」变化，正好落在 queen。公式：结果 = A − λ·B + λ·C（λ = 1 是完整类比）。选三个词，再拖 λ：白点沿着从 A 到答案的路走，读数里是离它最近（余弦最大）的词；注意走得不够远时最近的词可能是 prince，走完整个箭头才是 queen。输入的三个词不参与候选（常见做法，否则答案常常就是输入词本身）。图只画前两个维度，最近的词按全部 5 个维度计算。 {#s2e .explain}

::: html step2-1
s2aL: A（起点）
s2bL: B（减去）
s2cL: C（加上）
cv2: 类比箭头与结果点
s2lL: 走多远 λ
s2reset: 重置
:::

λ 是页面为了让你看清过程加的「走多远」系数，不属于模型；标准类比取 λ = 1。 {#s2term .term i18n=text}

::: strings
s2Res: 结果
s2ResOff: 结果（超出图范围）
s2Cap: 实线 = A−B；虚线 = 平移到 C；横轴性别，纵轴王室
s2ro: 结果 = {a} − {l}×{b} + {l}×{c} = <b>{v}</b>；最近的词是「<b>{top}</b>」（余弦 {cs}），第二名「{second}」。
:::

## 如果「正确答案」不在词表里呢？ {#step3 h2=s3t}

::: strings
nav3: 3 最近的词
:::

第 3 步 · 最近的词 {#s3k .step-kicker i18n=text}

这一步要回答：类比算术给出的究竟是什么？它先给出一个**点**，再由页面在词表里找离它最近的词。用勾选框决定词表里有哪些词，固定算 king − man + woman：先取消 queen，看答案变成谁、余弦有多高；再取消 princess、girl，继续观察。柱高是各候选词与结果点的余弦。结论：答案取决于词表，并不等于「真相」；余弦再高也只说明方向接近。（king、man、woman 三个输入词不参与候选。） {#s3e .explain}

::: html step3-1
s3vL: 词表（勾选 = 在词表里）
cv3: king − man + woman 在当前词表下的候选词
s3reset: 恢复全部词
:::

候选词 = 词表中除三个输入词以外的词；余弦只比较方向，不衡量「对不对」。 {#s3term .term i18n=text}

::: strings
s3Cap: king − man + woman 的候选词（余弦）
s3In: 输入词
s3Out: 不在词表
s3Ans: 答案：{w}
s3None: 词表里没有候选词
s3Has: 词表里有 queen，答案就是完整类比的结果。
s3Miss: queen 不在词表里，答案只是最近的替代词。
s3ro: 词表共 {n} 个词；答案「<b>{top}</b>」，余弦 <b>{cs}</b>。{miss}
:::

## 没有人手工写特征，向量从哪来？ {#step4 h2=s4t}

::: strings
nav4: 4 看它的邻居
:::

第 4 步 · 看它的邻居 {#s4k .step-kicker i18n=text}

这一步要回答：机器怎样自己得到词向量？核心想法是「看一个词常和谁出现在一起」。下面是只有 14 句话的迷你语料。拖动「读到第几句」（或按「逐句阅读」）：每读一句，就在表里给相邻的词对加 1。**窗口** = 一个词左右各多远算「相邻」（句子只有 3 个词，所以窗口大于 2 不再有变化）。每一行是一个目标词的**共现计数向量**（列是各个邻居词），用第 1 步的余弦比较两行：邻居最像的就是最相似的词。选目标词、改窗口，观察下方柱子。这里直接用原始计数，不是真正的训练；真实的 word2vec、GloVe 等方法在海量语料上把这类统计压成几百维的稠密向量。 {#s4e .explain}

::: html step4-1
s4tL: 目标词
cv4: 共现计数表与相似度排名
s4kL: 读到第几句
s4winL: 窗口大小
s4reset: 重置
:::

共现计数 = 两个词在窗口内一起出现的次数；邻居分布完全相同的两个词余弦为 1。语料很小，这只是演示。 {#s4term .term i18n=text}

::: strings

s4pause: ⏸ 暂停
s4Cap: 共现计数：行 = 目标词，列 = 邻居词
s4Sim: 与「{w}」邻居计数的余弦
s4ro: 读到第 <b>{k} / {n}</b> 句，窗口 {win}：与「{w}」邻居最相似的词是「<b>{top}</b>」（余弦 {cs}）。读 0 句时没有计数，显示 —。
:::

## 收束：把词摆成可计算的地图 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

词向量把词变成可以量距离、做加减的数字；本页从手工特征走到「看邻居」，说明这些数字既可以设计，也可以从文本里学出来。 {#s5e .explain i18n=text}

::: html step5-1
c1t: 词 = 一列数
c1b: 每个维度一个数，词成为空间里的点（第 0 步；本页是手工特征）。
c2t: 余弦看方向
c2b: 余弦只比较方向，与长度无关；欧氏距离同时受长度影响（第 1 步）。
c3t: 类比 = 加减 + 找最近
c3b: 向量加减给出一个点，答案是词表里最近的词，取决于词表（第 2、3 步）。
c4t: 向量可以学出来
c4b: 统计「谁和谁常一起出现」，邻居相似的词向量就相似（第 4 步）。
modelT: 模型与局限
modelB: 第 0–3 步是手工设定的 5 维玩具特征，每个轴都有名字；真实词向量有几百维，轴没有清楚的含义，类比也并不总是成立，并且会学到语料里的偏见。第 4 步只是原始共现计数加余弦，不是 word2vec 或 GloVe 的训练过程；迷你语料只有 14 句，结论仅作演示。
:::
