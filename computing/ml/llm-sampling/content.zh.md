## 模型每一步到底输出什么？ {#step0 h2=s0t}

::: strings
nav0: 0 下一词概率
:::

第 0 步 · 下一个词的概率 {#s0k .step-kicker i18n=text}

这一步要回答：大语言模型写下一个词之前，手里拿着什么？它先给每个候选词一个分数（**logit**，可正可负），再用 softmax 把分数变成加起来等于 1 的**概率**。本页为每个提示手工设定了 10 个候选词的分数（不是真实模型的输出）。切换提示：看分数（淡色柱）怎样变成概率（亮柱）；「法国的首都是」里一个词占绝大多数，「今天的天气是」则有好几个词势均力敌。读数里的**熵**衡量分布有多分散，「等效选项数」= 2^熵，约等于有几个词在认真竞争。 {#s0e .explain}

::: html step0-1
ctxL: 提示
cv0: 候选词的分数与概率
s0reset: 重置提示
:::

softmax：p_i = e^(z_i) / Σ e^(z_j)；熵 H = −Σ p·log₂p（比特），分布越平越大。 {#s0term .term i18n=text}

::: strings
s0Prompt: 提示：{p}
s0Log: 分数 logit（淡色）
s0P: 概率 softmax（亮色，单位 %）
s0ro: 概率最大的是「<b>{top}</b>」，<b>{p}</b>；熵 <b>{h}</b> 比特，等效选项数约 <b>{n}</b>；10 个概率之和 {s}。
:::

## 温度怎样把分布捏尖或摊平？ {#step1 h2=s1t}

::: strings
nav1: 1 温度
:::

第 1 步 · 温度 {#s1k .step-kicker i18n=text}

这一步要回答：同一组分数，怎样让模型更保守或更大胆？**温度** T 先把每个分数除以 T 再做 softmax：p_i ∝ e^(z_i/T)。拖动 T，提示不变：看亮柱相对虚线框（T = 1 的分布）怎样变化。T 小，概率向第一名集中，T → 0 就是每次选最高分（贪心）；T 大，分布趋于平均。读数给出第一名的概率、熵和等效选项数。 {#s1e .explain}

::: html step1-1
cv1: 不同温度下的概率分布
s1TL: 温度 T
s1reset: 重置温度
:::

T < 1 让分布更尖，T > 1 让分布更平，T = 1 是模型原样。温度只改变分布形状，不增加模型的知识。 {#s1term .term i18n=text}

::: strings
s1Cap: 温度 T = {T} 下的概率
s1Leg: 亮柱 = 当前温度；白色虚线框 = T = 1；数字单位 %
s1ro: T = {T}：最可能的是「<b>{top}</b>」，<b>{p}</b>；熵 <b>{h}</b> 比特，等效选项数约 <b>{n}</b>。
:::

## 怎样砍掉不靠谱的长尾？ {#step2 h2=s2t}

::: strings
nav2: 2 截断长尾
:::

第 2 步 · 截断长尾 {#s2k .step-kicker i18n=text}

这一步要回答：除了温度，还有什么办法避免偶尔抽到离谱的词？**Top-k** 只保留概率最高的 k 个词；**Top-p**（核采样）保留累计概率刚好达到 p 的最少几个词。被砍掉的词概率设为 0，剩下的重新归一，使总和仍为 1。本页顺序：先温度，再 top-k，再 top-p。拖动 k 或 p：灰柱是被砍掉的词，彩柱是重新归一后的概率，虚线框是砍之前的概率；留意读数里「覆盖的原始概率」。先把 T 调高，再收紧 p，看尾部怎样被截掉。 {#s2e .explain}

::: html step2-1
cv2: 截断并重新归一后的概率
s2TL: 温度 T
s2kL: top-k 的 k
s2pL: top-p 的 p
s2reset: 重置截断
:::

覆盖的原始概率 = 被保留词在截断前的概率之和；越小说明砍得越狠。 {#s2term .term i18n=text}

::: strings
s2Cap: 截断并归一后（灰 = 被砍掉）
s2Leg: 彩柱 = 截断后；白色虚线框 = 截断前；数字单位 %
s2ro: T = {T}，k = {k}，p = {p}：保留 <b>{kept}</b> 个词，覆盖原始概率 <b>{mass}</b>；截断后熵 <b>{h}</b> 比特。
:::

## 抽多少次，频率才像概率？ {#step3 h2=s3t}

::: strings
nav3: 3 抽样
:::

第 3 步 · 抽样 {#s3k .step-kicker i18n=text}

这一步要回答：模型每次只抽一个词，抽很多次后会怎样？按钮按当前分布（温度 T 与 top-p 处理后的概率，白色横线）随机抽样，彩柱是已抽到的频率。随机种子固定，同样的按钮序列会得到同样的结果。抽 1 次几乎看不出规律，抽 1000 次频率就贴近概率。读数里的**总变差距离** TV = ½Σ|频率 − 概率|，衡量两个分布还差多少（0 = 完全相同，越小越好）。注意：改动 T、p 或提示会清空已抽的次数，页面会提示。 {#s3e .explain}

::: html step3-1
cv3: 抽样频率与目标概率
s3TL: 温度 T
s3pL: top-p 的 p
s3d1: 抽 1 次
s3d100: 抽 100 次
s3d1000: 抽 1000 次
s3reset: 清空抽样并重置设置
:::

频率 = 该词被抽到的次数 / 总次数；TV 大致随抽样次数增大按 1/√N 下降（来自随机涨落）。 {#s3term .term i18n=text}

::: strings
s3Cap: 已抽 {n} 次的频率
s3Leg: 彩柱 = 频率；白线 = 当前设置下的概率；白框 = 最后一次抽到的词；纵轴按当前最高的一根缩放（最高 {m}）
s3Notice: （设置已改变，之前抽的次数已清空。）
s3ro: 已抽 <b>{n}</b> 次；最后抽到「{last}」；TV 距离 <b>{tv}</b>。{note}
:::

## 一个词接一个词，句子怎么长出来？ {#step4 h2=s4t}

::: strings
nav4: 4 逐词生成
:::

第 4 步 · 逐词生成 {#s4k .step-kicker i18n=text}

这一步要回答：把「每次抽一个词」重复下去，会写出什么？下面是手工设定的迷你模型，只看上一个词来决定下一个词的概率（真实模型会看整段上文）。按「下一个词」或「连抽 12 个词」，序列从「这」开始往后长；柱图是当前这一步的下一词概率，白框是刚抽到的词。试试 T = 0.1：几乎每次选最高分，句子很快陷入循环，重复率升高；T = 3：句子散成乱序。读数里的**重复率** = 序列中重复出现的三词组占全部三词组的比例。「换随机种子」会清空当前句子，从另一条随机路径重新开始。 {#s4e .explain}

::: html step4-1
cv4: 当前一步的下一词概率与已生成的序列
s4TL: 温度 T
s4next: 下一个词
s4gen: 连抽 12 个词
s4seed: 换随机种子（清空句子）
s4reset: 重置温度与句子
:::

这个迷你模型只看上一个词；序列少于 3 个词时重复率没有意义（按 0 显示）。 {#s4term .term i18n=text}

::: strings
s4Cap: 在「{w}」之后的下一个词概率（T = {T}）
s4ro: 序列长 <b>{len}</b>，用到 {d} 种词，重复率 <b>{rep}</b>；下一步最可能是「{top}」（{tp}）；随机种子 {seed}。
:::

## 收束：分数 → 概率 → 截断 → 抽一个 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

语言模型每一步都做同样的事：给候选词打分，用温度和截断整形，再抽一个词接上去。 {#s5e .explain i18n=text}

::: html step5-1
c1t: 分数变概率
c1b: softmax 把任意分数变成和为 1 的概率；熵告诉你有几个词在竞争（第 0 步）。
c2t: 温度整形
c2b: T 小更保守，T 大更随机；只改变形状，不增加知识（第 1 步）。
c3t: 截断长尾
c3b: top-k 和 top-p 砍掉低概率词再归一，代价是多样性变少（第 2 步）。
c4t: 抽样与累积
c4b: 一次抽样是随机的，很多次后频率贴近概率；一个词接一个词，低温会循环（第 3、4 步）。
modelT: 模型与局限
modelB: 所有分数都是手工设定的，不是真实模型的输出；第 4 步的迷你模型只看上一个词。真实模型的词表有数万个词，会看整段上文，还常使用重复惩罚等其他手段。温度和截断只改变分布的形状，不会让答案更「真实」。抽样用固定的伪随机种子。
:::
