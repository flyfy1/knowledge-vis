反向传播 · 误差沿网络回流

输出错了，每个权重该负多少责任？用最小的网络，从「推一下看变化」走到链式法则、梯度下降，再看深层网络里梯度为什么会消失。

第 0 步 · 前向与损失

网络现在错得有多离谱？

这一步要回答：给定两个权重，这个小网络的输出离目标差多远？网络只有一条链：输入 x = 1，乘权重 w1 得到 a，经过 σ（sigmoid，把任意数压到 0 到 1 之间）得到 h，再乘权重 w2 得到输出 ŷ。损失 L = ½(ŷ − 1.2)² 衡量输出与目标 1.2 的差距，越小越好。拖动两个权重（或直接点击下方的损失地图）：观察链上的数字怎样逐个变化，以及你的位置落在地图的亮处（损失小）还是暗处（损失大）。

损失地图：横轴 w1、纵轴 w2，每个点的颜色是该权重组合下的损失，越亮越小；亮带是满足 w2·σ(w1) = 1.2 的组合。

第 1 步 · 推一下看变化

把一个权重推一下，损失变多少？

这一步要回答：不用微积分，怎样量出「某个权重该为损失负多少责任」？办法：把这个权重增加一个很小的量 ε，看损失变化多少，再除以 ε，得到斜率（权重每增加 1 个单位，损失大约变多少）。曲线是只动所选权重、其余固定时的损失；橙色割线连着原位置和被推过的位置（红点），白色虚线是精确切线（下一步用反向传播算出）。选一个权重，把 ε 从 1 拖向 10^-5：橙线怎样靠近白色虚线？再拖「位置」换一个起点重试。

ε = 推的幅度；割线 = 过两点的直线，斜率 = (L(w+ε) − L(w))/ε；ε → 0 时割线变成切线。每个权重都要推一次，参数一多就太贵：这正是反向传播要解决的问题。

第 2 步 · 反向算账

怎样一次反向扫描就算出所有权重的责任？

这一步要回答：不逐个去推，能不能从损失出发一路往回乘，一次算出每个权重的斜率？链式法则：L 依赖 ŷ，ŷ 依赖 w2，所以 dL/dw2 = (dL/dŷ)·(dŷ/dw2)。下方账本从后往前：先算 dL/dŷ，再乘各处的「本地斜率」（ŷ = w2·h 对 w2 的斜率是 h，对 h 的斜率是 w2；h = σ(a) 的斜率是 h(1−h)；a = w1·x 对 w1 的斜率是 x）。拖动「反向进行到第几步」（或按「自动演示」），每前进一步出现一行新账；改变 w1、w2，所有数字随之重算。读数把反向传播的结果与第 1 步的「推一下」做对照。

本地斜率 = 链上相邻两个量之间的变化率；反向传播就是把它们从后往前连乘，每个量只算一次。

第 3 步 · 走下坡

知道了每个权重的责任，怎样让损失变小？

这一步要回答：拿到反向传播算出的梯度，权重该怎么改？梯度是损失对各个权重的斜率排成的向量，指向损失增长最快的方向；梯度下降每步把权重沿反方向挪一点：w ← w − η·梯度，其中 η 叫学习率（每步挪多远）。点击损失地图选起点（或拖起点滑杆），按「走一步」或「自动运行」：白线是权重走过的轨迹，下方曲线是损失随步数的变化。试试 η = 0.2（稳步下降）、η = 5（在谷底两侧来回跳而不收敛）、η = 8（直接飞出地图）；这些现象只对本页的小网络和这个起点成立。

梯度的方向是损失增长最快的方向，所以要走反方向；η 太小走得慢，太大会越过谷底。

第 4 步 · 深层梯度

层数多了，靠前的层还听得到误差吗？

这一步要回答：把网络加深，反向传回来的责任（梯度）会怎样？这里用 n 个单神经元串成的链：每层 a = w·(上一层输出)，经激活函数得到输出，最后输出与目标 0.5 比较。柱高是每一层权重的梯度大小（对数轴，1e-3 即千分之一）。反向时每过一层都要乘「w × 激活函数的斜率」，这个因子小于 1，层数越多梯度越小（梯度消失）。试试：保持 w = 1，切换 sigmoid / tanh / ReLU，把层数加到 12；再把 w 拖到 2.0，看连乘是缩小还是放大。

激活函数

梯度消失 = 靠前层的梯度小到几乎为零，权重基本不更新。本页只算一次梯度、不训练；结论只对这条各层权重相同的单神经元链成立。

第 5 步 · 终章

收束：用一次反向扫描分好责任

前向算出损失，反向沿链式法则一次连乘出每个权重的梯度，梯度下降据此修改权重；网络一深，连乘因子决定梯度是消失还是增长。

前向算损失

数字从输入流到输出，再与目标比较得到损失（第 0 步）。

推一下太贵

每个权重都要多算一次前向才能量斜率，参数多了不可行（第 1 步）。

反向连乘

链式法则从损失往回乘本地斜率，一次扫描得到所有梯度（第 2 步）。

下坡与深度

梯度下降用学习率 η 走下坡；层数越深，连乘因子决定梯度消失还是增长（第 3、4 步）。

模型与局限

全页是极小的单路径网络（1 个输入、1 个隐藏单元、1 个输出，没有偏置，没有批量数据）。真实网络有成千上万个权重和多条路径，反向传播在每个节点把多条路径的责任相加。第 3 步的收敛与振荡现象只对本页的损失和起点成立；第 4 步只比较一次梯度，不是训练曲线。
