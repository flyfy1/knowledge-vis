## 一个词怎样决定「看谁」？ {#step0 h2=s0t}

::: strings
nav0: 0 查询与键
:::

第 0 步 · 查询与键 {#s0k .step-kicker i18n=text}

这一步要回答：一个词（查询）怎样给其他词打「相关度」分？每个词有一个**键向量**（彩色箭头，表示「我是什么」）；正在提问的词发出一个**查询向量**（白色箭头，表示「我想找什么」）。两者的**点积** q·k = |q||k|cosθ 就是相关度分数：方向越一致分越高，反向则为负。先点选提问的词，再拖动「旋转查询」：长度不变，看哪个键最先被指向、下方柱高怎样变化；再拖「拉长查询」：方向不变，分数按比例放大。这里的向量是手工设定的二维玩具数据，不是训练出来的。 {#s0e .explain}

选择提问的词 {#s0tokL .cap i18n=text}

::: html step0-1
cv0: 二维平面上的键向量、查询向量与点积分数柱
s0rotL: 旋转查询（度）
s0mulL: 拉长查询（倍）
s0reset: 重置查询
:::

点积 = 对应分量相乘再相加；它的大小同时受夹角（方向）和长度影响。 {#s0term .term i18n=text}

::: strings
s0Q: 白色 = 「{w}」的查询
s0Keys: 彩色 = 各词的键
s0Bars: 分数 = 查询 · 键（点积）
s0ro: 「{w}」的查询长度 <b>{n}</b>，得分最高的键是「<b>{top}</b>」，分数 <b>{s}</b>（点积 = |q||k|cosθ，θ 为两向量夹角）。
:::

## 怎样把分数变成「看多少」？ {#step1 h2=s1t}

::: strings
nav1: 1 分数变权重
:::

第 1 步 · 分数变权重 {#s1k .step-kicker i18n=text}

这一步要回答：分数有正有负，怎样变成加起来等于 1 的「注意力权重」？**softmax** 先把每个分数 s 变成 e^(β·s)（恒为正，β 是锐度），再除以总和。上图是「sat」对各词的原始分数（步骤 0 的默认查询），下图是权重。拖动「锐度 β」，查询和键保持不变：β 变大，最高分的词几乎独占权重；β 趋向 0，权重趋于平均（每词 1/6）。β = 0.71 就是标准做法 1/√d_k（本页 d_k = 2，第 4 步解释为什么要除以 √d_k）。 {#s1e .explain}

::: html step1-1
cv1: 原始分数与 softmax 权重的柱图
s1bL: 锐度 β（标准值 0.71）
s1reset: 重置锐度
:::

熵 = 衡量权重有多分散：全部平均时最大，集中到一个词时为 0（单位：比特，越小越集中）。 {#s1term .term i18n=text}

::: strings
s1Sc: 「{w}」对每个词的原始分数
s1W: softmax 权重（β = {b}）
s1Uni: 平均线 1/6
s1ro: β = {b}：权重最大的是「<b>{top}</b>」，占 <b>{m}</b>；熵 <b>{h}</b> 比特（均匀分布为 {hm} 比特）；六个权重之和 {sum}。
:::

## 权重怎样变成输出？ {#step2 h2=s2t}

::: strings
nav2: 2 加权求和
:::

第 2 步 · 加权求和 {#s2k .step-kicker i18n=text}

这一步要回答：知道了「看谁多一点」，这个词的新表示是什么？每个词还有一个**值向量**（细箭头，表示「我能提供的内容」）。输出 = 各值向量按权重相加：o = Σ wⱼ·vⱼ。粗箭头把「权重 × 值」首尾相连，白点就是输出。拖动「查询方向」（长度不变，用标准的 1/√d_k）：看权重柱和粗箭头链怎样改变，绿线是输出点走过的轨迹；按「扫描」自动转一圈，亮线是已走过的部分。因为权重非负且和为 1，输出总落在值向量围成的范围之内。 {#s2e .explain}

::: html step2-1
cv2: 值向量、加权链、输出点轨迹和权重柱
s2thL: 查询方向（度）
s2reset: 重置并停止
:::

值向量 = 词「可被取走的内容」；输出是它们的加权平均，所以不会跑出这些向量围成的范围。 {#s2term .term i18n=text}

::: strings
s2play: ▶ 扫描一圈
s2pause: ⏸ 暂停
s2Out: 输出 o
s2Cap: 细箭头 = 值；粗链 = 权重×值
s2Wt: 当前权重
s2ro: 查询方向 <b>{d}°</b>：权重最大的是「<b>{top}</b>」；输出 o = (<b>{ox}</b>, <b>{oy}</b>)；轨迹已画 {k} / {n} 段。
:::

## 整句话一起看：注意力矩阵 {#step3 h2=s3t}

::: strings
nav3: 3 整句矩阵
:::

第 3 步 · 整句矩阵 {#s3k .step-kicker i18n=text}

这一步要回答：六个词同时各自提问，会得到怎样的表格？每一行是提问的词，每一列是被看的词，格子里是权重（行内相加为 1，越亮越大）。拖动「旋转所有查询」：键不变，相当于改变查询的生成方式（教学上代替训练出的权重矩阵），图案跟着重排。点「因果遮罩」：每个词只能看自己和前面的词（语言模型逐词生成时的做法），被遮住格子的权重为 0，其余重新归一。下方柱图是所选行的权重。 {#s3e .explain}

选择要细看的行 {#s3tokL .cap i18n=text}

::: html step3-1
cv3: 六个词的注意力权重矩阵与所选行的柱图
s3thL: 旋转所有查询（度）
s3reset: 重置矩阵
:::

遮罩后被遮格子取 0，再对剩下的格子做 softmax，所以每一行仍然相加为 1。 {#s3term .term i18n=text}

::: strings
s3Cols: 列 = 被看的词（键）
s3Rows: 行 = 提问的词
s3Row: 「{w}」这一行的权重
s3Mf: 无遮罩（每个词看全句）
s3Mc: 因果遮罩（只看自己和前面）
s3MaskOn: 因果遮罩：开（点击关闭）
s3MaskOff: 因果遮罩：关（点击开启）
s3ro: 查询旋转 <b>{th}°</b>，{mode}：各行权重之和在 {lo}–{hi} 之间；上三角（只看后面的词）的权重合计 <b>{up}</b>。选中「{w}」：最关注「<b>{top}</b>」，权重 <b>{tv}</b>。
:::

## 为什么要除以 √d_k？ {#step4 h2=s4t}

::: strings
nav4: 4 为何除以 √d
:::

第 4 步 · 为何除以 √d {#s4k .step-kicker i18n=text}

这一步要回答：向量维度 d 变大后，点积会怎样？随机向量 q 与 k（每个分量服从标准正态分布）的点积，标准差约为 √d。维度越大，分数越分散，softmax 越容易变成「一个词独占」；此时 softmax 饱和、梯度很小（本页只演示权重的集中程度，不演示训练）。把分数除以 √d 后，标准差回到约 1。拖动「维度 d」，其他不变：看橙色直方图（未缩放，横轴固定为 ±64）变宽、青色直方图（缩放后，横轴固定为 ±4）基本不变，以及下方单次试验里橙色柱是否「一柱擎天」。数据来自 300 次随机试验，每次 8 个键。 {#s4e .explain}

::: html step4-1
cv4: 点积直方图（未缩放与缩放后）与单次试验的权重柱
s4eL: 维度 d（2 的幂）
s4reset: 重置维度
:::

标准差 = 数据偏离平均值的典型幅度。随机试验会有小起伏，√d 是期望值。 {#s4term .term i18n=text}

::: strings
s4HU: 未缩放点积 q·k 的分布（标准差 {sd}）
s4HS: 缩放后 q·k/√d 的分布（标准差 {sd}）
s4Trial: 单次试验：8 个键的权重
s4Leg: 橙色 = 未缩放 softmax，青色 = 缩放后 softmax
s4ro: d = <b>{d}</b>：未缩放点积的标准差 <b>{sr}</b>（理论 √d = {ts}），缩放后 <b>{ss}</b>；8 个键里最大权重的平均值：未缩放 <b>{mu}</b>，缩放后 <b>{ms}</b>。
:::

## 收束：三步算出一个词的新表示 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

一个词怎样「环顾四周」：先用查询和键的点积打分，再用 softmax 变成权重，最后对值向量加权求和。 {#s5e .explain i18n=text}

::: html step5-1
c1t: 点积 = 相关度
c1b: 查询与键越同向分越高；长度也会放大分数（第 0 步）。
c2t: softmax = 权重
c2b: 把分数变成非负且和为 1 的权重；β 越大越集中（第 1 步）。
c3t: 加权求和 = 输出
c3b: 输出是值向量的加权平均，落在这些向量围成的范围内（第 2 步）。
c4t: 缩放与遮罩
c4b: 除以 √d_k 防止高维时权重塌缩成一个词；因果遮罩让每个词只看自己和前面（第 3、4 步）。
modelT: 模型与局限
modelB: 全页是手工设定的二维玩具向量（d_k = 2），不是训练出的 Q、K、V；真实模型使用高维向量、多个注意力头，以及由数据学出的线性投影。注意力权重只描述这一层怎样混合信息，不等于对模型输出原因的完整解释。第 4 步是随机模拟，数字会随随机种子起伏。
:::
