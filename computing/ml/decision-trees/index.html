决策树与信息增益

每一刀都问一个是非题：怎样挑最能降低混乱度的那一刀，一刀接一刀长成一棵树，又为什么不能长得太深。

第 0 步 · 不纯度

一组数据有多「混」？

这一步要回答：怎样用一个数衡量一组东西混得有多乱？想象 40 个点，每个点属于两类之一（圆点或方块）。不纯度：全是同一类时为 0，两类各占一半时最大。常用两个量：熵 H = −Σp·log₂p（单位：比特，p 是各类所占的比例，来龙去脉见熵 · 二元熵与二十问）和基尼不纯度 G = 1 − Σp²（两类时等于 2p(1−p)）。拖动「方块个数」：点阵怎样变化，两条曲线上的点怎样走；找出哪里最高，以及两端为什么都是 0。

两条曲线都在 p = 0.5 最高（熵 1 比特，基尼 0.5），在 p = 0 或 1（只剩一类）时为 0。

第 1 步 · 一刀切在哪

哪一刀切得最能把两类分开？

这一步要回答：沿一个特征切一刀（x 或 y 小于某个阈值），怎样算切得好？数据是人造的 80 个点（约 8% 的标签被故意翻错，模拟噪声）。切完后，两边各自的混乱程度（熵）按点数加权平均，叫切后熵；信息增益 = 切前熵 − 切后熵（单位比特，越大越好，0 表示这一刀毫无帮助）。先选特征，再拖动阈值：白线移动时，下方曲线上的橙点怎样走；白点是所有阈值里增益最大的位置。读数里列出两边各类的个数。

增益只是在这 80 个点上算出的；数据少，最佳阈值会随样本抖动。

第 2 步 · 长成一棵树

一棵树是怎样一刀接一刀长出来的？

这一步要回答：对分出来的每个区域继续切，树怎样一步步长大？规则很简单：每一步在所有区域里挑「按区域所占比例加权后信息增益最大」的一刀（贪心：只看眼前最好，不回头）。拖动「切的刀数」（或按「自动生长」）：上图是点的分区（白线 = 切线，底色 = 该区域的多数类，红圈 = 被当前这棵树分错的点）；下图是树，每个圆是一个区域，橙色扇形的占比 = 方块所占的比例。观察：前几刀把大块分开，分错的点迅速减少；后面的刀只是在抠个别点。

叶子 = 不再继续切的区域，它的预测是区域内的多数类。准确率只在训练集上测得，不代表新数据。

第 3 步 · 长多深

树越深越好吗？

这一步要回答：把树长得更深，对没见过的新数据也更好吗？这里用最大深度（从根到叶子最多切几刀）限制树的大小，并用另外 600 个点（按真实规则生成、没有噪声）当作「新数据」。橙线是训练集准确率，青线是新数据准确率。拖动「最大深度」，噪声不变：看深度增大时橙线逼近 100%，而青线先升后降；再把「标签噪声」调到 0，两条线的关系怎样变化。多项式版本的同一现象见过拟合 · 训练误差与测试误差。

准确率 = 判对的点数 / 总点数。「新数据」是同一条真实规则生成的 600 个无噪声点。结论只对这套固定数据成立。

第 4 步 · 用树判断

来了一个新点，树怎么给它分类？

这一步要回答：训练好的树怎样判断一个新点？拖动查询点的 x、y（十字）：树从根出发回答一连串「是/否」问题，沿着白线走到的叶子，就是它的类别；叶子里各类的比例给出一个粗略的把握度。再调「最大深度」：树越浅，问的问题越少，判断越粗。

把握度 = 叶子里多数类所占的比例，只反映训练点的分布，不是校准过的概率。

第 5 步 · 终章

收束：用最少的问题把两类分开

决策树把「二十个问题」变成算法：用不纯度衡量混乱，用信息增益挑最好的一问，贪心地一刀接一刀，再用深度控制它别学到噪声。

不纯度

全是一类为 0，对半分最大；熵与基尼都可用（第 0 步）。

信息增益

切前熵减去切后熵（按点数加权），越大越好（第 1 步）。

贪心长树

每步挑加权增益最大的一刀；前几刀见效最大，后面在抠个别点（第 2 步）。

深度与新数据

训练准确率随深度只升不降，新数据准确率在有噪声时先升后降（第 3、4 步）。

模型与局限

数据是人造的二维两类点（真实规则是两个矩形，训练标签带噪声）；每一刀只能与坐标轴平行；贪心不保证整棵树最优；本页用熵，基尼不纯度常得到相近的树；没有剪枝，也没有交叉验证。准确率的比较只对这套固定数据成立。
