## 一组数据有多「混」？ {#step0 h2=s0t}

::: strings
nav0: 0 不纯度
:::

第 0 步 · 不纯度 {#s0k .step-kicker i18n=text}

这一步要回答：怎样用一个数衡量一组东西混得有多乱？想象 40 个点，每个点属于两类之一（圆点或方块）。**不纯度**：全是同一类时为 0，两类各占一半时最大。常用两个量：**熵** H = −Σp·log₂p（单位：比特，p 是各类所占的比例，来龙去脉见[[entropy#step3|熵 · 二元熵与二十问]]）和**基尼不纯度** G = 1 − Σp²（两类时等于 2p(1−p)）。拖动「方块个数」：点阵怎样变化，两条曲线上的点怎样走；找出哪里最高，以及两端为什么都是 0。 {#s0e .explain}

::: html step0-1
cv0: 点阵与熵、基尼曲线
s0kL: 方块个数（共 40 个点）
s0reset: 重置
:::

两条曲线都在 p = 0.5 最高（熵 1 比特，基尼 0.5），在 p = 0 或 1（只剩一类）时为 0。 {#s0term .term i18n=text}

::: strings
s0Dots: 40 个点：圆点 = 一类，方块 = 另一类
s0Curve: 不纯度随方块比例 p 的变化
s0Ax: 方块比例 p：0 → 1
s0LegE: 青 = 熵（比特）
s0LegG: 绿 = 基尼不纯度
s0ro: 方块 <b>{k} / {n}</b>，比例 p = {p}：熵 <b>{h}</b> 比特，基尼 <b>{g}</b>。
:::

## 哪一刀切得最能把两类分开？ {#step1 h2=s1t}

::: strings
nav1: 1 一刀切在哪
:::

第 1 步 · 一刀切在哪 {#s1k .step-kicker i18n=text}

这一步要回答：沿一个特征切一刀（x 或 y 小于某个阈值），怎样算切得好？数据是人造的 80 个点（约 8% 的标签被故意翻错，模拟噪声）。切完后，两边各自的混乱程度（熵）按点数加权平均，叫**切后熵**；**信息增益** = 切前熵 − 切后熵（单位比特，越大越好，0 表示这一刀毫无帮助）。先选特征，再拖动阈值：白线移动时，下方曲线上的橙点怎样走；白点是所有阈值里增益最大的位置。读数里列出两边各类的个数。 {#s1e .explain}

::: html step1-1
s1fxL: 用 x 切
s1fyL: 用 y 切
cv1: 散点、切线与增益曲线
s1tL: 阈值
s1reset: 重置
:::

增益只是在这 80 个点上算出的；数据少，最佳阈值会随样本抖动。 {#s1term .term i18n=text}

::: strings
s1Scat: 白线 = 切线；圆点与方块 = 两类
s1Gain: 沿「{f}」切：增益 vs 阈值
s1Best: 最佳
s1ro: 沿「{f}」，小于 {t} 的一侧：圆点 {l0} / 方块 {l1}；其余一侧：圆点 {r0} / 方块 {r1}。切前熵 {hp}，切后熵 {ha}，信息增益 <b>{g}</b> 比特。这个特征的最佳阈值 {bt}，最大增益 {bg}。
:::

## 一棵树是怎样一刀接一刀长出来的？ {#step2 h2=s2t}

::: strings
nav2: 2 长成一棵树
:::

第 2 步 · 长成一棵树 {#s2k .step-kicker i18n=text}

这一步要回答：对分出来的每个区域继续切，树怎样一步步长大？规则很简单：每一步在所有区域里挑「按区域所占比例加权后信息增益最大」的一刀（**贪心**：只看眼前最好，不回头）。拖动「切的刀数」（或按「自动生长」）：上图是点的分区（白线 = 切线，底色 = 该区域的多数类，红圈 = 被当前这棵树分错的点）；下图是树，每个圆是一个区域，橙色扇形的占比 = 方块所占的比例。观察：前几刀把大块分开，分错的点迅速减少；后面的刀只是在抠个别点。 {#s2e .explain}

::: html step2-1
cv2: 点的分区与对应的决策树
s2nL: 切的刀数
s2reset: 重置为 0 刀
:::

叶子 = 不再继续切的区域，它的预测是区域内的多数类。准确率只在训练集上测得，不代表新数据。 {#s2term .term i18n=text}

::: strings
s2play: ▶ 自动生长
s2pause: ⏸ 暂停
s2Scat: 分区：白线 = 切线，红圈 = 分错的点
s2Tree: 树：圆的橙色扇形 = 方块占比
s2Last: 沿「{f}」在 {t}（增益 {g} 比特，作用于 {m} 个点）
s2None: 还没切：整棵树只有一个区域，全部判为多数类
s2ro: 已切 <b>{got}</b> 刀（滑块 {n}），共 {leaves} 个叶子区域；训练集准确率 <b>{acc}</b>，分错 {wrong} 个点。最新一刀：{last}。
:::

## 树越深越好吗？ {#step3 h2=s3t}

::: strings
nav3: 3 长多深
:::

第 3 步 · 长多深 {#s3k .step-kicker i18n=text}

这一步要回答：把树长得更深，对没见过的新数据也更好吗？这里用**最大深度**（从根到叶子最多切几刀）限制树的大小，并用另外 600 个点（按真实规则生成、没有噪声）当作「新数据」。橙线是训练集准确率，青线是新数据准确率。拖动「最大深度」，噪声不变：看深度增大时橙线逼近 100%，而青线先升后降；再把「标签噪声」调到 0，两条线的关系怎样变化。多项式版本的同一现象见[[overfitting#step1|过拟合 · 训练误差与测试误差]]。 {#s3e .explain}

::: html step3-1
cv3: 准确率随最大深度的变化
s3dL: 最大深度
s3zL: 训练标签噪声（被翻错的比例）
s3reset: 重置
:::

准确率 = 判对的点数 / 总点数。「新数据」是同一条真实规则生成的 600 个无噪声点。结论只对这套固定数据成立。 {#s3term .term i18n=text}

::: strings
s3Cap: 准确率与最大深度（竖线 = 当前深度）
s3Ax: 最大深度 1 → 10
s3LegTr: 橙 = 训练集
s3LegTe: 青 = 新数据
s3ro: 最大深度 <b>{d}</b>，噪声 {z}%：{leaves} 个叶子；训练准确率 <b>{tr}</b>，新数据准确率 <b>{te}</b>。新数据准确率最高的深度是 {bk}（{bt}）。
:::

## 来了一个新点，树怎么给它分类？ {#step4 h2=s4t}

::: strings
nav4: 4 用树判断
:::

第 4 步 · 用树判断 {#s4k .step-kicker i18n=text}

这一步要回答：训练好的树怎样判断一个新点？拖动查询点的 x、y（十字）：树从根出发回答一连串「是/否」问题，沿着白线走到的叶子，就是它的类别；叶子里各类的比例给出一个粗略的把握度。再调「最大深度」：树越浅，问的问题越少，判断越粗。 {#s4e .explain}

::: html step4-1
cv4: 查询点、分区与树上的路径
s4dL: 最大深度
s4xL: 查询点 x
s4yL: 查询点 y
s4reset: 重置
:::

把握度 = 叶子里多数类所占的比例，只反映训练点的分布，不是校准过的概率。 {#s4term .term i18n=text}

::: strings
s4Scat: 十字 = 查询点；白框 = 它所在的叶子区域
s4Tree: 树：白线 = 查询点走过的路径
s4NoQ: 树只有根，没有问题
s4ro: 查询点 ({x}, {y})：回答了 <b>{k}</b> 个问题（{q}）；所在叶子里 圆点 {c0} / 方块 {c1}；预测类别 <b>{cls}</b>，把握度 {conf}。
:::

## 收束：用最少的问题把两类分开 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

决策树把「二十个问题」变成算法：用不纯度衡量混乱，用信息增益挑最好的一问，贪心地一刀接一刀，再用深度控制它别学到噪声。 {#s5e .explain i18n=text}

::: html step5-1
c1t: 不纯度
c1b: 全是一类为 0，对半分最大；熵与基尼都可用（第 0 步）。
c2t: 信息增益
c2b: 切前熵减去切后熵（按点数加权），越大越好（第 1 步）。
c3t: 贪心长树
c3b: 每步挑加权增益最大的一刀；前几刀见效最大，后面在抠个别点（第 2 步）。
c4t: 深度与新数据
c4b: 训练准确率随深度只升不降，新数据准确率在有噪声时先升后降（第 3、4 步）。
modelT: 模型与局限
modelB: 数据是人造的二维两类点（真实规则是两个矩形，训练标签带噪声）；每一刀只能与坐标轴平行；贪心不保证整棵树最优；本页用熵，基尼不纯度常得到相近的树；没有剪枝，也没有交叉验证。准确率的比较只对这套固定数据成立。
:::
