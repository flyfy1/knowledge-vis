## 曲线该有多弯？ {#step0 h2=s0t}

::: strings
nav0: 0 拟合曲线
:::

第 0 步 · 拟合一条曲线 {#s0k .step-kicker i18n=text}

这一步要回答：用多项式去拟合 12 个带噪声的点，曲线应该多「弯」？**多项式的次数** d 越大，曲线越灵活（d 次多项式有 d+1 个可调系数）。点是在真实曲线 y = sin(2πx)（白色虚线）上加了随机噪声（标准差 0.25）得到的；橙线是用**最小二乘**（让各点到曲线的竖直误差平方和最小）拟合出的曲线。拖动次数 d：d = 0、1 时曲线太僵硬，抓不住起伏（欠拟合）；d = 11 时曲线刚好穿过每个点，却在点与点之间乱晃（过拟合）。读数里的**训练 RMSE** 是曲线到这 12 个点的平均误差（均方根），越小说明越贴着训练点。 {#s0e .explain}

s0reset: 重置
:::

RMSE = 误差平方的平均再开方，单位与 y 相同。训练 RMSE 只说明对已见数据的贴合程度。 {#s0term .term i18n=text}

## 贴得越紧就越好吗？ {#step1 h2=s1t}

## 加数据能治过拟合吗？ {#step2 h2=s2t}

::: strings

第 2 步 · 数据越多越稳 {#s2k .step-kicker i18n=text}

这一步要回答：固定一条很灵活的曲线（d = 9），样本数 n 增加会怎样？拖动「训练点数 n」：上图是用 n 个点拟合出的曲线，下图是**学习曲线**：横轴 n，青线是训练 RMSE，橙线是测试 RMSE。n 很小时橙线冲出图外（曲线在点间乱晃）；n 增大后两线逐渐靠拢到噪声线附近，说明足够的数据能约束住灵活的模型。注意：每个 n 的点都是按固定种子重新生成的，同一 n 的数值依赖这个种子。 {#s2e .explain}

## 同一个模型，换一批数据会怎样？ {#step3 h2=s3t}

::: strings
nav3: 3 换批数据
:::

第 3 步 · 换批数据 {#s3k .step-kicker i18n=text}

这一步要回答：高次拟合为什么「不稳定」？每按一次按钮，就用一批新的 12 个带噪声的点重新拟合一次，橙色细线累积在图上，绿线是这些拟合的平均。拖动次数 d：d 小时，每次拟合都差不多，但整体偏离真实曲线（**偏差**大）；d 大时，平均线接近真实曲线，但每次拟合各不相同，散布很大（**方差**大）。读数给出两者的数值：偏差² = 平均拟合与真实曲线之差的平方的平均；方差 = 各次拟合偏离平均拟合的平方的平均（都在 0 到 1 之间的 41 个格点上算，至少 2 批才有值）。 {#s3e .explain}

::: html step3-1
s3mL: 已拟合的批数

s3dL: 多项式次数 d
s3add: 再来一批数据
s3add5: 再来 5 批
s3reset: 清空所有拟合
:::

偏差² 衡量「平均下来偏了多少」，方差衡量「换批数据晃了多少」；最多 20 批，数值有随机涨落。 {#s3term .term i18n=text}

## 能不能不减次数，也管住曲线？ {#step4 h2=s4t}

::: strings
nav4: 4 正则化
:::

第 4 步 · 正则化 {#s4k .step-kicker i18n=text}

这一步要回答：不降低次数，怎样让灵活的曲线别乱晃？**岭回归（L2 正则化）**在最小化误差平方和的同时惩罚系数的大小：目标 = Σ(误差)² + λ·Σ(系数)²。λ 越大，系数被压得越小，曲线越平滑。固定 d = 11、12 个点，拖动 λ（对数刻度）：λ 极小时曲线穿过每个点（训练误差 0）并乱晃；适中的 λ 让测试误差大幅下降；λ 太大则曲线被压平，重新欠拟合。白点是扫描范围内测试误差最低的 λ。 {#s4e .explain}

::: html step4-1
cv4: 岭回归拟合与误差随 λ 的变化
s4lL: 惩罚强度 λ（对数）
s4reset: 重置
:::

λ 是我们设的惩罚强度（超参数），应当用没参与拟合的数据来选；本页用同一批测试点来选，真实使用时要另留验证集。 {#s4term .term i18n=text}

:::

## 收束：灵活度要刚刚好 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

训练误差只会随灵活度下降，没见过的数据上的误差先降后升；数据量、正则化和对「换批数据会晃多少」的认识，是管住它的三个抓手。 {#s5e .explain i18n=text}

::: html step5-1
c1t: 欠拟合与过拟合
c1b: 太僵硬抓不住规律，太灵活把噪声也记下来（第 0 步）。
c2t: 训练 ≠ 测试
c2b: 训练误差一路降，测试误差先降后升，最低点是刚好的复杂度（第 1 步）。
c3t: 数据与正则化
c3b: 更多数据或适度的 λ 都能约束灵活的模型（第 2、4 步）。
c4t: 偏差与方差
c4b: 次数小：偏差大方差小；次数大：偏差小方差大（第 3 步）。
modelT: 模型与局限
modelB: 数据来自 sin(2πx) 加高斯噪声，模型只有一元多项式（用 Chebyshev 基求解）；训练点与测试点由固定种子生成，数值随种子变化；最佳次数和最佳 λ 都是在这套数据上得到的。真实问题还需要验证集或交叉验证，并且模型和噪声要复杂得多。
:::
