## 运动的光钟滴答更慢 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 光钟
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 光速不变的后果
:::

这一步要回答：如果光速对所有观察者都一样，时间会怎样？**光钟**由两面镜子和来回弹的一束光组成，光走一个来回就是一次“滴答”。这里取 c = 1，速度 β 表示占光速的比例。静止时光沿竖直线走（绿色，距离 1）。观察者看到钟以 β 向右运动，光在两镜之间必须斜着走：它既要升高 1，又要随钟水平移动 βγ，而光速不变，所以斜线更长，花的时间更多：运动的钟被观察者看到滴答间隔变长为 **γ = 1/√(1 − β²)** 倍，这叫**时间膨胀**。**观察：**拖动 β：斜线越来越倾斜；β = 0.99 时 γ ≈ 7。这里是理想光钟，结论对任何钟成立。 {#s0e .explain}

::: html step0-2
s0cv: 左：静止光钟，光竖直走；右：运动光钟，观察者看到光斜着走，路径更长
betaL: 钟的速度 β（光速的比例）
:::

:::

## 换一个观察者，同一个事件的坐标怎么变？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 时空图
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 把事件画在时空图上
:::

这一步要回答：不同观察者怎样给同一个事件标坐标？**时空图**横轴是位置 x，纵轴是 ct（光在这段时间走的距离），所以光的轨迹是 45° 的橙色虚线。**事件**是时空中的一个点；A 是原点，B 可以拖动。以速度 β 运动的观察者有自己的坐标轴（青色）：他的时间轴 ct′ 是他自己的世界线（x = β·ct），他的空间轴 x′ 同样向光线倾斜（ct = β·x），网格也随之斜过去。**洛伦兹变换**：x′ = γ(x − β·ct)，ct′ = γ(ct − β·x)。**观察：**拖动 β：青色轴向橙色光线并拢，但光线永远在 45°；**间隔** ct² − x² 在所有观察者那里相同。ct² − x² &gt; 0（类时）的两事件，所有观察者对先后顺序一致；&lt; 0（类空）则不然。 {#s1e .explain}

:::

## 我看到两道闪电同时发生，运动的人会怎么看？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 同时性
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: “同时”不是绝对的
:::

这一步要回答：同时发生的两件事，对运动的观察者还同时吗？在静止系里，闪电 E₁ 与 E₂ 分别在 x = −2 和 x = +2，同一时刻 ct = 0 发生（灰色横线）。对以 β 向右运动的观察者，“同一时刻”的事件落在斜率为 β 的线上（青色轴 x′ 的方向），也就是虚线：E₁ 与 E₂ 落在不同的虚线上，因此在他的时间读数 ct′ 里不同时。**观察：**拖动 β，两条虚线越倾斜，E₂ 与 E₁ 的时间差 −4γβ 越大：他看到右边的 E₂ 先发生。同时性的这种相对性，是前两步“光速不变”的直接后果；类空分隔的事件才能被不同观察者排成不同顺序，不会造成因果矛盾。 {#s2e .explain}

:::

## 它们寿命只有 2.2 微秒，怎么能飞到地面？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 缪子的寿命
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 缪子的证据
:::

这一步要回答：时间膨胀有实际证据吗？宇宙射线在 15 km 高空产生缪子，静止时平均寿命 2.2 μs，飞行速度 β 接近光速。若没有相对论，它走完 15 km 需要 t = 15 km / (β·c)，存活概率约为 e<sup>−t/2.2 μs</sup>——小得几乎为零。有了时间膨胀，地面观察者看到缪子的寿命延长为 γ × 2.2 μs，存活概率大得多，实测与后者相符。从缪子自己看，是它面前的 15 km 被缩短成 15 km/γ（**长度收缩**）。**观察：**拖动 β，两条条的对数长度表示存活概率：红色（没有相对论）直接沉底，绿色（相对论）还剩可观的比例。 {#s3e .explain}

## 在 0.8c 的飞船里再以 0.8c 发射一束东西，对地面是 1.6c 吗？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 速度合成
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 光速不能叠加
:::

这一步要回答：怎样把两个速度合在一起？日常经验是直接相加 u = v + w。但如果光速不变，这个公式必然失效：相对论速度合成为 **u = (v + w)/(1 + v·w)**（单位 c）。**观察：**拖动 v 与 w：红色条是朴素相加，超过 1（光速）会标红；绿色条永远不超过 1；当 w = 1（飞船里射出一束光）时，不论 v 是多少，u = 1，光速对每个观察者都一样。下面的曲线是固定 v 时 u 对 w 的变化。v 和 w 都很小（比如 0.05）时，两个公式几乎相同，所以日常生活中看不出差别。 {#s4e .explain}

:::

## 把一个粒子加速到光速，要花多少能量？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 能量与光速
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 为什么到不了光速
:::

这一步要回答：为什么有质量的东西追不上光？经典的动能是 ½mv²（图中青线，以 mc² 为单位 ½β²），而相对论的动能是 (γ − 1)·mc²（橙线）。两者在低速时几乎重合，随着 β 接近 1，γ 趋于无穷，所需的能量发散：β = 0.99 时动能已是静止能量 mc² 的 6 倍多。**观察：**拖动 β：橙点越来越陡地向上蹿；读数还给出电子（静止能量 0.511 MeV）此时的动能。粒子加速器里的粒子速度看上去几乎不再增加，加进去的能量几乎全转成了 γ，也就是质量—能量。 {#s5e .explain}
