## 光照在金属上：什么时候有电子出来？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 光打金属
:::

::: html step0-1
:::

这一步要回答：光打到金属板上，什么条件下会打出电子？点播放：左侧射来的小点是**光子**（一份一份的光，能量 E = hf，h 是普朗克常数，f 是光的频率），金属板在右侧。每个光子被吸收时，如果 E 大于金属的**逸出功** φ（把一个电子拉出金属所需的最小能量），就打出一个电子（本页理想化为 1 个光子 1 个电子；真实效率远低于此）。颜色表示频率，可见光之外用偏暗的紫/红表示。本页金属为钠（φ ≈ 2.36 eV）。 {#s0e .explain}

## 一个光子对一个电子：能量账本 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 能量账本
:::

::: html step1-1
:::

这一步要回答：光子的能量去哪了？一个光子把全部能量 hf 交给一个电子，其中 φ 用来脱离金属，剩下变成电子的动能：**E_k,max = hf − φ**（最大值：从表面逸出的电子）。如果 hf < φ，一个光子的能量不够，电子出不来，多个光子也不能叠加。当 hf = φ 时的频率叫**截止频率** f₀ = φ/h。图中青色柱是 hf，橙线是 φ，绿色部分是剩下的动能；右侧表头显示光电流（电子数目），与光强成正比。 {#s1e .explain}

::: html step1-2
s1o: 选钠，把 f 从 3 慢慢拉高：柱顶越过橙线的瞬间，动能出现、电流出现；然后把光强拉到最大，但保持 f 低于截止频率：电流仍然为零。换成锌，截止频率移到哪里？
mCs: 铯 Cs（φ≈2.14 eV）
mNa: 钠 Na（φ≈2.36 eV）
mZn: 锌 Zn（φ≈4.3 eV）
:::

nameCs: 铯

:::

## 用实验点量出普朗克常数 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 测普朗克常数
:::

::: html step2-1
:::

这一步要回答：能不能用光电效应测出 h？E_k,max = hf − φ 是 f 的一次函数：斜率是 h，纵轴截距是 −φ。拖动 f，点“记录”，在图上加一个“测得”的点（加了固定的小幅模拟测量误差 ±0.04 eV，这是模拟，不是实测）。点够多后，用最小二乘直线拟合，读数给出由斜率得到的 h（真值 4.136×10⁻¹⁵ eV·s）和由截距得到的 φ。右图是电流与光强的关系：过了门槛，电流与光强成正比。 {#s2e .explain}

## 遏止电压：用反向电压把电子“挡回去” {#step3 h2=s3t pre=1}

::: strings
nav3: 3 遏止电压
:::

::: html step3-1
:::

这一步要回答：怎样直接测出电子的最大动能？在收集板上加反向电压 V，电子要克服 eV 的势垒才能到达。当 eV 刚好等于 E_k,max 时，最快的电子也到不了，光电流变成零，这个 V 叫**遏止电压** V_s = E_k,max/e。本页假设电子动能在 0 到 E_k,max 之间均匀分布，所以 I = I₀(1 − V/V_s)，这是简化，真实曲线更圆滑。灰色虚线是光强减半的曲线：光强只改变电流大小，不改变 V_s。 {#s3e .explain}

::: html step3-2
s3o: 选一种金属，调 f 高于截止频率，把 V 从负向正拉：电流在 V = V_s 处降为零；再提高 f，V_s 右移；对照读数里 V_s = E_k,max（以 eV 为单位的数值）。
lV: 反向电压 V（V）
:::

::: strings
r3: {metal}：hf = {e} eV，E_k,max = {ke} eV，V_s = {vs} V；当前 V = {v} V，光电流（相对）= {cur}。
:::

## 为什么经典波动模型解释不了？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 波动模型的矛盾
:::

::: html step4-1
:::

这一步要回答：如果光是连续的波，会发生什么？波动模型预测：光强越大，电子越快（与实验不符）；而且光很暗时，一个原子要从波里**积累**足够能量才能放出电子。估算：一个原子截面约 A = 10⁻¹⁹ m² 接收功率 P = I·A，积累 φ 需要 t = φ/(I·A)。光子模型：整块金属（取 10⁻⁴ m²）每秒接收 I·A_板/(hf) 个光子，第一个光子到达的时间约 hf/(I·A_板)。下图横轴是对数时间（秒）。实验里电子几乎立刻（<10⁻⁹ s）出现，与光子模型一致。本页取钠，f = 7×10¹⁴ Hz。 {#s4e .explain}

::: html step4-2
s4o: 把光强从 10⁻⁴ 拉到 1 W/m²：看橙色柱（波动积累时间）从数小时缩到约 1 秒的量级，但仍远长于蓝色柱（光子模型，十亿分之一秒量级）。
lIlog: 光强 I（数量级 10^x W/m²）
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 光由光子组成，E = hf；② 一个光子给一个电子，E_k,max = hf − φ，φ 是逸出功；③ 低于截止频率 f₀ = φ/h，光再强也没有电子；④ 光强只决定电子个数（电流），不决定最大动能；⑤ V_s = E_k,max/e；⑥ 用 E_k,max–f 直线斜率可测 h。 {#s5e .explain}

::: html step5-2
qq: 用低于截止频率的光照金属，把光强增大到原来的 10 倍，会发生什么？

qo1: 仍然没有电子
qo2: 电子数不变，动能增大
s5m: 本页是理想化模型：一个光子最多打出一个电子（真实量子效率约 0.1%–10%），电子动能均匀分布（真实更复杂），忽略接触电势、温度、表面状态和空间电荷；逸出功取常见教材近似值；第 2 步的模拟测量误差是人为加入的；第 4 步为数量级估算；动画是教学慢放，光子和电子速度不代表真实值。
lk0: 原子结构页：电子为什么被束缚在原子里，需要能量才能挣脱
lk1: 透镜页：光学线的几何光学，对照这里光作为粒子的一面
lk2: 干涉页：光的波动性证据，与光电效应互补
:::

::: strings
qwhy: 一个光子的能量 hf < φ，不够逸出，光强只是光子更多，每个光子仍然不够（第 1 步可验证）。
:::
