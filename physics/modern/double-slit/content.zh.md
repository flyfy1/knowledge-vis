::: strings

:::

<b>这一步回答：条纹间距怎样随波长和缝距变化？</b>两条狭缝到屏上某点的路程差是 d·sinθ，等于波长的整数倍时加强。小角度下亮条纹间距 Δy = λL/d：波长越长、屏越远、缝越近，条纹越稀。下方灰度条是屏上看到的样子。（路程差与相长相消的逻辑见干涉页，这里只关心条纹间距。） {#s0e .explain}

## 条纹为什么越往两边越暗，甚至整体消失？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 单缝包络
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 单缝包络
:::

<b>这一步回答：每条缝本身的宽度起什么作用？</b>真实的缝有宽度 a，每条缝自己就会衍射，亮度按 sinc² 包络下降，在 y = ±λL/a 处降到 0（红色虚线）。双缝的细密条纹被这个包络“罩”着：I = cos²(πdy/λL)·sinc²(πay/λL)。缝越窄，包络越宽，可见条纹越多；青线是只开一条缝的结果。拖动缝宽与缝距。 {#s1e .explain}

:::

## 每次只发一颗粒子，条纹还会出现吗？ {#step2 h2=s2t pre=1}

::: strings

:::

::: html step2-1

<b>这一步回答：单个粒子的落点怎样一点点累积成条纹？</b>每颗粒子在屏上只留下一个点，位置按上面的强度曲线随机抽取（固定随机种子，可重复）。几十颗时像一团乱点，几千颗后条纹清晰可见——条纹是概率分布，不是单个粒子的轨迹。读数统计落在“暗纹区”（强度小于 5%）的粒子数。 {#s2e .explain}

## 如果能知道粒子走了哪条缝，条纹会怎样？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 哪条缝
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 知道走了哪条缝
:::

<b>这一步回答：路径信息与干涉有什么关系？</b>可见度 V 与“可区分度”D（探测器能多可靠地判定走了哪条缝）满足 V² + D² ≤ 1（这里取等号的理想情形）。D = 0：不知道走哪条缝，条纹完全清晰；D = 1：完全知道，条纹消失，只剩两个单缝图样叠加。关键不是“被打扰”，而是“信息能否区分两条路径”。拖动 D。 {#s3e .explain}

:::

## 电子能干涉，为什么棒球不能？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 物质波
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 物质的波长
:::

<b>这一步回答：什么时候“波动性”才看得见？</b>德布罗意波长 λ = h/(mv)。电子在 10⁶ m/s 时约 7×10⁻¹⁰ m，与晶体间距相当，能衍射；富勒烯 C₆₀ 以 200 m/s 飞行 λ 约 3×10⁻¹² m，仍已被实验观测到干涉；棒球的 λ 约 10⁻³⁴ m，小到永远不可能观察。读数用缝距 100 nm、屏距 1 m 估计条纹间距，并判断能否分辨（间距大于 1 µm）。速度滑杆以对数倍数调整。 {#s4e .explain}

## 有哪些因素能让条纹消失？ {#step5 h2=s5t pre=1}

s5k: 终章 · 条纹由什么决定

<b>这一步回答：条纹的清晰度取决于哪几件事？</b>三个旋钮：关上第二条缝（只剩单缝包络）；增大路径区分度 D（条纹对比度 V = √(1−D²) 下降）；增大波长的离散度（不同波长的条纹错开，条纹被抹平）。读数用屏上一个条纹周期内的最大最小值计算可见度 V = (I_max − I_min)/(I_max + I_min)。 {#s5e .explain}
