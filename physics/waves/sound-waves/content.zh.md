## 声音在空气里传，是什么在动？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 一疏一密
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 空气里的波
:::

这一步要回答：声音在空气中传播的是什么？上方一排青色小点是空气里的一排分子（示意）；声源让它们来回挤压，挤得紧的地方（亮点）和松的地方（暗点）一疏一密向前传，但每个点自己只在原地来回小幅移动，并没有跟着波跑走（图中位移已极度夸大，真实位移只有微米量级）。下方橙色曲线是各处的**压强**变化：峰处最挤，谷处最松。一个“疏密”周期的长度就是**波长 λ**（绿色线段），一秒钟里发生多少次疏密就是**频率 f**。声音在空气中的速度约 343 m/s。**观察：**拖动频率：疏密变密，波长 λ = v/f 变短；拖动振幅：疏密的反差变大（声音更响，[[sound-vibration#step1|响度]]见上一页），但疏密间距不变。动画放慢了 250 倍，可以暂停。 {#s0e .explain}

## 同一列声波，示波器上的一个周期和地上的一个波长，是什么关系？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 v = fλ
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 时间上看与空间上看
:::

这一步要回答：怎样把“频率”和“波长”联系起来？上图是在**一个固定位置**记录压强随**时间**变化（像示波器屏幕）：一个完整起伏的时间是**周期 T**，T = 1/f；下图是在**某一瞬间**拍下各处压强随**位置**变化：一个完整起伏的长度是**波长 λ**。波每个周期向前走一个波长，所以速度 **v = fλ**（即 λ = v/f）。**观察：**选介质（空气 343、水 1480、钢 5000 m/s）并拖动频率：同一频率下，周期不变（上图不变），波长随介质变大（下图拉长）；同一介质里频率越高波长越短。 {#s1e .explain}

## 两个音调几乎一样的声音同时响，为什么会“嗡——嗡——”地忽强忽弱？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 拍
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 两个声音叠在一起
:::

这一步要回答：两列声波叠加会怎样？同一点的压强等于两列波分别产生的压强相加（叠加原理，见[[standing-wave#step0|驻波]]里的叠加）。当两个频率 f₁、f₂ 很接近时，它们一会儿同相（相加变强）、一会儿反相（相互抵消变弱），合成波的幅度按 |f₁ − f₂| 的频率忽强忽弱，这叫**拍**，**拍频** = |f₁ − f₂|。青色是合成波，橙色是它的包络（强弱的轮廓）。**观察：**把 f₂ 慢慢移向 f₁：忽强忽弱越来越慢，相等时消失；差大于约 15 Hz 时听起来变成粗糙的“颤音”而不是一下一下的拍（这是人耳的特性，不是公式）。调音师就是用拍来对准两根弦。这里没有播放声音，只画波形。 {#s2e .explain}

## 同一个音，钢琴和小提琴为什么听起来不同？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 音色
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 音调一样，音色不一样
:::

这一步要回答：音色由什么决定？除了基本频率 f 的正弦波（第 1 谐波）外，乐器还同时发出 2f、3f、4f……的正弦波（**谐波**），强弱各不相同；它们叠加后，整体周期仍是 1/f（音调不变），但波形形状变了，这就是**音色**。右边的柱子是各谐波的强度（频谱）。三种模式：只有基音的纯正弦；只含奇数次谐波（像单簧管，波形偏方）；所有谐波（像小提琴，波形偏锯齿）。滑杆 b 控制高次谐波衰减得多快：谐波强度 ∝ n⁻ᵇ。**观察：**切换模式、拖 b：绿色线段（一个周期）始终一样长，而曲线的形状（尖不尖、方不方）在变化。 {#s3e .explain}

## 看到闪电后数几秒才听到雷声，怎样算距离？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 打雷的距离
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 打雷离你多远
:::

这一步要回答：怎样用声速估算雷电的距离？光几乎瞬间到达（光速 3×10⁸ m/s），而声音在空气中约每秒 343 m（0 ℃ 时 331.3 m/s，温度每升 1 ℃ 约增加 0.6 m/s：v ≈ 331.3 + 0.606T），所以闪电和雷声之间的间隔就是声音走完这段距离的时间：距离 d = v·Δt。大约每 3 秒 ≈ 1 km。**观察：**拖动温度和间隔：间隔越长越远；温度高时声音略快，同样的间隔对应略远的距离；读数里给出光走这段距离的时间，小到可以忽略。这是均匀空气的近似，真实声速还受风、湿度和高度影响。 {#s4e .explain}

## 声音一定是人耳听得见的吗？ {#step5 h2=s5t pre=1}

::: strings

::: html step5-1

s5k: 听得见的范围

这一步要回答：声波的频率范围有多大，人耳能听到哪一段？横轴是频率（对数刻度，1 Hz 到 1 MHz）。人耳大约听到 20 Hz 到 20000 Hz：低于它的是**次声**（紫色区，如大象的低频叫声、地震），高于它的是**超声**（橙色区，如蝙蝠、医学成像）。青色条是一些声源的大致频率范围。拖动滑杆查看某个频率在空气中的波长 λ = 343/f：20 Hz 约 17 m，20 kHz 只有约 1.7 cm。下面还有一道分类题：按钮选这个频率属于哪一段，点「检查」；「下一题」换一个频率，「重来」清零得分。 {#s5e .explain}
