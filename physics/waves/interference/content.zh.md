## 先看清一列波：每一点只是在原地振动 {#step0 h2=s0t h2part=1}

::: html step0-1
s0k: 第 0 步
s0e: 这一步要回答：一列波经过时，水面上的一个点到底怎样动？上方是俯视图：一个**波源**（发出波的那个点）在水面点动，同心圆纹向外扩散，亮圈是波峰（水面最高处）的位置，暗圈是波谷。P 是浮在水面的一片小木屑。下方左图是侧面波形：横轴是离波源的距离 r，纵轴是水面高出平静面的**位移 y**；相邻两个波峰之间的距离就是**波长 λ**（图上已标出）。**振幅 A** 是位移的最大值；周期 T 是 P 完成一次完整振动的时间，本页 T = 4 秒。拖动 P（或用滑杆），看右下方 P 的位移随时间的曲线：P 只上下振动，并不随圆纹漂走——波传播的是振动，不是水本身。本页只讨论简谐波：每点的位移随时间按正弦规律变化。

## 两个波源：加强还是抵消，只看路程差 {#step1 h2=s1t h2part=1}

::: html step1-1
s1k: 第 1 步
s1e: 这一步要回答：再放一个波源，哪些点变强、哪些点变弱？两个波源 S₁、S₂ 同时点动，频率、波长、起步步调都相同。任意一点 P 同时收到两列波，它每一刻的位移都是两列波位移的**相加**——这叫叠加（<a class="fourier-link" href="../../../signal/transforms/fourier/#step2">傅里叶页第 2 步专讲：复杂波形 = 简单波形相加 →</a>）。P 到两个波源的距离之差叫**路程差 Δr**。拖动 P 到各处，看下方三条曲线：两列波各自在 P 的位移，和它们的和。有的点上两列波总同涨同落，合振幅达到 2A；有的点上总此涨彼落，合位移恒为 0，那个点永远不动，叫**静点**。这种两列波叠加后强弱分布固定下来的现象，就叫**干涉**。
btnMax: 把 P 放到加强点（Δr = 0）
btnMin: 把 P 放到静点（Δr = λ/2）
:::

::: strings
s1ro: r₁ = {r1}，r₂ = {r2}，路程差 Δr = {dr}，即 Δr = {n}λ；两列波在 P 的合振幅 = {amp}A（单列振幅 A = 1）。
clsMax: 加强：两列波到达 P 时步调一致，同涨同落，合振幅是单列的 2 倍。
clsMin: 抵消：两列波到达 P 时步调恰好相反，每一刻位移都互为相反数，相加恒为 0——P 是静点，始终不动。
clsMid: 未达完全加强或完全抵消：合振幅在 0 与 2A 之间，不能把小振幅叫作始终不动。

clsWordMin: 静点
clsWordMid: 一般干涉点

y2Lab: 波 2 在 P

:::

## 图样为什么稳定：强弱点各连成一组双曲线 {#step2 h2=s2t h2part=1}

::: html step2-1
s2k: 第 2 步
s2e: 这一步要回答：动画里波纹看着乱成一团，为什么说图样是稳定的？把 Δr 恰好等于 kλ（k = 0, 1, 2…）的所有点连起来，是一组双曲线——**加强线**（绿）；把 Δr 恰好等于 (k+½)λ 的点连起来，是另一组——**静线**（红虚线）。打开包络视图，动画继续播，这些线纹丝不动：因为每个点加强还是抵消只由它的路程差决定，与时间无关。拖 λ 滑杆：λ 越小，两组线排得越密。此结论的适用条件：两个波源同频、步调差恒定；频率不同，强弱位置会随时间漂移，连不成稳定图样。
envLab: 包络视图：叠印加强线与静线
legMax: — 加强线 Δr = kλ
legMin: ┄ 静线 Δr = (k+½)λ
:::

::: strings
s2ro: P：Δr = {dr} = {n}λ（λ = {lam}）；合振幅 = {amp}A。
:::

## 保持同一点、同一时刻，只改变相位差 {#step3 h2=s3t h2part=1}

::: html step3-1
s3k: 第 3 步
s3e: 相位表示振动走到一周期的哪里，相位差 φ 是两源的起步步调之差，以弧度计（一周为 2π）。拖动 φ 会暂停并保留当前 P 和时刻 t；三条曲线立即按新参数重算。两列波在 P 的到达相位差 δ，还要扣除传播路程的贡献：**δ=φ−2π(r₂−r₁)/λ**。这里 d=r₂−r₁ 带正负，不能把前两步同相源用的 |d| 直接搬过来。
:::

曲线是“当前 P 与参数”的前两个周期解析预测，不是过去的实测记录；改参会整段重画。右端圆点是同一时刻的值；前两行纵轴范围为 ±A，合成行是 ±2A，不能把不同标尺下的屏幕高度直接相比。合振幅描述周期极值，某一时刻的和为零并不等于振幅为零。 {#phaseTrace .hint i18n=text}

::: html step3-2
phaseSlider: 源相位差 φ/π（0–2；拖动会暂停）
:::

先预测：P 保持在等距离处，只把 φ 从 0 拖到 0.5π、π、2π，合振幅依次是 2A、√2A、0、2A。再把 P 移到左右两侧，比较带符号的传播路程。改 φ 不会换地点或推进时钟。 {#phaseTask .hint i18n=text}

::: html step3-3

phi0: φ = 0（同相起步）

phaseReset: 重置第3步并暂停

模型：同频、到达 P 的振幅相同、相位差固定（相干）的线性简谐波。A=1 是归一化位移，T=4s 是演示设定；忽略传播衰减、反射与色散。圆纹只示意波峰位置，不是真实水面求解。静点只用浮点计算误差级容差识别；接近抵消仍会动，小振幅不会四舍五入成“严格零”。 {#phaseScope .hint i18n=text}

## 终章：干涉的三句话 {#step5 h2=s5t h2part=1}

::: html step5-1
s5k: 终章
s5e: 这一页从一列波的振动出发：波传的是振动不是物质；两列波相遇后，每一点的命运只由路程差（和起步相位差）决定，于是强弱图样被几何定死。
card1t: 一 · 相加是本质
card1: 每一点的位移都是两列波位移之和。加强与抵消不是两种机制，只是这个加法的两个极端：同涨同落得 2A，此涨彼落得 0。
card2t: 二 · 路程差定加强与抵消
card2: 同相双源：Δr = kλ 加强，Δr = (k+½)λ 抵消。有相位差 φ 时，把 φ 折算成周期数与 Δr/λ 合并计算，整数 → 加强，半整数 → 抵消。
card3t: 三 · 图样由几何定死
card3: 加强点连成一组双曲线、静点连成另一组，不随时间漂移；λ 越小，两组线越密。前提是两源同频、步调差恒定。
slitNote: 光也是波：双缝干涉算的是同一笔账——屏上明暗条纹的位置同样由路程差决定；条纹间距的定量公式留到光学线再展开，本页先把账算清。
