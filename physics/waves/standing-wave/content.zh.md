## 两列波迎面跑：波形为什么停下来 {#step0 h2=s0t h2part=1}

::: html step0-1

s0e: 这一步要回答：一列向右跑的简谐波 y₁ = A·sin(ωt − kx)，再放一列一模一样、迎面跑来的 y₂ = A·sin(ωt + kx)，叠起来每一点怎么动？（正弦波形从哪来——<a class="fourier-link" href="../../../math/geometry/trigonometry/#step2">三角页第 2 步专讲：把身高摊开，就是正弦波 →</a>）每一点的位移都是两列波位移的相加。图上本页取 A = 1、周期 T = 4 秒、波速沿用口径；青线是右行波，橙线是左行波，白线是合成波。看合成波形：波峰不再左右迁移，只在原地升降——橙色虚线是波峰标记，它始终守在同一 x 附近，不像行波那样跑。拖 P，看下方 P 的位移—时间曲线：P 仍按正弦振动，但振幅随位置而异，有的点振多高、有的点纹丝不动。

## 波节与波腹：每点的振幅由包络定死 {#step1 h2=s1t h2part=1}

::: html step1-1
s1k: 第 1 步
s1e: 先看每点能振多高：最大位移的大小叫**振幅**，各点振幅连成的轮廓叫**包络**。这里 y(x,t)=C(x)·sin(ωt)，C(x)=2A·cos(kx)：振幅是 |C|，不是带符号的 C。C=0 是永远不动的**波节**，x=(2m+1)λ/4；|C|=2A 是**波腹**，x=mλ/2（m 为整数）。相邻波节间距 λ/2，波节到相邻波腹 λ/4。再问：两点是否一起升降？固定参考点 Q 在 x=0，拖动 P 或选下面预设，再播放；两条曲线共用时钟和刻度。

## 近似匹配，算满足固定端吗？ {#step2 h2=s2t h2part=1}

::: html step2-1
s2k: 第 2 步
s2e: 固定端要求 y(0,t)=y(L,t)=0 在**所有时刻**成立，不是某一瞬间经过零。A 是单列分量波振幅（本页取1），k=2π/λ。原候选式 y=A sin(ωt−kx)−A sin(ωt+kx)=−2A cos(ωt)sin(kx) 只自动保证左端 x=0；右端还要满足 sin(kL)=0，即 **q=2L/λ=n，n=1,2,…**。这样的单一自由振动形状才是本征模式，允许波长 λₙ=2L/n。不是整数的候选式仍可画出来检验，但不能把它当成真实固定弦的运动。
:::

白点/墙：真实固定端要求的零位移。青色虚线：不兼容的候选形状；红圈：它此刻要求的端点位移；红虚线：它整个周期的非零端点包络。只有边界匹配才画成绿色实线与波节。数值容差仅处理浮点误差，不是“差2%也算成立”。 {#boundaryLegend .hint i18n=text}

## 共振：外力踩中台阶 {#step4 h2=s4t h2part=1}

::: html step4-1
s4k: 第 4 步
s4e: 这一步要回答：在弦一端用很小的力以频率 f 持续强迫振动，什么时候振幅会长到很大？先定义：**固有频率**是系统自己能稳定振动的那些频率——就是上一步的 f_n = n·f₁ 一族。用滑杆把驱动频率 f 从 0.05 扫到 1.40 Hz：只有 f 命中某个 f_n 时，整弦才点亮成对应模式、振幅读数冲峰；一偏离就塌。结论：**共振** = 驱动频率等于某个固有频率时振幅显著增大。共振是「选模式」，不是「越大力越响」。本步的响应曲线是**示意模型，非实测**：峰位由 f_n 实算，峰高与峰宽是示意参数。
freqLab: 驱动频率 f（Hz）
s4hint: 像推秋千：每一下都踩在它自己摆动的节拍上，劲才攒得起来；踩错节拍，劲反而互相抵消。适用条件：小幅驱动、阻尼较小，且驱动点不能正好落在该模式的波节上（那里根本推不动）。阻尼变大时，响应峰会变矮、变宽——本页取小阻尼定值，峰高峰宽是示意参数，不是实测数据。
:::

::: strings
s4ro: 驱动频率 f = {f} Hz；最近的固有频率 f_{n} = {fn} Hz；稳态振幅（**示意模型**，非实测）= {amp}。
resLit: 踩中了：驱动频率命中 f_{n}，整弦正在以第 {n} 个模式的形状振动。
resOff: 没踩中：驱动频率在两个台阶之间，振幅塌下去，弦形也散了。
:::

## 终章：驻波的三句话 {#step6 h2=s6t h2part=1}

::: html step6-1
s6k: 终章
s6e: 这一页从两列对跑的波出发：波峰不再迁移，只在原地升降；包络把每点的振幅定死；边界把波长筛成整数台阶，外力踩中台阶就是共振。
card1t: 一 · 对跑叠加生出包络
card1: y = y₁ + y₂ = 2A·cos(kx)·sin(ωt)：空间包络 × 时间振动可以拆开。波形不迁移，全体一起到顶、一起回零。
card2t: 二 · 波节波腹由包络定死
card2: A(x) = 2A·|cos(kx)|：为 0 的点是波节（x = (2m+1)λ/4），为 2A 的点是波腹（x = mλ/2）。波节不动不是没波到，是两列波每刻互为相反数。
card3t: 三 · 边界筛出整数台阶
card3: 两端固定 → L = n·(λ/2)，频率排成 f_n = n·f₁。驱动频率踩中某个 f_n，振幅才显著长大——共振是选模式。
windNote: 管乐器是空气柱里的驻波：一端封闭时，台阶换成 λ/4 的奇数倍——那是声音线的账，本页不展开。
linkInt1: 干涉：两个波源、路程差定加强与抵消 —— 那是空间里的强弱图样；本页是一列波迎面撞上自己的反向同伴，是时间里的原地振动 →
linkInt2: 干涉的稳定图样：双曲线族 —— 与本页一维的驻波包络对照看 →
linkTrig: 正弦波从哪来：圆的侧影摊开成波 —— 本页两列对跑的波都是它 →
