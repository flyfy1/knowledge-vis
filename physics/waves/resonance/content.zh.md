## 没人推时，弹簧振子有自己的节拍 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 固有频率
:::

::: html step0-1
:::

这一步要回答：一个弹簧上的物体自由振动，一秒振几次由什么决定？拉开 1 个单位松手，物体做简谐振动，**固有角频率** ω₀ = √(k/m)（k 是弹簧劲度，越大越“硬”；m 是质量），周期 T = 2π/ω₀。点播放，右边轨迹 x(t) 逐渐画出；“实测周期”由轨迹相邻两次上穿零点的间隔得到，与公式对照。 {#s0e .explain}

::: html step0-2
s0o: 把 k 调大：振得更快；把 m 调大：振得更慢。播放一两个周期，核对实测周期是否等于 2π√(m/k)。
lK: 弹簧劲度 k
lM: 质量 m
bPlay: 播放 / 暂停
bReset: 重置：清除轨迹并回到起点
:::

## 阻尼：能量被一点点带走 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 阻尼
:::

::: html step1-1
:::

这一步要回答：加上摩擦（阻尼）后，振动怎样变化？用**阻尼比** ζ 表示阻尼大小：ζ = 0 无阻尼；ζ < 1 欠阻尼，振幅按 e^(−ζω₀t) 的包络衰减（虚线）；ζ = 1 临界阻尼，最快回到平衡且不来回；ζ > 1 过阻尼，缓慢爬回。本页 ω₀ = 2（后几步相同）。读数里的“相邻峰比”是曲线上前后两个峰高之比。 {#s1e .explain}

::: html step1-2
s1o: 把 ζ 从 0 慢慢拉到 1.6：看包络从不衰减、到衰减越来越快、到不再来回振荡；对照读数里的实测峰比与公式 e^(−2πζ/√(1−ζ²))。
lZ: 阻尼比 ζ
:::

::: strings
r1: ζ = {z}：{kind}；相邻峰比：实测 {rm}，公式 {rf}。
kUnder: 欠阻尼（来回振荡并衰减）
kCrit: 临界阻尼（不振荡，最快回零）
kOver: 过阻尼（不振荡，缓慢回零）
kNone: 无阻尼（永不衰减）
:::

## 周期性地推它：振幅怎样长大 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 被推着的振子
:::

::: html step2-1
:::

这一步要回答：用周期力 F cos Ωt 推一个有阻尼的振子，会发生什么？运动方程 x″ + 2ζω₀x′ + ω₀²x = F cos Ωt（F = 1，ω₀ = 2）。前几个周期是“瞬态”，随后进入**稳态**：以驱动频率 Ω 振动，振幅固定为 A = F/√((ω₀²−Ω²)² + (2ζω₀Ω)²)。点播放，橙色是 x(t)，青色虚线是推力（缩放后）。读数里的“实测振幅”取最近两个驱动周期内的最大位移。 {#s2e .explain}

::: html step2-2
s2o: 先把 Ω/ω₀ 设为 0.5 播放，记下稳态振幅；再设为 1（踩中固有频率）重播：振幅长到多大？再换到 1.6：振幅怎样？
lR: 驱动频率比 Ω/ω₀
:::

::: strings
r2: Ω = {W}（Ω/ω₀ = {r}），ζ = {z}；公式稳态振幅 A = {A}；实测最近两个驱动周期最大位移 = {Am}；t = {t}。
:::

## 共振曲线：只有一个频率附近振幅冲得高 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 共振曲线
:::

::: html step3-1
:::

这一步要回答：推力频率扫过一遍，稳态振幅怎么变？横轴是 Ω/ω₀，纵轴是稳态振幅 A。振幅峰在 Ω ≈ ω₀√(1−2ζ²) 处（阻尼小时就是 ω₀），峰高约 F/(2ζω₀²)。品质因数 Q = 1/(2ζ)：阻尼越小，峰越高越窄，半宽约 ω₀/Q。当前 ζ 的曲线为橙色，ζ = 0.05、0.15、0.5 的参考曲线为灰色。 {#s3e .explain}

::: html step3-2
s3o: 把 ζ 从 0.5 调到 0.05：峰变高变窄；移动 Ω/ω₀，看圆点沿曲线走到峰顶，核对读数里的峰位置与峰高。
:::

::: strings
r3: Ω/ω₀ = {r}，A = {A}；峰位置 Ω/ω₀ = {pk}，峰高 = {ph}；Q = 1/(2ζ) = {Q}，半宽约 {bw}（以 Ω/ω₀ 计）。
:::

## 相位：响应总是迟到一点 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 相位滞后
:::

::: html step4-1
:::

这一步要回答：振子的位置和推力同时到达最大值吗？稳态下，位移比推力滞后一个相位 φ = atan2(2ζω₀Ω, ω₀²−Ω²)：Ω 很低时 φ ≈ 0（跟着推力走），Ω = ω₀ 时 φ = 90°，Ω 很高时 φ ≈ 180°（反着走）。青色是推力，橙色是位移，横轴是时间（约 3 个驱动周期）。 {#s4e .explain}

::: html step4-2
s4o: 把 Ω/ω₀ 从 0.2 拉到 2：看橙色波相对青色波从同步、落后四分之一周期、直到反相；改 ζ，看在共振附近相位变化是快还是慢。
:::

::: strings
r4: Ω/ω₀ = {r}，ζ = {z}：φ = {phi}°，相当于滞后 {frac} 个周期。
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 固有频率 ω₀ = √(k/m)；② 阻尼比 ζ 决定衰减，ζ = 1 临界；③ 周期推力进入稳态后以 Ω 振动，A = F/√((ω₀²−Ω²)² + (2ζω₀Ω)²)；④ Ω 靠近 ω₀ 时振幅最高，阻尼越小峰越高越窄（Q = 1/2ζ）；⑤ 响应相位随 Ω 从 0° 滞后到 180°，共振时 90°。 {#s5e .explain}

::: html step5-2
qq: 在共振频率上推，把阻尼比 ζ 减半，稳态振幅大约变成原来的几倍？
qo0: 约一半
qo1: 不变
qo2: 约 2 倍
s5m: 本页是单自由度线性振子：弹簧力与位移成正比，阻尼力与速度成正比，推力是单一频率的余弦；真实结构有多个固有频率、非线性（振幅大时弹簧不再线性），共振还可能使结构破坏；阻尼比较大时峰会偏离 ω₀；动画是教学慢放。
lk0: 驻波页：弦上的共振——外力踩中谐波台阶
lk1: 频率响应页：同样的“按频率挑食”，用在线性系统的输入输出上
lk2: 干涉页：对照两列波叠加的加强条件
:::

::: strings
qwhy: 共振峰高约 F/(2ζω₀²)，与 ζ 成反比，ζ 减半，峰高加倍（第 3 步可验证）。
:::
