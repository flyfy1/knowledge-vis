共振 · 踩中节拍，小推也能荡高

从弹簧的固有节拍出发，看阻尼怎样让振动衰减，再看周期性的推力在什么频率下把振幅推到最高。

没人推时，弹簧振子有自己的节拍

这一步要回答：一个弹簧上的物体自由振动，一秒振几次由什么决定？拉开 1 个单位松手，物体做简谐振动，固有角频率 ω₀ = √(k/m)（k 是弹簧劲度，越大越“硬”；m 是质量），周期 T = 2π/ω₀。点播放，右边轨迹 x(t) 逐渐画出；“实测周期”由轨迹相邻两次上穿零点的间隔得到，与公式对照。

把 k 调大：振得更快；把 m 调大：振得更慢。播放一两个周期，核对实测周期是否等于 2π√(m/k)。

阻尼：能量被一点点带走

这一步要回答：加上摩擦（阻尼）后，振动怎样变化？用阻尼比 ζ 表示阻尼大小：ζ = 0 无阻尼；ζ < 1 欠阻尼，振幅按 e^(−ζω₀t) 的包络衰减（虚线）；ζ = 1 临界阻尼，最快回到平衡且不来回；ζ > 1 过阻尼，缓慢爬回。本页 ω₀ = 2（后几步相同）。读数里的“相邻峰比”是曲线上前后两个峰高之比。

把 ζ 从 0 慢慢拉到 1.6：看包络从不衰减、到衰减越来越快、到不再来回振荡；对照读数里的实测峰比与公式 e^(−2πζ/√(1−ζ²))。

周期性地推它：振幅怎样长大

这一步要回答：用周期力 F cos Ωt 推一个有阻尼的振子，会发生什么？运动方程 x″ + 2ζω₀x′ + ω₀²x = F cos Ωt（F = 1，ω₀ = 2）。前几个周期是“瞬态”，随后进入稳态：以驱动频率 Ω 振动，振幅固定为 A = F/√((ω₀²−Ω²)² + (2ζω₀Ω)²)。点播放，橙色是 x(t)，青色虚线是推力（缩放后）。读数里的“实测振幅”取最近两个驱动周期内的最大位移。

先把 Ω/ω₀ 设为 0.5 播放，记下稳态振幅；再设为 1（踩中固有频率）重播：振幅长到多大？再换到 1.6：振幅怎样？

共振曲线：只有一个频率附近振幅冲得高

这一步要回答：推力频率扫过一遍，稳态振幅怎么变？横轴是 Ω/ω₀，纵轴是稳态振幅 A。振幅峰在 Ω ≈ ω₀√(1−2ζ²) 处（阻尼小时就是 ω₀），峰高约 F/(2ζω₀²)。品质因数 Q = 1/(2ζ)：阻尼越小，峰越高越窄，半宽约 ω₀/Q。当前 ζ 的曲线为橙色，ζ = 0.05、0.15、0.5 的参考曲线为灰色。

把 ζ 从 0.5 调到 0.05：峰变高变窄；移动 Ω/ω₀，看圆点沿曲线走到峰顶，核对读数里的峰位置与峰高。

相位：响应总是迟到一点

这一步要回答：振子的位置和推力同时到达最大值吗？稳态下，位移比推力滞后一个相位 φ = atan2(2ζω₀Ω, ω₀²−Ω²)：Ω 很低时 φ ≈ 0（跟着推力走），Ω = ω₀ 时 φ = 90°，Ω 很高时 φ ≈ 180°（反着走）。青色是推力，橙色是位移，横轴是时间（约 3 个驱动周期）。

把 Ω/ω₀ 从 0.2 拉到 2：看橙色波相对青色波从同步、落后四分之一周期、直到反相；改 ζ，看在共振附近相位变化是快还是慢。

回顾与自测

回顾：① 固有频率 ω₀ = √(k/m)；② 阻尼比 ζ 决定衰减，ζ = 1 临界；③ 周期推力进入稳态后以 Ω 振动，A = F/√((ω₀²−Ω²)² + (2ζω₀Ω)²)；④ Ω 靠近 ω₀ 时振幅最高，阻尼越小峰越高越窄（Q = 1/2ζ）；⑤ 响应相位随 Ω 从 0° 滞后到 180°，共振时 90°。

在共振频率上推，把阻尼比 ζ 减半，稳态振幅大约变成原来的几倍？

本页是单自由度线性振子：弹簧力与位移成正比，阻尼力与速度成正比，推力是单一频率的余弦；真实结构有多个固有频率、非线性（振幅大时弹簧不再线性），共振还可能使结构破坏；阻尼比较大时峰会偏离 ω₀；动画是教学慢放。
