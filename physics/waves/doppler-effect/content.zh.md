## 静止的源：波前等距地向外扩 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 静止的源
:::

::: html step0-1
:::

这一步要回答：一个静止的声源，波前长什么样？源每隔 1/f 秒发出一个波前（圆环），每个圆环以波速 c 向外扩（本页取 c = 1，教学单位）。相邻圆环的间距就是**波长** λ = c/f。点播放，看圆环一圈圈累积。 {#s0e .explain}

::: html step0-2
s0o: 拖动 f：f 越大圆环越密、间距越小；读数里的 λ 与你眼睛看到的圆环间距对照。
lF: 发射频率 f（次/秒）
bPlay: 播放 / 暂停
bReset: 重置：清除波前并回到起点
:::

hint: 按“播放”开始
r0: f = {f}：波长 λ = c/f = {lam}；每个圆环之间相隔 {T} 秒发出；已发出 {n} 个波前。
:::

## 源在动：前面的波前被挤密，后面的被拉疏 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 运动的源
:::

::: html step1-1
:::

这一步要回答：源运动时，前后听者听到的频率各是多少？源以速度 v 向右运动，每个波前的圆心停在它被发出时源所在的位置，所以圆环不再同心。图以源为参考（源居中）。远处静止听者（在空气里静止）：在前方，相邻波前的间距缩成 λ前 = (c − v)/f，听到 f前 = f·c/(c − v)；在后方，λ后 = (c + v)/f，听到 f后 = f·c/(c + v)。 {#s1e .explain}

::: html step1-2
s1o: 把 v/c 从 0 拉到 0.9：看右边（前方）的圆环挤在一起、左边（后方）的圆环拉开；核对读数里的两个频率，并用公式反推：f前 > f > f后。
lM: 源速度比 v/c
:::

::: strings
r1: v/c = {m}：前方波前间距 λ前 = {lf}，听到 f前 = {ff}；后方 λ后 = {lb}，听到 f后 = {fb}（源频率 f = {f0}）。
:::

## 不在正前方、正后方呢？只有朝向听者的那一分量起作用 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 任意方向
:::

::: html step2-1
:::

这一步要回答：听者在任意方向 θ（从源的运动方向量起）时，听到的频率是多少？只有源速度朝向听者的分量 v cosθ 会挤压或拉疏波前：f′ = f/(1 − (v/c) cosθ)。θ = 0° 在正前方（最高），θ = 180° 在正后方（最低），θ = 90° 时没有朝向分量，f′ = f。右下方曲线是 f′ 随 θ 的变化，圆点是当前听者。θ 取的是发声那一刻源到听者的方向。 {#s2e .explain}

::: html step2-2
s2o: 把 θ 从 0° 转到 180°：听者圆点沿圆走，频率曲线上的点从最高降到最低；在 90° 附近确认 f′ ≈ f；再调 v/c，看曲线的起伏变大。
lA: 听者方位角 θ
:::

::: strings
r2: v/c = {m}，θ = {a}°：f′ = f/(1 − (v/c)cosθ) = {fp}（源频率 f = 1）；比源频率{dir}。
dirHigh: 高
dirLow: 低
dirSame: 相同
:::

## 车辆掠过：音调从高骤降到低 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 车辆掠过
:::

::: html step3-1
:::

这一步要回答：车辆驶过路边的人，听到的音调随时间怎么变？车沿直线以 v 行驶，路边听者离路线 b。每个时刻，听者听到的是更早发出的声音，频率 f′ = f/(1 − (v/c)cosθ)，θ 是发声时刻车相对听者的方向（用二分法求解发声时刻）。右边的曲线是听者收到的频率随时间的累积；离路线越远（b 越大）转折越缓和；b 很小则近乎瞬间跳变。f = 1。 {#s3e .explain}

::: html step3-2
s3o: 点播放，看曲线从高于 1 的水平线降到低于 1 的水平线；把 b 减到 0.3 再播放，转折变陡；把 v/c 调大，高低两端更远离 1。
lB: 听者离路线的距离 b
bPass: 播放 / 暂停：车辆驶过
:::

::: strings
r3: v/c = {m}，b = {b}：驶近极限 {hi}，驶离极限 {lo}；当前听到 f′ = {fp}；车到最近点时听到 {fc}。
:::

## 超过声速：波前叠成一个锥 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 超音速
:::

::: html step4-1
:::

这一步要回答：源比波更快会怎样？当 M = v/c > 1，源跑在自己的波前前面，所有圆环被一条包络线圈住，形成**马赫锥**，半角 α 满足 sinα = c/v = 1/M。M < 1 时圆环互相包含，没有锥；M = 1 时圆环在源的前方挤成一点。图仍以源为参考。 {#s4e .explain}

::: html step4-2
s4o: 把 M 从 0.5 调到 1，再到 2.5：看圆环从“互相包含”变成“被锥线圈住”，锥越来越尖；核对读数里的半角 α。
lMach: 马赫数 M = v/c
:::

::: strings
r4: M = {M}：{regime}；{cone}
regSub: 亚声速，没有锥
regSon: 恰为声速，圆环在源前挤成一点
regSup: 超声速，出现马赫锥
coneNone: 无半角。
coneAng: 半角 α = arcsin(1/M) = {al}°。
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 波前间距就是波长 λ = c/f；② 源运动时前方波前被挤密，f前 = f·c/(c − v)，后方 f后 = f·c/(c + v)；③ 任意方向只看朝向听者的速度分量，f′ = f/(1 − (v/c)cosθ)；④ 车辆掠过时音调由高到低，b 越小转折越陡；⑤ M > 1 出现马赫锥，sinα = 1/M。 {#s5e .explain}

::: html step5-2
qq: 救护车以 v = 0.5c 驶向你，鸣笛频率 f。你听到的频率是多少？
qo0: 2f
qo1: 1.5f
qo2: 0.5f
s5m: 本页只考虑波源运动、听者静止（听者运动时公式略有不同：f′ = f(c ± v_听)/c）；介质静止，波速 c 恒定（本页取 c = 1，教学单位）；二维画法，波前画成圆环；v < c 的亚声速在第 1—3 步，超声速仅在第 4 步给出几何图；没有声强随距离衰减或大气吸收；动画是教学慢放。
lk0: 驻波页：从另一个角度看波的叠加与频率
lk1: 干涉页：波前相互叠加的结果
lk2: 傅里叶页：把一个变化的音调拆成不同频率
:::

:::
