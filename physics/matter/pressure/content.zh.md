## 同样重的人，为什么穿雪鞋就不陷下去？ {#step0 h2=s0t}

::: strings
nav0: 0 雪地里的脚
:::

第 0 步 · 雪地里的脚 {#s0k .step-kicker i18n=text}

这一步要回答：同样的重力压在雪地上，接触面积变大，陷下多深会怎么变？**压力**是垂直压在表面上的力（单位牛，N）；**压强**是每单位面积承受的压力，p = F ÷ S（S 是接触面积），单位帕（Pa），本页用千帕（1 kPa = 1000 Pa）。拖动力和接触面积，看雪面的凹陷。 {#s0e .explain}

::: html step0-1
s0stage: 雪地剖面：箭头是压力 F，方块底边宽度代表接触面积 S，凹陷深度代表雪被压下多少
s0canvas: 雪地示意图：重物压在雪面上，接触面积越小凹陷越深
s0f: 压力 F（人的重力）
s0a: 接触面积 S
:::

结论：力不变，面积越大压强越小，陷得越浅。条件：雪是示意的均匀软物，凹陷深度按「深度 ∝ 压强」简单设定，封顶 25 cm。 {#s0result .readout i18n=text}

::: strings
s0ro: p = F ÷ S = {f} N ÷ {a} cm² = {p} kPa；雪被压下约 {d} cm。
:::

## 图钉两端受同一个力，压强差多少倍？ {#step1 h2=s1t}

::: strings
nav1: 1 图钉的两端
:::

第 1 步 · 图钉的两端 {#s1k .step-kicker i18n=text}

这一步要回答：用手指推图钉，钉帽和钉尖受力一样，压强为什么差那么多？拖面积滑杆（横轴按 10 的幂排布，每格大 10 倍），点沿曲线移动：面积每扩大 10 倍，压强缩小到十分之一。再改力 F，看整条线怎么平移。 {#s1e .explain}

::: html step1-1
s1stage: 横轴：接触面积 S（cm²，对数刻度）；纵轴：压强 p（kPa，对数刻度）；橙色点是当前面积
s1canvas: 压强对面积的对数坐标图：面积每大 10 倍压强小到十分之一，是一条下降直线
s1f: 手指推力 F
s1a: 接触面积 S 的 10 为底对数 lg S
:::

结论：同一个力下 p 与 S 成反比。条件：力均匀分布在接触面上；真实钉尖不是理想平面，本页取理想值。 {#s1result .readout i18n=text}

::: strings
s1ro: S = {a} cm² → p = {p} {u}；面积是钉帽（1 cm²）的 {r} 倍。
:::

## 液体里某一点的压强，由什么决定？ {#step2 h2=s2t}

::: strings
nav2: 2 水越深压越大
:::

第 2 步 · 水越深压越大 {#s2k .step-kicker i18n=text}

这一步要回答：容器侧壁越靠下的小孔，水为什么喷得越用力？液体内部 **深度 h**（该点到液面的竖直距离）处的压强 p = ρgh，ρ 是液体密度（[[density#step0|密度页]]讲了它），g = 9.8 N/kg。拖水位，选液体，看每个孔的压强箭头和水柱。 {#s2e .explain}

::: html step2-1
s2stage: 水槽：四个小孔，箭头长度 = 孔处压强；水柱走势按理想小孔出流画
s2canvas: 侧壁开孔的水槽：越靠下的孔压强箭头越长、水喷得越远
s2liq: 液体
s2h: 液面高度 H
:::

结论：同种液体里压强随深度线性增大，换密度更大的液体，同一深度压强按比例增大。条件：静止液体、不计大气压；水柱形状按理想出流（与 ρ 无关）近似。 {#s2result .readout i18n=text}

::: strings
s2ro: 最低孔处深度 {d} m，p = ρgh = {rho} × 9.8 × {d} = {p} kPa；最深孔压强是最浅孔的 {r} 倍。
:::

## 我们头顶的空气有多大压强，高处为什么变小？ {#step3 h2=s3t}

::: strings
nav3: 3 大气的重量
:::

第 3 步 · 大气的重量 {#s3k .step-kicker i18n=text}

这一步要回答：空气也有重量，所以也有压强。**大气压**就是头顶整个空气柱压在单位面积上的力，海平面约 101.3 kPa。用**气压计**：管里的液柱被大气压托住，液柱高 h = p ÷ (ρg)。拖海拔，看液柱怎么落。 {#s3e .explain}

::: html step3-1
s3stage: 气压计：管里的液柱高度由大气压托起；虚线是海平面处的高度
s3canvas: 气压计示意图：海拔越高液柱越矮
s3liq: 管里的液体
s3z: 海拔高度 z
:::

结论：海平面水银柱约 760 mm、水柱约 10.3 m；越高空气越稀，气压越低。条件：本页用等温近似 p = p₀·e^(−z/8400)，真实大气随温度、天气变化。 {#s3result .readout i18n=text}

::: strings
s3ro: 海拔 {z} m：大气压约 {p} kPa（海平面的 {r}%）；{liq} 柱高 {h} {u}。
:::

## 为什么按小活塞能顶起大重物？ {#step4 h2=s4t}

::: strings
nav4: 4 小力顶大力
:::

第 4 步 · 小力顶大力 {#s4k .step-kicker i18n=text}

这一步要回答：密闭液体里的压强处处相等（帕斯卡原理），小活塞上多大的力能顶起大活塞上的重物？压强 p = F₁ ÷ S₁，大活塞受力 F₂ = p × S₂。按「压下小活塞 10 cm」，看大活塞抬起多高。 {#s4e .explain}

::: html step4-1
s4stage: 液压机：左边小活塞，右边大活塞，上面放着 100 kg 的重物（约 980.7 N）
s4canvas: 液压机示意图：左边小活塞下压，右边大活塞抬起重物
s4f1: 小活塞上的力 F₁
s4a1: 小活塞面积 S₁
s4a2: 大活塞面积 S₂
s4push: 压下小活塞 10 cm
s4reset: 复位
:::

结论：F₂ = F₁ × S₂ ÷ S₁，力放大，位移缩小，功不变（理想情况）。条件：不可压缩、无泄漏、无摩擦；真实液压机有损耗。 {#s4result .readout i18n=text}

::: strings
s4ro: p = {p} kPa；F₂ = {f2} N（{cmp} 重物 980.7 N）。{move}
s4lift: 够顶起
s4nolift: 顶不起
s4moved: 小活塞下压 10 cm，大活塞升 {d2} cm；输入功 {w1} J，输出功 {w2} J。
s4stuck: 大活塞不动：F₂ 不够；增大 F₁ 或 S₂ ÷ S₁ 再试。
s4idle: 按「压下小活塞 10 cm」演示。
:::
