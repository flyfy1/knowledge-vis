## 压强不是别的，就是粒子撞墙的冲量总和 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 压强是撞墙
:::

::: html step0-1
:::

这一步要回答：盒子里的气体压强是怎么来的？每个粒子撞墙，垂直于墙的动量改变 2m·vₙ（撞来再弹回）；四面墙单位时间、单位墙长上收到的总冲量就是**压强** P（二维气体，单位长度上的力）。右图每根柱是 0.25 秒内测得的压强，折线是最近 8 秒平均，虚线是理论值 P = N·⟨KE⟩/(W·H)，其中 ⟨KE⟩ 是粒子的平均动能。粒子相互弹性碰撞，墙壁是理想弹性墙。 {#s0e .explain}

::: html step0-2
s0o: 先看柱子在虚线上下抖动、折线靠近虚线；把粒子数 N 从 40 加到 80（重新撒粒子），看柱子整体升高到约两倍。
lN: 粒子数 N
bPlay: 播放 / 暂停
bReset: 重置：重新撒粒子并清空统计
:::

::: strings
r0: N = {n}，平均动能 ⟨KE⟩ = {ke}；理论 P = N⟨KE⟩/A = {pth}；最近 8 秒实测 P = {pm}（{ratio}）；已模拟 {t} s。
measuring: 测量中，需累积 8 秒
:::

## 温度：平均动能的读数 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 温度
:::

::: html step1-1
:::

这一步要回答：温度升高，粒子和压强怎么变？本页取 ⟨KE⟩ = k T（二维两个自由度，k = 1），所以 T 越高，粒子平均动能越大，速率约按 √T 增大。右图是此刻所有粒子的速率直方图，竖线是平均速率。改变 T 会把所有粒子的速度整体缩放，压强统计会重新累积。 {#s1e .explain}

::: html step1-2
s1o: 把 T 从 1 调到 4：直方图向右移动并变宽，平均速率约变成 2 倍；读数里 P/T 应保持为同一个数 N/A。
lT: 温度 T
:::

::: strings
r1: T = {t}，平均速率 = {vm}；理论 P = {pth}，实测 P = {pm}；P/T = {pt}（N/A = {na}）。
:::

## 体积：压缩气体，压强随之升高 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 体积
:::

::: html step2-1
:::

这一步要回答：盒子变小，压强怎么变？粒子速度不变，盒子越窄，粒子越快撞到右墙，每秒撞墙次数越多。理论上 P·V = N⟨KE⟩ 保持不变（V = W×H 是盒子面积，玻意耳定律）。改变宽度，等 8 秒读数稳定后点“记录”，把实测点 (V, P) 放到右图，看点是否落在虚线双曲线 P = N⟨KE⟩/V 上。 {#s2e .explain}

::: html step2-2
s2o: 依次把 W 设为 8、6、4、2，每次等读数稳定再记录：点应落在同一条曲线上；V 减半，P 约加倍。
lW: 盒子宽度 W
bRec: 记录当前点 (V, P)
bClear: 清除记录点
:::

::: strings
r2: V = {v}；理论 P = {pth}；实测 P = {pm}；P×V = {pv}（理论常数 N⟨KE⟩ = {c}）；已记录 {k} 个点。
needWait: 读数还没稳定（需 8 秒），请稍后再记录。
:::

## 速率分布：碰撞把整齐的速率“洗”成钟形偏态 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 速率分布
:::

::: html step3-1
:::

这一步要回答：气体里的粒子速率为什么有快有慢？开始时 100 个粒子速率完全相同，只有方向不同。粒子之间互相弹性碰撞、交换动能，速率逐渐散开。柱状图是最近一段时间的速率分布，曲线是二维麦克斯韦分布 f(v) = (v/T)·exp(−v²/2T)（m = 1，k = 1）。读数里的差距是两者的总变差距离（0 表示完全重合）。 {#s3e .explain}

::: html step3-2
s3o: 点重置后播放：开始是一根尖柱，几秒内摊开成曲线；读数里的“差距”应从接近 1 降到很小。
bReset3: 重置：全部粒子同速出发
:::

## 轻粒子和重粒子：同一温度，平均动能相同 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 轻重粒子
:::

::: html step4-1
:::

这一步要回答：同一团气体里，轻粒子和重粒子谁快？开始时两种粒子速率相同（所以重粒子动能更大）。碰撞交换能量，重粒子把多余动能让给轻粒子，两条平均动能曲线汇合；最后动能相同，轻粒子的方均根速率是重粒子的 √M 倍（M 为质量比）。右图橙线是重粒子，青线是轻粒子。 {#s4e .explain}

::: html step4-2
s4o: 播放，看两条曲线从分开走到重合；把 M 从 4 改到 9 重置再播放：重合后，速率比应接近 √M。
lM: 重粒子质量 M
bReset4: 重置：所有粒子同速出发
:::

::: strings
r4: ⟨KE⟩：轻 {kl}，重 {kh}；方均根速率比 轻/重 = {vr}（√M = {sq}）；已模拟 {t} s。

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 压强 = 粒子撞墙的冲量总和，P = N⟨KE⟩/A（二维）；② 温度对应平均动能，⟨KE⟩ = kT；③ 体积减半，撞墙更频繁，P 约加倍（玻意耳）；④ 碰撞让速率分布自己长成麦克斯韦分布；⑤ 同一温度下平均动能相同，轻的更快。 {#s5e .explain}

::: html step5-2
qq: 温度和粒子数不变，把盒子体积压缩到原来的一半，压强变成多少？
qo0: 原来的一半
qo1: 原来的 2 倍
qo2: 原来的 4 倍
s5m: 本页是二维硬圆盘气体：粒子有（很小的）大小、没有吸引力，所以实测压强比理想值略高几个百分点，墙是理想弹性墙，动能就是全部能量；真实气体是三维，压强 P = N⟨KE⟩·2/(3V)，且有分子间力与转动振动自由度；改变 W 或 T 都是瞬时的教学操作（真实压缩会因做功升温）；时间为教学加速；读数含统计涨落，粒子数越少涨落越大。

lk1: 热力学页：从 P = nRT/V 出发走到做功与热机
:::
