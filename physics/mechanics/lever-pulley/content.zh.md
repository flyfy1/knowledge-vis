## 大人往支点挪一挪，就能和小孩坐平 {#step0 h2=s0t}

::: strings
nav0: 0 跷跷板·力矩
:::

第 0 步 · 跷跷板：力矩登场 {#s0k .step-kicker i18n=text}

这一步要回答：**大人比小孩重得多，为什么大人往支点挪一挪，两个人就能坐平？**图上这块板能绕中间那个固定点转动，这个点叫**支点**。人坐得离支点越远就「压得越沉」——量这股转动劲的不是力本身，而是**力矩 = 力 × 力臂**；**力臂**是支点到力的作用线的距离，本页重力竖直向下，力臂就是人到支点的水平距离（图上用双向标尺画出）。拖动板上的人，或用下面的滑杆挪位置，盯住两边的力矩牌。板自重忽略不计——支点在正中，板自己的力矩两边正好抵消。 {#s0e .explain}

::: html step0-1

s0aLab: 大人位置（距支点）

结论：**决定转动的是力矩，不是力本身；两边力矩相等，杠杆就平衡。**一个说明：图上板的倾斜角度是**示意**（力矩差越大、倾得越多），力矩数值是按 g = 10 N/kg 实算的。适用条件：力竖直向下（重力）、板水平时力臂就是到支点的水平距离。 {#s0hint .hint}

## 支点垫得越靠石头，手上越轻 {#step1 h2=s1t}

::: strings
nav1: 1 撬棍对账
:::

第 1 步 · 撬棍：支点滑杆对账 {#s1k .step-kicker i18n=text}

这一步要回答：**撬大石头时，支点垫在哪里最省力、能省多少，能不能当场算出来？**一根能绕支点转的硬杆就是**杠杆**，撬棍正是杠杆。你向下使的力叫**动力**，它的力臂叫**动力臂**；要克服的石头重力叫**阻力**，它的力臂叫**阻力臂**。大石重力 G = 800 N 压在棍的右端，棍长 1.5 m。拖动支点滑杆：支点在棍上一挪，两条力臂此消彼长，所需动力由平衡条件当场算出，对账表两边并排。 {#s1e .explain}

::: html step1-1
dragHint3d: 三维场景 · 拖动旋转视角，也可聚焦画布后用方向键
s1lrLab: 阻力臂 L阻（支点到石头）
s1try: 用力试试（按当前 F 撬起石头）
:::

结论：**支点越贴近重物，阻力臂越小、动力臂越大，越省力；省力倍数就是 L动/L阻。**但支点滑到最贴近石头，F 也只是变小，永远大于 0——没有不用力的杠杆。适用条件：静止或匀速撬起的平衡口径，棍自重忽略。 {#s1hint .hint}

::: strings

## 力省下的那一份，距离得补回来 {#step2 h2=s2t}

::: strings
nav2: 2 功的账本
:::

第 2 步 · 省力必费距离：功的账本 {#s2k .step-kicker i18n=text}

这一步要回答：**力省掉的那一部分，是不是凭空消失了？**先认一个新账目：**功 = 力 × 沿力方向移动的距离**，单位焦耳（J）。还是这根撬棍（石头 G = 600 N），先选一档力臂比，再按「撬起」：撬棍转过一个固定角度，手端沿弧线压下的距离 s 与石头被抬起的弧长 h，都由「力臂 × 转角」当场算出。下方两条「功账本」会同步变长：手做的功 W入 = F × s，石头得到的功 W出 = G × h——盯住看它们是不是严丝合缝一样长。 {#s2e .explain}

::: html step2-1
s2ratioLab: 力臂比（动力臂 : 阻力臂）
s2play: ▶ 撬起
s2ledgerIn: 手做的功 W入 = F × s
s2ledgerOut: 石头得到的功 W出 = G × h
:::

结论：**省力必费距离——省力倍数是几，手移动的距离就是几倍；W入 = W出，功的账本从不亏空。**为什么必然相等：同一个转角下，弧长 = 力臂 × 转角，弧长之比就是力臂之比，与力之比正好倒过来相抵——这是几何必然，不是近似。适用条件：理想口径（不计摩擦与棍自重）。 {#s2hint .hint}

## 井口那个轮子，一分力都不省 {#step3 h2=s3t}

::: strings
nav3: 3 定滑轮
:::

第 3 步 · 定滑轮：只改方向 {#s3k .step-kicker i18n=text}

这一步要回答：**井口、旗杆顶上那个轮子，到底省不省力？**轴固定不动的滑轮叫**定滑轮**。绳的一端吊着重物（G = 200 N），另一端用手拉。拉绳滑杆控制拉出的绳长 s，看重物升起的高度 h；再切换拉的方向（竖直下拉 / 斜向拉），盯住拉力 F 变不变。整条绳用同一种颜色、同一粗细画：理想绳里的张力处处相等（不计摩擦与绳重）。 {#s3e .explain}

::: html step3-1
s3down: 竖直下拉
s3diag: 斜向拉
s3sLab: 拉出的绳长 s
:::

结论：**定滑轮不省力、不省距离，只改变力的方向。**它值钱的地方正在方向：人可以站在地上往下拉、借上自己的体重，不必爬到高处去抱重物。适用条件：理想滑轮（不计摩擦、绳重）；拉力沿绳任意方向，大小都不变。 {#s3hint .hint}

## 轮子跟着重物走，力就分给了几段绳 {#step4 h2=s4t}

::: strings
nav4: 4 动滑轮与滑轮组

第 4 步 · 动滑轮与滑轮组：数段数定倍数 {#s4k .step-kicker i18n=text}

这一步要回答：**滑轮的轴跟着重物一起动，会怎样？**轴随重物一起移动的滑轮叫**动滑轮**，定、动滑轮搭配成的组合叫**滑轮组**。诀窍只有一句：直接吊着动滑轮与重物的那几段绳，叫**承重绳段**——有几段一起分担，拉力就是总重的几分之一。图上高亮的就是承重段，点「逐段数一数」让它们逐段亮起。先看单个动滑轮，再切滑轮组换段数。（理想口径：不计摩擦、动滑轮自重与绳重。） {#s4e .explain}

先数真正吊着动滑轮的绳段，再看 F=G/n：段数越多越省力，但同样绳长让重物升得更少。 {#s4bridge .hint i18n=text}

结论：**省力倍数 = 承重绳段数 n：F = G/n，代价是拉绳距离变成 n 倍（h = s/n）。**数段数口诀：只数图上高亮的、直接挂着动滑轮与重物的段。本页绕法里，偶数段的自由端从动滑轮向上出绳（这段也承重、要数），奇数段的自由端从定滑轮垂下来（不挂重物、不数）。适用条件：理想口径（不计摩擦、动滑轮自重与绳重）。 {#s4hint .hint}

③ 手拉出 3 m 绳，4 段滑轮组，重物升多高？ {#s5q3 .quiz-q i18n=text}

::: html step5-3
s5q3o0: 0.75 m
s5q3o1: 1.25 m
s5q3o2: 12 m
c1h: 力矩平衡
c1: 转动的账看力矩：两边 **F × L 相等**就平衡（F₁L₁ = F₂L₂）。支点挪一挪、力臂变一变，同样重的物体要用的力立刻不同——大人往支点坐近些，就能和小孩坐平。
c2h: 省力必费距离
c2: 功的账本两边永远相等：**W入 = W出**。省几倍力，就费几倍距离。任何「省力神器」先拿这本账核对：多出来的功，不存在。
c3h: 数段数定倍数
c3: 滑轮组不用背公式：数承重绳段数 n，拉力就是 **F = G/n**，代价是拉绳 n 倍距离。定滑轮是特例：一段绳、只改方向，一分力不省。
s5fin: 从跷跷板到滑轮组，用的是同一套账：力矩管平衡、功管总量、段数管分担。同族的还有斜面与轮轴——在那里，省下的力照样要拿距离来还。等以后学到「功与能」的专页，这本账还会接着往下记：能量，就是这本账的总账名。
:::
