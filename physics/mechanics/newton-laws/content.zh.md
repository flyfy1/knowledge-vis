## 推得越用力，速度涨得越快 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 推与加速
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 力改变速度
:::

这一步要回答：推力变大，箱子的运动会怎样变化？**力**是对物体的推或拉，单位是**牛顿（N）**；**加速度 a** 是速度每秒改变多少，单位 m/s²（速度怎么读见 [[velocity-vt#step1|速度–时间图]]）。箱子质量固定为 2 kg，放在没有摩擦的冰面上，向右被持续推 3 秒。画面每隔 0.5 秒“拍”一次，留下半透明残影。**观察：**拖动「推力 F」，其余不变，看相邻残影的间距——间距越来越宽，说明速度在持续增大；F 越大，间距增宽得越快。控件改变的是模型输入（力），不是显示方式。 {#s0e .explain}

## 质量是对“改变运动”的抵抗 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 质量的作用
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 同样的推，不同的质量
:::

这一步要回答：同样大小的推力，推重的和推轻的有什么不同？**质量 m**（kg）衡量物体改变运动有多难。**观察：**先固定推力 F，只改质量 m，看残影间距增宽的快慢；再试着把 m 加倍——加速度应当减半（读数里给出了理论的“一半”做对照）。结论的适用条件：无摩擦、质量恒定、力的方向沿运动方向。 {#s1e .explain}

## 摩擦把一部分推力“吃掉”，剩下的才让箱子加速 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 摩擦与合力
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 合力才算数
:::

这一步要回答：地面有摩擦时，推力还全部用来加速吗？**摩擦力**阻碍相对滑动，最大值取 μmg（μ 为摩擦系数，本页静、动摩擦取同一个 μ）。**合力**是所有力的矢量和，只有它决定加速度：a = 合力 / m。箱子 3 kg。**观察：**固定 μ，慢慢加大 F——F 不超过 μmg 时箱子纹丝不动（摩擦力等于推力），一旦超过，合力才出现，残影开始散开；红色箭头是摩擦力，橙色是推力。 {#s2e .explain}

## 重力拆成两份：一份拉着往下滑，一份压向斜面 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 斜面
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 斜面上的力
:::

这一步要回答：斜面把箱子下滑的“劲”变成了多少？重力 mg 竖直向下，可以拆成沿斜面向下的一份 mg·sinθ 和垂直压向斜面的一份 mg·cosθ；摩擦力最大为 μ·mg·cosθ。于是沿斜面加速度 a = g(sinθ − μcosθ)，质量 m 约掉了，所以与质量无关（g = 9.8 m/s²）。**观察：**固定 μ，加大坡角 θ，绿色“下滑分力”箭头变长、残影下滑加快；固定 θ，加大 μ，红色摩擦箭头变长，直到箱子卡住不动。 {#s3e .explain}

## 你推它，它也同样大地推你 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 作用力与反作用力
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 作用力与反作用力
:::

这一步要回答：两个物体互相推时，各自的加速度由什么决定？牛顿第三定律：A 推 B 的力，与 B 推 A 的力**大小相等、方向相反、作用在不同物体上**。两辆无摩擦小车相向被一根弹簧推开 0.5 秒，之后各自匀速滑行。两辆车受的力一样大，但 a = F/m，所以质量小的那辆加速度大。**观察：**固定 F，改任一辆车的质量，看哪边残影跑得远；读数里的“质量×速度”在两侧总是同样大、方向相反（[[momentum-collision#step1|动量]]在碰撞页详述）。 {#s4e .explain}

## 电梯里，体重秤为什么会变大变小？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 电梯里的秤
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 用 F = ma 解释“超重”
:::

这一步要回答：秤读的是什么？秤读的是它对你的支持力 N。电梯向上加速度为 a（向下为负）时，人受重力 mg 向下、支持力 N 向上，合力 N − mg = ma，所以 N = m(g + a)。**观察：**固定体重，拖动电梯加速度：向上加速 → 读数大于体重线；向下加速 → 小于；加速度 −9.8 m/s²（自由落体）→ 读数为 0。控件改变的是电梯运动，不是体重。 {#s5e .explain}
