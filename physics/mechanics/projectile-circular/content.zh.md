## 平着扔出去的球，和直接掉下的球，同时落地 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 水平与竖直互不干扰
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 两个方向各走各的
:::

这一步要回答：水平方向的速度会不会影响下落？从 20 m 高的塔顶，青球以水平速度 v₀ 扔出，橙球同一时刻直接松手下落。重力只在竖直方向起作用，所以竖直方向两球一样：位移 ½gt²（g = 9.8 m/s²，[[velocity-vt#step3|加速运动]]的位移）；水平方向没有力，青球匀速前进 v₀·t。每隔 0.25 s 画一次位置，虚线连接同一时刻的两个球。**观察：**拖动 v₀，青球的水平间距均匀变大，但每条虚线始终水平——两球高度永远一样；v₀ = 0 时两球重合。这是忽略空气阻力的理想模型。 {#s0e .explain}

## 同样的速度，抛多高射得最远？ {#step1 h2=s1t pre=1}

::: strings

这一步要回答：固定出手速度 20 m/s，抛射角 θ 怎样决定落点？把速度分成水平分量 v·cosθ（匀速）和竖直分量 v·sinθ（向上变慢再向下）：飞行时间 2v·sinθ/g，射程 R = v²·sin2θ/g，最大高度 (v·sinθ)²/(2g)。**观察：**拖动 θ，橙色轨迹的落点沿地面移动；紫色虚线是互余角 90° − θ 的轨迹——落点与橙色相同（射程相等），但高度、时间不同；射程在 45° 时最大。点「留下这条轨迹」可以把当前角度的轨迹留作对比（最多 6 条）。忽略空气阻力。 {#s1e .explain}

这一步要回答：飞行中某一时刻的速度，水平和竖直各是多少？水平分量 vₓ = v·cosθ 始终不变（青色箭头）；竖直分量 v_y = v·sinθ − g·t 每秒减小 9.8 m/s（绿色箭头）。橙色箭头是两者合成的速度，总指向轨迹的切线方向；**速率**是它的长度 √(vₓ² + v_y²)。**观察：**拖动时间 t：上升时绿箭头向上变短，到最高点缩为 0，之后向下变长；青箭头从头到尾不变。在最高点速率最小但不为 0（水平分量仍在）。 {#s2e .explain}

## 速度大小不变，为什么还有加速度？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 圆周运动
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 圆周运动
:::

这一步要回答：小球绕圈匀速转动，为什么说它在“加速”？**加速度**描述的是速度（含方向）的变化。小球速率不变，但速度方向每时每刻在转，所以必须有一个指向圆心的加速度 a = v²/r（绿箭头），也就是**向心加速度**；速度方向沿圆的切线（橙箭头）。**观察：**改半径 r 与速率 v：绿箭头随 v² 增长、随 r 减小；周期 T = 2πr/v。点「剪断绳子」：向心的“拽”消失后，球沿着切线飞出去，不再转圈——这正是惯性。画面是 ¼ 倍速的慢放示意，可以暂停。 {#s3e .explain}

## 把炮弹平着射得越来越快，会怎样？ {#step4 h2=s4t pre=1}

这一步要回答：水平速度大到什么程度，炮弹就不再落回地面？想象在地面（不计空气）水平射出炮弹，初速 v（km/s）。地球表面弯曲：每前进约 8 km，地面向下弯约 5 m，而炮弹每秒下落约 4.9 m；当速度刚好使炮弹下落的量与地面弯下去的量相等，它就绕着地球一圈圈地“掉”下去——**第一宇宙速度** 7.9 km/s。更快则轨道变成椭圆，到 11.2 km/s（**第二宇宙速度**）以上就脱离地球。这里用万有引力（点质量地球）逐步积分轨迹。**观察：**拖动 v，看橙色轨迹何时不再撞回地面；点重放看轨迹慢慢积累。 {#s4e .explain}

## 轨道高度怎么决定速度与周期？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 卫星的账本
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 卫星的账本
:::

这一步要回答：卫星为什么不会掉下来，高度如何决定它的周期？高度 h 处的圆轨道半径 r = 6371 + h（km），速度 v = √(GM/r)，周期 T = 2π√(r³/GM)。每秒卫星“掉”向地球的距离 ½·(GM/r²)·1² 与它前进时地面弯下去的 v²/(2r)·1² 恰好相等——所以一直在掉、总掉不到。图是双对数坐标：周期与半径的 3/2 次方成正比，所有卫星落在同一条直线上（开普勒第三定律）。**观察：**拖动高度，橙点沿虚线移动；绿点分别是国际空间站、GPS、同步卫星的近似高度。 {#s5e .explain}
