## 磁场里的力：总是垂直于速度 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 力垂直于速度
:::

::: html step0-1
:::

这一步要回答：带电粒子在磁场里受的力朝哪个方向？**洛伦兹力** F = q v × B。本页磁场 B 垂直指出屏幕（画面里的小点），粒子在屏幕平面内运动，所以 F 的大小是 q v B，方向垂直于速度 v。圆点是正电荷，青色箭头是速度 v，橙色箭头是力 F，虚线弧是力会把它带出的方向。 {#s0e .explain}

::: html step0-2
s0o: 拖动速度方向角：看橙色箭头始终与青色箭头成 90°；把 q 改成负数，力反向；把 q 改成 0，力消失。
lAng: 速度方向角
lQ: 电荷 q
lB: 磁感应强度 B
:::

::: strings
r0: v = ({vx}, {vy})，F = qv×B = ({fx}, {fy})，|F| = {f}；F·v = {dot}，所以磁力不做功、速率不变。
:::

## 垂直的力把直线运动弯成圆 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 画圆
:::

::: html step1-1
:::

这一步要回答：粒子会走出什么轨迹，半径多大？力始终垂直于速度，只改变方向不改变速率，于是粒子做匀速圆周运动，向心力就是洛伦兹力：q v B = m v²/r，所以 **r = m v / (q B)**（本页 m = 1，|q| = 1）。点播放，轨迹随时间累积；“实测半径”是用轨迹上三个点算出的外接圆半径，与公式对照。 {#s1e .explain}

::: html step1-2
s1o: 先播放一圈；再把速率 v 加倍重播：半径变成几倍？再把 B 加倍：半径又怎样变？对照读数里的公式半径与实测半径。
lV: 速率 v
bPlay: 播放 / 暂停
bReset: 重置：清除轨迹并回到起点
:::

## 绕一圈要多久？与速度无关 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 周期与速度无关
:::

::: html step2-1
:::

这一步要回答：快的粒子是不是绕一圈更快？周期 T = 2πr/v，把 r = mv/(qB) 代入得 **T = 2πm/(qB)**：v 约掉了。画面里三个粒子同时从顶部出发，速率为 0.6、1.2、1.8（半径各不相同），点播放看它们是否同时回到顶部。 {#s2e .explain}

::: html step2-2
s2o: 播放，看三个点何时一起回到顶部；然后改 B 或质量 m：周期变了，三个点仍然一起回到顶部。
lM: 质量 m
:::

::: strings
r2: 三个半径 r = {r1} / {r2} / {r3}；周期 T = 2πm/(qB) = {tp}；已运动 t = {t}，完成 {laps} 圈，三个粒子相位差 = {dphi}°。
:::

## 用半圆称离子：落点位置读出质量 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 称离子质量
:::

::: html step3-1
:::

这一步要回答：怎样用磁场测一个未知离子的质量？质谱仪里，离子以相同速率 v = 1 从缝口射入，在磁场里转半圈后落在距缝口 2r 处，r = mv/(qB)。落点越远，质量越大。图中三条灰线是已知质量 1、2、3 的离子，橙色是未知离子；用它的落点位置反推质量：m = qB·x / (2v)。 {#s3e .explain}

::: html step3-2
s3o: 拖动未知质量，看橙色半圆的落点沿着底线移动；改 B：所有落点一起缩放，但反推出的质量不变。
lMu: 未知离子质量 m
:::

::: strings
r3: 落点 x = 2r = {x}；由落点反推 m = qB·x/(2v) = {m}（设定值 {ms}）。
:::

## 再加一个电场：只有一种速率能走直线 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 电场加磁场
:::

::: html step4-1
:::

这一步要回答：怎样挑出某一速率的粒子？在 B 之外再加竖直向上的电场 E，电力 qE 与磁力 qvB 方向相反。两力相等时粒子走直线，即 **v = E / B**（与电荷正负、质量无关）；否则粒子沿一条漂移的摆线弯向一侧。本页 B = 1，粒子从左端向右射入。 {#s4e .explain}

::: html step4-2
s4o: 把速率 v 调到读数里的 E/B：轨迹拉成直线；比它大或小，看向哪一边弯；再改 E，看“选中速率”随之移动。
lE: 电场 E
:::

::: strings
r4: 选中速率 E/B = {vs}；当前 v = {v}，{case}；走完 {len} 单位水平距离后竖直偏移 y = {dy}。
caseOk: 两力相等，走直线
caseHigh: 磁力更大，向下偏
caseLow: 电力更大，向上偏
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① F = qv×B 垂直于 v，不做功；② 于是 r = mv/(qB)；③ T = 2πm/(qB)，与 v 无关；④ 落点 2r 读出质量；⑤ 加电场后 v = E/B 的粒子走直线。 {#s5e .explain}

::: html step5-2
qq: 质子（电荷 +e，质量 m）与 α 粒子（电荷 +2e，质量约 4m）以相同速率垂直射入同一磁场，谁的圆半径大？
qo0: α 粒子，半径约是质子的 2 倍
qo1: 两者相同
qo2: 质子更大
s5m: 本页是均匀、恒定磁场中的单个带电粒子，经典力学，忽略辐射损失与相对论效应；m = 1、|q| = 1 为教学单位（第 3、4 步沿用）；第 4 步 E 与 B 均匀；粒子之间不相互作用；动画是教学慢放，不是真实粒子速度。
lk0: 电场页：对照电场力 qE 如何做功、与磁力怎样不同
lk1: 动量与碰撞页：力×时间 = 动量改变，对照“只改方向不改速率”
:::
