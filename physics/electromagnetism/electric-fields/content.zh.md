## 一个电荷周围，空间里每一点都有一个“力的预告” {#step0 h2=s0t pre=1}

::: strings
nav0: 0 单个电荷的场
:::

::: html step0-1
:::

这一步要回答：**电场**到底是什么，它的大小怎么随距离变？电场 E 的定义：在某点放一个单位正试探电荷，它受到的力。画布上每根箭头是该点的 E：方向就是正试探电荷被推的方向，越长越强（长度做了压缩，便于看清）。点电荷的场 E = kq/r²，本页取 k = 1（教学单位）。 {#s0e .explain}

::: html step0-2
s0o: 只改电荷 q 的正负，看全部箭头一起掉头；再把探测距离 r 拉到原来的两倍，对比读数里强度变成原来的几分之一。
lQ: 电荷 q
lR: 探测距离 r
:::

::: strings
dirOut: 背离电荷（向外）
dirIn: 指向电荷（向内）
dirNone: 没有电荷，E = 0
r0: q = {q}，探测点 r = {r}：E = kq/r² = {e}，方向：{dir}。r 加倍后 E = {e2}，是现在的 {ratio} 倍。
:::

## 两个电荷：每个电荷的场在每一点相加 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 叠加
:::

::: html step1-1
:::

这一步要回答：有多个电荷时，某一点的电场怎么求？**叠加原理**：总场 = 每个电荷单独产生的场的矢量和（把箭头首尾相接）。橙色箭头是 q₁ 在探测点的场，粉色是 q₂ 的，青色是它们的和 E。箭头按最大者缩放，彼此长度比例是真实的。 {#s1e .explain}

::: html step1-2
s1o: 保持探测点不动，把 q₁、q₂ 设成同号、再设成异号，看青色总箭头怎样由橙、粉两个箭头拼出来；再把探测点移到两电荷正中间，比较两种情形。
lQ1: 电荷 q₁（左）
lQ2: 电荷 q₂（右）
lPx: 探测点 x
lPy: 探测点 y
:::

::: strings
r1: E₁ = ({e1x}, {e1y})，E₂ = ({e2x}, {e2y})，总场 E = ({ex}, {ey})，|E| = {mag}。
:::

## 场线：把场画成可以数的曲线 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 场线
:::

::: html step2-1
:::

这一步要回答：怎样一眼看出场的整体形状？**电场线**是顺着 E 的方向走的曲线：从正电荷出发，在负电荷终止（或伸向远处）。每个电荷发出的线数与它的电荷量成正比（本页每 1 个单位画 6 条）；线越密的地方场越强；两条线不会相交，因为同一点只有一个 E 的方向。 {#s2e .explain}

::: html step2-2
s2o: 设 q₁ = +3、q₂ = −1，数读数里有几条线落在负电荷上、几条跑向远处；再把 q₂ 改成正，看线怎样互相绕开。
:::

::: strings
r2: 共 {n} 条线：连接两个电荷 {hit} 条，伸向（或来自）远处 {out} 条；净电荷 q₁ + q₂ = {net}。
:::

## 等势线：沿它走不做功，场线与它垂直 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 等势线
:::

::: html step3-1
:::

这一步要回答：**电势** V 是什么，它和 E 什么关系？点电荷的电势 V = kq/r（k = 1），表示把单位正电荷从无穷远搬到该点所做的功。电势相同的点连成**等势线**：画布里色带的边界，相邻边界相差 ΔV。电场指向电势下降最快的方向，E = −∇V，所以场线（白色细线）总与等势线垂直。q₁ 固定为 +2。 {#s3e .explain}

::: html step3-2
s3o: 拖动 ΔV，色带变宽变窄，边界即等势线；移动探测点，看白色短线（等势线切向）是否始终垂直于青色 E 箭头，并核对读数里解析 |E| 与由 V 差分得到的 |E| 是否一致。
lDv: 等势线间隔 ΔV
:::

::: strings
r3: 探测点 V = {v}；解析 |E| = {ea}，由 V 数值差分得 |E| = {en}；E 与等势线切向的夹角 = {ang}°。
:::

## 释放一个试探电荷：它真的沿场线走吗？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 释放电荷
:::

::: html step4-1
:::

这一步要回答：电荷在场里怎么运动，能量去了哪里？受力 F = qE，加速度 a = (q/m)E（取 m = 1）。点播放，试探电荷从静止出发，轨迹累积成尾迹。因为有惯性，电荷一般**不会**严格沿场线走。能量守恒：动能 ½v² + 势能 (q/m)V 在运动中保持不变（场源 q₁ = +2、q₂ = −2 固定）。 {#s4e .explain}

::: html step4-2
s4o: 把 q/m 从 +1 改成 −1 再播放，对比尾迹方向；改变起点 x 再播放。读数里的“能量漂移”应接近 0。
lQm: 试探电荷 q/m
lX0: 起点 x
bPlay: 播放 / 暂停
bReset: 重置：清除尾迹并回到起点
:::

::: strings
st4idle: 尚未播放
st4run: 运动中
st4pause: 已暂停
st4hit: 已撞到电荷，停止（近距离截断）
st4out: 已飞出画面，停止
r4: t = {t}，速度 {v}，动能 {ke}，势能 {pe}，总能量 {tot}（起点 {tot0}，漂移 {drift}%）。状态：{state}
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 电场 E 是单位正试探电荷受的力，点电荷 E = kq/r²；② 多个电荷的场逐点矢量相加；③ 场线从正电荷到负电荷，线数与电荷量成正比；④ V = kq/r，E = −∇V，场线垂直于等势线；⑤ 电荷受力 F = qE，运动中动能与势能之和不变。 {#s5e .explain}

::: html step5-2
qq: 两个电荷量相同、符号也相同的电荷，在它们连线的正中点，电场是多少？
qo0: 最大，两个场同向叠加
qo1: 0，两个场大小相等、方向相反
qo2: 等于单个电荷场的一半
s5m: 本页是二维平面里的静止点电荷、真空静电模型；k = 1 是教学单位，数值不是 SI 值。没有导体、介质、磁场与辐射；试探电荷不改变场源；在 0.15 单位以内截断（真实点电荷此处场趋于无穷）；动画是教学慢放，不是真实电子速度。
lk0: 干涉页：两个波源的效果也是逐点相加，去看路程差如何决定加强或抵消
lk1: 动量与碰撞页：另一类“守恒账本”，对照这里的能量守恒
lk2: 热力学页：从能量账本出发看功与热，对照这里动能与势能的互换
:::

::: strings
qwhy: 两个场大小相等、方向相反，矢量和为 0（第 1 步：把探测点移到正中间可验证）。
:::
