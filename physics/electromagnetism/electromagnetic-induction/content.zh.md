## 先量一量：有多少磁场“穿过”线圈 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 磁通量
:::

::: html step0-1

这一步要回答：**磁通量**Φ 是什么，随磁铁位置怎样变？磁通量 = 垂直穿过线圈平面的磁场总量（磁场强度 × 面积，考虑方向）。图中线圈是竖着的圆环，磁铁（右端 N、左端 S）沿轴线移动。磁铁在线圈中心时穿过最多，离远了迅速减小。Φ(z) = 1 / (1 + z²)^{3/2}（线圈半径 = 1，磁偶极子近似，教学单位）。 {#s0e .explain}

::: html step0-2
s0o: 拖动磁铁位置 z：看下方曲线上的圆点沿曲线移动，对照读数里 Φ 的值：z = 0 时最大，|z| 越大越小。
lZ: 磁铁位置 z
:::

::: strings
r0: z = {z}：Φ = 1/(1+z²)^{3/2} = {phi}（相对于最大值 {pct}%）。

## 磁通量变化得越快，电压越大 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 变化率就是电压
:::

::: html step1-1
:::

这一步要回答：线圈两端的电压从哪里来？**法拉第定律**：感应电动势 ε = −N dΦ/dt（N 是匝数，这里 N = 1），即磁通量对时间的变化率；Φ 不变就没有电压。磁铁按 z = 3 sin ωt 往复穿过线圈。点播放：青色是 Φ(t)，橙色是 ε(t)，曲线随时间累积在右侧。 {#s1e .explain}

::: html step1-2
s1o: 播放后注意：Φ 在最高点（磁铁在线圈中心）时 ε = 0，Φ 变化最陡处 ε 最大；把 ω 加倍重播，ε 的峰值变成几倍？
lW: 磁铁往复角频率 ω
bPlay: 播放 / 暂停
bReset: 重置：清除曲线并回到起点
:::

::: strings
r1: t = {t}：Φ = {phi}，ε = −dΦ/dt = {eps}；到目前为止 |ε| 峰值 = {peak}。
hint1: 按“播放”开始
:::

## 楞次定律：感应电流总是反对变化 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 楞次定律
:::

::: html step2-1
:::

这一步要回答：感应电流朝哪个方向转？**楞次定律**：感应电流产生的磁场总是反抗磁通量的变化（变大就削弱，变小就补偿）。从右侧（+z 一侧）看，逆时针电流产生向右（+z）的磁场。磁铁在线圈左边 z = −1.5，速度 v 为正表示靠近。画面中绿色是感应电流，粉色箭头是它产生的磁场。 {#s2e .explain}

::: html step2-2
s2o: 把 v 从正拉到负（靠近变远离）：电流方向反转；再点翻转磁铁：电流再次反转；v = 0：没有电流。
lV: 磁铁速度 v
bFlip: 翻转磁铁（N、S 对调）
:::

::: strings
r2: 磁通量变化率 dΦ/dt = {dphi}（{trend}）；ε = {eps}；感应电流{dir}，其磁场指向 {bdir}。
trendUp: 增大
trendDown: 减小
trendNone: 不变
dirCcw: 沿逆时针（从 +z 一侧看）
dirCw: 沿顺时针（从 +z 一侧看）
dirNone: 为零
bRight: +z（向右）
bLeft: −z（向左）
bNone: 无
:::

## 匝数与速度：各自放大电压 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 匝数与速度
:::

::: html step3-1
:::

这一步要回答：怎样得到更大的电压？ε = −N dΦ/dt：匝数 N 越多，每匝的电压叠加；磁铁运动越快，dΦ/dt 越大。灰色是 N = 1、ω = 1 的基准曲线（一个周期），橙色是当前设置，同一时间轴。读数里的峰值由对一个周期逐点计算得到。 {#s3e .explain}

::: html step3-2
s3o: 只改 N：曲线形状不变，高度按比例放大；只改 ω：曲线变高也变窄。核对读数里“峰值比”是否等于 N × ω。
lN: 线圈匝数 N
:::

::: strings
r3: 峰值 |ε| = {peak}（基准 {base}），峰值比 = {ratio}；N × ω = {nw}。周期 = {per}。
:::

## 发电机：转动线圈，磁通量自己在变 {#step4 h2=s4t pre=1}

::: strings
nav4: 4 发电机
:::

::: html step4-1
:::

这一步要回答：不动磁铁，怎样让磁通量变化？在匀强磁场 B 里转动面积 A = 1 的线圈：Φ = BA cos θ，θ = ωt。于是 ε = BAω sin ωt，是一条正弦波，峰值 BAω。点播放：左边是线圈（侧视），右边是 Φ（青）与 ε（橙）累积的曲线。 {#s4e .explain}

::: html step4-2
s4o: 播放后调大 ω：正弦变密、变高；调大 B：变高但疏密不变。注意线圈与磁场垂直（Φ 最大）时 ε = 0。
lWr: 线圈转速 ω
lB: 磁感应强度 B
:::

::: strings
r4: f = ω/2π = {f}；峰值 BAω = {peak}；有效值 = 峰值/√2 = {rms}（对一周期数值均方根 {rmsn}）；t = {t}，θ = {th}°，ε = {eps}。
:::

## 回顾与自测 {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回顾自测
:::

::: html step5-1
:::

**回顾**：① 磁通量 Φ 是穿过线圈的磁场总量；② ε = −N dΦ/dt，变化率才产生电压；③ 楞次定律给出方向：反抗变化；④ 匝数和速度各自成比例放大 ε；⑤ 转动线圈得到正弦交流电，峰值 BAω。 {#s5e .explain}

::: html step5-2
qq: 线圈匝数加倍、磁铁往复的角频率也加倍，感应电动势的峰值变为原来的几倍？
qo0: 2 倍
qo1: 3 倍
qo2: 4 倍
s5m: 本页用磁偶极子近似、线圈半径为 1 的教学单位，忽略线圈自感与电阻（电压不产生反作用力）；第 1 步和第 3 步里磁铁运动按给定函数，不受线圈电流反作用（真实情况下按楞次定律会受阻力）；第 4 步 B 均匀、线圈无负载。动画是教学慢放。
lk0: 磁场页：感应电动势的微观来源是磁力作用在导线里的电荷上
lk1: 导数页：ε = −dΦ/dt 就是变化率，去看导数怎样一步步定义
:::

::: strings
qwhy: 峰值 ∝ N × ω，两个因子各乘 2，共 4 倍（第 3 步的“峰值比”可验证）。
:::
