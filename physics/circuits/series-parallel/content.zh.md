## 串联：电流处处相同，电压按电阻分 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 串联
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 首尾相接
:::

这一步要回答：两个电阻首尾相连（**串联**）时，电流和电压怎样分配？电源电压固定为 12 V。回路只有一条路，所以各处**电流**（每秒通过的电荷量，单位安 A）一样大，圆点流速处处相同；总电阻是两者之和 R = R₁ + R₂，电流 I = U/R（见[[ohms-law#step1|欧姆定律]]）；每个电阻上分到的**电压**（单位伏 V）是 U₁ = I·R₁、U₂ = I·R₂，所以电阻大的分到的电压多，两个电压之和等于电源电压。**观察：**拖动 R₁ 或 R₂：电流变化（圆点快慢），读数里 V₁ 与 V₂ 之比总等于 R₁ 与 R₂ 之比。可以暂停动画；圆点只示意相对快慢，不是电子真实速度。 {#s0e .explain}

:::

## 并联：电压处处相同，电流按电阻反比分 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 并联
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 分叉再汇合
:::

这一步要回答：两个电阻并排接在同一对节点之间（**并联**）时，电流怎样分？每条支路两端都直接接在电源两端，所以每条支路的电压都是 12 V；各支路电流 I = U/R，电阻小的支路电流大；总电流是各支路电流之和。**观察：**拖动 R₁ 或 R₂：R 变小的那条支路里圆点变快、电流变大，总电流（左侧）随之变化；读数里两支路电流之比等于电阻之比的倒数（R₂/R₁）。 {#s1e .explain}

::: html step1-2
s1cv: 并联电路：电流在节点处分成两股，各支路电压都等于电源电压
:::

::: strings
s1ro: R₁ = {r1} Ω，R₂ = {r2} Ω：I₁ = 12/R₁ = {i1} A，I₂ = 12/R₂ = {i2} A，总电流 I = I₁ + I₂ = {I} A；I₁ : I₂ = R₂ : R₁ = {ratio}。
:::

## 再接一个灯泡，总电阻是变大还是变小？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 总电阻
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 合起来等于多大
:::

这一步要回答：接上更多相同的灯泡，总电流怎样变？每个灯泡 6 Ω，电源 12 V。**等效电阻**指用一个电阻代替整个电路而电流不变时的阻值：n 个串联 R = 6n（每多一个都更大），n 个并联 R = 6/n（每多一个都更小，比任一个都小，因为多了一条路）。**观察：**拖动灯泡个数 n：青线（串联）的总电流随 n 增加而下降、每个灯泡电压变成 12/n，越来越暗；橙线（并联）总电流随 n 增加而上升，每个灯泡仍是 12 V，亮度不变。 {#s2e .explain}

## 拧下一个灯泡，其他灯泡还亮吗？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 拧下一个灯泡
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 一个坏了，其他会怎样
:::

这一步要回答：为什么有的灯一个坏了全灭，有的不会？三个相同灯泡每个 6 Ω，电源 12 V。点「拧下灯泡」把它拿掉（那个位置断开）。**串联**只有一条通路：断开一处，全回路无电流，全部熄灭；而且灯泡越多，每个分到的电压越少、越暗。**并联**每个灯泡有自己的支路：拿掉一个，其余各自仍是 12 V，亮度不变，总电流减小。**观察：**先选接线方式，再依次拧下灯泡，看亮着的灯泡数与读数里的总电流。「放回全部」会把灯泡全部装回去。 {#s3e .explain}

## 一个电阻串联着两个并联的电阻，怎么算？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 混联
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 混合接法
:::

这一步要回答：既有串联又有并联时怎么算？先把并联部分 R₂、R₃ 合成一个等效电阻 R₂₃ = R₂R₃/(R₂ + R₃)，它与 R₁ 串联，总电阻 R = R₁ + R₂₃，总电流 I = 12/R。R₁ 上分到 V₁ = I·R₁，剩下 V₂₃ = 12 − V₁ 同时加在 R₂ 和 R₃ 上，各自电流 I₂ = V₂₃/R₂、I₃ = V₂₃/R₃。**观察：**拖动三个电阻，读数核对两条规律：电压 V₁ + V₂₃ = 12 V（沿回路电压之和等于电源电压），电流 I₂ + I₃ = I（分叉前后电流守恒）。 {#s4e .explain}

:::

## 家里的电器为什么并联，保险丝又为什么串在总线上？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 家里的线路
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 用起来
:::

这一步要回答：家里的线路怎么接，为什么会跳闸？家用插座电压约 230 V，所有电器**并联**在同一对线上，每个电器都得到 230 V 并独立工作，各自的电流 I = P/U（P 是功率，单位瓦 W）；总电流是各电器电流之和，都要从**保险丝**（或空气开关）经过，保险丝与它们**串联**，总电流超过额定值（这里取 13 A）就熔断或跳闸，切断全部电路。**观察：**依次接入电器：灯和电视电流很小，开水壶 7.8 A，取暖器 8.7 A，两个大功率电器一起超过 13 A 就会跳闸；点「重新合上」复位。这里把电器当作纯电阻，忽略线路电阻和启动电流。 {#s5e .explain}
