## 电压加倍，电流也加倍 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 电压与电流
:::

::: html step0-1

这一步要回答：电路里的电流和电压是什么关系？**电压 U**（单位伏 V）表示电源给每份电荷提供的能量；**电流 I**（单位安 A）表示每秒通过导线某处的电荷量。电阻固定为 10 Ω，只改电压。小圆点只示意电流方向与相对大小，不是电子的真实速度（[[simple-circuits#step4|简单电路]]里有完整回路的说明）。**观察：**拖动电压，每到一个想要的值就点「记录这一点」，右图的点会连成一条过原点的直线——电流与电压成正比。可以暂停流动动画；改变的是电源电压，不改电阻。 {#s0e .explain}

## 电压不变，电阻越大，电流越小 {#step1 h2=s1t pre=1}

::: strings
nav1: 1 电阻的作用
:::

::: html step1-1

这一步要回答：电压不变时，换更大的电阻会怎样？**电阻 R**（单位欧 Ω）定义为 R = U/I：流过 1 A 电流需要多少伏的电压。电源固定 6 V，只改 R。**观察：**拖动 R，红点在右图曲线上滑动；R 加倍时 I 应减半（读数给出理论的一半做对照），而乘积 I×R 始终等于 6 V。流动圆点的速度也随电流变慢，仍然只示意相对大小。 {#s1e .explain}

## 灯丝越热电阻越大：电流不再与电压成正比 {#step2 h2=s2t pre=1}

::: strings
nav2: 2 灯丝不守规矩
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 并不是所有元件都服从
:::

这一步要回答：欧姆定律对所有元件都成立吗？欧姆定律说的是：对**电阻值不随电压变化**的元件（定值电阻），I 与 U 成正比；这类元件叫**欧姆元件**。灯丝通电后变热，电阻随之变大（模型：R = R₀(1 + γ·P)，R₀ = {R0} Ω，γ = 0.05 /W，P = UI 是灯丝的功率），所以灯泡的 I–U 曲线向下弯。**观察：**拖动电压，青色（6 Ω 定值电阻）是直线，橙色（灯泡）弯曲；读数里的“表观电阻”U/I 在电阻上不变，在灯泡上随电压升高。 {#s2e .explain}

:::

## 同样是电阻变大，功率可能变大也可能变小 {#step3 h2=s3t pre=1}

::: strings
nav3: 3 功率与发热
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 电能去哪儿
:::

这一步要回答：电阻变大时，它消耗的功率怎么变？**功率 P**（单位瓦 W）是每秒转化的电能，P = U·I = I²R = U²/R，在电阻上就是每秒产生的热。结果取决于你“保持什么不变”：保持**电压**不变（接在固定电源上）时 P = U²/R，R 越大 P 越小；保持**电流**不变（串联一个恒流源）时 P = I²R，R 越大 P 越大。**观察：**切换保持项，再拖动 R，看橙点在曲线上往哪个方向走；读数中三个公式的结果相同。 {#s3e .explain}

holdV: 保持电压 6 V

:::

## 负载多大时，电池给外面的功率最多？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 电池的内阻
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 电池也有电阻
:::

这一步要回答：真实电池接上负载后，外面能得到多少功率？电池有**电动势** E = 6 V（不接负载时两端的电压）和**内阻** r（电池自身的电阻），与负载 R 串联：I = E/(R + r)，负载分得的电压 U = IR 小于 E，r 上也要发热。负载功率 P = I²R 先随 R 增大，然后下降；当 R = r 时最大，为 E²/(4r)，此时电池效率 η = R/(R+r) 只有 50%。**观察：**选一个 r，拖动 R，看橙点是否在绿点（R = r）处达到最高。 {#s4e .explain}

这一步要回答：只看电流表，怎样知道一个看不见的电阻有多大？电路里有一个未知电阻。拖动电压并记录几个点，I–U 图上点连成的直线斜率是 1/R，也可以直接用 R = U/I 估计。选好答案后点「检查」，再点「换一个」试下一个。**观察：**电压为 0 时电流为 0，不能用来测 R；换较大的电压读数更清楚。「清空」会同时清除记录点与你的选择。 {#s5e .explain}
