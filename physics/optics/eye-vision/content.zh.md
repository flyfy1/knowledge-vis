## 看近处的东西时，如果晶状体不调节，像会落在哪里？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 眼睛成像
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 眼睛像照相机
:::

<b>这一步回答：物体离眼睛的远近怎样改变像的位置？</b>把眼睛简化成一个薄透镜加视网膜（相距 17 mm）。放松的晶状体焦距约 17 mm，远处的光恰好聚在视网膜上；物体靠近时，像移到视网膜<b>后面</b>（成像公式 1/v = 1/f − 1/u），视网膜上只得到一个模糊的光斑（右侧圆斑，直径超过约 10 µm 就感到模糊）。拖动物距；射线的发散程度只是示意。 {#s0e .explain}

## 眼睛怎样让不同距离的物体都清晰？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 调焦
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 调焦（晶状体变凸）
:::

<b>这一步回答：眼睛靠什么看清近处？</b>睫状肌让晶状体变凸、焦距变短，屈光力增加。物体在 u 处，需要额外增加 1/u（单位 D，屈光度 = 1/米）。屈光力增加量有上限，叫调节幅度 A：年轻人约 10 D，随年龄下降，所以近点 = 1/A，物体比近点更近就看不清（老花）。拖动物距和调节幅度。 {#s1e .explain}

:::

## 眼球稍微长一点或短一点，远处的东西就看不清吗？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 近视与远视
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 近视与远视
:::

<b>这一步回答：眼轴长度怎样决定近视、远视？</b>放松晶状体的屈光力约 58.8 D（焦距 17 mm）。眼轴 L 太长（&gt; 17 mm），远处平行光的焦点落在视网膜<b>前面</b>——近视；L 太短，焦点在视网膜<b>后面</b>——远视。屈光度偏差 = 1000/L − 58.8 D：负数是近视，数字的倒数就是不戴眼镜能看清的最远距离（远点）。拖动眼轴长度。 {#s2e .explain}

:::

## 戴几度的什么镜片才能让远处的像重新落在视网膜上？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 配眼镜
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 戴上眼镜
:::

<b>这一步回答：眼镜的度数怎么定？</b>镜片紧贴眼睛时屈光力直接相加：总屈光力 = 58.8 + P。近视需要 P &lt; 0 的凹透镜（发散，把焦点推后）；远视需要 P &gt; 0 的凸透镜（会聚，把焦点拉前）。使远处物体清晰的 P 恰好等于屈光度偏差（如 −2.0 D，常说“两百度近视”）。拖动眼轴和镜片度数，找到绿色（清晰）的位置。 {#s3e .explain}

## 为什么光线亮、瞳孔缩小时，远近都更清楚？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 瞳孔与景深
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 瞳孔与景深
:::

<b>这一步回答：瞳孔大小怎样影响“多大范围内都清晰”？</b>模糊斑直径 ≈ 瞳孔直径 × |像距 − 视网膜距离| / 像距。瞳孔越小，同样的失焦造成的斑越小，清晰的物距范围（景深，绿带）越宽——和小孔成像的道理相同。曲线是不同物距的模糊斑直径，虚线是约 10 µm 的可感知阈值。拖动瞳孔直径和对焦距离。 {#s4e .explain}

## 正常、近视、远视、老花，各自能看清哪一段距离？ {#step5 h2=s5t pre=1}

::: strings

s5k: 终章 · 不同的眼睛

<b>这一步回答：把眼轴和调节幅度合起来，谁的清晰范围是什么？</b>能看清的物距满足：需要的调节量 = 屈光度偏差 − P + 1/u 落在 0 到调节幅度 A 之间。绿条是矫正后（戴 P = 屈光度偏差的镜片）的清晰范围，橙条是裸眼。近视者远点有限；远视者靠调节才能看远，容易疲劳；老花者 A 很小，近点很远，需要为阅读额外加光度（约 3 D 减去自己的 A）。 {#s5e .explain}
