## 模型与失配

- `model.js`：`Hsec`/`H`/`phase`（公式）；`simulate`（RK4，任意 lp/hp/bp 节级联）；`bench`（整周期采样、≥ 40 个最慢时间常数后对各音做正交投影）；`measure`、`twoTone`、`cleanup`、`bestUnderLoss`（闭式）、`bandpass`（二分找 −3 dB 点）、`verdict`、`benchDesign`。
- 「实测」是数值积分不是仪器；首版只等 16 个时间常数，残余过渡（~1e−7）在 −136 dB 的嘶声上可见，测试抓到后改为 40 个。
- 页面明说：理想元件、节间理想缓冲、频响只描述稳态、指标只考核三个频点。

## 数值结论与测试（`tests/core.cjs`）

- 1.59 kΩ × 100 nF ≈ 1 kHz、RC ≈ 0.159 ms；53 个频点实测增益与公式相对误差 < 10⁻⁴（实际 1e−6），相位一致，单调下降。
- 全部 f_c 格点：−3.01 dB、−45°、±1 十倍频程的 −20.04/−0.04 dB 与 −5.7°、斜率 ≈ −20 dB/十倍频程、只依赖 f/f_c。
- 第 2 步：两音实测 = 公式；3f₁ 迟到更短；50 Hz 形变 < 0.1%、迟到 ≈ RC；1 kHz 形变在 15–16.5%；形变随 f₁ 单调增。
- 第 3 步：实测 = 公式；斜率 −20n；1 dB 预算最优值四舍五入为 22/38/51/63 dB 且为紧界；文案引用值由测试钉住。
- 第 4 步：低/高通 −3 dB、±45°、镜像；带通反推 Q = 设定 Q（1e−6）、lo·hi = f₀²、峰值 0 dB、带宽随 Q 单调减、相位斜率随 Q 增；Q = 0.5 → 2 kHz、Q = 10 → 100 Hz。
- 第 5 步：滑杆网格上 n = 1 无解（并有闭式论证）、n = 2 恰 3 个组合且位置如文案、n = 3、4 更宽；5 组设计实测与公式差 < 0.001 dB；默认设计不达标。
- 双语键集与占位符一致；页脚含模型 id 与原版标题；无左右图措辞；深链与锚点存在。
