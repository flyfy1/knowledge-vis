## 定位

- category `physics`，subtopic `thermal`，stage `junior`（与原版一致）。
- 受众：初中生。已知：温度、质量 = 密度 × 体积、热量 Q = cmΔt（比热容）。熔化热在页内当场解释。
- 一句话直觉：**能冻的只有那层几微米的膜；结冰放热会把膜暖回凝固点，热流不走，冻结就停；放热造成的温差让表面张力不均，液体被拉动，冰晶跟着漂。**
- 与原版的差异（设计选择）：
  - 全页用「三本账」组织：质量、热量、表面张力。
  - 第 0 步先算膜和空气各有多重。
  - 第 3 步用熔化热和比热容算出「靠自己能冻掉多少」（f* = cΔT / L），把「为什么会停」变成一笔可算的账。
  - 第 4 步把马兰戈尼流拆成温度 → 表面张力 → 流向三张同轴图。
  - 第 5 步用一个标明是示意的温度剖面解释前沿为何停下，并保留试过的曲线。
  - 颜色只在收束处说明并深链干涉页，不做光谱计算。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）分两类内容。
- **物理估算**（教科书常数，水的数值）：
  - 膜和空气的质量：`bubble`；
  - 熔化热账：`fStall`、`filmTemp`、`heatBudget`；
  - 表面张力随温度：`gamma`（75.6 − 0.15T mN/m）。
- **示意模型**（规则写明，单位是示意单位）：
  - 六臂冰晶：尖端速度 = 0.004·ΔT。一点归最先到达它的冰晶，所以冰占到的区域是各六边形的并集；网格采样得到占比。
  - 侧枝间距：min(0.3, 1/ΔT)。
  - 马兰戈尼流：u = 0.9·(dγ/dT)·dT/dx，高斯暖点，RK4 积分冰晶位置。
  - 温度剖面：指数衰减。
- **数据与来源**：S. F. Ahmadi 等，How soap bubbles freeze，Nature Communications 10, 2531（2019），DOI 10.1038/s41467-019-10021-6。本页只借用三样：
  - 定性结论：冷环境冻满、暖空气中前沿半路停下；
  - 结冰放热驱动马兰戈尼流；
  - −6.5 °C 凝固点参考值。
  - 预设按钮的 −18 °C 与 +25 °C 是本页的示例设定。本次编写没有重新打开论文核对原文，只以原版 BRIEF 中的引述为准。
- **模型失配**（页面明说）：
  - 质量与热量用纯水数值做量级估算，忽略甘油与肥皂；
  - 不向外散热的假设只用于第 3 步；
  - 冰晶形状、流速和前沿停顿高度都不是论文数据的复现，不能用来预测真实泡泡。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：
  - 膜质量 = πD²h，空气质量 = πD³/6·ρ；默认比值 17.2；
  - 全滑杆范围内空气都比膜重，泡越大比值越大；头发比 = 70/h。
- 第 1 步：
  - T ≥ Tm 时不长；冰占比不减，无冰种时为 0；
  - −20 °C 下单颗冰种 30 s 铺满；
  - 臂长不超过未裁剪长度；到达时间 ⇔ 位于某六边形内（200 个点）。
- 第 2 步：
  - 臂长比 = ΔT 比（全滑杆格点）；侧枝随 ΔT 变密；
  - 滑杆上限 −6 °C 时触发「不长」提示。
- 第 3 步：
  - f* = cΔT/L；−25 °C 时 f* ≈ 23.15%（文案「约 23%」由测试钉住）；
  - 膜温在 f* 处恰为 Tm、此后走平、从不超过 Tm；
  - 热量账相加一致；f* 永远落在 0–40% 坐标内。
- 第 4 步：
  - 越热 γ 越小，5 °C 对应 0.75 mN/m；
  - 温差 0 时无流动；流向永远背离暖点；
  - 冰晶从不向暖点漂，也不离开膜条。
- 第 5 步：
  - 冻满 ⇔ 泡顶的膜也低于 Tm（测试最初发现「气温高于 Tm 就一定半路停」的说法不对：气温略高于 Tm 时仍会冻满，已改文案）；
  - 前沿处膜温 = Tm，下冷上暖；气温越高前沿越低；
  - −18 °C 冻满，+25 °C 停在 12.5%。
- 文案引用的常数（−6.5 °C、334、4.18、0.15、70 µm、0.00129、预设温度、DOI）与模型一致。
- 双语与页面结构：
  - 键集与占位符一致，静态键不含占位符；
  - HTML / app 用到的键都存在，控件齐全，无 label guard，有署名占位；
  - 深链锚点存在。
