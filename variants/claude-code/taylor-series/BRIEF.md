## 定位

- category `math`，subtopic `calculus`，stage `university`（与原版一致）。
- 受众：学过导数的大学低年级；不要求复分析，第 4 步只借用「收敛半径 = 到最近奇点的距离」这一结论并明说来源。
- 一句话直觉：**在一点上每多对齐一阶导数，误差的阶就加 1；但级数能走多远由复平面上最近的奇点决定。**

## 数值结论与测试（`tests/core.cjs`）

- 系数与已知级数一致（5 函数 × k≤12）；60 次级数在 0.3 处收敛到函数；P 的 k 阶差分 = k!·cₖ。
- 第 0 步：全滑杆网格上「全部对齐」时斜率 ≈ 3；默认/对齐 c₁/全对齐/c₀ 偏离的阶为 1/2/3/0，比值 ≈ 2/4/8。
- 第 2 步：n=1 窗口 0.39、n=15 窗口 5.50；奇数次增量 0.645–0.755；偶数次不变；窗口内处处 < 0.01、边外 ≥ 0.01。
- 第 3 步：误差高于 10⁻¹³ 时实际 ≤ 上界；上界相邻比 = x/(n+2)；起步上升当且仅当 x > 2；na ≤ nb ≤ 32。
- 第 4 步：R=√(1+a²)；圈内 0.5R 处 80 次收敛；所有 a 上 n 10→40 圈内误差降、圈外升且 > 1；根值判别 ≈ 1/R；a=2 时 2.24。
- 第 5 步：所有 x 达到容差且 N 最小；正侧最多 20、负侧最多 26；x=−5 最大项 5⁵/5!；取倒数法达到容差。
