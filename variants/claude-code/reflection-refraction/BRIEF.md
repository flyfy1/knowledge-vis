## 定位

- category `physics`，subtopic `optics`，stage `junior`（与原版一致）。
- 受众：初中生与家长；知道光沿直线传播、会量角度，没学过折射率。
- 一句话直觉：**光在界面上只认法线：反射时两边等角；穿过界面时按 n₁·sin θ₁ = n₂·sin θ₂ 拐弯；从「密」往「疏」走时角度会先到 90°，再往后就只剩反射。**
- 与原版的差异（设计选择）：原版五步（反射、漫反射、折射、全反射、看鱼 + 自测）。本版拆成七步：漫反射用「9 条平行光 + 粗糙度滑杆 + 高亮一条看它在自己小平面上等角」；折射和全反射各配一张 θ₂–θ₁ 曲线图，留下试过的点；把全反射单独接一步「玻璃棒导光」（空气 / 水 / 包层三种外层，比较撞壁角和临界角）；看鱼一步让眼睛横向移动，竖线上留下每个位置看到的深度，说明「看得越斜越浅」。

## 模型与数值

- `model.js`（浏览器与 node 共用，`RR_MODEL`）：折射率 1.00 / 1.33 / 1.50 / 1.46；`reflect`、`snell`（refract / grazing / tir / invalid 四种状态）、`critical`、`surface` 与 `traceRough`（粗糙面小平面）、`beam`、`rod`（玻璃棒逐次撞壁追踪）、`acceptance`、`fishView`（鱼深 1.2 m、眼高 0.8 m）、`quiz`。
- 页面上所有角度、深度、光路都由这些函数算出；无随机数据（粗糙面小平面用固定伪随机序列，刷新不变）。
- 模型与现实的差距：不算部分反射的强度；不考虑色散；线的粗细不代表光强。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：所有滑杆值反射角 = 入射角，与镜面夹角 = 90° − 入射角。
- 第 1 步：平滑面出射全部平行；每条光线在自己的小平面上等角；粗糙面张开角随粗糙度增大；默认读数 28.9°。
- 第 2 步：全部滑杆值折射角 < 入射角、差值随入射角增大；sin 比 = n₂/n₁；玻璃比水拐得多；0° 直进。
- 第 3 步：θc = arcsin(1/1.33) = 48.753°，显示为 48.8°；滑杆邻近值（48.7 / 48.8）的状态正确；光路可逆；60° 时所需 sin θ₂ > 1。
- 第 4 步：空气外层所有角都被关住；水外层的界限 43.9° 与文案一致；包层界限小于水；关住 ⇔ 撞壁角 > 临界角；光路不出棒、撞壁次数与追踪一致。
- 第 5 步：任何眼位都显得更浅、越斜越浅；出射点满足斯涅尔；正上方极限 d/n 且连续；默认读数比 0.64。
- 第 6 步：三题答案（55°、约 28°、50° > 48.8° 全反射）。
