## 定位

- category `math`，subtopic `arithmetic`，stage `primary`（与原版一致）。
- 受众：小学高年级；会读写 0–100 的整数、会做正数范围的加减，见过数轴上「一个数 = 一个点」。
- 一句话直觉：**负数 = 先选好一个 0，再说「在 0 的哪一边」和「离 0 多远」。**
- 与原版的差异（设计选择）：原版用「数轴 / 温度计 / 电梯」三件衣服；本版用**海面**作主场景（竖着的高度标尺 ↔ 放倒的数轴），并多讲一件原版没有单列的事：**0 是我们选的**（第 1 步换 0：所有数改写、距离不变）。第 4 步用温度计讲「跨过 0 的差要分两段数」。加减只演示加/减一个正数（向右/向左走），不讲「减负数」。

## 模型与数据

- `model.js`（浏览器与 node 共用）：`describe`（哪一边、离 0 多远、同距数）、`relabel`（换 0 后的读数 = 高度 − r）、`compare` / `digitRule`（按位置比较 / 只看数字的错误规则）、`walk`（逐跳路径、首次踩 0 的跳数、是否跨过 0）、`axisFor`（第 3 步画轴范围：至少 −8..8，并比起点、落点各宽 1 格，最大 ±17）、`change`（变化量与 0 以下 / 以上两段）、`QUIZ`（答案由上述函数算出）。
- 场景数值（海鸥 +4、小鱼 −3、甲板 +2、海底 −6，温度）都是示例，不是实测；页面 s6 明说。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：−8..8 全部值的边、距离、同距数。
- 第 1 步：所有 r 下海鸥与小鱼相距 7；r 增大两数都减小；海底为 0 时小鱼为 +3。
- 第 2 步：比较 7 组（含 −5<−1、−1<0、0<3、−3=−3、−7<−2）；数字规则在 −7/−2 上给出相反结论；全部 A、B 组合下「陷阱提示」恰在 |小数| > |大数| 时出现；卡片排序与同排间距 ≥ 6 格。
- 第 3 步：五组落点（3−5=−2、−2+5=3、−1−4=−5、−4+3=−1、0−3=−3）；3 向左第 3 跳踩 0；全部滑杆组合下每跳 1 格、落点 = 起点 + 带符号步数、画轴覆盖起点与落点。
- 第 4 步：−3→5 为 3+5=8；−3→−8 为降 5 且只一段；全部 m、n 组合下两段之和 = 总差、跨 0 判定。
- 第 5 步：三题答案（−6、−9、7）在选项里，反馈文案中的 5 格、3+4 由模型核对。
- 双语：键集与占位符一致、中英不同；HTML/app 用到的键存在；深链目标页与锚点存在；对照链接、占位注释、provenance 样式存在；未引入 canvas-label-guard。
