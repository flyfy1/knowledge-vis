## 定位

- category `probability`，subtopic `inference`，stage `university`（与原版一致）。
- 受众：大学低年级；知道概率、二项系数；不要求学过正态分布（第 4 步的正态近似只作对照）。
- 一句话直觉：**p 值 = 假定无罪时看到这么反常证据的概率；α 管冤案率，样本量管放走率；「被定罪」离「真有罪」还差一个基础比例。**
- 法庭比喻只对应已定义的量：原假设 = 无罪推定，拒绝 = 定罪，第一类错误 = 冤枉公平硬币，第二类错误 = 放走偏硬币。全页不换比喻。
- 与原版的差异（设计选择）：原版 BRIEF 的最后一步讲多重检验与 Bonferroni；本版把多重检验并入第 5 步「1000 枚硬币的真相 × 判决」点阵，重点放在冤案占定罪的比例（错误发现率）取决于基础比例 π，并展示功效到顶后多抛也压不下这个比例；第 4 步显式指出锯齿（49 次够、50 次反而不够）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`pmf`（对数空间二项）、`pValue`、`critical`/`region`/`size`/`power`（拒绝域取在 H₀ 下总概率 ≤ α 的最大对称外圈）、`pBins`（p 值分布的精确分箱）、`flips`、`minN`、`approxN`（Acklam 逆正态）、`verdicts`（理论错误发现率）、`batch`（模拟一批硬币）、`familyWise`。
- 第 1、5 步是固定种子的**模拟**；其余是精确计算。
- 失配（s6 boundary 明说）：只讲精确双侧二项检验；独立抛掷；一批硬币与 π 是教学设定；p 值与贝叶斯后验回答不同问题。

## 数值结论与测试（`tests/core.cjs`）

- pmf 与二项公式一致；p 值 = 暴力求和（n ≤ 40 全部 k）；双侧对称；**p ≤ α ⇔ 落入拒绝域**（n = 10..100 × 全部 k × 4 个 α）。
- 文案引用：p(20,15) = 0.0414、p(20,12) ≈ 0.50、p(100,60) ≈ 0.057；H₀ 下 p ≤ 0.05 的比例 ≈ 3.3%（= 实际冤案率），q = 0.65 时 ≈ 51%；p 值只有二十几种取值；20000 次模拟与精确值相差 < 0.006。
- 第 2 步：全部 n × α 格点上实际率 ≤ α、拒绝域非空且是最大的；3.28%（α = 5%、6%）、6.49%（7%）；n = 10：≤1 或 ≥9，2.15%。
- 第 3 步：q = 0.5 时功效 = 冤案率；功效随 q 单调；默认功效 50.6%。
- 第 4 步：q = 0.7、α = 5% 首个 n = 49，n = 50 为 78.2%；q = 0.6 约 200；正态近似在全部 q（步长 0.01）× α 上 < 精确值 + 0.5，n ≥ 40 时相差 < 15%。
- 第 5 步：默认错误发现率 27.4%；π = 0 为 100%；π = 50% 为 4.0%；n = 200 仍在 25%–28%；40 批模拟计数与期望一致；900 枚公平硬币至少冤一枚 > 99.9%。
- 格式化：`fmt(90, 0)` 仍为 90。双语：键集与占位符一致、中英不同；无「左图/右图」；键都存在；深链与对照链接目标存在。
