## 定位

- category `earth`，subtopic `astronomy`，stage `primary`（与原版一致）。
- 受众：小学中高年级与家长。会看钟表，知道太阳东升西落、白天亮夜里黑。
- 一句话直觉：**太阳一直照着地球的一半；地球自己转，把你轮流带进亮的半边和暗的半边。**
- 与原版的差异（设计选择）：
  - 原版以可转动的 3D 地球为主，配 2D 辅助图；本版全部用 2D canvas，不依赖 WebGL。
  - 本版把「同一时刻各地不同」（经度，每 15° 一小时）单独成一步，用北京、东京、伦敦、纽约四座城市。
  - 本版另加一步「我们跑得有多快」：用纬度滑杆算地面速度，并与高铁、飞机比较，回答「为什么感觉不到」。
  - 「假如反着转」放在天空那一步，用一个切换钮实现，没有单独成步。
  - 自测共 3 题，不锁终章。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：
  - `spinAngle(t, dir)`：正午 0°、18:00 为 90°、半夜 180°、6:00 为 270°；`dir = −1` 时是假想的反转。
  - `sunDot` / `isDay` / `phase`：日出、日落各取 6:00、18:00 前后半小时。
  - `skySun`：天空中太阳的方位与高度，东画在左。
  - `litBy` / `litFraction`：灯照球。
  - `CITIES` 与 `localTime`：每 15° 经度一小时。
  - `groundSpeed`：2πR·cos(纬度)/24，R = 6371 km。
  - `turnAccel`：向心加速度。
  - `cellOf` / `cellIsDay`：96 格时间带，每格 15 分钟。
- 页面上所有数字都由模型算出；文案里引用的数字由测试钉住。
- 失配（前三条在终章明说，后两条在第 3 步正文和观察顺序里说明）：
  - 地轴画成竖直，所以各地都是昼 12 小时、夜 12 小时。真实地轴倾斜约 23.5°。
  - 「一圈 24 小时」是太阳日；恒星日约 23 小时 56 分。
  - 太阳和地球的大小、距离都是示意。
  - 第 3 步四座城市画在同一圈上，只表示经度，不表示纬度。
  - 用的是地方时，不是时区时间。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：灯在 0–359° 的每个整数度上，被照亮的比例都是 0.5；正对灯的点亮、背对灯的点暗；小明处昼夜与灯所在的一侧一致。
- 第 1 步：
  - 四个锚点（正午、18:00、半夜、6:00）的转角，以及对应的状态词；
  - 每 15 分钟逆时针转 3.75°，正午后 6 小时是日落（由昼转夜），用来防止方向画反；
  - 时间带：昼、夜各 48 格，昼格在 6:00–18:00；
  - 状态词与 `sunDot` 一致；时钟回绕时不出现负值。
- 第 2 步：
  - 日出在东边地平线、正午在头顶、日落在西边地平线、半夜在脚下；东画在左；
  - 天空中的高度与俯视图一致，太阳在地平线上方当且仅当是白天；上午太阳在东边，下午在西边；
  - 反转时太阳从西边升起，而白天仍在同样的钟点。
- 第 3 步：
  - 北京 12:00 时纽约约 23:18，且是夜里；东京早 1.55 小时；
  - 四个城市点在圈上互不重叠；文案中的经度 116、140、74 由测试钉住。
- 第 4 步：
  - 赤道一圈约 40 000 km，速度约 1670 km/h，比飞机快；北京约 1280 km/h；
  - 速度降到飞机以下的纬度约为 57.3°；拐弯的力在重力的 0.3%–0.4% 之间；
  - 文案引用上述数字；最大一根柱子不超出 1700 的刻度。
- 判断题：北京与纽约经度差 190.4°，约合 12.69 小时（正确选项「前一天 23:20 左右」与干扰项「次日 00:40」都由模型算出）。
- 双语与页面：
  - 中英文键集和占位符一致，两种语言的文本互不相同；
  - 页脚写明模型 id；全文没有「左图/右图」；
  - HTML 和 app.js 用到的键都存在，控件 id 都存在；
  - 3 条深链的目标页和锚点都存在，对照链接也存在；
  - 没有引入 canvas-label-guard，署名占位齐全。

## 可访问性、动态与双语

- 控件全部是原生 range、button、radio；每个 canvas 都有 aria-label；读数在 DOM 里（aria-live），图例也在 DOM 里。
- 播放类控件（第 1、2 步「让地球转一圈」）：
  - 速度为每秒 2 个地球小时，转满 24 小时自动停；
  - 时间带和天空中的太阳轨迹会保留走过的部分，读数显示「已经转过 X 小时 / 一圈 24 小时」；
  - 减弱动态时一按直接涂满；页面隐藏时停止动画。
- 语言存在 `localStorage` 的 `knowledge-lang`，读写都包了 try/catch；切换语言后 canvas 和判断题反馈都会重绘。
- canvas 上的文字：面板标题单独占一行，太宽时缩小字号；另有天空图里的「东 / 西 / 头顶」和时间带刻度。城市名放在 DOM 图例里，不写在 canvas 上。
