## 定位

- category `probability`，subtopic `basics`，stage `senior`（与原版一致）。
- 受众：高中；会算概率、分数和简单求和；不要求学过方差或二项分布（第 4 步的二项概率只作为读数出现，由模型精确计算）。
- 一句话直觉：**期望是概率分布的平衡点；它的意义来自重复。** 反复下注的一方（赌场、保险公司）用它记账是对的；只玩一次、损失伤筋动骨、或期望藏在极罕见结果里时，只看期望会出错。
- 与原版的差异（设计选择）：原版 BRIEF 从加权和与贡献条出发；本版从一台会倾斜的秤出发（支点处净转动 = E − g），让「平衡点」可以被拖出来；保险一步把「你的一次结果」与「保险公司的 N 单平均」放在同一张图的上下两格；圣彼得堡把平均值按档拆开，看见期望藏在哪些档里。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`mean`/`sd`/`torque`、种子 PRNG（mulberry32）、`play`（累计平均）、`band`、`coverage`、`fairness`、`netPath`、`sumDist`（独立用卷积）、`insurance`（Lanczos lgamma + 精确二项尾和）、`avgClaimDist`、`stPeteMean`、`stPetePlay`。
- 第 1、2、5 步是固定种子的**模拟**；「换随机数」只换种子。第 3、4 步是精确计算。
- 失配（s6 boundary 明说）：理想公平器具；各户独立失火（共同灾难不成立）；刮刮乐奖表虚构；不讨论效用、税费、本金上限；log₂n + 2 只是经验参考线。

## 数值结论与测试（`tests/core.cjs`）

- 三个游戏：概率和为 1；净转动 = E − g（全部滑杆格点）；E = 3.5、2、161/36；max2 的 E > 3.5。
- 第 1 步：σ_die = √(35/12)；n = 1000 时 2000 次重来的带内比例在 0.93–0.975（三个游戏）；带宽每十倍缩 √10 ≈ 3.16。
- 第 2 步：轮盘 E = 360/37、优势 1/37（2.7%，每局 −0.27）；刮刮乐 E = 4、每奖贡献 1 元；1000 张内中头奖 ≈ 1%；400 位模拟玩家平均终点 ≈ 1000·(E − c)。
- 第 3 步：所有模式与 n 下 E = 3.5n；σ√n、σn、两两相反的 σ；n = 4 时 21 / 6 / 1 根柱、三角在 14；σ ≈ 1.708。
- 第 4 步：全部滑杆格点上期望损失、保费、σ/√N；N ≤ 1000 时尾概率 = 直接求和；附加费 0、N = 100,000 时亏损概率在 48%–50%（文案「约 49%」）；默认附加费 30%、N 最大时 < 1e−10；附加费 > 0 时 N = 100,000 优于 N = 1000。
- 第 5 步：K = 1..40 时 E = K + 1（数值级数对照）；P(≤ 4 元) = 3/4（模拟 ±0.01）；301 次重来的累计平均中位数在 n = 100/1000/10000 处与 log₂n + 2 相差 < 0.5；K = 3 时 400 局内平均接近 4。
- 格式化：`fmt(90, 0)` 仍为 90。
- 双语：键集与占位符一致、中英不同；无「左图/右图」；HTML/app 用到的键都存在；深链目标与锚点存在；对照链接目标存在。
