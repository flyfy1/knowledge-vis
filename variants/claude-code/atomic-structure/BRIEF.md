## 定位

- category `chemistry`，subtopic `matter`，stage `junior`（与原版一致）。
- 受众：初中生与家长；知道物质由粒子构成、听过元素名。
- 一句话直觉：**原子几乎是空的，质量挤在极小的核里；质子数定元素，电子按 2、8、8 分层住，最外层满不满决定它稳定还是倾向得失电子；得失电子成离子，元素不变。**

## 数值结论与测试（`tests/core.cjs`）

- 元素符号、A = Z + N 与独立的常见质量数表一致。
- 排布与课本表一致；内层住满才开外层；总数守恒；氯 2, 8, 7（小测）。
- 20 个元素的倾向逐一钉住；住满恰在 2、10、18；锯齿在 3、11、19 落回 1。
- 离子：Na⁺、Cl⁻、Mg²⁺、O²⁻、Al³⁺；净电荷 = Z − e；每个「易失/易得」判定都能用第 4 步按钮做到并使最外层住满；稀有气体按钮锁定；小测镁 → Mg²⁺。
- 第 0 步：核半径、原子/核 ≈ 28,000 倍、质量 99.97% / 0.027%、体积 4.5×10⁻¹²%；画布宽 240–920 px 内，最左时核 < 1 px、原子边界在画面内，滑杆 ≤ 0.5 时核 < 2 px（仍是十字），最右时核可见且不出画面。
