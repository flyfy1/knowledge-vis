## 模型与数值

- `model.js`（浏览器与 node 共用，`WAVE_MODEL`）：A = 1 mm、f₁ = 1 Hz（教学慢放）、v = 2 cm/s；`wave`、`field`（两源叠加，可带相位差和频率比）、`pointInfo`（B = 2A|cos(δ/2)|，δ = 2πΔr/λ + φ）、`classify`（严格分类：只有 |cos| = 1 才算加强、= 0 才算静止，其余为「部分抵消」）、`sampledAmp`（对实际和逐点采样，作为 B 的独立核对）、`pointWithDelta`、`hyperbola`、`lines`、`envelope`、`beatPeriod`、`screen`、`quiz`。
- 俯视图每个像素的亮暗、曲线、读数都由这些函数算出；无随机数据。共用时钟在减弱动态时默认暂停，只为可见的步骤动画。
- 模型与现实的差距：振幅不随距离衰减（真实水波会减弱，静点只是「几乎不动」）；波源是点；周期放慢到 1 s。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部 λ 滑杆值，r 处的振动 = 源振动延迟 r/λ 个周期；周期 1 s；|y| ≤ A。
- 第 1–3 步：多组点和相位下采样振幅与 2A|cos(δ/2)| 一致（容差 2e-5）；y = y₁ + y₂；三个预设点的 Δr、类别、振幅（2 / 0 / 2）；静点 50 个时刻都为 0；接近半波长的点归为部分抵消而不是静点；不同周期的振幅相同。
- 第 2 步：λ、d 全部滑杆组合下加强线与静线条数，双曲线上每个采样点的 Δr 与类别；默认 5 条加强线、6 条静线。
- 第 3 步：φ = 180° 时加强线与静线对调、360° 回原样；全部 φ 滑杆值中垂线振幅 = 2|cos(φ/2)|，只有 180° 为静、0° 与 360° 为加强。
- 第 4 步：频率比 1.05 拍周期 20 s（与文案一致）；全部频率比下实际振动不超出包络、包络按拍周期重复；比值 1 时振幅恒定。
- 第 5 步：L = 10 cm 与文案共用同一参数；全部 d、λ 组合：λ < d 时才有第一加强点、精确点都是 Δr = mλ 的加强点、实际 x₁ 总在近似值之外、固定 d 时偏差随 λ 单调增大；默认 x₁ = 2.69 cm、偏差 7.5%。
- 第 6 步：q1 Δr = 1.5λ 为静点；q2 λ 减半后静点变加强点；q3 φ = 180° 中垂线静止但两列波振幅都不为 0。
- 双语：键集与占位符一致、非符号键中英不同、页脚含模型 id、读数字符串不含标记；HTML/app 用到的键都存在；控件 id 存在；有 provenance 占位与样式表、未引入 canvas-label-guard；深链目标页与 `#stepN` 锚点存在；对照链接目标存在。
