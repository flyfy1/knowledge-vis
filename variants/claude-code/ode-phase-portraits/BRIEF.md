## 定位

- category `math`，subtopic `calculus`，stage `university`（与原版一致）。
- 受众：大学低年级；知道导数是变化率、会读函数图像；不要求学过微分方程。
- 一句话直觉：**方程只给出「此刻的变化率」；一小步一小步推，就得到未来。把时间藏起来，兔狐的起落是相平面上一条闭合回路——零线决定它绕谁、朝哪转，守恒量 H 决定它精确闭合；拥挤项打破守恒，回路变成螺旋。**
- 与原版的差异（设计选择）：参数取 a = 1、b = 0.5、c = 1、d = 0.25（平衡点 (4, 2)，小圈周期恰为 2π）；第 0 步先拆开四个项看「变化率」本身，并用一个「按变化率走 0.1 年」的按钮预演欧拉法；第 4 步把守恒量与「周期随圈变大而变长」放在一起；第 5 步证明并展示「欧拉法每步都让 H 增加」（H 是凸函数），并实测步长减半时的误差缩小倍数；第 6 步用容纳量 K 展示闭圈 → 螺旋 → 结点 → 狐狸灭绝的三个分界（K = 2 + 2√2、K = 4），用雅可比特征值解释。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`rates`、`terms`、`stepEuler`、`stepRK4`、`integrate`（离开第一象限即停）、`H`、`V`（拥挤模型的李雅普诺夫函数）、`period`（相邻两次向上穿过 y = 2 的时间）、`returnGap`、`story`、`drift`、`eqCrowd`（平衡点与特征值）、`K_SPIRAL`、`crowdRun`。

- 模型失配（s7 明说）：连续数量，真实小种群会灭绝；参数恒定，无季节、迁移、其他物种。第 5 步的漂移是数值误差，不是生态现象。

## 数值结论与测试（`tests/core.cjs`）

- 平衡点 (4, 2)；四项之和 = 方程；四个区域的符号与逆时针顺序；小测答案 b。
- 第 1、2 步：全部 x₀、y₀ 滑杆格点上，狐狸高峰晚于兔子且滞后小于半个周期；一周后回到起点 0.01 以内；兔子高峰时狐狸在增、狐狸高峰时兔子在减；起点 (4, 2) 保持不动；y₀ 变小幅度与周期都变大。
- 第 4 步：y₀ = 0.2 … 1.9 每圈 RK4 的 H 波动 < 1e−7；周期随 y₀ 下降单调增长；y₀ → 2 时周期 → 2π（误差 < 2e−4）；网格上 dH/dt 解析为 0；所有圈在 16 × 8 坐标内。
- 第 5 步：欧拉法每一步 H 都严格增加（所有 Δt）；恰好在 Δt ≥ 0.2 时冲出第一象限；RK4 漂移 < 2×10⁻⁴；Δt ≤ 0.02 时欧拉减半倍数在 2–2.4、RK4 在 18.5–23（文案引用值由测试钉住）。
- 第 6 步：K = 3.0 … 40.0 每个格点：K ≤ 4 灭绝、4 < K < 2 + 2√2 结点、其余螺旋；平衡点满足方程；V 不增；K = ∞ 时 V 守恒。
