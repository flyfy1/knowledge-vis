## 定位

- category `math`，subtopic `linear-algebra`，stage `senior`（与原版一致）。
- 受众：高中；会坐标、勾股定理和三角函数的定义。
- 一句话直觉：**向量是一对分量；加减、伸缩按分量各算各的；点积把两个方向压成一个数。**

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全滑杆网格勾股、极坐标往返、换起点分量不变、零向量无方向角。

- 第 2 步：|k·a| = |k||a|、k·a 共线、k<0 反向、a−b = a+(−b)、b+(a−b)=a。

- 第 5 步：自动航向下偏离为 0、地速 √(200²−w²)、航向在滑杆范围内；航向 0 时 1.5 h、偏离 1.5w（文案 120 km）；所有组合航迹在地图内。
