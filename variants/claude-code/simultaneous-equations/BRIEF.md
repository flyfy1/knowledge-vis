## 定位

- category `math`，subtopic `algebra`，stage `junior`（与原版一致）。
- 受众：初中；会解一元一次方程，认识坐标平面。
- 一句话直觉：**一张收据（一个方程）只给出一条直线的价格组合；两张不成倍数的收据才把价格钉在交点上。**
- 设计选择：全页一个故事（苹果 x 元、梨 y 元）。代入法画成「点只沿直线 A 走，下图看它在 B 上的偏差何时为 0」；加减法画成「B − m·A 是一束绕交点转的直线，m 取特殊值时变成竖线 / 横线」，让两种算法都有看得见的几何含义。

## 模型、设定与失配

- `model.js`（浏览器与 node 共用）：`solve`（克拉默法则，分 one / none / many）、`residual`、`yOn`、`substitution`（逐项中间数）、`residualAlongA`、`combine`、`elimX` / `elimY`、`family`、`receipts`。所有结果按 1e-9 取整，避免 0.1 + 0.2 式的尾数。
- 预设：x + 2y = 10 & 3x + y = 15 → (4, 3)；x + y = 7 & 2x + 4y = 22 → (3, 4)；x − y = 1 & 2x + 3y = 12 → (3, 2)。
- 失配（s6 boundary 明说）：只讨论两元一次；D = 0 时公式不适用；三元以上一句带过。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：21 个滑杆位置都在 A 上；x = 3.14 也有配套 y；沿 A 每 +1 的 x 对应 −0.5 的 y。
- 第 1 步：每组预设在滑杆网格（x 0..10、y 0..8，步长 0.5）上恰有一个点两个偏差同为 0。
- 第 2 步：代入结果 = 克拉默；y* 在 y2 滑杆（0..5.5）上；r(y) = coefY·y − rhs、r(y*) = 0；默认组中间数 30、−6、−5、−15、3、4。
- 第 3 步：m 网格上每条 B − m·A 都过交点；消元 m 在滑杆网格上、恰消掉一个未知数、剩下的直接读出解；默认 m = 0.5 → 2.5x = 10，m = 3 → −5y = −15。
- 第 4 步：全部 (k, c) 网格 D = 2 − 2k、分类正确；默认交点 (2.5, 3.75)；c = 15 时 k 从 3 到 1.25 交点 |x| 单调增大并出图；判断题答案「无解」。
- 第 5 步：p、q 全网格解回原值（D = −5）；翻倍收据重合。
