## 模型与失配

- `model.js`（浏览器与 node 共用）：`value`、`kept`、`ledger`、`gainShareLost`、`loadAsAnnual`、`breakEvenYears`、`extraNeeded`。全部是确定性计算，没有随机模拟。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：1%、30 年拿走 26.0%（选项 c 最接近）；差距逐年加速；前十年差距 < 10%。
- 第 1 步：第 1 年费 212、第 30 年约 858（文案引用）；第 1 年无损失的增长；账本 = 闭式；差距 = 每笔费按 6% 滚到当年的和；第 30 年损失的增长 > 累计交费；坐标装得下。
- 第 2 步：保留比例与 r 无关（多组 r、f 验证）；74% / 60% / 55%（文案引用）；f × T 总是高估。
- 第 3 步：31% / 58% / >100%（文案引用）；r = 1% 时连本金都没保住；随 r 单调。
- 第 4 步：等价式 (1 − e)^T = 1 − L；随 T 单调变薄；相等年数为首个整年、随 f 前移；3% 对 0.5% 为 7 年；超过 50 年只在 L ≥ 4.5%、f = 0.1% 时出现（读数改用 s4never）。
- 第 5 步：所需额外回报恰好打平；总不小于费率差；随 f₂ 拉开；坐标装得下。
- 双语：键集与占位符一致、无重复键、非符号键中英不同、无「左图/右图」措辞；所有键存在；深链目标与锚点存在；对照链接存在；无 canvas-label-guard。
