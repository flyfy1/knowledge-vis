## 定位

- category `math`，subtopic `geometry`，stage `primary`（与原版一致）。
- 受众：小学中高年级 + 家长；认识正方形、长方形、三角形，知道「度」是量角的单位（第 2 步有深链）。
- 一句话直觉：**对折后两半完全重合，折痕是对称轴；转不到一整圈就重合，是旋转对称；沿两条相交的线各翻一次，等于转一次。**
- 与原版的差异（设计选择）：对折用真实的「半边翻过去」动画并给出没盖住部分的百分比（不是「看着差不多」）；对称轴计数用「转一圈扫描」；旋转一步用跟着转的粉色角点说明「看起来没变但确实转了」；新增「翻两次 = 转一次」一步，解释为什么有两条对称轴就一定有旋转对称、反过来不成立；万花筒用「每份 1 面 / 2 面」把复制份数与两种对称连起来。

## 模型

- `model.js`（浏览器与 node 共用）：图形顶点表（以面积中心为原点）、`rot`、`refl`、`same`（顶点集重合）、`isAxis`、`axes`（候选方向 = 过顶点或边中点的方向，逐个验证）、`turnsOnto` / `turns` / `order`（整数度 1..360）、`foldMismatch`（173 × 173 取样估计没盖住部分占图形面积的比例）、`twoMirrors`、`kaleido`、`copyOutline`、`patternSymmetry`、`QUIZ`、`quizAnswers`。
- 圆单独处理（对称轴、重合次数都是无穷）。第 0 步百分比是取样估计值，在对称轴处恰为 0（取样网格避开了边，测试钉住）。

## 数值结论与测试（`tests/core.cjs`）

- 对称轴表：正方形 4、长方形 2、等边三角形 3、等腰三角形 1、三边不等三角形 0、平行四边形 0、正五边形 5、正六边形 6、两种风车 0；并以 0.5° 步长全扫，确认没有漏掉或多出的轴；圆无穷。
- 旋转表：重合角正好是 360/n 的倍数，n = 4、2、3、1、1、2、5、6、3、4。正多边形「轴数 = 边数 = 重合次数」。
- 第 0 步：滑杆上每个方向，对称轴处没盖住 = 0，其余 > 10%（实测最小 16%）。
- 第 3 步：任意两条对称轴夹角 θ ⇒ 转 2θ 重合（所有图形逐对验证）；风车、平行四边形是「能转不能翻」的反例；翻两次 = 转 2θ（θ = 15..90 及任意角、任意起点）；小旗自身没有镜像对称。
- 第 4 步：份数 = 章数 × n（× 2）；图案实测重合次数 = n、对称轴数 = n（开镜子）或 0（关镜子），n = 2..8。
- 测验：长方形转 90° 不重合；只有平行四边形「无轴但能转」；正六边形最小 60°。
- 双语与结构：同另外两页。
