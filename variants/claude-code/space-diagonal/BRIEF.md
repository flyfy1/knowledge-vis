## 定位

- category `math`，subtopic `geometry`，stage `junior`（与原版一致）。
- 受众：初二前后；学过平面勾股定理 a² + b² = c²，认识长方体。
- 一句话直觉：**空间对角线不是新公式，是勾股定理用两次：先底面，再一个竖着的截面。**
- 与原版的差异（设计选择）：
  - 原版用 Three.js；本版不引外部依赖，在 2D canvas 上自写旋转 + 轻透视（`model.project`），拖动旋转（鼠标可改俯仰；触摸只左右转，保证页面能上下滚动）。
  - 从「28 条顶点连线里哪种最长」这个问题起步（棱 / 面对角线 / 空间对角线，按跨几个方向分类），再推公式。
  - 多了两步：第 4 步「换一个面先算」（三条路线同一个 d，说明为什么顺序无关），第 5 步实际应用「60 cm 细棍放得进 50 × 40 × 30 cm 的箱子吗」（滑杆找到 70.71 cm 的分界）。
  - 第 3 步用一张「d 随 c 变化」的曲线图 + 账本表做参数隔离：改 c 时 e 不变、白点沿同一条曲线走；改 a / b 时整条曲线移动（虚线留下旧曲线）。

## 模型与数据

- `model.js`（浏览器与 node 共用）：`corners`、`segments`（28 条线段按跨方向数分类）、`summary`、`diagonal`（e² 保持为 a² + b² 的精确和，不把四舍五入后的 e 再平方）、`route`（三条路线）、`fits`（L ≤ d）、`QUIZ`、`project`（旋转 + 透视投影）。
- 3D 画幅：第 0、5 步按自身盒子定比例；第 2–4 步比例参考 max(14, d)（d ≤ 14 时盒子变大看得见，再大才整体缩小以免出画）；第 1 步俯角限制在 ≥ 0.8 弧度，比例参考 max(9, √(a² + b² + (0.75c)²))，让底面更大。
- 第 5 步的箱子、棍子数值是举例，不是实测；棍子按无粗细线段处理（s5e、boundary 明说）。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：28 条 = 12 棱 + 12 面对角线 + 4 空间对角线；默认盒子最长棱 12、最长面对角线 √160 ≈ 12.65、空间对角线 13（四条相等）；三种面对角线 5、12.65、12.37；滑杆范围内全部 12³ 个盒子：空间 ≥ 面 ≥ 棱，最长 = √(a² + b² + c²)。
- 第 1–3 步：e² 精确、d² = a² + b² + c²、d = √(e² + c²)；默认 16 + 9 = 25、25 + 144 = 169；改 c 时 e 不变；c → 0 时 d = e；d − c 随 c 增大而减小；立方体 d = a√3；图表纵轴 0..21 覆盖最大 d。
- 第 4 步：全部盒子三条路线 d² 相同；默认盒子先正面 f² = 160、先侧面 f² = 153。
- 第 5 步：√5000 ≈ 70.71；70 放得进、71 放不进（滑杆格点上逐一核对）；60 放得进；小测答案 3。
- 投影：旋转保持长度（正交时）。
- 双语：键集与占位符一致、中英不同（纯符号键除外）；HTML/app 用到的键存在；深链目标页与锚点存在；对照链接、占位注释、provenance 样式存在；未引入 canvas-label-guard，无外部脚本。
