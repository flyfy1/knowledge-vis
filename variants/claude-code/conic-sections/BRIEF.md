## 定位

- category `math`，subtopic `geometry`，stage `senior`（与原版一致）。
- 受众：高中生；会二次函数、勾股定理、基本三角函数（sin）；正在或将要学椭圆、双曲线、抛物线的标准方程。
- 一句话直觉：**圆锥曲线是同一个圆锥被不同倾角的平面切出来的；两个贴住圆锥的球（丹德林球）说明了焦点从哪来，「PF = e · PD」用一个数 e 把四种曲线排成一条线，焦点之所以叫焦点，是因为它能把光汇到一起。**
- 与原版的差异（设计选择）：原版用「平面与轴夹角」分类，再讲 e、两焦点、反射与判别式。本版按「为什么」串起来：第 1 步用丹德林球把「圆锥上切下的椭圆」与「到两焦点距离之和不变」连成同一条曲线（侧视图 + 正视图 + 同比例长度条）；第 2 步给钉子和绳作图并写标准方程；第 3 步用焦点–准线统一 e 并留下各 e 的历史曲线；第 4 步用同速光脉冲演示「路程相等 ⇒ 同时到达焦点」。不讲一般二次方程判别式。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：β = 0..85 每个整数度：类型与「β 比 60° 小/等/大」一致；e = sin β ÷ sin 60°；采样点与绘制点都在圆锥上；由真实形状 a、b 反算的 e 与公式一致；β < 60 一个闭合圈，= 60 一支，> 60 两支且分属上下圆锥；β = 0 圆半径 1.5·tan30°；默认 e = 0.395。
- 第 1 步：β = 0..40、P 每 5°：两球与圆锥、平面相切；球给出的焦点 = 椭圆焦点；PF₁ + PF₂ = 母线段 L = 2a；P 沿母线到接触圆的距离 = PF₁、PF₂（切线等长）；大球在侧视框内。
- 第 2 步：a、c 全部滑杆格点：椭圆存在当且仅当 a > c、双曲线当且仅当 a < c；和/差恒为 2a；点满足标准方程；e = c/a；默认 b = 3.2；c 增大 b 减小。
- 第 3 步：e = 0..2.5（步长 0.05）× 方向每 3°：PF/PD = e；e = 0 半径 1.5；焦点正上方距离 1.5；e < 1 时所有方向在近侧；e > 1 方向 0° 落在准线外侧那支；圆锥切出的椭圆上 c/a = sin β ÷ sin 60°，且 PF/PD = e。
- 第 4 步：3..24 条光线：抛物线反射线过焦点、路程 6.2 = 5.2 + 1；椭圆反射线过 F₂、路程 6 = 2a；入射角 = 反射角；焦点 ±√5。
