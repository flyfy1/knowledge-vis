## 定位

- category `signal`，subtopic `transforms`，stage `university`（与原版一致）。
- 受众：大学低年级；会复数与欧拉公式、知道积分是面积；见过傅里叶变换更好（第 2 步就近解释并深链）。
- 一句话直觉：**s = σ + jω 是一种「带寿命的振荡」；乘上 e^(−σt) 让增长的信号也积得出来，但只在 ROC 里；|X(s)| 是以极点为尖峰的地形，傅里叶是 σ = 0 那一刀。**
- 设计选择：先让读者看清积木 e^(st)（第 0 步），再用最简单的 e^(at)u(t) 在实数 σ 上直观展示积分收敛与否（第 1 步），然后才上整张地形（第 2 步）；ROC 的必要性用「同式两信号」（第 3 步）；极点位置与时域性格（第 4 步）；最后用「到极点的距离之积」几何读频响（第 5 步），把地形与共振连起来。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：Re e^(st) 与 |e^(st)| = e^(σt)；默认半衰期 1.733 s、周期 1.571 s；翻倍时间。
- 第 1 步：全部 a × σ 格点 I(10) 闭式 = 黎曼和；σ > a 时 I(400) → 1/(σ − a)，否则 > 100；σ = a 时 I = T；左右两侧复数 s 的直接积分 = 1/(s − a)（容差 2e−3）。
- 第 2 步：X(s) 闭式；对衰减振荡直接数值积分 = X(s)（ROC 内）；切片在 ROC 内越靠近极点峰越高；α 增大傅里叶切片峰单调下降；H(0) = 1。
- 第 3 步：全部 a × 两种 ROC，∫|x| 有限 ⇔ ROC 含虚轴（截断到 ±40 时与 (1 − e^(−40|a|))/|a| 一致）；小测信号变换核对。
- 第 4 步：稳定性按 σp 符号；2% 时间、周期；e^(σp t)cos(ωp t) 的数值变换 = (s − σp)/((s − σp)² + ωp²)；默认 13.04 s。
- 第 5 步：距离积公式 = |H(jω)|（全部 α × ω 格点）；数值搜索峰位 = √(β² − α²)；α 越小峰越高、半功率宽度越窄；α = 0.3 峰在 1.977；α = 1.5 峰 < 1.05。
- 双语：键集与占位符一致、非符号键中英不同；无「左图/右图」措辞；HTML/app 键都存在；深链目标与锚点存在。
