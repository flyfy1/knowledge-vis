## 定位

- category `probability`，subtopic `inference`，stage `university`（与原版一致）。
- 受众：大学低年级；会百分数、乘除和对数的基本性质；不要求学过条件概率。
- 一句话直觉：**后验 = 只看证据发生的那一组里假设成立的比例；写成赔率就是「先验赔率 × 似然比」，证据只负责乘一个固定倍数。**
- 与原版的差异（设计选择）：原版用医学检测 / 星标卡与抛币 Beta 后验；本版全程用一个垃圾邮件过滤器场景（报警 = 证据），从数人头（1000 封邮件方块图）→ 面积（马赛克图）→ 对数赔率（同长箭头）→ 朴素贝叶斯连乘（打乱顺序终点不变）→ 网格后验估计点击率 → 两种先验与「零先验救不回来」。连续后验用 401 点网格直接相乘归一，而不是共轭公式，让「每个可能值乘一次似然」看得见。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`counts`（1000 封期望人数）、`posterior` / `joint`、赔率工具 `odds` `prob` `lo10`、滑杆档位 `PRIORS` `LRS`、`WORDS`（6 个词的 P(词\|垃圾)、P(词\|正常)）、`chain`（逐条乘 LR）、`shuffled`（mulberry32 确定性洗牌）、`gridPosterior`（401 点网格，先验 × θ^k(1−θ)^(n−k)，梯形归一）、`summary`（均值、等尾 90% 区间，区间夹在先验支撑内）、`track`（n = 0..400 的缓存）。
- 第 4、5 步共用同一串**模拟**数据：400 位访客，真值 θ = 0.3，种子 20261109；400 位中点了 115 位。
- 先验：平坦；偏高 Beta(14, 6)（均值 0.7）；偏低 Beta(2, 10)（均值 1/6）；「认定 θ ≤ 0.2」= 0.2 以下平坦、以上为 0。
- 模型失配（页面 s3e、s5hint、s6 明说）：词的似然是设定的教学数字；真实邮件中词相关，连乘高估证据；过滤器在别的邮箱里未必还是 90%/10%；零先验无法被数据修正；模拟数据与模型一致，现实中模型本身也可能错。

## 数值结论与测试（`tests/core.cjs`）

- `fmt` 只在有小数点时去尾零（90 仍是 90）；百分数格式在 0.1%、99.999% 等处正确。
- 第 0 步：基础率 1–50% 每一档的人数都是精确整数；数人头比例 = 贝叶斯公式；默认 10 / 9 / 990 / 99 / 108 → 8.3%（判断题反馈文案里的数字由测试核对）；10% 时 50%。
- 第 1 步：面积和 = 报警池；马赛克 = 公式 = 赔率形式（全网格）；b 增大后验单调下降；默认 50%。
- 第 2 步：所有先验 × LR 档位，对数赔率位移恰为 log₁₀ LR，且在绘制范围 ±5.4 内；1% → 8%、50% → 90%；LR = 9 时 q − p 最大在 25%（25% → 75%）；LR = 1 不变。
- 第 3 步：6 个词 LR = 15、20、5、3、0.5、0.2；任意顺序终点相同；终点 = 先验赔率 × ∏LR；改变先验 = 阶梯整体平移。
- 第 4 步：平坦先验下网格均值 = (k+1)/(n+2)（全部 n）；Beta(2,1) 的 90% 区间 = [√0.05, √0.95]；密度积分为 1；宽度 × √n 在 n ≥ 25 时为 1.450–1.550；未覆盖真值的 n 只有 21（前 21 位点了 10 位）。
- 第 5 步：偏高/偏低均值差 n = 0 为 0.53、n = 400 为 0.02（与文案一致）；「θ ≤ 0.2」先验下所有 n 的均值与区间上端 ≤ 0.2。
- 双语：键集与占位符一致、非符号键中英不同、无「左图/右图」；HTML/app 用到的键都存在；深链目标页与 `#stepN` 锚点存在；对照链接目标存在；有 provenance 占位、无 label guard。
