## 定位

- category `math`，subtopic `geometry`，stage `university`（与原版一致）。
- 受众：大学低年级或高中毕业；会直角三角形与勾股定理，见过坐标平面与斜率。
- 一句话直觉：**一个点在单位圆上转：横坐标是 cos，高度是 sin，连线斜率是 tan；振幅、频率、相位就是圆的半径、转速、起点。**
- 与原版的差异（设计选择）：先用「弧长 ÷ 半径」把弧度讲成一个长度比，再定义函数；正切用「斜率 = 与 x = 1 的交点高度」讲清无定义与「只是画不下」的区别；最后两步用旋转箭头把 A·sin(ωt + φ) 和 a·cos t + b·sin t = R·sin(t + φ) 连起来，作为傅里叶页的前传。

## 模型与失配

- `model.js`（浏览器与 node 共用）：`cosDeg`/`sinDeg`/`tanDeg`（0°、90°、180°、270° 用精确值，tan 在 90° + k·180° 返回 null）、`exactOf`（特殊角精确形式）、`quadrant`、`reference`、`mirrors`、`arc`、`wave`（周期、首个波峰、零点）、`phasorSum`、`tanSamples`（极点处断开）、`piForm`。
- 浮点：除四分之一圈外都是双精度近似；tan 89.9° ≈ 572.96 是有限数，页面明确区分「画不下」与「无定义」。
- 第 6 步的合成只对同频率成立，终章明说。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：1 弧度 ≈ 57.3°、2π ≈ 6.283、余 0.283；所有 θ、r 格点上 s ÷ r = θ。
- 第 1 步：0°–360° 每度 cos² + sin² = 1、各象限符号、四分之一圈精确；特殊角精确形式；sin 30° = cos 60°。
- 第 2 步：峰、谷、零点位置；cos θ = sin(θ + π/2)；周期 2π。
- 第 3 步：90° + 180°k 无定义；tan 89.9° ≈ 572.96、tan 90.1° ≈ −572.96；(1, tan θ) 在 OP 上；周期 180°；采样曲线不跨极点连接。
- 第 4 步：参考角范围、|sin|、|cos| 只随参考角变、三条镜像关系；150° 例。
- 第 5 步：全部滑杆组合上周期、首个波峰（并与细网格最大值核对）、零点、左移 φ/ω；ω 1→2 波峰 2→4；φ = 90° 得 cos。
- 第 6 步：全部 a、b 格点上恒等式成立、最大值 = R、tan φ = a/b；√2、45°、135° 三个引用值。
