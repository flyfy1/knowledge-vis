## 定位

- category `math`，subtopic `algebra`，stage `junior`（与原版一致）。
- 受众：初一、初二（会解一元一次方程、认识负数和数轴）。
- 一句话直觉：**不等式的答案是数轴上的一段；变形规则和方程一样，只多一条：乘除负数会把数轴绕 0 翻面，所以不等号要翻。**
- 与原版的设计差异：原版用天平。本版用行李箱限重（「不超过」→ ≤）引出解集；用「端点附近放大 10/100/1000 倍」说明空心圆的含义（x < a 没有最大的解）；第 2、3 步统一用「上下两条数轴 + 连线」表示变换，加法连线平行、乘负数连线交叉，次序颠倒看得见；第 4 步把 a·x + b 画成直线、c 画成水平线，把解集和一次函数图像连起来；第 5 步是带运费的整数预算题，专门指出向下取整而不是四舍五入。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：25 个试值中恰好 0–7（15 个）成立；7 成立、7.5 不成立。
- 第 1 步：所有 a × 4 种符号 × 3 种放大倍数：端点是解 ⇔ 带等号；紧挨端点（以及更近 10 倍）的数是解；另一侧的不是。
- 第 2 步：所有 c：仍为 <、间距 3；3 + x ≤ 10 → x ≤ 7。
- 第 3 步：所有 m：m > 0 为 <、m < 0 为 >、m = 0 为 =；差 = 3m，且在记录图范围内。
- 第 4 步：a × b × c × 符号的全部滑杆组合、以及每个检验点：「代入真假」⇔「在解集里」；端点 = (c − b)/a 且为最简分数；a < 0 时翻转；端点开闭随符号；a = 0 的全体 / 无解；默认 2x + 3 < −2 → x < −5/2。
- 第 5 步：M × p × s 全部组合上与暴力枚举的最大 n 一致；无解 ⇔ M < s；花费不超、多一本就超、剩余少于一本的价钱；数轴 0–34 覆盖所有端点；凡四舍五入大于向下取整时都会超支；提示中的例子 (60, 7, 5) 与默认 (60, 6, 8) 的读数。
- 双语：键集与占位符一致、非符号键中英不同；HTML/app 用到的键都存在；深链目标页与锚点存在；对照链接存在；页脚含模型 id；有 provenance 占位与样式；未引入 canvas-label-guard。
