## 定位

- category `physics`，subtopic `electromagnetism`，stage `primary`（与原版一致）。
- 受众：小学中高年级；玩过磁铁、见过指南针；不要求任何公式。
- 一句话直觉：**磁铁周围有一片看不见的「磁场」：它有方向（从 N 极出来、回到 S 极），两端最强；铁屑和指南针都只是顺着它躺下。**
- 与原版的差异（设计选择）：原版从「两端最强」开始；本版先让读者动手分辨「磁铁吸什么」（破除「金属都会被吸」），再用回形针链把吸力量化；两块磁铁加入有摩擦的「松手」实验，让「力随距离迅速变小」变成看得见的结果（近处啪地吸上、远处不动）；铁屑先乱撒、敲卡片后才顺着磁场排好，把「铁屑是被磁场转过来的小磁针」演出来；指南针步加入地球磁场，用足迹和一圈指南针保留历史；终章是「藏起来的磁铁」推理题。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：条形磁铁 6 cm × 1.4 cm，N 端面带 +1、S 端面带 −1 的「磁极量」（每个端面 7 个点），每个点的磁场按距离平方反比（软化半径 0.06 cm）。`pullRaw`（吸力 ∝ \|∇B²\|）、`pairForce`、`release`（有摩擦的一维滑动，数值积分）、`traceLines`（沿磁场方向追线）、`filings`（按磁场强弱取舍的随机点，种子固定）、`compass`、`pieces`、`quiz`。
- 都是相对数值：吸力以两端为 100，两块磁铁之间的力以 1 cm 异极为 100；回形针数、摩擦力、地球磁场强度是示意值，页面「适用范围」段落明说。
- 模型失配：真实磁铁端面附近的磁场比端面磁极模型复杂；铁屑和磁感线是按模型算出来画的，磁感线不是实物。动画（滑动、撒铁屑、敲卡片）共用模型状态，滑动按数值解播放（时间为教学慢放）。

## 数值结论与测试（`tests/core.cjs`）

- 模型：端面磁极量 ±1；远处平方反比；磁铁上方磁场由 N 指向 S。
- 步 0：9 样、6 样金属、3 样被吸、3 样金属没被吸；只试铁和钢时结论为「到目前为止都被吸住」。
- 步 1：两端 100、对称、向两端单调增大；正中 < 1%（页面读数 0.3%）；回形针 0 → 8，按每 12 点 1 枚。
- 步 2：1 cm 异极 = −100；同极与异极大小相同、方向相反；随距离单调减小；距离加倍剩不到三分之一（s6fin）；两块受力等大反向；摩擦 5%；每个滑杆格点：松手时动不动 ⇔ 力是否超过摩擦，异极吸上、同极推远且单向滑动；4 cm 吸上、4.5 cm 不动。
- 步 3：三种画布尺寸下，同极相对时没有线从一块连到另一块，异极相对时 ≥ 3 条；单块时线回到磁铁；线处处沿磁场方向；同极正中磁场为 0；铁屑在磁极附近更密；敲过后每粒铁屑沿磁场。
- 步 4：针沿磁场；方位角换算；打开地球磁场后从 6 cm 往外走针单调转向北；角落偏离北 < 35°；近处磁铁比地球强 3 倍以上。
- 步 5：N = S = 段数；贴紧时外面磁场与整块相同（相对差 < 1e−9）。
- 步 6：60 道题里，靠近 N 端的针尖背对 N 端、靠近 S 端的针尖指向 S 端；每题两端各一只；两种答案都会出现。
- 格式化：整数不去尾零。双语：键集与占位符一致、非符号键中英不同、无「左图/右图」类说法；HTML/app 用到的键都存在；深链目标与锚点存在；对照链接目标存在；未引入 canvas-label-guard。
