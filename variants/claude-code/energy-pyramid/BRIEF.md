## 定位

- category `biology`，subtopic `ecology`，stage `junior`（与原版一致）。
- 受众：初中生；知道植物靠光合作用、动物吃植物或别的动物；会百分数和乘法。不用指数记号以外的数学（第 1 步的「效率^(k−1)」配了文字解释）。
- 一句话直觉：**每往上传一级，能量要过三道关（被吃、被吸收、长成身体），大部分变成热散掉；效率连乘，所以上层很小、顶端需要巨大地盘。**
- 与原版的差异（设计选择）：原版从阳光进入讲起；本版先把「约 10%」拆成三道关相乘（第 0 步），让「为什么只有一成」有因果；地盘一步按真实比例画面积并配足球场作参照；倒立金字塔用「生物量 = 生产量 ÷ 更新次数」做成可拖动的因果，而不是三组固定数据；能量守恒（每 1 kJ 都有去处）在测试中逐格验证。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：所有滑杆格点上能量守恒（四个去处之和 = 1000 kJ）、传递比例 = 三关乘积、不超过 40.5%；默认 500/250/100、热 150、分解者 750；50/50/20 = 5%。
- 第 1 步：10000/1000/100/10；顶级 0.1%（自测答案）；5% 时 1.25 kJ = 1/8；数量级画法下每级都在 0.1 kJ 底线以上。
- 第 2 步：每升一级面积 ×(1/效率)；70/700/7000 m²；每平方公里 1,429；5% 时 ×4；足球场 7140 m²；每天约 1900 kJ。
- 第 3 步：更新次数 > 30 时且仅此时生物量倒立；能量金字塔从不倒立；生物量 × 更新次数 = 生产量。
- 第 4 步：10.5 / 2.8 / 1 人；饲料地占 81%；每天约 10400 kJ ≈ 2500 kcal；坐标轴 0–3.2 公顷容纳所有情形；任何含肉饮食都养活更少人。
