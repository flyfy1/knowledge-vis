## 定位

- category `math`，subtopic `applied`，stage `senior`（与原版一致）。
- 受众：高中生；会解一元二次函数的最值、知道「概率 × 结果」的平均。不要求学过博弈论。
- 一句话直觉：**付款规则决定报价策略**。赢家付自己报价时，报价同时决定「赢不赢」和「付多少」，所以要压价；赢家付别人报价时，报价只决定「赢不赢」，说真话最稳。
- 与原版的差异（设计选择）：原版对手报价设为 0–50 均匀；本版第 0 步先让对手报价「已知」，把收益曲线的跳变看清，再在第 1 步变成 0–100 均匀并用 4000 个模拟对手的点阵把「赢的概率」画成可数的比例。第 2 步把横轴换成对手报价 r，一张图同时看出「从不更好」和「何时更差」。第 3 步加了逐轮标准差对比（第一价格更稳）。第 4 步用可拖动的钟面价格统一英式与荷式。第 5 步用直方图累计赢家利润。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：所有 v、r、b 格点上收益公式；最优整数报价 = r + 1（若 r + 1 < v）否则 0。
- 第 1 步：argmax = v/2、最大值 v²/400；模拟赢率 ≈ b/100（±0.03）；**模拟平均与公式的偏差在全部格点上 < 1 元**（实测 0.693，文案引用）。
- 第 2 步：全部格点上偏离真话的最大多赚 ≤ 0；最大少赚趋近 |b − v|；平均少赚 = (b − v)²/200（与黎曼和对照）；判断题区间 (60, 90)。
- 第 3 步：n = 2..8 时 6 万轮模拟平均 ≈ 100(n−1)/(n+1)（±0.4）、标准差 ≈ 闭式（±0.3）；标准差比 = √((n−1)/(2n)) < 0.71；v(n−1)/n 是对其余人按均衡出价时的最优回应（数值搜索）。
- 第 4 步：50 组估值上英式价 = 第二高估值、荷式价 = 0.8 × 最高估值、赢家都是最高者。
- 第 5 步：4 万场模拟平均利润 ≈ s − σ(n−1)/(n+1)；盈亏线压价；n 增大更糟；默认设置前 500 场亏损比例 > 95%。
