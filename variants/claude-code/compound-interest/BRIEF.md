## 定位

- category `investment`，subtopic `rates`，stage `senior`（与原版一致）。

- 与原版的差异（设计选择）：原版按「单利/复利 → 频率 → 72 法则 → 贴现 → 定投 → 贷款」排列。本版第 0 步把复利余额拆成「本金 / 本金生的利息 / 利息生的利息」三层，让差额有出处；72 法则配对数纵轴（翻倍点等间距）和误差曲线；贴现之后用「三份奖金」比较现值，第一名随贴现率换人；贷款明确是「现值等于借款的年金」，把第 4、5 步连起来。不单列定投。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：三层相加 = 复利余额、青色层 = 单利利息（全部 r、n 格点）；7%·30 年利息生的利息占 68%；5 年时不到 1/5；r 7%→14% 橙层涨 5 倍以上。
- 第 1 步：翻倍点等间距；8% → 72 法则 9 年、精确 9.006 年；低利率误差正、高利率负；±2% 区间 3.7%–12.2% 且为单一区间；小测 16 ≈ ln4/ln1.09 = 16.09。
- 第 2 步：实际年利率随 m 单调上升、不超过 eʳ − 1；8% 时每月→每日只多 0.01–0.1 个百分点；20% 时频率差别是 8% 时的 3 倍以上。
- 第 3 步：验算回到 10000；现值每年降得更少；+1 点降幅随 t 单调增大。
- 第 4 步：面额 10000/15000/25000；年金公式 = 逐项求和；换人顺序 later → stream → now，4.21%、5.56%；r = 0 后者赢、6% 「今天」赢；橙线在整个范围下降最快。
- 第 5 步：还清、还款现值 = 借款、总利息一致、半程余额 > 一半、余额始终在直线之上、本金部分逐月增大、换人月份正确；默认第一年利息过半；10 年期月供更高而总利息不到一半；1% 时离直线不到 5%。
