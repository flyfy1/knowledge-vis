## 定位

- category `earth`，subtopic `geo`，stage `senior`（与原版一致）。
- 受众：高中；知道速度 = 距离 ÷ 时间、密度、向量分解的直觉；tan 只在第 3 步用一次并给出数值。
- 一句话直觉：**板块运动太慢看不见，但每种边界留下各自的证据；从证据可以反推运动方向和速度。**
- 与原版的差异（设计选择）：原版以三种边界为主线、证据卡片收尾；本版把每种证据做成可定量读取的实验：磁条带 → 扩张速率（含判断题）；相对速度分解 → 边界类型；深度–年龄曲线 → 谁俯冲；贝尼奥夫带拟合 → 俯冲角与火山弧距离；粘滑模型 → 复发周期；最后用三份模拟地震记录让读者自己分类。

## 页面上的数值结论（全部由 tests/core.cjs 钉住）

- 0.78 Ma 边界距离 = 7.8u km（u = 2.5 → 19.5 km；u = 5 → 39 km，判断题答案）；条带左右对称、首尾相接、交替。
- 方向 70° 仍是张裂（夹角 20°），75° 起为转换；速度不改变类型。
- 海底越老越深（0–180 百万年严格单调）；两经验式在约 26.3 百万年相交，在 20–70 百万年内相差 < 100 m；同龄（深度差 < 50 m）判为不分胜负。
- 俯冲角 15–75° 的拟合误差 < 1.5°（300 次）；火山弧 30° ≈ 173 km，60° ≈ 58 km，35° ≈ 143 km（站点 3 文字「约 140 km」）。
- 复发周期 = D ÷ 速率（默认 114 年）；任意时刻 已释放 + 亏欠 = 速率 × 时间；随机 ±30% 时长期平均间隔与 D ÷ 速率相差 < 3%。
- 站点：转换 < 20 km、张裂 < 15 km、俯冲最深 > 600 km。
