## 定位

- category `biology`，subtopic `body`，stage `junior`（与原版一致）。
- 受众：初中生；会乘除、百分数、读坐标图；对数纵轴只在第 3 步出现，并就近解释「每往上一格乘 10」。
- 一句话直觉：**一颗心推着血走两圈（体循环送氧、肺循环装氧），单向的瓣膜保证只往前；每分钟泵出约 5 升，正好约一分钟把全身的血过一遍；毛细血管总面积最大所以流得最慢，正好用来交换；用氧多了，靠「送得更多」和「取得更多」一起跟上。**
- 与原版的差异（设计选择）：本版六步。先跟一滴血走完十段路线（可切换「按真实时间比例」，看出约三分之二时间花在静脉），再拆一次心跳的五个阶段与四扇门（可让二尖瓣关不严），再用「累计泵血台阶」把心输出量和全身血量对上，再用连续性 v = Q ÷ 总截面积解释毛细血管为什么慢，最后用菲克原理算送氧够不够。

## 模型与失配

- `model.js`（浏览器与 node 共用）：`SEGMENTS`（十段血量，合计 5000 mL）、`segmentSeconds`、`roundTripSeconds`、`loopSeconds`、`saturationAt`；`PHASES`、`lvVolume`（心房收缩 110 → 120、等容、射血 120 → 50、等容、充盈 50 → 110）、`squeeze`、`forwardStroke`；`pumpedBy`、`fullVolumeBeat`；`STATIONS`（总截面积 3 / 20 / 2500 / 80 / 10 cm²）、`speed`、`capillaryTransit`（1 mm）；`oxygen`（菲克原理，摄氧上限 80%）、`SAT_VEN`（安静时静脉含氧，由第 4 步模型算出，第 0 步颜色共用）。
- 全部是教科书近似值，没有实测数据。第 0 步的动画默认每段等时（否则毛细血管一闪而过），切换后按真实比例（1/10 速度）。
- 失配（boundary 明说）：路线图、心脏结构和颜色都是示意；各段血量、截面积、每升带氧量、80% 上限因人而异；未画冠状动脉、淋巴、血压与心音；不能用来判断健康。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：十段合计 5000 mL；一圈 59.5 s，体循环 50.6 s、肺循环 5.4 s、静脉 38.7 s（约三分之二血量在静脉）；只有毛细血管改变含氧，肺动脉含氧少、肺静脉含氧多；98% / 74%。
- 第 1 步：EDV 120、ESV 50、SV 70；五个阶段首尾相接覆盖一拍；任何时刻两组门不同时开；两组门全关只发生在两个等容期且血量不变；血量只在房室门开时上升、只在动脉门开时下降；一拍 833 ms；5.04 升/分；倒流 30%：21 / 49 mL、3.53 升/分。
- 第 2 步：72 × 70 第 72 拍 59.2 s；一天 7258 升；150 × 100 第 50 拍 19.6 s、15 升/分；滑杆网格上「首次达到 5 升」的那一拍正确；40 × 30 这类低设置超出一分钟时读数附加说明。
- 第 3 步：主动脉 27.8 cm/s、毛细血管 0.033 cm/s、约 833 倍；停留约 3 s / 0.75 s；20 升/分时流速 ×4；毛细血管截面积最大、流速最慢；滑杆全范围流速都在对数轴内。
- 第 4 步：1008 mL、24.8%、73.7%（与第 0 步静脉含氧一致）；2000 mL 不够、至少 12.5 升/分；50%、62.5%；全网格上「够用 ⇔ 摄氧 ≤ 80%」，最少心输出量恰好让摄氧 = 80%；预设都在滑杆网格上。
- 双语：键集与占位符一致、非中性键中英不同；文案数字中英文都出现；不出现「左图/右图」；带标签的字符串只走 `data-i18n-html`；键、控件、深链锚点、对照链接、六个步骤锚点都存在；未引入 `canvas-label-guard.js`。
