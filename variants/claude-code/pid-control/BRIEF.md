## 定位

- category `engineering`，subtopic `control`，stage `senior`（与原版一致）。
- 受众：高中生；会速度、加速度、牛顿第二定律，不要求微积分基础（积分讲成「误差曲线下的面积」，微分讲成「每秒变化多少」）。
- 一句话直觉：**P 看现在差多少，D 看变化有多快，I 看过去欠了多少；每一项都解决一个看得见的问题，也带来一个看得见的代价。**
- 与原版的差异：原版用抽象的二阶质量-弹簧对象，按 P、I、D 顺序；本版用一架有重力、推力上限（0–30 N，不能向下拉）的无人机。重力是天然的恒定负载，所以 P 的下沉 m·g/Kp 有直观来由；顺序为 P → D（先压晃动）→ I（再消下沉）→ 推力上限与积分饱和 → 带噪声的四指标调参实验。第 0 步先用「开环回放 vs 闭环」说明为什么要反馈。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`simulate`（m·z'' = u − m·g − c·z'，m = 1、c = 1、g = 9.8，推力夹在 [0, 30] N，地面 z ≥ 0，半隐式欧拉 dt = 0.01 s，10 s）、`metrics`、`thrustJitter`、`crossings`、`meetsSpec`、种子噪声 `gaussian`。
- 控制器：e = r − y_meas；P = Kp·e；I = Ki·Σe·dt（可选钳制）；D = −Kd·(y_meas 变化率)；u = clamp(P + I + D)。
- 全部曲线与读数来自模拟；第 0 步的开环推力就是 1 kg 闭环飞行录下的推力。
- 模型失配（页面 boundary 明说）：只有竖直运动；无电机延迟、姿态耦合、阵风、电池电压变化；真实 D 项通常先滤波。

## 数值结论与测试（`tests/core.cjs`）

- 模拟器：推力范围、地面、P + I + D = u（未饱和时）、D 在 t = 0 无尖峰、积分 = Σe·dt、种子噪声可复现、σ = 5 mm。
- 第 0 步：m = 1 回放精确重现；录下的悬停推力 ≈ 9.8 N；m ≥ 1.1 落地、m ≤ 0.9 飞出图顶；闭环全部回到 5 ± 0.05 m。
- 第 1 步：所有 Kp 下下沉与 m·g/Kp 相差 < 0.05 m；Kp = 5 下沉约 2 m、无超调；Kp 5/10/20/40 峰值与穿越递增。
- 第 2 步：下沉恒为 0.49 m；超调随 Kd 不增、Kd ≥ 6 为 0；推力抖动随 Kd 递增；噪声几乎不改高度峰值。
- 第 3 步：Ki = 0 停在 4.51 m；Ki = 2/5 时 10 s 的 I 项范围；判断题（P、D ≈ 0，总推力 ≈ 9.8 N）；超调随 Ki 递增。
- 第 4 步：r ≤ 2 不饱和、两线重合；r = 4/6/8/9 普通积分器超调与饱和时间递增、积分更高、超调 > 钳制的 2 倍、钳制超调 < 6.5%、钳制更早稳定。
- 第 5 步：三个预设各自失败的条目；示例 (10, 4, 3.5) 全过；可行组合 > 10 个；文案中的指标与 `SPEC` 一致。
