## 模型与失配

- `model.js`（`MOD_MODEL`）提供以下函数：
  - 基础：`fft`（基 2）、`amplitude`、`bandKeep`（理想频段掩码）、`analytic`（解析信号）、`lines`；
  - 各步：`multiply`、`share`、`coherent`、`am`、`fm`、`besselJ`（积分式，仅供测试）、`gauss`（mulberry32 + Box–Muller）、`noisy`。
- 滤波器和包络检波器都是理想化的。页面在收束里明说：真实电路的滤波器有过渡带，检波器有纹波。
- 第 5 步的噪声是模拟的，固定 3 组种子，数字会随种子小幅波动。AM 在 μ = 1 时实际发送功率略大于 FM（0.63 对 0.5），这一点对 AM 有利，页面也写明了。
- 画图时，快载波用解析式在细网格上画。102.4 kHz 的样本在 40 kHz 载波下每周期只有 2.56 点，直接连线会出现假的锯齿。

## 数值结论与测试（`tests/core.cjs`，1703 项）

- FFT 设置：单音振幅精确，无泄漏。消息峰值 |m| = 1。
- 第 0 步：在 5–40 kHz 的全部格点上，谱线都在 f_c ± 0.5/1.5 kHz，高度 0.3/0.2，f_c 处没有谱线。
- 第 1 步：滑杆格点上，串扰为 0 ⇔ 间隔 ≥ 3 kHz；2.5 kHz 时为 −13.6 dB；波形不超出坐标轴。
- 第 2 步：Δf × φ 全部格点上，输出与 m·cos(2πΔf·t + φ) 的 RMS 差 < 1e−9；Δf = 0 时比例 = cos φ，Δf > 0 时比例为 0；12.5 Hz 是 20 kHz 的 0.0625%。
- 第 3 步：失真为 0 ⇔ μ ≤ 1；6.7% / 34%；效率随 μ 单调增，μ = 1 时 20.6%；包络最低点 = 1 − μ；载波谱线 = 1。
- 第 4 步（f_m × Δf 共 451 个格点）：
  - 功率恒为 0.5；
  - 谱线在 5–45 kHz 内，间隔 f_m；
  - β ≤ 0.2 时 98% 带宽为 0，β > 0.2 时与卡森带宽相差不超过一对谱线；
  - 4 个 β 下前 7 根谱线等于 \|J_k(β)\|（1e−6）；
  - β = 2.4 时载波谱线为 0.0025。
- 第 5 步（3 组种子 × 14 个输入值）：
  - 输入 ≥ 6 dB 时 FM 领先 15.9–18.7 dB（文案写 16–19）；
  - 输入 ≤ −2 dB 时 FM 落后；
  - 无噪声时 FM 约 51 dB；
  - 发送功率 0.63 / 0.5，带宽比 6。
- 双语一致性：两种语言的键集和占位符一致；中英文本不同（中性键只有 3 个：`nav4`、`s3lgIdeal`、空的 `s2nobeat`）。
