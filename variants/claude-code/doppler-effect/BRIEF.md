## 定位

- category `physics`，stage `senior`（与原版一致）。受众：高中生；已知波速 = 波长 × 频率、周期 = 1/频率。
- 一句话直觉：**听到的频率 = 每秒到达耳朵的波峰数。声源动，改变空气里波峰的间距；听者动，改变与波峰相遇的快慢。**
- 与原版的差异（设计选择）：原版用教学单位 c = 1 和角度公式贯穿；本版用真实声速 340 m/s、440 Hz 喇叭，每一步都在画面下方给「到达时刻刻度条」，听到的频率是**数出来的**（实测到达间隔），再和公式对账。增加了「声源动 vs 听者动」的不对称（第 2 步）和「回声测速」（第 4 步，两段多普勒相乘、拍频与近似误差），超音速只作为最后的几何延伸。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`heard`（一般式）、`rings`、`arrivalAt`/`arrivals`（逐个波峰的到达时刻）、`arrivalsMovingListener`、`laneCrests`、`emissionTime`（二分法求发声时刻）、`passBy` 与 `passByNumeric`（波峰到达率的有限差分，独立核对）、`reflect`、`speedFromBeat`、`echoLane`、`echoArrivals`、`machAngle`、`aheadSpacing`。
- 声音在静止空气中、c = 340 m/s；点声源、点听者；无衰减、无风、无相对论修正。第 4 步条带用真实速度比（u/c ≤ 0.12），只把时间放慢；第 5 步只画几何，激波物理不在模型内（正文写明）。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部 f 下到达间隔 = T、实测频率 = f；圆间距 = λ；慢放倍数 300。
- 第 1 步：全部 v 下 A/B 到达间隔 = (c∓v)T/c，实测频率 = f·c/(c∓v)；画面前后间距；200 m/s ≈ 0.6c。
- 第 2 步：全部 s 下两条道的实测频率 = 各自公式；s ≠ 0 时声源动的一条总更高；下道间距 = λ；小 s 曲线重合、大 s 分开；思考题 555.6 / 550 Hz。
- 第 3 步：v × d × t 全网格：发声时刻满足 te + r/c = tr；公式 = 有限差分到达率；f′ 在两端极限之间、只降不升；t = d/c 时正好 440 Hz；t = 0 时仍高于 440 Hz；d 越大滑落越缓。
- 第 4 步：回声 = 两段多普勒相乘；由 Δf 反推 u；近似偏小、相对误差 = u/c；回声到达间隔与条带间距；雷达 30 m/s → 4830 Hz。
- 第 5 步：M ≤ 1 无锥、前方间距 (1−M)λ；sin α = 1/M 且锥线与每个圆相切；M = 1.5 → 41.8°。
- 双语键集与占位符一致；HTML/app 引用的键都存在；深链目标页与锚点存在。
