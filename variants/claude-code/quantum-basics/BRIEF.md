## 定位

- category `physics`，subtopic `modern`，stage `university`（与原版一致）。
- 受众：大学低年级；会平方、三角函数，知道复数的模与辐角更好（第 2 步就近复述，并链到复数页）。
- 一句话直觉：**量子比特带着两个振幅；测量给出一个结果，概率是振幅的模平方。振幅能相加也能抵消（干涉），一旦路径可知就只剩概率相加；测量本身会改变状态。**
- 与原版的差异（设计选择）：本版从实数振幅（单位圆）起步，再引入相对相位；用马赫–曾德尔干涉仪而不是双缝讲干涉与路径标记；用布洛赫球把「概率 = 在测量轴上的投影」画出来；最后用 Z → χ → Z 三次测量链展示测量扰动。

## 模型、设定与失配

- `model.js`（浏览器与 node 共用）：复数工具、`realState`、`bloch`、`hadamard`、`pAlong`、`mz`（马赫–曾德尔，含路径标记）、`rng`（mulberry32，固定种子）、`shots`、`pFinalZero`、`chain`（三次测量链模拟）。
- 全部为理想模型：单个量子比特、纯态、理想投影测量、无噪声无退相干、无损耗分束镜。
- 模拟计数来自固定种子的伪随机数，只用来演示抽样涨落；页面在第 1 步与终章明说不是实验数据。
- 整体相位（两个振幅同乘 e^(iγ)）不影响任何测量，布洛赫球不画它，终章写明。多比特与纠缠不在本页范围。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部 ψ 上 P(0) + P(1) = 1、P(0) = |α|²；45° 与 135° 概率相同、α 符号相反；默认 ψ = 30° 得 P(0) = 0.75（第 1 步标题引用）；选择题 0.6² + (−0.8)² = 1、答案 0.64。
- 第 1 步：多组 p × N × 2000 个种子下 ±2σ 带覆盖率在 90%–99.5%（约 95%）；5000 次长跑频率在 0.75 ± 0.025 内；生成器均值 ≈ ½。
- 第 2 步：全部 θ × φ 格点上归一、Z 概率与 φ 无关、|β| 不随相位变、H 门后 P = (1 + x)/2 = |α + β|²/2、Y 基 P = |α − iβ|²/2、布洛赫向量在单位球面；θ = 90° 时 φ = 0 / 180 给 P(+) = 1 / 0；θ 越小 X 起伏越小。
- 第 3 步：全部 φ 上 P(D0) = cos²(φ/2)、D0 + D1 = 1、与 H·相移·H 逐门计算一致、每臂振幅 1/√2；标记路径恒为 ½；每批 100 光子 ≥ 99% 落在 3σ 内。
- 第 4 步：pAlong(0) = Z、pAlong(90°) = X；赤道上 Z 条 = 0.5。
- 第 5 步：(1 + cos²χ)/2 与两分支相加一致；不测时恒为 1；40000 次模拟与理论差 < 0.01；χ → 90° 单调扰动增大、过 90° 后减小。
