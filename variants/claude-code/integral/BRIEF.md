## 定位

- category `math`，subtopic `calculus`，stage `senior`（与原版一致）。受众：高中生；会面积公式、v-t 图面积 = 路程、导数的割线—切线直觉。
- 一句话直觉：**曲边面积没有公式，就切细：下估计和上估计从两侧把真值夹住，切到无限细时两边贴到的数就是定积分；它是「高 × 宽」的带符号累加；累加函数的增长速度就是被积函数，所以求积分 = 找原函数。**
- 与原版的设计差异：从「数格子」开场（完全在下方的格子 vs 碰到区域的格子），先建立「夹住」的思路，再换成长条；路程例子用刹车（速度递减，左和反而偏大），顺带说明「左小右大」只对递增函数成立；单设「带符号」一步（y = x² − 1，b = √3 时正负抵消）；第 4 步用「多加一条宽 dx 的窄条，增加量 ÷ dx → x²」把累加函数接到导数。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：每个格子逐一按几何条件核对内格/触格计数；1/3 始终在上下界之间；夹缝逐档变窄；N = 40 时 0.3125–0.36125。
- 第 1 步：三种和 = 闭式（1e−12）；L < 1/3 < R；R − L = 1/n；n 翻倍夹缝恰好减半；中点和比左右和都近；n = 4 时 0.21875 / 0.46875（自测 ②）、中点和误差 < 0.006。
- 第 2 步：真值 24 = ½·4·12；左和 = 24 + 24/n；每段 = 速度 × 时间；n = 1 为 48、n = 32 为 24.75；路程轴容得下。
- 第 3 步：正部/负部/净值 = 数值积分（全部格点 + √3）；b ≤ 1 只有负部；√3 前为负、后为正、在 √3 处为 0；b = 1 为 −2/3；√3 不在滑杆格点上（故设按钮）。
- 第 4 步：描线 ≈ x³/3（2e−6）；ΔA/dx − x² = x·dx + dx²/3，恒为正并随 dx 减小；A′(1) = 1；A(1) − A(0) = 1/3；全部点在画布范围内。
- 第 5 步：① = 2、④ = 7/3（原函数与数值两种算法），8/3 是干扰项（0 → 2）。
