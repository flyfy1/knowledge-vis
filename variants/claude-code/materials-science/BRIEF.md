## 定位

- category `physics`，subtopic `matter`，stage `university`（与原版一致）。
- 受众：大学低年级理工科；会求导、知道积分是面积；不要求学过材料力学。
- 一句话直觉：**一次拉伸试验的记录，除掉尺寸以后就是材料的「履历」：斜率、拐点、最高点、面积各对应一个设计用的数。**
- 与原版的差异（设计选择）：原版比较三种材料的曲线与取舍；本版围绕「一次拉伸试验」展开，先讲为什么要除以尺寸（含 Barba 定律：颈缩后的伸长率依赖试样几何），再用卸载路径定义永久应变和 Rp0.2，用 Considère 判据解释抗拉强度为何是最高点，用面积讲韧性，然后做一个多约束选材题，最后用断裂力学（K_IC）讲裂纹如何把「先屈服」变成「先断裂」。材料换成低碳钢、6061-T6 铝合金、退火铜、氧化铝陶瓷（引入一个脆性对照，避开聚合物的黏弹性）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：Ludwik 硬化 σt = σp + K·εpⁿ（真应力–真塑性应变），体积不变换算工程量；`necking` 用 Considère 判据二分求颈缩点；颈缩后是从 UTS（零斜率）到 drop·UTS 的二次经验下降；断后伸长率按 Barba 关系 e_f = e_u + (A_std − e_u)·5.65·√A₀/L₀；`rp02` 求 0.2% 平移线交点；`energyTo` 用 Simpson 积分；`design` 求三约束最小截面；`fractureStress`、`transitionCrack`、`failure` 用于第 5 步。
- 材料参数（E、σp、K、n、断后伸长率、密度、KIC）是教科书量级的示意值：K、n 由本作者拟合到典型 UTS 与均匀伸长率，不是标准数据。页面 s6 boundary 明说不能当设计数据。
- 模型失配（页面明说）：颈缩后段为经验曲线；未建模屈服平台、应变率、温度、疲劳、蠕变、各向异性；第 4 步吸能是乐观上限；第 5 步 KIC 只是量级，LEFM 在 a* 附近只是近似。

## 数值结论与测试（`tests/core.cjs`）

- Considère 交点 = 工程曲线最大值（10⁻⁵ 应变网格扫描）；σt = σ(1+ε)；颈缩点连续；标准试样伸长率 = A_std；铝 / 铜颈缩应变约 8% / 38%（与 s2hint 一致）。
- 第 0 步：所有尺寸在颈缩前 σ–ε 完全重合、颈缩后不同；F ∝ A₀；Barba 趋势；标准按钮对每个 d 都落在滑杆网格上，默认试样即标准试样。
- 第 1 步：弹性极限以下永久应变为 0，以上为正且单调；Rp0.2 在平移线上，且卸载模型给出 ≈0.2% 永久应变；铜比例极限最低、铝 E 最小。
- 第 3 步：韧性 115 / 41 / 99 / 0.09 MJ/m³（Simpson vs 梯形法）；ε ≥ 5% 后可回收部分 < 6%；陶瓷韧性 = 弹性能；陶瓷 260 MPa 接近铝 Rp0.2。
- 第 4 步：s4hint 每条论断在 F 全范围内成立；滑杆范围内至少出现三个不同的胜者；铝密度约钢的 1/3；陶瓷每焦耳约 11 mm²。
- 第 5 步：a* 数值、两线在 a* 相交、斜率 −1/2、失效方式在 a* 切换。
- 双语：键集与占位符一致、中英不同；纯文本键不含 HTML；HTML/app 用到的键都存在；深链目标与锚点存在；对照链接、占位注释、provenance CSS 存在，未引入 canvas-label-guard。
