## 定位

- category `physics`，subtopic `electromagnetism`，stage `senior`（与原版一致）。
- 受众：高中；会受力分析、动能、做功、向心力 mv²/r。
- 一句话直觉：**洛伦兹力始终垂直于速度 ⇒ 不做功、只拐弯 ⇒ 匀速圆周，r = mv/(qB)，T = 2πm/(qB) 与速度无关**；质谱仪用 r，回旋加速器用 T。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`lorentz`、`orbitAt`（匀强 B 中的解析轨道）、`eFieldAt`、`rk4`（独立数值积分并累计功）、`measurePeriod`/`measureRadius`、`spectro`/`massFromX`（SI、CODATA）、`cyclotron`（逐次过缝记账，每次增益 qU·cos(πkδ)）、`cycloPath`、`tolerance`（二分求引出边界）、`gamma`。
- 第 0–3 步教学单位；第 4–5 步 SI。全部是计算，不含随机数据。
- 模型失配（页面 s6 明说）：单粒子、匀强场、v ⊥ B（有平行分量时走螺旋线）；不计重力、辐射；回旋加速器按非相对论计算，只给出相对论修正的大小；忽略穿缝时间、边缘场、聚焦。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：所有角度、电荷、B 方向下 F = qv×B、F ⟂ v、\|F\| = 1、转向（顺/逆时针）正确；左手定则示例。
- 第 1 步：RK4 = 解析轨道；磁场功 < 5e−4（显示 0.000）；电场功 = 动能变化；坐标轴容纳路径与动能。
- 第 2 步：所有滑杆格点测得半径 = mv/(qB)（< 1e−3）；v×2、B×2、m×2 的比例。
- 第 3 步：所有 B、m、v 组合测得周期 = 2πm/(qB)（1e−6）；一周期回到原点；三箭头平行；两圈装得下滑杆范围。
- 第 4 步：x = (2/B)√(2mU/e)、eU = ½mv²、由落点反推质量；相对间距 ≈ 4.9% 且与 U、B 无关；x ∝ √U、∝ 1/B；图内比例。
- 第 5 步：E_max ≈ 11.97 MeV、f_c ≈ 15.25 MHz、240 次过缝；允许偏差 ≈ 0.13%、γ − 1 ≈ 1.3%（近 10 倍）；δ = 0.5% 失步；U×2 → 120 次；E_max ∝ B²；轨迹拼接与边界；氘核不能引出、最高 = eU；周期约 2 倍。
- 双语：键集与占位符一致、非符号键中英不同；HTML/app 用到的键存在；深链与锚点存在；对照链接存在；文案不用「左图/右图」称呼图。
