## 定位

- category `probability`，subtopic `statistics`，stage `senior`（与原版一致）。
- 受众：高中生；会算平均数、方差与标准差，会写一次函数 y = a + bx；不要求学过导数。
- 一句话直觉：**r 是「标准分乘积」的平均；最小二乘线过中心点、斜率 r·s_y/s_x；这两个东西只看直线、会被远点撬动、不代表因果，并且 |r| < 1 必然带来回归到平均。**
- 与原版的差异（设计选择）：
  - r 用「每个点与中心围成的带符号矩形」直接算出来（同向绿、反向红），并演示换单位 r 不变；
  - 最小二乘把直线拆成「绕中心点转动 + 上下平移」两个滑杆，SSE = SSE(b, 0) + n·d² 让「必过中心点」可见；
  - 预测一步给出 RMSE 带、R² = r²、外推警告和「标准分下斜率 = r」；
  - 「r 只看直线」用残差图诊断；
  - 离群点改为逐点删除的影响力图（区分杠杆与影响力）；
  - 因果陷阱换成「脚长 vs 阅读分，混杂变量是年龄」；
  - 回归到平均换成两次考试（测–再测），ρ 可调。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`fit`（均值、标准差（除以 n）、r、b、a、SSE、SST、R²、RMSE）、`rFromProducts`（矩形法）、`sseLine`、各步数据生成（mulberry32 + Box–Muller，固定种子）。
- 所有数据都是模拟：小卖部 30 天（同一组气温与噪声，三种商品只换趋势和波动大小）；三种形状各 40 点；16 名学生；210 名小学生；500 名学生两次考试。
- 模型失配（s7 boundary 明说）：除以 n 与 n − 1 不影响 r 与回归线；用 y 预测 x 是另一条线；混杂与成绩模型是构造的；30 个点时 r 本身有抽样波动。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：三种商品 × 9 档波动：矩形平均 = r，(pos + neg)/n = r，r ∈ [−1, 1]，°F 下 r 不变；冰饮 / 热汤无波动时 r = ±1，|r| 随波动单调下降；文具任何波动下 r = −0.21（文案引用），无波动时 r 无定义。
- 第 1 步：r ≈ 0.75；b = r·s_y/s_x、a = ȳ − b·x̄；斜率 × 平移全网格上 SSE(b, d) = SSE(b, 0) + 30·d²，且不低于最小 SSE；「跳到最优」按钮落在滑杆范围内。
- 第 2 步：带内恰 17 天（文案引用）；R² = r²；RMSE = s_y√(1 − r²)；数据范围在 18–33 °C 内（外推提示）；标准分下斜率 = r、截距 0。
- 第 3 步：直线组 r > 0.9 且五段残差均值都小于 0.2·RMSE；U 形 r ≈ 0.01、残差 +−+；饱和 r ≈ 0.77、残差 −+−。
- 第 4 步：远点 50 分时，前 15 点影响均 < 0.2，去掉远点斜率 −0.11 → 3.26；其余 15 人在 20 小时的预测 ≈ 119；远点落在该预测上时影响为 0，向上、向下逐分偏离时影响严格增大。
- 第 5 步：210 人、每龄 30 人；全体 r ≈ 0.84；组内 r 范围 −0.28…0.43、平均 0.06（文案引用）；点都在坐标范围内。
- 第 6 步：ρ 全格点上 r ≈ ρ（±0.06）、斜率 = r·s_y/s_x、全体平均变化 < 1.5 分；ρ < 1 时前 10% 回落、后 10% 上升、斜率 < 1；ρ = 1 时两次成绩完全相同；ρ = 0.5 时约 86 → 78。
- 数字格式化：只在有小数点时去尾零。
- 双语：键集与占位符一致、非符号键中英不同、无「左图 / 右图」；HTML/app 用到的键都存在；深链与 `#stepN` 锚点存在；对照链接目标存在；stage 为 senior；页头占位注释与 provenance 样式存在，未引入 canvas-label-guard。
