## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`FUNCS`（x² − 2、cos x − x、eˣ − 3，根用闭式或二分独立求得）、`step`、`iterate`、`digits`、`newtonSqrt`、`bisectSqrt`、`multi(k)`、`errors`、`FAIL` 与 `classify`、`BASIN` 与 `basin`。
- 没有随机数据；所有数值是双精度确定性计算。
- 失配（终章明说）：只有一元光滑实函数；分类与上色按有限步数；色带分辨率等于屏幕像素；实际求根器常把二分与牛顿结合。

## 数值结论与测试（`tests/core.cjs`）

- 根：√2、ln 3、cos r = r、x³ − 2x + 2 的根 ≈ −1.7693、f′ = 0 于 ±0.8165。
- 第 0 步：全部 x₀ 格点上 x₁ = (x₀ + 2/x₀)/2、e₁ = e₀²/(2x₀) 精确成立、x₁ ≥ √2；一步变差当且仅当 x₀ < √2/3；误差 0.1 → 约 0.003。
- 第 1 步：x² − 2 从 3 出发的位数序列 0.5、1.5、3.3、6.8、13.9；三个函数默认起点 8 步内 ≥ 15 位；全部起点格点 8 步都存在。
- 第 2 步：a = 2…100 牛顿到 10 位 4–7 步、二分 27–35 步（a = 4、16、64 巧合除外并单独核对）；a = 2 时 4 vs 29；近根处 e₁/e₀² ≈ 1/(2√a)。
- 第 3 步：x₀ 全部格点上 k = 2、3 的比值 → (k − 1)/k（±0.01）；k = 1 时 e₁/e₀² → 0.5；k = 3 精度停在 1e−8～1e−7、k = 2 到舍入级。
- 第 4 步：五个预设的分类、步数与 −54407；x₀ 全部格点都能分类，范围内同时有到根与循环。
- 第 5 步：[0, 1/√5) → 0、(1/√3, 2] → 1 及对称负侧；(1/√5, 1/√3) 内粉青交替；0.447 处 ×10/×100/×1000 窗口在 250/330/900 像素宽下都出现三色且多次切换；±1/√5 是 2 周期。
