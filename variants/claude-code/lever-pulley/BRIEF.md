## 定位

- category `physics`，stage `junior`（与原版一致）。受众：初中生；已知力（N）、质量（kg）、重力 = 质量 × g、长度。
- 一句话直觉：**力可以被杠杆和滑轮放大，但要用距离来还：转动看力矩（力 × 力臂），搬运看功（力 × 距离），理想机械里功的两本账永远相等。**
- 与原版的差异（设计选择）：全页围绕「两本账」组织——第 0–1 步记力矩账，第 2–4 步记功的账；第 2 步与第 4 步用同一种「W入 / W出」账本条，让杠杆和滑轮组的代价用同一张图对比。滑轮组用一个重物（600 N）贯穿 n = 2/3/4，绕法图按段数真实重绘、承重段逐段编号。

## 模型与数值口径

- `model.js`（浏览器与 node 共用）：`seesaw`、`balanceSeat`、`crowbar`、`ledger`（转角下 s = L动·sinθ、h = L阻·sinθ，精确几何，不用小角近似）、`fixedPulley`、`pulleyBlock`、`winding`（奇数段绳头系在下框，偶数段系在上梁，自由端总从定滑轮垂下）、`QUIZ`。
- 全页 g = 10 N/kg；理想机械（不计摩擦，杠杆、绳、滑轮无重量）。跷跷板倾斜角是示意量（14°·tanh(ΔM/200)），力矩是实算量；撬棍、滑轮的位移是实算量。
- 数字格式：整数结果显示整数，非整数一位小数加「≈」；去尾零只在有小数点时去。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部 9×9 座位组合下力矩 = 600·dL、300·dR；平衡当且仅当 dR = 2dL；倾斜方向 = 力矩大的一边；力矩条不超出 0–1200 轴；1.0/2.0 m 平衡、外挪一格向挪的人倾。
- 第 1 步：全部支点位置 F·L动 = G·L阻、F 单调增且 > 0；0.1 m 约 57 N；0.3 m → 200 N；0.5 m → 400 N。
- 第 2 步：三档力臂比 × 201 帧 W入 = W出、s/h = 力臂比；4:1 → 200 N / 0.2 m，2:1 → 400 N / 0.1 m，3:1 ≈ 266.7 N；终态 40 J。
- 第 3 步：F = 200 N、h = s、功相等。
- 第 4 步：n = 2/3/4 × 全部拉绳长度：F = G/n、h = s/n、绳长守恒、绕法上下交替且画出的承重段数 = n；正文引用的 300/150 N、1/0.5 m 被钉住。
