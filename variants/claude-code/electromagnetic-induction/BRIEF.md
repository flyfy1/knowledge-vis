## 定位

- category `physics`，subtopic `electromagnetism`，stage `senior`（与原版一致）。
- 受众：高中；知道磁感线、电流、电阻，会读函数图像。
- 一句话直觉：**磁通量 Φ = B·S·cosθ 一变就有电动势 ε = −N·ΔΦ/Δt；快慢决定大小，「电压 × 时间」只看变了多少；方向阻碍变化。**
- 与原版的差异（设计选择）：原版用磁铁沿轴运动贯穿多步；本版先把 Φ 的三个因子（B、S、θ）拆开讲，再用「B 线性升降」的矩形 ε 讲法拉第定律（并强调 ∫ε dt 与 τ 无关），楞次定律用磁铁穿线圈并显示线圈等效磁极与对磁铁的力，另加一步导轨上的导体棒（ε = BLv、安培力、动能变焦耳热），最后是转动线圈发电机。全部 SI 单位。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`flux`、`slice`（侧视图的磁感线计数）、`Bramp`/`emfRamp`/`emfArea`、`dipoleFlux`/`dFluxDz`/`magnetEmf`/`lenz`（点磁偶极子，m = 1 A·m²，线圈半径 2 cm、100 匝）、`rod`（解析解）与 `rodNumeric`（数值积分对照）、`generator` 与 `rmsNumeric`。
- 全部是确定性计算，没有随机数据；第 2 步动画是慢放（4 s 走完真实 0.16 s 的路程，在 s2e 写明）；第 1、3 步动画按真实时间。
- 模型失配（页面 s5 写明）：忽略线圈自感；磁铁看作点磁偶极子，且按给定速度运动（不计楞次力造成的减速）；导轨无摩擦、棒和导轨无电阻。第 2 步侧视图中线圈半径受面板高度限制，未与磁铁同比例。

- 第 0 步：全部滑杆格点上 Φ = BS cosθ、90° 为 0、180° 为负、a ×2 → ×4、坐标轴容纳；投影宽 a·|cosθ|；线数计数与画法一致、随 θ→90° 单调减少；默认 6.00 mWb、4 条；6 → 12 cm 阴影带宽度翻倍。
