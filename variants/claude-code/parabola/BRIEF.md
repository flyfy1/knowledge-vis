## 定位

- category `math`，subtopic `algebra`，stage `junior`（与原版一致）。受众：初中生；已会一次函数（斜率、截距）、坐标系、平方。
- 一句话直觉：**直线每步抬高一样多；抛物线每步的抬高量本身按固定的量变化。y = a(x − h)² + k 把开口方向与胖瘦（a）、顶点 (h, k)、对称轴 x = h 写在脸上，与 x 轴的交点就是 y = 0 的地方。**
- 与原版的设计差异：从「抬高量的变化是恒定的」（二阶差分）切入，与一次函数页「抬高量恒定」直接对照；第 1 步用台阶 a、3a、5a 把 a 的含义落到数上；第 3 步用「交点个数 vs k」的台阶图让 2/1/0 的跳变可见；第 4 步把投篮写成顶点式并指出式子的负根在出手点身后（模型适用范围）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：投篮 `shotAt`/`shotDots`/`rises`/`peak`/`shotVertexForm`/`judgeShot`，代数 `f`/`crossings`/`equation`/`stepRises`，格式化 `num`/`exactAt`。
- 投篮为**模拟**：g = 9.8 m/s²，不计空气阻力与旋转；第 0、4 步共用同一模型，第 4 步默认值即第 0 步那一投。
- 失配（s6 boundary 明说）：真实球受空气影响；式子在出手前、落地后也有值，但不描述球。一般式与配方、判别式不展开。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：17 个点；首格抬高 0.651 m；每格少 g·Δt² = 0.098 m；第 8 格转负；顶点 t = 5/7 ≈ 0.71 s、2.86 m、4.5 m，落在两个点之间；关于顶点对称。
- 顶点式 = 时间式（全部滑杆格点）；a = −4.9 ÷ vx²。
- 第 1 步：抬高 a、3a、5a，每格多 2a，和 = 9a；a = 0 → y = 0。
- 方程书写：抽样集逐字断言（无双符号、用 Unicode 减号）；第 ① 题选项 A 就是所画的图。
- 第 2 步：顶点、对称点对等高 = 4a + k、最高/最低（全部格点）。
- 第 3 步：交点个数规则（全部格点），交点是根且关于 x = h 对称，一个交点 ⇔ k = 0，三种情形均可达；≈ 只用于非两位小数。
- 第 4 步：篮筐 x ≈ 5.03 m，默认投篮进球；每组速度两根、负根在身后、正根 = vx × 落地时间、整条轨迹在图内；进球组合 > 1（30 组），偏高、偏短都可达；vy 增大 → 顶点右上移、落点变远；vx 增大 → |a| 变小。
- 第 5 步：③ 的交点为 −1、3；② 的目标在滑杆格点上。
