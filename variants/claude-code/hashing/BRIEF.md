## 定位

- category `computing`，subtopic `algorithms`，stage `university`（与原版一致）。
- 受众：大学低年级，知道二进制、十六进制、取余；不要求学过概率论（生日问题从配对数讲起）。
- 一句话直觉：**指纹有用因为它短，会撞车也因为它短**；撞车数由「配对数」决定，所以比直觉早，指纹长度要按对象数的平方定。
- 与原版的差异（设计选择）：
  - 原版用 FNV-1a 演示雪崩；本版把 FNV-1a 与「FNV-1a + MurmurHash3 fmix32 末尾混合」并排，用可证明的事实说明 FNV-1a 低位雪崩差（第 k 低位最多 (k+1)/8 翻转，最低位恰好 1/8），再看混合后如何接近 0.5。
  - 哈希表步加入反面对照「字节相加」，用实测说明差的哈希在桶多时才暴露（只有 47 种取值）。
  - 生日步用真实哈希做实验，与理论 CDF 对比，而不是只画公式。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`utf8`、`fnv1a`（含逐字节轨迹）、`fmix32`、`mixed`、`avalanche`、`table`（拉链法）、`poissonBins`/`expectEmpty`/`expectProbes`、`pCollide`/`k50`、`firstCollision`（真实哈希实验）、`pAny`/`bitsNeeded`。
- 第 3 步实验：键为 `t<编号>-<j>`，编号全局递增（每次实验不同），取 `mixed` 的前 b 位。
- 失配（页面 boundary 明说）：两种哈希都不是密码学哈希；第 3、4 步公式假设均匀独立；只讲拉链法。

## 数值结论与测试（`tests/core.cjs`）

- FNV-1a 公开测试向量（""、"a"、"foobar"）；UTF-8 与 Node Buffer 一致（含汉字）；任意输入都是 32 位、行数 = 字节数；cat/cats 前 3 个字节行相同、指纹差 ≥ 12 位。
- 雪崩：200 个输入上 FNV-1a 最低位翻转比例恰为 1/8、且「最低位翻转 ⇔ 翻了某字节最低位」逐位验证；第 k 低位 ≤ (k+1)/8；混合后平均在 14.5–17.5 且高于 FNV-1a；fmix32 在 10 万输入上无碰撞。
- 哈希表：只有 47 种字节和、item-12/item-21 同和；好哈希在 n×m 网格上空桶与随机预期相差 ≤ 3√(E+1)、平均比较接近 1+(n−1)/2m（n ≥ 40）；差哈希最多用 47 个桶；n=200、m=40..64 时差哈希空桶 ≥ max(4, m−47) 且比较多 0.9 以上；蒙特卡洛验证两个预期公式。
- 生日：23 人过半（与链接页一致）；b=8..20 的 k50 与 1.18√d 相差 ≤ 1.5、√d 处约 39%、b+2 时 k50 ×1.85–2.05；300 次真实哈希实验与理论的 KS 距离 < 0.1；小 d 穷举验证公式。
- 位数：N=10⁹、64 位 P≈2.7%；10⁻⁶ 需 79 位；网格上最少位数确为最小、落在 16–256；N×10 → +6~7 位、p/1000 → +9~11 位；N=10¹²、128 位 P < 10⁻¹⁴；近似式与精确乘积一致。
- 双语：键集与占位符一致、中英不同、无「左图/右图」；HTML/app 用到的键都存在；深链与对照链接目标存在；不引入 canvas-label-guard。
