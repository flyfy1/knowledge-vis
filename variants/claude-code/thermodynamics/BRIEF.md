## 定位

- category `physics`，subtopic `thermal`，stage `university`（与原版一致）。
- 受众：大学低年级；会定积分（面积）、对数；中学学过 PV = nRT 更好，页内当场复述。
- 一句话直觉：**功是 P–V 图上的面积、随路径变；内能只看温度、不随路径变；第一定律把两者记成一本账。把过程绕成循环，效率的上限 1 − Tc/Th 只在热量全在 Th 吸入、全在 Tc 放出时才达到。**
- 与原版的差异（设计选择）：原版用两段等温的教学循环；本版在固定的 A→B 上比较三条路径（功不同、ΔU 相同），用累计账本条形图展示卡诺循环一圈的能量流，再用斯特林循环（有/无回热器）说明「上限从何来」：两个回路面积相等，差别全在吸热。

## 模型、设定与失配

- `model.js`（浏览器与 node 共用）：`pressure`/`temp`、`paths`（三条路径的 W、Q、ΔU）、`along`/`workAlong`（动画进度与累计功）、`isoAdia`、`carnot`（含 `at(s)` 与累计账本 `ledger(s)`）、`stirling`（含回热器开关）。
- 全部为理想模型：0.2 mol 理想气体、准静态可逆过程、热容为常数（单原子 γ = 5/3，双原子 γ = 7/5）；单位 kPa·L = J。
- 页面终章明说：真实发动机效率更低；「η ≤ 1 − Tc/Th」来自第二定律，本页只展示两种循环满足它，不是证明。

## 数值结论与测试（`tests/core.cjs`）

- 文案常数（0.2 mol、8.314、2 L、250 kPa、1.5 L、400 K、Cv 12.47 / 20.79）与模型对账。
- 第 0 步：全部格点 PV = nRT、P 在 0–1080 kPa 轴内；体积翻倍压强减半。
- 第 1–2 步：全部 B × γ 格点上折线累计功 = 闭式、终点 = B、Q = ΔU + W、三路径 ΔU 相等且 = U(B) − U(A)、功大者吸热多、压缩时功为负、等容时功为 0；默认 B 下 W = 750 / 360 / 555 J 且 ΔU 明显非零。
- 第 3 步：全部 V₂ × γ 上 W = 数值积分 ∫P dV（Simpson）、PV^γ 与 TV^(γ−1) 守恒；膨胀时绝热降温且功更小，压缩时绝热升温；γ 大降温多。
- 第 4 步：全部 Th × Tc × r × γ 上 η = 1 − Tc/Th、回路闭合、鞋带公式面积 = W、账本终值 = Qh/Qc/W、吸热只在①、放热只在③、W 膨胀段增压缩段减；默认 η = 0.5。
- 第 5 步：无回热器 η < ηC 且随 r 单调上升；理想回热器 η = ηC；收支平衡；斯特林与卡诺面积（净功）相等。
