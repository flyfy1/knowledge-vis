## 定位

- category `signal`，subtopic `transforms`，stage `university`（与原版一致）。
- 受众：大学低年级；会复数的模与辐角、等比级数；拉普拉斯与采样页给深链但不强求先读。
- 一句话直觉：**zⁿ 是离散世界的积木（模管衰减、辐角管振荡）；X(z) 只在 ROC 里收敛；z = e^(sT) 把 s 平面卷进单位圆；频响就是单位圆上的值，可以用到极点、零点的距离直接读。**
- 设计选择：从复数幂的螺线出发（第 0 步），用等比级数的部分和轨迹直接「看见」收敛与发散（第 1 步）；再接上拉普拉斯与混叠（第 2 步）；用两个实极点的三种 ROC 讲清 ROC 决定序列与稳定（第 3 步）；最后两步以真实运行差分方程得到的输出为证据，讲单位圆上的频响与零点陷波（第 4、5 步）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：复数运算、`seq0`、`partialSums`/`closed1`、`s2z`、`twoPole`/`seq3`/`X3`/`rocRange`/`stable3`/`series3`、`filter`（通用差分方程）、`Hw`、`measureGain`（对稳态输出做 cos/sin 最小二乘）、`res`/`resGeometry`/`peakInfo`、`notch`/`input5`/`settle`。
- 第 4、5 步的「量得」振幅是把余弦真的送进差分方程、取第 700–1199 个样本拟合得到，不是抄公式。
- 失配（页面 s6 明说）：双边变换；「圆内 ⇔ 稳定」只对因果；距离公式中 b₀ = 1；单边变换、量化、相位响应不在范围内。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：x[n] = Re z₀ⁿ、\|z₀ⁿ\| = rⁿ（网格）；默认 r¹⁰ = 0.349、周期 12 样本。
- 第 1 步：全部 a × ρ 格点：\|a/z\| < 1 时 S₄₀ 与闭式之差 ≤ 几何尾项界；\|a/z\| = 1 时项不缩小；> 1 时第 40 项 > 1。
- 第 2 步：\|z\| = e^σ、孪生点重合、圆内 ⇔ σ < 0；e^(−0.3) = 0.741。
- 第 3 步：全部 p₂ × ROC：ROC 内逐项求和 = 闭式（1e−6）；Σ\|x\| 有限 ⇔ 单位圆在 ROC 内；极点在单位圆上判不稳定；外侧为因果、内侧为反因果；提示与小测情形；x[0] = 1。
- 第 4 步：1/(d₁d₂) = \|H\| = 差分方程实测（全部 r × Ω 格点）；峰在 π/3 附近；r ≥ 0.9 半功率宽度 ≈ 2(1 − r)（±10%）；r = 0.98 比 0.9 高且窄；r = 0.5 峰 < 1.6。
- 第 5 步：零点方向处增益为 0；实测 = 公式；Ω₀ = 1.2 时稳态输出只剩 0.3 音；过渡 44 样本（ρ = 0.9），ρ = 0.98 超过 100、ρ = 0.5 少于 10；ρ 近 1 时 0.3 音变化 < 3%，ρ = 0.5 时 > 20%。
