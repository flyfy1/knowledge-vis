## 定位

- category `probability`，subtopic `basics`，stage `senior`（与原版一致）。
- 受众：高中生；会组合数 C(n, k) 或刚学过，知道平方根与指数；不要求学过正态分布。
- 一句话直觉：**钉板上的每条路是一串左右选择；数路径得到 C(n, k)，加上每步的概率得到二项分布；标准化之后，n 越大，柱子越贴同一口钟——p = 0.5 时贴得快，p 偏时慢；用钟算整数结果的概率要挪半格。**
- 本版的设计选择：第 0 步把杨辉三角直接画在钉板上（框里数 = 到达该处的路数，可逐条走完所有路核对）；第 4 步用标准化把不同 n 叠在同一坐标，再配一张对数坐标的「最大差距随 n」图，让 1/n 与 1/√n 两种收敛速度直接看得见；第 5 步把连续性修正多出来的「半根柱子」单独高亮。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`pascal`、`choose`、`pmf`（对数阶乘）、`mean/variance/sd`、`phi`、`Phi`（West 2005 双精度有理近似，测试中与 φ 的数值积分比对误差 < 1e−10）、`paths`（字典序枚举）、`drop`、`within1sd`、`fit`、`tail`。
- 第 1 步球由 mulberry32（种子 77）模拟；改 n 或 p 清空。
- 失配与诚实声明（页面 boundary 明说）：理想钉子与独立性；数字只对本页滑杆范围核验；「差距」口径是整数点上的概率与密度之差，不是分布函数误差；远尾相对误差大。

## 数值结论与测试（`tests/core.cjs`）

- 去尾零只在有小数点时生效。
- 第 0 步：n ≤ 12 杨辉三角 = C(n,k)、行和 2ⁿ、左上 + 右上；n ≤ 10 路径枚举个数 = C(n,k)，每条恰好 k 个 R；P = C/2ⁿ。
- 第 1 步：pmf 和为 1 且等于 C pᵏ(1−p)ⁿ⁻ᵏ；20000 颗模拟球每格比例与公式相差 ≤ 0.012。
- 第 2 步：均值 np、方差 np(1−p)（逐项求和核对）；σ(20) = 2.236、σ(80) = 4.472；μ±σ 内概率 n = 30..100 × 17 个 p 为 57.1%–78.0%；正态 ±1σ = 68.3%。
- 第 3 步：p = 0.2 时 n = 50 规则首次满足；默认最大差在 k = 1；n = 10 时钟形伸到 0 以下。
- 第 4 步：最后两档的收缩比（p = 0.5：0.24–0.26；|p − 0.5| > 0.06：0.47–0.51；0.45/0.55 介于其间）；满足规则时 n = 1..400 的标准化最大差距 ≤ 0.026；偏度按 1/√n。
- 第 5 步：默认值 0.0284/0.0228/0.0287；全部设置最大误差 0.123 与 0.0027；精确概率 1%–99% 时修正后从不更差。
