## 定位

- 分类 `psychology`，子主题 `cognition`，阶段 `senior`，与原版一致。
- 受众：高中生，不要求学过心理学。
- 一句话直觉：**「记不住」有五种不同的原因：工作台按组块计数、放不下；复述不够、没进长时记忆；中枢决策一次只能做一件事；线索没对上编码时存下的特征；相似的记忆在提取时互相竞争。**
- 与原版的差异：本版每一步各用一个可调参的教学模型，对照一项经典研究的定性方向：
  - 组块与容量 K；
  - 复述缓冲模型解释系列位置曲线；
  - Pashler 中枢瓶颈解释 PRP；
  - 特征重叠解释编码特异性；
  - 强度竞争解释前摄 / 后摄干扰。

## 数值结论与测试（`tests/core.cjs`）

- **组块**：各种字符串、K 值和「认得 / 不认得」组合下的单元数和回忆数；不认得时 K 最大为 7，永远不够。
- **系列位置**：
  - U 形，首因来自长时记忆，近因来自缓冲区；
  - 速度为 4 时开头和中间升高，最后一个的变化不超过 0.02；
  - 延迟时，所有长度和速度下缓冲区部分都为 0、首因等于它的长时记忆部分、最后一个最低（约 0.16）；
  - 20 词时中段平坦。
- **PRP**：在所有 B1 和 SOA 取值下验证 RT2 公式、临界 SOA、平台值和斜率 −1；B1 = 300 时，加难在 SOA ≤ 150 时不变，在 SOA ≥ 300 时恰好多 150 ms。
- **提取**：8 种条件的数值（0.590 / 0.360 / 0.672 / 0.790 / 0.488）；浅加工时提示无效；换房间少 2 个特征。
- **干扰**：
  - 在相似度与延迟的网格上，都有对照 > 前摄 > 后摄，前摄组与后摄组的目标强度相同；
  - 相似度为 0 时三者相等；
  - 曲线随延迟单调下降，差距缩小；
  - 0.669 / 0.505 / 0.355。
- **页面检查**：
  - 双语键集和占位符一致；
  - 不出现「左图 / 右图」；
  - 深链锚点存在；
  - 控件 id 齐全；
  - 有 provenance 占位注释和对照链接。
