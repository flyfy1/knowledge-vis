## 定位

- category `probability`，subtopic `statistics`，stage `university`（与原版一致）。
- 受众：大学低年级；会平均数、平方根、对数刻度；不要求学过方差的性质或卷积。
- 一句话直觉：**n 个独立、σ 有限的数取平均，宽度按 σ/√n 收窄，形状趋向正态；多大的 n 才够取决于原料，σ 无限时定理失效。**
- 与原版的差异（设计选择）：四种离散原料（平的骰子、右偏的快递件数、两头高的评分、10% 的次品标记）贯穿第 0–3 步；除了模拟实验，还用 n 次卷积算出**精确**分布，并用 KS 距离量化「离钟形还有多远」，让「n 要多大」有了因原料而异的具体答案；第 4 步把定理落到民调 ±3%，并给出精确覆盖率；第 5 步用柯西分布展示失效。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`SOURCES`（四种原料的取值与概率）、`moments`（μ、σ、偏度）、`sumDist`（n 次卷积，带缓存）、`Phi` / `phi`（正态 CDF 与密度）、`ksGap`（精确 CDF 与正态 CDF 在每个跳跃点前后的最大差）、`sdOfMean`、`experiment`（mulberry32 抽样）、`nNeeded`、`margin` / `poll` / `exactCoverage`（二项分布精确求和）、`cauchy` / `runningMeans`。
- **模拟**：第 1 步实验（种子 1109，连续抽样）、第 4 步民调（种子 4242）、第 5 步累计平均（第 k 组用种子 10k..10k+3）。**精确计算**：第 0、2、3 步的分布与标准差、第 4 步的精确覆盖率、判断题的 93%。
- 模型失配（页面 s4hint、s5e、s6 boundary 明说）：现实民调不是简单随机抽样，还有无应答与加权；相关数据的有效样本更小；σ 无限时定理不成立；「近似正态」需要的 n 因原料而异。

## 数值结论与测试（`tests/core.cjs`）

- `fmt` 只在有小数点时去尾零。
- 原料概率和为 1；骰子 μ = 3.5、σ = √(35/12) ≈ 1.71；次品 μ = 0.1、σ = 0.3；骰子与两极评分对称，快递和次品右偏。
- `sumDist` 与穷举（n = 1..3）逐项相等；n = 1..300 时平均值的均值 = μ、标准差 = σ/√n（1e−9）。
- 判断题：100 个骰子平均落在 [3.2, 3.8] 的精确概率四舍五入为 93%。
- 第 1 步：4000 次模拟的均值、标准差与理论一致（不是页面断言，验证抽样实现）。
- 第 2 步：KS < 0.05 的最小 n 为 6 / 6 / 18 / 284（与 s2hint 一致）；KS 随 n 下降；n = 1 时次品 > 0.5，在绘图范围内。
- 第 3 步：4n 与 n 的标准差比恰为 0.5；所需 n 是满足目标的最小整数，且 ≤ 20000（在绘图范围内）；目标减半 n 变 4 倍（取整范围内）；骰子到 0.1 需 292。
- 第 4 步：n = 1000、p = 50% 误差 ±3.1%；±3.0% 需 1068；p = 5%、n = 100 精确覆盖 87.7%；默认精确覆盖 94.6%；精确覆盖 = 穷举（小例）；3000 次模拟覆盖率 ≈ 精确值。
- 第 5 步：骰子第 1–200 组 4 条线在 n = 5000 时最大相差 0.123 < 0.15；柯西 n = 1、10、100 个的平均落在 [−1, 1] 外的比例 ≈ 0.5（±0.03）；前 20 组中至少 15 组柯西线在 n = 5000 仍相差 > 1。
