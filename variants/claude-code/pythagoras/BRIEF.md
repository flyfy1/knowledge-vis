## 定位

- category `math`，subtopic `geometry`，stage `junior`（与原版一致）。
- 受众：初中生；会算面积、会乘方的写法 3² = 9；没证过定理。
- 一句话直觉：**直角三角形两条短边上的正方形，面积合起来正好装满最长边上的正方形；这个等号只属于直角。**
- 与原版的差异（设计选择）：原版从 3-4-5 的数字巧合出发，再灌注、拼图、拖顶点。本版先在方格纸上「抄近路」量出规律（第 0 步），再用**铰链**改变夹角，看见等号恰好只在 90° 成立、两侧分别是 > 和 <（第 1 步），把「为什么只属于直角」放在证明之前；证明用同一个框、同四个三角形的**两种摆法**（三个三角形只平移，不旋转），而不是代数展开；应用换成坐标格上的两点距离；最后用 1–20 的整数点阵看勾股数有多稀少、排成过原点的倍数线，再用分数逼近 √2 说明它写不成分数。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部 64 组 c < a+b；c² = a²+b²；表中 c×c 两位小数等于整数。

- 第 2 步：全部 a, b（0.5 步长）：斜空洞边长 c、面积 a²+b²；两块空洞合计 a²+b²；三角形直角边 a、b 且在框内；摆法乙用采样核对「三角形 + 空洞」恰好铺满框一次；右下角三角形平移量为 0（文案「右下角那个不用动」）。
- 第 3 步：d² = Δx²+Δy²；离 A 恰好 5 的格点共 4 个，且有不在横竖线上的。
- 第 4 步：测验 6 题答案；1..15 全部三元组：拼不成时两短边和 ≤ 最长边；「直角」⇔ 最大角 = 90°，钝角 ⇔ > 90°；放图边长正确；提示里的 3-4-5、3-4-6、3-4-2 例子。
