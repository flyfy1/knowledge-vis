## 定位

- category `probability`，subtopic `basics`，stage `senior`（与原版一致）。
- 受众：高中生；学过（或正在学）孟德尔遗传和古典概型，会分数乘法。
- 一句话直觉：**遗传比例是几次「公平抛硬币」的组合：分离给 1/2，受精相乘，显性合并，两对基因再乘一次；证据来了就划掉格子换分母。**

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：精确分数 `frac`/`fstr`；`gameteProbs`、`punnett`、`cross`；`binomPMF`；`rng`（mulberry32，固定种子）、`drawGamete`、`family`；`dihybrid`（16 格）与 `productRule`；`linkedGametes`、`testcross`、`selfLinked`、`simulateTestcross`；`conditional`、`nextGeneration`。
- 第 0、2、4 步的模拟是**伪随机模拟**（固定种子，可复现），不是实验数据。
- 失配（页面 boundary 明说）：完全显性、公平分离、后代独立、无选择无突变；自由组合只适用于不同染色体或相距很远的基因；不含不完全显性、伴性遗传、多基因性状。

## 数值结论与测试（`tests/core.cjs`）

- 分离：Aa 1/2，纯合子只给一种；2000 个配子的比例接近 1/2（±0.03）。
- 九种单基因杂交：概率和为 1、整格、对称；Aa×Aa 1:2:1 与 3:1；Aa×aa 1:1；AA×aa 全 Aa。
- 二项：n = 1..10 和为 1、均值 n/4、P(0) = (3/4)^n；n = 4 时 42.2% / 31.6%、众数 k = 1；n = 10 时每个 k < 30%；20000 批模拟均值 ≈ n/4。
- 两对基因：九种组合 16 格 = 乘法法则；默认 9:3:3:1；Aa×aa × Bb×Bb 为 6:2:6:2（= 3:1:3:1）。
- 连锁：测交和为 1、重组型占比 = r、亲本型随 r 单调减少；r = 50% 测交 = 1:1:1:1、自交 = 56.25/18.75/18.75/6.25%；r = 0 测交 50/0/0/50、自交 75/0/0/25；所有柱子在坐标轴内；200 株模拟估计 r 无偏、标准差 < 4%。
- 条件概率：P(Aa \| 紫) = 2/3、P(AA \| 紫) = 1/3、P(aa \| 白) = 1；下一代 × aa = 1/3、× Aa = 1/6。
- 格式化：`fmt(90, 0)` 仍是 `90`。双语键集、占位符、中英不同、无「左图/右图」；深链与锚点存在。
