## 定位

- category `signal`，subtopic `sampling`，stage `university`（与原版一致）。
- 受众：大学低年级；会三角函数、知道「频率 = 每秒周期数」；不要求学过傅里叶变换（第 4 步就近解释频谱并给深链）。
- 一句话直觉：**均匀采样只在 t = n/fs 处看信号，f 与 f + k·fs 在这些时刻相位只差整圈，所以样点分不清它们；能做的只有事先限带。**
- 设计选择：从单辐条车轮的频闪现象出发，先在一个频率上讲清「为何分不清」（第 1 步）和「会被认成什么」（第 2 步的折线），再讲重建的边界（第 3 步，含 f = fs/2 时振幅与相位搅在一起），最后换到频谱上看复制与重叠（第 4 步），并以 44.1 kHz 的抗混叠滤波余量收束（第 5 步）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`aliasSigned`/`fold`（别名与折叠）、`wheel`/`spoke`（车轮）、`sameSamples`、`recon`/`reconRun`/`predicted`（sinc 重建与折叠预测）、`sampledSpec`/`aliasFraction`/`aliasFractionTheory`、`butter`/`antiAlias`。
- 第 3 步：420 个样点（n = −200…219）的有限 sinc 和，显示 0–2 秒，误差为截断误差。
- 第 5 步：30 kHz 干扰是模拟设定；巴特沃斯只用幅频，不讨论相位与实际电路。
- 失配（页面 s6 明说）：无量化、无时钟抖动；带通采样、滚动快门、过采样 ADC 不在范围内。

## 数值结论与测试（`tests/core.cjs`）

- 别名代数：g ∈ (−fs/2, fs/2]，fold = |f − fs·round(f/fs)|（多种 fs、全频率网格）。
- 第 0 步：24 静止、23 → −1（345° → −15°）、25 → +1、12 与 36 为半圈边界；锯齿周期 24；每帧位置 = 累计表观转角。
- 第 1 步：所有 f × k 样点差 < 1e−9；候选 ≠ 原信号时曲线最大差 > 0.5；f = 3 示例 > 1；最低别名 ≤ 4。
- 第 2 步：30 @ 44.1 → 14.1；小测 40 @ 48 → 8；拐点 22.05、44.1 → 0；fa ≤ fs/2。
- 第 3 步：全部滑杆格点重建与预测之差 < 0.013（最大在 5/15 Hz 边界，文案引用由测试钉住）；f < 5 重建 = 原信号；f > 5 且非自身时与原信号差 > 0.1；7 Hz → 3 Hz 且相位变号；5 Hz φ = 90° 为直线；10 Hz → 常数。
- 第 4 步：全部 B × fs 格点 fs ≥ 2B 时占比为 0，否则 > 0；B ≤ fs 时等于 (1 − fs/2B)²；B = 6、fs = 12 正好相接。
- 第 5 步：N = 10、fc = 20 时 24.1 kHz 约 −16.3 dB（文案「约 16 dB」）；N 增大干扰单调下降；fc = 20 时 5 kHz 损失 < 0.3 dB；fc 是 −3 dB 点；降低 fc 换来更多衰减与更钝的高音。
- 双语：键集与占位符一致、中英文不同；无「左图/右图」措辞；HTML/app 用到的键都存在；深链目标页与锚点存在（同批次的 Z 变换 Claude 版写完后一并核对）。
