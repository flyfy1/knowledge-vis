## 定位

- category `physics`，subtopic `mechanics`，stage `junior`（与原版一致）。
- 受众：初中生；知道速度、力（牛顿）、会读简单的折线图；F = ma 当场复述，不要求先学过。
- 一句话直觉：**动量 p = m·v 是「运动有多难停下」的量；只有「力 × 时间」能改变它；两物体互相作用时一方的损失恰好是另一方的收获，所以总量不变。**
- 与原版的差异（设计选择）：从「同样刹车力，谁要刹更久」这个可观测的问题引出 m·v（中图对速度散乱、下图对动量排成一条线）；冲量用两张图（F–t 面积 ↔ p–t 台阶）对应；软着陆用「等面积长方形」一张图讲清 F = Δp/Δt；碰撞把「一失一得」画成随时间的动量曲线；单独一步区分动量守恒与动能损失（恢复系数 e 连续可调）；最后用冰面互推讲反冲。

## 模型、设定与失配

- `model.js`（浏览器与 node 共用）：`braking`（恒力刹车）、`push`（恒力推动）、`cushion`（平均力）、`collide`（一维碰撞，含 e）、`keLossFormula`（½μu²(1−e²) 对照）、`timeline`（接触期间恒力的动量与位置随时间）、`recoil`。
- 全部是理想化模型，不是实测：刹车力 2 N；蛋 0.06 kg、承受力 25 N（演示设定）；接触时间 0.08 s（示意，接触期间按恒力）；冰面无摩擦。
- 页面终章明说适用范围：一维、不计摩擦与空气阻力、碰撞时外力可忽略。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部滑杆格点 t = p/F、停下后位置不变、0.5 s 点距逐段变小；轴范围装得下全部情形；1 kg、3 m/s 与 B 同时停但距离不同；同速不同质量用时不同。
- 第 1 步：全部 m×F×Δt 格点 Δp = F·Δt = J、Δv = J/m、曲线在 3 s 窗口内走完、Δp 与 m 无关；4 N×0.5 s 与 1 N×2 s 终点相同。
- 第 2 步：全部格点面积 = Δp、F ≤ 100 N 轴、「完好 ⇔ Δt ≥ Δt_min」；重力 ≈ 0.59 N；默认值碎、0.1 s 全部完好；10 倍时间 → 十分之一力（判断题反馈）。
- 第 3–4 步：全部 mA×mB×vA×vB×e 格点动量守恒、A 失 = B 得、分开速度 = e×接近速度、动能损失 = ½μu²(1−e²)、e = 1 动能守恒、e = 0 共速、留存比例随 e 单调上升；时间线上任一时刻总动量不变、t = 1 s 恰好接触、挤压不超过 u·τ/2；默认读数（A 6→4、B 0→2、动能留 2/3）。
- 第 5 步：全部格点总动量 0、速度比 = 质量反比、6 s 内留在 ±25 m 冰面上。
