## 定位

- category `biology`，subtopic `ecology`，stage `senior`（与原版一致）。
- 受众：高中生；会读函数图像、知道斜率是「变化的快慢」；不要求学过微积分（dN/dt 每次出现都说成「每年增加的条数」）。
- 一句话直觉：**增长速度 = 数量 × 每个个体的净增长率**；拥挤把后一个因子压低，于是指数增长弯成 S 形；捕捞和捕食者都接进同一个公式。
- 与原版的差异（设计选择）：原版从 r、K、t 三个旋钮直接看 logistic 曲线；本版先把 r 拆成出生率 b 与死亡率 d（第 0、1 步），让 K 成为「两条线的交点」而不是一个给定参数；用「矩形面积」解释增长为什么在 K/2 最快（第 2 步）；加了一步捕捞（最大可持续产量 rK/4，第 4 步）把驼峰图用于决策；捕食者一步用带拥挤项的猎物模型，振荡逐渐收敛，并给出相平面。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`expo`、`doublingTime`、`birthRate`/`deathRate`、`perCapita`、`growth`、`logistic`（解析解）、`tReach`、`tInflection`、`rk4`、`harvestEq`、`simHarvest`、`ppEq`、`simPP`、`ppLag`。
- 全部是**模拟**，参数为示意值：N₀ = 20、r = 0.5/年、K = 1000 条；捕食者一步猎物 r、K 相同，转化率 0.05，起点猎物 100、捕食者 5，RK4 步长 0.02 年。
- 第 1 步把净率拆成两条直线 b(N) = 0.6 − 0.3·N/K、d(N) = 0.1 + 0.2·N/K；滑杆范围（N ≤ 1600、K ≥ 800）保证 b ≥ 0。拆分比例是假设，只影响两条线的位置，不影响净率。
- 第 4 步轨迹画 60 年，崩溃年份用 300 年的模拟求出；H 恰为 125 时是半稳定点，页面明说「缓慢逼近 500，额外损失会滑向崩溃」。
- 模型失配（s6 明说）：确定性、连续时间、无年龄结构；不含季节繁殖、时滞、随机灭绝、K 的变化。

## 数值结论与测试（`tests/core.cjs`）

- 翻倍 / 减半时间与等距；默认 1.39 年、10 年后 ≈ 2,968 条。
- 第 1 步：b − d ≡ r(1 − N/K)，符号恰在 K 处翻转；b(K) = d(K) = 0.3（小测反馈引用）；滑杆范围内 b ≥ 0。
- 第 2 步：逐点扫描找到峰在 N = 500、125 条/年；箭头方向与 dN/dt 符号一致；N = 1400 处 −280 在画布纵轴范围内。
- 第 3 步：解析解与 RK4 积分一致；r 加倍 = 时间减半；最陡时刻（扫描）= ln((K−N₀)/N₀)/r；默认 7.8 年、90% K 在 12.2 年；从 K 以上单调回落。
- 第 4 步：H ≤ 125 才有平衡点；两根都使净变化为 0；低于不稳定根必崩溃；H = 120 → 600/400；H = 130 → 第 55 年捞光；H = 125 时 60 年后仍在 500–540 之间。
- 第 5 步：整个滑杆网格上，共存 ⇔ m/(0.05a) < 1000；平衡点使两式为 0，400 年模拟收敛到它；有两个峰时捕食者峰都在猎物峰之后（滞后 3.0–34.7 年）；默认 N* = 200、P* ≈ 13.3、峰在 6.8 / 11.1 年；猎物峰逐个变低；相平面轨迹逆时针；m 增大 N* 增大。
- 双语键集与占位符一致；页面键都存在；深链落在存在的步骤锚点；无「左图 / 右图」。
