## 定位

- category `physics`，subtopic `mechanics`，stage `junior`（与原版一致）。
- 受众：初中生；知道速度、质量、重力，会用 g = 9.8 N/kg；E_p = mgh、E_k = ½mv² 在第 0 步当场定义。
- 一句话直觉：**只有重力做功时，少掉的高度一分不差地换成速度；有阻力时，账本多出一栏「热」，总数仍然不变。**
- 与原版的差异（设计选择）：用「账本」贯穿：第 0 步三根能量条 + 能量–下落高度图；第 1 步沿轨道的堆叠面积（势能 + 动能 = 水平白线）；第 3 步把热作为第三层堆在随时间变化的账本上。加了一步伽利略钉子单摆（路线不同、最高点相同），把「只看高度」推广到过山车之外；最后一步不讲刹车距离，而把车速换算成「等效坠落高度」（楼层），让平方关系看得见。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`fallState`（解析）；轨道 `h(x)` 为 8 个关键点之间的半余弦拼接（关键点处斜率为 0）；`simulate`（沿轨道 RK4，dt = 2 ms，阻力 k·m·g 恒定，过零时按同一系数判断是否静止）；`pendulum`（速度 Verlet，dt = 0.2 ms，绳子在最低点换半径，速度连续）；`dropHeight`。
- **账本不强制平衡**：模拟只积分运动方程，热 = k·m·g × 实际路程；测试检查 势能 + 动能 + 热 与出发值的相对差，以此验证积分。
- 模型失配（页面 s5 明说）：质点、不计车轮转动能量；阻力大小恒定（真实空气阻力随速度增大）；轨道图竖直方向已放大；第 0–2、4 步不计任何阻力。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部 h₀ × m 网格上 E_p + E_k = E₀；落地速度 = √(2gh₀)，与质量无关；h₀ = 10 m → 14.00 m/s；每 0.1 s 影子间距递增。
- 第 1 步：每个松手高度 H（4–15，步长 0.5）：无摩擦模拟账差 < 1e−5；模拟速度 = √(2g(H−h))；最远位置 = 轨道升到 H 处（±0.05 m）；第二坡（10 m）恰在 H ≥ 10 时冲过；H = 12 时约 93 m 掉头；x = 30 m 速度 6.3 m/s；探测读数全网格校验；能量图 0–80 kJ 装得下。
- 第 2 步：θ 10–50° × p 0–1.9 m 全网格：绳子绷紧、两侧最高点差 < 1 mm、绕钉角 ≤ 90°、回到左侧松手高度；钉子越低绕钉角越大；无钉子时角度相同。
- 第 3 步：H ∈ {4, 8, 12, 15} × k 0.01–0.1：300 s 内停下、账差 < 0.01%、停下时热 = E₀ − E_p、热 = k·m·g × 路程、播放 ≤ 15 s；k 越大停得越早、路程越短；k = 0.05 时每次爬坡更低；k = 0 永不停。
- 第 4 步：3.54 / 14.17 / 56.69 m 与 1 / 5 / 19 层；所有档位翻倍 ×4；图与楼高范围。
- 双语：键集与占位符一致、非公式键中英不同、不出现「左图/右图」；HTML/app 用到的键都存在；页脚含模型 id 与原版标题；深链目标页与 `#stepN` 锚点存在；对照链接存在；无 canvas-label-guard。
