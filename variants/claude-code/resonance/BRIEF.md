## 定位

- category `physics`，subtopic `waves`，stage `senior`（与原版一致）。
- 受众：高中；会用牛顿第二定律、知道弹力 −kx 和周期/频率；不要求微分方程（运动由页面数值模拟给出）。
- 一句话直觉：**推的节拍对上固有节拍时，推力和速度同向，推力每时每刻都在送能量；振幅一直长到送入的能量等于阻力消耗的能量为止。**

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：RK4（dt = 0.002 s）积分 m·a = −kx − bv + F₀cos(Ωt)；`measuredPeriod`（过零插值）、`peaks`（抛物线插值）、`free`、`damped`、`steady`（闭式 A 与 φ）、`driven`（从静止推，取末 3 个推力周期内最大位移）、共振曲线测量与 `cycleWork`（一个周期的正负功与耗散）。
- 动画是 5 倍速等教学变速，页面已标明。
- 模型失配（页面收束段明说）：线性、单自由度；真实桥梁、建筑、乐器有多个固有频率，振幅大时弹簧不再线性；阻力取与速度成正比的模型。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部 m、k 滑杆组合下测得周期 = 2π√(m/k)；m ×4 → 周期 ×2；默认 0.993 s、f₀ 1.007 Hz。
- 第 1 步：每振一次剩余比例测得 = e^(−bT/2m)；比例随 b 单调减小；b ≤ 1.6 周期变化 <1%；临界 2√(mk) ≈ 12.6 及以上不越过 0；半衰时间 2m ln2/b。
- 第 2 步：模拟稳态振幅 = 闭式 A；r = 1 时 39.5 cm、静态位移 2.5 cm 的 15.8 倍；r = 1.5 小于静态位移；暂态时间常数 2m/b = 5 s。
- 第 3 步：每个 b、r 的测量点与公式一致；峰位、峰高、Q = mω₀/b、Δr ≈ 1/Q；b 减半峰高约 ×2（判断题）；b = 1.6 峰左移。
- 第 4 步：一个周期内净功 = 阻力耗散；r = 1 时负功为 0、φ = 90°；读数中的正功、负功与相位。
- 双语与结构：键集与占位符一致；HTML/app 用到的键存在；深链与锚点存在；元素 id 唯一；无「左图/右图/上半图/下半图」等依赖排版位置的说法；无 canvas-label-guard；有 provenance 占位。
