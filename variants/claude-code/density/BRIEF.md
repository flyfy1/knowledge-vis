## 定位

- category `physics`，subtopic `matter`，stage `junior`（与原版一致）。
- 受众：初二学生；会用天平、量筒，知道一次函数的图像是直线。
- 一句话直觉：**多重、多大各自说明不了材料；两者相除得到的比值才几乎只由材料决定。**
- 与原版的差异（设计选择）：
  - 从「同样重的东西各占多大地方」出发，用「切大切小」的 m–V 图找出比值，比值就是直线的陡度。
  - 再做三个应用：
    - 用这个比值称教室里的空气；
    - 用排水法认金属块，并把读数误差变成密度范围，让学生看到小块认不出来；
    - 检验王冠是否掺银，说明平均密度不能把两种密度直接平均。
  - 最后用密度塔把密度和上下次序联系起来，并链到浮力页。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：
  - `equalMass(m)`：给出同质量下各材料的体积。
  - `piece(k, i)`、`slope(pts)`：给出切块的尺寸与读数，以及过原点直线的平均比值。
  - `room(L, W, H)`：给出空气质量与「几个同学」（AIR = 1.2 kg/m³）。
  - `measure(id)`：给出排水前后读数，以及在 ±0.5 mL 误差下的密度范围和落在范围内的参考金属。
  - `crown(f)`：给出王冠体积、多排开的水、真平均密度与直接平均。
  - `settle(r)`：给出方块在密度塔中的位置；夹在两层之间时用 f = (r − ρ上)/(ρ下 − ρ上) 平衡。
- 设定：
  - 密度（g/cm³）：松木 0.5、冰 0.92、铝 2.7、铁 7.9、铜 8.9、铅 11.3、金 19.3、银 10.5。
  - 待认金属块：A 铝 20 cm³、B 铁 5 cm³、C 铅 8 cm³、D 铜 10 cm³。
  - 密度塔四层：植物油 0.92、水 1.00、洗洁精 1.06、蜂蜜 1.42。
- 失配（页面明说或示意）：
  - 松木密度随含水量变化很大，这里取典型值。
  - 空气密度随温度、气压而变。
  - 真实的密度塔放久了，相邻液体会互溶，分界变模糊。
  - 排水法忽略金属块表面附着的气泡。
  - 画面比例为示意。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：V·ρ = m（50..500 g 全网格）；松木体积 / 铁体积 = 15.8（「约 16 倍」）；质量翻倍，体积也翻倍。
- 第 1 步：天平读数到 0.1 g；在天平分辨率内 m/V = ρ；拟合斜率 = ρ（误差 0.005 以内）；2.7、7.9、0.5 与提示文字一致。
- 第 2 步：
  - 8×6×3 m 时为 172.8 kg，约 173 kg，超过 3 个同学；
  - 长 8 → 12 m 时质量正好变为 1.5 倍；
  - 1.2 kg/m³ = 0.0012 g/cm³。
- 第 3 步：
  - 可认出的结果为 A 铝；B 铁或铜；C 铅；D 铜；
  - 每个范围都包住真值，水面读数都在刻度内；
  - B 的范围宽度大于 A 的 3 倍以上。
- 第 4 步：
  - 纯金 51.8 cm³；掺 30% 银时多约 13 mL，银占体积的 44%；
  - 0..50% 全网格满足 ρ·V = 1000；
  - 掺银时真平均密度低于直接平均。
- 第 5 步：
  - 各层自上而下密度递增；方块密度越大，停得越不高（单调不升）；
  - 夹在两层之间时满足平衡式；
  - 只有密度低于 0.92 时浮在油面，只有 ≥ 1.42 时到杯底；
  - 0.92、1.00、1.06 处各有超过 1.5 cm 的台阶。
- 双语：
  - 中英键集与占位符一致，中英文本不同；纯文本键不含 HTML；
  - HTML 和 app 用到的键都存在；深链目标与锚点存在；
  - 对照链接、占位注释、provenance CSS 都在，没有引入 canvas-label-guard。
