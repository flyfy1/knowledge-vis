## 定位

- category `physics`，subtopic `circuits`，stage `university`（与原版一致）。
- 受众：大学低年级。已知：电压、电流、欧姆定律、功率 P = VI。电感在页内当场解释；不要求学过电力电子。
- 一句话直觉：**开关不改能量守恒，只是让电感在「从电源吸能」和「向负载放能」之间切换；稳态由伏秒平衡决定，于是降压 V_out = D·V_in，升压 V_out = V_in ÷ (1 − D)。**
- 与原版的差异（设计选择）：
  - 从「线性稳压为什么发热」引出开关变换器。
  - 第 2 步让读者先把输出设成错的猜测值，看电感电流逐周期漂走，再「找到」伏秒平衡。
  - 第 3 步用 RK4 逐周期仿真开机过程，让电路自己走到稳态，并连到二阶系统的阻尼比。
  - 第 5 步把公式的适用边界（CCM / DCM）用仿真与理论曲线对照讲清。
  - 电容不单独设步，只在启动与升压步骤里按功能出现。

## 模型、仿真设定与失配

- `model.js`（浏览器与 node 共用）提供：
  - 公式：`linear` / `ideal`、`pulseStep`、`buckRatio` / `boostRatio`、`buckRipple` / `boostRipple`、`buckDrift`、`Kpar` / `buckCCM` / `buckM`（含 DCM）、`Lcrit`、`filter`（ζ、f0）、`budget`；
  - 时域仿真：`simulate`，理想开关与二极管，二极管阻止电流反向（DCM），RK4，每周期 200 小步；
  - `steady`：从预测工作点起跑 400 周期，取最后一周期；
  - `startup`：从 0 起跑 600 周期。
- 参数：100 kHz，L = 47 µH，C = 100 µF；降压 12 V / 6 Ω，升压 5 V / 24 Ω。
- 模型失配（页面 boundary 明说）：
  - 元件理想，无导通压降、开关损耗、ESR、反馈控制；
  - 第 2 步「输出恒为 V_g」是思想实验；
  - 第 3 步的超调是开环理想电路的结果，实际电源有软启动；
  - 第 6 步只用 η 概括损耗。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：线性输入 = 输出 + 热，效率 = V_out/12；理想开关的输入电流小于负载电流；条形图刻度装得下 36 W。
- 第 1 步：Δi = VΔt/L；0 V 不变；正负对称；½Li² 与方向无关；文案中的元件值与模型一致。
- 第 2 步：
  - 每个 D 下，「取 V_g」后漂移 < 0.005 A，相邻一格就 > 0.005 A；漂移符号 ⇔ V_g 与 D·V_in 的大小关系；
  - 默认负载下全 D 都在 CCM；
  - 仿真稳态 = D·V_in（< 0.3%），仿真纹波 = 公式（±0.01 A）。
- 第 3 步：
  - 全部 D × R 格点都超调且在 CCM，600 周期末与目标差 < 0.5%（实测最大 0.34%）；
  - R 越大 ζ 越小、超调越大。
- 第 4 步：仿真 = V_in/(1−D)（< 0.3%），全范围 CCM；电感平均电流 = I_out/(1−D)；输入功率 = 输出功率；二极管电流均值 = 负载电流。
- 第 5 步：
  - 5 × 8 × 5 个 (D, L, R) 格点上，仿真与 CCM/DCM 理论差 < 0.5%（实测最大 0.35%）；
  - DCM 时输出 > D·V_in、电流有 0 段；CCM ⇔ L > L_crit。
  - 测试中发现 K = 1 − D 恰在边界时浮点比较判错，已把边界归入 CCM（两式此处都等于 D）。
- 第 6 步：2.67 A、13.33 W、理想 2.4 A；四个选项互不相同；η ≥ 70% 时条形图刻度装得下。
- 文案引用的 47 µH、100 µF、24 Ω、5 V、100 kHz、2.4 与模型一致。
- 双语与页面结构：
  - 键集与占位符一致，静态键不含占位符；
  - HTML / app 用到的键都存在，控件齐全，无 label guard，有署名占位；
  - 深链锚点存在。
