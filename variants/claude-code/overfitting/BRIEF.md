## 定位

- category `computing`，subtopic `ml`，stage `university`（与原版一致）。
- 受众：大学低年级；会读散点图、知道多项式和平方根；不要求学过统计学习。
- 一句话直觉：**训练误差只量「离见过的点多近」；灵活度一高，曲线把噪声当规律记住，对新数据的误差先降后升。误差 = 偏差² + 方差 + 噪声，对策是按验证误差选灵活度、多收数据、或早停。**
- 与原版的差异（设计选择）：
  - 真实规律换成 f(x) = 0.8 sin(2.5x) + 0.3x，x ∈ [−1, 1]，用 Legendre 基 + Householder QR 求最小二乘（不走正规方程）。
  - 第 0 步只给训练误差（「训练 RMSE」图只画试过的 d，留下历史），真实规律默认隐藏，先让读者自己判断。
  - 第 2 步噪声 σ 只缩放固定的标准正态误差，点只在竖直方向按比例移动，读者能把「噪声」单独隔离出来。
  - 第 3 步学习曲线用嵌套的 120 点池（加点不换旧点），并让读者看到「曲线最离谱处 = 训练点空档」。
  - 第 4 步偏差²/方差：读者自己抽批次看扇形，右图给 200 批的平均曲线（对数轴）。
  - 第 5 步用**早停**（梯度下降 + 40 个验证点）代替原版的岭回归，并把验证集与测试集的分工讲清楚。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`truth`、`sample`（均匀网格 + 抖动的 x，标准正态 z 单独保存以便缩放 σ）、`testSet`（均匀随机 x）、`labels`、`legendre`、`lstsq`（Householder QR）、`fit` / `predict` / `rmse`、`degreeScan`、`fan`（偏差²/方差，41 个网格点）、`gdRun`（梯度下降，步长 1/L，L 由幂迭代求 (2/n)XᵀX 最大特征值）。
- 全部是**模拟**数据：训练种子 7、测试种子 4242（400 点）、学习曲线点池种子 99（120 点）、验证种子 777（40 点）、偏差/方差参考 200 批种子 1000–1199；读者抽批次的种子从 5000 递增（最多 60 批）。
- 模型失配（页面 s6 明说）：只有一元多项式与已知光滑规律；「d=3 最佳」「第 6 步早停」只属于这组数据；实际应只用验证集挑选、测试集只用一次；未覆盖交叉验证与正则化。
- 期望均方误差 ≈ 偏差² + 方差 + σ²：测试在 41 个网格点上核对恒等式（批次平均的平方偏离 = 偏差² + 方差·(B−1)/B，机器精度），噪声项 σ² 用测试点噪声核对；页面用「约等于」，因为方差按 B−1 归一、并且网格点与随机测试点的权重不同。

## 数值结论与测试（`tests/core.cjs`）

- 最小二乘解满足正规方程（每个 d）；Legendre 递推与闭式一致。
- 第 0 步：训练 RMSE 对 d 不增，只有 d=11 为 0；d=11 曲线在 [−1, 1] 内超出 ±2。
- 第 1 步：最佳 d=3、测试 0.29±0.005；噪声底线 0.24±0.005；测试先降后升；超出 1.2 的恰为 d ≥ 9；底线 ≈ 0.96σ。
- 第 2 步：σ=0 时 d ≥ 5 测试 < 0.02 且随 d 无实质上升；σ=0.1/0.25/0.5 最佳都是 d=3；σ 越大每个 d 的测试 RMSE 越高、高次端越陡；点只竖直按比例移动。
- 第 3 步：n=10 插值且测试 > 1.2；n ≤ 20 测试都 > 1.2、n=30 < 0.4；n ≥ 40 测试 < 0.3、训练在 0.19–0.3；训练 RMSE 缓升；点池嵌套。
- 第 4 步：d=1 方差 0.011±0.001、偏差² 0.055±0.002；d=9 方差 3.7±0.1、偏差² < 0.01；d=3 偏差² 0.001±0.0006、方差 0.024±0.001；方差随 d 单调上升；偏差² 0→1→3 下降；偏差-方差恒等式。
- 第 5 步：验证最低在第 6 步；第 100000 步验证 > 2.6、测试 > 2，而早停点测试 < 0.3；训练 RMSE 单调下降；早停点之后验证单调上升；91 个检查点；末尾训练 RMSE < 0.02。
- 文案引用的数字（0.29、0.24、d = 3、9、0.96、20、30、40、0.011、0.055、3.7、0.001、0.024、6、2.6、40、400）都由测试核对中英文均出现。
