## 定位

- category `computing`，subtopic `ml`，stage `university`（与原版一致）。
- 受众：大学低年级；会向量的加减和点积；不要求学过机器学习。
- 一句话直觉：**一个词的意思，可以从它常和哪些词一起出现数出来；把计数换成 PPMI、用余弦比较、再压到少数方向，就得到一张词的地图，向量的加减有时还能做类比。**
- 与原版的差异（设计选择）：本版走「计数法」的完整链条，每一个数都能在页面上追溯到一个手写的 28 句玩具语料：独热编码为何不够 → 逐句数窗口内的邻居 → 余弦 → PPMI 压低「是」这类到处都有的词 → 对 6 个名词做 SVD 画地图 → 在 PPMI 向量上逐位看「国王 − 男人 + 女人」怎样落到「女王」，并专门给出一个**不成立**的类比（他 − 男人 + 女人 → 富有，「她」只排第 7）。不训练 word2vec，也不画预训练向量。

## 模型、玩具语料与失配

- `model.js`（浏览器与 node 共用）：29 词词表（英文词 + 中文显示名）、28 句三词句、`oneHot`、`dot`/`norm`/`cosine`/`dist`、`counts(k, w)`（读前 k 句、窗口 w）、`pairsIn`、`ppmi`、`neighbours`、Jacobi 特征分解与 `compress`（Gram 矩阵的特征分解 = SVD，方向符号固定为最大分量为正）、`truncate`、`analogy`。
- 中文界面按英文原句的词序逐词显示中文词（如「他 是 国王」），所以中英两种语言的计数完全相同。
- 语料是手写的，词与词的关系是有意安排的（同类名词共享内容邻居，所有名词都和「是」及代词同现）。
- 失配（终章明说）：真实词向量从数十亿词训练、几百到几千维、单个维度无可读含义；类比常常不成立，也会继承语料偏见；本页是「计数 + PPMI + SVD」的计数法，word2vec 等是预测法，但都利用「看邻居」的信息。

## 数值结论与测试（`tests/core.cjs`）

- 语料：29 词、28 句、每句 3 词、每个词都出现过；中文显示名互不相同。
- 第 0 步：所有不同词对点积 0、余弦 0、距离 1.414；同词点积 1。
- 第 1 步：读句时计数只增不减、对称；最大计数 3（柱轴 0..3）；国王行的 7 个非零计数逐项钉住；窗口 1 时国王不再记「他」；窗口 1 计数 ⊆ 窗口 2；国王在第 1 句。
- 第 2 步：猫–狗 0.83、国王–女王 0.85、男人–女人 0.82；国王原始最近邻为女王；猫–王冠 < 0.3；每个名词都与「是」同现；余弦与缩放无关。
- 第 3 步：同类/不同类平均余弦 原始 0.833/0.411 → PPMI 0.686/0.072；同类最小 0.661 > 不同类最大 0.215（原始不同类最大 0.548）；窗口 1 时差距同样拉大；PPMI ≥ 0 且只在有计数处非零；名词 PPMI ≤ 3.5（轴）；国王–是 0.81、国王–王冠 2.39，「是」在国王行原始最高、PPMI 最短；国王–女王 0.69、国王–猫/狗 < 0.05；每个名词的「是」都被压到内容邻居之下。
- 第 4 步：份额 0.330/0.625/0.851/0.924/0.972/1、逐方向份额递减且 ≤ 40%（轴）；余弦最大误差 0.994/0.889/0.337/0.260/0.077/0；最像名词一致数 2/6/6/6/6/6；坐标重建 Gram 矩阵；方向 2 把动物和人分开；方向 2×3 中每个词最近的点都是同类伙伴，类内距离 × 2.5 < 类间最小距离。
- 第 5 步：四个类比命中、一个不中，首位余弦 0.690/0.735/0.696/0.542/0.440；他−男人+女人 → 富有，「她」第 7；国王−男人+女人 的结果中「他」0.32、「她」2.39、「帽子」< 0、王冠/统治/国土/富有原样保留，第二名「是」0.332；−男人+女人 中「她」正、「帽子」负，工作/城市/街道/忙碌大体抵消。
- 双语：键集与占位符一致、中英不同（`rowProd` 例外）、无「左图/右图/上图/下图」类指代、文中引用的 0.83/1.414/0.89/100% 中英都有；HTML/app 键存在；控件存在；无 label guard；占位注释与 CSS；深链与对照链接存在。
