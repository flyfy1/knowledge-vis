## 定位

- category `investment`，subtopic `rates`，stage `senior`（与原版一致）。
- 受众：高中；会百分数和复利 (1+r)^t，知道加权平均；不要求任何金融背景。
- 驱动问题：利率上升，为什么已经发行的债券价格会下跌？
- 一句话直觉：**债券是一串写死的现金；价格 = 按市场利率贴现后的总和。加息后，老债券必须降价到新买家也能拿到新利率，折价正好等于它每年少拿的票息的现值。**
- 与原版的差异（设计选择）：原版用「新买家要新利率」的利率滑杆讲反向机制、久期只定性比较。本版：
  - 第 2 步把价格画成「现值首尾相接的长条」，直接看见价格是和、越过面值线就由溢价变折价；
  - 第 3 步让读者自己给老债券报价，读出买家的到期收益率，再用「逐轮对半试价」动画演示市场怎样把价格压到收益率 = 新利率的交点，并给出「折价 = 票息差额的现值」这一恒等式；
  - 第 5 步用「现值砝码 + 平衡点」把久期讲成加权平均等待时间，并把直线估算与精确值并排比较（含凸性带来的系统偏差）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`cashflows`、`df`/`pv`/`grow`、`pvFlows`、`price`、`ytm`（二分法，价格对 r 严格单调）、`marketSearch`（对价格区间逐轮对半）、`shortfall`（票息差额及其按 r_new 的现值）、`pctChange`、`duration`（Macaulay）、`approxPct`（−D/(1+r)·Δr）。
- 全部是虚构示例：面值 100，年付息，付息日刚过报价，单一平坦市场利率，不违约，不计税费。没有真实发行人、行情或利率预测。
- 第 3 步的逐轮对半试价不是真实交易机制，页面 s6 明说。
- 模型失配（页面 s6 明说）：真实市场不同期限利率不同；有违约风险；有应计利息与税费；久期估算只适用于小幅变化。

## 数值结论与测试（`tests/core.cjs`）

- 格式化：只在有小数点时去尾零（90 不变成 9）；app 用的是同一实现。
- 第 0 步：本金只在最后一年；合计 = n × 票息 + 100（全部滑杆格点）。
- 第 1 步：复利验算回到 100.00；r = 0 曲线水平、r > 0 时等得越久越少；按比例远年下降更多；提示中的例子「5%→6%，1 年约少 1%，30 年约少 25%」。
- 第 2 步：价格 = 现值和；r = 票息率 ⇔ 平价（读数的平价判定只在 r = c 时触发），r 高于票息 ⇒ 折价，低于 ⇒ 溢价；最后一笔缩掉的金额最多；价格随 r 严格下降；曲线凸。
- 第 3 步：起点 4% 时价格 100；每个 r_new 格点上市场价的到期收益率 = r_new；市场价 = 100 − 票息差额现值；对半试价每轮区间减半、始终包住市场价、抬价/降价方向正确、第 12 轮误差 ≤ 0.02 且读数判定为「市场价」；收益率曲线落在 0–11% 坐标内、随要价下降。
- 第 4 步：三张债券起点均为 100；所有格点上 |变化| 2 年 < 10 年 < 30 年且同向；起点处斜率随期限增大；判断题数字 15.37% / 19.6%（凸性：降息涨幅 > 加息跌幅，三种期限都成立）；2 年期加息 1 点跌不到 2%。
- 第 5 步：零息债 D = n，有票息且 n ≥ 2 时 D < n；平衡条件 Σ(t − D)·PV = 0；票息越高 D 越小；D 随 n 每年增长 < 1；修正久期 = 价格曲线斜率；估算 ≤ 精确（低估涨幅、高估跌幅）；D < 10 年时 ±1 点估算误差 ≤ 0.652 个百分点（文案写「不超过 0.7」，由测试钉住），D 大时误差 > 1.5。
- 双语：键集与占位符一致；中英全部键不同；正文无「左图/右图」；HTML/app 用到的键都存在；深链目标页与 `#stepN` 锚点存在；对照链接目标存在；无 canvas-label-guard。
