## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：两店模型 `shopOutcomes`（8 种等可能结果，精确）、`mixSd`；`shopYears`（硬币，种子 5、17、29、43、61）；`pairYears`（正态，种子 7，ρ 只改配对方式）；`portSd`、`floorSd`；`marketWorld`（共同 + 自己部分，种子 100 + 上述种子，30 年 × 50 样）。
- 第 0、1 步柱子、第 2 步散点、第 4 步路径是**模拟**；曲线与「长期」读数由公式精确算出；读数里的「实测」都标明是本组模拟。
- 模型失配（页面「模型假设」明说）：全部数字虚构；现实相关系数会变、坏年份往往一起变大；资产平均回报各不相同；无费用和税。

## 数值结论与测试（`tests/core.cjs`）

- 两店：8 种结果枚举得平均 6、波动 17、协方差 −225、ρ ≈ −0.78；四种结果 +29/+13/−1/−17（文案引用）；天气决定正负（s0hint）；5 组实测波动在 13–20（s0hint）；mixSd = 精确枚举；U 形底在 50%、≈ 5.7、约三分之一。
- 两资产：公式 20√((1+ρ)/2)；ρ 越小越低；ρ = 1 为 20、ρ = −1 为 0 且组合每年恰为 +6%；各 ρ 第一样资产不变。
- N 资产：测验答案 19.1 且选项 c 最接近；ρ = 0、N = 40 ≈ 3.2；N 增加不增波动、永不低于地板、极限是地板；ρ = 0.9 曲线几乎平。
- 拆分：10² + 17.32² = 400、ρ = 0.25、拆分方差 = 第 3 步公式；5 组模拟中组合离共同部分的距离随 N 缩小、N = 50 时最差年与共同部分最差年相差 ≤ 5；所有实测方差在坐标范围内。
- 双语：键集与占位符一致、非符号键中英不同、无「左图/右图」措辞；所有键存在；深链目标页与锚点存在；对照链接存在；无 canvas-label-guard。
