## 定位

- category `physics`，subtopic `thermal`，stage `university`（与原版一致）。
- 受众：大学低年级；会动量、冲量、平均值，知道 PV = NkT 的形式。
- 一句话直觉：**压强是撞墙冲量的平均流量；把三维各向同性和 PV = NkT 对照，温度就是分子平均平动动能的刻度。**
- 与原版的差异（设计选择）：原版是 2D 硬盘模拟；本版是 3D 点粒子、墙光滑，因而能用**解析的撞墙记账**（逐次撞击时刻与冲量）精确测压强，不靠长时间随机模拟；单独用一步讲「1/3 从哪里来」（各向同性与有限 N 的起伏、束流反例）；温度一步用真实气体与 SI 单位；最后用随机配对碰撞模型展示速率分布如何长成麦克斯韦分布。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`bounce`/`hitsBy`（展开到周期 2L 的反射运动与解析撞击计数）、`single`、`wallLedger`（逐分子撞击账）、`pressureTheory`、`shares`/`shareSD`（Beta(N/2, N)）、`realGas`（CODATA 常量）、`maxwell`/`tail`/`tvDistance`、`relaxStart`/`relaxRound`（随机配对碰撞，守恒动量与能量）。
- 盒子模拟是**模拟**数据：速度分量为独立正态（σ = 1），mulberry32 + Box–Muller，固定种子；第 1、4 步分子互不碰撞（理想气体不需要），第 5 步才加碰撞。
- 第 3 步是公式计算（真实分子质量、SI 单位），不是盒子模拟。
- 模型失配（页面 s6 明说）：点粒子、无分子间作用；只计平动动能；高密度/低温不适用；第 5 步碰撞规则是简化模型。

## 数值结论与测试（`tests/core.cjs`）

- 解析撞击计数与位置 = 逐事件模拟（400 组随机）。
- 第 0 步：长期平均力 = mv²/L（全部滑杆格点）；首撞 t = L/v；运行平均 ≤ 2mv²/L（坐标轴不截断）；v×2 → ×4、L×2 → ÷2；默认读数 6 次撞击、恰为 1。
- 第 1 步：长时测得压强 → Σ m vₓ²/V（1%）；账本 = 逐分子之和；N = 300 的最大偏差 < N = 20 的 1/3；P/N ≈ m⟨vₓ²⟩。
- 第 2 步：份额均值 1/3、标准差 = Beta(N/2, N)（±15%）、带内比例 90–99%、0.385/√N；束流份额 1、压强 ×3；1 升空气 ≈ 2.5 × 10²² 个分子；1 atm 反算。
- 第 3 步：Xe/He 质量比 ≈ 33、v_rms 比 ≈ 5.7（判断题反馈引用）；室温 N₂ v_rms ≈ 500 m/s > 343 m/s；4T → 2v_rms；同温各气体动能相同；坐标轴容纳所有值。
- 第 4 步：曲线上 P·V 恒定；40 时间单位测量偏差 < 1%（提示引用）；V÷2 → P×2；温度 ×2 → P×2。
- 第 5 步：分布归一、尾部闭式 = 数值积分；尾部 4.6%；每轮能量、动量守恒；第 0 轮 TV > 0.85、第 1 轮减半、第 5–12 轮到抽样噪声水平；噪声底 ≈ 0.03；N₂ 300 K 的 σ、v_mp、⟨v⟩、v_rms。
- 双语：键集与占位符一致、非符号键中英不同；HTML/app 用到的键存在；深链目标页与锚点存在；对照链接目标存在；无 canvas-label-guard。
