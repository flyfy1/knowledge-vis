## 定位

- category 为 `earth`，subtopic 为 `climate`，stage 为 `senior`，均与原版一致。
- 受众：高中生。读者需要知道能量守恒、功率 = 能量 ÷ 时间，以及 sin 的含义。四次方只当作「升温时散热增长很快」来用。
- 一句话直觉：**温度是让地球能量账本收支相等的那个数**。阳光先被摊薄，再被反射掉一部分，剩下的由红外辐射送走；温室层拦下一部分红外，地面就必须升温才能把账算平。

## 页面上的数值结论（全部由 tests/core.cjs 钉住）

- S = 1361。40° 时 h = 50°，光斑拉长 1.31 倍，收到 1043 W/m²（赤道的 77%）；60° 时光斑拉长 2 倍。
- 九对纬度带按面积加权的累计平均：从 431.0 单调降到 S/4。两边的读数用同一种舍入，都显示为 340.3。
- 预设的吸收量：海洋 320、森林 289、地球平均 238、沙漠 204、新雪 68 W/m²。
- Te(0.30) = 254.6 K（约 −18 °C）。从 200 K 和 320 K 出发，10 年内都收敛到这个值。时间尺度约 1.8 年。
- ε = 0.78 时：
  - Ts = 288.1 K，大气层温度 242.2 K；
  - 地面收入 = 238.2 + 152.3 = 390.5 W/m²，等于地面发出的量；
  - 到太空合计 = 85.9 + 152.3 = 238.2 W/m²。对任意 ε、α，到太空合计都等于吸收量；
  - ε = 0 时回到 Te。
- Δε = +0.02：N0 = +3.90 W/m²，升温 1.19 K，时间尺度 2.0 年。Δα 为正时 N 为负。
- 在滑杆的全部组合上：
  - |N0| < 30，新平衡温度落在 278–298 K 以内；
  - 第 5 步两幅图按当前显示的各次模拟自动缩放坐标轴，曲线不会被截断。
