## 定位

- category `earth`，subtopic `climate`，stage `senior`（与原版一致）。
- 受众：高中；知道光合作用、溶解平衡，会读对数和指数曲线。
- 一句话直觉：**碳原子在空气里只待三四年，但多出来的碳要靠净流量才能离开；海洋缓冲因子和植物施肥效应限制了净吸收，所以排放的碳有三到五成留在空气里，停排后几百年仍剩约三成。**
- 与原版的差异（设计选择）：本版以一个五库（空气、植物、土壤、海洋表层、深海）RK4 模型贯穿全页，海洋用缓冲因子 ξ、陆地用施肥系数 β 做非线性。核心反直觉点是「记号原子」与「超额碳」的区别（第 1 步），其后依次看持续排放、汇的强弱、停排后的衰减和稳住浓度所需的排放路径。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：各库进出相等；E = 0 时 300 年不变；590 GtC ≈ 278 ppm；周转时间分档。
- 第 1 步：所有脉冲大小下，记号原子 10 年 18–22%，超额 100 年 20–30%；记号曲线与 P 无关；超额始终高于记号且随 P 增大；脉冲碳守恒。
- 第 2 步：全部 E 下空气 + 陆地 + 海洋 = 累计排放；滞留比例随时间下降、与 E 相差 < 3 个百分点；E 加倍升幅 ×1.9–2.15；516 ppm；坐标轴覆盖。
- 第 3 步：ξ 单调；β = 0 最高；ξ = 1 / 15 的一成多 / 四成多；默认 39%；轴 0–70% 覆盖。
- 第 4 步：所有 T 下停前上升、停后下降、先快后慢；T 越晚峰值与尾巴越高；459 ppm；500 年后 25–35%；轴覆盖 0–700 年、0–250 ppm。
- 第 5 步：所有目标都在 500 年内到达并保持；到达年份与初始允许排放随目标增大；允许排放单调下降；450 ppm 的 93 年、7.3/4.6/3.0。
