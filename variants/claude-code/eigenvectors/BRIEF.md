## 定位

- category `math`，subtopic `linear-algebra`，stage `university`（与原版一致）。
- 受众：大学低年级；会 2×2 矩阵乘向量、点积，见过行列式。
- 一句话直觉：**特征向量是矩阵只伸缩、不转向的方向；它由 det(A − λI) = 0 算出，决定了反复作用的去向和数据散得最开的方向。**
- 与原版的差异（设计选择）：先用一圈 24 根同色箭头看「转向」，再用偏转角曲线的零点「找」，然后用 A − λI 压扁单位圆的面积把特征方程讲成几何事实；用迹–行列式平面解释何时没有实特征方向；用幂迭代和 PCA 两个应用收尾。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：默认矩阵 λ = 2（45°）、0.5（116.565°）；b = 0 时有 90° 方向；a = −1 时 λ = −1；全部滑杆格点（41³ × 8）上 `eig2` 与暴力检验一致，复根时每个方向都被转向。
- 第 1 步：Av = p·v + 偏离部分且偏离 ⟂ v；偏转角在 [0, 180) 上恰穿过 0 两次且位置正确；精确方向通过 64ε 判定、偏半度不通过；44.5° 偏转 0.375°。
- 第 2 步：det(A − λI) 与特征多项式在整个 λ 滑杆上一致；根处被压扁的方向就是特征方向。
- 第 3 步：家族 tr = 2、det = 1 − k、判别式 4k，类型随 k 符号变化；k = 0.25 的值；旋转复根 cos30° ± i·sin30° 且每根箭头恰转 30°；剪切、数乘、反射三种类型。
- 第 4 步：三个比值 0.25 / 0.382 / 0.583，特征值 2、0.5、1.618、−0.618、1.2、0.7；全部起始方向上夹角的 tan 比趋向比值、长度倍数趋向 |λ₁|；斐波那契坐标；「接近」矩阵 λ₂ 方向恰为 135°，与主方向 78.69°；等模或复根时无主方向。
- 第 5 步：种子可复现；ρ = 0.6 的四个值；ρ = −0.9…0.9 每档：方向互相垂直、λ₁ + λ₂ = 迹、uᵀSu 等于投影的样本方差、λ₁/λ₂ 是曲线的最大/最小；ρ = −0.6 主轴 134.9°；ρ = 0 两特征值接近。
