## 定位

- category `probability`，subtopic `stochastic`，stage `university`（与原版一致）。
- 受众：大学低年级；会期望、方差、标准差，见过二项分布；不要求会推导中心极限定理。
- 一句话直觉：**N 户平摊，每户的账按 1/√N 变稳；要把赔穿概率压到 ε，附加费率随 N 才降得下来；但共同冲击给波动设了下限，统一定价会把低风险的人挤走。**
- 与原版的差异（设计选择）：统一用「每户每年 p 概率损失 1 万元」这一个两点模型贯穿全页；定价一步用二项分布精确计算 k*（并与正态近似对照，显示小 N 时近似偏低）；相关性用「暴风雨年」两状态共同冲击，给出标准差下限公式；逆向选择用逐轮重新定价的死亡螺旋，并与按风险定价对照。

## 数值结论与测试（`tests/core.cjs`）

- 二项 pmf 求和为 1，尾概率边界值。
- 第 0 步：默认历史 N = 1 恰 2 年 1 万元；种子 7–30 × 4 个 p × 5 个 N 上分摊 = 理赔数 × L ÷ N；N = 100 最多不超过 600 元；N = 10000 每年在 60–140 元；理论标准差公式。
- 第 1 步：N = 100 / 10000 的实测标准差约 100 / 约 10 元；每个 N 实测标准差、均值在理论值的统计容差内；坏年份概率 N ≥ 100 单调降、小 N 非单调；点都在坐标范围内。
- 第 2 步：三种 ε × 9 个 N 上 k* 是满足条件的最小值、θ 与保费公式一致、随 N 单调降、ε 越严越高；N = 10 时 900%，N = 100 时 300% 与近似约 231%，N = 10 万时 7.4%；1000 → 100000 比值在 8–13；ε = 1% / 0.1% 且 N ≤ 300 时正态近似明显偏低。
- 第 3 步：默认下限 120 元、N = 1000 起与下限差 < 6%、N = 100 时仍高 30% 以上；N = 10000 时独立 < 12 元、有冲击 > 120 元；种子 2 有 5 个暴风雨年，其柱高超过普通年份最大值 3 倍；滑杆全网格上 N → ∞ 收敛到下限、无冲击时两线重合、柱与曲线都在坐标内。
- 第 4 步：平均风险约 2.1%；m = 0 第 4 轮清空；m = 100% 留下 27–33%；m = 300% 离开 37–43%；m 全网格上池子只缩不涨、保费只升不降、稳定时确实无人再走、点与保费在对数坐标内；按风险定价 m ≥ 10% 全留。
