## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：MB = 100 − Q，MPC = 20 + dQ（默认 d = 1），外部损失 e 每吨固定；`privateSurplus`、`unitGain`、`socialQ`、`welfare`、`deadweight` 与闭式 `deadweightFormula`、`taxedQ`、`taxWelfare`、`commonsPath`（轮流最佳回应，轮数 ⌈10 + 2.5m⌉）、`extraCow`、`coase`。
- 本页没有随机模拟；第 4 步路径是确定性的最佳回应迭代。
- 失配（终章明说）：真实损失随排放变化且难测；征税成本为 0；牧人对称、头数可为小数、收敛路径依赖调整顺序（均衡不依赖）；中点分账只是一种分法；多受害者时谈判昂贵。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：Q_m = 40、P = 60、买方/卖方剩余各 800、总剩余 1600 且为最大；总剩余 = 两线间面积（数值积分）；第 1–40 吨净赚、之后亏。
- 第 1 步：Q* = (80 − e)/2；MB = MSC；e 取偶数时粉柱合计 = 全社会净收益之差 = 无谓损失（滑杆步长 2 由测试钉住）；默认 e = 20 时 30 吨、损失 800/600。
- 第 2 步：全部 (e, d) 格点上 DWL = 闭式 = ½·e·gap、gap = e/(1 + d)；e 减半损失变 1/4；d 越大损失越小；e = 20/40 时 100/400。
- 第 3 步：全部 e 上 argmax_t W = e；Q(e) = Q*；税低 → 过多、税高 → 过少；W 定义（税收不扣）。
- 第 4 步：N* = 40、利润 1600；对每个 m ≤ 20，对称均衡是最佳回应、利润占比 4m/(m+1)²、路径从 40 出发且终点距均衡 < 0.1、数值在坐标范围内；m = 5 时 66.7；开始时多放一头对个人有利、对全村有害。
- 第 5 步：全部 (G, D, T) 格点上：|G − D| > T 时两种产权结果相同且有效；T = 0 时总是有效；「谈不成」带的位置；付款在可谈范围内；合计 = 净收益 − 交易成本；默认值（60, 80, 5）。
- 双语：键集与占位符一致、中英文本不同；HTML/app 用到的键存在；深链与锚点存在；对照链接存在；占位注释与 provenance 样式引入；未引入 canvas-label-guard。
