## 定位

- category `math`，subtopic `arithmetic`，stage `primary`（与原版一致）。
- 受众：小学中高年级与家长；会背九九表、会一位数乘法、知道除法和余数，但不知道乘法「为什么」是这个数。
- 一句话直觉：**乘法是在数一块长方形地上的砖：每行一样多时，「一行一行加」就是乘；交换律是把地转个方向，分配律是把地切开，竖式是切成四块。**
- 与原版的差异（设计选择）：原版从点阵与面积切入。本版第 0 步先比较「一个一个数」和「一行一行加」两种数法（动画进度可见），并用「最后一行少放一个」反例点明乘法的前提；第 1 步用真实的 90° 旋转动画看交换律（不交换滑杆，只转画面）；第 2 步的分配律带一张「每个试过的切法」历史柱图，所有柱子一样高，把「总和不变」画出来；第 3 步四块面积与竖式两行逐行对应（并处理个位为 0 的情形）；第 4 步把砖按「每列 w 块」摆，最后一列不满处画出空位，连接余数与因数，并在质数时点明。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部 r, c：r × c = 总数、行累计、行数 ≤ 个数；少放一个时乘积恰好多 1。
- 第 1 步：逐块计数 = a × b = b × a（全部滑杆组合）。
- 第 2 步：全部行、列、切点：两块之和 = 整块；7 × 13 切在 10 = 70 + 21。
- 第 3 步：m, n ∈ 11..29 全部组合：四块之和 = m × n；竖式第一行 = 右两块、第二行 = 左两块；个位 0 时那条面积 0；12 × 13 = 100 + 30 + 20 + 6 = 156；23 × 15 = 200 + 100 + 30 + 15。
- 第 4 步：N ∈ 1..48、w ∈ 1..12：N = q·w + r、整除判定、缺口数；所有因数对的小因数都在 w 滑杆范围内（保证每对都能找到）；24 有 4 对、13 是质数、36 有 5 对、w = 8 与 w = 3 算同一对。
- 第 5 步：三题的答案与解析里的数。
