## 定位

- category `investment`，subtopic `basics`，stage `junior`（与原版一致）。

## 数值结论与测试（`tests/core.cjs`）

- 文案中的设定数字（100 股、100 元、5000、8%、400、80、1000）与模型一致；两种选择都花 1000。
- 第 0 步：k 股 = k%、一股一票、利润 = 分红 + 留存、你的分红 = 比例 × 分红、利润 0 无分红（全部滑杆格点）。
- 第 1 步：每年票息 = 1000c、本金只在最后一年、总额公式、不超出坐标范围。
- 第 2 步：利息 + 剩余 = 经营利润；债券在利润 ≥ −600 时恒为 80、以下才下降；交点 1200 两侧大小关系；8 年无违约、债券 640、股票 1160、有亏损年与 >300 的好年；全部在坐标范围内。
- 第 3 步：钱全部分完；V ≤ 5000 股东 0、之后债主封顶；债券最多 1000；小测 4000 → 股票 0、债券 800；12000 → 股票 700。
- 第 4 步：好消息下价格与成交量单调不降；成交对都接受价格、下一对不会同时接受；±30 时涨跌方向；全部在坐标范围内。
- 双语键集与占位符、非空且中英不同、无「左图/右图」；HTML/app 键存在；深链与锚点存在；对照链接存在；未引入 canvas-label-guard。
