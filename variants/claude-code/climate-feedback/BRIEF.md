## 定位

- category `earth`，subtopic `climate`，stage `senior`（与原版一致）。
- 受众：高中；会对数的基本含义、一次函数、等比数列求和的直觉；不要求微积分（第 4 步的指数解只读不推）。
- 一句话直觉：**CO₂ 先让支出少一截（强迫 F）；地球只能靠变暖把账配平；反馈让每一份变暖再引出一笔收入，所以最终升温 = F ÷（普朗克响应 − 反馈之和）。**
- 与原版的差异（设计选择）：原版是因果链 + 反馈卡片 + 误解辨析。本版把全页做成一本「账」：每步都是账上的条目（瀑布式条形账目），反馈用「一轮一轮结账」的等比级数讲清增益从何而来，再加入时间（海洋热容）与碳账（碳汇份额），所有参数取 IPCC AR6 中心值并标明。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`forcing`、`imbalance`、`equilibrium`、`gain`、`ledger`、`rounds`/`roundsTo`、`fbSum`、`heatCap`、`oneLayer`（闭式）与 `oneLayerEuler`（数值对照）、`ppmRate`/`ppmAt`、`eqWarming`。
- 常数：S0 = 1361、反照率 0.30、λP = 3.22、水汽 1.30、冰雪 0.35、云 0.42（范围 −0.10–0.94，AR6 表 7.10）；5.35 ln(C/280)（Myhre 1998）；1 ppm = 2.124 GtC；海水 ρc_p = 4.18e6 J/m³/K，海洋占 71%。
- 失配（页面 s4、s5、s6 明说）：零维全球平均；反馈当常数；无气溶胶（所以 420 ppm 的平衡值 1.89 K 高于观测约 1.2 K）；单层海洋；碳汇份额固定、排放为 0 时浓度不回落。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：收入 238.2；F(560) = 3.71；每次加倍、减半强迫相等；滑杆范围内缺口最大约 3%（1120 ppm）；支出条始终在 220–248 轴内。
- 第 1 步：有效辐射温度 ≈ 255 K、4σT³ = 3.74；普朗克平衡 1.15 K；0.05 网格上只有 1.15 报「账平」；账目求和 = N。
- 第 2 步：全部 f 格点上 400 轮和收敛到 F/(λP − f)、增益 = 1/(1 − r)、95% 所需轮数 ≤ 12 且是第一个越过 95% 的轮；1.65 = 水汽 + 冰雪。
- 第 3 步：中心 ECS 3.22、两端 2.22 / 5.89；上端增量 > 2.5 倍下端；四种勾选下曲线都凸；去掉水汽后范围缩小一半以上；云滑杆格点含 −0.10、0.42、0.94；处处稳定。
- 第 4 步：8 个深度上 τ 时 63%、3τ 时 > 95%；N + ΛT = F；欧拉积分 = 闭式（≤ 2e−3）；τ 在 2–17 年；更深更慢。
- 第 5 步：2.12 GtC/ppm；s 降低越过 560 更早；默认 66 年越过；E = 0 停在 420；最大设置在两轴内；420 ppm 平衡值比 1.2 K 高 0.5 K 以上。
- 双语：键集、占位符一致；中英不同（符号键 `s4lgTau` 例外）；无「左图/右图」；HTML/app 用到的键都存在；深链目标与锚点存在；对照链接存在；格式化不把 90 变 9。
