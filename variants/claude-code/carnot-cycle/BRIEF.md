## 模型、模拟设定与失配

- `model.js`：`pressure`、`isoWork`、`stripSum`（中点规则）、`adiabatV/T`、`cycle`（四状态、四段 Q/W/ΔU、熵）、`pointAt`（循环上的点，V 按几何插值）、`loopArea`（鞋带公式，独立于各段公式）、`cumWork`、`axisFor`（固定坐标：取 T_c = 250 K 的最宽循环，拖 T_c 不重新缩放）、`ledger`、`copFridge/copPump`。
- 设定：1 mol 单原子理想气体，γ = 5/3，V₁ = 10 L，全程可逆。是模型计算，不是实测。
- 失配（s6 boundary 明说）：真实热机有摩擦、有限温差传热、有限时间，效率低于上限；本页不模拟损耗。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：细条和→nRT ln r（全部滑杆格点）；中点误差随 N 单调减小，N = 40 时 < 0.05%；10→20 L 与 20→40 L 功相等；面积 ∝ T。
- 循环：绝热线 TV^(γ−1) 守恒；每段 Q = ΔU + W；等温 ΔU = 0、绝热 Q = 0；ΔU 一圈为 0；W = Q_h − Q_c；T–S 矩形面积 = W；鞋带面积 = W；η = 1 − T_c/T_h 与 r 无关（全部 T_h × T_c × r 格点）；循环落在固定坐标内。
- 第 1 步：累计功在膨胀段单调升、压缩段单调降、恒非负、终点 = W；沿 T_h 原路压回净功 0；W 随 T_c 增大而减小；默认值 Q_h 3458 J、Q_c = W = 1729 J。
- 第 4 步：卡诺效率处总熵 = 0；以下全正、以上全负（全部格点）；默认上限 62.5%。
- 第 5 步：COP_热泵 = COP_冰箱 + 1；冷端越冷 COP 越小；COP 在 1–100 对数轴内；默认 5.32。
