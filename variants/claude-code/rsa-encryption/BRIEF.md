## 模拟设定与失配

- 第 0 步为浏览器**实测**：b 位时取 2^(b/2) 以下最大的两个质数 p > q，试除计数 = 1 + (q − 1)/2（先试 2，再试奇数）。乘法代价按竖式一位数乘法次数 = 位数(p) × 位数(q)。
- 第 1–5 步的数全部精确计算（n ≤ 1081，乘积 < 2^53，不需要 BigInt）。
- 第 5 步下图：试除 ≈ 2^(L/2−1)；GNFS ≈ exp((64/9)^(1/3)(ln n)^(1/3)(ln ln n)^(2/3))；合法解密 ≈ 1.5·L³ 次位运算；一年 = 10^18 × 3.156×10^7 ≈ 10^25.5。均为量级估算，页面 boundary 注明，并给出 RSA-250（829 位，2020 年约 2700 核年）作为对照。
- 失配（s6 boundary 明说）：教科书 RSA 无填充（第 3 步看到的不动点即其漏洞）；无签名；不模拟量子计算；实际用途多为交换对称密钥或签名。

## 数值结论与测试（`tests/core.cjs`）

- 快速幂 = 逐次相乘（n ≤ 60、E ≤ 70 全枚举）；乘法次数 = 平方 + 再乘，且 L−1 ≤ 次数 ≤ 2(L−1)；阶梯末行指数 = E。
- 第 0 步：17 种位数、p/q 为最大两质数、n 恰为 b 位、试除停在 q、计数公式；相邻位数比值 1.85–2.55；b ≥ 16 时 q 距 √n < 2%；乘法 4 → 49；默认范围比值 2.12。
- 第 1 步：n = 3..36 全部 a：互质 ⇔ 回到 1 且循环长度整除 φ 且 a^φ ≡ 1；n = 14、a = 5 的序列与长度 6；提示中的空心例 2、4、7；存在循环长度 < φ 的例子；φ(pq) = (p−1)(q−1)。
- 第 2–5 步：全部 336 把钥匙（7 × 6 × 8）：e·d = kφ + 1、散点恰一个在高度 1、欧几里得每行不变式、t → d；全部明文往返（173280 次）；不动点数 = (1+gcd(e−1,p−1))(1+gcd(e−1,q−1)) ≥ 9；n−1 不动；窃听者试除得 p < √n 且恢复的 d 一致。默认钥匙 319 / 280 / 187。
- 量级：GNFS(2048) ≈ 10^35.2；一年线 10^25.5；滑杆格点上首次越过一年线在 1024 位（960 位未越过）；试除在 ≤ 448 位冲出图顶；合法代价全程 < 10^12；2048 位 ≈ 10^9.7 年；2048 位指数快速幂 4094 次、逐次 10^616；2048 位 ≈ 617 位十进制。
