## 定位

- category `math`，subtopic `algebra`，stage `junior`（与原版一致）。
- 受众：初中生 + 家长；会在坐标系里描点。
- 一句话直觉：**每一步变化同样多 → 点排成直线；「每步变多少」是斜率 k，「出发时多高」是截距 b，合起来 y = kx + b。**
- 与原版的差异（设计选择）：用「温室每小时温度变化」引入，并给出「变化越来越大」的对照（点弯成曲线），说明「直线」的条件；斜率用「任意两点的竖直变化 ÷ 水平变化都相同」来定义，并保留试过的三角形；截距一步同时显示三处点的平移距离；增加「两点定一条线」（反求 k、b，含分数与竖直线）；交点一步用「高度差柱状图」解释为什么斜率相等就永不相交。

## 模型

- `model.js`（浏览器与 node 共用）：`readings`（等量 / 变化量每步增加 k/4）、`diffs`、`onOneLine`、`riseRun`、`fmt`（真负号、至多 2 位小数）、分数 `frac` / `fstr`、`eq`（书写习惯：1 省略、−1 写 −x、0 项省略、负常数写「− |b|」、分数斜率加括号）、`through`（两点 → 约分后的 k、b，或竖直 / 重合）、`meet`（交点、平行、重合，高度差每步变化 k₁ − k₂）、`gap`、`QUIZ`、`quizAnswers`。
- 第 1–5 步的坐标平面横纵等比例（1 横 = 1 纵），所以三角形和陡度看起来与数值一致；第 0 步横轴是小时、纵轴是 °C，不等比例（图中注明）。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：k 滑杆全部取值下等量模式共线且 = kx + 2，增长模式除 k = 0 外不共线、变化量逐步变大；所有读数落在 −12..16 的显示范围内；变化量用 3 位小数可精确显示。
- 第 1 步：k × A × B 全部滑杆组合，比值 = k；A = B 无比值；点都在显示范围内。
- 第 2 步：改 b 时任意 x 处移动距离 = Δb；b 是 x = 0 时的 y。
- 第 3 步：方程书写表（k ∈ {−3, −1, −0.5, 0, 0.5, 1, 2, 3} × b ∈ {−2, 0, 3}，外加分数情形）逐条断言，并把文字反解析成算式对照 kx + b；默认探针 y = 2 × (−3) + 1 = −5。
- 第 4 步：−5..5 全部 P、Q 组合（14 641 组）：直线过两点、分数已约分；默认 P(−2, −1)、Q(4, 3) → y = (2/3)x + 1/3；提示里的 (0, 1)、(2, 5) → k = 2、b = 1。
- 第 5 步：k₂ × b₂ 全部组合：交点 x = (b₂ − 2) ÷ (0.5 − k₂)、两式相等、高度差为 0、高度差每步变 0.5 − k₂；k₂ = 0.5 时平行或（b₂ = 2）重合；默认交点 (−2, 1)。
- 测验：y = −x + 2；2 × 5 + 8 = 18；3x + 10 = 5x → x = 5（25 元）。
