## 定位

- category `chemistry`，subtopic `solutions`，stage `junior`（与原版一致）。
- 受众：初中（九年级「溶液」单元）；知道质量守恒、会看折线图。
- 一句话直觉：**一定温度下一定量的水能溶的溶质有上限（溶解度）；到了上限就是饱和——溶解和结晶仍在进行，只是一样快。上限随溶质、水量、温度变；饱和不等于浓。**
- 与原版的设计差异：
  - 第 0 步用「加到不化」的杯子 + 质量刻度，同时引出溶解度和水量的比例关系；
  - 第 1 步用带固定种子的粒子模型和「放入带标记的晶体」实验，展示饱和是动态平衡；
  - 第 3 步把三种物质的「质量分数随放入量」画在一张图上，用氢氧化钙反驳「饱和 = 浓」；
  - 第 4 步把降温结晶和蒸发结晶放在同一对烧杯上对比。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`S`（表值插值）、`mix`、`dissolveAllT`、`crossing`、`crystallise`、`makeSim`（固定种子 mulberry32 + 泊松溶解 + 逐粒结晶）、`smoothRates`（4 秒滑动平均）。
- 第 1 步的粒子模型：溶解按固定速率（有固体时），结晶按每个已溶微粒的固定概率，所以平衡时已溶数 = KD/KC = 360 个 = 36 g；只有在有固体或溶液超过上限时才会结晶。
- 失配与说明（页面 boundary 明说）：溶解度为常用表值并线性插值；不考虑过饱和、结晶水、溶解热；粒子模型的速率是教学取值，抖动幅度（约 ±2 g）来自有限粒子数。

## 数值结论与测试（`tests/core.cjs`）

- **第 0 步**：滑杆全部格点上「饱和 ⇔ 放入 ≥ 上限」、质量守恒、上限 ∝ 水量且不超出 0–100 g 刻度；36 g 恰好饱和；默认 40 g 在 200 g 水中全溶。
- **第 1 步**：上限 36 g = 第 0 步溶解度；溶解速度 3.6 g/s；滑杆格点都是整数个粒子；≤ 36 g 全溶且速度归零；> 36 g 时 40 s 前到达上限、40–90 s 平均在 36 ± 2.5 g、两速度相差 < 10%、前 3 秒溶解快于结晶；600 s 长跑平均 36 ± 0.5 g；标记晶体加 3 g 固体、多数标记微粒进入水中；所有曲线在 60 g、6 g/s 轴内；固定种子可重复。
- **第 2 步**：KNO₃ 60 g 全溶温度 37.85 °C（文案 38）；交点 23.17 °C（文案 23），两侧大小关系；NaCl 0–100 °C 全程 < 40 g；纵轴 260 g 够用。
- **第 3 步**：所有格点质量分数 < 75% 轴、不超过饱和值 S/(100+S)；Ca(OH)₂ < 0.2%；KNO₃ 60 °C 50 g = 33% 不饱和；小测 20% vs 0.16%，答案 B。
- **第 4 步**：169 g / 38.4 g；80→20 °C 析出 137.4 g（81%）与 2.4 g（6%）；格点上 留下 + 析出 = 原有；只蒸发时比例 = 蒸发量/100。
- **格式**：只在有小数点时去掉末尾 0（90 不会变成 9）。
- **双语与链接**：键集与占位符一致；中英文不同；页脚含模型 id；无「左图/右图」；HTML/app 用到的键都存在；深链目标与锚点存在；对照链接存在；无 canvas-label-guard。
