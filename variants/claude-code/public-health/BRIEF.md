## 定位

- category `biology`，subtopic `body`，stage `senior`（与原版一致）。
- 受众：高中生；会百分数、指数、读坐标图；不要求学过微分方程（SIR 用「每天新增 = …」的语言写出）。
- 一句话直觉：**涨跌看 Rₑ = R₀ × S：易感者被消耗到 1/R₀ 时到顶；干预只在实施期间压低 Rₑ，人群没有免疫时只会推迟；疫苗直接降低起始 Rₑ；阳性结果的分量取决于患病率。**
- 与原版的差异（设计选择）：原版四步（传播曲线、检测四格、干预取舍、收束）。本版七步：先用代际传播树讲 R₀ 与指数增长，再给出整条 SIR 曲线，单独一步讲「为什么会到顶」（Rₑ = 1 与过冲），干预一步用三个预设对比「推迟 vs 压低」，另加疫苗临界接种率一步，最后才是检测与 PPV，并可把第 1 步曲线的高峰当作检测的患病率。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`generation`、`cumulative`、`tree`（每代 round(R₀ᵏ) 个，均分给上一代）；`sir`（RK4，0.1 天步长，每天取样，算到第 720 天）、`summary`（峰、到顶日、最终规模 = 1 − 免疫 − S 终值、超承载线天数）、`finalSize`（z = 1 − e^(−R₀z) 二分）、`peakFormula`、`herdThreshold`、`effectiveR`、`window`、`vaccineThreshold`；`testCounts`、`testGrid`（最大余数取整）。
- 全部是**确定性模拟**，没有实测数据。第 2、3、4 步共用 R₀ = 2.5、D = 7 天的基线；第 1 步可改 R₀、D；第 5 步的患病率默认独立设定，可选用第 1 步曲线的峰值。
- 失配（boundary 明说）：均匀混合、参数固定、无潜伏期、无出生死亡、终身免疫、无偶然灭绝、干预按统一比例；不是预测，不是医疗、公共卫生或政策建议。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：R₀ = 2.5 第 10 代 9537 例、累计 15894 例；R₀ = 0.8 累计极限 5 例；传播树每代 = round(R₀ᵏ)、每人子代数相差 ≤ 1。
- SIR：S + I + R = 1；最终规模与闭式解差 < 2e−4（多组 R₀ < 1e−3）；峰高与 1 − (1 + ln R₀)/R₀ 一致（日取样误差 < 2e−3）。
- 第 1 步：默认第 45 天到顶、23.4%、最终 89.3%；D = 3/14 时第 19/90 天到顶，峰高 23.3%–23.4%，最终都是 89.3%；R₀ 单调；滑杆网格（R₀ ≥ 1.3）上 720 天内流行结束、峰在自适应横轴内（R₀ 下限因此定为 1.3）。
- 第 2 步：Rₑ 在第 44–45 天穿过 1，之前 I 逐日上升、之后逐日下降；到顶时 S ≈ 40%；阈值 60%；过冲约 29 个百分点。
- 第 3 步：基线超承载线 38 天；三个预设的峰、到顶日、最终规模、超线天数（22.9%/第 105 天/89.1%；5.9%/76.1%/29 天；第 345 天/23.3%）；强而长解除时 Rₑ ≈ 2.5；粗网格上所有组合 720 天内结束；c = 0 或 0 天时与基线完全相同。
- 第 4 步：临界接种率 66.7%；40% 接种最终 41.1%；效力 < 60% 时不可达；全网格上起始 Rₑ ≤ 1 时感染者从不上升；最终规模随接种单调下降。
- 第 5 步：默认 TP 90、FP 495、FN 10、TN 9405、PPV 15.4%；患病率 20% → 81.8%；特异度 99% → 47.6%；灵敏度 99% → 16.7%；网格计数总和恒为 10,000 且与期望值差 < 1。
- 双语：键集与占位符一致、非中性键中英不同；文案数字中英文都出现；不出现「左图/右图」；带标签的字符串只走 `data-i18n-html`；键、控件、深链锚点、对照链接都存在；未引入 `canvas-label-guard.js`。
