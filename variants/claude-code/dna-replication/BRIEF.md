## 定位

- category `biology`，subtopic `cells`，stage `senior`（与原版一致）。
- 受众：高中生；知道细胞有细胞核、DNA 是遗传物质；不要求学过分子生物学。
- 一句话直觉：**配对让一条链决定另一条；所以复制是「拆开各当模板」，造蛋白质是「抄一段（转录）再三个一组地读（翻译）」。改一个字母的后果，要沿这条线算到底。**
- 与原版的差异（设计选择）：半保留复制不直接宣布，而是让读者在三种历史猜想间切换，用 Meselson–Stahl 离心带逐代排除（全保留在 g=1、弥散在 g=2 被排除）；新增复制叉一步（5′→3′ 限制 → 前导链连续、冈崎片段），原版明确略去了方向；突变一步加了「本基因全部单碱基替换按密码子位统计」，让「第 3 位多为同义」成为看得见的现象。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`complement`、`hbonds`、`randomStrand`（mulberry32，可复现）；`generation`/`bands`/`observed`（三种猜想的分子与带；实测 = 1958 年结果，等于半保留预测）；`fork`、`ecoliMinutes`；`GENE`（自编 10 个密码子的基因 ATG GCT TGG AAA GAG TTC TGT CAG GGA TAA，肽链 MAWKEFCQG）、`templateOf`、`transcribe`、标准密码表 `aaOf`、`translate`、`protein`；`mutate`、`classify`、`substitutionTally`。
- 失配（页面 s6 明说）：序列为演示编造；单复制叉、无解旋酶/连接酶/校对；转录无启动子/内含子；翻译无 tRNA；复制速度是大肠杆菌值。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：默认链 30 条氢键、G–C 6；399 条随机链上「氢键 = 24 + GC」、互补两次回到原链。
- 第 1 步：全保留在 g=1、弥散在 g=2 第一次与实测不符，半保留各代一致；中间带恒为 2 个分子、占 2/2ᵍ；重材料守恒；家谱连线的亲代确实含旧链；弥散条纹比例精确；自测答案 2/8。
- 第 2 步：全部滑杆格点上「前导 = 打开长度」「后随完成 + 空当 = 打开长度，空当 < 片段长」「引物 = 片段 + 1」；默认读数 3 片段 / 300 空当 / 4 引物；大肠杆菌约 38 分钟。
- 第 3 步：每个滑杆值上 mRNA 前缀 = 编码链前缀（T→U）。
- 第 4 步：64 个密码子、3 个终止、20 种氨基酸、Leu 6；表格抽查；正确框 10 个密码子以 UAA 结束；错开 1、2 个字母无终止、氨基酸几乎全变。
- 第 5 步：提示中的三个例子（同义/错义/无义）；每处单碱基插入/删除都是移码；TAA→TAC 终止丢失；统计 27/27/27、同义 0/0/11；全表验证第 2 位替换从不同义。
- 双语：键集与占位符一致、非符号键中英不同、页脚含模型 id、正文不出现「左图/右图」；HTML/app 引用的键都存在；深链目标与 `#stepN` 锚点存在；对照链接目标存在；不引入 canvas-label-guard。
