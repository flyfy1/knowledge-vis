## 定位

- category `signal`，subtopic `control`，stage `university`（与原版一致）。
- 受众：大学低年级；知道均值、方差、标准差，见过正态分布钟形曲线；第 4 步用到 2×2 矩阵乘法。
- 一句话直觉：**K 不是调出来的，是「让合成估计方差最小」解出来的**；其余一切（K 随证据下降、稳态锯齿、估出没测的速度、断测时误差增长）都是这一条加上「预测会让方差变大」推出来的。
- 与原版的差异（设计选择）：第 0 步让读者亲手拖权重 w，在方差曲线上找到最低点，K 当场「被发现」；第 1 步把卡尔曼与算术平均、过分自信的先验对照；第 3 步专讲 Q 假设失配（实测 RMSE vs 滤波器自报 σ）；第 5 步讲测量中断。全页一个场景：直走廊上的小车 + 激光测距。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`blend`/`fuse`（第 0 步）、`staticRun`（第 1 步，含闭式 P_k = 1/(1/P0 + k/R)）、`varianceRun`/`steady`/`settleStep`（第 2 步，标量 Riccati 稳态闭式）、`walkScene`/`trackRun`/`tuningCurve`（第 3 步）、`cvRun`/`ellipse`/`corr`（第 4 步，2×2 矩阵）、`gapRun`/`gapStats`（第 5 步）。
- 所有数据都是**模拟**：mulberry32 + Box–Muller，固定种子 11/23/37/41/59（「换噪声」在其中轮换），第 5 步固定种子 7。
- 失配与限度（页面 s3e、s6 boundary 明说）：只适用于线性高斯模型；Q、R 假设错时自报误差不可信；第 3 步的「最低点在 0.28/0.35」「相差 20% 以内」只对本页 5 段数据成立。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全滑杆网格上 K 是 (1−w)²P + w²R 的最小点；合成 σ 小于两者；「设成最优 K」后超出最优 < 0.1%。
- 第 1 步：闭式 P_k；K 单调下降；σ₀=10 时 K≈1/k（±0.003）、估计≈平均（±0.01 m）、σ≈σᵣ/√k；σ₀=0.1 时 5 组种子第 30 次估计 < 4.5 m 且真值在 ±2σ 带外。
- 第 2 步：迭代收敛到闭式稳态；预测后总高于更新后；settleStep 之后 K 都在 K∞ 的 1% 内；K∞ 随 σ_q 单调增。
- 第 3 步：5 组种子的 RMSE 最低点在网格 0.28 或 0.35；网格 0.28/0.35 处自报与实测相差 ≤ 20%；最小 5 个网格点自报 < 实测的 1/4；调好时 RMSE < 测量 RMSE 的 0.65 倍；σ_q=3 时 RMSE > 测量 RMSE 的 0.85 倍。
- 第 4 步：ρ 在第 1、2 秒转正并增大；测量期间 σ_v 不增；K_v > 0；椭圆在两种缩放下都在坐标范围内；默认数据第 10 秒起 |v̂ − v| < 0.25；P 更新 = (I − KH)P⁻；2σ 椭圆概率 1 − e⁻² ≈ 86%。
- 第 5 步：中断中 σ_p 上升且方差增量递增；开始于第 5 秒比第 20 秒涨得多、σ_v 大 3 倍以上（全部持续时长）。
