## 定位

- category `math`，subtopic `algebra`，stage `junior`（与原版一致）。
- 受众：初二前后；会平面直角坐标系、正比例。
- 一句话直觉：**乘积不变就是反比例**。面积固定的长方形，右上角的轨迹就是双曲线。
- 与原版的差异（设计选择）：原版的长方形与双曲线分开讲；本版把长方形的左下角钉在原点，让「试过的右上角」留下轨迹，直接长出双曲线；完整给出 k < 0 的两支与象限；单设「碰不到轴」一步（缩放显示范围 + 逐行记录 y 值）；判别一步加入两个「都不是」的反例（周长固定的长方形、正方形面积）；现实一步对比「离散的人数」与「有范围的速度」；求值一步可以输入任意数并在检查后画出曲线。
