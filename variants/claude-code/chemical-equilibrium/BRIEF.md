## 定位

- category `chemistry`，subtopic `reactions`，stage `senior`（与原版一致）。
- 受众：高中生与自学者；知道反应速率、浓度的概念。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`probs(T, cat)`（阿伦尼乌斯缩放）、`K`、`xEq`、`expectedB`（独立粒子的精确期望）、`settleTicks`（期望差距降到 5%）、`Sim`（mulberry32 种子化；记录每步 B 数与正/逆事件数）、`catalystRun`、`measureShare`。
- 种子：第 0 步 101、第 1 步 202（纯 B 时 402）、第 2 步 303、第 3 步实时 404、测量 7、第 4 步 41。
- 失配（页面终章明说）：单步单分子反应、概率固定且独立、粒子移动仅示意（无碰撞）；温度参数为教学设定；真实反应可能多分子、受压强体积影响；模拟有随机涨落。

## 数值结论与测试（`tests/core.cjs`）

- 300 K 下 p正 2%、p逆 3%、K ≈ 0.67、B 占比 40%（A 120 / B 80）；文案里的参数（30/20 kJ/mol、+10、3.5、2%、3%、0.67）与模型一致；全温度范围概率有效。
- 期望曲线 = 300 次种子模拟的平均（t = 10/30/60/150，误差 ≤ 1.2 个）；走平时刻 59 步（第 58 步时差距仍 > 5%）。
- 第 1 步：纯 A、纯 B 两次运行在 100–300 步平均 B ≈ 80（±6），该段正/逆事件数相差 < 10%；事件账：正 − 逆 = B 的变化；早期正反应占优。
- 第 0 步：600 步内 B 在 55–105 之间，两累计次数都 > 1000 且相差 ≤ 30，几乎每个粒子都转变过。
- 第 2 步：加 A 后 Q < K；新平衡 B ≈ 100、A ≈ 150（±8），A 仍高于 120；加 B 后 Q > K。
- 第 3 步：占比随温度单调上升、= K/(1+K)；260–340 K 每 5 K 的实测与公式差 ≤ 2 个百分点；26.5% / 51.7%；升温两概率都升、正反应升得多。
- 第 4 步：各温度下催化剂不改 K、两方向倍数相同；300 K 倍数 4.1；走平 59 vs 14 步（约 4.2 倍）；两组终点占比都在 40% ± 2 个百分点内且彼此相差 < 2 个百分点；纵轴 0–120 覆盖。
- 双语键集与占位符一致；无「左图/右图」；深链与锚点存在；对照链接存在；无 canvas-label-guard。
