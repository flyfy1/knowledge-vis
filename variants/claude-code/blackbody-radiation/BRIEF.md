## 定位

- category `physics`，subtopic `modern`，stage `senior`（与原版一致）。
- 受众：高中生；知道光是电磁波、知道指数函数和开尔文温度；不要求微积分（面积 = 求和，用图说明）。
- 一句话直觉：**黑体的光只由温度决定。峰的位置读温度，曲线下面积读散热快慢，短波端的下坠逼出了「能量一份一份」。**
- 与原版的差异（设计选择）：原版按「颜色 → 光谱 → 维恩 → T⁴ → 紫外灾难 → 能量子」逐条讲；本版同样的知识点，但①第 0 步用 CIE 配色函数从光谱算出显示颜色，把「颜色」和「可见光段在光谱中的位置」放在同一张图里讲因果；②第 2 步把光谱按峰值归一后画在对数波长轴上，展示「形状不变、只是平移」，并用双对数图把反比画成直线；③第 3 步用「高 ×32、宽 ÷2」解释 T⁴，而不只是给公式；④第 5 步把普朗克定律拆成「模式数 × 每模式平均能量」，用能级梯子上的概率条直接显示短波模式为什么是空的。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`planck`、`rayleighJeans`、`modeFactor`、`meanEnergyRatio`、`occupancy`、`peakNumeric`（对 ln λ 黄金分割搜索，与 b/T 独立）、`integrate`（ln λ 网格上的辛普森积分）、`totalNumeric`、`visiblePower/Share`、`rjTail`、`rjValidLambda`、`cmf`（CIE 1931 2° 配色函数的多高斯拟合，Wyman, Sloan & Shirley 2013）、`colorOf`（光谱 × 配色函数 → XYZ → sRGB，负通道截断、最亮通道归一）、`lineColor`。
- σ 与 b 由 h、c、k（SI 2019 精确值）推出，不手写。
- 所有曲线都是公式计算，无噪声、无「实测」数据；预设温度（人体 310 K、炭火 1000 K、灯丝 2800 K、太阳 5772 K、天狼星 9940 K）是常用近似值。
- 失配（页面 s6 明说）：真实物体发射率 < 1 且随波长变；恒星有吸收线；显示颜色亮度拉齐，屏幕无法显示真实亮度差；按每单位频率计时峰位置不同。

## 数值结论与测试（`tests/core.cjs`）

- σ ≈ 5.67×10⁻⁸、b ≈ 2.898 mm·K 由常数推出；维恩 x 满足 x = 5(1 − e⁻ˣ)。
- 250–12000 K 每 10 K：数值找峰 = b/T（相对误差 < 10⁻⁶）；归一光谱只依赖 λT（「形状相同、只是平移」）。
- 人体峰 ≈ 9.35 μm，是 0.75 μm 的 12–13 倍；五个预设中只有太阳的峰在可见光内；1500 K 的峰在 2000 nm 附近。
- 颜色：1000 K 红橙、5772 K 近白、9940 K 蓝白；600–5000 K 蓝通道单调不减；色品坐标与 CIE 普朗克轨迹表值相差 ≤ 0.012；可见占比 1000 K < 10⁻⁴、5772 K > 40%。
- 峰高 ∝ T⁵、总量 ∝ T⁴（滑杆全格点）；200–10000 K 数值积分 = σT⁴（< 10⁻⁶）；翻倍 = 16；峰高 ×32、半高全宽 ÷2。
- 经典 ≥ 普朗克、比值 = (eˣ−1)/x（滑杆全格点）；100 μm、1000 K 时相差 < 8%；0.1 μm、8000 K 时 > 10⁴ 倍；5% 界限 ∝ 1/T；长波尾积分公式 = 数值积分，每缩 10 倍 ×1000。
- 能级概率和 = 1、平均 = x/(eˣ−1)、P(≥1) = e⁻ˣ；模式数 × ⟨E⟩ = 普朗克、模式数 × kT = 瑞利–金斯；滑杆覆盖 x < 0.05 到 x > 100。
- 双语：键集与占位符一致、所有键中英不同；HTML/app 用到的键都存在；深链目标与 `#stepN` 锚点存在；对照链接目标存在；无 canvas-label-guard。
