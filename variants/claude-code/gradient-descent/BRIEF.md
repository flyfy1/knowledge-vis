## 定位

- category `computing`，subtopic `ml`，stage `university`（与原版一致）。
- 受众：大学低年级；知道导数是斜率；不要求学过优化或机器学习。
- 一句话直觉：**只知道脚下坡度时，按 x ← x − η·∇f 走；在碗里每步把距离乘一个固定因子，η 的上限由最陡方向决定，速度由最缓方向决定。**
- 设计选择：从一维单步 → 一维迭代（缩放因子 r = 1 − ηa）→ 二维狭长碗（条件数 κ）→ 选 η（η* 与步数 ∝ κ）→ 非凸两谷 → 拟合直线（特征居中、小批量），全部数值都可用闭式核对。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步全网格：实际变化 = −ηg²(1 − η/2)，预报差 = ½η²g²；η < 2 下降、= 2 不变、> 2 上升。
- 第 1 步全网格：迭代 = r^k x₀；regime 分类；η < 2/a ⇔ 收敛；到 1/1000 的步数精确（默认 8）；「全橙」⇔ r ≥ 0；判断题答案。
- 第 2 步全网格：两方向因子；到达 ⇔ η < 2/κ；默认 38 步、η = 0.05 为 120 步；κ = 10 夹角 54°，κ = 1 为 0°；梯度垂直于等高线。
- 第 3 步：η*/上限 = κ/(1+κ)；两因子平衡；κ = 2..50 时最少步数 / κ ∈ [3.0, 3.25]；η* 与网格最优相差 ≤ 2 步；q = 0.05 为 608 步。
- 第 4 步：驻点与全局性；η ≤ 0.55 干净分割；η ≥ 0.6 有右侧起点进左谷；x₀ = 4 在 0.55/0.6 间翻转；η = 0.8 左端 [−4, −3.95] 进右谷。
- 第 5 步：κ ≈ 157 / 6.9；最优点梯度为 0；原样特征全系数 300 次后未到最小；居中 0.3 在 60 次内；B = 1 五种顺序下末 100 次平均高于最小且随系数（0.1–0.5）单调增大。
- 双语：键集与占位符一致；非符号键中英不同；无「左图/右图」；HTML/app 键都存在；深链目标与锚点存在。
