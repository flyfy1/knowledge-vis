## 定位

- category `math`，subtopic `arithmetic`，stage `junior`（与原版一致）。
- 受众：初中；会四则运算、乘方记号；不要求学过排列组合。
- 一句话直觉：**先拆成最小的部件，再数部件能怎样组合。**质因数是整数的部件（且唯一）；因数、gcd、lcm 都是「每种质数取几块」；最短路是一串 R/U，数路就是数「哪几步向上」。

| 0 质数积木 | 乘法 | 拆法不同，最后的质数组会不同吗？ | n ∈ 2..400、第一刀序号 → 叶子质数组 | 「换一种第一刀」：树形变（逐层长出），橙色叶子组不变；读数累计试过几种、是否始终相同 | 正整数 > 1；测试覆盖 2–400 每种第一刀 |
| 1 因数表 | 质因数分解、指数 | 不试除能说出因数个数吗？ | n、选中第 i 个因数 → d(n)、搭档 n/d | 拖 n：表的行×列 = 因数个数；拖选中：橙框与青框反向移动；完全平方数有一格自配 | 需先分解 n |
| 2 切正方形 | 带余除法 | 不分解怎样求 gcd？ | a, b ∈ 6..120 → 除法链、gcd | 「一刀一刀切」k/N 进度，同色 = 同一次除法；89、55 最慢（9 次） | 正整数；9 次上限只对本页范围 |
| 3 两盏灯 | 倍数、gcd | 下一次同时闪在何时？ | a, b ∈ 2..24 → lcm、各闪几次 | 播放：两行闪光逐个累积，橙线处对齐；5→6（b=8）等待 40→24 秒 | 0 秒同时起闪 |
| 4 街区路径 | 加法、乘法 | 最短路有几条？ | r ∈ 1..6、u ∈ 1..5 → C(r+u, u) | 「逐条画出全部路径」k/N，常用街段越画越亮；r、u 对调总数不变 | 只向右/向上 |
| 5 讲不讲顺序 | 组合数 | 排列比组合多几倍？ | n ∈ 3..6、k ∈ 1..3、第 j 组 → P、C、k! | 每列 = 一个组合，列内点 = 排序；k 增大每列点数 1→2→6；读数列出第 j 组所有顺序 | 元素互不相同 |
| 6 收束 | 全部 | — | 随机题（种子）→ 用户答案 | 核对 / 看答案 / 出新题；答案与解释由同一模型计算 | — |

## 模型与数值

- `model.js`（浏览器与 node 共用）：`factorize`、`splits`、`factorTree`（根按选中的第一刀，下层按最接近平方根的一对）、`divisorTable`、`euclid`、`exponentView`（min/max 指数）、`lamps`、`choose`、`pathTable`、`allPaths`、`subsets`、`orderings`、`orderedPicks`、`question`（mulberry32 种子出题）。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：2–400 每个数、每种第一刀的叶子质数组相同且乘积为 n；质数恰好没有第一刀；360 有 11 种第一刀；1 不是质数。
- 第 1 步：因数表恰含全部因数各一次；Π(e+1) = 枚举数；奇数个 ⇔ 完全平方；72 → 12（正文例）；表不超过 9 行 × 8 列（排版前提）。
- 第 2 步：6–120 全部数对：gcd = 枚举 = 最小指数；每行是合法带余除法；gcd 沿链不变；正方形面积和 = a·b；最多 9 次除法且只有 89/55 这一对（正文引用）；默认链 84 = 2×36+12，36 = 3×12+0。
- 第 3 步：2–24 全部数对：首次同闪 = lcm，之前无同闪；gcd × lcm = ab；正文引用 lcm(5,8)=40、lcm(6,8)=24、lcm(4,8)=8。
- 第 4 步：加法表 = C(i+j, j) = 枚举路数；对调 r、u 总数不变；最大 462（三位数标签）。
- 第 5 步：枚举得 P = C × k!；每组 k! 种顺序；1、2、6。
- 第 6 步：400 个种子的答案与独立暴力计算一致，四种题型都会出现。
