## 定位

- category `math`，subtopic `data`，stage `primary`（与原版一致）。
- 受众：小学中年级（单式、复式条形图所在学段）；会读表格、会两位数加减。
- 一句话直觉：**条形图用长度表示多少，所以长条必须从 0 画起，刻度要选得让差别看得清。**
- 与原版的差异（设计选择）：原版用 8 个同学的身高，讲柱高、比差、截断轴、平均线、新增数据。本版用“图书角一周借书数”这种分类计数，从表格出发；新增“刻度单位怎么选”（一格代表几本）、“横放竖放”、“从高到低排序”和“复式条形图”（两周对比），截断轴改为左右并排的对照图并量化“看起来的倍数”；平均线一步与本批平均数页互链。

## 模型、设定与失配

- `model.js`（浏览器与 node 共用）：`scale`（刻度）、`diff`、`rank`、`truncated`（截断轴下的长度与倍数）、`compare`（两周）、`balance`（横线上下）。

- 失配：第 0 步的修改只在本步生效（文中说明）；条形图适合分类比较，连续变化建议用折线图（终章）。

## 数值结论与测试（`tests/core.cjs`）

- 第 1 步：一格 1 本有 3 天顶出；只有一格 2 本既全放下又超过半张图（最高 7.5 格）；周二与周四差 2、1、0.4、0.2 格。
- 第 2 步：所有日对的差 = 大 − 小；默认周三 − 周二 = 8；排序 [周三, 周一, 周五, 周四, 周二]（并列保持星期顺序）。
- 第 3 步：起点 0、1、2、5、6 时看起来 2.14、2.33、2.6、5、9 倍；真实倍数恒为 15/7；起点 ≥ 7 时有长条消失；起点升高倍数单调变大。
- 第 4 步：变化 [−2, +2, −2, +3, +4]，3 天多 2 天少，合计 55 → 60。
- 第 5 步：滑杆格点上只有 h = 11 时高出 = 不足（都为 6）；h < 11 时高出更多；11 不在数据中。
- 双语：键集与占位符一致、中英不同；HTML/app 用到的键都存在；深链目标与锚点存在；对照链接存在；provenance 占位存在、无 canvas-label-guard。

## 可访问性、动态与双语

- 原生 range / button；数据表格是真正的 `<table>`；每个 canvas 有 aria-label；读数在 DOM（aria-live）；图例在 DOM。
- 动画（横竖切换、排序）减弱动态时直接到终态；页面隐藏时结束动画。
- 语言存 `localStorage` 的 `knowledge-lang`，读写都包 try/catch；切换后表格与 canvas 重绘。
