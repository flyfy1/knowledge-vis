## 定位

- category `probability`，subtopic `inference`，stage `senior`（与原版一致）。
- 受众：高中生；会算平均数，听说过标准差和正态分布（页内就近解释），不要求会积分。
- 一句话直觉：**一批的平均会晃；先量出它晃多大（SE = σ/√n），再用这把尺子回答两个不同的问题：μ 大概在哪（置信区间），以及「若声明为真，这批有多不寻常」（p 值）。**
- 与原版的差异（设计选择）：原版四步切片（抽样分布、置信区间、z、p）。本版用一个贯穿全页的具体对象：标签写 500 mL 的灌装机，模拟里真实平均 498 mL、σ = 6 mL。先让读者亲手抽批次看见 x̄ 会晃，再揭晓真相；p 值用公式和「零假设世界」4000 批模拟并排验证；置信区间用逐行对错的 50 批图并累计覆盖率；最后单列一步讲「显著 ≠ 重要」和功效不足。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：mulberry32 + Box–Muller 正态；`batchStream`（第 0 步固定流）、`truthMeans` / `nullMeans`（第 1、3 步，种子依 n）、`erfc`（级数 + 连分式，相对误差 < 1e-9）、`zStar`（二分）、`zScore`、`pTwo`、`simulatedP`、`intervalSet`（每组 50 批，x̄ 与水平无关）、`coverageOver`、`typical`、`nStar`、`nFromSlider`。
- 模拟设定：单瓶 ~ Normal(498, 6²) mL，彼此独立；σ 当作已知（说明书给出），所以 z 方法精确。第 3 步零假设世界 ~ Normal(500, 6²)。
- 失配（终章明说）：真实中 σ 常未知，要用 s 与 t 分布；数据相关时 σ/√n 低估；偏斜 + 小 n 时正态近似失准；0.05 是约定；多重检验。

## 数值结论与测试（`tests/core.cjs`）

- erfc 对照参考值；z* 四个水平；1 − p(z*) = 水平。
- 第 0 步：所有单瓶落在画布轴 474–522 内；批平均有高于也有低于 500。
- 第 1 步：每个 n 的中心 ≈ 498；实测标准差/公式在 0.955–1.055 之间且文案引用 0.96–1.05；±1.96 SE 内恰为 94.3%–95.6%；所有批平均和曲线峰值都在画布轴内。
- 第 2 步：497/16 → z = −2；SE(4) = 3、SE(100) = 0.6。
- 第 3 步：p(−2) ≈ 0.0455；全部滑杆格点（7 个 n × 101 个 x̄）模拟与公式差 ≤ 0.014；粉色柱计数 = 模拟 k；零假设批平均在轴 488–512 内。
- 第 4 步：每个水平 × n 在 2000 个区间上覆盖率与名义值差 < 0.03；区间不含 500 ⇔ p < 1 − 水平；不同水平用同一批 x̄；95%、n = 16 每组平均漏 2–3 行。
- 第 5 步：nStar(499.5) = 554 且恰为边界；498/16 → p ≈ 0.18 不显著；μ = 500 → 永不显著；滑杆 4..10000、默认 16。
- 双语：键集与占位符一致、非符号键中英不同；HTML/app 用到的键都存在；深链目标页与 `#stepN` 锚点存在；对照链接目标存在；不引入 canvas-label-guard。
