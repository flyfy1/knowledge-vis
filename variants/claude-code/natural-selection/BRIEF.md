## 定位

- category `biology`，subtopic `ecology`，stage `senior`（与原版一致）。
- 受众：高中生；知道基因、遗传、概率；会对数。
- 一句话直觉：**有差异 + 会遗传 + 存活有差别 ⇒ 比例定向改变；方向由环境定、速度由优势比定（对数优势每代加 ln r），种群小时运气能压过弱优势。**

## 模型、模拟设定与失配

- `model.js`：`survival`/`wL`/`wD`、`hunt`/`makeMoths`、`nextP`/`run`（三个条件开关）、`logit`/`advantage`/`gensBetween`/`rNeeded`、`barkAt`/`history`/`crossings`（示意树皮、带双向突变的逐年递推）、`wfRun`/`wfBatch`/`fixProb`（Wright–Fisher 与扩散近似）。随机数为带种子的 mulberry32。
- 页面明说的失配：单基因单倍体（不分显隐性、二倍体）；被吃概率线性于色调差是假设；树皮曲线是示意；历史数字为常被引用的记录，「1848 年约 1%」为假设；经典实验细节曾有争论，后续重复研究支持鸟类捕食；固定概率公式是近似。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：色调与 0.6 与正文一致；0.525 处存活率相等；0.15 / 0.85 两端方向；400 次狩猎平均 = 模型（±0.015）。
- 第 1 步：全开时单调上升且 40 代后 > 90%；关任一条件曲线恒定；方向由树皮相对 0.525 决定；「几乎相同」提示只在 0.5–0.55。
- 第 2 步：logit 每代恰好增加 ln r；首次 ≥ 99% 的代数 = ⌈9.19/ln r⌉；0.6 → 80+ 代、1.0 → < 20 代；历史反推 r ≈ 1.198（约 20%）。
- 第 3 步：树皮 1800/1920/2010 取值；双向滞后为正、树皮转回在 1956 年之后；K = 0.2 滞后更长且到 2020 年未跌破一半；K ≥ 0.3 两个穿越都存在；p 始终在 (0,1)。
- 第 4 步：s = 0 时 u = p₀；N·s = 20 → u > 0.97；N·s = 0.2 → u < 0.13；五组 (N, s) 下 3000 次模拟与公式一致（±0.02–0.03）。
