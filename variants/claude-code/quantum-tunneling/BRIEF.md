## 定位

- category `physics`，subtopic `modern`，stage `university`（与原版一致）。
- 受众：大学低年级；知道能量守恒、指数函数和「概率密度」的说法；不要求会解薛定谔方程。
- 一句话直觉：**能量不够时，波在墙里按 e^(−2κx) 衰减而不是戛然而止；墙够薄，尾巴就接成墙后的波。κ 含 √m 和 √(V − E)，所以 T 对墙厚、质量、能量都是指数敏感。**
- 与原版的差异（设计选择）：先用「没有背面的墙」把衰减尾巴单独讲清（R = 1，不隧穿），再削薄墙；用对数图同时比较电子、μ 子、质子；波包推演后加「逐个探测」把概率与单次结果连起来；用 α 衰变（伽莫夫模型 vs 七种核素实测半衰期）作为指数敏感性的真实证据；STM 放进终章。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`step`（半无限台阶）、`barrier`（矩形墙的边界匹配解，复数 q 同时覆盖 E < V、E > V）、`Tformula`（闭式，交叉验证）、`Tthick`、`log10T`（不下溢的对数，用于质子）、`resonances`、`packet`（Crank–Nicolson，L = 100 nm，N = 4000，σ = 2.5 nm，墙在 50 nm）、`averagedT`（按波包 k 分布平均的 T）、`gamow`、`ISOTOPES`（Q 值与半衰期为标准核数据）、`stmFactor`、`mulberry32`（探测抽样）。
- 第 4 步推演结束于波包中心应到墙后 25 nm 处；测试核对总概率守恒（1e−6）、墙内残余 < 1e−4、波包从未碰到盒子两端。
- 失配（终章明说）：一维、矩形墙、非相对论、无耗散；伽莫夫估算忽略角动量、核形状与 α 粒子预形成概率，R = 1.2(A^1/3 + 4^1/3) fm；STM 用恒定功函数的厚墙近似。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：R = 1；墙面密度 = 4E/V；δ = 1/(2κ) 处降为 1/e；ψ、ψ′ 在墙面连续；条纹 ≤ 4。
- 第 1–3 步：匹配解 = 闭式（E 0.02–4 eV × a 0.1–2 nm，误差 < 1e−7），T + R = 1；墙后密度 = T；κa ≥ 2 时厚墙近似误差 < 4%（细扫）；每 0.1 nm 倍数 ≈ e^(−0.2κ)（κa ≥ 2 时 2% 内）；√207 = 14.4、√1836 = 42.9；每个 E 下质子都会掉出 10⁻³⁰；判断题比值 36；共振处 T = 1 且恰为整数个半波长，共振之间 T < 1；a = 1 nm 时刚过墙顶 T < 0.2；共振间隔随 a 变小；默认读数 1.38、2.50 eV。
- 第 4 步：E₀ 全档 × a = 0.4、a 全档 × E₀ = 0.5/1.2：推演平台与按能量散布平均的 T 相差 < 0.01（最差 6.3e−3）；默认推演约 107 fs。
- 第 5 步：七种核模型与实测都在 2 个数量级内、最差为 ²¹⁰Po；半衰期跨 24 个数量级；Q 比 2.19；墙厚比 > 2；²¹²Po < 1 µs，²³⁸U > 10⁹ 年；墙顶 26–28 MeV；半衰期与 b 随 Q 单调下降。
- 终章：STM 倍数 8.8（0.1 nm）、1.5（0.02 nm）。
