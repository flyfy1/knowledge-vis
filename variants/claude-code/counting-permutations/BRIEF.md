## 定位

- category `probability`，subtopic `basics`，stage `senior`（与原版一致）。
- 受众：高中生；会乘法，知道「概率 = 想要的情况数 ÷ 全部情况数」的说法即可，不要求先学过排列组合。
- 一句话直觉：**分步的事各步相乘；排队就是一步步选人，得到 n! 和 A(n, k)；只选不排时，同一群人的 k! 种顺序算一种，所以除以 k!。用哪个只看「换个顺序算不算另一种」。**
- 本版的设计选择：第 0 步把路线图和路线树画在同一张图上，一条条点亮路线，叶子数就是 a × b × c；第 2 步用青色/灰色方框把 n! 拆成「用到的 k 个位置」和「被砍掉的 (n − k)!」；第 3 步把 A(n, k) 条彩色方块条按「选了谁」动画归进 C(n, k) 个框，每框恰好 k! 条；第 4 步是先判断后计算的六个情景；第 5 步用生日问题把计数接回概率。

## 教学链（每步五项）

| 步 | 读者已知 | 唯一要回答的问题 | 输入 → 想求的量 | 控件操作与预期观察 | 结论适用条件 |
| --- | --- | --- | --- | --- | --- |
| 0 乘法原理 | 乘法 | 三段路一共多少条路线？ | a, b, c ∈ 1..4 → a·b·c | 「下一条路线」「逐条列出所有路线」：路线图亮起的三段路与树叶同步；默认 3 × 2 × 4 = 24；c 从 4 改 2 总数减半 | 每步选法个数不受前面选择影响 |
| 1 全排列 | 乘法原理 | n 个人排一排有几种？ | n ∈ 1..10 → n! | n ≤ 4 列出全部排法（「逐个排出」逐条点亮）；n > 4 改画 n! 的对数增长图；3! = 6、4! = 24、8! = 40320、10! = 3,628,800 | 对象互不相同 |
| 2 排列数 | n! | 只选 k 个排成一列有几种？ | n ∈ 1..10，k ∈ 0..n → A(n, k) = n!/(n − k)! | 默认 n = 8, k = 3 → 336 = 40,320 ÷ 120；k 从 0 拖到 8：1, 8, 56, 336, 1680, 6720, 20160, 40320, 40320 | 0! = 1 的约定 |
| 3 组合数 | A(n, k) | 只选不排，为什么除以 k!？ | n ∈ 2..6，k ∈ 1..3 → C(n, k) = A(n, k)/k! | 「按『选了谁』归组」：n = 5, k = 3 时 60 条进 10 框、每框 6 条；k = 1 时排列组合一样多 | 同上 |
| 4 判断顺序 | A 与 C | 换个顺序算不算另一种？ | 六个情景 → 先选「算/不算」，再核对 | 答案 90、45、10、20、336、2,598,960；条形图同时画 A 与 C，比值 = k!；情景 3/4 差 2!，情景 6 差 5! = 120 | 题意决定顺序是否算数 |
| 5 生日问题 | 计数、对立事件 | 几个人时同生日的机会过半？ | n ∈ 2..80 → 1 − A(365, n)/365ⁿ；模拟 100 个班 | n = 23 首次过半（50.7%），n = 57 达 99.0%，23 人有 253 对；「模拟 100 个班」白点散在曲线附近 | 365 天等可能、独立，不算 2 月 29 日 |
| 6 收束 | 全部 | — | — | 公式汇总、适用条件、4 条互链 | — |

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`fact`、`perm`、`comb`、`factors`、`routes`、`orderedPicks`（字典序）、`groupBySet`、`SCENARIOS`/`answer`、`allDifferent`/`shared`/`firstAbove`、`simulateRooms`（mulberry32，按钮每按一次种子加 1，从 500 起）。页面上所有计数都小于 2⁵³，用普通数即精确。

## 数值结论与测试（`tests/core.cjs`）

- 去尾零只在有小数点时生效。
- 基础：n ≤ 12 时 A = n!/(n − k)!、C = A/k!、杨辉递推、越界为 0。
- 第 0 步：a, b, c ∈ 1..4 全部组合路线数 = a·b·c 且互不相同；默认 24、c → 2 时 12。
- 第 1 步：n ≤ 6 的排法枚举个数 = n!；3!、4!、8!、10! 与提示文字一致。
- 第 2 步：A(8, k) 序列逐项钉住并与中英文提示一致；最后两项相等。
- 第 3 步：n = 2..6、k = 1..3 归组后框数 = C(n, k)、每框 k! 条、框内集合相同且顺序互异；60 → 10 × 6。
- 第 4 步：六个答案、两条之比 = k!、情景解释与「顺序算不算」标记一致；C(5, 2) = 10、A(5, 2) = 20、A(52, 5) = 311,875,200。
- 第 5 步：首次过半 n = 23（50.7%）、首次达 99% n = 57（99.0%）、C(23, 2) = 253、P 单调；「偏差几个百分点」：100 个班的标准差 ≤ 5 个百分点，648 次模拟平均偏差 < 3 个百分点、超过 95% 在 ±10 以内（实测最大 15.3，属正常的 3σ 尾部）；20000 个班的长模拟与 50.7% 相差 ≤ 1.2 个百分点。
