## 定位

- category `math`，subtopic `calculus`，stage `university`（与原版一致）。
- 受众：大学低年级；会函数图像、绝对值不等式，听说过导数。
- 一句话直觉：**极限是一场游戏：对手给 ε，你回 δ；对每个 ε 都能赢，极限才成立；一条对所有 ε 都赢的 δ 公式就是证明。**
- 设计选择：全页用精确算出的「最大可赢 δ*」作裁判，而不是从图上目测；第 3 步横轴以 δ 为单位随 δ 缩放，让「δ 再小也没用」看得见；第 5 步用 δ ÷ δ* 的对数图揭穿「δ = ε/斜率」这条看似合理、实际处处失败的规则，再给出 min(1, ε/5) 这个教科书技巧。

## 模型、设定与失配

- `model.js`（浏览器与 node 共用）：`hole`（不约分直接算）、`bestDelta`、`worstSq`（开区间上的上确界）、`wins`、`F3`、`witness`（跳跃、振荡、冲向无穷用解析位置找反例；x·sin(1/x) 先查不等式保证，再密集采样 8000 点）、`SEQ`、`epsN`（逐项检查到可证明的界）、`ruleCheck`（含反例 x）。
- 说明（s6 boundary）：δ* 精确计算；采样不等于证明；双精度浮点；不展开单侧极限、x → ∞ 与连续性。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：所有 h 档位下字面公式与 x + 1 相差 < 1e-9 且低于显示位数；|f − 2| = h（3 位有效数字）；f(1) 为 0/0；每格约缩到 1/3。
- 第 1–2 步：全部 (a, ε) 网格上 worstSq(δ*) = ε、δ* 赢而略大即输、采样确认、右侧决定、δ* < ε/(2a)；ε → 0 比值 → 1；a = 1000 时 δ* < 3e-4；第 1 步滑杆网格上「赢 ⇔ δ ≤ δ*」；默认回合为输。
- 第 3 步：所有 L × δ 网格上，跳跃 / 振荡 / 冲向无穷都找到有效反例；对照函数的反例有效、只在 δ ≤ ε − |L| 时给出保证、|L| ≥ ε 必输；L = 0 时赢 ⇔ δ ≤ 0.5。
- 第 4 步：所有 ε 档位上 N 之后 3000 项（sin 为保证界之后 2000 项）都在带内、N 是最小的；alt 的 N = ⌊2/ε⌋ + 1、ε 缩 10 倍 N 约 ×10；sin 的 N 在 0.9/ε² 到 1/ε² + 1 之间；flip 无 N；画图项数 < 13000。
- 第 5 步：ε 网格上 ε/4 全输、ε/5 赢 ⇔ ε ≤ 5、min(1, ε/5) 全赢；反例有效；比值不超出坐标；规则 C 的不等式采样验证；判断题。
