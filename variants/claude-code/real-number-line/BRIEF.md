## 定位

- category `math`，subtopic `arithmetic`，stage `junior`（与原版一致）。
- 受众：初二；会勾股定理、分数、乘方，知道数轴。
- 一句话直觉：**√2 是数轴上一个确定的点，小数读不完也不循环；任何分数都打不中它，因为 p² 里因数 2 是偶数个、2q² 里是奇数个。**
- 与原版的差异（设计选择）：原版用观察 + 证明思路、二分逼近、根号螺旋；本版把「为什么打不中」做成可交互的证明（数因数 2 的奇偶，配对方块），用逐层放大读小数代替二分，用 y = x² 图像定位任意 √n 代替根号螺旋，并加一步「给数分类」（22/7 与 π、√9 与 √8 两组对照）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`sqrtDigits`（BigInt 整数开方，牛顿法从上方收敛）、`fracDigits`（长除法，检测循环起点与循环节）、`terminatesByDenominator`、`bestFor/bestUpTo/records`（误差用 |p² − 2q²| / (q(p + q√2)) 计算，避免相减抵消）、`twos`、`rootInfo`、`classify`。
- π 的数字是引用的常数串（测试核对与 Math.PI 一致）；π 的无理性页面明说「已证明、本页不证」。
- 第 0 步图示按真实比例；第 2 步上图只画约分后的分数。
- 失配说明（终章）：「√n 要么整数要么无理」只对正整数 n；屏幕分辨率不足以区分 1.4142 与 √2，结论靠数字与证明。

## 数值结论与测试（`tests/core.cjs`）

- √n（n ≤ 60）各精度的数字满足 x² ≤ n·10^(2k) < (x+1)²；√2、√3 前若干位与已知值一致。
- 第 0 步：转动全程长度不变，落点 = √(1+b²)、y = 0；起点在长方形右上角；√10 在画出的轴内。
- 第 1 步：7/8 = 0.875，从第 3 行起点在刻度上（前两行不在）；1/7 循环 142857、1/3 循环 3；√2、√3 前 40 位无循环尾；q ≤ 60 的所有分数长除法与「分母只含 2、5」规则一致。
- 第 2 步：q ≤ 10000 时 p² − 2q² ≠ 0；纪录分母含 5、12、29；N = 60 最近 41/29（p² − 2q² = −1）；7/5、17/12、41/29 为 ±1；误差公式与直接相减一致；最小误差在对数轴下限之上。
- 第 3 步：p ≤ 99 时 p² 的因数 2 为偶数个（= 2·v₂(p)），q ≤ 70 时 2q² 为奇数个；所有组合 p² ≠ 2q²；按钮设定的 p 不超出滑杆。
- 第 4 步：各数分类、循环节、22/7 与 π 在第 3 位分开、0.1010010001… 零的段长逐次加 1、所有数在画出的轴内。
- 第 5 步：1..50 中完全平方数恰为 1、4、9、16、25、36、49；其余夹在相邻整数之间；相邻根的间距递减；非平方数恰有某质因数出现奇数次。
