## 模型、失配与数据

- `model.js`：`relaxTrace`（投影梯度下降，η = 0.1，单步移动上限 0.1，停止阈值 1e−5，上限 1500 轮）、`arrange`（8 个种子取最低能量，2000 轮）、`fourStats`、`count`、`compare`、`netDipole`、`bentNet`、`orient`（只换显示朝向）。
- 失配（页面 s3 说明与终章边界都明说）：所有成键域一样大 → SO₂ 偏小 5.4°；孤对间排斥被低估 → XeF₄ 两对孤对相隔约 95°（实验 180°）；ClF₃ 偏小 2–4°。SF₄ 的赤道键角此模型方向都算反（自查发现），因此未列入分子表。
- 实验数据：键角取常见气态值（NH₃ 106.7°、H₂O 104.5°、SO₂ 119.5°、ClF₃ 87.5°/175°等）；偶极矩（D）取手册值；电负性为鲍林值。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：N = 2–6 × 种子 1–97 全部收敛到理想角（0.1° 精度）、能量单调不增、在上限前停止、曲线在前半程即变平；N=5 为 90°×6、120°×3。
- 第 1 步：0.5° 网格上 E 最小在 109.5°；四面体处同对 = 跨对 = 109.47°；平面十字最小夹角 90° 且 E 更高；两侧单调。
- 第 2 步：λ = 1.25 时 NH₃、H₂O 与实验差 ≤ 1°（H₂O 显示 104.4°）；网格上最接近 NH₃ 线的 λ 为 1.25；键角随 λ 单调减小；N=5 孤对恒在赤道（λ > 1）；N=6/L=2 孤对夹角 < 120°（失灵提示）；TBP 邻居数 2/3。
- 第 3 步：11 个分子的 AXₘEₙ；CH₄/NH₃/H₂O ≤ 1°；对称分子 < 0.1°；SO₂ 在 −5～−6°；XeF₄ 孤对约 95°；|差| > 5° 的恰为 SO₂、XeF₄ 且为最大两行；ClF₃ T 形且偏小。
- 第 4 步：ΔEN(O–H) = 1.24、104.5° 处约 1.5、180° 为 0；模型净偶极为 0 ⇔ 实测为 0（10 个分子）；B–F 1.94、N–H 0.84；判断题。
