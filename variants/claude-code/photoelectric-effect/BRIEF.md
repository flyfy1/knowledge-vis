## 定位

- category `physics`，subtopic `modern`，stage `university`（与原版一致）。
- 受众：大学低年级；知道电压、电流、频率与波长 f = c/λ；不要求学过量子力学。
- 一句话直觉：**电子一次只吞一个光子**。所以门槛由频率决定、亮度只决定个数；K_max = hf − φ 可以用遏止电压量出，几条谱线的直线斜率就是 h。
- 与原版的设计差异：全页贯穿一只钠阴极光电管；第 2 步用「电子行」把 I–V 曲线的每个点对应到「哪些电子爬得过坡」；第 3 步用真实汞灯谱线（含两条测不到的）和三种金属的平行直线；第 4 步把波动图像与光子图像的等待时间放在同一条对数时间轴上，并显示随机的到达时刻。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：常数为 2019 SI 精确值；`photonEV`、`threshold`、`photocurrent`（η=10%）、`iv`（均匀动能分布）、`findStopping`（5 mV 步进找零点）、`reach`/`sampleK`（电子行）、`measureVs`（真值 + ±0.03 V 固定伪随机，不低于 0）、`fit`（最小二乘）、`classicalWait`、`electronRate`、`emissionTimes`（泊松过程）、`human`（时间单位）。
- 模型失配（页面 s5 边界段明说）：逸出功为教科书近似值；真实量子效率更低且随波长变化；真实 I–V 下降段更弯；接触电势差平移 V_s 但不改斜率；第 3 步读数是模拟；第 4 步是数量级估算；忽略热电子发射；动画为教学慢放。

## 数值结论与测试（`tests/core.cjs`）

- hc = 1239.84 eV·nm、h = 0.4136 eV/10¹⁴ Hz；hc/λ = hf；h f₀ = φ；五种金属 K_max–f 斜率都等于 h。
- 钠 λ₀ ≈ 544 nm，铜 λ₀ ≈ 267 nm（紫外），铂可在 200 nm 端达到；门槛以上有电流、以下任何功率都为 0（含 600 nm、100%）；600 nm 光子 2.07 eV < φ。
- 第 0 步：I ∝ 亮度；同功率下 λ 越长电流越大（λ₀ 以下）；电流在 0–50 µA 轴内。
- 第 2 步：V_s 在 K_max 的一个 5 mV 步内且 ≤ 4 V；V≥0 饱和、V≤−V_s 为 0；10 行电子到达比例与 I/I_sat 相差不超过 1/10；亮度减半 I_sat 减半。
- 第 3 步：钠测不到恰为 546.1、577.0 nm；锌只有 253.7 nm；铯 7 条都有；读数在 ±0.03 V 内且 ≥0；全谱线拟合 h 误差 <1.5%（钠 0.4%）；Cs/Na 斜率差 <2%、Cs 线处处更高；只用 404.7/435.8 nm 时误差 >3 倍。
- 第 4 步：两种等待时间之比恒定（≈7.4×10¹⁴，介于 10¹⁴–10¹⁵）；10⁻⁶ W/m² 时波动等待 >1 年；400 组随机种子 × 全部滑杆位置下第一个电子 <1 µs；泊松平均间隔 ≈ 1/rate。
- 双语：键集与占位符一致、非符号键中英不同、无「左图/右图」字样；HTML/app 用到的键都存在；深链目标页与锚点存在；对照链接存在；无 canvas-label-guard。
