## 定位

- category `earth`，subtopic `astronomy`，stage `university`（与原版一致）。
- 受众：大学低年级；会导数（da/dt）、积分的含义、最小二乘的直觉；不要求广义相对论。
- 一句话直觉：**均匀膨胀 = 所有距离乘同一个 a(t)。由此直接推出没有中心、v = H₀d、1 + z = 1/a；再加上弗里德曼方程，就能算出年龄和三种不同的「距离」。**

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：格点 `chi`（10 Mpc 间距 + 哈希抖动）、`separation`、`velocity`；`catalogue`（mulberry32 + Box–Muller，种子 1–6，不挑选）、`fitH`、`sigmaH`；`timeAt`/`scaleAt`（平直 ΛCDM 闭式）与 `timeAtNumeric`（Simpson，对照并可加辐射）；`accelA`、`q0`；`comoving`（Simpson）、`lookback`、`distances`、`zAtHubbleDistance`、`zEmitPeak`；`redshift`、`observed`。
- 第 2 步是**模拟**数据：真值 70，40 个星系距离在 [2, 最远距离] 均匀，同一组的随机数在不同最远距离间复用（拖滑杆时是同一批星系被拉开）。
- 失配（页面 s2e、boundary 明说）：距离无误差；忽略辐射（z ≤ 10 影响 < 0.1%，测试钉住）；束缚系统不膨胀；H₀ 取 70、Ωm 取 0.3 的整数值；现实 H₀ 有 67 / 73 分歧。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：5 个参照星系 × 31 个 a × 169 个星系：距离比 = a、运动沿径向；邻居间距 5–15 Mpc。
- 第 1 步：所有参照星系与 H₀ 下 v/d = H₀；用第 4 步的 a(t) 数值求导得 (da/dt)/a = H₀；1/H₀ = 13.97 Gyr；轴范围装得下。
- 第 2 步：6 组中最远 20 Mpc 偏差最大 ≈ 6%（5.5–6.5），200/300/400 Mpc 都 < 1%；σ_H 随距离单调减；拟合是最小二乘极小；600 次独立模拟的散布与 σ 公式相差 < 10%、均值无偏；所有拟合值在 55–85 轴内。
- 第 3 步：全部 a 格点 1 + z = 1/a、λ 比 = 1 + z、在 8000 nm 轴内；a = 0.5 → 1312.6 nm；a = 0.1 → z = 9；回看时间一致。
- 第 4 步：20 个 Ωm 上闭式年龄 = 数值积分、scaleAt 是 timeAt 的逆、今天的斜率 = H₀、在 accelA 前后二阶差分变号、q₀ < 0 ⇔ Ωm < 2/3；Ωm = 0.3 年龄 13.47；Ωm = 1 年龄 = (2/3)/H₀ = 9.31。
- 第 5 步：z = 1 时 10.8 / 7.7 Gly、比值 1.4；发出时距离峰值 z ≈ 1.6、5.7 Gly；v = c 于 z = 1.46；哈勃距离 13.97 Gly；全部 z 格点上 共动 > 光行 > 发出时、超光速提示恰在 z_H 之外；z → 0 三者重合；辐射影响 < 0.1%。
- 双语：键集、占位符一致；中英不同（符号键 `s1lgLine` 例外）；无「左图/右图」；HTML/app 用到的键都存在；深链目标与锚点存在；对照链接存在。
