## 定位

- category `investment`，subtopic `basics`，stage `junior`（与原版一致）。
- 受众：初中；会百分数和平均数，不要求学过方差、概率分布或复利。
- 一句话直觉：**风险是结果散开；风险溢价是说服人承担散开的价钱；许诺的是平均，不是每个人的结果。**
- 与原版的差异（设计选择）：用一个六面骰子（等距六个面，平均 + 摆幅两个参数）贯穿全页，所有分布都能数清；风险用「平均偏离」（平均绝对偏差）而不是方差来量，初中可直接从图上的粉色线段读出；「为什么风险大要许诺更多」用一个 100 位虚构买家的小市场讲因果（溢价不够就没人买），而不是只给结论；第 4 步给出精确概率（枚举全部掷法）并和模拟对照，并点出中位数低于许诺。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`faces`（m + s·Z，Z = ±1、±0.6、±0.2）、`mad`、`rolls`/`runningMean`（mulberry32 固定种子 11、23、37、41、59）、`willing`/`premiumFor`（100 位买家，比例 (i+1)/200）、`paths`（200 条路径，种子 1000 + 上述种子）、`endDist`/`endStats`（按各面出现次数的多项分布精确枚举，T = 20 时 53 130 种组合）。
- 第 2、4 步是**模拟**（固定种子）；第 4 步的概率曲线和读数里的百分比是**精确值**，模拟只做对照。
- 模型失配（页面「模型假设」明说）：全部数字虚构；骰子公平且每年独立；买家要求的补偿与摆幅成正比是讲机制的简化；无费用、税、通胀；「风险大回报高」只指许诺的平均。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：六个面 −17…+23（文案引用由测试钉住）、平均 = 3%、金额 83–123、3 个面拿回不到 100。
- 第 1 步：所有摆幅下平均 = 3%、平均偏离 = 0.6 s、最好/最坏面 = 3 ± s、s = 0 时 B = A。
- 第 2 步：5 组种子终点都在 +3% ± 2.5 内（文案引用）；前 10 次最大偏离 > 后 50 次最大偏离；最后 20 次仍覆盖 −17 与 +23；各组前 10 次不同。
- 第 3 步：没有溢价就没人买（s > 0）；说服 50 人需 0.25 s、90 人需 0.45 s；人数随 m 单调不减、随 s 单调不增；m = 8、s = 20 恰好 50 人（第 4 步文案依据）；坐标范围装得下所有点。
- 第 4 步：精确枚举 = 暴力枚举（T = 1..4）；概率和为 1；平均终值 = 按 +8% 复利；中位数 < 许诺；落后 A 的概率 < 50%、随 T 不增、到 T = 20 仍 > 0；5 批模拟与精确值在 4σ 内一致。
- 双语：键集与占位符一致、非符号键中英不同、无「左图/右图」措辞；HTML/app 用到的键都存在；深链目标页与 `#stepN` 锚点存在；对照链接目标存在；没有引入 canvas-label-guard。
