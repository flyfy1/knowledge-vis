## 模型

## 数值结论与测试（`tests/core.cjs`）

- 猜数字：1–100 所有秘密数最多 7 次；最坏链 100 → 50 → 25 → 12 → 6 → 3 → 1；范围只缩不扩，范围外的猜测不改变范围。
- 第 1 步：1–100 每个目标结果正确、≤ 5 次、不变量每步成立、缺失时 lo = hi + 1 且为插入点。
- 第 2 步：多个 n 穷举最坏次数 = ⌊log₂n⌋ + 1（命中与缺失）；10³/10⁶/10⁹ → 10/20/30。
- 第 3 步：正确版 17/17；lo = mid 在 80 卡在两格（mid = lo）；lo < hi 无死循环、错在 [10, 30, 50, 80]；hi = mid 在 5 死循环。
- 第 4 步：0–26 所有目标的左右边界、次数 = ub − lb、每次 4 或 5 次；15 → 8、12、第 1 步算法停在 11；5、13 两边界重合。
- 第 5 步：c = 2…10 每步都夹住 √c、宽度 = c/2ᵏ；c = 2 时 k = 10/20/30 定 2/5/8 位。
- 双语键集/占位符一致、无「左图/右图」、id 唯一、深链锚点存在；文案中引用的数字由测试核对。
