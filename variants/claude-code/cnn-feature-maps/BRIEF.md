## 定位

- category `computing`，subtopic `ml`，stage `university`（与原版一致）。
- 受众：大学低年级。需要知道矩阵和加权求和；梯度只用「权重加一点点，损失变多少」的口径，不要求会求导。
- 一句话直觉：**特征图上的每个数，都是九个权重和九个亮度的乘积之和**。核决定看什么；ReLU 和池化决定留什么；第二层把第一层的结果组合成更复杂的形状；这九个数也可以靠梯度下降学出来。
- 与原版的差异（设计选择）：
  - 全部用 14×14 合成图（方块、圆、斜线、字母 T），每个像素和每个结论都能精确核对。
  - 增加「第二层认角」一步：ReLU(V + H − c) 是一个两通道的 1×1 卷积，门槛区间 [1, 1.5) 可以算出来。
  - 增加「学出核」一步：用真实梯度下降学出竖直边缘核，并给出由 Hessian 最大特征值决定的学习率上限（约 0.56）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）的内容：
  - 图与核：`IMAGES`（4 张图和训练图 `TRAIN`），`edgeAt`、`KERNELS`。
  - 运算：`conv`（带补零与步幅），`products`，`relu`，`maxpool`。
  - 第二层：`corner`、`cornerRange`。
  - 训练：`lossGrad`、`step`、`train`、`maxErr`，以及 `hessianEig`（Jacobi 求 9×9 特征值）。
- 训练图用 mulberry32(2026) 生成的固定随机斑点，九个权重都会被用到，最优解唯一（Hessian 正定）。
- 失配（页面 boundary 明说）：
  - 真实 CNN 处理多通道彩色图，有许多层，核从数据中学出。
  - 本页只有单通道灰度图，第 0–4 步的核是手设的，第二层只演示了一个组合。

## 数值结论与测试（`tests/core.cjs`）

- **卷积**：40 张随机图 × p、s 九种组合，与补零后的暴力定义逐点一致。输出边长与公式一致；九个乘积之和等于卷积；非对称核验证不翻转。
- **第 0 步**：14×14 → 12×12。方块的竖直边缘图只在第 2、3 列为正、第 8、9 列为负，其余为 0。默认窗口的和为 3。
- **第 1 步**：
  - 边缘核各角度和为 0，模糊与锐化核和为 1，原样核等于原图去掉一圈。
  - 90° 的结果是 0° 的转置。方块在 45° 时的最强点恰为 (3, 3)（正）和 (8, 8)（负）。
  - 斜线在 45° 时全 0，在 135° 时最强。锐化的最大值为 3、最小值为 −1。
- **第 2 步**：九种 (p, s) 组合下，未覆盖条带都窄于步幅，且与暴力覆盖一致。p = 0、s = 3 时漏 2 列/行；p = 1 时仍是 14；s = 2 时为 6×6。
- **第 3 步**：
  - 四张图上 ReLU 后无负数、正数不变。
  - 池化等于逐块最大值，最大值保留，边长为 12/q。
  - 圆的正值只在左半、负值只在右半。144→36→16。
- **第 4 步**：
  - 方块、圆、字母 T 的 V + H 最大值都是 1.5，第二大的值都是 1。
  - c 以 0.1 为步长扫 0..2：方块和字母 T 在 [1, 1.5) 内恰好一个点；圆在这个区间内恰好 7 个点，都在左上弧上；c ≥ 1.5 全灭；c < 1 多于一个点。
- **第 5 步**：
  - 梯度与有限差分一致；目标核的损失为 0。
  - 学习率上限 2/λmax ≈ 0.56。
  - 学习率 0.3 时损失单调下降：300 步后最大偏差 < 0.01，200 步时还没有；100 步后形状已可辨认。
  - 学习率 0.05–0.55 收敛，0.6 发散；滑杆范围为 0.05–0.6。
- **双语与页面结构**：中英键集与占位符一致，中英文本不同，没有「左图/右图」类说法。HTML 和 app 用到的键都存在；控件齐全。深链锚点存在，对照链接目标存在。没有引入 canvas-label-guard，署名占位符在。
