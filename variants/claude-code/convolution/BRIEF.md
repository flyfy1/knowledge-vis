## 定位

- category `signal`，subtopic `systems`，stage `university`（与原版一致）。
- 受众：大学低年级；会求和记号 Σ、知道积分是面积；不要求学过信号与系统。
- 一句话直觉：**线性 + 时不变 ⇒ 输入是一串「拍手」，输出是各次拍手回响之和；这个和就是卷积。**「翻转、滑动」是按列读同一个和的结果，而不是另一条规则。
- 与原版的差异（设计选择）：原版从「翻转、滑动、相乘、求和」的手艺出发；本版先给出动机（为什么已知 h 就能算出一切输出），由叠加推出公式，再把「翻转滑动」作为按列读法推出来。全页只用一个系统 h = [1, 0.6, 0.3] 贯穿前三步；第 3、5 步用同一个滑动平均核，把「时域平滑」和「频域零点」连成一件事。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`conv`（完整线性卷积）、`terms`（按列的项）、`copies`（逐条回响）、`convCentered`（带原点的卷积，用于中心对称核）、`smoothing`、`contY`（连续卷积解析面积）与 `contYNumeric`（黎曼和对照）、`measureGain`（对稳态输出做 cos/sin 最小二乘拟合）、`HboxFormula`、`dft`。
- 第 3 步数据是**模拟**：240 个样本的台阶（n=60 升、n=180 降）+ 独立高斯噪声 σ=0.3，种子 1–5（mulberry32 + Box–Muller），不是挑出来的。噪声比例只在窗口完全落在数据内的样本上算。
- 第 5 步输入是 400 个样本的余弦，显示与拟合只用中段（拟合 n=100..299，显示 n=100..163），避开两端补零的过渡。
- 模型失配（页面 s6 明说）：只适用于线性时不变系统；DFT 是循环卷积；相关与 CNN 惯例不翻转核；1/√w 只对独立噪声、平均意义成立。

## 数值结论与测试（`tests/core.cjs`）

- 卷积实现 = 定义式（200 组随机序列）、交换律、按列求和 = 逐条回响叠加 = y[n]。
- 第 0 步：所有 k、a 组合下输出 = a·h[n−k]。
- 第 2 步：默认输入下只有 n=0..6 有重叠（判断题答案 7 = 5+3−1），y[3] 的展开项为 (k,j) = (1,2),(2,1),(3,0)。
- 第 3 步：斜坡长度恰为 w−1（5 组噪声 × 8 个 w）；线性拆分 = 直接平滑原始数据；中心核无延迟；噪声残余 ÷ (1/√w) 在 0.91–1.21（文案引用值由测试钉住）；另用 300 次独立模拟验证平均值 ≈ 1/√w（±0.01）。
- 第 4 步：解析面积 vs 黎曼和（误差 ≤ 2e−3，全部 b、t 网格）；非零范围 1+b；总面积 = 1 × g 的面积；矩形峰值 min(1,b)、平台 |1−b|；b=1 矩形三角形对称、斜坡不对称。
- 第 5 步：全部滑杆格点（w × f）上拟合增益 = |H(f)|（1e−9）；DTFT 求和 = 闭式；拟合余弦符号 = H 符号（反相提示）；「几乎抹掉」提示恰好出现在 f = m/w；卷积定理（补零 DFT）。
- 双语：键集与占位符一致、非符号键中英不同；HTML/app 用到的键都存在；深链目标页与 `#stepN` 锚点存在；对照链接目标存在。
