## 定位

- category `probability`，subtopic `stochastic`，stage `university`（与原版一致）。
- 受众：大学低年级；会对数与概率加权平均；不要求学过信息论。
- 一句话直觉：**熵 = 最聪明的是非题策略平均要问的题数 = 惊讶度 −log₂ p 的平均 = 无损压缩每个符号至少要的位数；用错分布要多付 KL 散度。**

| 0 猜数游戏 | 是非题 | N 种一样可能，至少问几题？ | N ∈ 2..32 → 每局题数、平均题数 vs log₂ N | 「玩一局」逐行显示剩余候选（进入页面时已有一局）；「连玩 50 局」累积直方图；N = 8 恒为 3 题；N = 6 平均 2.67，略多于 log₂ 6 = 2.585；改 N 会清空并提示 | 对半问；整数题数使平均 ∈ [log₂ N, log₂ N + 1) |

| 4 压缩极限 | 熵 | 每天至少要几位来记录？ | α → 哈夫曼树、码表、平均码长、分块 k = 1/2/3 | 「随机抽 1000 天来编码」：每天位数接近 L；α = 2：H = 0.661，L = 1.156，k = 3 时 0.683；「晴」占 86% | 前缀码；天气独立同分布 |
| 5 用错了概率 | 码长 = −log₂ p | 按错误的分布编码要多付多少？ | 真实 α、模型 α → 交叉熵、KL | 曲线在模型 α = 真实 α 处最低等于 H；默认 2.157 → 3.02，多付 0.862；「模型认定冰雹不可能」→ ∞ | 理想码长（未取整） |

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`surprise`、`entropy`、`binaryH`、`halving` / `avgQuestions`（闭式 k + 2(N − 2^k)/N）、`SYMBOLS` / `source(α)`、`huffman`（按概率、再按建立顺序打破平局，结果确定）、`blockAvg`（6^k 联合分布上的哈夫曼）、`kraft`、`encodeSample`、`coinRun`、`crossEntropy` / `kl` / `withoutLast`、`mulberry32`。
- **模拟**：第 0 步游戏的秘密牌随机；第 2 步每按一次用种子 1, 2, 3…（最多保留 6 条路径）；第 4 步每按一次用种子 1, 2, 3…。**精确计算**：其余全部数值。
- 模型失配（s6 boundary 明说）：真实天气前后相关，条件熵更小；−log₂ q 是理想码长，实际码长要取整；熵只看概率不看「意义」；热力学熵公式同形但对象不同。

## 数值结论与测试（`tests/core.cjs`）

- `fmt` 只在有小数点时去尾零。
- 第 0 步：N = 2..32 时对半问必定找到秘密牌；平均题数等于闭式；题数只取 ⌊log₂ N⌋ 或 ⌈log₂ N⌉；log₂ N ≤ 平均 < log₂ N + 1；最多 5 行；N = 8 恒为 3；N = 6 为 2.67 vs 2.585（中英文案均引用）。
- 第 1 步：0.05 网格上惊讶度可加；组合惊讶 ≤ 9（绘图范围）；1/p 可加当且仅当 a + b = 1。
- 第 2 步：H(0.9) = 0.469、正面 0.15、反面 3.3、H(0.5) = 1；H 对称且在 (0, 1]；20000 次累计平均惊讶 ≈ H（±0.02）。
- 第 3 步：α ∈ 0..2 概率归一、H ≤ log₂ 6、H 随 α 严格下降；α = 0 时 H = 2.585。
- 第 4 步：每个 α 上 H ≤ L < H + 1、Kraft 和 = 1、码前缀无关、严格更罕见的符号码长不更短、分块 H ≤ L/k < H + 1/k、k = 3 不差于 k = 1、树深 ≤ 5；α = 2 时 1.156 / 0.683 / 0.661 / 86%；10 万次抽样每符号位数 ≈ L。
- 第 5 步：默认 2.157 / 3.02 / 0.862；交叉熵 ≥ H（吉布斯不等式）、最小值在模型 α = 真实 α 处且等于 H；q = 0 时为 ∞；KL ≥ 0。
- 双语：键集与占位符一致、中英不同、无「左图/右图」；HTML/app 用到的键与控件都存在；深链目标页与锚点存在；对照链接目标存在；有 provenance 占位、无 label guard；7 个步骤锚点。
