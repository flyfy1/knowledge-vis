## 定位

- category `biology`，subtopic `body`，stage `senior`（与原版一致）。
- 受众：高中生；知道离子、电压、电流；不要求会微分方程。
- 一句话直觉：**膜电位总在追赶「按电导加权的平均电位」这个目标**；通道开关改变权重，目标就移动——上升、下降、下冲、阈值、不应期、频率、传导都用这一条解释。

## 模型与失配

- `model.js`（浏览器与 node 共用）：HH 速率函数（静息 −65 mV、6.3 °C）、`target`（电导加权平均）、`simulate`（RK4，dt 0.01 ms）、`threshold1`/`threshold2`/`absRefractory`（二分）、`train`（尖峰时刻按线性插值求过零，频率取平均间隔）、`propagate`（电缆方程，Thomas 算法半隐式 + 指数欧拉门变量，dx 0.025 cm、dt 0.01 ms；刺激为前 0.3 cm、400 µA/cm²、0.5 ms）。
- 失配（boundary 明说）：乌贼巨轴突、6.3 °C；哺乳动物数值不同；有髓鞘纤维跳跃传导，不服从 √d；无突触、树突整合、随机通道。
- 本模型在大持续电流下尖峰变矮、80 µA/cm² 只发一次（去极化阻滞），页面如实写出并把滑杆限在 40。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：静息 V = −65、权重百分比、V 恒在 E_K 与 E_Na 之间、g_Na 极大 → 趋近 E_Na。
- 第 1 步：阈值 6.919（二分），阈下抬高与 I 成正比、阈上峰值 > +30 mV、6.5/7 两侧结论。
- 第 2 步：峰值时刻、g_Na 峰 ≈ 3.6 ms 早于 g_K 峰 ≈ 5.1 ms、下冲接近 −76、各阶段文案与数值一致。
- 第 3 步：绝对不应期 ≈ 6.39 ms、强度 40 时 Δt ≈ 9 分界、17 ms 回到 1.1 倍内、20 ms 附近阈值 5.82 < 6.92、120 时 Δt ≈ 7。
- 第 4 步：起跳 6.5 → 55 Hz、10 → 68 Hz、40 → 109 Hz、尖峰顶点低于单脉冲峰、80 只发一次。
- 第 5 步：0.5 mm → 12.39 m/s、√d 比例（直径 ×4 速度约 ×2）、尖峰形状不衰减。
- 双语键集与占位符一致；页面键都存在；深链落在存在的步骤锚点；无「左图 / 右图」。
