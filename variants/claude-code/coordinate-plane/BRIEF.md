## 定位

- category `math`，subtopic `algebra`，stage `junior`（与原版一致）。
- 受众：七年级上下；会用数轴和负数。
- 一句话直觉：**坐标就是一份走法记录：从原点出发，先横着走几格，再竖着走几格。** 一条线上一个数够用，平面上要两个；顺序约定好了不能反；地址相对原点而定。
- 与原版的差异（设计选择）：
  - 第 0 步用「找宝藏」把一维和二维放在同一张图上对比：同一个线索「往东 3 步」，宝藏在路上时只剩 1 个位置，在空地上时剩一整列 13 个，加第二条线索才剩 1 个。候选数都由 `candidates` 算出。原版用座位网格。
  - 第 1 步有「从原点走一遍」动画：青色先沿 x 轴横走，橙色再竖走，走到的点留成白点。
  - 第 2 步专讲「换原点」：三个地标不动，原点一挪，三个地址一起变，但房子减水井的差 (1, 6) 永远不变。
  - 第 3 步有换位动画：A 沿虚线滑到 A′，紫色对角线 y = x 是对称轴；a = b 时提示两点重合。
  - 第 4 步拖点走遍四块区域，走过的象限着色并写出符号。
  - 第 5 步小测：第 2 题用一个十字（滑杆或直接点格点）放点，而不是选择题。

## 模型与数据

- `model.js`（浏览器与 node 共用）：`fmtCoord`（真减号 U+2212，正数不加「+」）、`candidates`（line / plane 两种模式下符合线索的格点）、`walk`、`LANDMARKS`（房子 (2, 3)、大树 (−4, 1)、水井 (1, −3)）、`address`、`swap`、`sameAfterSwap`、`quadrant`、`SIGNS`、`sign`、`QUIZ`、`samePoint`。
- 网格固定为 −6..6（13 × 13）；第 2 步原点范围 −3..3。原点在任何位置，三个地标都还在画出的网格内。

## 数值结论与测试（`tests/core.cjs`）

- 坐标格式：(3, −2)、(0, 0)、(−4, 5)，正数不带「+」。
- 第 0 步：所有 x，路上候选 1 个，空地只报 x 时候选 13 个且都在 x 这一列，两条线索都报时恰好 1 个。
- 第 1 步：所有 169 个格点：第一段沿 x 轴从 (0, 0) 到 (x, 0)，第二段从 (x, 0) 到 (x, y)，格数 = |x| + |y|。
- 第 2 步：所有 49 个原点：房子 − 水井 = (1, 6)；原点右移 1，房子横坐标少 1；新原点地址 (0, 0)；地标始终在网格内。
- 第 3 步：所有 169 对 (a, b)：交换结果为 (b, a)；只有 a = b 时重合；中点在 y = x 上，连线与 y = x 垂直；默认 (3, 1) ↔ (1, 3)。
- 第 4 步：13 个代表点（四个象限各 2 个、两条轴各 2 个、原点）分类正确；全部格点上象限符号 = (x 的符号, y 的符号)，没有象限的点都在轴上。
- 第 5 步：题 1 答案等于 P 且选项含写反的 (−3, −4)；P 在第三象限；题 2 目标 (−2, 3) 在第二象限；题 3 答案「不同」，两点横、纵各差 3；反馈文字引用的坐标与模型一致。
- 双语：键集一致、中英不同（纯符号键除外）；HTML / app 用到的键都存在；深链目标页与锚点存在；对照链接目标存在；页脚与对照链接写明原版标题与模型 id；占位注释、provenance 样式存在；没有引入 canvas-label-guard。
