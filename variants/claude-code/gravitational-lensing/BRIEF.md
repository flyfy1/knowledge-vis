## 模型、模拟设定与失配

- `model.js`：`deflectionArcsec`/`newtonArcsec`/`focusAU`；`images`（θ±、μ±、A）；`thetaE`/`ringCase`/`HUBBLE`（1.22λ/D，λ=500 nm，D=2.4 m）；`totalA`/`lightCurve`；`sourceOf`/`imageMask`/`maskMag`（逐像素）与 `extendedMag`（以透镜为中心的一维环积分）、`arcSpanDeg`；`massFromRing`。
- 常数：G = 6.674e−11，c = 2.998e8，M☉ = 1.989e30 kg，R☉ = 6.957e8 m，pc = 3.0857e16 m。
- 失配（页面 s6 明说）：点质量、薄透镜、弱场；距离直接相减而非角直径距离；真实星系椭圆且受外部剪切（常见四像）；第 3 步点光源（有限源会削平峰值）。分辨率 60″（肉眼）和 1″（地面视宁度）是常用典型值。

## 数值结论与测试（`tests/core.cjs`）

- 太阳边缘 1.75″、牛顿式正好一半、b 加倍 → α 减半且交点 ×4、交点 ≈ 548 AU；示意放大倍数统一。
- 透镜方程两根满足方程、内外像位置与符号、|μ₊|+|μ₋| = A(u)、μ₊ − |μ₋| = 1、间距 √(β²+4)；判断题：β 0.2→2.5 内像单调靠拢变暗，β=2.5 时 ≈0.015 倍。
- 三个预设的 2θE（1.4 mas / 4″ / 2′）、对应结论档；θE ∝ √M、∝ √((1−x)/x)；θE 满足 β=0 的透镜方程。
- A(1)=1.34、A(0.1)=10.04、光变曲线对称且单峰、小 u₀ 时峰 ≈ 1/u₀。
- 面积比：逐像素（1400²）与环积分一致（1%）；弧张角（像素测得）= 2·arcsin(ρ/β)；β ≤ ρ 成闭环；内像上下颠倒；文案中的 0.4% 与 27%。
- 默认质量 5.52×10¹¹ M☉、环半径 7.27 kpc、±5% → −9.75%/+10.25%、D_s 增大时 M 单调减小并趋于下限、往返一致。
- 双语键集与占位符一致；无「左图/右图」措辞；HTML/app 用到的键都存在；深链与锚点存在；对照链接目标存在；未引入 canvas-label-guard。
