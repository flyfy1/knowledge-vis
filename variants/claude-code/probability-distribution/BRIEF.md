## 定位

- category `probability`，subtopic `basics`，stage `senior`（与原版一致）。
- 受众：高中生，会古典概型和求和符号。
- 一句话直觉：**分布就是一排柱子（取值 → 概率）。期望是这排柱子的平衡点，方差衡量柱子离平衡点有多远。aX + b 只会把柱子平移、伸缩或翻转。二项分布的柱子在 n 大时长成钟形曲线。**
- 与原版的差异（设计选择）：
  - 全页用「两颗骰子之和」作为主线。
  - 第 0 步真的掷骰子，看频率柱逼近理论概率。
  - 第 1 步把期望做成跷跷板：支点可拖，净转动效果 Σ (x − c)·P 直接读出；另有一个假设的右偏例子「快递件数」，说明期望 ≠ 众数。
  - 第 2 步把方差拆成每个取值的贡献柱。
  - 第 3 步用奖金 Y = aX + b 同轴对照两张图。
  - 第 4 步讲二项分布，第 5 步讲正态近似和连续性修正，并给出误差读数。

## 模型与失配

- `model.js` 浏览器与 node 共用，提供：
  - 分布构造：`make`、`twoDice`、`oneDie`、`coins3`、`parcels`
  - 统计量：`mean`、`variance`、`sd`、`modes`、`torque`、`tail`、`contributions`
  - 各步模型：`spreadFamily`（第 2 步）、`linear`（第 3 步）
  - 二项与正态：`choose`、`binom`、`normalPdf`、`erf`（A–S 7.1.26）、`normalCdf`、`tailNormal`
  - 模拟：`rng`（mulberry32，固定种子）、`rollDie`
- 「快递件数」的权重 22/32/20/12/7/4/3 是为演示右偏分布而假设的，不是统计数据，页面上已明说。
- 掷骰子是伪随机模拟，不是实验数据。
- 第 5 步的误差读数只覆盖页面上能调到的 n、p、k。

## 数值结论与测试（`tests/core.cjs`）

- **第 0 步**：
  - 两颗骰子的概率列为 1..6..1 / 36，并与 36 种结果的穷举对照；16.7% 和 2.8% 两个数也被钉住。
  - 用页面同一种子模拟：10000 次时的最大频率偏差小于 100 次时，且小于 1.5%。
- **第 1 步**：
  - 四个预设的期望分别是 7、3.5、1.5、1.74，每个预设都核对了 torque = E − c。
  - 众数：快递件数是 1，两颗骰子是 7，三枚硬币是 1 和 2。
  - 快递件数在 1.74 平衡，滑杆网格上的 1.70 和 1.75 都不平衡（阈值 0.005）。
- **第 2 步**：
  - 21 个分散程度下，期望都是 5，分布对称，贡献之和等于方差。
  - 方差单调增大，所有柱子都在固定坐标轴之内。
  - s = 1 时两端的贡献最大，s = 0 时中间的贡献更大。
- **第 3 步**：
  - 对 a ∈ [−2, 3]、b ∈ [−10, 10] 的全部网格，核对 E(aX + b) = aE(X) + b 和 D(aX + b) = a²D(X)。
  - D(X) = 35/6；a = 0 时方差为 0；a = 2 时相邻取值间距为 2。
  - 页面上的公式标签由 `formulaY` 生成，测试也钉住了它。
- **第 4 步**：
  - n = 1..30、p = 0.05..0.95 全部组合，核对 E = np、D = np(1 − p)。
  - n = 10 时 p = 0.5 方差最大；σ ∝ √n。
- **第 5 步**：
  - n = 100、p = 0.5、k = 60：精确值 2.84%，正态近似 2.87%。
  - n = 10、p = 0.1：k = 2 处误差超过 3 个百分点；n = 100、p = 0.5 的最大误差小于 0.1 个百分点。
  - 另核对：Φ(1.96) ≈ 0.975，密度曲线下面积为 1。
- **格式与文案**：
  - `fmt` 从 app.js 中提取后测试，只在有小数点时才去掉末尾的 0。
  - 中英键集和占位符一致；文案里没有「左图/右图/上图/下图」。
  - 深链和锚点都存在，没有用 canvas-label-guard。
