## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`makeDiffusion`（种子化随机行走，膜为厚 0.08 的板，只能经 4 个孔道穿过）、`jSimple`/`jCarrier`/`occupancy`、`tau`/`cInside`/`tHalf`/`t90`、`vEq`/`cInsideOsm`/`simVolume`/`burstCout`、`leak`/`pumpFlux`/`steadyNa`/`simNa`。
- 第 0 步是**随机模拟**：近膜处会出现「耗竭层」（两侧并非瞬间搅匀），所以页面不宣称单向穿膜次数之比精确等于两侧总数之比，只给出方向和双向计数；s0e 写「与这一侧靠近膜那一带的分子数成正比」。
- 其余各步是确定性模型，参数为示意值（每步正文写明）。
- 模型失配（s5 boundary 明说）：每步只保留一个机制；不含膜电位对离子的推动；植物细胞壁；细胞内部非瞬间混匀。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：种子可复现；分子守恒；外多内少时净流入、反过来净流出；两侧相等时 8 个种子平均净流 ≈ 0；约 9,800 步后两侧差在二项噪声 3.5σ 内；平衡后 1000 步内双向仍各有 > 15 次穿膜（测验答案）。
- 第 1 步：Km 处半数载体在忙；上限 10；载体数缩放；加倍浓度时载体通量倍数恒在 (1, 2)；Co = 1 → 1.71、Co = 40 → 1.06（提示文字引用）；全滑杆范围载体通量高于脂双层。
- 第 2 步：t½、t90 落点；R 加倍 t½ 加倍；欧拉积分与解析式一致；A/V = 3/R；R = 10 → 2.31 s；最大细胞 t90 < 60 s（图内）。
- 第 3 步：等渗 1、500 → 0.76、200 → 1.3；150 mOsm/L 为破裂阈值，< 150 必破裂，≥ 150 不破；平衡时内外相等；低渗时水先流入。
- 第 4 步：默认稳态 ≈ 12 mM；全网格上漏入 = 泵出、长时模拟收敛到稳态、只与 泵/漏 比值有关；ATP 50% 与漏入 ×2 都 ≈ 45 mM；切断 ATP 单调上升并在 300 分钟内接近 145；3 Na⁺/2 K⁺。
- 双语键集与占位符一致；页面键都存在；深链落在存在的步骤锚点；无「左图 / 右图」。
