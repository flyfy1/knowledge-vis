## 定位

- category `physics`，subtopic `mechanics`，stage `university`（与原版一致）。
- 受众：学过微积分、知道对数和指数增长的大学低年级读者。

## 模型、模拟设定与失配

- `model.js`：`orbit/orbit32`（64 / 32 位逻辑斯谛迭代，32 位用 `Math.fround`）、`splitAt`、`lyapunov`、`longTerm/periodOf`、`lorenzStep`（RK4）、`lorenzTwin`、`horizon`、`fitLine`、`lorenzRegime`、`threeBody`（自适应 RK4，基础步长 0.002，近距离自动缩步）、`energy`、`gap`、`maxRadius`；常数 `LORENZ_LAMBDA = 0.9056`、`SOFT = 0.01`、`TWIN = 1e-8`。
- 失配（终章 boundary 明说）：λ 是长时间平均，局部增长率沿轨迹快慢不一，所以预报期限点上下有起伏；三体在极近距离做了引力软化（这是模型设定，正文已说明）；「相差超过 0.1 / 1」是人为选的阈值；8 字形初值只取 8 位小数。
