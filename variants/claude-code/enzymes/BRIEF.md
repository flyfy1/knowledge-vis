## 定位

- category `biology`，subtopic `cells`，stage `senior`（与原版一致）。
- 受众：高中生；知道催化剂、反应速率，见过指数函数；不要求学过酶动力学。
- 一句话直觉：**酶用一个形状专一的口袋把能垒挖矮，速度随之指数上升；口袋数量有限所以会饱和；口袋的形状和电荷怕热、怕错的 pH；抑制剂要么抢口袋（可被底物挤走），要么把酶掰歪（挤不走）。**
- 与原版的差异（设计选择）：开头先量化「快多少」（ΔEₐ → e^(ΔEₐ/RT)，用对数半衰期条形图体会百万倍）；锁钥一步用确定性的逐个送底物动画代替随机模拟，突出「酶不被消耗」；温度一步加了「加热后冷却再测」实验，演示变性不可逆；抑制剂一步用模型算出的 E/ES/EI/ESI 比例画 20 个酶分子，让「为什么竞争性能被挤走」在图上可见，并保证图与速度曲线同源（v = Vmax × ES 占比）。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：全部滑杆格点上半衰期比 = 加速倍数；5.9 kJ/mol 每 ×10；默认 2.7 天、43 毫秒、≈5.5×10⁶；所有半衰期落在对数轴范围内；曲线端点不变、峰高 = Eₐ。
- 第 1 步：方形全部转化、产物 = 2×送来数、酶数恒 1；其他形状 0。
- 第 2 步：所有 Kₘ、酶量格点 v(Kₘ) = Vmax/2；v/Vmax = 占用比例；曲线不出坐标轴；酶量加倍 v 加倍；10Kₘ 加倍 +9.1%、Kₘ 处 +33%；自测 98.04% → 99.01%（+1%）。
- 第 3 步：最适 42.68 °C；Q₁₀ 1.97；37 °C 为 81.6%、折叠 98.2%；最适前单调升、后单调降；冷却后活性不超过新酶且随加热温度单调下降；60 °C 后低于新酶的 5%。
- 第 4 步：三种酶最适 2、6.8、8（扫描验证）；三处各自最高；胃蛋白酶 pH 8、淀粉酶 pH 2 均 < 0.1%。
- 第 5 步：全部 [I]、[S] 格点上状态比例和为 1、v = Vmax×ES 占比、图标数 20、抑制剂不加速；竞争性 47% → 87%、默认需 70 mM；非竞争性恒 20%、永不达 90%；表观 Vmax、Kₘ 公式。
- 双语：键集与占位符一致、非符号键中英不同、页脚含模型 id、正文无「左图/右图」；HTML/app 引用的键存在；深链目标与锚点存在；对照链接存在；不引入 canvas-label-guard。
