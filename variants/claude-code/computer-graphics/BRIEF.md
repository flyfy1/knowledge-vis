## 定位

- category `computing`，subtopic `graphics`，stage `university`（与原版一致）。
- 受众：大学低年级；会向量、点积、2×2 矩阵；不要求学过图形学。
- 一句话直觉：**一帧画面 = 一条按顺序执行的流水线：变换 → 投影 → 光栅化 → 深度测试 → 着色 → 抗锯齿，每一级都是一个小公式。**
- 与原版的差异（设计选择）：原版是四步切片（坐标变换、光栅化、漫反射、管线收束）。本版把管线拆成六级，每级给一个能被测试钉住的现象：变换顺序（T·R·S ≠ R·S·T）、透视（像高 × 距离 = f·h）、边函数光栅化（面积误差随分辨率收敛）、重心插值 + 深度缓冲 vs 画家算法（互相穿插时整块排序必错）、朗伯着色（像素全在余弦曲线上、亮面比例 = 月相公式）、超采样（采样数 ×4 误差至少减半）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：3×3 变换与 `compose`、`project`、`edge`/`inside`/`rasterize`、`bary`、`renderDepth`（z-buffer 与画家算法）、`compareMethods`、`lightDir`/`shade`/`renderSphere`/`litFraction`、`clipArea`（Sutherland–Hodgman 精确覆盖）、`coverage`/`exactCoverage`/`aaError`。
- 全页没有随机数；所有像素都是确定性计算。
- 失配（s6 明说）：无视锥裁剪、左上规则、透视校正插值、纹理、阴影、间接光、光线追踪；第 3、5 步的数值只对本页三角形与滑杆范围成立。

## 数值结论与测试（`tests/core.cjs`）

- 变换：所有 θ、s 下 t = 0 两种顺序一致；T·R·S 使原点移动 t，R·S·T 移动 R·S·t；两处距离 = |R·S·t − t|。
- 透视：全部 f × c 滑杆格点上像高 × 距离 = f × 1.2，柱子 z ≥ f，像落在 ±0.75 m 画面内；2→1 m 翻倍、6→5 m 增 1.2 倍。
- 光栅化：点亮 ⟺ 三个 E ≥ 0（全部 N 的全部像素）；默认三角形 N = 24–48 误差 < 1%（实测最大 0.60%），小 N 可超过 3%；顺时针输入同样处理。
- 深度：重心权重和为 1、能重建 p、在内 ⟺ 权重都 ≥ 0；全部倾斜 × 后移格点上：不穿插 ⇒ 画家算法 0 错；穿插 ⇒ 错像素数恰为 A 更近或 B 更近的像素数；默认参数穿插；滑杆两端分开。
- 着色：kₐ = p = 0 时每个像素 = max(0, n·l)；亮面比例 vs (1+cos γ)/2 误差 ≤ 0.012（64×64 网格）；环境光地板；高光只增不减，p ≥ 32 时高出 0.02 的像素 < 1/6。
- 抗锯齿：上移 0–1 像素全部 21 个位置，采样数 ×4 误差至少减半；精确覆盖率之和 = 三角形面积；64×64 采样与精确值相差 ≤ 0.03。
- 格式：`fmt` 只在有小数点时去尾零。双语键集、占位符、无「左图/右图」、深链锚点、对照链接。
