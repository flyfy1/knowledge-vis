## 定位

- category `biology`，subtopic `cells`，stage `senior`（与原版一致）。
- 受众：高中生；知道细胞有细胞核、DNA 在染色体上；会 2ⁿ 和「独立事件概率相乘」。
- 一句话直觉：**复制一次、分裂两次：第一次分开同源染色体（数目减半），第二次分开姐妹单体；各对朝向独立 + 交叉互换 = 几乎无穷的配子组合，所以兄弟姐妹平均只共享一半。**
- 与原版的差异（设计选择）：用「为什么兄弟姐妹不同」作主线；第 0 步先用代际翻倍算账说明「为什么必须减半」；第 1 步同时画细胞图和「每个细胞的染色体数 / DNA 分子数」阶梯图，并可切到有丝分裂对照；第 3 步把重组率与基因距离画成直线（每次恰好一次交换 ⇒ 重组率 = 距离 ÷ 2，最多 50%）；第 4 步模拟兄弟姐妹共享比例分布；第 5 步对比第一次 / 第二次分裂不分离的后果（三体 / 单体）。

## 模型、模拟设定与失配

- `model.js`：`counts`（各阶段每个细胞的数目表）、`meiosis(n, orient, cross)`（构造带交换片段的四分体、两个子细胞、四个配子）、`assortTypes`/`simulateAssort`、`twoGeneGametes`/`simulateRF`/`expectedRF`、`siblingPair`/`simulateSiblings`/`pIdentical`/`sharedSD`、`nondisjunction`。随机数为带种子的 mulberry32，测试可复现。
- 页面明说的失配：只画 3 对、不按比例；每对恰好一次均匀交换（真实交换次数可变、存在干涉，重组率与物理距离不严格成正比）；第 4 步不计交换；不画性染色体，不画卵细胞形成的不等分裂。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：减半时恒为 2n，不减半为 2n·2^g；46×64 = 2944。
- 第 1 步：减数分裂每细胞染色体 6,6,6,6,6,3,3,3、DNA 6,12,12,12,12,6,6,3；有丝分裂染色体 6,6,6,6,12,6；S 期后总 DNA 守恒；200 组随机排列下每个配子各对一条、每对 2 根重组单体、片段铺满且母/父源物质守恒。
- 第 2 步：2ⁿ；一次分裂 2 种互补类型各 2 个；51 次分裂漏掉某类型概率 < 1e−5；大样本各类型 1/8。
- 第 3 步：交换点在 A、B 之间才重组；各距离下 20000 次模拟重组率 = d/2 ± 0.012；最大 45%。
- 第 4 步：2^46 = 70,368,744,177,664；均值 50%、sd ≈ √(1/(8n))；n = 2 全同概率 1/16。
- 第 5 步：配子 23×4 / 24,24,22,22 / 24,22,23,23；受精卵 47,47,45,45 / 47,45,46,46；正常配子 4/0/2。
