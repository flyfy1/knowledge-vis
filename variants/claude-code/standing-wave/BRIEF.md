## 定位

- category `physics`，stage `senior`（与原版一致）。
- 受众：高中生；会读正弦曲线（振幅、波长、周期），知道一列波每点按正弦振动。
- 一句话直觉：**两列一样的波迎面叠加，y = 2A·cos(kx)·sin(ωt)：位置只在包络里、时间只在时钟里，所以形状不跑；两端钉死只放行 λₙ = 2L/n，频率排成 fₙ = n·f₁ 的台阶，推力踩中台阶就是共振。**
- 与原版的差异（设计选择）：第 0 步用「空间–时间条带」（每列一个点，向下是更早）保留历史：行波是斜条纹，驻波是竖柱和暗线，一眼分出「跑」和「不跑」；第 2 步用「右端被要求的振幅–试探波长」曲线记下试过的每个波长，模式就是它的零点；第 4 步不用秋千类比当主线，而是用多模式受迫弦模型（放大倍数、对数轴），同时给出「此刻弦形最像第几个模式」。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`yRight/yLeft/ySum/yProduct`、`crests`、`amp/coef/nodes/antinodes/classify/phaseVsOrigin/swing`、`yIncoming/yReflected/yFixed/endAmp/modeCheck/snap`、`fN/modeShape/countNodes`、`shapeAt/gain/likeness/bestMode/peaks`、`QUIZ`。
- 第 0–2 步：A = 1 cm、T = 2 s（教学慢放）、绳长 4 m。第 3–4 步：L = 0.65 m、v = 143 m/s（f₁ = 110 Hz），动画速度 = 真实频率 ÷ 440。
- 第 4 步：点力在 0.1L 处，按 12 个模式叠加，每个模式响应 1/(fₙ² − f² + 2iζfₙf)。放大倍数 = 弦上最大振幅 ÷ f → 0 时的最大弯曲。峰位由 fₙ 定；峰高、峰宽依赖选定的 ζ，是示意，不是测量。
- 视觉层与计算层：没有独立视觉层；所有曲线、标记、读数都由 model.js 逐点实算。第 0 步条带是「按当前设置算出的最近 4 秒」，第 1 步下图同理，均在文案中注明是公式算出。
- 失配（页面 s6 明说）：理想弦；真实弦有刚度与阻尼，高次谐波略偏离整数倍；管乐器一端封闭只剩奇数次谐波，不展开。

## 数值结论与测试（`tests/core.cjs`）

- y₁ + y₂ = 2A·cos(kx)·sin(ωt)（多 λ、x、t 采样，差 < 1e−9）；波峰高度 = A、以 ±λ/T 移动；叠加后最高点始终在波腹上。
- 波节恒为 0、相邻相距 λ/2、离最近波腹 λ/4；波腹摆幅 2A；A(x) 与逐时刻采样最大值差 < 1%；同相/反相与跨过的波节数奇偶一致；λ = 2.1 的波节 0.525 能被精确判定。
- 反射翻转后 = 2A·sin(kx)·cos(ωt)，左端恒静止；L ∈ {1, 1.5, …, 6} × 滑杆上全部 λ：判定「模式」⇔ 2L/λ 为整数（有理数精确检查）；模式时端点和内部波节恒静止；默认 L = 6、λ = 5 拒绝，吸附到 6，6.05 拒绝。
- f₁ = 110 Hz、fₙ/f₁ = n、f = v/λ；L = 0.325 m → 220 Hz（在滑杆格点上）；画出的形状恰有 n + 1 个波节。
- 共振：ζ ∈ {0.005, …, 0.05} 下 20–500 Hz 恰 4 个峰，偏离 fₙ < 0.5%；fₙ 处弦形与模式 n 相似度 > 0.95 且为最像的模式；半宽 ζ·fₙ 内放大倍数 ≥ 65% 峰值；峰间低；阻尼越大峰越低；扫描格点含全部 fₙ。
- 自测四题答案；文案中引用的数字（110/220/330/440、0.325、0.5%、0.65、143）。
- 双语：键集与占位符一致、非符号键中英不同；HTML/app 用到的键都存在；深链目标页与锚点存在；对照链接目标存在。
