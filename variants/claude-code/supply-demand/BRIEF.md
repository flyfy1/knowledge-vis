## 定位

- category `math`，subtopic `applied`，stage `university`（与原版一致）。
- 受众：大学低年级；会解一元一次方程、读直线图；不要求学过经济学。
- 一句话直觉：**一条水平的价格线同时碰到需求和供给，两点之差是短缺或过剩；差为 0 处是均衡。价格以外的变化移动整条线，税在买卖价之间撑开楔子，而所有得失都是图上的面积。**
- 与原版的差异（设计选择）：
  - 全页只用一个虚构市场（外带咖啡，Qd = 100 − 4P，Qs = −20 + 6P，P* = 12，Q* = 52），每步复用，读数可以跨步对照。
  - 第 0 步把每个试过的价格的差额线段留在图上，形成向交点收拢的「漏斗」。
  - 增加第 1 步「价格怎样找到交点」：一条明说是教学假设的调价规则，收敛条件 |1 − k(b + d)| < 1 在时间序列图里直接看见（单调、振荡收敛、发散）。
  - 第 2 步配一道「移动 vs 沿线移动」判断题；第 3 步弹性用「所有需求线穿过原交点」的设计，只改斜率，副图里价格与数量变化的百分比两条曲线恰好在 |εd| = 1 处相交。
  - 第 5 步税与补贴放在同一根滑杆的两侧，无谓损失是同一个公式 ½ t² · bd/(b + d)。

## 模型、模拟设定与失配（`model.js`）

- 线性需求与供给，`qd`/`qs` 在 0 处截断；`equilibrium`、`gap`、`adjustPath`（越出 0–28 元即停）、`adjustFactor`、`shifted`、`pivotDemand`（穿过原交点）、`elasticityD/S`、`policy`（t < 0 为补贴）、`buyerShare`、`surplus`（闭式面积）、`dwlFormula`、`surplusNumeric`（数值积分对照）。
- 数字是虚构的教学市场；调价规则是教学假设；不含收入效应、定价权、时间滞后、外部性（终章 boundary 明说，并链接外部性页）。

## 数值结论与测试（`tests/core.cjs`）

- 均衡 12 元 / 52 百杯、停供价 3.33、最高价 25；差额在 0–25（步长 0.5）上的符号与单调收拢；默认 18 元时 28 vs 88。
- 调价规则：k 全格点上，线性区内每轮偏差比 = 1 − 10k；k = 0.05 单调且 12 轮后在 0.005 内；0.15 越过后收敛；0.22 摆幅增大并冲出图外；k = 0.2 为边界。
- 移动：全格点上两次单独移动的变化之和 = 同时移动的变化；交点在图内；判断题的新交点落在原需求线上。
- 弹性：b = 1..16 时 ΔP = 20/(b + 6)、ΔQ = 20b/(b + 6)，%ΔQ ÷ %ΔP = |εd| 精确成立（s3hint 的「在 |εd| = 1 处交叉」）。
- 税：全格点上楔子 = t、两侧数量一致、份额 = d/(b + d) = εs/(εs + |εd|)；b = 4 时 60%。
- 剩余：t ∈ [−6, 10] 全格点闭式面积 = 数值积分（1e−6）、DWL = 闭式 = ½|t||ΔQ|；文案引用的 563.33、533.33、30、120、−5 → 30 由测试钉住。
- 双语：键集与占位符一致、中英文本不同、页脚含模型 id；HTML/app 引用的键与控件 id 存在；深链目标与锚点存在；占位注释与 page-provenance.css 在。
