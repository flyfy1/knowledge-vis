## 定位

- category `probability`，subtopic `stochastic`，stage `university`（与原版一致）。
- 受众：大学低年级；知道概率、期望、二项分布的含义；Beta 分布、后验在页内就近解释。
- 一句话直觉：**每拉一次既在赚也在学；探索的代价现在付，收益以后才拿到。遗憾把这笔账算成一个数。**
- 与原版的差异（设计选择）：原版用五台机器，依次讲贪心/ε-贪心/UCB/汤普森后再对比。本版用四台机器（A 0.35、B 0.55、C 0.65、D 0.45）贯穿前五步，并加了一步「先试后定」：用二项分布**精确**算出押中各台的概率与期望遗憾随 m 的 U 形曲线，让「探索代价 vs 押错代价」先变成可以算的东西，再引出 ε-贪心、UCB、汤普森。第 3、4 步各用一局固定种子的完整轨迹，可拖动 t 或播放，旁边累计每台被拉的次数；第 4 步可从后验抽签，统计结果对照精确的「是最好的概率」。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：mulberry32、Box–Muller、Marsaglia–Tsang gamma → Beta 抽样；`game`（第 0 步每台固定结果流，换局重排概率）；`etcCommit`（二项分布 + 并列随机的精确概率）、`etcRegret`、`etcSimulate`；通用 `run` 与策略 `epsGreedy`、`ucb`、`thompson`；`meanRegret`、`epsCurve`；`trace`（第 3、4 步单局逐步状态）；`ucbIndices`；`lgamma`、`betaPdf`、`probBest`（网格积分）；`compare`（第 5 步）。
- 模拟：遗憾为伪遗憾（用真实概率算期望损失，不是实际中奖次数之差）。第 2 步 200 局、第 5 步 100 局，固定种子；所有策略先把未拉过的臂各拉一次（汤普森除外，它直接从 Beta(1,1) 抽）。
- 失配（终章明说）：真实场景中概率漂移、结果延迟、依赖上下文；遗憾只能在模拟里算；排名对参数敏感。

## 数值结论与测试（`tests/core.cjs`）

- 抽样器：Beta(3,7) 均值与方差、Gamma(0.5) 均值、lgamma、Beta 密度积分为 1。
- 第 0 步：50 局都用同一组四个概率且会换位置；结果流够 20 次。
- 第 1 步：押中概率和为 1；m = 1 → 34%、48.5；argmin m = 20、24.4；精确值 vs 2 万局模拟（押中比例 ±0.012、遗憾 ±1.2）；对称臂对半分。
- 第 2 步：51 个 ε；贪心 73.7、最后 100 次 52%；ε = 0.5 为 81.3 且斜率恒定；argmin 0.08、30.7；ε ∈ 0.05–0.1 曲线前陡后缓；后段斜率不为 0；所有曲线在 0–90 轴内。
- 第 3 步：c = 1 → 43/47/182/28；c = 0 → B 297；c = 2 → C 107；每一步所拉的臂都是指数最大的。
- 第 4 步：结束时 8/70/213/9；P(C 最好) ≈ 0.954；4 万次抽签比例与 probBest 差 ≤ 0.006；均匀先验各 1/4；轨迹可复现。
- 第 5 步：Δ = 0.1 时 107/96/47/44 与排序；Δ ≥ 0.1 汤普森最低、Δ = 0.02、0.05 ε-贪心最低；ε-贪心后段斜率不降、汤普森变平。
- 双语：键集与占位符一致、非符号键中英不同；HTML/app 用到的键都存在；深链目标与锚点存在；对照链接存在；不引入 canvas-label-guard。
