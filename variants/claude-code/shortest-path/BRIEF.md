## 模拟设定与失配

- 全部是确定性计算（无随机）。道路图 8 节点 12 条边；网格 16 × 10，泥地 5 × 7、岩石墙留缺口。
- 平局：图上按字母，网格上按 f、再按 h、再按加入顺序。终章说明换一种平局规则距离相同、路线可能不同。
- 失配（终章 boundary 明说）：线性扫描 O(V²) vs 堆 O((V+E) log V) 未实测；负环无定义；无向图负边即负环；只允许四方向。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：21 条简单路线；最短 SACEFT = 16 唯一；段数最少 SADT = 18 唯一；贪心 SACBEFDT = 23；每条代价 = 权重和。
- 第 1 步：8 轮；各节点 = 暴力枚举最短；确认顺序 S A B C E D F T、距离 0,2,6,7,10,12,12,16 不减；E 11→10；D/F 平局 D 先；确认后不再变。
- 第 5 步：从 T 出发每轮候选唯一；结果 = 暴力枚举；S = 16。
- 第 2 步：w ∈ −4..4，贝尔曼-福特 = 暴力；迪杰斯特拉恒为 A=2、T=5；不一致 ⇔ w < −2。
- 第 3–4 步：m = 1..9 最优 = min(必穿泥, 必绕泥)；均确认 ≥ 100 格；路径代价自洽；w ∈ {0, 0.5, 1} 均最优；加权 A* 确认格数不多于迪杰斯特拉；m=1 直线 13、m=2 穿 5 格泥 18（绕路 21）、m≥3 绕路 21；m=3 时 128/64 格、w=2、3 代价 23；反向搜索验证 h 不高估。
- 双语：键集与占位符一致；中英不同；无「左图/右图」；纯文本键无 HTML 实体；键、控件、深链与锚点、对照链接、占位注释都存在。
