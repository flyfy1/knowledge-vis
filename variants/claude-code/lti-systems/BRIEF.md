## 定位

- category `signal`，subtopic `systems`，stage `university`（与原版一致）。
- 受众：大学低年级；会求和记号 Σ，见过复数 e^(jθ)；不要求学过信号与系统。
- 主线：**一只看不见内部的黑盒子**。所有「实际输出」都是按盒子自己的规则真跑出来的，从不由 h 卷积得到；卷积只用来做「预测」，与实际对账。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：7 个盒子的规则（`BOXES`）、`recordH`、`predict`（因果卷积截到窗口）、`superposition`/`shift`/`prediction`、`stepStudy`、`worstCase`、`sineTest`（128 点输入、后 64 点 DFT、频外功率比例、新频率列表）、`Hof`（由 h 求 H）、`Hclosed`（闭式）。
- 所有盒子从零状态开始，只在 n = 0..L−1 上看输入；平滑器的 h 无限长，窗口内预测只用 h[0..15]（因果），页面边界段明说。
- 平移检验只比 n = d..15（两边都有定义处），图上灰带标出不比较的区域。
- 第 5 步取 ω = 2πm/64 让 64 点窗口装下整数周期，DFT 无泄漏；页面边界段说明其他频率会有窗口泄漏，不是盒子造出的新频率。
- 无随机数据；全部是确定性计算。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：4 组预设 × 每个 c，部分和 = x 的前 c 项；8 块之和 = x。
- 盒子规则与 i18n 中印出的公式一致（随机输入逐点核对）。
- 第 1 步：3 个 LTI 盒子 × 4 组预设，h 预测与实际最大差 < 10⁻⁹；h 的前几项与闭式一致；h 落在 ±1.2 轴内。
- 第 2 步：全部 A 格点 × d ∈ 1..4：LTI 三盒三项全过；平方器、加偏置叠加失败/平移通过/预测失败；预热放大器叠加通过/平移失败/预测失败；限幅器平移恒过，叠加与预测通过 ⟺ |A·x₁ + x₂| ≤ 1 ⟺ A ≤ 1.25，A ≥ 1.5 时差值随 A 单调增大。
- 第 3 步：s = cumsum h、h = diff s（所有盒子、a 格点）；回声室终值 1.5；差分器 [1, 0, 0, …]；平滑器 s[15] = 1 − a¹⁶、直流增益 1；「还差」提示恰在 a ≥ 0.8 出现；a 增大时 h[0] 变小、s 爬得更慢。
- 第 4 步：r 格点 × n₀：稳定 ⟺ |r| < 1、因果 ⟺ n₀ ≥ 0；最坏输入确实达到 Σ|h|；稳定时累加不超过 1/(1−|r|)；前 31 项 Σ|h| 只依赖 |r|；r = 1 时 Σ|h| = 31 且线性增长。
- 第 5 步：7 盒 × 31 个 m × 7 个 A：LTI 盒频外功率 < 10⁻⁹、增益 = |H| 闭式、由 h 算的 |H| = 闭式、相位 = ∠H；平方器输入频率处为 0、频外 100%、新频率恰为 {0, 2m 折回}；限幅器 A ≤ 1 时为直通，A > 1 时出现频外成分（唯一例外 m = 16，增益 1/A），新频率都是奇数倍（折回）；预热放大器频谱铺开；平滑器单调低通、差分器单调高通且 m = 31 处 ≈ 2；回声室 |H| 在 [0.5, 1.5]。
- 双语：键集与占位符一致；非符号键中英不同；页脚含模型 id 与原版标题；无「左图/右图」字样；HTML/app 用到的键都存在；深链目标与 `#stepN` 锚点存在；对照链接目标存在；页头占位注释与 provenance 样式存在。
