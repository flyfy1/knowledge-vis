- category `computing`，subtopic `algorithms`，stage `university`（与原版一致）。

## 数值结论与测试（`tests/core.cjs`）

- 所有算法对 n = 1..40 的多组输入都排对。
- 选择排序：任何输入都是 n(n−1)/2；事件日志 28 次比较。
- 插入排序：已排好 n − 1、倒序 n(n−1)/2；200 组平均 ≈ n(n−1)/4 + n − Hₙ（±3%）；单组在 0.7–1.4 倍 n(n−1)/4。
- 归并：n = 16 恰 4 层、第 1 层恒 8、每层 ≤ n − 合并数、总 ≤ 64、各段有序；n = 2..300 都 ≤ n·log₂n。
- 增长：文案中所有区间（×4–4.3、×2.9–4.9 及 n ≥ 256 时 3.9–4.1、×2.1–2.9 且归并递减、0.65–0.89、÷n² → 0.5、n = 2048 时 1–2.2 百万）。
- 快排：已排好/倒序 + 首元素 496 次、31 层；9 组随机性下随机/三数取中 5–10 层、100–200 次；打乱 + 首元素 100–199；比较数 = Σ(m − 1)。
- 下界：mergeWorst ≥ ⌈log₂ n!⌉（n ≤ 7），n = 5 时 8 vs 7；候选数单调不增、终为 1；n ≥ 4 有恰好达下界的运行；n = 3、5 有低于下界的运行；Stirling 近似 −1.44n；计数排序 0 次比较。
- 双语键集/占位符一致、无「左图/右图」、id 唯一、深链锚点存在。
