## 定位

- category `chemistry`，subtopic `solutions`，stage `senior`（与原版一致）。
- 受众：高中化学（会 pH、物质的量、离子方程式；弱电解质的电离平衡在第 2 步就近解释）。
- 一句话直觉：**每滴带进的 OH⁻ 一样多，但 pH 看的是 H⁺ 的倍数；快到等当点时剩下的酸只有一滴的量，一滴就让 H⁺ 缩小约一千倍——悬崖由此而来。**
- 与原版的差异（设计选择）：原版用斜率 dpH/dV 描述悬崖；本版逐滴画「每滴的 ΔpH」柱，并在读数里给出「这一滴消掉剩余酸的百分比」（1% → 100%），把悬崖的原因落到「倍数」上。等当点用「加入的 OH⁻ 长条填满原有酸的框」来定义，与曲线共用横轴。浓度单独成一步，用教材的「±0.1% 突跃范围」量化悬崖；选指示剂一步给出精确等价「变色点 ∈ 突跃范围 ⟺ 终点误差 ≤ ±0.1%」，并放大 23–27 mL 看终点与等当点之差。原版的「测未知浓度」练习本版没有做。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`pH(kind, pKa, c, V)` 用完整电荷守恒 [H⁺] + [Na⁺] = [OH⁻] + [A⁻] 在 log[H⁺] 上二分求解（无 Henderson–Hasselbalch 近似）；`dropJump`、`inventory`、`jump`（±0.1%）、`volumeAt`（二分求达到某 pH 的体积）、`endPoint`、`inJump`。
- 页面所有数都由模型算；曲线是计算结果，不是实验数据（页面明说）。
- 失配（终章明说）：25 °C、一元酸、酸碱同浓度、体积相加、浓度当有效浓度；不计离子强度、CO₂、指示剂消耗；「终点 = 变色范围中点」是本页约定，真实变色点因人因光而异。

## 数值结论与测试（`tests/core.cjs`）

- 求解器：3 种浓度 × 强/弱 × V 网格上电荷守恒残差 < 1e−9；强酸与闭式解一致；pH 随 V 严格单调（0.01 mL 网格）。
- 第 0 步：起点 1.00、强酸等当点 7.00、20 mL 时 1.9–2.0、醋酸起点更高且突跃更矮；2.50 mmol、25.00 mL 文案钉住。
- 第 1 步：20 mL 剩 0.500 mmol、每滴 1%；24.95 mL 剩 0.005 mmol（一滴）；两滴各 +3（±0.05）；约一千倍；最大柱在 25 mL 两侧，此前单调增大、此后单调减小；柱高不超出 0–3.2 坐标。
- 第 2 步：pKa 2–10（步长 0.02）等当点 pH > 7 且随 pKa 升高；突跃随 pKa 变矮；pKa ≥ 4 时半等当点偏差 < 0.01；pKa 2 时 ≈ 0.18；醋酸 4.76。
- 第 3 步：4.30–9.70、5.30–8.70、6.28–7.72、7.75–9.70 逐个钉住（±0.005）并核对文案；醋酸 0.00100 < 0.4；稀释使突跃变矮。
- 第 4 步：24 种组合下「变色点在突跃内 ⟺ |误差| ≤ 0.1%」；终点处 pH = 变色点；甲基橙 −0.36%、为盐酸 0.100 最差；醋酸 0.100 只有酚酞；强酸 0.00100 只有溴百里酚蓝；甲基橙、甲基红在醋酸上早 5 mL 以上；判断题答案。
- 双语：键集与占位符一致、中英文不同、无「左图/右图」；HTML/app 用到的键都存在；3 条深链目标与锚点存在；对照链接存在；未引入 canvas-label-guard。
