## 定位

- category `probability`，subtopic `stochastic`，stage `university`（与原版一致）。
- 受众：大学低年级；知道概率、平均值、标准差，见过正态分布；第 2 步用到积分 = 曲线下面积。
- 一句话直觉：**把要算的量写成随机实验的平均值，然后真的做很多次；误差按 σ/√N 缩小，σ 越小、样本越均匀越省点。**
- 与原版的差异（设计选择）：第 1 步用 500 次重复的直方图 + 双对数散布图直接展示 1/√N；第 2 步比较投点法与平均值法（同 1/√N、不同常数）；第 3 步把「维度灾难」写成网格与随机在同一预算下的相对误差，并如实说明随机法的相对误差也随 p 变小而增长；第 4 步分层抽样（斜率 −1/2 → 约 −3/4）；第 5 步用一个故意做坏的 mod 256 线性同余生成器展示伪随机数的格子结构和偏差。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`mulberry`、`badLcg`（a = 5, c = 1, m = 256）、`scatter`、`replicate`（500 次）、`exact`（Simpson）/`integrate`/`integrateReps`、`ballFrac`/`gridEstimate`/`mcEstimate`/`dimTable`、`jitter`/`stratReps`/`slope`、`pairs`/`distinctPairs`/`firstNumbers`。
- 全部伪随机、固定种子；每一步的重复实验种子由 N、k、d 决定，「换随机数」在种子 1–20 中轮换。
- 失配与限度（页面 s6 boundary 明说）：SE 是典型值不是保证；π ± 2SE 灰带是围着已知真值画的参照，不是置信区间；分层斜率 −3/4 只对二维光滑边界；坏生成器是刻意构造的。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：20 个种子 × 10000 点的命中判定与滚动估计；N ≥ 30 时估计在坐标范围 2.5–3.8 内；p = π/4、σ_g ≈ 1.64。
- 第 1 步：四档 N 的 500 次实测 sd 与 SE 相差 < 10%；落在 ±1.96SE 的比例 93–97%；相邻档 sd 比 0.5 ± 0.06；直方图范围 π ± 0.6 包住全部估计；100 倍点数 → 误差 1/10。
- 第 2 步：两个函数的精确值（e^(−x²) 为 0.746824，四分之一圆为 π/4）；平均值法每样本 sd 更小；400×400 重复实测 sd 与 σ/20 相差 < 15%；e^(−x²) 时点数倍数 ≈ 4.7；估计曲线在坐标范围内。
- 第 3 步：d = 2..10 的球体积比与闭式一致；网格在预算内；d = 2 每轴 64 格、d = 8 每轴 2 格；d ≤ 4 网格相对误差 < 5%；d ≥ 8 网格估计为 0；随机法单次误差都在 3 个相对 SE 内、d ≥ 8 仍 < 50%；p 单调减、相对 SE 单调增；绝对 SE ≤ 1/(2√N)。
- 第 4 步：每档分层 sd < 纯随机且比值越来越小；纯随机 sd 与 SE 相差 < 15%；斜率 −0.5 ± 0.03、−0.73 ± 0.02；每格恰好一个点。
- 第 5 步：20 个种子下坏生成器 5000 对最多 128 个不同点、10000 点估计离 π 0.04–0.085、第 500 点后变化 < 0.03、点落在 ≤ 6 条平行线上、周期 256；好生成器 5000 对全不同；同种子开头四个数一致。
- 双语：键集与占位符一致、中英文本不同（公式按钮 fGauss 除外）；HTML/app 用到的键都存在；控件 id；深链与对照链接目标存在；无 canvas-label-guard。
