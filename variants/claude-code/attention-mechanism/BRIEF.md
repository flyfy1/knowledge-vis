## 定位

- category `computing`，subtopic `ml`，stage `university`（与原版一致）。
- 受众：大学低年级；会向量点积、2×2 矩阵；听说过 softmax 更好，但不要求。
- 一句话直觉：**注意力 = 用查询给每个键打相似度分 → softmax 变成和为 1 的权重 → 按权重平均值向量。**
- 设计选择：从一张 4 行的「软查表」起步（先看清为什么要软），再拆 softmax，再进入一句话的 Q/K/V、整句矩阵与因果遮罩，最后讲两个常被跳过的点：√d 缩放（用固定种子模拟钉住）和注意力对词序的置换不变性（位置编码）。

| 0 软查表 | 点积 | 只取最像的一条 vs 按相似度混合，有何不同？ | 查询方向（|q| = 2.5）→ 4 个得分、权重、硬/软输出 | 拖或「转一整圈」：硬查表是台阶，跨分界跳 2–3；软查表平滑，每度最多变 0.046 | 4 个单位键、值 3/1/−2/0.5 |

| 2 Q、K、V | 矩阵乘向量 | 一个词怎样向别的词提问？ | φ（W_Q = 3·旋转 φ）、提问词 → 该词的 5 个权重 | φ = 0：「它」平分给「球」0.45 和自己 0.46；φ = 90°：「它」→「猫」0.59，「猫」→「它」只有 0.01（不对称） | 手设二维词向量，W_K = W_V = I |

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：所有查询角度权重和为 1、硬 = 最高分的值、软 = Σw·v；硬查表 4 处跳变、幅度 2–3；软查表每度最大变化 0.046（0.05° 细扫 < 0.0475）。
- 第 1 步：β × c 全部滑杆格点上加 c 权重不变；β = 0 各 0.25、有效条数 4；有效条数随 β 单调降；β = 5 时 0.77 / 1.54，键 1+2 > 0.999。
- 第 2 步：所有 φ、遮罩下每行和为 1、O = A·V；φ = 0 得分矩阵对称，「它」→ 球 0.45、自己 0.46；φ = 90° 它→猫 0.59（最大）、猫→它 0.01。
- 第 3 步：所有 φ：遮罩后右上三角和为 0、第一行 1.00、最后一行全正；不遮罩全正；输出都在凸包内；5 个值向量都是凸包顶点。
- 第 4 步：每个 d 标准差 / √d 在 ±8% 内，缩放后 0.93–1.04；未缩放最大权重随 d 严格增；梯度 512 时 < d = 1 的 1/5；缩放后范围 0.30–0.37 / 0.18–0.22；直方图范围（±80、±5）覆盖几乎全部样本。
- 第 5 步：所有 a：「咬」输入两句相同；a = 0 距离全 0；a > 0 三个都 > 0；点都在视野内；距离曲线 < 1.2（纵轴上限）。
- 格式与双语：`fmt` 只在有小数点时去尾零；键集、占位符一致；无「左图/右图」；静态键无占位符；深链锚点存在；对照链接存在。
