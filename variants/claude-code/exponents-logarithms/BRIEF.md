## 定位

- category `math`，subtopic `algebra`，stage `senior`（与原版一致）。
- 受众：高中生；会乘方、知道一次函数「加等量」。不要求学过对数。
- 一句话直觉：**对数数的是「乘了几次」。** 所以它是指数的逆问题，也因此把乘法变成加法、把指数增长拉成直线。
- 与原版的差异（设计选择）：用两只培养皿（+3 与 ×2）贯穿第 0、4 步；对数用「夹逼」逐次折半去求非整数指数，让「log₂6 是一个确定的数」被亲眼逼出来；运算律用一把可视的对数尺（长度首尾相接）说明，而不是对账表；最后用对数刻度把第 0 步被压扁的 A 皿救回来，并在同一张图上演示换底（线不动，刻度换）。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：A、B 公式；每小时 A +3、B ×2；B 在第 4 小时首次领先且 4..24 一直领先、1..3 落后、0 时相等；2²⁴ = 16,777,216（「一千六百多万」）。
- 第 1 步：滑杆格点上 a⁰ = 1、(a^0.5)² = a、a⁻¹ = 1/a、a^(x+1)/aˣ = a、aˣ > 0、涨跌判断；2^0.5 ≈ 1.414。
- 第 2 步：log₂8 = 3、log₂32 = 5、log₃81 = 4、log₂(1/8) = −3、log₁₀1000 = 3 精确；log₂6 ≈ 2.585；三种底数 × 目标滑杆全部格点上夹逼区间始终包含真值、宽度 1/256。
- 第 3 步：m, n ∈ 1..32 全部组合上 log(mn) = log m + log n 且落在尺内；mᵏ 的幂律。
- 第 4 步：rᵀ = 2、第 k 次翻倍在 kT（对数刻度等距）、log₂y / log₁₀y = log₂10 ≈ 3.32 与 r 无关、72 法则提示与 5% 判据一致；T(1.07) ≈ 10.24。
- 第 5 步：三题答案 −3、4、1,048,576 及选项键。
- 双语：键集与占位符一致、非符号键中英不同；HTML/app 用到的键都存在；深链目标页与锚点存在；对照链接目标存在；不引入 canvas-label-guard。
