## 定位

- category `physics`，subtopic `matter`，stage `junior`（与原版一致）。
- 受众：初二、初三学生；知道重力 G = mg、压强 p = ρgh 的意思，会用比例。
- 一句话直觉：**浮力是上下两个面的压力差，算出来正好等于被挤走的那份液体的重量。**
- 与原版的差异（设计选择）：从一块挂在弹簧秤下的铝块的「读数变小」出发，先用两个面的压力差解释浮力的来源，并用它说明浸没后浮力为何不随深度变，再用溢水杯验证阿基米德原理。之后把原理用在三处：浮沉比较两种密度，钢船靠平均密度浮，密度计的刻度不均匀。全程只用一个物体尺寸，g 取 9.8 N/kg。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`lowered(z)` 给读数与浮力；`pressure`、`faces(z)` 给上下表面压力；`overflow(mat, V)` 给浮力与排开水重；`settle(ρo, ρl)` 判浮沉并给浸入比例或支持力；`boat(H, cargo)` 给吃水、平均密度、最大载货、实心团体积；`hydLevel(ρ)` = (m/ρ − bulb)/stem。
- 设定：G = 9.8 N/kg；铝 2.7 g/cm³、5×5×8 cm（W ≈ 5.29 N）；液体 0.92 / 1.00 / 1.10；第 3 步物体 200 cm³；钢 7.9 g/cm³、600 g；密度计 18 g / 14 cm³ / 0.5 cm²。
- 失配（页面明说或示意）：水槽足够大、液面不随浸入升高；第 1 步忽略侧面压力（相互抵消）；钢船吃水按薄板近似；悬浮只在密度恰好相等时出现，实际不稳定；画面比例为示意。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：读数 + 浮力 = W（0..12 cm 全网格）；8 cm 前浮力线性增大，之后恒为 1.96 N；W ≈ 5.29 N、540 g、200 cm³ 与正文一致。
- 第 1 步：下表面压力 − 上表面压力 = 第 0 步的浮力；浸没前上表面压力为 0；浸没后两面增量相等；20 cm 下表面 4.9 N 在坐标轴内。
- 第 2 步：每种材料、每个体积，浮力 = 排开水重且与材料无关；铁/铝 ≈ 2.93（「将近 3 倍」）。
- 第 3 步：三种液体 × 0.2..3 全网格的浮/悬/沉判定、浸入比例 = ρo/ρl、支持力 = W − F最大 > 0；1.05 在清水沉、浓盐水浮。
- 第 4 步：实心团约 76 cm³；最大载货 400 / 1000 / 0 g；沉没当且仅当平均密度 > 1、当且仅当超过最大载货；吃水 = 质量 ÷ (ρA)。
- 第 5 步：0.8–0.9 间隔 5.0 cm、1.1–1.2 约 2.7 cm；液面始终在 20 cm 细管上；刻度在高密度端更密。
