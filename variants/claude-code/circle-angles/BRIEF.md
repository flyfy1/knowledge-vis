## 定位

- category `math`，subtopic `geometry`，stage `junior`（与原版一致）。
- 受众：初中生；认识圆、半径、角的度量，学过等腰三角形底角相等、三角形内角和 180°。
- 一句话直觉：**站在圆上看一条弦，张角是站在圆心看它的一半；在同一段弧上怎么走都不变，换到弦的另一侧就变成它的补角。**
- 与原版的差异（设计选择）：把「角不变」做成一张「P 的位置—量得角度」的散点图，P 走过的每个位置都留下一个点，改圆心角会开一条新记录、旧的留作对照，于是「水平线」和「落在一半上」都是肉眼可见的历史；证明步同时覆盖 O 在角内（相加）和角外（相减）两种情形，拖 P 就能切换；直径一步用「弦到圆心的距离 d」做连续对照；最后加一个应用步：用三角尺的直角找圆心（泰勒斯定理的逆用）。

## 模型、判定口径与失配

- `model.js`（浏览器与 node 共用）：所有角度由 `angleAt`（叉积、点积的 atan2）从点坐标算出，不用「圆心角 ÷ 2」反推。`chord`、`pointAt`、`inscribed`（P 离 A/B 不到 1° 时返回 null）、`central`、`proof`（含 O 是否在角内的判定）、`cFromOffset`、`arcPoint`、`quad`、`setSquare`、`intersect`、`QUIZ`/`quizKey`。
- 纯几何，没有随机数据或测量误差模拟；读数保留 0.1°。终章 boundary 说明：恒定是定理，不是测量凑巧；纸上量角另有误差。

## 数值结论与测试（`tests/core.cjs`）

- 全部圆心角滑杆格点 × 全部 P 位置：优弧上 ∠APB = ∠AOB/2、劣弧上 = 180° − ∠AOB/2（容差 1e-9），只有贴近 A/B 时无定义；第 1、2 步滑杆范围内 P 始终在优弧上且有定义。
- 证明：OA = OP = OB；两组底角相等；∠AOD = 2α、∠BOD = 2β；角内时相加、角外时相减，∠AOB = 2∠APB；两种情形在滑杆范围内都能到达；默认（100°, −25°）是相加情形。
- 直径：d = 0 时全圆 90°；d ∈ (0, 0.8] 时上方 < 90°、下方 > 90°（含 d = 0.4 提示）。
- 两侧：∠APB + ∠AQB = 180°、∠AQB = 优角/2（全部 c × u × v 格点）。
- 找圆心：∠XVY = 90°、XY = 2、XY 过圆心；任意两条不平行的线交于圆心。
- 自测答案 40°、115°、90°（由模型在实际图形上量出）。
- 双语：键集与占位符一致；HTML/app 用到的键都存在；元素 id 不重复；深链目标与锚点存在；对照链接目标存在；不引入 canvas-label-guard。
