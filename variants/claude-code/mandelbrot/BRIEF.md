## 定位

- category `math`，subtopic `calculus`，stage `university`（与原版一致）。
- 受众：大学低年级；会复数的加法与乘法（知道复数是平面上的点），知道三角不等式。
- 一句话直觉：**一条规则 z → z² + c，一个判据 |z| > 2；判据可证明，黑色只是「有限步内没逃」的数值结果。**
- 与原版的差异（设计选择）：原版强调「无限放大」的观感；本版先让读者手动追轨道，再证明半径 2 是不归点，然后才涂色。面积随迭代上限的收敛、内部的周期结构与 p/q 旋转、浮点精度的边界、朱利亚集连通性的二分法，都给出可核对的数值或明确的定理出处。

## 模型、数值设定与失配

- `model.js`（浏览器与 node 共用）：`orbit`、`escapeTime`、`escapeFast`（心形/圆盘闭式判定 + 精确重复检测，测试证明与 `escapeTime` 结果一致）、`smoothEscape`（仅用于第 4 步配色）、`modSeq`、`areaEstimate`、`attractor`、`multiplier`、`bulbCenter`（对 f_c^q(0) = 0 用牛顿法）、`alphaFixed`、`rotationAround`、`insideShare`、`ulp`、`juliaEscape`。
- 所有黑色都是「有限步内没逃」，不是证明；第 4 步越深，黑色里越可能混有逃得比 N 晚的点（页面明说）。
- 周期检测：4000 步瞬态 + 容差 10⁻⁷；左图（第 3 步）为速度只用 700 步、周期 ≤ 12，检测不到的内部像素涂灰。
- 面积是格点中心计数估计，不是精确值；只给出本页能复核的数字（1.51、1.507）。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：各预设的轨道行为；0.3 在第 12 步、−0.1+0.65i 在第 75 步逃逸（文案引用值由测试钉住）。
- 第 1 步：在 |c| ≤ 2.5 的网格上，首次越界时 |z| ≥ |c|、之后严格增长且增长倍数 ≥ |z| − 1；c = −2 恰好停在 2；c = 2.1 第一步越界；纵轴压缩的说法。
- 第 2 步：`escapeFast` = `escapeTime`（网格 × 两个 N）；心形、圆盘内部不逃；N = 1 恰为半径 2 的圆盘；网格上幸存点落在 Re ∈ [−2, 0.48]、|Im| < 1.13；面积随 N 不增、N = 1000 时 ≈ 1.51、1200² 格点 N = 5000 时 ≈ 1.507、N = 100 以后变化 < 0.04。
- 第 3 步：心形周期 1、圆盘周期 2；6 个泡（及 2/3）中心周期恰为 q、0 在第 q 步回到 0、超吸引、α 是不动点、绕 α 跳 p 位；泡内离中心 1/4、1/2 处周期与跳步不变；报出周期的循环都吸引。
- 第 4 步：迷你拷贝中心周期 3；海马谷在 10⁰–10⁹ 每一层都有内外两种点和 > 30 种逃逸时间；迷你拷贝 10^1.5 时部分为黑、10^3 起全黑；页面所有宽度下 10⁹ 时像素 ≥ 10⁴ 个双精度间距、10¹³ 时 < 50 个。
- 第 5 步：预设在集合内/外；兔子 = 1/3 泡中心；c = i 的 2-循环排斥（无内部）；c = −1 的朱利亚集关于原点对称。
- 双语：键集与占位符一致、非符号键中英不同；HTML/app 用到的键都存在；深链目标页与 `#stepN` 锚点存在；对照链接目标存在；页头占位与 `page-provenance.css` 存在；未引入 `canvas-label-guard.js`。
