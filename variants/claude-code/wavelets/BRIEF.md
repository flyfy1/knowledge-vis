## 定位

- category `signal`，subtopic `transforms`，stage `university`（与原版一致）。
- 受众：大学低年级；知道正弦波、频率（Hz）、「频谱 = 各频率成分的强度」（傅里叶页），知道标准差。
- 一句话直觉：**固定窗口的时间宽度与频率宽度此消彼长；小波让窗口随频率伸缩，包络里周期数不变，于是高频看得准时间、低频看得准频率；Haar 这样的小波基把突变压缩成少数系数。**
- 与原版的差异（设计选择）：第 0 步用「同一声短音挪时刻、幅度谱完全不变」（而非时间反转）；第 1、3 步用一段专门设计的测试信号——频率很近的两个音（12/20 Hz）+ 时刻很近的两声咔嗒（0.97/1.03 s），并用同一条「谷深 < 0.5」判据给每档窗口、每个 ω₀ 打分，读者能看到「没有一档固定窗口能兼顾，ω₀ = 7–10 的小波可以」；第 4 步用保留 K 个系数的重建误差比较 Haar 与 DCT；第 5 步是软阈值去噪。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：基 2 FFT、`burst`/`burstSpectrum`、`testSignal`、`gaussWin`/`winSpread`/`stft`、`morletS`/`morletSigmaT`/`morletSigmaF`/`cwt`、`separated`/`stftResolution`/`cwtResolution`、`haar`/`ihaar`/`dct`/`idct`/`keepK`/`rmseCurve`/`stepRecon`、`blocks`/`noisy`/`denoise`/`denoiseCurve`。
- 采样率 256 Hz；第 1、3 步测试信号 2 s；频谱图 NFFT 512、帧移 4 点。σt、σf 都按能量（|·|²）的标准差，乘积 1/(4π)。
- 失配与限度（页面 s6 boundary 明说）：全部模拟；「谷深 < 0.5」是本页判据；Haar 优于 DCT 只对跳变信号展示过；最佳阈值只对本信号与 σ=0.5；尺度图两端有补零造成的边缘亮纹。

## 数值结论与测试（`tests/core.cjs`）

- FFT = 直接 DFT。第 0 步：0.10–0.90 s 全部 81 个时刻幅度谱与参照最大差 < 1e-12、峰都在 32 Hz、相位随时刻变；包络 FWHM ≈ 0.094 s（「约 0.1 秒」）。
- 第 1 步：每档窗口实测能量 σt、σf 与公式差 < 2%，乘积 ≈ 1/(4π)；16/32 点只分开咔嗒、128/256 点只分开两音、64 点都分不开；没有一档两者都分开；幅度标定（0.5 振幅读 ≈ 0.5）。
- 第 2 步：Morlet σt·σf = 1/(4π)、周期数 = ω₀/(√2π) ≈ 1.80（含采样包络的实测 σt 对照）；固定窗周期数 4 Hz 时 < 1、96 Hz 时 > 5；平面里最宽的块不出界。
- 第 3 步：ω₀ = 7、8、9、10 两件都分开；3–6、11、12 至少一件分不开；ω₀=3 两音谷深 > 0.9；ω₀=12 咔嗒分不开。
- 第 4 步：所有跳变位置 Haar 非零 ≤ 7、每层 ≤ 1、恰好用非零个数就能精确重建；DCT 非零 > 30、达到 RMSE 0.05 所需 > Haar 非零的 3 倍；两种逆变换精确、能量守恒；RMSE 曲线 = 实际重建误差；跳变在 32、16 处非零为 2、3。
- 第 5 步：5 组噪声最佳 T 在 0.5–0.7；T=0 不变；T=3 比最佳差 1.5 倍以上；噪声实测 σ ≈ 0.5；数据在坐标范围内。
