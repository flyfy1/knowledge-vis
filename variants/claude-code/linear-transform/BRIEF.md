## 定位

- category `math`，subtopic `linear-algebra`，stage `university`（与原版一致）。
- 受众：大学低年级；会向量加法与数乘、会读坐标；不要求学过矩阵。
- 一句话直觉：**矩阵的两列就是 e₁、e₂ 的去处；坐标不变、换的是基，整张网格跟着两根箭头走。行列式是带符号的面积倍数，等于 0 时平面被压扁、无法倒回；两个变换的先后一般不能交换。**
- 与原版的差异（设计选择）：
  - 用不对称的字母 F 贯穿第 0、3、5 步，翻面（镜像）一眼可见。
  - 第 1 步左右（窄屏上下）两幅图并排：同一组坐标 (x, y)，在原基和新基上各走一遍折线。
  - 第 2 步不直接给定义，而是把同一个矩阵与「再平移」「再掰弯」对比，用 T(u+v) 与 T(u)+T(v) 是否重合、T(λu) 与 λT(u) 是否重合检验两条规则，并说明「原点不动」只是必要条件。
  - 第 3 步让 Ae₂ 绕一圈，副图描出 det = 1.68·sin(θ − 30°)，正负号与转向对应。
  - 第 4 步用测量误差圈讲逆矩阵：det 越接近 0，误差被放得越大；det = 0 时整条直线压到一点。
  - 第 5 步用旋转与剪切演示 AB ≠ BA，同时两种顺序面积相同（det(AB) = det A · det B）。

## 模型（`model.js`）

- 矩阵 `{a, b, c, d}` 表示 [[a, b], [c, d]]；`apply`、`det`、`mul`（A·B = 先 B 后 A）、`inverse`（奇异时返回 null）、`lerp`、`rot`、`shearX`、`area`（鞋带公式）、`stretches`（奇异值闭式）、`nullDir`。
- 数据：默认 A = [[1.5, −0.5], [0.5, 1]]（det 1.75）；6 个预设（转 45° 在滑杆上取到 0.01，显示 0.71）；第 2 步 A = [[1.2, 0.5], [−0.3, 1]]、平移 (0.8, 0.5)、掰弯项 (0.25·y², 0.2·x²)、u = (1, 0.5)、v = (0.5, 1)；第 3 步 |Ae₁| = 1.4 指向 30°、|Ae₂| = 1.2；第 4 步 p = (1, 0.6)、误差半径 0.2。
- 不含：平移（仿射）、三维、复特征值、数值误差分析（终章 boundary 明说）。

## 数值结论与测试（`tests/core.cjs`）

- 第 0/1 步：两列 = e₁、e₂ 的像；整数格点 (i, j) → i·Ae₁ + j·Ae₂；Ap 公式在 x、y 全格点成立；插值端点为 I 与 A；各预设的说法（行列式、翻面、压扁）在 0.01 取整后仍成立。
- 第 2 步：线性映射两误差为 0；平移映射的第一条误差恒等于平移长度、第二条只在 λ = 1 为 0；掰弯映射原点不动、第一条误差 > 0；粉色误差随 λ 远离 0 和 1 增大（s2hint）。
- 第 3 步：θ 全格点 det = 1.68·sin(θ − 30°)；单位正方形与 F 的像面积 = det × 原面积；det 符号 = Ae₁ 到 Ae₂ 的转向；30°、210° 为 0；最大值 1.68；随机矩阵上任意多边形面积按 det 缩放。
- 第 4 步：s 全格点 A⁻¹·A = I、送回 p；s = 2 时奇异；误差圈送回后的最远偏离 = 0.2 / 最小拉伸（采样核对），det → 0 时两侧都单调增大（读数里的偏离与倍数由 model 实时计算）。
- 第 5 步：复合 = 先右后左；k = 0 或 θ ∈ {0°, ±180°} 时可交换，其余格点都不可交换；两种顺序的行列式都为 1。
