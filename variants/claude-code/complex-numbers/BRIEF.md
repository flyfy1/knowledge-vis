## 定位

- category `math`，subtopic `algebra`，stage `senior`（与原版一致）。
- 受众：高中生；会实数运算、平面直角坐标、勾股定理，见过 sin、cos 是单位圆上点的坐标。
- 一句话直觉：**乘 −1 是掉头（转 180°），「半个掉头」就是转 90°，这个数叫 i；于是复数是平面上的点，加法是平移，乘 w 是绕原点转 arg w 再伸缩 |w| 倍。**
- 与原版的差异（设计选择）：不从「解 x² = −1」的形式定义入手，而是从「什么运算做两次等于乘 −1」这个几何问题出发，让 i 作为答案出现；全页用一个不对称的 F 形图案，让加法（平移）和乘法（转 + 缩放、形状不变）都能一眼看出；乘法一步同时走「代数展开」和「模相乘、角相加」两条路并读出两者之差；最后一步一直乘同一个 w，看圆、螺旋和 n 次单位根。

## 模型、判定口径与失配

- `model.js`（浏览器与 node 共用）：复数是 `{re, im}`；`add`、`mul`（按 (ac − bd) + (ad + bc)i 展开）、`mod`、`arg`（原点返回 null）、`normDeg`（−180 记为 +180）、`fromPolar`、`mulPolar`（几何路线，用于和代数路线对照）、`turnTwice`、`halfTurnRoots`、`timesI`、`orbit`、`SHAPE_F`、`mapShape`、`powers`、`QUIZ`/`quizKey`。
- 纯代数与几何，没有随机或测量误差；读数一般保留 3 位小数、角度 0.1°。画布是复平面的一个窗口，超出的点被截掉，读数仍按模型算并提示。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：φ 每 1° 扫 0–360°，转两次恰好落在 −1 当且仅当 φ ∈ {90°, 270°}；转一次长度不变；实数 k² ≥ 0。
- 第 1 步：|3 + 4i| = 5、arg(−2) = 180°、arg 2i = 90°、单位圆预设模 1、辐角 40°；网格上模 = √(a² + b²)、极坐标与分量互换一致；原点无辐角。
- 第 2 步：分量相加；F 的每个点都移动 w；默认 (2 + i) + (−1 + 1.5i) = 1 + 2.5i。
- 第 3 步：(a, b) → (−b, a)、长度不变、点积 0、辐角 +90°；i⁰…i⁴ = 1, i, −1, −i, 1（精确）、周期 4；按 2 次 = ×(−1)，按 4 次回原处。
- 第 4 步：滑杆全格点（r 步长 0.05 × φ 步长 5° × z 网格）上两条路一致（1e-9）；|zw| = |z||w|、arg 相加（模 360）；预设 2、i、1 + i（45°、√2 ≈ 1.414）；F 的两两距离按 |w| 缩放；零因子时积为 0。
- 第 5 步：r × φ × n 全格点 |wⁿ| = rⁿ、arg wⁿ ≡ nφ；预设 i 四次、72° 五次回到 1 且五边等长；两个螺旋预设确实向里/向外。
- 自测答案 −3 − 2i、模都为 5、2i（由模型算出后对选项）。
