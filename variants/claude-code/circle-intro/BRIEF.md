## 定位

- category `math`，subtopic `geometry`，stage `primary`（与原版一致）。
- 受众：小学高年级（学过长度、角的度数、长方形与三角形面积）；不用 √、sin、tan。
- 一句话直觉：**圆 = 一根拉紧的绳子扫过的点；周长被内外多边形夹住得出 π；面积先数方格看出「3 个多 r×r」，再剥洋葱说明为什么正好 π 个。**
- 与原版的设计差异：原版用圆规画圆、只用内接多边形、扇形拼长方形。本版从「绳子 + 足迹」出发；弦长用一张保留历史的「角度—弦长」记录图找出最长弦；滚轮子时把多种轮子的 (d, C) 记到同一张图上，看出成正比；π 用内接与外切两个多边形夹住（阿基米德的 6→96 加倍）；面积用两种不同的证据：数方格（上下界）与剥洋葱（台阶 → 三角形，多出的正好是 1/n）。

| 0 一样远 | 长度、角的度数 | 到一个点一样远的点排成什么形状？ | 绳长 r（1–5 cm）、方向 θ（每 5°）→ P 到 O 的距离、足迹 | 拖方向：每个方向留一个足迹；「绕一圈」：72 个足迹连成圆；换绳长：新颜色的圈，旧的保留 | 平面、绳子始终拉紧 |
| 1 最长的弦 | 圆心、半径 | 圆里一条线段最长多长？ | r（2–5）、B 转开角 φ → 弦长 | 拖 φ 0→360：记录图的点先升后降，最高点在 180°，等于 2r；那时弦过圆心 | 弦两端都在圆上 |
| 2 滚一圈 | 直径 | 周长是直径的几倍？ | d（1–5）、已滚圈数 → 橙线长、C ÷ d | 「滚一圈」：轮边贴过地的部分 = 地上橙线；尺子按直径分格；换三种轮子：记录图的点在过 0 的直线上，C ÷ d 全是 3.1416 → 命名 π | 不打滑；模拟（轮边按 4096 段测量） |
| 3 夹住 π | π 的定义 | 不滚轮子，能把 π 算准吗？ | 边数 n ∈ {3,…,96} → 内、外多边形一圈 ÷ 直径 | 拖 n：青点升、橙点降，π 虚线始终夹在中间；「每次加倍」：6→12→24→48→96 | 正多边形；内接 < 圆 < 外切 |
| 4 数方格 | 面积单位 cm² | 圆里能铺多少 1 cm 方格？ | r（2–20）→ 整格数、碰到的格数、÷ r² | 拖 r：记录图下界（绿）上升、上界（橙）下降，π 一直在中间，宽度总的趋势变窄 | 圆心在格点上；整格 = 四角都在圆内 |
| 5 剥洋葱 | 周长 = π × d、三角形面积 | 为什么正好是 π × r × r？ | 圈数 n（2–30），r = 3 → 台阶面积、三角形面积、差 | 「一圈圈剥下来」：上图圆环由外向内变淡、下图台阶叠高（k/n）；拖 n：伸出三角形的小尖变碎，多出 = 三角形 ÷ n | 每条按外圈周长取长（偏大估计）；n 越大越接近 |
| 6 收束 | 全部 | 知道一个量，能求其余三个吗？ | 选 r/d/C/A + 数值 → 其余三个（π 与 3.14 两版） | 换已知量类型与数值，读数与画出的圆同步 | 平面理想圆 |

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`point`、`dist`、`chord`（由两点坐标量出）、`rimLength`（4096 边形周长）、`rolled`、`polygon`/`perimeter`/`polyRatios`（由顶点坐标求和）、`gridCells`（逐格判断整格 / 部分 / 不碰）、`strips`（按外圈周长的台阶）、`fromKnown`（可选 π = 3.14）。
- 第 2 步是**模拟**：滚动距离 = 圈数 × 轮边长度，轮边长度由 4096 段折线量出，不是用 π 公式写死的。
- 第 5 步的台阶按每圈**外沿**周长取长度，所以总是偏大，偏大量 = π r² ÷ n；页面如实写出。
- 理想平面圆；π 的小数无尽不循环，3.14 是近似。

## 数值结论与测试（`tests/core.cjs`）

- 第 0 步：所有滑杆格点上足迹到圆心距离 = r；72 个足迹（每 5°）。
- 第 1 步：弦 ≤ 2r；最长恰在 180° 且 = 2r；0° 与 360° 为 0；先升后降左右对称；默认读数 3.44 cm。
- 第 2 步：滚一圈 = 轮边长；C ÷ d 对所有 d 相同、在 3 与 3.2 之间、显示为 3.1416。
- 第 3 步：每个 n 都有 内 < π < 外；内单调升、外单调降、窗口单调窄；内/外 = n·sin(π/n) / n·tan(π/n)；6 边形内 = 3.0000；96 边形 3.1410–3.1427；只有 n = 3、4 的外值超出图表上沿（读数有提示）。
- 第 4 步：每个 r 都有 整格数 ≤ π r² ≤ 碰到的格数；r ≤ 6 用 41×41 采样逐格核对状态；上下界间距每隔 4 都变窄、r = 20 不到 r = 2 的 1/4；默认 r = 4：32 绿 28 橙。
- 第 5 步：三角形 = π r²；台阶 = π r²(n+1)/n；多出 = 三角形 / n，且随 n 增大而减小。
- 第 6 步：四种已知量往返一致；3.14 版保留给定值，其余与 π 版相差 ≤ 0.11%。
