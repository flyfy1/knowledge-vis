## 定位

- category `physics`，subtopic `mechanics`，stage `senior`，与原版一致。
- 受众：高一。读者会用 ½gt²，知道速度有方向；向量加减只需要会画箭头。
- 一句话直觉：**重力每秒都把速度改变同样多（大小 g、竖直向下）。** 抛体、拱桥上的车、绕地球的炮弹都只是这件事；要让它沿圆走，所需的向心加速度 v²/r 必须刚好由力来提供。
- 与原版的差异：原版的顺序是分解 → 射角 → 速度两份 → 圆周（剪绳）→ 牛顿大炮 → 卫星高度与周期。本版以「速度的变化 Δv」为主线：
  - 抛体每段相等时间的 Δv 都相同（速度图）。
  - 圆周运动的 Δv 指向圆心，|Δv|/Δt 随 Δt 变小而趋近 v²/r。
  - 拱桥顶点由重力和支持力提供 v²/r（v² = gr 时离开桥面）。
  - 牛顿大炮用「1 秒内下落 ½g 与地面弯下去的量」两条线的交点得出 v² = gr。
  - 另外加了一个示意性的空气阻力（最佳角度约 43°）。本版不讲开普勒第三定律和卫星高度，那部分交给 gravity-orbits。

## 模型、模拟设定与失配

- `model.js` 在浏览器和 node 中共用，提供以下函数：
  - 平抛：`tLand`、`height`、`strobe0`。
  - 斜抛：`ideal`；阻力版 `dragFlight`（RK4，dt 0.002 s）、`dragAt`、`dragOptimum`（黄金分割搜索）。
  - 速度：`vel`、`pos`、`dv`。
  - 圆周：`circle`、`chordAccel`、`circVel`。
  - 拱桥：`bridge`、`vCrit`、`fallParabola`、`fallBridge`。
  - 大炮：`vCirc`、`vEsc`、`g0`、`orbit`（解析判断轨道类型）、`flight`（RK4，1 s 步长）、`oneSecond`。
- 失配，终章写明：
  - 阻力模型（减速度 0.01·v²）只是示意。
  - 「100 km 的山」是假想的。
  - 地球按均匀球体处理，不计空气和自转。
  - 拱桥只分析最高点那一刻。离桥顶较远时，抛物线最终会落到桥面下方，这一点在 s4hint 里写明了，测试只钉住桥顶附近（x ≤ 2 m）的结论。

## 数值结论与测试（`tests/core.cjs`，30844 项检查）

- 第 0 步：t = √(2h/g) = 2.02 s；推出的球与松手的球在每个频闪时刻等高；x = v₀t；动画最后一帧就是落地。
- 第 1 步：R = v₀² sin2θ / g；45° 最远（40.8 m）；互余角射程相同；轨迹在坐标范围内。阻力相关：
  - 每次射程都变短，结果在 dt 上已收敛；
  - 下落段更陡（用细步长 0.0002 s 校验顶点）；
  - 互余角中低角更远；
  - 最佳角约 43°，且比相邻角度更远。
- 第 2 步：vx 不变；Δv = −g·0.25 s，没有水平分量；速率不低于 vx；最高点只剩 vx；箭头不出面板。
- 第 3 步（全滑杆网格）：
  - a = v²/r，T = 2πr/v；
  - \|Δv\|/Δt 不超过 v²/r，Δt 越小越接近，最终趋近 v²/r；
  - Δt 不超过半圈时，Δv 指向圆心（误差 1e-4°）；
  - v 加倍 a 变 4 倍，r 加倍 a 减半；
  - 箭头在面板内。
- 第 4 步：
  - 临界速度 √(gr) ≈ 19.8 m/s，车离开桥面当且仅当 v > √(gr)；
  - N = m(g − v²/r)，不低于 0；
  - 默认 12 m/s 时 N = 6200 N（63.3%）；
  - 桥顶附近，抛物线在桥面下方当且仅当 v < √(gr)；
  - 判断题 39.6 m/s、正好 2 倍，app 判定选项 b。
- 第 5 步：
  - 山顶环绕速度 7.85 km/s，地面处 7.9 km/s；逃逸速度 11.1 km/s；山顶 g = 9.52 m/s²；1 s 下落 4.76 m；
  - 环绕速度下「下落量 = 地面弯下去的量」，v² = gr；
  - 地面弯下去的量小于下落量，当且仅当速度低于环绕速度；
  - 轨道分类正确：落地 / 圆（10 km 内）/ 椭圆；周期正确；从 7.85 km/s 起炮弹能绕回；轨迹在坐标轴范围内。
