## 定位

- category `computing`，subtopic `graphics`，stage `university`（与原版一致）。
- 受众：大学低年级（理工科）；会三角函数、向量加法、2×2 矩阵乘向量；不要求学过机器人学。
- 一句话直觉：**关节角 → 手的位置是一个非线性映射；它在每个姿态附近的线性近似就是雅可比 J。** J 告诉你转速怎样变成速度，det J = 0 告诉你手在哪些姿态「卡住」，J 还能拿来迭代求逆运动学。
- 与原版的差异（设计选择）：原版是四步切片（正解、逆解、Jacobian、奇异）。本版多了「工作空间」（关节空间扫描 ↔ 圆环）和「迭代求解」（牛顿法 vs 阻尼最小二乘）两步，让 J 不止是一个公式：它既解释速度与奇异，也是数值 IK 的引擎。全页用同一台臂 l₁ = 1.0 m、l₂ = 0.6 m（第 1 步可改 l₂）。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`fk`、`radiusOf`、`reach`、`ik`（闭式两解）、`jac`、`det`、`svd2`（2×2 奇异值；σ₂ = |det|/σ₁ 保证奇异附近精度）、`sweepPath`（恒定转速下手的真实路径）、`jointSpeedFor`、`ikStep`/`ikRun`（λ = 0 为牛顿，>0 为阻尼最小二乘）。
- 所有数据都是模型计算，没有随机数。
- 模型失配（s6 明说）：无动力学、关节限位、碰撞、控制延迟；真实工业臂 6 自由度、J 为 6×n；冗余臂有无穷多解。

## 数值结论与测试（`tests/core.cjs`）

- 正运动学：两节长度、r = 余弦定理（15° 网格）。
- 工作空间：每个 l₂ 下 r 的最小/最大值 = |l₁−l₂| / l₁+l₂；环内每个 ρ 恰有 ±a 两解；l₂ = l₁ 时内孔闭合。
- 逆运动学：0.02 m 网格上「可解 ⇔ 0.4 ≤ r ≤ 1.6」；回代误差 < 1e−12 m；两解肘部关于底座—目标连线镜像；边缘两解重合。
- 雅可比：与有限差分一致；J₁ ⟂ 底座→手且 |J₁| = r；J₂ ⟂ 肘→手且 |J₂| = l₂；det J = l₁l₂ sin θ₂；σ₁σ₂ = |det J|；默认姿态 Δt 减半时差距比在 3.6–4.05（文案「约 1/4」）。
- 奇异：θ₂ = 0、±180° 时 σ₂ = 0、无有限解；1°–179° 所求 ω 真的产生 0.2 m/s 径向速度；θ₂ ≤ 30° 时 |ω| sin θ₂ 在 0.5–0.6（文案「约按 1/sin θ₂」）；提示值 3.3、16.3；σ₁ 从 90° 到 1° 上升。
- 迭代：牛顿第 7 次首次低于 1e−6；第 5/6/7 次误差区间与指数倍增；λ = 0.3 每步缩小 2.9–3.3 倍；不可达时牛顿最大误差 > 2 倍初值，λ = 0.3 终值 = |p| − 1.6（±1e−3），θ₂ ≈ 0、指向目标。
- 格式：`fmt` 只在有小数点时去尾零（90 不变成 9）。
- 双语：键集与占位符一致、非符号键中英不同；无「左图/右图」措辞；HTML/app 用到的键都存在；带占位符的键不走静态 `data-i18n`；深链与对照链接目标存在。
