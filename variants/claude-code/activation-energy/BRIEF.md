## 定位

- category `chemistry`，subtopic `reactions`，stage `senior`（与原版一致）。
- 受众：高中（选择性必修「化学反应原理」）；知道反应热、放热/吸热、碰撞理论的说法；会指数和对数的基本运算。
- 一句话直觉：**反应先要爬到过渡状态；碰撞能量 ≥ Eₐ 的比例是 e^(−Eₐ/RT)。山高决定快慢，两端高差决定终点。**
- 与原版的设计差异：原版用弹球发射演示能否翻山，再做 Arrhenius 拟合。本版：
  - 第 0 步把能量山和三个原子的成键/断键同步画出，说明山顶为什么存在；
  - 第 1 步用可复现的随机碰撞「抽签」，让成功比例从计数中长出来；
  - 第 2 步把比例换成「平均要等多久」，用对数时间轴说明 Eₐ 每多 5.74 kJ/mol 就慢 10 倍；
  - 第 3 步用柱子直接对比「平均能量 +3%」与「成功比例翻倍」；
  - 第 4 步在对数时间轴上展示催化剂 = 曲线整体左移、终点不变；
  - 第 5 步用正逆两条 k–T 曲线说明升温有利于吸热方向。

## 模型、模拟设定与失配

- `model.js`（浏览器与 node 共用）：`profile` / `catProfile`（半余弦分段插值，最高点恰为节点值）、`atoms`、`rng`（mulberry32）+ `sampleEnergy`、`fraction`、`wait`、`decadeStep`、`humanTime`、`heatRatio`、`doublingEa`、`relax`（一阶可逆反应解析解）、`twoWay`、`sci`。
- 第 1 步是**模拟**：碰撞正面能量 E = −RT·ln(1−u)，页面用固定种子，打开时预置 200 次碰撞，可继续慢放、快进或清空。
- 其余各步是解析公式计算，不含随机数。
- 模型失配（页面 s6 boundary 明说）：
  - 只适用于一步反应和简单碰撞模型（不考虑方位因子、隧穿，A 视为常数）；
  - K = e^(−ΔH/RT) 忽略了熵变；
  - Z、A 是数量级假设；
  - 页面数值不是任何具体反应的实测值；
  - 课本上的驼峰分布是单分子动能，本页用的是碰撞正面能量分布，s1e 有说明。

## 数值结论与测试（`tests/core.cjs`）

- **第 0 步**：剖面在全部滑杆格点上最高点恰为 Eₐ（位于 ξ = 0.5），两端为 0 和 ΔH；Eₐ′ ≥ 10；原子起点、终点和过渡状态的键级。
- **第 1 步**：密度归一且均值为 RT；尾部积分 = e^(−Eₐ/RT)；每升 RT 比例 ×1/e；40000 次抽样在全部门槛值上与理论相差不超过 4σ；RT(300) = 2.494（文案「2.49」）。
- **第 2 步**：RT·ln10 = 5.743；每升这么多等待 ×10；Eₐ = 50 约 0.10 s，100 约 1.64 年；四类提示按序出现在 50/75/100/160；纵轴范围覆盖整条曲线。
- **第 3 步**：+10 K 平均能量 +3.3%、碰撞频率 +1.7%；翻倍 Eₐ = 53.59（小测选项「约 54」）；450 K 时倍数 < 1.5；倍数随 Eₐ 单调增；对数轴上限。
- **第 4 步**：催化路线最高点 = Eₐ − ΔEₐ，起终点不变，中间产物为谷；正逆 k 同倍；平衡占比 96.1% 不变；半程时间按倍数缩短；对数时间轴上严格平移；时间轴覆盖两条曲线。
- **第 5 步**：K = e^(−ΔH/RT) 与 Eₐ 无关；ΔH 符号决定哪边增幅大；Arrhenius 斜率 −Eₐ/R。
- **双语与链接**：键集与占位符一致；中英文不同；页脚含模型 id；无「左图/右图」；HTML/app 用到的键都存在；深链目标页与 `#stepN` 锚点存在；对照链接存在；无 canvas-label-guard。
