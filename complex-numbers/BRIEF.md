# BRIEF：复数——乘法 = 旋转 + 伸缩（complex-numbers）· 高中数学

## 定位
- slug `complex-numbers`，category math，stage senior。受众：高中生 + 家长。课本里 i 以「规定 i²=−1」空降，学生只会背法则、不知道复数乘法在图上发生了什么——本页把 i 讲成一个动作：**乘 i 就是转 90°**；于是 i²=−1 不再是要背的规定，而是「转两次 90° 正好掉头指向 −1」这个看得见的几何事实。一般乘法随之落地：模相乘、角相加。
- 核心直觉一句话：**复数是平面上的一个点（也是一根箭头）；加法是平移，乘法是旋转 + 伸缩——乘上谁，就按谁的模伸缩、按谁的辐角旋转**。
- 已知：实数与数轴、平方非负、平面直角坐标系与勾股定理、角度与弧度（trig 页程度）、向量平移的直观（没有也行，本页自足）。唯一新问题：x²=−1 在实数里无解——出路在哪？复数乘法除了 (a+bi)(c+di) 的展开法则，还有没有一眼看懂的几何意义？

## 学习契约
| 项 | 内容 |
|---|---|
| 读者此时已知 | 实数都在一条数轴上；任何实数的平方 ≥ 0；平面上的点有坐标 (x, y)；勾股定理量斜边长；角度从正半轴量起 |
| 学完能做到 | 在复平面上读出任一点的实部/虚部/模/辐角；用平行四边形画出两复数之和；说清 i、i²、i³、i⁴ 的几何意义（转几次 90°）；对任意两复数先预言乘积的模与辐角再拖图验算；判断「乘积的模 = 模之和」这类说法对错 |
| 明确不做 | 不讲复数的除法（终章一句带过「除法是乘法的逆：角相减、模相除」不展开）、不推导欧拉公式（终章只埋线一句）、不讲代数基本定理、不要求弧度制计算（角度以度为主读数，弧度仅在术语口径里提及） |

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件操作与预期观察 / 结论适用条件）
0. **数轴不够用**：已知实数排满一条数轴、平方恒 ≥ 0；唯一问题：x²=−1 的解站在哪里？控件：数轴上的平方探针——拖 x 沿数轴走，读数实时给 x²（实算），轨迹描出抛物线贴在数轴上方、永远够不到 −1 那条横线；随后「把数轴竖起来当一条边」的转场：平面展开，第二条轴（虚轴）淡入，原点上方标出一个待认领的点。预期观察：在线上怎么找都没有 −1 的平方根，缺的不是某个数、是一个维度。结论：给数轴加一条垂直的轴，数从「线上的点」升级为「平面上的点」；新轴上的单位记作 **i**，先只承诺一件事：这一页会把 i²=−1 变成看得见的事实（不在这一步下定义式断言）。
1. **复数是平面上的点**：已知平面点有横纵坐标；唯一问题：一个复数要几个数才能钉住？控件：复平面（横轴实轴、纵轴虚轴，首现即标轴义）上一个可拖点 z，读数四栏同源实算——实部 a、虚部 b（z = a + bi 的写法随读数出现）、模 |z| = √(a²+b²)（由勾股实算，点到原点的连线即斜边、随拖动同步画出）、辐角 θ（从实轴正半轴逆时针量到箭头的角，atan2 实算）。预设点巡演：3+4i（模恰 5）、纯实数点（θ=0 或 180°）、纯虚数点（θ=±90°）、单位圆上的点（模 1、只剩角度在变）。边界态写死：拖到原点时模为 0、辐角无定义，读数须明示「原点没有辐角」而非给出假角度。预期观察：钉住一个点有两套办法——(a, b) 或（模， 辐角），同一根箭头的两种读法。结论：复数 z = a + bi 与平面点/箭头一一对应；模是长度、辐角是方向，辐角取主值（见判定口径）。
2. **加法 = 平移**：已知第 1 步的点与箭头；唯一问题：两个复数相加，图上动了什么？控件：z₁、z₂ 两点可拖，第三根箭头 z₁+z₂ 以平行四边形（兼首尾相接）画出并随拖动跟随；读数三栏对账——实部：a₁+a₂ 与和的实部、虚部：b₁+b₂ 与和的虚部，逐栏打勾核对（读数全由 (a, b) 实算）。预期观察：加 z₂ 就是整幅图沿 z₂ 的箭头平移那么远；和的横纵坐标恰是两边各自相加——与向量加法同一件事。结论：复数加法 = 分量相加 = 平移；适用条件：只对加法成立，乘法不是分量相乘（下一步的反差预告一句）。
3. **乘 i：转 90°**：已知第 1 步的模与辐角读法；唯一问题：i 自己到底「是」什么？控件：任选起点 z（预设 1、3+2i 两档），「×i」按钮连按——箭头每按一次逆时针转 90°，模的读数纹丝不动、辐角每次 +90°（归一化后显示）；连按四次回到原方向，轨迹弧线与每次落点全程留痕（不许只剩当前帧）。第二演台：单位点序列 1 → i → −1 → −i → 1 固定巡演，落点逐个钉在坐标轴上，读数栏并排给出 i¹、i²、i³、i⁴ 的值。预期观察：乘 i 不改长度、只转 90°；按两次就是掉头 180°，落在 −1 上——i²=−1 是转出来的，不是背出来的。结论：**×i = 逆时针旋转 90°**；i 的幂以 4 为周期。此步须把「i 是 √−1 的记号」与「i 是转 90° 的动作」两个说法并置收口：同一个 i，两副面孔。
4. **一般乘法 = 模相乘、角相加**：已知 ×i 是纯旋转、乘正实数是纯伸缩（本步内用预设先各自验明，不许直接宣称）；唯一问题：乘上任意一个复数，模和角各发生什么？控件：z₁（被乘）与 z₂（乘数）两点可拖，乘积 z₁·z₂ 实时画出；对账台三组读数全部实算——|z₁|、|z₂|、|z₁z₂| 与 |z₁|·|z₂| 对账；θ₁、θ₂、θ₁+θ₂（先归一化再显示）与乘积辐角对账；乘积坐标同时给出 (a₁a₂−b₁b₂, a₁b₂+b₁a₂) 的代数读数，两条路同源互证。预设三档：z₂ 为纯实数 2（只伸缩不转）、z₂ 模为 1（只转不伸缩，角度自选）、z₂ = 1+i（既转 45° 又放大 √2 倍）。拖动中预期观察：乘积箭头随 z₂ 的角度转动、随 z₂ 的模伸缩，两个效应互不干扰。结论：**乘法法则——模相乘、角相加**；适用条件：角度相加后须按主值区间归一化（340° 与 −20° 是同一个方向，本页统一写后者）；z₂=0 时乘积为原点、无辐角可言（口径同第 1 步）。
5. **自测**（判定全由与正文同源的实算函数给出，错答给诊断式反馈、不给笼统对错）：① z = 3+2i，连乘两次 i 落在哪里？（选项给四个点：−3−2i 为正解；选项顺序加载时随机洗牌，判定与诊断均按坐标比对、与位置无关。三个错项的诊断必须按各自真实的几何来历写——(3, 2) 整数次乘 i 的轨道只有 (3,2) → (−2,3) → (−3,−2) → (2,−3) 一圈，三个错项都不在这条轨道上，严禁把它们说成「转错次数 / 转错方向的落点」：错项 −3+2i 诊断「只把实部单独变了号：转一次是 (a, b) → (−b, a) 落到 (−2, 3)、两个分量换位，连转两次两个分量一起变号」；3−2i 诊断「只把虚部单独变了号（沿实轴翻镜像）：顺时针转一次落 (2, −3)、转两次与逆时针两次同为 −3−2i；×i 是逆时针、两个分量换位且新实部变号」；3+2i（起点本身）诊断「乘两次 i 是掉头 180°，不是原地不动」）② |3+4i| 与 |−4+3i| 哪个大？（一样大，5=5；诊断「模只看长度不看方向」）③ 判断题「乘积的模等于两模之和」（错：是模之积；须引用第 4 步对账台任一实数例，如 |1+i|·|1+i| = 2 ≠ 2√2 的说法反驳，让学生自己在对账台验一组）。答对锁定该题（文案明示），答题后拖动正文控件不冲已锁定状态。
6. **终章**：三卡收束（复数是平面上的点、加法是平移、乘法是旋转+伸缩）+ 一句埋线：这个点若自己转起来、角度随时间长大，就是 e^{iθ} 在单位圆上跑——欧拉公式只点名不展开。互链区（锚点已按 CONCEPT-MAP 与实页核对，2026-10-20）：① `../trig/#step2`「把身高摊开，就是正弦波」——单位圆上的点转起来、身高摊开就是正弦波，本页辐角 θ 的那个点就是它（若正文在别处首提 sin/cos 的单位圆定义，定义出处在 trig#step1，按首提处就近链）；② `../eigen/#step2`「四个数随便调，λ 当场改命」——旋转矩阵没有实的特征方向、特征值是一对复数，图上化作一圈圈螺旋，去那页看复数第一次在矩阵里现身；③ `../fourier/#step1`「正弦波三要素」——相位就是起始角：傅里叶页每个圆的起始位置，正是本页辐角的用处。另登记供 CONCEPT-MAP 新增本页概念行（构建者不直接改 CONCEPT-MAP，注册时由 Alberto 补）：「乘 i = 旋转 90° / Multiplying by i is a 90° rotation → complex-numbers#step3」「乘法 = 模相乘角相加 / Multiplication: moduli multiply, arguments add → complex-numbers#step4」。

## 判定口径（写死，不许构建者自行改动）
- **同源原则**：所有读数（实部/虚部/模/辐角/和/积）只许由 (a, b) 数值经实算函数得出；图形（箭头角度、长度、平行四边形、旋转弧）由同一组数值绘制——图与读数不得各算一套。判定函数集中为 PURE 段，自测题判定与正文读数共用。
- **辐角主值区间**：(−180°, 180°]，atan2 实算；边界写死：负实轴上的点辐角记 +180°（不写 −180°）；两角相加先归一化进该区间再显示与对账（170° + 170° 显示 −20°，不得显示 340°）。
- **原点特例**：模 0 的点辐角无定义，读数栏显示「—（原点没有辐角）」口径（双语），任何对账行涉及原点时该行只核模、不核角；乘积为原点同此。
- **数值断言组**（自查脚本逐条断言）：|3+4i| = 5 精确；(3+2i)·i = −2+3i 精确（分量式）；(1+i)² = 2i（模 2、辐角 90°）；i¹..i⁴ = i, −1, −i, 1 精确；i 的幂周期 4、连乘 4 次回起点（坐标与辐角双核）；乘积双路互证：分量式 (a₁a₂−b₁b₂, a₁b₂+b₁a₂) 与「模相乘、角相加再换算回分量」两路结果差 < 1e-9（随机抽 100 组 (a,b) 对断言）；×i 后模不变（差 < 1e-12）、辐角 +90° 归一化后一致。
- **图读一致性容差**：画布上箭头的像素角度/长度与读数反推值之差 ≤ 1° / ≤ 1%（截图量测或以绘制参数回读断言，二选一留痕）；角度读数显示保留 1 位小数，恰为整数时显示整数，非整值不得冒充精确（分量与模读数保留 2 位小数、尾零按全站口径处理，全页统一）。
- **自测真值**：题 ① −3−2i、题 ② 一样大（5 = 5）、题 ③ 错（模之积非模之和）——由 PURE 实算当场算出，不许把答案写成与计算分离的常量表。
