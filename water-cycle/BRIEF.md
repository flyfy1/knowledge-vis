# BRIEF：水的循环（water-cycle）· 小学科学
- category `earth`，stage `primary`（已注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，记录不确定性）。
- 核心：蒸发（随温度指数增强）→ 上升冷却到露点凝结成云 → 水滴合并降水 → 径流/地下水回海；三水库模型里总量守恒并收敛到稳定值。

## 步骤（五必填项）
0. 太阳晒海。问题：气温越高蒸发越快吗？输入气温 0–40 ℃；观察：饱和水汽压曲线上的点、蒸发箭头数量；读数 es（Tetens 公式）与相对 20 ℃ 的倍数；适用：把蒸发强度正比于 es 是教学简化。
1. 凝结成云。问题：云底在哪个高度？输入地面气温、露点（露点不超过气温）；观察：气温线（每公里 −9.8 ℃）与露点线（−1.8 ℃）相交处出云；云底 = (T−Td)/8 km；相等时起雾；适用：上升的未饱和空气。
2. 降水。问题：云何时降雨？输入：加一份/五份水汽、重置；观察：云里水滴逐格积累，满 8 份降雨，累计降水量与次数；阈值示意；重置清零。
3. 回到海洋。问题：落到陆地的水多久回海？输入渗入比例、天数；观察：累计回海曲线，径流立即、地下水每天放 5%；与全径流虚线对比。
4. 整个循环。问题：总量变吗、各处稳定多少？输入：开始/暂停/重置、气温；观察：O/A/L 堆叠条（总量恒 1000）与 A、L 随天数曲线逼近解析稳定值（虚线）；动画 25 天/秒，可暂停，减弱动态直接跑到 300 天，隐藏停止。
5. 终章。问题：更暖时空气水量？输入气温；读数稳定时空气水量及相对 20 ℃ 的百分比；深链 particles-states#step0、climate-energy#step0、climate-feedback#step0（均已核对存在）。

## 模拟设定 / 模型失配
三水库箱式模型，速率常数（ke20=0.004/天、kp=0.11/天、φ=0.3、kr=0.05/天）为教学示意，非观测；忽略冰雪、蒸腾、深层地下水；云底公式只对上升的未饱和空气。
