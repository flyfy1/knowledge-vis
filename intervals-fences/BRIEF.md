# BRIEF：间隔与植树（intervals-fences）· 小学数学
- category `math`，stage `primary`（已注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，记录不确定性）。
- 核心：点数与段数差 +1/0/−1，取决于两端种不种；锯木头、爬楼梯同构。

## 步骤（五必填项）
0. 数手指缝。已知：点与间隔；问题：n 个点之间几段？输入 n；观察：青色括号逐个编号，段 = n−1；适用：一排点。
1. 两头都种。已知段=点间空隙；问题：24 米路两头都种几棵？输入间隔（2/3/4/6/8/12，均整除 24）；观察：树随间隔移动，数字标树序，色带标段；树 = 段+1。
2. 端点不同。已知步 1；问题：一头不种/两头不种/环形怎样？输入种法+间隔；观察：被拿走的树，树−段 = +1/0/−1/0；适用：间隔相等且整除。
3. 锯木头。问题：k 段几刀？输入：每按一次加一刀（最多 9），重置回整木；观察：切口标号、木段标号，时间 = 3×刀数，对照错误算法 3×段数。
4. 爬楼梯。问题：已知 1 楼到 a 楼 30 秒，到 b 楼多久？输入 a、b；观察：楼梯折线按 a、b 着色；段数 = 层数−1，与比例错误算法对比；适用：每层所需时间相同。
5. 终章。问题：反推路长。输入种法、棵数 T、间隔 d；画出对应路；深链：patterns-sequences#step1、division-remainder#step0、equations-balance#step3（均已核对存在）。

## 新术语首现表
段/间隔（步 0、1 各带口径）；两头都种等四种种法（步 2）；切口（步 3）；楼梯段（步 4）。

## 模拟设定 / 模型失配
树是无宽度的点、间隔相等、路直（环形为整圆）；不整除时不适用；楼梯每段时间相同是假设（真实上楼速度不恒定）。棵数全部由位置列表计数，不是写死。
