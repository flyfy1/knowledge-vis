## 一个有随机结果的游戏，“平均”能拿到多少？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 加权相加
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 加权相加
:::

<b>这一步回答：期望怎样算出来？</b>每个结果的数值乘以它的概率，再全部相加：E = Σ p·x。表格每一行是“数值 × 概率 = 贡献”，横条是所有贡献首尾相接，黑线的位置就是 E。选四个游戏：骰子（E = 3.5，却永远掷不出 3.5）、投币赢 2、轮盘押红（返还 2，赢的概率 18/38）、彩票（极小概率赢一百万）。 {#s0e .explain}

## 参加这个游戏最多愿意付多少钱才不亏？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 公平价
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 公平价
:::

<b>这一步回答：要价多少才算公平？</b>净期望 = E − 价格。价格等于 E 时净期望为 0，这就是公平价；高于它，长期平均每次亏钱；低于它则赚。轮盘押红 1 元，返还期望 36/38 ≈ 0.947，每注平均亏 5.3%，这就是“庄家优势”。拖动价格，看橙线上的点是绿还是红。 {#s1e .explain}

:::

## 只玩几次结果很乱，玩很多次呢？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 多次平均
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 长期平均
:::

<b>这一步回答：期望为什么叫“长期平均”？</b>橙线是前 n 次的平均所得。开始几次起伏很大，次数越多越贴近虚线 E，两条灰线是 E ± 2σ/√n，围出典型误差，随 n 按 1/√n 收窄。用步骤 0 选中的游戏：试试彩票，几千次之内几乎永远赢不到，平均值停在 0 附近，远低于 E——期望要靠“很长很长”才兑现。 {#s2e .explain}

## 把几次结果加起来，期望是各次期望之和吗？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 可加性
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 期望的可加性
:::

<b>这一步回答：和的期望怎么算？</b>E[X + Y] = E[X] + E[Y]，不要求 X、Y 独立；E[aX + b] = aE[X] + b。掷 n 个骰子，每个 E = 3.5，点数和的期望就是 3.5n；整体平移 b，期望也平移 b。下面的柱子是点数和的完整分布（由逐个卷积算出），橙线在 3.5n + b。拖动骰子数与平移量。 {#s3e .explain}

## 保险费高于期望损失，为什么还有人买？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 保险
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 保险：期望之外的风险
:::

<b>这一步回答：期望相同或更差，为什么还值得？</b>房子损失 L 的概率是 p。不买保险：期望 −pL，但有 p 的概率一次亏掉 L；买保险：确定付保费，期望 −保费。保险公司的期望利润是保费 − pL（要覆盖成本）。买保险的期望更差，却把大额的不确定亏损换成小额确定亏损——标准差从很大降到 0。期望只是故事的一半，另一半是风险（方差）。 {#s4e .explain}

## 期望是无穷大的游戏，该付多少钱参加？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 圣彼得堡
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 终章 · 圣彼得堡悖论
:::

<b>这一步回答：期望很大就一定值得重金参加吗？</b>反复抛硬币直到出现正面；第 k 次才出现，奖金 2ᵏ。每个 k 对期望贡献 2ᵏ × 2⁻ᵏ = 1，所以期望无穷大。但庄家的钱有限：奖金封顶 2ᴹ 时期望只有 M + 1，随银行规模只按对数增长。实际玩一玩：平均数被偶然的大奖拉高，而中位数永远很小。期望只回答“长期平均”，不回答“你这一次会拿到什么”。 {#s5e .explain}
