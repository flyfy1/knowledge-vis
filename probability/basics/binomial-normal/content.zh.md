## 落到某一格有多少条不同的路？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 路径数
:::

::: html step0-1

s0k: 数路径

<b>这一步回答：每个落点各有多少条路径？</b>每过一层，小球向左或向右。到第 n 层第 k 格的路径数等于上一层相邻两格路径数之和——这就是杨辉（帕斯卡）三角，数目是 C(n,k)。n 层共 2ⁿ 条等可能路径，所以落在第 k 格的概率是 C(n,k)/2ⁿ。 {#s0e .explain}

## 柱子的中心和宽度由什么决定？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 均值与波动
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 均值与标准差
:::

<b>这一步回答：n 与 p 怎样决定二项分布的中心和宽度？</b>期望 μ = np，方差 σ² = np(1−p)，标准差 σ = √(np(1−p))。橙线是 μ，浅蓝带是 μ ± σ。n 翻 4 倍，中心移 4 倍，宽度只变 2 倍。p 越靠近 0.5，宽度越大。 {#s2e .explain}

lblN: 层数/次数 n
:::

<b>这一步回答：正态曲线能多准地替代二项柱子？</b>橙色曲线是正态密度 (1/(σ√2π))·exp(−(x−μ)²/(2σ²))，用的就是同一组 μ 和 σ。读数给出柱高和曲线的最大差距。n 大、p 靠近 0.5 时贴得很好；n 小或 p 很偏时，会看到偏斜与明显缝隙。 {#s3e .explain}

## n 要多大，正态才够用？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 要多大 n
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 拟合误差随 n
:::

<b>这一步回答：拟合误差怎样随 n 缩小，又怎样被 p 拖慢？</b>曲线是“最大差距÷峰高”随 n 的变化，大致按 1/√n 缩小。p 越偏离 0.5，曲线越高、下降越慢。常用经验规则：np ≥ 10 且 n(1−p) ≥ 10，读数会告诉你当前是否满足。 {#s4e .explain}

## 抛 n 次公平硬币，正面至少 k 次的概率能心算吗？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 用正态算尾部

::: html step5-1

<b>这一步回答：怎样用正态曲线估计“至少 k 次”的概率？</b>精确值要把许多项相加；正态近似只需 z = (k − 0.5 − np)/σ 和一张表。减 0.5 叫连续性修正：柱子 k 的左缘在 k − 0.5。橙色柱是要累加的部分，绿线是正态曲线。比较“精确”“不修正”“修正”三个数。 {#s5e .explain}
