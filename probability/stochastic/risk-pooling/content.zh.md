## 平均每年损失 200 元，实际却是 0 或 10000 元 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 一个人的风险
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 个人面对的赌局
:::

这一步要回答：一个人的风险，为什么难以“预算”？设每个人每年有概率 p 发生一次损失 10000 元（如重病、车祸），否则损失 0。**期望损失**是长期平均：p × 10000。但任何一年里实际结果只有两种：0 或 10000，永远等于不了平均。下图每个竖条是一年，红条表示发生了损失；青线是到该年为止的平均年损失，绿虚线是期望。**观察：**点「重放」看 100 年慢慢累积；青线会剧烈上下，即使一百年后也和绿线有明显差距。拖动概率 p 试试。这是用伪随机数模拟的一个人。 {#s0e .explain}

## 把很多人放在一起，人均损失会怎样？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 人多了，账就稳了
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 大数的力量
:::

这一步要回答：N 个人共担风险时，“每人平均损失”有多稳？每个人独立地以概率 p 损失 10000 元。把 N 人当年的总损失除以 N 得到**人均损失**，期望仍是 p × 10000，但波动变小：标准差 = 10000·√(p(1−p)/N)，与 √N 成反比。下图把“人均损失”除以期望，重复了 400 个年份画成直方图：N = 1 时几乎全在 0 或 ≥4 倍；N = 10000 时紧紧挤在 1 倍附近。**观察：**增加 N（分 7 档，10 到 10000）看直方图收窄；N 增加 100 倍，波动只缩小到 1/10。这是[[central-limit-theorem#step3|σ/√n]]在保险中的样子。 {#s1e .explain}

## 保费收多少，才不会赔不起？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 保费与破产概率
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 定价与偿付
:::

这一步要回答：保险公司向 N 人各收保费 π，总收入 N·π；如果当年出险人数 K 乘以 10000 超过总收入，就赔不起（**破产**）。设 p = 2%，**附加费率**指在期望损失 p·10000 之上多收的比例，π = p·10000·(1 + 附加费率)。出险人数 K 服从二项分布（柱形，蓝 = 赔得起，红 = 赔不起）。**观察：**固定附加费率 20%，把 N 从几百加到一万：红色尾部不断缩小，破产概率从三成多降到千分之几（小 N 时因为只能整人数计，数值会起伏）；固定 N = 10，把附加费率拉到 60% 也不够安全。破产概率由二项分布精确计算。结论：规模比加价更能降低风险，但小规模靠加价无法补救。 {#s2e .explain}

## 同一场洪水淹没所有人，还能分摊吗？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 同一场灾难
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 大数定律失灵的地方
:::

这一步要回答：当风险不是彼此独立的，池子越大越稳吗？假设每年有概率 q 发生一场共同灾难（如大地震），发生时每个人的损失概率从 1% 升到 p<sub>c</sub>。这时各人的损失不再独立，而是被同一个原因一起推高。青线是“独立”风险的波动（均值相同），随 N 增大不断下降；橙线是共同灾难下的波动，下降到一个**下限**（红虚线 = 10000·(p<sub>c</sub> − 1%)·√(q(1−q))）就停住。**观察：**增大 q 或 p<sub>c</sub>，下限抬高；再把 N 加到 10000，橙线仍卡在下限。这就是为什么保险公司会买再保险、并且对战争、大规模灾害设除外条款。 {#s3e .explain}

## 为什么只有高风险的人留在保险里？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 逆向选择
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 保费螺旋
:::

这一步要回答：如果大家按平均风险缴费，会发生什么？人群分两类：低风险（占 70%，损失概率 1%）与高风险（占 30%，概率 5%）。保费定为当前投保者的平均期望损失再加 10% 附加。每个人愿意付的最高价是自己期望损失的 (1 + 风险厌恶 m) 倍：低风险者的上限 = (1+m)×100 元。若保费高于自己的上限就退出。低风险者退出后，投保者平均风险变高，保费上涨，更多人退出……这就是**逆向选择**。**观察：**设 m = 120%：第 0 轮保费 242，低风险者的上限 220 &lt; 242 退出，第 1 轮保费涨到 550，只剩高风险者；把 m 提高到 150% 以上则人人留下。点「下一轮」看过程。 {#s4e .explain}

## 想把赔不起的概率压到 1%，每个人要多留多少钱？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 准备金
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 留多少备用金
:::

这一步要回答：除了保费外，公司还需要多少**准备金**，才能让赔不起的概率不超过 1%？准备金 = 出险人数的 99% 分位数所需赔款 − 保费总收入。图中的橙线是**人均准备金**随 N 的变化（双对数）：N 大 100 倍，人均准备金约缩小到 1/10。**观察：**拖动 p 和附加费率：p 越大、附加费率越低，所需准备金越多；附加费率足够高时，大 N 下准备金归零，说明保费本身已经能覆盖。准备金按二项分布精确计算，不含共同灾难。 {#s5e .explain}

::: html step5-2
s5cv: 为使赔不起概率 ≤ 1%，人均准备金随人数 N（双对数）
recapTitle: 回顾
recap1: 个人风险是 0 或 L 的赌局，难以预算；N 个人独立共担，人均损失的波动按 1/√N 缩小，保费能按期望加一点附加费率定价。
recap2: 小池子靠加价也不安全，大池子才安全；共同灾难使波动停在下限，所以需要再保险和除外条款。
recap3: 按平均风险定价会引来逆向选择：低风险者退出，保费上涨，池子只剩高风险者。
