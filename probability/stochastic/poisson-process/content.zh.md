## 每一个时刻都随机，长期却有稳定速率 {#step0 h2=s0t pre=1}

::: strings
nav0: 0 随机到达
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: 稳定的平均速率
:::

这一步要回答：“事件以恒定平均速率随机到达”长什么样？设**速率 λ** 为平均每秒到达的次数（例如 λ = 2 表示平均每秒 2 次），每个到达在时间轴上是一条竖线，下方的阶梯曲线数出累计个数 N(t)；紫色虚线是平均期望 λt。**泊松过程**指：到达彼此独立，且在任何一小段时间里到达的可能性只由 λ 与这段时间长短决定。**观察：**先点「重放」看累计怎样一步步增长，再改 λ；阶梯总是围着虚线上下摆动，但从来不贴着它。这是用伪随机数生成的模拟，不是实测。 {#s0e .explain}

## 两次到达之间的等待时间服从什么分布？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 间隔的分布
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 到达之间的间隔
:::

这一步要回答：相邻两次到达的间隔有什么规律？把每个间隔量出来，画成直方图（条的高度是“密度”：某一段间隔出现的占比 ÷ 这段的宽度，所以面积加起来为 1）。橙线是理论的**指数分布** λ·e<sup>−λt</sup>，平均值 1/λ。**观察：**反复点「增加样本」，青色柱会一点点贴向橙线；样本少时参差不齐，样本多了才显出形状。改 λ：整条曲线横向拉伸，但形状不变，最短间隔永远最常见。 {#s1e .explain}

## 固定长度的窗口里，到达个数怎样分布？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 窗口里的个数
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 数一数窗口里有几个
:::

这一步要回答：把时间切成等长的窗口，每个窗口里到了几个？每个窗口的平均个数是 m = λ·w，个数的分布是**泊松分布** P(k) = e<sup>−m</sup>·m<sup>k</sup>/k!（橙点）；青柱是 300 个窗口的实际占比（[[probability-distribution#step2|方差]]是个数偏离平均的程度）。泊松分布有个标志性特点：**方差 = 平均值**，比值（称为“散度比”）约为 1。**观察：**改 λ 或窗口长度，看柱形是否始终贴着橙点；平均值变大时，分布变得更像对称的钟形。 {#s2e .explain}

:::

## 已经等了一会儿，剩下的等待会更短吗？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 无记忆性
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 没有记忆
:::

这一步要回答：如果已经干等了 s 秒还没来，接下来还要等多久？橙柱只取那些“间隔 > s”的样本，把已等的 s 秒扣掉后画出**剩余等待时间**的分布；青色轮廓是全部间隔的分布。**无记忆性**指：两者形状一样，剩余等待的平均值仍是 1/λ——过去等了多久，对将来没有影响。**观察：**拖动 s，橙柱的样本变少（读数给出个数与理论存活概率 e<sup>−λs</sup>），但形状始终贴着青线。这是指数分布独有的性质，不是对所有等待都成立。 {#s3e .explain}

## 两条泊松流叠在一起，还是泊松吗？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 合并与稀释
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 合并与稀释
:::

这一步要回答：把两路独立的随机到达合在一起，会得到什么？青色是速率 λ₁ 的一路，紫色是 λ₂ 的一路，橙色是它们的合并；绿色是把合并流中每个事件以概率 p 保留（“稀释”）后剩下的。结论：合并流仍是泊松过程，速率为 λ₁ + λ₂；稀释后仍是泊松过程，速率为 p·(λ₁ + λ₂)。**观察：**改速率和 p，比较每行右侧的个数；读数里“实测”是另外一段 300 秒的模拟的平均速率。 {#s4e .explain}

## 这组数据像泊松过程吗？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 这是泊松吗？
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 用它来判断
:::

这一步要回答：拿到一串到达时刻，怎样判断它是不是泊松过程？有三种平均速率都是 2 次/秒的到达模式：**随机**（泊松）、**规则**（间隔大致相等）、**成团**（一次来一小簇）。把 200 秒分成 200 个 1 秒窗口，数每个窗口的个数，算**散度比** = 方差 ÷ 平均。泊松约为 1；规则的小于 1（个数很整齐）；成团的大于 1（有的窗口空、有的窗口很多）。**观察：**看直方图是否贴着橙点、散度比偏离 1 多少，再选一类并点「检查」；「换一组数据」会清空你的选择。 {#s5e .explain}
