## 哪台老虎机最值得拉？ {#step0 h2=s0t}

::: strings
nav0: 0 盲拉五台
:::

第 0 步 · 盲拉五台机器 {#s0k .step-kicker i18n=text}

这一步要回答：五台外表一样的老虎机，每台的中奖概率不同且你看不见，怎样在有限次数里多赢？每按一次「拉 X」就拉一次那台机器，中奖得 1 分。柱子是你**目前估计**的中奖率 = 中奖次数 ÷ 拉动次数，白色竖线是大致的误差范围（约 95%，次数少时很宽）。先每台拉几次，再决定把次数投到哪里。点「揭晓真实概率」：红线是各台的真实概率，下方绿色虚线是「一开始就拉最好那台」的期望得分，橙线是你的累计得分，两线之间的差就是你为了「找」而付出的代价（**遗憾**）。「新一局」会换一组机器并清零。 {#s0e .explain}

::: html step0-1
s0armsL: 选择要拉的机器
cv0: 五台机器的估计中奖率与累计得分
s0new: 新一局（换机器并清零）
s0reset: 重置为第一局
:::

遗憾 = 每次拉动时「最好那台的真实概率 − 你拉的那台的真实概率」之和（期望值，不是实际运气）；只有知道真实概率才算得出，所以实战中看不到。 {#s0term .term i18n=text}

s0Cum: 累计得分（橙）
s0Ax: 拉动次数 → {n}

## 只拉当前最好的，为什么会吃亏？ {#step1 h2=s1t}

::: strings
nav1: 1 探索与利用
:::

第 1 步 · 探索与利用 {#s1k .step-kicker i18n=text}

这一步要回答：是不是一直拉目前看起来最好的那台就行？**贪心**：永远拉估计最高的；开局运气不好时，它可能永远锁在一台次优机器上（不再「探索」其他机器）。**ε-贪心**：以概率 ε 随机拉一台（探索），其余时候拉估计最高的（利用）。图是 500 步内的平均累计遗憾（80 次独立模拟取平均；机器的真实概率是 0.25 / 0.40 / 0.50 / 0.62 / 0.45）。拖动 ε，其余不变：看橙线怎样变化；灰虚线是 ε = 0（纯贪心），青虚线是 ε = 0.10。ε 太小探索不足，太大则一直浪费在差机器上。 {#s1e .explain}

::: html step1-1
cv1: 不同 ε 的平均累计遗憾曲线
s1eL: 探索概率 ε
s1reset: 重置
:::

平均累计遗憾 = 把每次模拟的遗憾曲线在多次模拟间取平均；曲线越平，说明越早找对了最好的机器。 {#s1term .term i18n=text}

::: strings
s1Cap: 平均累计遗憾（越低越好）
s1Ax: 步数 1 → {T}
s1G: 灰虚线 = 纯贪心 (ε=0)
s1E10: 青虚线 = ε=0.10
s1Cur: 橙线 = 当前 ε={e}

:::

## 怎样让「拉得少」的机器也有机会？ {#step2 h2=s2t}

::: strings
nav2: 2 UCB
:::

第 2 步 · 乐观面对不确定 {#s2k .step-kicker i18n=text}

这一步要回答：不靠抛硬币，能不能系统地决定探索谁？**UCB**（上置信界）给每台机器的估计加一个「乐观加成」：得分 = 估计 + c·√(2·ln t / n)，t 是已拉的总次数，n 是这台机器已拉的次数。拉得少的机器加成大，所以会被试一试；拉得多的机器加成小，估计更可信。c 是探索权重（c = 1 是教科书的 UCB1）。拖动「已拉步数 t」或按「自动播放」：白色短横线是估计 + 加成，白框是下一步选中的机器；柱子是估计，红线是真实概率。再拖 c：c 越大探索越多，c 小则更接近贪心。（一次固定随机种子的模拟。） {#s2e .explain}

::: html step2-1
cv2: 各台的估计、乐观上界与下一步选择
s2tL: 已拉步数 t
s2cL: 探索权重 c
s2reset: 重置
:::

加成 c·√(2 ln t / n)：n 越小越大，随 t 缓慢增大，因此每台机器最终都会被再试。 {#s2term .term i18n=text}

::: strings
s2play: ▶ 自动播放
s2pause: ⏸ 暂停
s2Cap: 第 {t} 步时的估计与乐观上界
s2Leg: 彩柱 = 估计；白竖线 = 约 95% 误差范围；白横线 = 估计 + 加成；红线 = 真实概率；白框 = 下一步选中的机器
s2ro: c = {c}，已拉 <b>{t}</b> 步：下一步选 <b>{next}</b>；最高的「估计 + 加成」是 {ub}；各台拉动次数 {n}；累计遗憾 {reg}。
:::

## 用概率分布表达「我有多不确定」 {#step3 h2=s3t}

::: strings
nav3: 3 汤普森采样
:::

第 3 步 · 汤普森采样 {#s3k .step-kicker i18n=text}

这一步要回答：能不能直接用「信念」来选择？**汤普森采样**为每台机器维护一条 **Beta 分布**曲线，表示对它中奖概率的信念：起初是平的（什么都不知道，Beta(1,1)），每次中奖 α 加 1，每次没中 β 加 1。选择时从每台的曲线里各抽一个数，拉抽到最大的那台。拖动「已拉步数 t」（或自动播放）：曲线怎样从宽变窄，向真实概率（底部短竖线）靠拢；拉得多的机器曲线更窄。（一次固定随机种子的模拟。） {#s3e .explain}

::: html step3-1
cv3: 各台中奖概率的 Beta 分布
s3tL: 已拉步数 t
s3reset: 重置
:::

Beta(α, β) = 看到 α−1 次中奖、β−1 次没中之后，对中奖概率的信念；均值 α/(α+β)。 {#s3term .term i18n=text}

::: strings

s3Ax: 中奖概率 0 → 1
s3Leg: 曲线 = 信念；底部短竖线 = 真实概率；曲线越窄越确定
s3ro: 已拉 <b>{t}</b> 步；各台 Beta 参数 α/β：{ab}；各台拉动次数 {n}；累计遗憾 {reg}。
:::

第 4 步 · 策略对比 {#s4k .step-kicker i18n=text}

这一步要回答：几种策略谁更省？图是平均累计遗憾（越低越好）。五台机器里一台的中奖概率是 0.5 + Δ，其余四台都是 0.5：Δ 是最好机器的优势。拖动 Δ：优势越小越难分辨，各条曲线怎样变化？拖动「总步数」看曲线增长是否放缓：遗憾曲线变平，说明已经锁定最好的机器。注意：UCB 的 c = 1 是教科书的取值，这里它在较短的时间内探索偏多；c = 0.3 在本页的设置里更省，但这只是本页这组机器上的现象，不构成保证。 {#s4e .explain}

## 收束：探索和利用之间的取舍 {#step5 h2=s5t}

::: strings
nav5: 5 终章
:::

第 5 步 · 终章 {#s5k .step-kicker i18n=text}

多臂老虎机把「再试试」与「拉最好的」的矛盾量化成遗憾；几种策略只是用不同方式让不确定性随着次数缩小。 {#s5e .explain i18n=text}

::: html step5-1
c1t: 看不见真实概率
c1b: 只能靠估计，次数少时估计很宽，遗憾衡量为此付出的代价（第 0 步）。
c2t: 纯贪心会锁死
c2b: 开局不走运就可能永远不再尝试好机器；ε 提供随机探索（第 1 步）。
c3t: 让不确定性指路
c3b: UCB 给拉得少的机器加成；汤普森采样从信念里抽样（第 2、3 步）。
c4t: 没有通用赢家
c4b: 常数 c、优势 Δ 和时间长度都会改变排名（第 4 步）。
modelT: 模型与局限
modelB: 每台机器是概率固定不变、相互独立的伯努利事件；真实场景（广告、临床试验）常有概率随时间变化、上下文信息和延迟反馈。遗憾需要知道真实概率，只能在模拟中计算。所有模拟使用固定随机种子，排名只对本页的机器设置成立。
:::
