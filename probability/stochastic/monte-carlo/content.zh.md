## 一颗豆子不会算，一万颗会 {#step0 h2=s0t}

::: strings
nav0: 0 钩子
:::

第 0 步 · 钩子 {#s0k .step-kicker i18n=text}

在正方形里均匀地乱撒点，中间画一个内切圆。落在圆里的点数 ÷ 总点数，就是圆与正方形的**面积比**——而这个比值恰好是 π/4。所以不用量、不用算，只要数点，π 就会自己浮出来：**π̂ = 4 × 圆内点数 / 总点数**。看右上角的读数：长期误差尺度会随点数增多而缩小，但单次加点不保证更接近3.14159… {#s0e .explain}

## 频率多起来，就会露出概率的脸 {#step1 h2=s1t}

::: strings
nav1: 1 比例即概率
:::

第 1 步 · 比例即概率 {#s1k .step-kicker i18n=text}

慢下来，一颗一颗看。每颗点落在圆内还是圆外，是一次随机事件；撒得多了，「落在圆内」的**频率**会贴上它的**概率**，而概率就是面积比。这里藏着关键的约分：圆面积 πr² 与它外接正方形面积 (2r)² 之比 = π/4，**r 被约掉了**——所以换半径，比例纹丝不动。撒点范围是圆的外接正方形，切到 r = 0.3，圆和正方形同比例缩小，亲手验一验。 {#s1e .explain}

::: html step1-1
s1rLab: 圆半径 r（撒点范围 = 圆的外接正方形）
dropOne: 撒一颗
autoSlow: 自动慢撒
:::

单颗点什么都说明不了：它要么在内，要么在外，没有「0.7854 颗落在圆内」这回事。概率不是某一颗点的属性，是点多了之后，频率自己露出来的脸——这就是大数定律在干活，它是概率线后面几页的地基。 {#s1hint .hint}

## 样本四倍，每次误差都减半吗？ {#step2 h2=s2t}

第2步 · 重复估计的波动 {#s2k .step-kicker i18n=text}

## 没有公式？撒就完了 {#step3 h2=s3t}

::: strings
nav3: 3 无公式的面积
:::

第 3 步 · 无公式的面积 {#s3k .step-kicker i18n=text}

换上一个心形：它由右边的隐式方程定义，面积没有顺手的公式可套（硬算要上重积分）。但撒点不在乎有没有公式：在包围盒里均匀撒点，**面积估值 = 包围盒面积 × 落入率**。读数里的参考值不是解析真值，是用 1600×1600 的密网格一格一格数出来的数值积分——把口径摆在明处，估值慢慢贴上它，就是蒙特卡洛在干正经活。 <a class="fourier-link" href="../../../signal/systems/convolution/#step3">面积在卷积页是另一种算出法：输出 = 重叠面积 →</a> {#s3e .explain}

::: html step3-1
s3formulaNote: 心形的定义方程。落入判定就是把点的坐标代进去看不等式成不成立——没有第二句规则。
s3shapeLab: 形状
shHeart: 心形
shStar: 五角星
shBlob: 云朵
runStart: 开始撒点
:::

积分的本质是「数格子」：网格法把格子摆整齐了数，网格越细越准、格子数却平方地涨；蒙特卡洛把格子换成运气，精度只认 1/√N。形状越怪，公式越先投降，而撒点永远只有一句「数就行」。第 5 步你会看到：到了高维，网格连投降的机会都没有。 {#s3hint .hint}

## π 还能从「撞线」里掉出来 {#step4 h2=s4t}

::: strings
nav4: 4 布丰投针
:::

第 4 步 · 布丰投针 {#s4k .step-kicker i18n=text}

地板上画等距平行线（间距 d），把一根长 L 的针随机抛下去：针的中心位置均匀、朝向 θ 在 [0, π) 上均匀。它压到线的概率是 **P = 2L / (πd)**——反解出来，**π̂ = 2L · N / (d · 相交数)**。1777 年布丰提出这个问题时没有计算机，他是靠真人一根根扔针数出来的。注意公式成立要求 L ≤ d，滑杆就卡在 1.0。 {#s4e .explain}

::: html step4-1
s4lenLab: 针长 L / 线距 d
dropNeedle: 扔一根
autoDrop: 自动连扔
drop100: 连扔 ×100
:::

和第 0 步是同一台机器，只是把「面积比」换成了「撞线概率」：π̂ 的分母是相交数，所以开局相交太少时它会疯狂跳动，扔得多了才肯稳下来。概率这东西不住在公式里，住在重复里。 {#s4hint .hint}

## 网格死了，豆子还活着 {#step5 h2=s5t}

::: strings
nav5: 5 高维
:::

第 5 步 · 高维 {#s5k .step-kicker i18n=text}

把撒点搬进 d 维：单位超立方体 [0,1]<sup>d</sup> 里内切一个半径 0.5 的超球，它的体积比真值是 π<sup>d/2</sup>·(0.5)<sup>d</sup> / Γ(d/2+1)（Γ 读作「伽马」，是阶乘的推广：整数上 Γ(n+1) = n!，半整数上也有值，如 Γ(1/2) = √π——读数里的真值就是拿它算的，公式里把它当一个普通数看即可）。网格法先死给你看：哪怕每维只取 10 个点，总数就是 <strong>10<sup>d</sup></strong>——维度一高，没开始算就结束了。而撒点的**绝对**误差依旧 ~1/√N，不随维度变；代价转嫁成另一件事：高维里超球的体积占比小得可怜，命中越来越稀有（盯着命中数看）。左图画的是点的前两维投影，落入判定用的却是全部 d 维。 {#s5e .explain}

::: html step5-1
s5dimLab: 维度 d
:::

真实世界的高维积分——电影渲染里光线怎么走、期权怎么定价、粒子在反应堆里乱撞——维度动不动几十上百。网格在那儿连「开始」都做不到，所以这些行业全在撒豆子：不是它多聪明，是别无选择。 {#s5hint .hint}

## 随机数从哪来——以及一场挑战 {#step6 h2=s6t}

::: strings

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

本页所有的「随机」都是**带种子的伪随机**（mulberry32 算法）：种子一给定，整条点列就被定死，同一颗种子必然逐点重现。这不是作弊，恰恰是科学实验要的品质——**结果可复查**。下面亲自验：记下某个种子撒出的前 10 个点，再点「用同一种子重演」，它们会一个不差地重新落一遍。 {#s6e .explain}

::: html step6-1
s6seedLab: 种子
s6first: 撒前 10 点并记下
s6replay: 用同一种子重演
:::

**挑战：用最少的点，把 π̂ 送进 3.14 ± 0.005**（即落进 [3.135, 3.145]）。小批多次撒、每批后看读数，进了带就锁定达标点数。先把话说破：N 很小时就能进带，多半是**运气**；按 σ 估算，想让 2σ 都缩进这条带，需要约 43 万个点。真正让点变「值钱」的是方差缩减术——分层采样、对偶变量——是概率线后面的后话，本页只立路牌。 {#s6ce .explain}
