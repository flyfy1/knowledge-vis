- category `probability`，stage `senior`（均已在 pages.config.js 注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure + water-cycle；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，此处存疑，仅记录）。
- 去重：站内无回归/相关页；gradient-descent 的第 6 步“当场训一个模型”是同一拟合的优化视角（重合 <20%），statistical-inference/mean-median-mode 不涉及双变量。
- 核心直觉：r=标准化偏离乘积的平均；最小二乘使残差平方和最小；离群点与高杠杆点拽动拟合；相关≠因果（混杂）；r 只量线性；回归到平均。

## 步骤（每步五必填项：已知 / 唯一问题 / 输入与求量 / 控件与预期观察 / 适用条件）
0. **相关系数 r**
   - 已知：平均数。
   - 唯一问题：怎样用一个数说明两量一起变化得多整齐？
   - 输入与求量：输入设定相关度 ρ（−1…1）、随机种子；求样本 r 与同/反向点数。
   - 控件操作与预期观察：拖 ρ：点云由圆变斜长条，绿点占多数 r>0；换一批点看抽样波动。
   - 适用条件：正态二元模拟数据；80 点。
1. **最小二乘**
   - 已知：r。
   - 唯一问题：怎样的直线算最贴？
   - 输入与求量：输入 m（0–2）、b（−2…12）；12 点；求 SSE 与最优线。
   - 控件操作与预期观察：拖 m、b：残差方块面积随之变化；显示最优线；一键对齐（斜率精确到 0.05）。
   - 适用条件：只算竖直残差。
2. **一个离群点**
   - 已知：最小二乘线。
   - 唯一问题：一个异常点会拽歪多少？
   - 输入与求量：输入离群点 (x 2–21, y −5…25)；求带/不带它的斜率与 r。
   - 控件操作与预期观察：中间上下拖：线几乎不动；最右端上下拖：斜率大幅摆动。
   - 适用条件：12 个基准点固定。
3. **相关不是因果**
   - 已知：r。
   - 唯一问题：相关就是因果吗？
   - 输入与求量：输入按气温分五档开关；求总体 r、档内 r、气温与两量 r。
   - 控件操作与预期观察：分档后各条线变平，档内 r 小得多（平均≈0.07，最大|r|≈0.34）。
   - 适用条件：构造的混杂模拟，真实混杂常未知。
4. **r 看不见曲线**
   - 已知：r 与 R²。
   - 唯一问题：r 接近 0 就没关系吗？
   - 输入与求量：输入四种形状；求 r、R²。
   - 控件操作与预期观察：直线 r≈0.91；抛物线 r≈0；圆环 r≈0；一个远点撑出 r≈0.57–0.6+。
   - 适用条件：每组 40 点，种子固定。
5. **回归到平均**
   - 已知：拟合斜率。
   - 唯一问题：极端父母的孩子为何平均不那么极端？
   - 输入与求量：输入 ρ（0–1）；300 对；求斜率与最高 10% 父母/孩子均值。
   - 控件操作与预期观察：拖 ρ：橙色大点从 y=x 线向平均下落；终章含回顾与 3 条互链。
   - 适用条件：均值 170、标准差 7；ρ 非遗传模型。

## 模拟设定与模型失配
全部为种子伪随机模拟，非实测；探针独立手算 lsq 与 SSE（1/6），验证扰动最优线必增大 SSE、曲线/圆环 r≈0、离群点伪相关、混杂分档下降与高度回归斜率≈ρ。
