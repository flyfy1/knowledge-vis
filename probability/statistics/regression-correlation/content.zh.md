这一步要回答：怎样用一个数说明两个量一起变化得有多整齐？画面里 80 个点，横纵坐标已标准化（以各自平均为中心）。把每个点到平均点的水平偏离与竖直偏离相乘：同向（右上或左下，绿点）乘积为正，反向（红点）为负。**相关系数 r** 就是这些乘积按两个量的波动幅度归一化后的平均，范围 −1 到 +1：+1 是完美正比直线，0 是看不出线性关系，−1 是完美反比。**观察：**拖动设定的相关度 ρ，点云从圆变成斜长条，绿点占多数时 r 为正；样本的 r 与设定的 ρ 不完全相等，点「换一批点」看抽样的波动。这是模拟数据。 {#s0e .explain}

## 怎样的直线，才算“最贴”这些点？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 最小二乘
:::

::: html step1-1

s1k: 最贴的那条线
:::

这一步要回答：给定 12 个点，哪条直线 y = m·x + b 与它们的总体差距最小？每个点到直线的竖直距离叫**残差**；把每个残差画成一个正方形（面积 = 残差²），所有正方形面积之和就是**残差平方和**（SSE）。**最小二乘线**就是使 SSE 最小的那条。**观察：**调斜率 m 和截距 b，橙色方块的总面积（读数 SSE）会变大变小；点「显示最小二乘线」看绿色虚线，或点「一键对齐」把滑杆设为最优值（斜率精确到 0.05），此时 SSE 到达最小，比其他任何直线都小。 {#s1e .explain}

这一步要回答：个别奇怪的点会改变结论吗？拖动红色点的位置，青色线是包含它的最小二乘线，灰色虚线是不含它的。最小二乘用**平方**惩罚残差，所以离得远的点“发言权”特别大；在横轴的两端（x 很小或很大）的点杠杆更大（称为**高杠杆点**）。**观察：**先把红点放在中间（x ≈ 7），上下拖：线几乎不动；再放到最右端（x = 21）上下拖：斜率大幅度摆动，r 也跟着变。结论：看到相关系数前，先画图看一眼。 {#s2e .explain}

## 冰淇淋卖得多，溺水的人也多，是冰淇淋害的吗？ {#step3 h2=s3t pre=1}

这一步要回答：两个量相关，就是一个导致了另一个吗？这里模拟 150 天：每天的气温 T 同时推动“冰淇淋销量”和“溺水人数”，两者之间没有任何直接影响；但把所有天放在一起，销量与溺水强相关（红线）。**混杂因素**指同时影响两者的第三个量（这里是气温）。点「按气温分五档」：每档内（气温几乎相同）两条青/紫/橙线都变平，档内的 r 小得多。**观察：**对比总体 r 与档内 r：相关来自气温，不来自冰淇淋。要判断因果，通常需要做实验（随机分配）或控制混杂因素。 {#s3e .explain}

## r 接近 0，就说明两个量没有关系吗？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 r 看不见曲线
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: r 的盲区
:::

这一步要回答：r 能发现所有类型的关系吗？不能：r 只衡量**线性**关系。四组数据：直线，r 接近 +1；抛物线 y = x²（完全确定的关系！）但对称，r 约为 0；圆环，r 约为 0；一堆无关的点加一个远处的点，r 竟然很大（一个点撑起来的假相关）。**R²** 是 r 的平方，表示直线“解释”了多少比例的变化。**观察：**依次点四个按钮，比较红虚线（最小二乘线）与点的形状，以及 r。结论：永远先画散点图。 {#s4e .explain}

## 高个子父母的孩子，平均比父母矮一点？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 回归到平均
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 回归到平均
:::

这一步要回答：为什么“极端”的父母，孩子平均没那么极端？本图模拟 300 对父母与孩子身高（平均 170 cm，标准差 7 cm），设定父母与孩子的相关度为 ρ。灰虚线是“孩子和父母一样高”的 y = x 线，绿线是最小二乘线，斜率约等于 ρ。若 ρ &lt; 1，最小二乘线比 y = x 平，所以最高的 10% 父母（橙点）的孩子平均更接近 170——这就是**回归到平均**。它不是遗传在“拉回”，而是因为父母身高只能解释孩子身高的一部分。**观察：**拖动 ρ：ρ = 1 时橙色大点落在 y = x 上，ρ 越小越向下靠近平均。 {#s5e .explain}
