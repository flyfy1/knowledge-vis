## 骰子平均值的变形记 {#step0 h2=s0t}

::: strings

第 0 步 · 钩子 {#s0k .step-kicker i18n=text}

一台骰子机。先掷 **1 颗**：直方图是平的（1–6 等高）。切换到**掷 2 颗取平均**：开始隆起；**5 颗**、**30 颗**：钟形拔地而起，中心始终钉在 3.5。单颗骰子毫无钟形可言，平均却把钟形变了出来——这是全概率论最像魔法的一条定理。 {#s0e .explain}

## 原料什么样都有 {#step1 h2=s1t}

::: strings
nav1: 1 母分布画廊
:::

第 1 步 · 母分布画廊 {#s1k .step-kicker i18n=text}

把「原料」（母分布）轮流摆上台：平的、歪的、双峰的、离散的、长尾的。每种旁边都写明理论均值 μ、标准差 σ 的**来源公式**——后面所有理论曲线都只用这些值画，不许拿经验值冒充。原料越怪越好：定理的威力就在于对原料几乎不挑。 {#s1e .explain}

::: html step1-1
pUniform: 均匀 U(0, 1)
pExp: 指数 Exp(1)
pBimodal: 双峰（两个高斯混合）
pDice: 骰子（1–6）
pPareto: 帕累托 Pareto(α)
alpha15: α = 1.5（方差无穷）
alpha35: α = 3.5（方差有限）
s1warn15: ⚠ α = 1.5 时 σ = ∞：经典的中心极限定理**不适用**。它在第 4 步有一场专门的「失效展览」——不美化、不截尾，原样呈现。
:::

记住这五个原料的形状。第 2 步你会选一种、把它的均值抽 1 万组，看钟形怎么从任意一种原料里长出来。 {#s1hint .hint}

::: strings
s1ro: 理论 μ = <span>{mu}</span> · 理论 σ = <span>{sigma}</span> · 公式：{formula} · 采样 2 万点绘直方图，种子 {seed}
fUniform: μ = (a+b)/2 = 0.5，σ = (b−a)/√12 ≈ 0.2887
fExp: μ = 1/λ = 1，σ = 1/λ = 1
fBimodal: 混合 μ = Σwᵢμᵢ = 3.5，方差 = Σwᵢ(σᵢ²+μᵢ²) − μ² = 2.61，σ ≈ 1.6155
fDice: μ = (1+2+⋯+6)/6 = 3.5，σ² = 35/12，σ ≈ 1.7078
fPareto35: μ = α/(α−1) = 1.4，方差 = α/[(α−1)²(α−2)]，σ ≈ 0.6110
fPareto15: μ = α/(α−1) = 3，方差 = **无穷**（α ≤ 2 时「二阶矩发散」——把每个值离中心的距离平方、再平均，这个数大到没有有限值，所以方差不存在）
lgPdf: 理论密度 pdf
lgHist: 真采样直方图
:::

第 2 步 · 抽样分布实验室 {#s2k .step-kicker i18n=text}

## 诚实展览角：磨得慢的，和磨不出来的 {#step4 h2=s4t}

::: strings
nav4: 4 慢与坏
:::

第 4 步 · 慢的与坏的 {#s4k .step-kicker i18n=text}

左：**指数分布**，n = 2 / 5 / 10 / 30——偏态被一点点磨平的现场。偏态越重、需要的 n 越大，「n ≥ 30 就够」只是经验法则、不是定律。右：**帕累托 α = 1.5**——方差无穷，经典的中心极限定理**不适用**：n 拉到 100，均值直方图依然野，单个极端值能把整组平均拽走。它不趋向正态——会收敛到另一种稳定分布（点名而已，不展开）。 {#s4e .explain}

::: html step4-1

n2: n = 2
n5: n = 5
n10: n = 10
n30: n = 30
s4rt: 坏：帕累托 α = 1.5——方差无穷，定理下班
n100: n = 100
:::

⚠ 诚实声明：**经典中心极限定理要求母分布方差有限。**帕累托 α ≤ 2 时二阶矩发散（把离中心的距离平方再平均、这个量大到无穷），均值没有「σ/√n」的收缩律。本页所有「趋向正态」的表述，都默认方差有限——这句话是定理的一部分，不是脚注。 {#s4warn .warn-box tag=div}

左图看「慢」：偏态 2 的指数分布，n = 30 才勉强像钟。右图看「坏」：方差无穷时，直方图不收敛、不美化、不截尾——原样呈现。 {#s4hint .hint}

## 样本量计算器：民调 ±3% 的出身 {#step6 h2=s6t}

::: strings
nav6: 6 样本量计算器
:::

第 6 步 · 终章 {#s6k .step-kicker i18n=text}

场景：想估计一个均值/比例，要求误差不超过 **±E**、**95%** 置信。公式：**n = ⌈(zσ/E)²⌉**（z = 1.96）。算完不算完——当场真跑 K 组验证覆盖率，实测比例如实呈现（约在 95% 上下统计波动，**不是**恰好 95.00%）。经典数字：民调里常说的 n ≈ 1067，来自 E = 3%、σ = 0.5：(1.96×0.5/0.03)² = 1067.11，按四舍五入得 1067、向上取整得 1068——口径不同，差的只是这一个。 {#s6e .explain}
