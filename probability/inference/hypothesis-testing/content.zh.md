## 抛 20 次得到 15 次正面，硬币还像是公平的吗？ {#step0 h2=s0t pre=1}

::: strings
nav0: 0 p 值
:::

::: html step0-1
s0step: "第 0 步 · "
s0k: p 值
:::

<b>这一步回答：p 值到底是什么？</b>零假设 H₀：硬币公平，每次正面概率 0.5。柱子是 H₀ 下各个正面次数的概率。p 值 = 在 H₀ 为真时，出现“和观测一样罕见或更罕见”的结果的总概率（橙色柱，双侧）。p 越小，说明“如果硬币公平，这很难发生”，我们越怀疑 H₀。注意 p 值不是“硬币公平的概率”。拖动试验次数和正面次数。 {#s0e .explain}

lblFlips: 抛掷次数 n
lblHeads: 观测到的正面次数 k
:::

## 同一个实验做很多遍，p 值会是什么样子？ {#step1 h2=s1t pre=1}

::: strings
nav1: 1 p 值的分布
:::

::: html step1-1
s1step: "第 1 步 · "
s1k: 重复做实验
:::

<b>这一步回答：p 值本身也是随机的。</b>设定硬币真实的偏向 q 和每次抛的次数，点“做 100 次实验”：每次实验算一个 p 值，累计成直方图。q = 0.5（零假设为真）时，p 值大致均匀分布，约有 5% 落在 0.05 以下，那是“错误警报”（精确二项检验是离散的，所以略保守）；q 偏离 0.5 时，p 值堆在 0 附近——有真实效应时才常得到小 p。 {#s1e .explain}

## “p ≤ 0.05 就判有罪”，冤枉公平硬币的风险是多少？ {#step2 h2=s2t pre=1}

::: strings
nav2: 2 显著性水平
:::

::: html step2-1
s2step: "第 2 步 · "
s2k: 显著性水平 α
:::

<b>这一步回答：α 到底控制什么？</b>事先规定 α，当 p ≤ α 就拒绝 H₀。这样，公平硬币被误判的概率（第一类错误）至多是 α：橙色柱就是“拒绝域”，它们的概率之和是实际的第一类错误率。因为正面次数是整数，实际值常常略小于 α。α 是你愿意承担的“冤假错案率”的预算，调小它会让拒绝域变窄。拖动 α 和试验次数。 {#s2e .explain}

lblAlpha: 显著性水平 α（%）
:::

## 硬币其实有偏，检验能把它揪出来吗？ {#step3 h2=s3t pre=1}

::: strings
nav3: 3 漏判与功效
:::

::: html step3-1
s3step: "第 3 步 · "
s3k: 第二类错误与功效
:::

<b>这一步回答：真有问题时，检验有多大把握发现？</b>蓝柱是公平硬币的分布，右边彩柱是偏向 q 的真实硬币；彩柱落在拒绝域内（绿）的部分，是正确拒绝 H₀ 的概率，叫功效 = 1 − β；落在拒绝域外（红）是漏判，叫第二类错误 β。q 离 0.5 越远、试验越多，功效越高；收紧 α 会降低功效。拖动 q、次数和 α。 {#s3e .explain}

## 差别很小的偏硬币，要抛多少次才有八成把握发现？ {#step4 h2=s4t pre=1}

::: strings
nav4: 4 要抛多少次
:::

::: html step4-1
s4step: "第 4 步 · "
s4k: 要抛多少次

<b>这一步回答：样本量怎么定？</b>曲线是功效随抛掷次数的变化，虚线是常用的目标 80%。偏向越小，所需次数增长得非常快：q = 0.55 要近八百次（本页只算到 400，会显示“> 400”），q = 0.6 约两百次，q = 0.7 只要几十次。曲线略有锯齿，是因为正面次数是整数、拒绝域一格一格地变。读数给出第一次达到 80% 功效的次数。拖动 q、α 和次数。 {#s4e .explain}

## 同时检验很多枚公平硬币，总会有“显著”的吗？ {#step5 h2=s5t pre=1}

::: strings
nav5: 5 多重检验
:::

::: html step5-1
s5step: "第 5 步 · "
s5k: 终章 · 做了很多次检验
:::

<b>这一步回答：为什么“找到一个 p &lt; 0.05”不等于有发现？</b>每枚公平硬币单独检验，误报率约 α_实际（20 次抛掷时约 4.1%）。同时检验 m 枚，至少有一个误报的概率 = 1 − (1 − α_实际)ᵐ：20 枚就约 57%，100 枚几乎肯定。点“检验 m 枚”：红点是“显著”的硬币——它们全是公平的。打开“校正”把每次的标准收紧到 0.05/m（Bonferroni），误报几乎消失，代价是功效下降。 {#s5e .explain}

::: html step5-2
s5cv: 上：至少一个误报的概率随检验个数上升；下：每枚硬币一个点，红色为“显著”
lblM: 检验的硬币数 m
runTests: 检验 m 枚
bonfOff: 校正：关（α = 0.05）
recapTitle: 回顾
recap1: p 值 = 零假设为真时，出现至少和观测一样极端的结果的概率；它不是“假设为真的概率”。
recap2: α 是第一类错误（冤枉好人）的预算；β 是第二类错误（漏判），功效 1 − β 随效应大小和样本量上升。
recap3: 做很多次检验，总会碰到“显著”；需要校正，并区分“显著”与“重要、真实”。
modelTitle: 模型范围与局限
modelText: 模型：精确二项检验，H₀: q = 0.5，双侧 p 值用“不比观测更常见的结果”的概率相加；每枚硬币独立。因为离散，实际误报率常低于名义 α。真实研究还有效应大小、先验、研究设计、重复检验等问题；p 值也不能替代贝叶斯的“给定数据，假设为真的概率”。
