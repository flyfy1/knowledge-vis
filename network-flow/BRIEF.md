# Network Flow · 教学 BRIEF

## 一句话
把“网络很慢/很可靠”拆成可操作的因果链：分包 → 延迟与带宽 → 下一跳路由 → TCP 握手 → 拥塞窗口。

## 交互红线
- 分包读数由 `ceil(size*1024/mtu)` 真算，头部开销随包数变化。
- 传输时间由 `RTT + size/bandwidth` 真算；延迟与带宽不合并成一个黑箱旋钮。
- 路径策略改变跳数、传播延迟与队列等待，读数与画布同步。
- TCP 必须按 SYN → SYN-ACK → ACK 顺序改变状态；重置回 closed。
- 拥塞负载提高时，丢包率与等待上升、窗口下降，全部由纯函数生成。

## 边界
这是教学模型：省略真实路由表、MSS/TLS、ACK 累积和具体实现的 cwnd 单位；页面明确每层只承担自己的问题。
