# BRIEF：浮与沉（float-sink）· 小学科学
- category `physics`，stage `primary`（已注册）。Built-By: Claude Sonnet 5.5 via Mini Claude Code（self-check，无独立评审）。模板页 cell-structure；共用生成脚本。可见标识：页脚双语署名（provenance 规范对 Claude 版无明确要求，记录不确定性）。
- 核心：浮力 = 排开的水的重量；密度小于水则浮；空心船靠外形体积排开更多水；水密度变大更易浮。

## 步骤（五必填项）
0. 谁会浮。已知：重量、体积；问题：同体积 40 cm³ 的五种物体谁浮？输入选物体；观察：重力箭头（橙）与浮力箭头（绿）、水面随排开体积变化；浮者排开 ρV，沉者排开 40；适用：理想水 1 g/cm³、静止。
1. 排开的水。问题：浮力如何随浸入变化？输入浸入比例 0–1；观察：水面随浸入上升，右图浮力线与重量线 24 gf 相交于 60%；读数比较浮力与重量。
2. 球变成船。问题：形状为何改变浮沉？输入船的外形体积（31.25–150）；观察：外形<50 沉底、≥50 浮起且排开水恒为 50，浸入比例 = 50/外形；适用：外形体积为含空气的外轮廓体积。
3. 装货。问题：载重上限？输入：加/拿走弹珠、清空；观察：水线逐格升高，10 颗刚好满载，11 颗沉；清空恢复到 50 gf。
4. 盐水。问题：水密度变了怎样？输入水密度 1.00–1.25；观察：鸡蛋在 >1.08 时上浮，浸入比例 = 1.08/ρ水。
5. 终章。输入自重、外形体积；读所需最小外形体积 = 自重/ρ水；深链 lever-pulley#step0、equations-balance#step1（均已核对存在）。

## 新术语首现表
密度、浮力（步 0）；排开的水（步 1）；外形体积（步 2）；水线/载重（步 3）；gf 克力（步 0 带口径，模型说明里补充与牛顿的关系）。

## 模拟设定 / 模型失配
理想不可压缩水；不计波动、表面张力、翻覆稳定性；物体形状在图中为示意；步 4 中水密度可变。
